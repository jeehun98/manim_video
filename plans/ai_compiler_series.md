# AI 컴파일러

계산을 표현하고, 의미를 지키며, 실행을 바꾸는 방법.

새 영상 7편과 기존 영상 2편을 재생목록에 배치한다. 역사적 계보와 기술적 변환 경로를 구분한다. 정규식에서 오토마타를 거쳐 IR로 직접 변환된다고 설명하지 않는다. 영상 안에서는 앞 영상 복습·다음 영상 예고 없이 각 질문을 독립적으로 완결한다.

| 편 | 제목 | 범위 |
|---|---|---|
| 01 / aic01 | 유한한 뉴런으로 무한히 많은 패턴을 인식할 수 있을까? — 신경망에서 정규 표현식까지 | 사용자 콘티에 따른 역사·상태·정규 언어 도입 |
| 02 | 기억이 유한한 기계는 무엇을 인식할 수 있을까? | 상태·전이·구별 가능한 입력 |
| 03 | 무한히 많은 문자열을 하나의 식으로 표현할 수 있을까? | 선택·연결·반복 |
| 04 | 정규식과 상태 기계는 정말 같은 문자열을 알아볼까? | 동등성의 양방향 근거 |
| 05 | 정규 표현식은 어떻게 실행 가능한 기계로 바뀔까? | Thompson 구성 |
| 06 | 같은 정규식인데 왜 실행 속도가 다를까? | 상태 집합 시뮬레이션·DFA 실행·백트래킹 |
| 07 | 왜 정규 표현식만으로는 모든 문법을 이해할 수 없을까? | 임의 깊이 괄호·스택·Parsing·AST |
| 기존 calc07 | 같은 신경망인데 실행 그래프는 왜 다를까? | 연산 그래프·실행 계획 |
| 기존 calc08 | AI 컴파일러는 어떻게 같은 계산을 알아볼까? | 의미 보존·합법성·비용 모델 |

07에서는 이론적 정규식의 한계를 다룬다. 깊이 상한이 있으면 정규 언어로 표현 가능하며, 재귀 등 실용 엔진 확장과 구분한다. IR 연결은 표현 능력의 언어 계층 상승이 아니라 대상에 적합한 표현과 의미 계약의 설계 원리이다.

01의 실제 제작 자료는 `episodes/aic01_neurons_regex/`에 있다. 나머지 새 편은 기획만 확정된 상태이다.

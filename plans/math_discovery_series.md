# 다음 영상 시리즈 제작 계획 — 정답을 찾는 것과 이해하는 것

작성일: 2026-10-13 · 상태: 기획 초안, 대본·TTS·렌더 미착수

## 제작 방향

첨부 기획을 바탕으로 세로형 숏폼 10편을 계획한다. 편당 60~90초를 초기 목표로 삼되 실제 대본과 TTS를 기준으로 조정한다. 롱폼으로 제작하려면 대본 확장과 씬 분할을 별도로 진행한다.

시리즈를 관통하는 질문은 **“정답을 발견하는 것과 수학을 이해하는 것은 같은가?”**다. 처음부터 AI와 리만 가설을 묶지 않는다. 1부에서 인간이 발견한 수학적 연결을 경험하고, 2부에서 AI의 구체적인 발견 방법을 살핀 뒤, 3부에서 두 이야기를 만난다.

각 편은 질문 하나와 주장 하나로 완결한다. 다음 편 예고를 보지 않아도 그 편의 학습 목표가 남아야 한다. AI의 이해 여부에 대한 단정은 결론으로 정해 두지 않는다.

## 1부 제작 기준

### 01 — 개별 위치와 전체 개수

- 학습 목표: π(x)는 x 이하 소수의 개수이며, 소수정리는 π(x)/(x/log x) → 1이라는 상대적 진술임을 이해한다.
- 예상 흐름: 0~8초 소수 위치 관찰, 8~22초 개수 계단 생성, 22~43초 근사 곡선 비교, 43~60초 범위를 넓혀 상대 오차 관찰, 마지막 10초 질문 회수.
- “소수에는 규칙이 없다”, “근사가 정확한 개수를 준다”는 표현을 피한다. 절대 오차 감소도 주장하지 않는다.
- 작은 범위에서 근사가 부정확한 모습도 보여준다. x>1에서 곡선을 계산하고, 화면용 소수 데이터는 체로 생성해 개수를 확인한다.
- 울람 나선은 선택적 도입 이미지다. 대각선 무늬를 소수정리의 근거로 사용하지 않는다.

### 02 — 연결을 만드는 언어

- 학습 목표: 유일한 소인수분해가 오일러 곱의 기반임을 보여준다.
- 실수 s>1에서 곱의 전개를 먼저 관찰하고 복소수 s=σ+it로 넘어간다.
- 급수와 오일러 곱의 해당 표현에는 Re(s)>1 조건을 표시한다. 임계띠에는 해석적 연속으로 접근함을 구분한다.
- “복소수를 넣으면 소수 위치가 바로 나온다”는 인상을 주지 않는다. 한 편에 해석적 연속의 엄밀한 구성을 모두 담지 않는다.

### 03 — 영점과 오차

- 학습 목표: 영점의 위치가 분포 오차와 연결된다는 직관을 얻는다.
- 제작 시 π(x)를 파동으로 직접 복원한다고 단순화하지 않는다. 명시적 공식의 대상은 ψ(x) 등으로 명확히 정하고 소수 거듭제곱의 가중치를 설명한다.
- 유한 개 영점으로 만든 근사는 절단 근사라고 표시한다. 계단의 불연속점 처리와 나머지 항은 실제 계산식에 맞춰 기록한다.
- 리만 가설은 모든 비자명 영점의 실수부가 1/2이라는 명제로 소개한다. “영점이 전부 1/2”이라고 줄이지 않는다.
- 사용할 공식과 수치 자료의 출처를 먼저 확정한 뒤 화면 계산을 구현한다.

### 04 — 예상하지 못한 연결

- 학습 목표: 통계적 유사성이 발견의 단서가 될 수 있음을 경험한다.
- 제목의 비교 대상은 소수 자체보다 제타 함수의 비자명 영점임을 분명히 한다.
- 영점과 에너지 준위의 간격은 평균 간격을 맞춘 뒤 비교한다. 모든 양자계가 같은 통계를 보인다고 말하지 않는다.
- 쌍상관, 최근접 간격 분포, 수치 관찰, 추측을 구분한다. 표본 크기와 데이터 생성 방식을 화면 밖 제작 자료에 남긴다.
- 통계적 유사성이 물리적 동일성이나 리만 가설의 증명이 되지는 않는다. 필요한 원문과 데이터 확보 후 상세 콘티를 확정한다.

## 마지막 두 편의 평가 틀

네 축은 순위표나 AI의 내면을 판정하는 점수가 아니라 사례를 읽는 질문으로 쓴다.

1. 발견: 어떤 결과가 새로 추가됐는가?
2. 검증: 어떤 가정 아래 누가 무엇을 확인했는가?
3. 독창성: 선행 결과와 비교해 무엇이 달라졌는가?
4. 이해: 설명, 다른 문제로의 전이, 일반화, 개념 연결에서 무엇을 보여주는가?

형식 검증도 명제의 형식화와 가정이 의도에 맞는지 확인해야 한다. 검증된 복잡한 증명을 다루는 09편 도입은 실제 사례인지 사고실험인지 명시한다. 인간의 이해도 하나의 방식으로 고정하지 않는다.

마지막 질문: “수학의 발전은 정답이 늘어나는 일일까요, 세계를 설명하는 새로운 방법이 늘어나는 일일까요?” 두 가능성을 배타적인 선택으로 만들지 않고 시청자가 자신의 기준을 생각하도록 마친다.

## 제작 순서와 산출물

1. 01~04편의 출처·수학적 조건을 조사하고 각 편 brief.md와 narration.md를 작성한다. 01과 04의 핵심 시각 실험을 먼저 확인한다.
2. 01편 대본과 구간 목표 시간을 확정하고 TTS를 준비한다. 화면 표기는 원래 숫자·영문을 유지하며 발음 표기는 tts_script.txt로 분리한다.
3. episodes/discover01_prime_count/부터 scene.py를 구현한다. 누적 목표 시간과 프레임·자막 영역을 확인한다.
4. scripts/render.py에 실제 구현된 편만 등록하고 README에 파일과 실행법을 기록한다. 계획 단계의 ID는 아직 등록하지 않는다.
5. 360×640 미리보기를 검토한 뒤 1080×1920, 30fps 최종본을 만든다. 음성 결합 여부와 자막 제공 방식을 해당 편 brief.md에 기록한다.
6. 01편의 설명 밀도와 가독성을 반영해 02~04를 순차 제작한다. 1부가 정리된 후 조사 결과에 따라 05~08의 사례를 확정한다.
7. 09~10은 앞선 완성 영상의 실제 주장과 화면을 회수하도록 마지막에 대본을 확정한다.

현재 체크아웃에는 다수의 episodes와 longforms/mm01~mm08 등이 존재한다. 과거 환경 기록만으로 소스나 렌더 도구의 부재를 판단하지 않는다. 실제 렌더 단계에서 Python·Manim·FFmpeg·한글 폰트를 다시 점검한다.

다음 작업의 완료 기준은 **01편의 출처가 붙은 제작 기준, 구간별 대본, 화면 콘티 확정**이다. 전체 10편의 화면 제작을 동시에 시작하지 않는다.

# 최소 구조를 찾아서

2026-10-31 · 사용자 요청을 반영한 현재 전체 구성 · 독립 쇼츠 10편 + 통합 롱폼

최종 질문: **우리가 발견한 가장 작은 구조와, 실제로 존재할 수 있는 가장 작은 구조는 같은 것일까?**

## 변경 사항과 현재 단계

이 문서가 이전 `minimal_neural_computation_series.md`의 신경망 중심 9편 구성을 대체한다. 사용자 제시 순서대로 ETH → 최소 유전체 → 최소 실현 → 충분통계량 → 그래프 희소화 → Lottery Ticket → 대칭성 → Superposition → Representation Alignment → Minimum Network Search를 배치한다.

Git Re-Basin은 09편의 비교 방법 중 하나로 다룰 수 있다. Neural Collapse, Low-Rank, Intrinsic Dimension은 독립 편 목록에서 제외하고, 필요성이 있을 때만 후반부의 보조 자료로 검토한다. 이들을 반드시 모두 설명해야 한다는 전제를 두지 않는다.

현재 작업은 전체 구성 수정이다. 01편에는 대화에서 검토한 대본이 있으나 새 기획에 맞춘 결말 수정이 필요하다. 나머지 편의 완성 대본과 TTS·타이밍·자막·영상은 이 구성 작업에서 생성하지 않는다. 전체 길이는 확정 대본의 실제 발화시간에 따라 정한다.

## 서사 원칙

최소 구조를 탐색하기 전에 **보존 대상, 적용 조건, 허용 오차, 줄일 비용**을 정한다. 각 사례의 최소성은 서로 다른 문제다. 실행시간, 유전자 수, 상태 차원, 통계적 정보, 간선 수, 신경망 파라미터 수를 하나의 수치로 비교하지 않는다.

‘실제로 발견된 최소 구조’라는 소개는 사례별로 한정한다. 증명된 최소 차원, 충분한 요약, 근사 보존 구조, 실험으로 얻은 작은 후보를 구분한다. 모든 사례에서 절대 최소가 발견되었다고 말하지 않는다.

각 쇼츠는 자체 질문 → 관찰·실험 → 조건과 해석 → 해당 질문의 답으로 완결한다. 이전 영상 복습·요약, 다음 영상 예고를 넣지 않는다. 01~05편 끝에 신경망 연결을 붙이지 않는다. 롱폼의 탐구 흐름은 편의 순서와 일관된 시각 언어로 형성한다.

## 10편 구성

### 01 · 계산의 한계는 정말 존재할까? — 지수시간가설(ETH)

- 질문: 경우의 수가 폭발하면 계산도 반드시 같은 속도로 증가해야 할까?
- 관찰: 10개와 20개 이진 선택의 경우의 수, 조건에 따른 후보 제거, 전수조사보다 빠른 알고리즘과 준지수시간의 구분.
- 보존 대상: 같은 논리 문제의 정확한 답. 소개하는 계수 알고리즘에서는 만족 할당의 정확한 개수.
- 줄일 비용: 입력 규모에 따른 실행시간 증가율. 표현 크기나 신경망 크기의 최소화가 아니다.
- 핵심: ETH에 도전하는 알고리즘의 공개 주장을 소개하되, 연구가 검토 중이라는 상태와 전체 계산 비용을 함께 설명한다. 보간은 제시된 접근 중 하나이며 가장 강한 상한의 모든 기법을 대표하지 않는다.
- 독립 결론: 현재 알려진 방법의 계산량이 그 문제의 피할 수 없는 계산량이라고 단정할 수는 없다.
- 기존 대본 수정 범위: ‘그렇다고 이 결과가 신경망도…’부터 마지막까지의 신경망 연결을 삭제한다. ‘이 주장이 옳다면…’ 뒤를 계산복잡도 자체의 결론으로 마무리한다. 새 결말 후보: “다만 더 빠른 알고리즘을 찾았다는 것이 가장 빠른 알고리즘을 찾았다는 뜻은 아닙니다. 계산 방법의 개선과, 더는 개선할 수 없다는 증명은 서로 다른 일이기 때문입니다.” 이 결말은 새 대본 검토 대상으로 둔다.
- 주의: ETH는 전수조사 필수설이 아니다. 준지수시간도 다항시간이나 실용적인 실행시간을 뜻하지 않는다. 검토 상태는 대본 확정·공개 시 다시 확인한다.

### 02 · 생명에 필요한 유전자는 몇 개일까? — 최소 유전체

- 질문: 유전자를 어디까지 제거해도 세포가 살아가고 증식할 수 있을까?
- 관찰: 유전자 제거 → 배양·증식 확인 → 조합 수정의 실험. JCVI-syn3.0의 473개 유전자는 역사적 사례로 표시한다.
- 보존 대상: 정해진 배양 조건에서의 생존·증식. 생존과 정상적 분열·성장 속도는 구별한다.
- 줄일 비용: 선택한 유전자 구성의 크기. 유전체 길이와 유전자 수도 구별한다.
- 독립 결론: 어떤 유전자가 필요한지는 환경과 함께 남아 있는 유전자에 따라 달라질 수 있다.
- 주의: 풍부한 배지의 지원을 받는 사례다. 473을 모든 생명의 보편적 최솟값이나 현재 최저 기록이라고 하지 않는다. 하나씩 제거할 수 없다는 결과와 가능한 모든 조합 중 전역 최소라는 증명은 다르다.

### 03 · 서로 다른 시스템이 완전히 같은 동작을 할 수 있을까? — 최소 실현

- 질문: 같은 외부 입출력을 만드는 데 내부 상태는 몇 개나 필요할까?
- 관찰: 입력으로 도달할 수 없는 상태 또는 출력에 드러나지 않는 상태가 있는 작은 선형 시스템을 비교한다. 물리적 회로·진동계는 동기를 제공하는 예로 쓰고, 정리는 명시한 선형 모델에서 설명한다.
- 보존 대상: 유한차원 선형 시불변 시스템의 전달함수, 즉 초기 상태 0에서 모든 허용 입력에 대한 정확한 입출력 관계.
- 줄일 비용: 상태 차원. 물리 부품 수·에너지·실행시간과 동일시하지 않는다.
- 독립 결론: 이 모델 계열에서는 가제어성과 가관측성을 만족하는 실현이 최소이며, 서로 다른 최소 실현은 가역적인 상태 좌표 변환으로 연결된다.
- 주의: 일부 테스트 입력의 일치로 전체 동작의 동일성을 증명하지 않는다. 임의 초기 상태에서의 반응까지 보존하는 문제는 별도 조건이 필요하다. 일반 비선형 시스템에 정리를 확대하지 않는다.

### 04 · 정보를 얼마나 버려도 정답을 유지할 수 있을까? — 충분통계량

- 질문: 관측값을 모두 보관하지 않아도 특정 추론에 필요한 정보가 남을까?
- 관찰: 독립·동일한 성공확률의 Bernoulli 시행에서 시행 횟수를 고정하고, 전체 0·1 순서와 성공 횟수 요약을 비교한다. 알려진 확률모형에서 성공확률에 대한 우도가 요약으로 결정되는 것을 보여준다.
- 보존 대상: 지정한 통계모형에서 모수에 관한 정보. 모든 질문에 대한 정답이나 원자료의 완전한 복원이 아니다.
- 줄일 비용: 추론에 쓰는 요약. 값 하나로 썼다고 저장 비트 수까지 무조건 최소인 것은 아니다.
- 독립 결론: 무엇에 대해 추론할지, 어떤 모형을 가정할지 정하면 버려도 되는 정보가 달라진다.
- 주의: 충분통계량과 최소충분통계량을 구분한다. 최소충분은 다른 충분통계량으로부터 결정될 수 있다는 정보적 의미이며, 최소 파일 크기·최소 실수 좌표 수와 곧바로 같지 않다. 시행 순서나 시간 변화가 중요한 질문에는 성공 횟수만으로 충분하지 않을 수 있다.

### 05 · 수많은 연결을 지워도 같은 성질이 남을까? — 그래프 희소화

- 질문: 간선을 줄이면서 무엇을 그대로, 또는 거의 같게 유지할 수 있을까?
- 관찰: 작은 가중 무방향 그래프에서 간선을 선택하고 남은 가중치를 조정한다. 저항망의 에너지에 해당하는 Laplacian 이차형식을 여러 벡터에서 비교한다. 보편 보장은 정리와 연결하며 몇 개 예시만으로 증명했다고 하지 않는다.
- 보존 대상: 스펙트럴 희소화의 경우 모든 x에 대해 (1−ε)xᵀLx ≤ xᵀL' x ≤ (1+ε)xᵀLx인 근사 관계.
- 줄일 비용: 간선 수. 동일한 간선을 무작정 삭제하는 방식과 가중치 재조정을 구별한다.
- 독립 결론: 어떤 성질과 오차를 보존할지 정해야 작은 그래프의 의미가 정해진다.
- 주의: 모든 최단거리·개별 간선·그래프의 모든 성질을 보존하지 않는다. 적은 간선을 가진 구조의 존재·구성 보장과 정확한 최소 간선 수는 다르다.

### 06 · 거대한 신경망의 모든 연결이 필요할까? — Lottery Ticket Hypothesis

- 질문: 큰 신경망 안의 일부 연결만으로도 학습할 수 있을까?
- 관찰: 학습·가지치기로 마스크를 찾고, 남은 가중치를 원래 초기값으로 되돌려 독립적으로 다시 학습한다.
- 보존 대상: 지정한 과제·데이터·학습 조건에서 원래 모델에 견줄 테스트 성능과 학습 가능성.
- 줄일 비용: 활성 연결 수. 희소 연결의 감소가 하드웨어 실행시간 감소를 보장하지 않는다.
- 독립 결론: 큰 설계 안에 더 작은 학습 가능한 부분망이 있을 수 있지만, 그 부분망이 최소라는 뜻은 아니다.
- 주의: 임의 부분망·임의 초기값에 대한 보장이 아니다. 앞선 사례와 달리 신경망만 실험적이라는 대비는 쓰지 않는다. 최소 유전체 역시 실험적 탐색이다. 같은 정확도와 같은 함수도 구별한다.

### 07 · 서로 다른 신경망이 같은 기능을 표현할 수 있을까? — 신경망의 대칭성

- 질문: 가중치 배열이 달라도 모든 입력에서 같은 출력이 나올 수 있을까?
- 관찰: 은닉 뉴런 순서와 앞뒤 연결·편향을 일관되게 교환해 출력을 보존한다. 원소별 활성화에서의 순열 대칭성을 작은 식으로 확인한다.
- 보존 대상: 정확한 입력·출력 함수.
- 탐구 대상: 같은 함수를 나타내는 여러 파라미터 표현의 동치. 이 단계는 크기 감소가 아니다.
- 독립 결론: 배열이 다르다는 이유만으로 서로 다른 계산이라고 판단할 수 없다.
- 주의: 뉴런 재배열은 뉴런 수 감소가 아니다. 상태·정규화·다른 연결이 있으면 함께 변환해야 한다.

### 08 · 하나의 뉴런에 여러 특징을 담을 수 있을까? — Superposition

- 질문: 특징의 개수는 뉴런이나 표현 차원의 개수와 같을까?
- 관찰: 저차원 공간에 더 많은 희소 특징 방향을 배치한 토이 모델에서 활성화와 간섭을 비교한다. 제목의 한 뉴런에서 출발해 분산된 방향의 중첩으로 설명을 넓힌다.
- 보존 대상: 특정 특징 분포에서의 재구성 또는 과제 성능. 모든 입력의 임의 정보를 손실 없이 담는다는 뜻은 아니다.
- 탐구 대상: 특징 수·표현 차원·개별 뉴런의 차이.
- 독립 결론: 특징의 단위가 반드시 개별 뉴런과 일대일로 대응하지는 않는다.
- 주의: 이미 압축된 표현일 수 있어 중첩이 추가 압축을 보장하지 않는다. 토이 모델의 결과를 모든 신경망에 대한 정리로 확대하지 않는다.

### 09 · 여러 신경망에서 공통된 구조를 발견할 수 있을까? — Representation Alignment

- 질문: 같은 입력을 처리한 서로 다른 모델의 표현에서 무엇을 비교할 수 있을까?
- 관찰: 공통 입력 집합에 대한 활성화 행렬을 얻고, 뉴런 순서·좌표계 변화·표현 차원이 다른 경우를 분리한다. CKA 같은 표현 유사도, 좌표 정렬, 같은 구조에서의 순열 정렬을 서로 다른 도구로 제시한다.
- 보존·비교 대상: 명시한 입력 집합에서의 표현 관계와 유사도. 비교 지표의 불변성을 먼저 밝힌다.
- 탐구 대상: 공통 구조의 후보와 차이. 단일한 ‘Representation Alignment 알고리즘’이 존재하는 것처럼 말하지 않는다.
- 독립 결론: 비교 기준을 정하면 공통점이 보일 수 있지만, 높은 표현 유사도가 동일한 기능이나 같은 인과적 회로를 증명하지는 않는다.
- 주의: 표본·정규화·지표 선택에 의존한다. Git Re-Basin의 가중치 순열 정렬과 CKA의 표현 유사도 측정은 서로 다른 작업이다. 선택한 입력에서의 상관관계와 모든 입력에서의 함수 동일성을 구별한다.

### 10 · 가장 작은 신경망은 어떻게 찾을까? — Minimum Network Search

- 질문: 정해진 기능을 유지하는 작은 모델을 찾으려면 무엇부터 정해야 할까?
- 독립 도입: “두 모델의 정확도는 같습니다. 하나는 더 작고, 다른 하나는 더 빠릅니다. 어느 쪽이 최소일까요?” 전편 요약으로 시작하지 않는다.
- 설계 순서: 과제·입력 분포·허용 오차·모델 계열·비용 기준 지정 → 작은 후보 제작 → 별도 데이터와 실제 실행 환경에서 평가 → 실패 사례와 탐색 범위 기록.
- 후보 경로: 가지치기, 정렬 후 중복 후보 분석, 증류·재학습 등을 비교한다. 앞선 연구들을 조합하면 항상 공통 최소망이 나오는 알고리즘이 있다는 주장은 하지 않는다.
- 보존 대상: 선택한 기준에 따라 정확한 함수 또는 분포상의 허용 성능. 두 문제를 명시적으로 구별한다.
- 줄일 비용: 연결 수·파라미터 수·저장량·연산 수·지연시간 중 선택. 여러 기준을 쓰면 하나의 최솟값 대신 절충 관계가 생길 수 있다.
- 독립 결론: 탐색한 후보 중 가장 작은 모델을 발견하는 것과, 조건을 만족하는 모든 모델 중 최소임을 증명하는 것은 다르다.
- 마지막 질문: “우리가 발견한 가장 작은 구조와, 실제로 존재할 수 있는 가장 작은 구조는 같은 것일까?”
- 주의: Minimum Network Search는 이 편의 탐구 제목이다. 범용적으로 확립된 단일 방법명으로 소개하지 않는다. 단일 제거로 더 줄일 수 없는 구조와 전역 최소도 구별한다.

## 화면과 편집의 공통 기준

- 각 편에서 보존 대상과 줄일 비용을 짧게 명시한다. 이것을 전편 회고 문구로 반복하지 않고 현재 실험의 조건으로 제시한다.
- 보존 수준은 정확 보존, 허용 오차 내 근사, 지정 데이터에서의 실험적 성능으로 구분한다.
- 결과의 지위는 수학적 정리, 실험적 구성, 검토 중인 주장으로 구분한다. ‘최소’라는 제목만으로 증명된 하한처럼 보이지 않게 한다.
- 생명·물리·통계·그래프·신경망을 하나의 보편 법칙으로 묶는 화살표는 쓰지 않는다. 같은 질문을 다른 대상에 적용하는 비교로 연결한다.
- 쇼츠는 세로, 롱폼은 가로 구도를 고려하되 실제 화면비·장면 설계는 대본 검토 이후 결정한다. 씬 하나는 주장 하나이며 독립적으로 교체 가능하게 만든다.

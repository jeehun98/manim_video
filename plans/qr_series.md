## 중심 관점

QR은 서로 다른 수학적 구조를 분리하고 보존하는 방법이다. 열벡터의 순서를 따라 공간이 확장되는 과정, 그 공간의 직교 기준, 원래 열벡터의 조합 계수를 드러낸다.

공통 질문: 새로운 벡터가 추가되었을 때, 기존 벡터들이 설명하지 못하던 것은 무엇인가?

## 제작 원칙

- 각 편에서 새로운 수학적 사실 하나를 발견하도록 구성한다. 기하학적 현상이나 질문에서 출발해 공식이 자연스럽게 등장하게 한다.
- 각 쇼츠는 자체 질문과 결론으로 완결한다. 전편 복습, 기존 영상 회수, 다음 편 예고를 넣지 않는다.
- 직관적 설명과 수학적 명제를 구분하고, 필요한 조건을 화면·대본에 명확히 반영한다.
- 1부는 차원 확장, 2부는 삼각구조가 필연적인 이유에 집중해 중복을 피한다.
- 5부의 AᵀA = RᵀR을 시리즈의 핵심 관계로 강조한다. 외부 좌표계에서의 배향과 열벡터 사이의 내적 구조를 구분한다.
- 대본 작성 요청 전에는 narration.md, tts_script.txt를 생성하지 않는다. 대본·발화시간 확정 전에는 영상·자막·timing.json을 생성하거나 렌더 ID를 등록하지 않는다.

## 수학적 기준

### 공통 설정과 1–2부

- 기본 설명은 실수 행렬 A ∈ ℝ^(m×n), m ≥ n, 열 전체 계수인 경우의 축약 QR을 사용한다. QᵀQ = I이며 R은 n×n 위삼각행렬이다.
- Q의 열은 서로 직교하는 단위벡터이다. 잔여 벡터를 구한 뒤 정규화해야 q_k가 된다.
- 기본 구성에서는 r_kk > 0 규약을 사용한다. 일반 부호 규약에서 수직 높이는 |r_kk|이다.
- 선형종속은 도입 질문으로 사용할 수 있다. 잔여 성분이 0이면 새 방향은 생기지 않고 이를 정규화할 수 없음을 분명히 한다. 실제 직교화 구성은 선형독립인 예시로 진행한다.
- 앞부분 공간의 등식 span(a_1,…,a_k) = span(q_1,…,q_k)은 위 선형독립 설정 아래 설명한다.
- flag 용어는 제작 참고이며 필수 발화 내용이 아니다.

### 3부: 부피

- 3×3 예시에서는 |det A| = |r_11 r_22 r_33|.
- 첫 벡터의 길이, 평면 안에서 첫 방향에 수직인 높이, 기존 평면 밖의 수직 높이를 구별한다.
- 직사각행렬의 열벡터가 만드는 n차원 부피 sqrt(det(AᵀA)) = ∏|r_ii|는 보충 후보이며 필수 내용이 아니다.

### 4부: 최소제곱과 안정성

- 축약 QR에서 ||Ax−b||₂² = ||Rx−Qᵀb||₂² + ||(I−QQᵀ)b||₂².
- 두 번째 항은 x와 무관하므로 최소해는 Rx = Qᵀb를 후진대입해 구한다.
- 열 전체 계수인 경우 κ₂(R) = κ₂(A), κ₂(AᵀA) = κ₂(A)².
- QR은 원래 문제의 민감성을 없애지 않는다. 정규방정식을 구성하며 조건수를 제곱하는 일을 피한다는 점을 설명한다.
- 안정성 설명은 Householder 등 안정적인 구현을 전제로 한다. 고전적 Gram–Schmidt는 유한 정밀도에서 직교성을 잃을 수 있다.

### 5부: 내적 구조

- AᵀA = RᵀQᵀQR = RᵀR.
- R의 열벡터끼리 계산한 내적이 원래 A의 열벡터끼리 계산한 내적과 같다. 길이와, 영벡터가 아닌 열 사이의 각도도 보존된다.
- R만으로 외부 좌표계에서의 원래 배향은 정해지지 않는다.
- A에서 R로 바꾸는 것은 일반적으로 고윳값 보존을 뜻하지 않는다.

### 6부: 고윳값

- 정사각행렬에 대해 A_k = Q_kR_k, A_(k+1) = R_kQ_k = Q_kᵀA_kQ_k.
- 각 단계가 직교 유사변환이므로 고윳값을 보존한다. 5부의 Gram 행렬 보존과 구별한다.
- 무시프트 반복이 모든 행렬에서 대각행렬로 수렴한다고 말하지 않는다.
- 실수 Schur 형태에는 2×2 대각 블록이 남을 수 있다. 실제 알고리즘은 시프트와 Hessenberg 축소 등을 사용한다.

### 7부: SVD와 비교

- QR은 주어진 열 순서에 의존한다. SVD의 특이값 자체는 열 순열로 변하지 않는다.
- SVD는 입력과 출력 양쪽에 직교 기준을 선택해 대각 형태로 표현한다. QR은 주어진 열 순서에 대응하는 위삼각 계수 구조를 유지한다.
- 특이벡터는 부호나 중복 특이값 등의 이유로 유일하지 않을 수 있으므로, SVD 결과 전체가 열 순열에 무관하다고 표현하지 않는다.

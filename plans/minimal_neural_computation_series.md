# 신경망의 최소 계산 구조를 찾아서

> 이전 9편 구성안. 2026-10-31 사용자의 전체 구성 변경으로 대체되었다. 현재 제작 순서와 이후 방향은 [최소 구조를 찾아서 — 현재 계획](minimal_structure_series.md)을 따른다. 아래 편 번호·순서·ETH 보류 사항은 현재 계획에 적용하지 않는다.

2026-10-31 구성안 · 사용자 검토 전 · 독립 쇼츠 9편을 연결하는 3막 롱폼

## 기획의 중심

전체 질문: 같은 문제를 해결하는 신경망들에서 더 작은 계산 구조를 발견할 수 있을까?

2부는 공통 최소 구조의 증명이 아니라, 그 가능성을 탐색하기 위한 단서의 수집이다. 연구들이 관찰하는 대상은 함수, 손실 지형, 표현 기하학, 행렬의 방향, 학습의 자유도, 특징의 중첩으로 서로 다르다. 이를 하나의 구조가 발견되었다는 결론으로 합치지 않는다.

‘최소’는 과제·입력 분포·허용 오차·모델 계열·비용 기준을 정한 뒤에만 구체화한다. 파라미터 수, 저장량, 연산 수, 실제 지연시간은 따로 평가한다. 같은 정확도는 같은 함수라는 뜻이 아니다. 더 작은 후보를 발견하는 일과 그보다 작은 후보가 없음을 증명하는 일도 구분한다.

현재 범위는 구성 기획이다. 대본·TTS·씬·자막·타이밍·렌더 등록은 아직 없다. 편당 2~3분은 편집 목표일 뿐이며, 전체 길이는 확정 대본의 실제 발화시간을 받은 뒤 정한다.

01은 연구 나열에 앞서 ‘크다’와 ‘필요하다’의 의미를 관찰하는 독립 영상이다. 첨부에 언급된 ETH 관련 연구는 논문·주장·검증 상태가 특정되지 않아 필수 도입에서 보류한다. 정확한 출처가 확보되면 필요성을 따져 선택한다.

Low-Rank와 Intrinsic Dimension을 별도 편으로 둔다. 표현 또는 가중치 행렬의 랭크와 목적함수 지형에서 학습에 필요한 탐색 차원은 같은 양이 아니다. 한 편으로 합쳐야 한다면 두 실험을 분리하고 ‘차원이 작다’는 말의 대상부터 구분한다.

## 각 편의 관찰과 결론

### 01 · 크기의 기준

동일한 크기의 행렬에서 0인 가중치의 수를 바꾸고, 저장 방식과 실행 방식을 나란히 관찰한다. 연결이 줄어도 실행기가 같은 밀집 연산을 수행할 수 있음을 설명한다. 결론은 “얼마나 작은가를 말하려면 무엇을 세는지 먼저 정해야 한다.” 특정 하드웨어의 속도 수치는 측정 없이 제시하지 않는다.

### 02 · Lottery Ticket

큰 모델에서 마스크를 찾은 뒤 남은 연결을 원래 초기값으로 되돌려 독립 학습하는 절차를 보여준다. ‘훈련 후 잘라내도 된다’와 ‘초기값을 유지한 부분망도 학습한다’를 구분한다. 초기값·데이터·구조·학습 조건에 의존하는 실험적 결과이며, 임의의 부분망이나 모든 현대 모델에 적용되는 보장은 아니다. 결론은 “큰 설계 안에 더 작은 학습 가능한 후보가 있을 수 있다.”

### 03 · 순열 대칭성

은닉 뉴런 두 개의 순서와 앞뒤 연결을 함께 교환한다. 원소별 활성화에서는 P를 순열행렬로 두고 W1'=PW1, b1'=Pb1, W2'=W2P⁻¹로 바꾸면 출력 함수가 보존되는 예를 사용한다. 다른 연산·상태가 있으면 그것도 일관되게 변환해야 한다. 결론은 “다른 숫자 배열이 다른 함수를 뜻하지는 않는다.” 뉴런 재배열은 뉴런 수 감소가 아니다.

### 04 · Git Re-Basin

독립 학습한 같은 구조의 두 모델에서 정렬 전후 가중치 선형 보간의 손실 곡선을 비교한다. 실제 실험을 만들기 전 그림은 개념도로 표시한다. 정렬은 대상 모델의 함수를 보존하지만 두 모델의 함수가 같아졌다는 뜻은 아니다. 논문에는 단일 basin 가설의 한계와 반례도 있다. 결론은 “배열의 차이를 제거하면 해들 사이의 관계가 더 잘 보일 수 있다.” 정렬·평균이 압축을 보장하지 않는다.

### 05 · Neural Collapse

마지막 은닉층의 클래스별 점구름과 중심을 관찰한다. 클래스 내부 산포 감소와 중심을 뺀 클래스 평균의 simplex ETF 형태를 구분한다. 3클래스의 삼각형은 회전·축척 등이 다른 표현에도 같은 기하학적 관계가 있을 수 있다는 개념 예시로 사용한다. 조건·차원이 허용되는 경우의 현상이며 모든 층·모든 학습에서 동일하게 나타난다고 하지 않는다. 결론은 “과제와 학습 조건이 표현의 규칙적인 관계를 유도할 수 있다.” 같은 기하학은 같은 특징 좌표나 최소 계산 회로의 발견이 아니다.

### 06 · Low-Rank

특잇값 분포를 보고 작은 값부터 제거하면서 재구성 오차를 관찰한다. m×n 행렬을 랭크 r의 두 인자로 근사하면 매개변수 수가 mn에서 r(m+n)으로 바뀌는 예를 쓴다. 충분히 작은 r과 적합한 실행 조건에서 비용 절감 가능성이 생긴다. 근사 오차와 전체 모델 정확도는 따로 평가한다. 결론은 “큰 행렬에도 적은 방향으로 근사 가능한 구조가 있을 수 있다.” 모든 행렬이 낮은 랭크라는 주장은 하지 않는다.

### 07 · Intrinsic Dimension

θ=θ₀+Az로 파라미터를 제한하고 z의 차원을 늘려 성능 변화를 관찰하는 원 논문의 실험 설정을 설명한다. 초기점·무작위 부분공간·최적화·목표 성능에 의존하는 측정이다. θ를 다시 큰 모델로 복원해 실행할 수 있으므로 작은 z가 작은 추론망을 뜻하지 않는다. 결론은 “좋은 해를 찾는 데 필요한 탐색 자유도가 전체 파라미터 수보다 작을 수 있다.”

### 08 · Superposition

저차원 공간에 그보다 많은 특징 방향을 놓고, 희소하게 활성화되는 경우와 여러 특징이 겹쳐 간섭하는 경우를 비교한다. 선형 독립 정보 전체를 손실 없이 임의 복원한다는 그림을 피한다. 토이 모델의 희소 특징·비선형 처리·간섭 사이의 관계를 설명한다. 결론은 “특징을 이해하려면 개별 뉴런뿐 아니라 공간 속 방향과 그 상호작용을 봐야 할 수 있다.” 이미 압축된 표현이므로 더 쉽게 줄일 수 있다는 뜻도 아니다.

### 09 · 작은 후보를 만드는 탐구

독립 도입은 “같은 과제를 잘 푸는 모델 여러 개가 있다. 여기서 더 작은 하나를 만들려면 무엇을 비교해야 할까?”로 잡는다. 앞선 편의 요약으로 시작하지 않는다.

1. 과제·입력 분포·허용 성능 저하·비용 기준·모델 계열을 고정한다.
2. 같은 구조에서 가능한 순열을 정렬하고, 다른 구조는 공통 입력에 대한 표현·출력·개입 반응을 비교한다. 상관관계만으로 같은 계산이라고 판정하지 않는다.
3. 중복 후보를 제거하거나 낮은 랭크로 근사하고, 필요하면 작은 학생 모델을 증류·재학습한다. 이는 탐색 후보 경로이며 연구들이 보장하는 통합 알고리즘은 아니다.
4. 별도 평가 데이터에서 성능·실패 사례·실제 실행 비용을 확인한다. 비교 모델과 데이터·학습 예산도 기록한다.
5. 탐색한 후보들 중 가장 작은 모델과 전역적으로 최소인 모델을 구분한다.

공통 부분만 남기면 희귀 입력에 필요한 기능이 사라질 수 있다. 작은 모델이 기존 모델과 다른 내부 표현을 사용해도 목표 성능은 달성할 수 있다. 결론은 “단서들은 작은 후보를 설계하는 데 쓰일 수 있다. 최소라는 결론에는 정해진 조건에서의 하한이나 별도의 증명이 필요하다.”

## 독립 쇼츠와 롱폼 연결 원칙

- 각 편은 자체 질문 → 관찰 → 조건과 해석 → 해당 질문의 답으로 끝낸다. 이전 편 복습, 시리즈 요약, 다음 편 예고는 넣지 않는다.
- 3막은 제작 내부의 배열이다. 막의 전환은 챕터 제목과 시각적 연결로 처리하며 ‘앞에서 봤듯이’ 같은 의존 문장을 만들지 않는다.
- 내부 논리는 크기 기준 → 작은 후보 → 표현의 비유일성 → 정렬 → 표현 기하학 → 행렬 차원 → 탐색 차원 → 특징 중첩 → 후보 제작이다. 이것을 영상 내 예고로 읽지 않는다.
- 공통 시각 언어를 둔다. 파라미터 배열, 출력 함수, 표현 공간, 연산 비용을 구별해 표시한다. 여러 편에서 같은 색을 쓴다는 이유로 같은 특징이나 회로로 오인하게 하지 않는다.
- 쇼츠는 세로 구도, 롱폼은 가로 구도로 동일한 주장과 음성을 활용할 수 있게 설계한다. 가로판은 단순 확대 대신 비교 대상과 근거를 동시에 배치한다.
- 각 편 안에서도 씬 하나에 주장 하나만 두고 교체 가능하게 제작한다. 실제 씬 분할은 전체 대본 검토 후 진행한다.

## 근거 자료와 다음 제작 단계

- [Lottery Ticket 원 논문](https://arxiv.org/abs/1803.03635): 작은 부분망과 초기값의 역할.
- [Git Re-Basin 원 논문](https://arxiv.org/abs/2209.04836): 순열 정렬과 손실 연결, 가설의 한계.
- [Neural Collapse 원 논문](https://arxiv.org/abs/2008.08186): 학습 말기의 마지막 표현 및 분류기의 기하학.
- [Intrinsic Dimension 원 논문](https://arxiv.org/abs/1804.08838): 무작위 부분공간에서의 학습.
- [Toy Models of Superposition 원문](https://transformer-circuits.pub/2022/toy_model/index.html): 희소 특징의 중첩과 간섭. 대규모 모델 전반에 대한 증명으로 확대하지 않는다.

Low-Rank 편은 SVD의 수학적 예제로 구성한다. 특정 학습 모델의 저랭크성이나 속도 개선을 주장하려면 해당 모델의 측정 또는 추가 1차 출처가 필요하다. 증류는 09편의 후보 방법으로 두며 구체 대본 작성 시 원 논문과 적용 조건을 추가 확인한다.

다음 단계: 구성 피드백 → 편별 narration.md·tts_script.txt·brief.md 초안 → 사용자 대본 확정 → 해당 확정 대본의 TTS 또는 사용자 발화시간 → 씬 명세와 화면 제작 → 미리보기 → 최종 렌더·결합. 지금 단계에서 임의 발화시간이나 영상 제작물을 만들지 않는다.

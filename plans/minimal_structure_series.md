# 최소 구조를 찾아서 — 현재 제작과 이후 탐구 방향

2026-11-01 · 8편 도입과 향후 영상 톤에 관한 사용자 요청 반영

중심 질문: **우리가 원하는 기능을 유지하려면, 실제로 무엇이 필요한가?**
롱폼 가제: **모든 것이 필요할까? — 자연과 수학, 인공지능에서 발견한 최소 구조**
최종 질문: **우리가 발견한 가장 작은 구조와, 실제로 존재할 수 있는 가장 작은 구조는 같은 것일까?**

이 문서는 실제 제작 순서와 현재 요청을 기준으로 한다. ETH를 포함했던 이전10편 계획은 [보존본](archive/minimal_structure_series_20261031.md)이며 현재 순서로 사용하지 않는다. 전체 편수와8편 이후의 편 번호는 확정하지 않는다.

## 앞으로의 탐구 태도

강한 질문 → 눈에 보이는 현상 → 무엇을 비교하는지 확인 → 수학적 이유 또는 통제된 실험 → 이 단서가 말해 주는 범위 → 그 편의 답.

최소 표현을 이미 발견했다는 해설이 아니라, 그 질문에 답할 단서를 추적한다. 개념 이름은 관찰할 이유를 만든 뒤 제시한다. 8편은 사용자가 요청한 대로 탐구의 시작을 선언하고 복권 가설을 짧게 언급한다. 이를 이후 모든 편의 긴 복습이나 예고 형식으로 반복하지 않는다. 다른 편의 도입은 그 편의 독립적인 질문으로 시작하고, 마지막에는 해당 단서의 결론을 남긴다.

‘최소 표현’은 무엇을 보존하고, 어떤 모델 계열에서, 어떤 비용을 줄이는지 정한 뒤 구체화한다. 앞으로 찾을 것은 훨씬 작은 유용한 표현의 가능성·조건·구성법이며, 보편적으로 하나인 최소 신경망이 이미 알려져 있다는 인상을 주지 않는다.

## 반드시 구분할 주장

| 주장 | 이를 뒷받침하는 데 필요한 것 |
| --- | --- |
| 같은 성능을 내는 작은 후보가 있다 | 과제·입력 분포·평가·학습 조건을 정한 실험 |
| 다른 파라미터 배열이 같은 함수를 나타낸다 | 지정한 변환에서 모든 입력의 출력이 보존된다는 대수적 확인 |
| 특정 계산을 줄일 수 있다 | 제거·병합·인수분해 이후에도 목표를 보존하는 구성 |
| 더 적은 연속 자유도로 기술할 수 있다 | 연속 대칭성 또는 적절한 차원 분석; 순열만으로 결론 내리지 않음 |
| 발견한 모델이 최소다 | 모델 계열·보존 기준·비용 기준 아래 하한이나 별도 최소성 논증 |

복권 가설의 성능 보존을 곧바로 정확한 함수 동일성으로 바꾸지 않는다. 같은 함수의 여러 표현과 제거 가능한 계산의 존재도 구분한다. 한 모델에서 발견한 중복을 모든 모델·입력에 대한 보장으로 확대하지 않는다.

## 8편의 역할과 결론

서사: 복권 가설의 작은 부분망 → 필요한 표현에 대한 질문 → 함수 표현의 비유일성 → 두 은닉 뉴런의 순열 대칭성.

주된 결론은 **서로 다른 파라미터 배열이 반드시 서로 다른 함수를 뜻하지는 않는다.**

사용자가 제안한 ‘파라미터의 수가 곧 독립적인 표현의 수는 아니다’는 시리즈 내부의 넓은 문제의식으로 남기되, 8편의 정리처럼 단정하지 않는다. 파라미터 개수와 서로 다른 함수의 수는 다른 종류의 양이다. 순열은 이산적인 재배열이므로 뉴런·연결 수를 줄이지 않으며, 일반적으로 연속적인 파라미터 공간의 국소 차원을 줄이는 근거도 아니다.

## 이후 후보의 권장 순서 — 번호·편수 미확정

| 순서 | 독립 질문·주제 | 단서가 말하는 것 | 넘어가면 안 되는 결론 |
| --- | --- | --- | --- |
| A | 숫자를 계속 바꾸어도 같은 함수일까? — ReLU 스케일 대칭성 | 양의 스케일 변환에 따른 연속적인 동등 표현 | 계산량이나 뉴런 수가 자동으로 감소한다 |
| B | 정말 같은 일을 하는 뉴런 둘을 하나로 합칠 수 있을까? — 정확한 중복 뉴런 | 같은 활성화를 만드는 두 항을 결합하는 정확한 축소의 특수 사례 | 모든 비슷한 뉴런을 안전하게 합칠 수 있다 / 전역 최소다 |
| C | 따로 학습한 모델을 정렬하면 무엇이 보일까? — Git Re-Basin·표현 정렬 | 좌표 차이를 정리해 모델 사이의 관계를 조사 | 두 모델이 같은 함수가 된다 / 유사도만으로 같은 회로임이 증명된다 |
| D | 큰 행렬의 모든 방향이 필요한가? — Low-Rank | 정확한 저랭크 인수분해 또는 오차를 정한 근사 | 일반 신경망 전체의 최소 차원을 얻었다 |
| E | 모든 파라미터를 독립적으로 움직여야 학습할까? — Intrinsic Dimension | 특정 과제·학습 조건에서 작은 탐색 부분공간의 가능성 | 추론 모델의 최소 크기나 함수 다양체의 차원을 증명했다 |
| F | 특징은 뉴런과 하나씩 대응할까? — Superposition | 특정 특징 분포에서 여러 특징을 적은 표현 차원에 중첩 | 임의의 고차원 정보를 손실 없이 항상 압축할 수 있다 |
| 종합 | 이 단서들로 더 작은 신경망을 만들 수 있을까? | 조건을 정하고 후보를 구성·평가하는 탐색 | 보편적인 최소 신경망 발견 알고리즘이 확립되어 있다 |

후보는 모두 필수 편이 아니다. 실제로 독립적인 질문과 설득력 있는 실험이 준비되는 주제부터 대본화한다. Low-Rank와 Intrinsic Dimension은 대상이 달라 분리한다. Neural Collapse는 특정 분류 학습 말기의 규칙적 기하학이 필요할 때 별도 후보로 검토하며, 작은 모델의 직접적 증거로 끼워 넣지 않는다.

## 구체화 단계의 정확성 기준

- 스케일 대칭성: ReLU의 양의 동차성을 사용한다. c>0에서 들어오는 가중치·편향을 c배 하고 나가는 가중치를1/c배 한다. 함수 보존과 정규화 항·학습 궤적 보존을 구분한다.
- 중복 뉴런: 같은 활성화 h(x)를 내는 두 항 v₁h(x)+v₂h(x)를 (v₁+v₂)h(x)로 합친다. 모든 입력에서 같은 활성화라는 조건이 필요하다. 표본에서의 높은 상관관계는 별도 근사 실험이다.
- 정렬: 한 모델의 순열 변환은 그 모델의 함수를 보존한다. 독립 모델 사이의 보간 손실·표현 유사도·함수 동일성은 각각 다르다.
- Low-Rank: 정확한 W=UV를 설명할 때 두 인자 사이에 새 비선형성을 넣지 않는다. 인수분해가 파라미터 수를 실제로 줄이는지도 크기로 확인한다.
- Intrinsic Dimension: 학습의 탐색 차원, 표현 행렬의 랭크, 추론 회로의 크기를 하나로 부르지 않는다.
- 모든 실험: 데이터 범위, 오차, 함수 보존 여부, 비용 기준을 명시한다. 표본 그림을 보편적인 수학적 증명으로 제시하지 않는다.

## 근거와 제작 단계

[Git Re-Basin](https://arxiv.org/abs/2209.04836), [Neural Mechanics](https://arxiv.org/abs/2012.04728), [Intrinsic Dimension](https://arxiv.org/abs/1804.08838), [Toy Models of Superposition](https://transformer-circuits.pub/2022/toy_model/index.html). 실제 대본화하는 주제는 원문·조건을 다시 확인한다.

현재는 기획과8편 도입 초안 단계다. 전체 대본 검토·확정 → 해당 원고의 실제 TTS 또는 사용자 종료 시각 → 씬 명세·화면·자막·타이밍 → 미리보기 → 최종 렌더 순서를 따른다. 현재 발화시간, 자막, timing.json, scene.py, 렌더 ID는 생성하지 않는다.

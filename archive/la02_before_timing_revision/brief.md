# 선형대수학 02 — 기여를 모으면 결과가 된다

120초 · 1080×1920 · 30fps · 무음 마스터.1편과 같은 색상·자막 배치 사용.

## 전달할 개념

**한 목적지의 결과 = 모든 출발점에서 온 기여의 총합.**

곱셈은 각 출발점의 값과 연결의 가중치를 결합해 기여를 만들고, 덧셈은 같은 목적지의 기여를 모은다. 구체적인 수치 → 한 목적지의 합 → 일반 기호 → 모든 목적지 → y=Ax 순서로 설명한다.

행렬 A=[[0,0.8,0.1],[0.3,0,0.5],[0.2,0.7,0]]는 1편의 값을 유지한다. A[i,j]는 출발점 j에서 목적지 i로 향하는 가중치다.

- 입력 x=(10,5,20).
- 첫 결과 y₁=0×10+0.8×5+0.1×20=0+4+2=6.
- 둘째 결과 y₂=0.3×10+0×5+0.5×20=3+0+10=13.
- 셋째 결과 y₃=0.2×10+0.7×5+0×20=2+3.5+0=5.5.
- 일반식 yᵢ=Aᵢ₁x₁+Aᵢ₂x₂+Aᵢ₃x₃.

입력은 모든 출력 계산 동안 고정이다. y₁을 x₁으로 덮어써 다음 결과를 계산하지 않는다. 입출력을 화면의 양쪽에 분리하여 보여준다. 이동하는 숫자는 기여 전달을 표현하는 도식이며, 입력이 소모되거나 총량이 보존된다는 뜻은 아니다. 여기서는 가중합 자체를 다루며, 편향·활성화 함수·추가 동역학은 포함하지 않는다.

## 장면

행렬 복습 → 실제 값 → 첫 목적지 확대 → 4와 2의 기여 → 6으로 합산 → 0의 기여 포함 → 기호로 일반화 → 곱셈과 덧셈의 역할 → 둘째·셋째 결과 → 행렬과 벡터의 곱 → 한 행과 한 출력의 대응 → 기여의 총합 강조.

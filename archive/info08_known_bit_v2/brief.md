# 정보이론 08 — 이미 아는 것은 다시 보내지 않는다

- 개정 목적: 총 비트 수의 연속 비교와 빠른 공식 설명을 줄이고, 보내는 사람/받는 사람이 같은 결과 B를 두 방식으로 주고받는 실제 통신 장면을 지속한다. 앞31초는 같은 무대와 인물·코드표를 유지한다. 첫 비트를 이미 안다는 장면을6초 확보한다. 전체 발화 목표59.10초,12구간.
- 학습 목표: 받는 사람이 이미 아는 내용은 다시 설명할 필요가 없다. 조건부 엔트로피는 X를 알고도 남는 평균 설명량, 상호정보량은 X 덕분에 생략한 평균 설명량이다. 물체처럼 정보가 이동한다는 은유 대신 실제 전송 비트와 수신자에게 이미 있는 단서를 구분한다.
- 구간0~5: 보낼 B와 아직 모르는 수신자 → 공유 코드표(A00/B01/C10/D11) → 단서 없이01 전송·B 복원 → 같은 B를 보내는 두 번째 상황에서 X=left가 이미 존재 → 수신자에게0을 고정 표시하고 송신자의 중복0에 취소 표시 →1만 실제 이동 → 기존0+받은1로B 복원 → 원본B는 동일하고 새 설명만 줄었음을 대조.
- 구간6~11: left(A/B)·right(C/D)에서 각1bit 남음 →1/2×1+1/2×1=1 조건부 엔트로피 →2−1=1 상호정보량 → 단서없음/그룹앎/B이미앎으로 전송2/1/0 비교 → X도 새로 보내면 전체2bit → 일반적으로는 여러 X값에 대한 평균 → 새로운 관측 없는 가공의 정보 한계로 연결.
- 원안의 날씨 예시·16기호 묶음 전송·수치 막대 비교는 제거하고 B라는 단일 결과의 복원 과정에 시간을 배분한다. 공식은30.8초 이후에만 등장한다. 코드표는 물리적인 메시지가 아닌 사전에 공유한 약속이다. 반복은 같은 데이터로 다른 사전 지식 상황을 비교하는 시연이며 수신자가 직전 B를 기억한 채 무지하다고 가정하는 것이 아니다.
- 수학: Y∈{A,B,C,D} 균등. X=left이면 A/B, right이면 C/D이며 네 결합 사건 각1/4. P(X=left)=P(X=right)=1/2, 조건부 후보 각1/2. H(Y)=2,H(Y|X)=1,I(X;Y)=1bit. B의 실제 코드01, 공유X에 해당하는0, 조건부 본문1. 01로도, X0+본문1로도 정확히B 복원한다.
- 송수신자가 X·코드·길이·정렬을 모두 알고 있는 설정. 수신자만 X를 알고 송신자는 모르는 일반 압축 문제와 혼동하지 않는다. X를 새로 보내면 그룹0+그룹 내 구별1로 총2bit. 전송 생략의 근거는 이미 있는 단서이지 새로운 정보가 공짜로 생기는 것이 아니다.
- H(Y|X)=Σₓp(x)H(Y|X=x). 주 예시에서는 모든 X에서1bit지만 일반적으로 X값마다 남는 양이 다를 수 있고, 특정X 관측으로 엔트로피가 커질 수도 있다. 평균적으로만 H(Y|X)≤H(Y). 상호정보량은 대칭이며 방향별 다른 KL 비용이라고 설명하지 않는다.
- 독립 모델은 X이진·Y사분 균등으로 H(Y|X)=2,I=0. 완전한 단서 모델은 X=Y(사분 균등)로 H(Y|X)=0,I=2. 이 두 비교는 다른 관계 모형이다. 화면의 B이미앎은 완전한 단서 모형의 한 사건이지 기존 이진 그룹X가 모든 Y를 알아낼 수 있다는 주장이 아니다.
- 다음 편: 새 관측·외부 정보 없이 X→Y→Z인 Markov 가공의 I(X;Z)≤I(X;Y). 가공 변수 자체의 엔트로피가 항상 줄어든다는 주장과 구별한다.

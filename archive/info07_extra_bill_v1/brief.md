# 정보이론 07 — KL과 추가 청구서

- 제목: 틀린 예측 때문에 몇 비트를 더 쓰고 있을까? 원안20화면을 11발화 구간으로 압축. KL을 거리로 소개하기보다 “본래 비용을 뺀 평균 추가 청구서”로 먼저 보여준다.
- 앞편과 수치 연속성 유지: p=(.7,.1,.1,.1), q=(.1,.3,.3,.3), A/B/C/D. 원안 중간 p=(.5,.25,.125,.125)는 이 편에 별도 혼용하지 않는다.
- BASE=H(p)=1.356779649, TOTAL=H(p,q)=2.846439345, EXTRA=KL(p‖q)=1.489659695 bits/기호. 비용은 이상적 log-cost이며 실제 정수 prefix-code 길이 차이라고 주장하지 않는다. 실제 유한 부호에는 길이 반올림·헤더·모형 오버헤드가 있다.
- 본래 H(p)는 알려진 데이터 생성 분포 아래 관측 전에 남는 불확실성의 비용. 물리적 현실이 언제나 본질적으로 확률적이라는 철학적 단정이나 추가 맥락 없이도 피할 수 없는 모든 비용으로 일반화하지 않는다. 추가 정보/맥락이 있다면 조건부 비용이 달라질 수 있다.
- 사건별 Δ(x)=−log₂q(x)−(−log₂p(x))=log₂[p(x)/q(x)]. A의 Δ=2.807354922, B/C/D 각 Δ=-1.584962501. 각 항은 음수 가능. 실제 p로 가중한 A의 기여는 1.965148445, 나머지 각 -0.158496250. 합계 KL은 0 이상이다.
- KL=Σₓp(x)log₂[p(x)/q(x)]=H(p,q)−H(p). 이 예시의 유한 이산 분포에서 공식 적용. p>0인데 q=0인 항은 +∞, p=0인 항은 제외. 두분포 모두 정규화된 확률분포이다. KL이0이면 p=q.
- KL(p‖q)=1.489659695, KL(q‖p)=1.145730758. 역방향은 실제 source=q, 가격모형=p이며 baseline도 H(q)로 바뀐다. 원래 p의 같은 영수증에서 단순 부호만 바꾸는 것이 아니다. 막대는 동일척도 1bit당1.8단위.
- 비대칭은 일반적 성질로 대칭인 특정쌍도 존재한다. 부등호 화면은 이 수치 예시를 뜻함을 명시. 거리의 대칭성/삼각부등식을 만족하는 보통 metric이라고 설명하지 않는다.
- q_t=(1−t)p+tq의 특정경로에서 KL이 감소하는 것을 수치검증. 임의의 거리에서 멀어질수록 KL이 항상 단조 증가한다고 주장하지 않는다. q=p이면 추가 막대는 폭0·불투명도0으로 처리하고 baseline은 그대로 둔다.
- 학습은 p가 고정되고 qθ만 바뀔 때 CE와 KL 최소화가 동치. 실제 분포를 제한된 모델이 정확히 구현할 수 있거나 학습이 항상 성공한다고 가정하지 않는다. 학습 장면은 추가분을 일부 줄이는 것으로 표현한다.
- 다음 질문은 X와 Y. 장면의 Y는 A/B/C/D 균등이며 X=0은 Y∈{A,B}, X=1은 Y∈{C,D}를 알려주는 예시다. 관측에 따라 모든 일반 조건부 분포의 엔트로피가 매번 줄어든다고 주장하지 않는다. 조건부 엔트로피/상호정보량은 다음 편으로 남긴다.

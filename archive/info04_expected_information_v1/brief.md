# 정보이론 04 — 제작 기준

- 원안 17개 화면을 12개 발화 구간으로 압축. 핵심은 “미래 정보량 I(X)도 확률변수이며 엔트로피는 기대값”이다. 관측 전 모름과 분포의 앎을 구별한다.
- p=(0.5,0.25,0.25), I=(1,2,2) bits. X는 A/B/C이고 I(X)는 1/2를 취한다. P(I(X)=1)=0.5, P(I(X)=2)=0.5로 B/C의 같은 정보량을 합친다.
- H(X)=E[I(X)]=Σₓp(x)I(x)=−Σₓp(x)log₂p(x)=1.5 bits. 1.5는 이 예시의 단일 관측 실현값이 아니다. 단순 산술 평균 5/3과 구별한다.
- 핵심 평균 장면: 동일 확률 0.25의 A,A,B,C 네 조각. A의 0.5가 두 조각으로 분할되고 1/2/2의 정보량은 블록 높이로 표시된다. 조각 수는 확률 가중치, 블록 수는 자기정보량이다. 합계 6개 블록 / 4개 조각 = 1.5.
- ABACABAC는 반복 관측을 설명하는 구성 예시이며 실제 무작위 시뮬레이션의 수렴 증거가 아니다. 나레이션은 같은 분포에서 독립 반복을 조건으로 제시한다. 모든 유한 표본 비율이 정확히 확률과 일치한다고 주장하지 않는다.
- 결과가 확실한 p=(1,0,0)에서 H=0. p=0 항은 0 log 0=0의 극한 관례로 계산에서 제외한다. 불가능한 B/C의 자기정보량을 0으로 표기하지 않는다.
- 균등 p=(1/4,1/4,1/4,1/4)에서 모든 I=2, H=2. 균등 최대성은 고정된 결과 수에서의 비교이며 결과 수와 무관하게 모든 균등 분포가 최대라는 표현을 피한다.
- 마지막 동일 4결과 비교: 균등 H=2, 집중 (0.97,0.01,0.01,0.01)의 H≈0.241941. 엔트로피 막대는 공통 고정 스케일 1 bit당 프레임 3단위. 확률 막대는 전체 폭 7.2에서 실제 비율 사용.
- 길이 59.10초. TTS 비공백 글자 / 초당 7자, 문장 휴지 0.18초, 마지막 0.5초. 프레임 정렬 경계. 등장·전환은 구간 안에 포함. 실제 음성이 없어 발화 추정이다.
- 1080×1920 30fps 무음. TTS와 SRT 별도. 숫자와 영문은 화면/대본/SRT 그대로, 발음 표기는 TTS에만 둔다.

# GPU 개론3부 · 11~16 통합 롱폼

사용자 지정 음성 포함 exports/gpui_long_11.mp4부터 gpui_long_16.mp4까지 순서대로 결합한다. 16번은3부마무리영상이다. 동명과유사한무음 gpui11_long.mp4 등은사용하지않는다. 원본영상/음성을자르거나대본을수정하지않는다. 영상스트림복사,오디오는각영상길이로무음패딩/정렬후AAC결합. MP4챕터6개와유튜브설명생성.

`python longforms/gpui_full_11_16/build.py`

출력: exports/gpui_11_16_long.mp4. 실제시작시각은manifest.json,검증은verification.json,유튜브설명은youtube_description.txt.

# 여러 클럭에 나누어 실행한다

확정 시간: 119–134초. 주장: 여러 클럭에 나누어 실행한다.

119–123: 이제 하나의 명령어를 여러 클럭에 걸쳐 실행할 수 있습니다.
123–128: 각 과정에서 필요한 정보를 저장하고, 제어 회로가 순서대로 다음 동작을 선택하는 것입니다.
128–134: 이처럼 하나의 명령어를 여러 클럭에 나누어 처리하는 구조를 다중 사이클 실행 구조라고 합니다.

화면은 storyboard_reference.md 해당 구간을 따른다. IR·주소·데이터·상태 레지스터를 초록색으로 추가하고 기존 데이터 경로는 유지한다. 입력과 저장된 출력, 다음 상태와 현재 상태를 분리한다. 메모리 Ready=0에서는 읽기 상태 유지, RegWrite=0. Ready=1일 때 임시 데이터 저장 후 기록 상태로 전이한다. 104 주소 계산은 별도 예시이며 주 LOAD는 주소100이다. 명칭은 기능 시연 후 공개한다. 도식과 하단 단일 자막 영역을 분리한다. 원문 외 예고·엔드카드는 추가하지 않는다.

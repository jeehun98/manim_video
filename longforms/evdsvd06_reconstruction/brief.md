# 6편 제작 기준 — 복원 정확도

사용자가 제작 요청한 원문과 실제 문장 종료 시각을 그대로 사용한다. 0–133초, 23개 독립 씬. 화면 제작 전 대본·spec·구간 길이 확정. 세로9:16·가로16:9 각각 배치. 기본 영상은 자막 포함 무음(TTS 음원 미제공).

실험은 A=diag(B,B,B,B,B), B=[[2,3],[0,1]] 하나로 고정한다. 반복 고윳값·특이값의 기저는 블록별로 고정한다. EVD와 SVD 모두10개 랭크1 성분 중5개를 남기며 실제 근사의 랭크도5다.

원소 격자는 모두−6..6 고정색상 범위. 음수보라·0짙은남색·양수청록, 방법은외곽선색으로 구분한다. 오차는별도금색막대, 각패널자동정규화금지. 각성분은10×10원본과같은크기의행렬이며이미지조각이아니다.

EVD 상쇄는 블록의 실제 E1=[[2,6],[0,0]], E2=[[0,-3],[0,1]]로 시각화. 같은칸에서6−3=3, 두번째제거후6. SVD는 실제Frobenius직교관계와잔여특이값제곱합 표시. 고차원직교의2D그림은개념도표시.

최적성 기준은 rank≤k, 원소별제곱오차(Frobenius노름 제곱). 후보몇개비교를증명처럼제시하지않고정리의보장을문장으로구분한다. 대칭행렬은고윳값절댓값순으로선택할때SVD와같은최적근사가능.

이예시의실제오차는EVD≈7.071,SVD≈1.208. 일반적인차이의크기로과장하지않는다. 최종점수3:3. 이전편복습·다음편예고없음.

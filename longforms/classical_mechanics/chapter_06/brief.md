# 제작 기준

사용자 확정 46문장·265초, 7개 독립 씬. 16:9 1080p30. 음원 미제공, 무음·원문 전체 자막.

원문 복습은 사용자 대본대로 유지. 파동함수의 실수부·허수부와 Born 확률밀도를 분리. 측정은 같은 상태를 재준비하는 독립 반복. hbar=m=omega=1 조화 진동자 (|0>+|1>)/sqrt(2)의 정확한 시간 진화. 교환자는 오른쪽 연산자부터 적용하며 2×2 Hermitian 행렬의 실제 결과를 표시. 기대값 변화식은 명시적 시간 의존성 없는 연산자로 한정. 고전역학과 양자역학을 단순한 좌표 교체로 등치하지 않음. 마지막 발화 내에서 진자로 복귀, 임의 길이 추가 없음.

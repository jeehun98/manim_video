# 제작 기준
- 사용자 확정 원문 37문장, 180초, 16:9 1920×1080 30fps. 음원 미제공으로 무음·전체 자막.
- 1장의 진자 모델·도형·폰트·자막·렌더 검사 흐름을 재사용한다. 1장 소스는 수정하지 않는다.
- 좌표 → 에너지 → L=T−V → 시간 이력 → 부호 있는 작용 → 정지 조건 → 같은 운동방정식.
- 진자는 g=9.81, ℓ=2m, 초기각 .65rad, 초기각속도0. 이상적 비선형 진자 RK4 모델.
- 경로 비교는 고정 시간구간 [0,1.2]와 동일 끝점. 가상 경로 θ_ε=θ+ε sin(kπt/1.2), k=1,2,3. 각속도도 같은 변형의 도함수로 계산한다.
- T, V, L(t), S는 하나의 경로에서 연결해 계산한다. 작용은 부호 있는 시간 적분. 정지 조건은 S=0이 아니며 항상 최소라는 주장도 아니다.
- 파랑 가상 경로 / 금색 실제 경로 / 흰 고정 끝점 / 초록 양의 기여 / 빨강 음의 기여.
- 91~116초 정지 조건 씬을 저해상도 확인하고 최종 렌더한다. 7개 씬은 독립 교체 가능.
- 마지막 연결계는 정적인 좌표 개념도이며 동역학 시뮬레이션으로 표시하지 않는다. 끝의 작은 위상 공간은 현재 질문의 화면 표현이며 다음 장 타이틀은 넣지 않는다.

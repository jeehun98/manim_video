# **복잡한 물리 방정식을 이해하는 하나의 방법 — 해밀토니안**

9:16 쇼츠

총 169초 · 2분 49초 · Manim 중심

이번 영상의 핵심은 **복잡한 방정식들이 화면을 가득 채우다가, 서로 다른 이론에서 반복되는 하나의 수학적 역할을 발견하는 과정**입니다.

앞서 제작했던 고전역학 영상처럼 뉴턴에서 해밀턴까지 발전하는 과정을 다시 설명하기보다는, 서로 다른 물리 이론을 나란히 놓고 해밀토니안이라는 공통된 요소를 발견하도록 구성하겠습니다.

시각적 흐름은 다음과 같습니다.

\\(R\_{\mu\nu}-\frac12Rg\_{\mu\nu}=\frac{8\pi G}{c^4}T\_{\mu\nu}\\)\\((i\gamma^\mu D\_\mu-m)\psi=0\\)\\(Z=\int\mathcal D\phi\\,e^{iS[\phi]/\hbar}\\)

서로 다른 이론 · 서로 다른 수학적 표현

**반복되는 수학적 대상의 발견**

\\(H\\)

고전역학

\\(H(q,p)\\)운동의 변화

양자역학

\\(\hat H\\)상태의 변화

통계물리학

\\(e^{-\beta H}\\)평형 확률

여기서 영상 초반의 방정식들은 **복잡하고 다양한 물리 이론의 존재를 보여주는 도입 장치**입니다. 그 방정식들이 모두 해밀토니안 하나로 직접 변환된다는 식으로 연출하지는 않겠습니다.

### **실제 사용할 주요 수식**

아인슈타인 장방정식

\\[ R\_{\mu\nu}-\frac12 Rg\_{\mu\nu}+\Lambda g\_{\mu\nu}=\frac{8\pi G}{c^4}T\_{\mu\nu} \\]

디랙 방정식 · 자연단위계

\\[ (i\gamma^\mu\partial\_\mu-m)\psi=0 \\]

양-밀스 장방정식

\\[ (D\_\mu F^{\mu\nu})^a=J^{a\nu} \\]

양자장론의 생성 범함수

\\[ Z[J]=\int\mathcal D\phi\\,\exp\left[\frac{i}{\hbar}\left(S[\phi]+\int d^4x\\,J\phi\right)\right] \\]

이때 방정식마다 한글 설명을 크게 넣을 필요는 없습니다. 화면에 실제 수식이 등장하는 것만으로도 목적을 달성할 수 있습니다.

제작에서는 수식이 겹쳐 읽기 어려워지는 순간을 일부러 만들되, 처음 등장하는 각각의 수식은 1초 이상 형태를 알아볼 수 있도록 유지하는 편이 좋겠습니다.

## **Scene 03 · 33–77초**

**고전역학 — 해밀토니안은 운동을 어떻게 결정할까?**

이 장면은 이전 고전역학 영상의 위상 공간 시각화를 일부 재사용할 수 있습니다.

하지만 이번에는 위상 공간의 정의를 다시 설명하지 않습니다. 화면에서는 상태를 점으로 표현하더라도 내레이션의 중심은 **현재 상태에서 시간 변화를 계산하는 과정**에 둡니다.

| 시간     | 화면 연출                                                      |
| ------ | ---------------------------------------------------------- |
| 33–35초 | \\(H(q,p)\\)가 작아지며 천장에 매달린 진자 하나가 등장합니다.                   |

진자를 화면에서 없애지 않고, 오른쪽에 상태 점을 함께 보여줍니다.

진자와 점을 같은 시간 변수로 구동해 두 표현이 동일한 물리적 상태에 대응한다는 사실을 전달합니다.

### **45–66초 · 해밀토니안으로 시간 변화를 계산하다**

해밀토니안이 화면 중앙에 등장합니다.

\\[ H(q,p)=\frac{p^2}{2m\ell^2}+mg\ell(1-\cos q) \\]

이상적인 단진자의 정준운동량을 사용한 표현입니다.

\\[ H(q,p)=\frac{p^2}{2m\ell^2}+mg\ell(1-\cos q) \\]

위치의 변화

\\[ \dot q=\frac{\partial H}{\partial p} \\]

운동량의 변화

\\[ \dot p=-\frac{\partial H}{\partial q} \\]

현재 상태에서 시간 변화율을 계산

| 시간     | 화면 연출                                                                          |
| ------ | ------------------------------------------------------------------------------ |
| 45–51초 | 상태 점 위에 \\(H(q,p)\\)가 나타납니다. 해밀턴 방정식에서 위치와 운동량의 변화율이 계산되고, 점에 작은 방향 화살표가 생깁니다. |
| 51–56초 | 해밀토니안의 두 항을 운동에너지와 위치에너지로 구분합니다. 두 항의 합이 일정하게 유지되는 모습을 보여줍니다.                  |
| 56–60초 | 에너지 값만 표시하던 화면에서, 다시 방향 화살표와 운동의 흐름으로 전환합니다.                                   |
| 60–66초 | 위상 공간의 각 상태에 해밀턴 방정식으로 계산한 화살표들이 나타나고, 진자의 상태 점이 그 흐름을 따라 움직입니다.               |

여기서 시청자가 발견해야 하는 사실은 **해밀토니안이 에너지 값뿐 아니라, 상태가 시간에 따라 어떻게 변화할지도 알려준다는 점**입니다.

해밀토니안의 등고선은 궤적의 형태를 보여주지만, 각 지점의 실제 시간 변화는 해밀턴 방정식으로 결정한다는 순서를 유지합니다.

## **Scene 04 · 77–108초**

**양자역학 — 상태 표현이 달라져도 이어지는 역할**

이번 영상에서 가장 중요한 비교 장면입니다.

고전역학과 양자역학을 단순히 비슷한 수식으로 보여주지 않고, **상태 자체를 표현하는 방법이 달라졌다는 사실**을 먼저 보여주겠습니다.

| ------ | ---------------------------------------------------------------------- |

| 81–87초 | 고전적 상태 점 \\((q,p)\\)를 강조합니다. 그다음 오른쪽에 별도의 양자 상태 표현이 나타납니다.             |

여기서 양자 상태를 단순한 확률밀도 그래프 하나로 대체하지 않겠습니다.

파동함수는 일반적으로 복소수이므로, 파동의 진폭뿐 아니라 위상도 표현하는 그래픽이 좋습니다. 예를 들어 선의 밝기나 색상을 위상에 따라 변화시키는 방식을 사용할 수 있습니다.

### **94–108초 · 같은 역할을 발견하다**

고전역학

\\[ \dot q=\frac{\partial H}{\partial p} \\]

\\[ \dot p=-\frac{\partial H}{\partial q} \\]

양자역학

\\[ i\hbar\frac{d}{dt}|\psi\rangle=\hat H|\psi\rangle \\]

상태 표현은 다르지만, 시간 진화를 결정하는 역할은 이어진다

| 시간       | 화면 연출                                                                                  |
| -------- | -------------------------------------------------------------------------------------- |
| 94–101초  | 오른쪽의 \\(\hat H\\)가 슈뢰딩거 방정식에 결합되고, 양자 상태가 시간에 따라 변화합니다.                                |
| 101–108초 | 고전역학과 양자역학의 두 화면을 나란히 배치합니다. 두 해밀토니안에 같은 색의 강조 표시를 넣고 공통된 역할인 `상태의 시간 진화`라는 문구가 나타납니다. |

여기서 두 이론이 동일한 방식으로 물체의 실제 위치를 계산하는 것처럼 표현하지 않는 것이 중요합니다.

고전역학에서는 위치와 운동량이 시간에 따라 결정되고, 양자역학에서는 슈뢰딩거 방정식을 통해 양자 상태가 시간에 따라 변화합니다.

두 이론은 서로 다르지만, **해밀토니안이 시간 진화를 생성한다는 역할**이 이어진다는 것이 이 장면의 결론입니다.

## **Scene 05 · 108–137초**

**통계물리학 — 시간 변화에서 상태의 확률분포로**

시청자가 확률분포의 의미를 쉽게 이해할 수 있도록, 서로 다른 에너지를 가진 상태들을 시각적으로 배열하는 방식을 추천합니다.

에너지 0, 1, 2, 3인 네 개의 미시 상태를 가정한 개념 예시입니다. 각 상태의 확률은 정준 앙상블의 볼츠만 가중치를 정규화해 계산했습니다.

이 시각화에서는 에너지가 높은 상태일수록, 다른 조건이 같다면 개별 미시 상태의 확률이 낮아지는 모습을 보여줍니다.

온도가 달라지면 확률분포가 변화합니다.

영상에서는 위 수식을 한 번에 보여주기보다 먼저 상태마다 다른 에너지 값을 표시하고, 그다음 에너지에 따른 확률 막대가 나타나도록 구성하면 좋겠습니다.

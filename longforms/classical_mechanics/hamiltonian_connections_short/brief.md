# 제작 기준

사용자 확정 30문장·169초, 세로 1080×1920 30fps. 8개 독립 씬. 음원 미제공, 무음·원문 전체 자막. 화면 제작 전 원문·spec·종료 시각 확정.

도입 장방정식·디랙·양밀스·생성 범함수는 각 이론의 다양성 제시이며 H로 환원하지 않는다. 기존 진자/정준운동량/양자 조화 진동자 모델 공유. 새 행성 궤도는 초점에 중심질량을 둔 정확한 케플러 타원해, 위치에 따라 속도 변화. 통계 장면은 정준 앙상블, 네 단일 미시 상태 E=0,1,2,3, kBT=1의 정규화 확률. 상태 수 축퇴와 에너지준위의 확률을 혼동하지 않는다. 통계물리학에서도 미시적 시간 진화가 존재하되 여기서는 다른 역할인 열평형 분포를 강조.

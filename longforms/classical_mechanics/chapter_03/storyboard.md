이번 3장은 앞선 두 장보다 추상적인 개념이 많습니다. 따라서 개별 그래프를 차례로 보여주는 것이 아니라, **하나의 진자에서 새로운 수학적 표현이 추출되고, 그 표현이 다시 다음 개념으로 이어지는 과정**을 시각화하겠습니다.

이 값에 `운동량 p`라는 이름을 붙입니다.

\\[ (\theta,\dot\theta)\longrightarrow(\theta,p\_\theta) \\]

이 변환은 아직 좌표의 변화를 보여주는 단계입니다. 다음 장면에서는 이를 이용해 함수 자체도 다른 방식으로 표현합니다.

### **Scene 05 · 132–188초**

**르장드르 변환 — 기울기로 함수를 다시 표현하다**

이 구간은 특히 일반적인 함수 그래프의 접선에서 출발해 설명하는 것이 좋겠습니다.

르장드르 변환을 처음부터 \\(H=p\dot q-L\\)이라는 수식으로 제시하면, 왜 이런 계산을 하는지 이해하기 어렵습니다.

반대로 접선의 기울기와 절편을 함께 보여주면, 이 변환이 어떻게 함수를 재구성하는지 시각적으로 전달할 수 있습니다.

**132–143초 · 왜 새로운 함수를 만들까?**

라그랑지안 그래프에서 각속도와 그 지점의 접선이 강조됩니다.

각속도를 바꿀 때마다 접선의 기울기도 달라지고, 시청자는 입력값과 기울기 사이에 대응 관계가 있음을 확인합니다.

**143–158초 · 기울기를 새로운 변수로**

기존의 가로축에는 \\(\dot q\\)가 표시되어 있습니다.

이제 그 지점의 접선 기울기를 \\(p\\)라고 표시하고, 접선의 기울기를 기준으로 그래프의 정보를 다시 읽어봅니다.

이때 기존 곡선이 갑자기 사라져 새로운 곡선으로 바뀌면 안 됩니다. 동일한 접선에 대해 원래 함수값, 속도, 기울기가 어떻게 연결되어 있는지 먼저 보여줍니다.

**158–172초 · 르장드르 변환의 등장**

\\[ p=\frac{\partial L}{\partial\dot q} \\]

이 관계를 보여준 뒤,

\\[ H=p\dot q-L \\]

이라는 새로운 함수가 등장합니다.

여기에서는 기울기 \\(p\\)와 위치 \\(q\\)가 주어졌을 때, 대응하는 \\(\dot q\\)를 찾아 \\(H\\)의 값을 계산하는 과정을 시각화합니다.

접선의 세로축 절편이 \\(-H\\)에 대응한다는 점을 보여줄 수도 있습니다. 단, 이때는 위치 \\(q\\)를 고정하고 라그랑지안을 속도에 대한 함수로 그려야 합니다.

**172–188초 · 새로운 함수가 완성되다**

기존의 \\(L(q,\dot q)\\) 옆에 \\(H(q,p)\\)가 나타납니다.

두 표현은 서로 다른 입력 변수를 사용합니다. 그러나 적절한 조건에서는 같은 물리계의 정보를 재표현합니다.

마지막에는 라그랑지안 그래프가 작아지면서 왼쪽에 남고, 운동량을 사용하는 새로운 표현이 오른쪽에 나타납니다.

이 장면에서는 \\(H\\)를 아직 해밀토니안이라고 길게 설명하지 않고, 다음 장에서 그 역할을 다룰 수 있도록 이름만 가볍게 예고해도 좋겠습니다.

## **4. Manim 제작에서 필요한 핵심 구현**

이번 장에서는 Manim 객체를 단순히 등장시키고 이동시키는 방식보다, **하나의 물리 상태 데이터를 여러 표현에 연결하는 방식**을 권합니다.

예를 들어 다음 구조입니다.

```
class PendulumModel:    def state_at(self, t):        # theta, angular_velocity, momentum        ...    def lagrangian(self, theta, omega):        ...    def action(self, time_samples, theta_samples):        ...class PendulumVisuals:    def physical_pendulum(self):        ...    def angle_velocity_space(self):        ...    def lagrangian_curve(self):        ...    def legendre_transform(self):        ...    def phase_space(self):        ...class Chapter03Director:    def show_same_position_different_states(self):        ...    def transform_motion_to_state_point(self):        ...    def review_lagrangian_action(self):        ...    def reveal_momentum_as_slope(self):        ...    def animate_legendre_transform(self):        ...    def transition_to_phase_space(self):        ...
```

중요한 구현 원칙은 다음과 같습니다.

| 대상      | 계산 기준                               | 화면 요소        |
| ------- | ----------------------------------- | ------------ |
| 실제 진자   | \\(\theta(t)\\)                     | 추와 실의 움직임    |
| 상태 공간   | \\((\theta,\dot\theta)\\)           | 좌표계의 점과 궤적   |
| 라그랑지안   | \\(L(\theta,\dot\theta)\\)          | 함수값과 접선      |
| 운동량     | \\(\partial L/\partial\dot\theta\\) | 기울기와 값       |
| 르장드르 변환 | \\(p\dot\theta-L\\)                 | 접선과 새로운 함수   |
| 위상 공간   | \\((\theta,p\_\theta)\\)            | 새로운 축의 상태 궤적 |

특히 102\~188초의 그래프는 별도로 만들어 둔 임의의 애니메이션을 재생하는 것이 아니라, 실제 진자의 라그랑지안과 운동량에 대응하는 데이터를 사용하는 것이 좋겠습니다.

그래야 속도가 달라질 때 기울기가 변하고, 그 기울기가 다시 운동량이라는 새로운 변수로 연결되는 과정을 정확하게 구현할 수 있습니다.

## **5. 가장 공들일 구간**

이번 3장에서는 다음 세 구간을 우선 제작하는 것이 좋겠습니다.

01

**33–70초 — 상태 공간의 등장**

실제 진자가 움직일 때, 각도와 각속도로 이루어진 점이 동시에 움직이는 장면입니다. 시청자가 새로운 좌표 공간의 필요성을 이해하는 핵심입니다.

02

**102–188초 — 운동량과 르장드르 변환**

이번 장에서 수학적으로 가장 어려운 부분입니다. 하나의 함수 그래프 위에서 접선의 기울기가 새로운 변수가 되고, 이를 바탕으로 새로운 함수를 구성하는 과정이 자연스럽게 연결되어야 합니다.

03

**188–240초 — 위상 공간의 완성**

앞서 등장한 각도와 운동량이 실제 하나의 점과 궤적으로 연결되는 장면입니다. 4장에서 해밀토니안의 시간 진화를 설명하기 위한 시각적 기반이 됩니다.

이번 장에서 시청자가 이해해야 할 가장 중요한 흐름은 다음과 같습니다.

**실제 운동 → 순간 상태의 표현 → 라그랑지안의 변화율 → 운동량 → 르장드르 변환 → 위상 공간**

특히 화면의 그래프들이 독립적으로 등장하는 것이 아니라, **앞선 그래프에서 얻은 정보가 다음 그래프의 입력이 되는 방식**으로 연결되도록 제작하겠습니다.

그리고 마지막에는 1\~3장에서 발전한 수학적 표현들을 한 번에 되짚으면서, 다음 장에서 해밀토니안이 왜 등장해야 하는지 자연스럽게 이어지도록 구성하면 좋겠습니다.

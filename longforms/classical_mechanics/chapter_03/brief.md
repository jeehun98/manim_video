# 제작 기준
- 사용자 원문56문장·종료시각299초. 16:9 1920×1080·30fps, 무음·전체 자막. 음원 미제공.
- 사용자 콘티를 참고하되 원문과 확정 발화시간을 최우선으로 한다. 본문에 포함된 복습·연결 문장은 유지하고 별도 다음 장 타이틀은 넣지 않는다.
- 기존 chapter_01의 비선형 진자 모델·색·도형·폰트와 chapter_02의 렌더 검사 흐름을 재사용한다. 이전 장 소스는 수정하지 않는다.
- 8개 독립 씬. 각도·각속도 상태 공간과 각도·정준운동량 위상 공간을 구별한다. I=mℓ²=4, pθ=Iω.
- 위상 궤적은 정확한 비선형 에너지 관계에서 계산한다. 작은 각도 근사 타원을 사용하지 않는다.
- L 속도 그래프는 θ=.35rad 고정. 접선의 기울기 pθ, 절편 −H, H=pθω−L을 같은 데이터로 계산한다. 규칙적 변환 조건 I>0을 검증한다.
- 마지막 화살표는 이미 알려진 운동방정식의 벡터장이다. 실제 운동 방향이 불확정하다는 연출은 하지 않는다.
- 132~188초 르장드르 변환 저해상도 확인 → 대표 화면 검수 → 최종 렌더 → 프레임·자막·소스 해시 확인.

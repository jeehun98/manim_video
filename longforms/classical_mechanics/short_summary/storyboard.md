# **뉴턴에서 해밀토니안까지 — 174초 쇼츠 영상화 콘티**

9:16 · 세로 영상

총 2분 54초 · Manim 중심 제작

이번 쇼츠는 6개 장의 개념을 짧은 시간에 압축하므로, **하나의 진자가 계속해서 새로운 수학적 표현으로 변하는 영상**으로 구성하는 것이 좋겠습니다.

특히 장면마다 새로운 그래프를 갑자기 등장시키지 않고, 앞에서 얻은 수학적 대상이 다음 표현의 입력으로 연결되도록 설계하겠습니다.

## **1. 전체 영상의 흐름**

**실제 진자**

\\(F=ma\\)힘과 초기조건으로 운동 예측

**에너지와 운동 경로**

\\(L=T-V\quad\longrightarrow\quad\delta S=0\\)라그랑지안 · 작용의 정지 조건

**운동을 하나의 점으로 표현**

\\((\theta,p\_\theta)\\)위상 공간의 상태와 궤적

**해밀토니안**

\\(H(\theta,p\_\theta)\\)르장드르 변환 · 시간 진화

**보존되는 구조**

심플렉틱 구조 · 대칭성 · 뇌터 정리

**양자역학으로 이어지는 역할**

\\(\hat H\\,|\psi\rangle\\)달라진 상태 표현 · 이어지는 시간 진화의 수학

진자는 계속 움직이지만, 그 옆에 새로운 두 표시가 나타납니다.

`운동에너지 T` / `위치에너지 V`

새로운 수식이 갑자기 나타나는 것이 아니라, 그래프의 값을 시간에 따라 누적한 결과로 작용이 등장해야 합니다.

대신 실제 경로는 금색, 가능한 가상 경로는 파란색으로 표시하고, 양 끝점이 고정되어 있다는 사실을 명확히 보여주면 됩니다.

화면 하단 결론: 같은 운동 · 다른 수학적 원리

**연출의 핵심은 진자를 없애는 것이 아니라, 진자의 운동을 하나의 점으로 압축하는 것**입니다.

### **Scene 05 · 90–123초**

**르장드르 변환과 해밀토니안의 등장**

이 구간은 단순한 그래프 전환이 아니라 세 가지 단계를 짧게 연결해야 합니다.

라그랑지안의 기울기

\\(p=\partial L/\partial\dot q\\)

르장드르 변환

\\(H=p\dot q-L\\)

해밀토니안의 흐름

\\(H(q,p)\\)

| 시간       | 화면 연출                                                                              |
| -------- | ---------------------------------------------------------------------------------- |
| 90–94초   | 2장에서 사용했던 \\(L(\theta,\dot\theta)\\) 그래프를 재등장시킵니다. 점에 접선을 그려 그 기울기가 운동량이 됨을 보여줍니다. |
| 94–102초  | 접선의 기울기 \\(p\\)가 새로운 변수로 사용되고, 르장드르 변환을 통해 \\(H(\theta,p)\\)가 만들어집니다.              |
| 102–109초 | 이상적인 진자의 해밀토니안을 두 에너지의 합 \\(T+V\\)로 보여줍니다.                                         |
| 109–114초 | 위상 공간의 여러 점에 에너지 값이 나타나고, 같은 에너지의 점들이 등고선으로 연결됩니다.                                 |
| 114–118초 | 해밀턴 방정식에서 각 상태의 시간 변화율을 계산합니다.                                                     |
| 118–123초 | 위상 공간 전체에 방향 화살표가 펼쳐지고, 상태 점이 그 화살표를 따라 움직입니다.                                     |

특히 109\~123초는 **등고선과 운동의 방향장을 구분하는 것**이 중요합니다.

처음에는 등고선만 나타납니다. 그다음 해밀턴 방정식으로 방향이 정해지면서 점이 움직이기 시작해야 합니다.

최종 제작에서는 실제 단진자의 해밀턴 벡터장으로 화살표의 방향과 크기를 계산합니다.

이렇게 구현하면 해밀토니안이 단순히 에너지를 계산하는 함수에 그치지 않고, 물리계의 시간 진화를 만들어낸다는 사실을 짧은 시간 안에 전달할 수 있습니다.

| 127–133초 | 시간이 흐르면서 영역이 길게 늘어나고 휘어집니다. 면적 표시 값은 일정하게 유지됩니다. |

자유도가 하나인 진자의 정준 위상 공간에서는 면적 보존으로 나타나며, 일반적인 다자유도 계에서는 더 강한 심플렉틱 구조의 보존이 성립합니다.

## **3. Manim 제작에서 중요한 구현 원칙**

이번 174초 쇼츠는 실제로 모든 물리 현상을 그 자리에서 실시간 계산하기보다, 물리 모델에서 계산한 결과를 각 시각화 장면이 공유하는 방식이 적합합니다.

**공통 진자 모델**

\\(\theta(t),\ \dot\theta(t),\ p\_\theta(t)\\)

**진자 객체**

실제 운동

**에너지 그래프**

\\(T,V,L\\)

**운동 경로**

\\(\theta(t),S\\)

**위상 공간**

\\((\theta,p\_\theta)\\)

**해밀턴 흐름**

방향장 · 여러 초기 상태의 변형

이 공통 데이터 구조가 있어야 화면에서 보여주는 서로 다른 수학적 표현이 정확히 같은 운동을 나타낼 수 있습니다.

특히 제작 과정에서 신경 써야 할 것은 다음과 같습니다.

- **25\~64초:** 작용의 정지 조건은 작용 자체가 0이라는 뜻이 아니라, 경로의 미소 변화에 대한 일차 변화가 0이라는 뜻입니다.
- **64\~123초:** 진자의 운동량은 단순한 직선 운동량 \\(mv\\)가 아니라, 각도에 대응하는 정준운동량 \\(p\_\theta=m\ell^2\dot\theta\\)입니다.
- **123\~150초:** 면적 보존과 대칭성에 따른 보존량은 서로 다른 수학적 성질입니다.
- **150\~162초:** 양자역학은 동일한 고전 운동을 다시 표현하는 방법이 아니라, 상태와 측정에 관한 새로운 물리 이론입니다.

## **4. 제작 우선순위**

174초 안에 개념이 많이 등장하기 때문에, 모든 장면을 똑같은 복잡도로 제작하는 것은 효율적이지 않습니다.

| 구간       | 제작 강도 | 이유                        |
| -------- | ----- | ------------------------- |
| 0–25초    | 중간    | 영상의 질문과 물리적 대상 소개         |
| 25–64초   | 높음    | 라그랑지안에서 작용으로 이어지는 연결이 중요  |
| 64–90초   | 매우 높음 | 실제 진자가 수학적 상태로 전환되는 핵심 장면 |
| 90–123초  | 매우 높음 | 운동량·르장드르 변환·해밀토니안 연결      |
| 123–162초 | 중간    | 발견한 구조들의 의미를 압축해서 전달      |
| 162–174초 | 낮음    | 익숙한 진자만 남겨 마무리            |

**이번 쇼츠에서 가장 강하게 보여줘야 하는 변화는 64\~123초입니다.**

실제 진자의 운동이 위상 공간의 한 점으로 표현되고, 라그랑지안에서 얻은 운동량을 이용해 해밀토니안을 구성한 뒤, 그 함수로부터 점의 시간 진화를 결정하는 과정입니다.

이 부분을 하나의 연속적인 장면처럼 연결하면, 시청자는 뉴턴 이후의 고전역학이 단순히 수식을 복잡하게 만든 것이 아니라 **동일한 운동을 새로운 수학적 공간과 구조로 바라보게 만든 과정**이라는 사실을 이해할 수 있습니다.

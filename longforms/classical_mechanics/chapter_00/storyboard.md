# **CHAPTER 00 — 고전역학의 발전을 따라가는 지도**

INTRO · 91초

16:9 롱폼 · Manim 기반

이번 0장은 개념을 하나씩 소개하는 일반적인 인트로보다, **영상 전체를 하나의 거대한 수학적 지도로 보여주고, 카메라가 그 지도를 따라 이동하는 방식**이 적합하겠습니다.

중심에는 하나의 진자가 있고, 진자로부터 서로 다른 수학적 표현들이 뻗어 나갑니다. 카메라는 뉴턴 역학에서 출발해 라그랑주 역학, 위상 공간, 해밀턴 역학, 보존 구조, 양자역학까지 이동합니다.

중요한 것은 **각 개념을 독립적인 장면으로 끊지 않는 것**입니다. 이전 개념에서 새로운 질문이 생기고, 그 질문을 따라 다음 영역으로 이동하는 느낌을 만들겠습니다.

## **1. 전체 영상의 기본 화면 — 하나의 지도**

지도 구성 예시 — 실제 영상에서는 16:9 캔버스 안에 이 경로를 가로로 넓게 펼치고 카메라가 이동합니다.

이 지도는 게임의 스킬 트리나 탐험 지도와 비슷한 역할을 하지만, 화면을 너무 게임 UI처럼 만들 필요는 없습니다.

각 지점은 하나의 수학적 공간처럼 구성합니다. 예를 들어 뉴턴의 영역에는 힘 화살표가 있는 진자가 움직이고, 라그랑주의 영역에는 여러 경로가 겹쳐 있으며, 해밀턴의 영역에는 위상 공간의 등고선과 방향장이 펼쳐집니다.

카메라는 이를 따라 이동하다가 마지막에 줌아웃하여 **처음부터 하나의 지도 안에 존재하던 개념들이었다는 사실**을 드러냅니다.

## **2. 카메라가 이동하는 경로**

0–24초 · 뉴턴의 영역에서 출발

24–35초 · 힘에서 에너지와 작용으로

35–54초 · 진자의 상태가 점으로 변환

54–74초 · 보존 구조와 양자역학으로 확장

74–91초 · 전체 지도로 돌아오며 영상 시작

# **3. 시간별 상세 영상화 콘티**

## **Scene 01 · 0–24초**

**뉴턴 역학 — 지도의 출발점**

| 시간     | 화면 구성 및 카메라                                                                               |
| ------ | ----------------------------------------------------------------------------------------- |
| 0–4초   | 검은 화면에서 진자 하나가 나타납니다. 진자가 움직이며 실제 운동 경로를 남깁니다.                                            |
| 4–10초  | 카메라가 뒤로 조금 물러나고, 진자 주변에 `NEWTON`, `LAGRANGE`, `HAMILTON`이라는 이름이 희미하게 나타납니다. 뉴턴 영역만 밝아집니다. |
| 10–12초 | 카메라가 뉴턴 영역을 향해 이동합니다.                                                                     |
| 12–19초 | 진자에 힘 화살표와 초기 상태를 표시합니다. 운동방정식이 등장하고 미래 운동 궤적이 그려집니다.                                     |
| 19–24초 | 힘 화살표와 운동방정식은 뉴턴 영역에 그대로 남고, 카메라가 오른쪽의 다음 영역으로 움직이기 시작합니다.                                |

### **핵심 전환**

“그런데 반드시 힘을 직접 분석해야만 운동을 설명할 수 있을까요?”

이 질문에서 뉴턴 영역을 지우지 않습니다.

대신 힘 화살표가 그려진 진자는 왼쪽으로 멀어지고, 카메라가 진행하는 방향에는 에너지 막대가 나타납니다.

**뉴턴의 설명이 사라진 것이 아니라, 그 옆에 새로운 설명이 추가되는 느낌**입니다.

## **Scene 02 · 24–35초**

**라그랑주 역학 — 힘이 아닌 에너지와 작용**

| 시간     | 화면 구성 및 카메라                                                                          |
| ------ | ------------------------------------------------------------------------------------ |
| 24–32초 | 이동 중인 카메라 앞에 동일한 진자가 등장합니다. 힘 화살표 대신 운동에너지와 위치에너지 막대가 변합니다. 두 값이 `L = T − V`로 합쳐집니다. |
| 32–35초 | 라그랑지안에서 여러 가능한 경로가 펼쳐지고, 그중 실제 운동 경로가 강조됩니다. 카메라가 다음 영역으로 이어집니다.                     |

이 구간에서는 작용의 정지 조건을 따로 설명하지 않으므로 \\(\delta S=0\\)은 화면에 잠깐 나타나는 정도로 충분합니다.

**라그랑주 영역의 핵심적인 시각적 특징은 여러 가능한 운동 경로**입니다.

뉴턴 영역에서 하나의 미래 궤적을 예측했다면, 라그랑주 영역에서는 여러 가능한 경로 중 실제 운동을 결정하는 원리를 보여주는 것입니다.

## **Scene 03 · 35–54초**

**위상 공간과 해밀턴 역학 — 새로운 공간으로 들어가다**

이 구간에서는 카메라가 단순히 다음 장소로 이동하는 것만으로 끝내지 않고, **카메라가 바라보는 공간 자체가 바뀌는 느낌**을 주겠습니다.

| 시간     | 화면 구성 및 카메라                                                          |
| ------ | -------------------------------------------------------------------- |
| 35–39초 | 라그랑주 영역을 떠나며 하나의 진자가 화면 중앙에 남습니다.                                    |
| 39–48초 | 진자에서 각도와 운동량이 추출되고, 두 값이 오른쪽의 좌표평면에 하나의 점을 형성합니다. 점이 궤적을 그리며 움직입니다.  |
| 48–54초 | 카메라가 좌표평면 속으로 이동합니다. 점과 궤적이 화면 중앙을 차지하고, 주변에 에너지 등고선과 방향 화살표가 펼쳐집니다. |

### **중요한 시각적 장치**

39\~48초의 내레이션에서 진자의 순간 상태가 하나의 점으로 바뀌는 순간은 전체 지도의 경계가 바뀌는 장면으로 설계합니다.

진자의 좌표와 운동량이 위상 공간으로 옮겨지면서, 카메라도 실제 운동이 보이는 영역에서 **상태를 표현하는 수학적 공간**으로 이동합니다.

즉, 하나의 지도 안에 있지만 여기서부터는 실제 물리적 공간이 아닌 새로운 표현 공간을 탐험하는 것입니다.

## **Scene 04 · 54–74초**

**보존되는 구조를 발견하고 양자역학으로 확장하다**

| 시간     | 화면 구성 및 카메라                                                                                       |
| ------ | ------------------------------------------------------------------------------------------------- |
| 54–58초 | 카메라가 위상 공간 위로 올라가며 하나의 점이 아닌 여러 점의 운동을 보여줍니다.                                                     |
| 58–66초 | 가까운 점들을 작은 영역으로 둘러싸고 시간에 따라 변형시킵니다. 영역의 넓이는 일정하게 유지됩니다. 옆에 대칭성과 보존량을 연결하는 간단한 기호가 나타납니다.          |
| 66–74초 | 카메라가 지도의 바깥쪽으로 조금 더 이동합니다. 새로운 영역에 `QUANTUM`이라는 이름이 희미하게 나타나고, 상태를 표현하는 점이 새로운 수학적 상태 표현으로 전환됩니다. |

양자역학 영역에서는 본격적인 설명을 시작하지 않습니다.

해밀토니안이라는 이름은 이어지지만, 상태의 표현 방식은 달라진다는 것을 암시하는 정도면 충분합니다.

**표현이 바뀌며 새로운 구조가 발견되고, 그 사고가 이후의 이론에도 이어진다**는 방향으로 시청자의 시선을 유도합니다.

## **Scene 05 · 74–91초**

**지도가 완성되며 본편의 출발점으로 돌아오다**

마지막 17초는 앞에서 지나온 공간들이 하나의 전체 구조를 형성하고 있음을 보여주는 장면입니다.

이번 인트로에서 가장 중요한 연출이기도 합니다.

| 시간     | 화면 구성 및 카메라                                                                                                      |
| ------ | ---------------------------------------------------------------------------------------------------------------- |
| 74–79초 | 카메라가 천천히 뒤로 물러납니다. 뉴턴, 라그랑주, 위상 공간, 해밀턴, 기하학과 대칭성 영역이 모두 화면에 들어오기 시작합니다.                                         |
| 79–85초 | 각 영역을 잇는 길이 밝아지며 전체 로드맵이 완성됩니다. 중앙에 `고전역학은 어떻게 발전해 왔는가?`라는 제목이 나타납니다.                                            |
| 85–91초 | 카메라가 완성된 지도 속 첫 번째 지점인 `CHAPTER 01 · NEWTON`을 향해 다시 확대됩니다. 해당 영역에 매달려 있던 진자가 화면 전체로 커지면서 1장의 첫 장면으로 자연스럽게 이어집니다. |

특히 마지막에 장면을 검게 전환했다가 1장을 시작하기보다, **완성된 지도에서 뉴턴 영역으로 직접 진입하는 것**을 추천합니다.

0장은 앞으로 여행할 수학적 공간을 보여주는 역할을 하고, 1장부터 그 공간을 하나씩 탐험한다는 연출이 완성됩니다.

# **4. Manim 구성 방식**

이번 인트로는 개별 장면 5개를 렌더링한 뒤 이어 붙이는 것보다, **하나의 큰 월드 좌표계에서 카메라가 이동하는 방식**을 기본으로 잡으면 좋겠습니다.

**WorldScene**

넓은 가상 캔버스 · 공통 배경 · 연결 경로

**NewtonRegion**

진자 · 힘 · 운동방정식

**LagrangeRegion**

에너지 · 작용 경로

**PhaseRegion**

위상 공간의 점과 궤적

**HamiltonRegion**

등고선 · 방향장

**StructureRegion**

영역 변형 · 대칭성

**QuantumRegion**

새로운 상태 표현의 예고

전체 카메라 흐름은 다음처럼 잡겠습니다.

| 구간     | 카메라 동작            | 효과                   |

카메라 동작은 Manim의 `MovingCameraScene`을 기준으로 구성할 수 있습니다. 복잡한 입체 공간보다, 2차원 월드에 깊이감 있는 레이어를 추가하는 방식이 안정적입니다.

## **5. 본편과 연결하는 방법**

여기서 한 가지 더 고려하면 좋겠습니다.

0장에서 사용하는 지도를 **0장에서만 등장하는 장식적인 화면으로 끝내지 않는 것**입니다.

각 장의 시작과 끝에서 이 지도를 재사용하면, 영상 전체가 일관된 구조를 갖게 됩니다.

0장

전체 지도 공개

1장 시작

NEWTON에 진입

1장 종료

NEWTON → LAGRANGE 경로 활성화

2\~5장

각 영역을 지나며 지도 확장

6장 종료

전체 지도로 복귀

0장에서는 모든 영역이 지도에 표시되지만, 자세한 내용은 흐릿하게 처리합니다. 이후 실제로 해당 장에 진입할 때 그 영역의 그래프와 수식이 활성화되는 방식입니다.

이렇게 하면 시청자는 새로운 장이 시작될 때마다 **지금까지 무엇을 배웠고, 다음에는 무엇을 발견할 것인지** 자연스럽게 인식할 수 있습니다.

또한 마지막 6장에서는 처음 공개한 지도 전체를 다시 보여주며, 뉴턴에서 시작한 탐험이 양자역학으로 이어졌다는 사실을 시각적으로 마무리할 수 있습니다.

**최종적으로 추천하는 연출은 ‘지도를 설명하는 인트로’가 아니라 ‘지도를 실제로 한 바퀴 탐험한 뒤 출발점으로 돌아오는 인트로’입니다.** 91초 동안 카메라가 각 영역을 잠깐 방문하고, 모든 영역을 연결한 다음 1장으로 진입하는 구조가 영상 전체의 방향성을 가장 명확하게 전달할 수 있습니다.

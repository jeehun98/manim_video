결과: `exports/classical_ch04_366s_longform_final.mp4`, 같은 이름의 `_captions.srt`.

`timing.json`은 사용자 제공 문장 종료 시각, `manifest.json`과 씬별 `spec.md`는 독립 구간과 주장, `storyboard.md`는 사용자 콘티이다. `mechanics.py`는 하나의 해밀토니안에서 에너지 곡면·등고선·운동 벡터·적분 궤적·물질 영역을 계산하고 검증한다. 기존 chapter_01의 비선형 진자와 시각 요소를 재사용하고 의존 파일을 캐시 해시에 포함한다.

회전 구간은 가벼운 강체 막대 진자를 사용한다. 이전 장의 왕복 운동에서는 같은 운동방정식을 따른다. Ec=2mgℓ이며, 화면의 에너지 선택기는 E/Ec이다. 임계 에너지의 운동은 정확한 점근 해로 표시한다. θ=−π와 π를 같은 각도로 연결한 차트에서 회전을 표시하며, 궤적을 경계에서 인위적인 선으로 닫지 않는다.

에너지 곡면은 실제 H의 3차원 샘플로 만든 투시 메쉬이며 장식용 임의 곡면이 아니다. 방향장은 화면 좌표로 사영한 뒤 공통 배율을 적용한다. 점과 영역은 실제 해밀턴 시간 적분을 사용한다. 마지막은 질문과 영역의 변형을 유지하며 별도 다음 장 엔드카드를 넣지 않는다.

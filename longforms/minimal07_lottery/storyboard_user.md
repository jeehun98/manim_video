# 「모든 것이 필요할까?」 07 — 복권 가설(Lottery Ticket Hypothesis) 상세 영상화 콘티

총 170초 · 2분 50초 · 9:16 세로 영상 · Manim 기반

이번 편은 앞선 여섯 편을 정리하면서 신경망으로 진입하는 전환점이야.

영상의 중심은 같은 작은 신경망이라도 어떤 초기 가중치에서 출발했느냐에 따라 학습 결과가 달라질 수 있다는 사실이야.

가장 중요한 구간은 80\~114초의 실험 과정과 117\~135초의 초기값 비교야. 여기서는 단순한 개념 애니메이션보다 실제 가중치의 변화와 학습 곡선을 함께 보여주는 것이 좋아.

## 1. 전체 시각적 구성

회색 연결은 제거 대상, 노란색 연결은 남겨질 부분 신경망을 나타내는 개념 도식.

색상 체계는 영상 전체에서 일관되게 유지하자.

| 요소          | 색상      | 의미                      |
| ----------- | ------- | ----------------------- |
| 원래 큰 신경망    | 청록색     | 전체 모델                   |
| 제거되는 연결     | 어두운 회색  | Pruned weights          |
| 남겨지는 연결     | 노란색     | Winning Ticket 후보       |
| 원래 초기 가중치   | 파란색     | Original Initialization |
| 새로운 무작위 초기값 | 분홍색     | Random Reinitialization |
| 정확도·손실 곡선   | 노란색/분홍색 | 두 학습 결과 비교              |

## 2. 상세 장면별 콘티

### Scene 01. 지금까지의 질문 (00:00–00:05)

00:00–00:04

검은 배경에 이전 영상에서 사용했던 그래프, 유전자, 통계 데이터, 상태공간, 스핀 격자 이미지가 빠르게 등장한다.

중앙에 문구가 나타난다.

`모든 것이 정말 필요할까?`

00:04–00:05

다섯 개의 이미지가 작은 카드로 정렬되며 다음 장면으로 전환된다.

### Scene 02. 그래프 — 연결을 줄여도 성질은 남는다 (00:05–00:11)

00:05–00:11

완전그래프에 가까운 구조에서 연결들이 순서대로 제거된다.

마지막에는 모든 정점이 여전히 연결된 트리 구조가 남는다.

화면 문구: `연결은 줄어도 연결성은 유지`

이 장면에서는 그래프 희소화의 모든 성질을 보여주려 하지 말고, 연결성 보존을 대표 사례로 사용한다.

### Scene 03. 유전체 — 필수성은 조건에 따라 달라진다 (00:11–00:18)

00:11–00:18

긴 DNA 서열 또는 유전자 블록들이 화면을 가로지른다.

일부 유전자 블록이 제거되고, 생존 여부를 나타내는 표시가 바뀐다.

환경 A에서는 제거 가능한 유전자가 환경 B에서는 필수적으로 표시되는 장면을 보여준다.

문구: `필요한 유전자는 환경에 따라 달라진다`

### Scene 04. 충분통계량 — 데이터가 하나의 숫자로 (00:18–00:26)

00:18–00:26

수많은 측정값이 점 구름으로 나타난다.

데이터들이 하나의 평균값을 향해 모이는 애니메이션을 적용한다.

\\[ x_1,x_2,\ldots,x_n\longrightarrow\bar x \\]

문구: `특정 추론에 필요한 정보만 보존`

이 장면에서는 정규분포와 알려진 분산이라는 조건을 작은 보조 자막으로 표시한다.

### Scene 05. 최소 실현 — 상태 두 개가 하나로 (00:26–00:33)

00:26–00:33

두 개의 상태 블록 \\(x_1,x_2\\)가 합쳐져 하나의 상태 \\(z\\)로 변환된다.

\\[ z=x_1+x_2 \\]

아래에는 원래 시스템과 축소 시스템의 출력 곡선이 정확히 겹쳐진다.

문구: `상태 차원 감소 · 입출력 동작 유지`

### Scene 06. 보편성 — 다른 물질, 같은 임계 법칙 (00:33–00:39)

00:33–00:39

스핀 격자와 액체의 밀도 요동이 좌우에 등장한다.

두 시스템에서 서로 다른 미시적 패턴이 축소되면서 동일한 임계 지수 기호 \\(\beta\\)가 중앙에 남는다.

문구: `다른 구조 · 같은 보편적 법칙`

### Scene 07. 신경망으로의 전환 (00:39–00:51)

00:39–00:43

이전 다섯 장면이 하나의 화면에 축소되어 정렬된다.

중앙에 질문이 등장한다.

`원하는 결과를 유지하려면 무엇이 필요한가?`

00:43–00:47

다섯 장면이 사라지고 신경망의 노드와 연결이 화면을 채우기 시작한다.

00:47–00:51

복잡한 신경망이 완성된다.

상단 문구: `이제, 신경망에서는?`

### Scene 08. 수많은 연결이 모두 필요할까? (00:51–01:05)

00:51–00:57

4\~6개 층으로 이루어진 신경망을 보여준다.

연결마다 작은 가중치 값이 나타나고 학습 과정에서 숫자가 바뀐다.

00:57–00:59

화면 전체를 멈추고 질문을 강조한다.

`모든 연결이 필요할까?`

00:59–01:05

일부 연결이 회색으로 변하며 사라진다.

오른쪽에는 정확도 그래프가 나타나고, 일부 연결 제거 후에도 정확도가 크게 떨어지지 않는 예시를 보여준다.

이때 그래프는 실제 측정 결과가 아니라면 `개념 예시`라고 표시한다.

### Scene 09. 학습 후 가지치기와 처음부터 학습은 다르다 (01:05–01:20)

학습 후 가지치기

Train → Prune

학습된 가중치 유지

복권 가설의 질문

Train → Prune → Reset → Retrain

초기값으로 되돌려 재학습

01:05–01:08

학습된 큰 신경망에서 일부 연결을 제거하는 장면.

01:08–01:15

오른쪽에 동일한 희소 연결 구조를 복제한다.

이 복제본의 가중치를 초기값으로 되돌리는 장면을 예고한다.

01:15–01:20

`Lottery Ticket Hypothesis`라는 제목을 중앙에 등장시킨다.

### Scene 10. 복권 가설 실험 — 초기화와 전체 학습 (01:20–01:26)

01:20–01:24

큰 신경망이 무작위 가중치로 초기화된다.

각 연결의 가중치를 작은 색상 막대 또는 숫자로 표시한다.

이 초기값을 별도의 메모리 패널에 저장한다.

\\[ W_0 \\]

01:24–01:26

학습을 시작한다. 가중치 색상과 손실 곡선이 변한다.

### Scene 11. 연결 제거와 초기값 복원 (01:26–01:41)

01:26–01:32

학습이 끝난 가중치 중 일부 연결을 제거한다.

남은 연결은 노란색, 제거된 연결은 어두운 회색으로 표시한다.

01:32–01:34

잠시 멈춘 뒤 `Reset`이라는 문구를 강조한다.

01:34–01:41

남은 연결의 가중치가 학습 전의 값으로 되돌아간다.

이때 연결 구조는 유지되고 가중치 값만 바뀐다는 사실이 명확해야 해.

수식으로는 다음과 같이 표현할 수 있어.

\\[ W\_{\mathrm{ticket}}=M\odot W_0 \\]

여기서 \\(M\\)은 어떤 연결을 남길지 결정하는 마스크야.

### Scene 12. 작은 신경망을 다시 학습한다 (01:41–01:57)

01:41–01:44

남은 연결만 활성화된 작은 신경망이 다시 학습을 시작한다.

01:44–01:54

원래 큰 신경망과 작은 부분 신경망의 학습 정확도 곡선을 비교한다.

학습 곡선의 형태를 설명하기 위한 개념 예시. 실제 연구 수치로 제시하려면 해당 실험 데이터를 사용해야 한다.

01:54–01:57

두 곡선이 유사한 성능에 도달한 모습을 강조한다.

### Scene 13. 같은 구조, 다른 초기값 (01:57–02:15)

01:57–02:01

희소 신경망을 두 개로 복제한다.

두 신경망의 연결 구조는 정확히 동일하게 유지한다.

02:01–02:03

왼쪽에는 `Original Initialization`, 오른쪽에는 `Random Reinitialization`을 표시한다.

02:03–02:09

두 모델을 같은 학습 설정으로 학습시킨다.

02:09–02:15

학습 곡선을 비교한다.

일부 실험에서는 원래 초기값을 유지한 모델이 더 좋은 학습 결과를 보인다는 점을 보여준다.

다만 모든 설정에서 동일한 차이가 발생하는 것처럼 표현하지 않는다.

### Scene 14. 구조만이 아니라 초기값도 중요하다 (02:15–02:24)

02:15–02:19

두 신경망의 연결 구조를 반투명하게 겹쳐서 완전히 같음을 보여준다.

02:19–02:24

가중치 값만 다른 색으로 강조한다.

화면 문구:

`같은 연결 구조 ≠ 같은 학습 결과`

### Scene 15. 복권 가설의 한계 (02:24–02:38)

02:24–02:29

모든 연결이 제거 가능한 것처럼 보이는 화면을 잠시 보여준 뒤, `항상 가능한 것은 아니다`라는 문구를 표시한다.

02:29–02:34

작은 신경망을 찾기 위해 먼저 큰 신경망을 학습하는 과정을 다시 보여준다.

`발견 비용 ≠ 최종 모델 크기`

02:34–02:38

`조건에 따라 달라지는 학습 가능성`이라는 문구로 정리한다.

### Scene 16. 결론과 다음 질문 (02:38–02:50)

02:38–02:41

큰 신경망과 Winning Ticket을 나란히 배치한다.

02:41–02:47

연결의 개수와 독립적인 학습 자유도를 나타내는 두 아이콘을 비교한다.

왼쪽에는 `Connections`, 오른쪽에는 `Degrees of Freedom`.

02:47–02:50

마지막 질문을 화면 중앙에 표시한다.

“신경망에 정말 필요한 자유도는 몇 개일까?”

아래에 작게 `모든 것이 필요할까?`를 표시하고 마무리한다.

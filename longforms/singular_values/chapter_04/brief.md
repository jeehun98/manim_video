# 제작 기준

사용자 확정 25문장·137초. 16:9 1920×1080 30fps. 음원 미제공으로 무음, 화면 자막 포함. 콘티의 여섯 연속 그룹을 독립 렌더한다.

새 대각행렬 Aₜ=diag(2,t), 0≤t≤1을 명시한다. t>0이면 랭크2, 정확한0에서만 랭크1로 바뀐다. 작은 양수가 반올림되어0으로 보이지 않도록 0<t<0.001이면 >0으로 표시한다.
입력 공간 자체가 아닌 이미지 공간의 차원 감소를 설명한다. 길이0의 벡터는 점, 퇴화타원은 선분으로 교체한다. 비교는 동일 척도이며 확대창은 세로 단면×60으로 명시한다.
3차원은 B=diag(2,s,t)를 실제 변환하며, 정확한0에서 평면 영역 또는 선분으로 교체한다. 랭크는 3→2→1로 감소한다.
저랭크 근사는 A=diag(2,0.1), A₁=diag(2,0)이다. 최대 오차0.1은 단위입력의 최대 절대 변환 오차다. 작은 특잇값을 데이터의 의미적 중요도와 동일시하지 않는다.
막대 분포는 설명용 예시다. 마지막에는 두 양의 특잇값을 갖는 타원과 σ₁σ₂=?를 표시하며 행렬식 공식은 공개하지 않는다.

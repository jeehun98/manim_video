가장 중요한 장면은 타원이 점차 납작해지는 과정과 정확히 선분으로 붕괴하는 순간이다. 이를 통해 랭크와 영공간의 의미를 기하학적으로 이해하고, 마지막에는 작은 특잇값을 의도적으로 제거하는 저랭크 근사로 연결한다.

3장에서는 수식 중심의 설명이 많았으므로, 이번 장에서는 다시 **공간의 변화와 실제 벡터의 움직임을 중심으로 영상화**한다.

### **3장과의 수학적 연결**

3장에서 사용했던 관계식으로부터,

\\[ \\|A\mathbf v_i\\|^2=\sigma_i^2 \\]

이므로,

\\[ \sigma_i=0 \quad\Longrightarrow\quad A\mathbf v_i=\mathbf0 \\]

가 된다.

## **Manim 구현 핵심**

### **1. 특잇값과 모든 시각적 객체를 하나의 변수로 제어**

이번 장에서는 두 번째 특잇값을 나타내는 `ValueTracker` 하나를 중심으로 여러 애니메이션을 연결할 수 있다.

```
import numpy as npfrom manim import *sigma2 = ValueTracker(1.0)def current_matrix():    return np.diag([        2.0,        sigma2.get_value()    ])def transformed_vector(v):    return current_matrix() @ np.asarray(v)def transformed_circle(theta):    v = np.array([        np.cos(theta),        np.sin(theta)    ])    w = transformed_vector(v)    return output_plane.c2p(w[0], w[1])
```

이 변수를 다음 객체에 연결한다.

| 객체        | 변경되는 요소     |
| --------- | ----------- |
| 출력 타원     | 세로 반축 길이    |
| 좌표 격자     | 세로 간격       |
| 출력 벡터     | 세로 성분       |
| 특잇값 막대그래프 | 두 번째 막대의 높이 |
| 행렬 수식     | 두 번째 대각 원소  |
| 랭크 표시     | 2 또는 1      |
| 영공간의 차원   | 0 또는 1      |

이렇게 구성하면 각 객체가 서로 독립적으로 움직이지 않고 동일한 수학적 변환의 결과로 움직인다.

### **2. 정확히 0이 되는 순간 처리**

작은 양수와 0을 구분하는 것이 이번 장에서 중요하므로, 단순히 특잇값이 작아졌다는 이유만으로 랭크를 감소시키면 안 된다.

```
def current_rank():    t = sigma2.get_value()    return 2 if t > 0.0 else 1
```

최종 애니메이션에서 `sigma2`를 정확히 0으로 설정하고, 그때 랭크 표시를 변경한다.

실제 수치 행렬의 랭크를 계산하는 상황에서는 부동소수점 오차로 인해 별도의 허용 오차가 필요하지만, 이번 영상의 예시는 직접 제어하는 대각행렬이므로 정확한 0을 기준으로 연출한다.

### **3. 단위 원과 단위 원판의 표현 구분**

특잇값이 양수일 때 단위 원의 변환 결과는 타원의 경계다.

특잇값이 0이 되면 그 경계에 있던 점들이 선분 위로 투영된다.

삼차원에서도 특잇값이 0이 되면서 구면이 평면 위의 타원 영역으로 변할 수 있다.

따라서 차원의 붕괴 장면에서는 단순히 타원이나 타원체의 외곽선만 변형하는 것보다, 내부 격자 및 표본점들을 함께 변환하는 것이 정확한 표현에 도움이 된다.

### **4. 저랭크 근사의 오차 검증**

```
A = np.diag([2.0, 0.1])A_approx = np.diag([2.0, 0.0])error_matrix = A - A_approxrank_original = np.linalg.matrix_rank(A)rank_approx = np.linalg.matrix_rank(A_approx)max_error = np.linalg.norm(error_matrix, ord=2)assert rank_original == 2assert rank_approx == 1assert np.isclose(max_error, 0.1)
```

이 코드는 근사 행렬의 랭크가 감소하면서도 최대 변환 오차가 작은 상태로 유지된다는 예시를 검증하기 위한 것이다.

실제 Manim 렌더링까지 수행한 것은 아니며, 위 코드는 콘티 구현을 위한 참고 코드다.

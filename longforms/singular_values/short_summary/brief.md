# 特잇값은 왜 중요할까? 제작 기준

사용자 확정 27문장, 150초, 9:16 1080×1920 30fps. 음원 미제공: 무음과 화면 자막. 기존 16:9 영상을 자르지 않고 동일한 행렬 계산과 공통 도형을 세로로 재배치한다.

항등행렬과 전단행렬의 고윳값은 (1,1). 전단행렬은 고유방향이 하나다. 이후 A=[[1,2],[0,1]], M=AᵀA=[[1,2],[2,5]], σ=1+√2, √2−1. 입력 최대·최소 방향 67.5°,157.5°. 출력 주축 22.5°,112.5°. M의 직교 고유벡터와 A의 고유벡터를 구별한다.

랭크 예시 A_t=diag(2,t)는 별도 행렬. t>0이면 rank2, 정확히 0이면 rank1. 넓이 예시 diag(2,.75), 넓이 배율1.5. 정사각행렬에서 |det|=특잇값 곱.

조건수 별도 예시 D=diag(1,.01), x=(1,0), dy=(0,.002), dx=(0,.2), 상대오차 .2%→20%, 증폭100. 정확·오차 벡터에 동일한 역변환. 확대창은 세로차이×200 명시. κ₂는 고정 가역 실수 정사각행렬, 우변만 오차인 상황의 상대오차 상한. 모든 실제 오차가 κ배라는 표현 금지.

첫 미리보기는 랭크·조건수 그룹만. 최종 렌더 후 전체 프레임/타임스탬프/자막 및 주요 시각 전환 검사. 최하단과 오른쪽에 핵심 수식 배치하지 않는다.

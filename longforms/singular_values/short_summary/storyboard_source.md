## **2. 공통 행렬과 기하학적 객체**

도입부, 특잇값의 발견, 수학적 정의, 마지막 엔딩에서는 동일한 전단행렬을 사용한다.

```
A = np.array([    [1.0, 2.0],    [0.0, 1.0]])M = A.T @ Aeigenvalues, V = np.linalg.eigh(M)order = np.argsort(eigenvalues)[::-1]eigenvalues = eigenvalues[order]V = V[:, order]sigma = np.sqrt(eigenvalues)# 출력 공간의 주축 방향U = (A @ V) / sigma
```

정확하게 표현해야 하는 수학적 값은 다음과 같다.

| 항목                | 값              |
| ----------------- | -------------- |
| 최대 특잇값            | \\(1+\sqrt2\\) |
| 최소 특잇값            | \\(\sqrt2-1\\) |
| 최대 길이에 대응하는 입력 방향 | 67.5°          |
| 최소 길이에 대응하는 입력 방향 | 157.5°         |

## **4. 차원 붕괴와 조건수 애니메이션 재사용**

랭크와 조건수는 사실상 동일한 수축 애니메이션으로 구현할 수 있다.

```
sigma_min = ValueTracker(1.0)def current_matrix():    return np.diag([        1.0,        sigma_min.get_value()    ])def current_rank():    return (        2 if sigma_min.get_value() > 0        else 1    )def current_condition():    s = sigma_min.get_value()    return (        1 / s if s > 0        else np.inf    )
```

랭크 장면에서는 최소 특잇값이 정확히 0이 되는 순간에 집중하고, 조건수 장면에서는 0에 가까워지는 과정에 집중한다.

똑같은 공간 수축 현상을 서로 다른 수학적 관점으로 관찰하는 것이므로 애니메이션 객체를 재사용하는 것이 오히려 개념적인 통일성을 높여준다.

위 코드에서 최대 특잇값은 1로 고정했으며, Scene 17\~18의 예시처럼 최대 특잇값을 2로 설정할 경우 조건수 계산도 그에 맞춰 변경해야 한다.

\\[ \begin{aligned} \text{크기}&\longrightarrow\text{길이 변화}\\\ \text{개수}&\longrightarrow\text{랭크}\\\ \text{곱}&\longrightarrow\text{행렬식}\\\ \text{비율}&\longrightarrow\text{조건수} \end{aligned} \\]

특잇값이라는 새로운 개념 하나를 소개하는 데서 끝나는 것이 아니라, **기존에 서로 다른 공식으로 배웠던 선형대수학의 개념들이 하나의 공간 변환을 관찰하는 과정에서 연결된다**는 느낌을 주는 것이 이번 영상의 핵심이야.

# **2장. 단위 원에서 발견하는 특잇값**

**전체 길이: 121초 (2분 1초)**

이번 장에서는 1장에서 방향별로 관찰했던 벡터의 길이 변화가 하나의 기하학적 구조로 나타나는 과정을 보여준다.

가장 중요한 연출은 **단위 원이 타원으로 변화하고, 타원의 두 반축에서 우리가 찾던 최대·최소 길이 변화 배율을 발견하는 장면**이다.

특히 입력 공간의 특별한 방향과 출력 공간의 타원 주축이 서로 다르다는 사실을 시각적으로 구분하여, 고윳값과 특잇값의 차이를 명확하게 전달한다.

\\[ A= \begin{pmatrix} 1&2\\\ 0&1 \end{pmatrix} \\]

이 행렬의 특잇값은 다음과 같다.

\\[ \sigma_1=1+\sqrt2\approx2.4142 \\]

\\[ \sigma_2=\sqrt2-1\approx0.4142 \\]

```
A = np.array([    [1, 2],    [0, 1]])def transformed_circle(t):    v = np.array([np.cos(t), np.sin(t)])    w = A @ v    return output_plane.c2p(w[0], w[1])
```

### **추가적인 시각적 연출**

타원을 중심으로 반지름이 변화하는 보조 원을 사용할 수 있다.

- 타원 전체를 포함하는 가장 작은 원은 장축의 양 끝점에서 타원과 접한다.
- 타원 내부에 들어가는 가장 큰 원은 단축의 양 끝점에서 타원과 접한다.

이 두 원은 최대 거리와 최소 거리의 의미를 직접적으로 보여준다.

**제작 시 주의사항:** 장축과 단축은 타원의 양쪽 끝점을 연결한 전체 축이다. 다음 장면에서 특잇값과 연결할 때는 전체 축의 길이가 아니라 중심에서 끝점까지의 거리인 **반축의 길이**를 사용해야 한다.

## **Scene 8. 최대 길이 변화 배율의 발견**

00:35–00:44 · 9초

**나레이션**

> 처음 원의 반지름은 모든 방향에서 1이었으므로, 변환된 타원의 가장 긴 반지름은 행렬이 만들어낼 수 있는 최대 길이 변화 배율을 나타냅니다.

**화면 구성 및 애니메이션**

35\~38초에는 입력 원과 출력 타원을 다시 나란히 배치한다.

출력 타원의 장축 끝점에 대응하는 입력 단위벡터를 찾아 보라색으로 강조한다.

이번 예시에서 해당 입력 방향은 67.5도이고, 출력 방향은 22.5도이다.

38\~41초에는 입력 벡터와 출력 벡터의 길이를 각각 측정하여 표시한다.

\\[ \\|\mathbf v_1\\|=1 \\]

\\[ \\|A\mathbf v_1\\|\approx2.414 \\]

41\~44초에는 길이의 비율을 화면 중앙에 나타낸다.

\\[ \frac{\\|A\mathbf v_1\\|}{\\|\mathbf v_1\\|} =\frac{2.414\ldots}{1} \\]

이후 해당 숫자를 일반적인 최대값 표현으로 연결한다.

\\[ \max\_{\\|\mathbf v\\|=1}\\|A\mathbf v\\| \\]

**연출 포인트**

입력 벡터와 출력 벡터가 서로 다른 방향을 향하고 있다는 사실을 반드시 유지한다.

최대 길이 변화가 일어나는 방향이 고유방향일 필요는 없다는 점을 이후의 고윳값 비교 장면에서 활용할 수 있다.

**나레이션**

여기서 입력 벡터의 방향 역시 이전 입력 방향과 서로 수직이라는 점을 짧게 보여준다.

## **Scene 13. 특잇값 — 입력 방향과 출력 방향의 분리**

01:00–01:05 · 5초

**나레이션**

> 하지만 특잇값에서는 변환된 벡터가 원래 어떤 방향을 향하고 있었는지는 중요하지 않습니다.

입력 공간에서는 67.5도의 단위벡터를 강조하고, 출력 공간에서는 그 벡터가 변환된 22.5도 방향의 벡터를 표시한다.

출력 공간에 원래 입력 방향을 회색 점선으로 남겨 두 방향이 서로 다르다는 사실을 명확히 보여준다.

여기서 특이벡터 관계를 보조 수식으로 등장시킬 수 있다.

\\[ A\mathbf v_1=\sigma_1\mathbf u_1 \\]

\\(\mathbf v_1\\)은 입력 공간의 단위벡터이고, \\(\mathbf u_1\\)은 출력 공간의 단위벡터이다.

```
def fibonacci_sphere(n):    points = []    golden_angle = np.pi * (3 - np.sqrt(5))    for i in range(n):        y = 1 - 2 * (i + 0.5) / n        r = np.sqrt(1 - y * y)        theta = golden_angle * i        points.append([            r * np.cos(theta),            y,            r * np.sin(theta)        ])    return np.array(points)
```

입력 공간의 두 특별한 단위벡터는 서로 수직이고, 변환된 두 출력 벡터도 서로 수직이다. 그러나 입력 공간의 주축과 출력 공간의 주축은 같은 방향이 아니다.

이 구분은 특히 중요하다. 타원의 장축 방향인 22.5도를 최대 길이 변화를 일으키는 **입력 방향**으로 잘못 사용하지 않도록 한다.

### **Manim 제작용 검증 코드**

```

```

실제 영상의 모든 벡터, 반축, 좌표 및 길이 표시는 이와 같이 행렬 곱셈을 기반으로 생성한다.

이번 콘티에서는 삼차원으로 확장할 때 이해하기 쉬운 새로운 대각행렬을 선택했으며, 차원이 붕괴하지 않는 정사각행렬을 중심으로 구성했다. 특잇값이 0이 되어 타원이 선분으로 붕괴하거나, 직사각행렬에 특잇값을 적용하는 경우는 이후 랭크와 정보 손실을 설명하는 장에서 다루는 것이 적합하다.

## **이번 장의 핵심 연출 세 가지**

**첫 번째 — 18\~23초: 단위 원이 타원으로 변화하는 장면**

1장에서 개별적으로 관찰했던 방향별 길이 변화가 하나의 도형으로 나타나는 순간이다.

**두 번째 — 35\~51초: 타원의 반축이 특잇값이라는 사실을 발견하는 장면**

단순한 기하학적 관찰에서 실제 수학적 측정값으로 연결되는 이번 장의 가장 중요한 부분이다.

**세 번째 — 110\~121초: 길이를 수식으로 표현하면서 다시 고윳값으로 돌아가는 장면**

기하학적인 직관에서 수학적인 정의로 넘어가는 전환점이다.

영상 전체의 흐름으로 보면,

\\[ \underbrace{\text{길이 변화 배율}}\_{\text{1장}} \longrightarrow \underbrace{\text{타원의 반축}}\_{\text{2장}} \longrightarrow \underbrace{\text{길이 제곱의 수학적 구조}}\_{\text{3장}} \\]

이렇게 연결된다.

3장에서는 새로운 행렬 \\(A^TA\\)를 처음부터 주어진 공식으로 소개하지 않고, **이번 장에서 발견한 타원의 반축 길이를 수학적으로 구하려는 과정에서 자연스럽게 등장시키는 것**이 중요하다.

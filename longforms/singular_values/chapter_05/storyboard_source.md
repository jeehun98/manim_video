## **Scene 5. 길이 변화 배율의 곱**

00:20–00:25 · 5초

**나레이션**

> 즉, 서로 수직인 두 방향의 길이 변화 배율을 곱하면 넓이의 변화 배율을 구할 수 있습니다.

\\[ \boxed{\text{Area Scaling}=\sigma_1\sigma_2} \\]

직사각형의 가로 길이 2와 세로 길이 3을 수식 위치로 이동시킨다.

두 숫자 사이에 곱셈 기호를 추가한다.

이후 구체적인 숫자를 일반적인 특잇값 기호로 변환한다.

\\[ 2\times3 \longrightarrow \sigma_2\sigma_1 =\sigma_1\sigma_2 \\]

위 예시의 특잇값을 내림차순으로 정렬하면 \\(\sigma_1=3,\ \sigma_2=2\\)이다.

**수학적 주의사항:** 임의의 두 직교하는 입력 방향이 변환 후에도 항상 직교한다는 뜻은 아니다. 여기에서는 변환 후에도 직교하는 특이벡터 방향을 기준으로 설명한다.

## **Scene 28. 행렬식은 동일하지만 특잇값은 다르다**

> 행렬식의 절댓값은 1이지만, 공간의 형태는 크게 달라진 것입니다.

\\[ A=\begin{pmatrix}1&0\\\0&1\end{pmatrix} \\]

\\[ \sigma_1=1,\quad\sigma_2=1 \\]

det(A) = 1

\\[ B=\begin{pmatrix}100&0\\\0&0.01\end{pmatrix} \\]

\\[ \sigma_1=100,\quad\sigma_2=0.01 \\]

det(B) = 1

같은 행렬식, 극단적으로 다른 방향별 길이 변화

두 행렬을 화면 좌우에 나란히 배치한다.

공간의 넓이 변화 배율은 두 경우 모두 1이라고 표시한다.

| 측정 대상       | 행렬 A | 행렬 B |
| ----------- | ---- | ---- |
| 최대 길이 변화 배율 | 1    | 100  |
| 최소 길이 변화 배율 | 1    | 0.01 |
| 넓이 변화 배율    | 1    | 1    |

**핵심 연출:** 행렬식이 동일하다는 사실과 실제 공간 변환의 형태가 다르다는 사실이 동시에 화면에 나타나야 한다.

이는 0장에서 보여줬던 동일한 고윳값과 서로 다른 공간 변환이라는 비교 구조를 다시 사용하는 것이다.

### **1. 단위 원판과 내부 격자의 동시 변환**

\\[ \mathbf p(r,\theta) = \begin{pmatrix} r\cos\theta\\\ r\sin\theta \end{pmatrix}, \qquad 0\leq r\leq1 \\]

```
import numpy as npfrom manim import *A = np.diag([2.0, 0.75])def disk_point(r, theta):    return np.array([        r * np.cos(theta),        r * np.sin(theta)    ])def transformed_point(r, theta):    return A @ disk_point(r, theta)
```

## **영상 전체에서 5장이 갖는 의미**

지금까지 다뤘던 특잇값에 대한 관찰을 다음과 같이 정리할 수 있다.

| 특잇값에 적용한 연산       | 얻을 수 있는 정보      |
| ----------------- | --------------- |
| 개별 값을 관찰          | 주축 방향별 길이 변화    |
| 양의 값의 개수를 계산      | 랭크와 출력 공간의 차원   |
| 0인 값에 대응하는 방향을 관찰 | 영공간과 정보의 소실     |
| 모든 값을 곱함          | 행렬식의 절댓값과 부피 변화 |
| 가장 큰 값과 작은 값의 비율  | 조건수와 계산의 안정성    |

이번 장에서 특히 살리고 싶은 것은 **행렬식이 공간 전체의 변화를 하나의 숫자로 요약하는 반면, 특잇값은 그 변화가 각각의 방향에서 어떻게 이루어졌는지를 보여준다는 차이**다.

이는 다음 장으로 자연스럽게 이어진다.

\\[ \underbrace{\sigma_1\sigma_2\cdots\sigma_n}\_{\text{5장: 공간 전체의 부피 변화}} \qquad\longrightarrow\qquad \underbrace{\frac{\sigma\_{\max}}{\sigma\_{\min}}}\_{\text{6장: 방향별 변화의 불균형}} \\]

5장에서는 서로 다른 방향의 길이 변화가 전체적으로 어떻게 결합되는지 살펴봤다면, 6장에서는 그 방향별 변화의 차이가 얼마나 큰지를 관찰한다.

결국 같은 특잇값에 어떤 수학적 연산을 적용하느냐에 따라 행렬에 관한 전혀 다른 성질을 알아낼 수 있다는 구조로 영상의 흐름을 이어가면 좋겠다.

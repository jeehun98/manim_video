# **6장. 작은 오차가 커지는 이유 — 특잇값과 조건수**

**전체 길이: 156초 (2분 36초)**

이번 장에서는 특잇값이 단순히 공간의 기하학적 변화를 설명하는 숫자를 넘어, 실제 수치 계산에서 발생하는 오차의 민감도를 분석하는 도구라는 사실을 보여준다.

특히 후반부에서는 균일한 수축과 불균일한 수축을 비교하여, 최소 특잇값의 역수만으로는 상대 오차의 민감도를 충분히 설명할 수 없는 이유를 전달한다.

## **Scene 2. 역행렬이 존재한다는 것**

00:05–00:10 · 5초

**나레이션**

> 행렬이 역행렬을 가진다면, 수학적으로는 원래의 벡터를 정확하게 복원할 수 있습니다.

\\[ \mathbf x\xrightarrow{A}A\mathbf x\xrightarrow{A^{-1}}\mathbf x \\]

\\[ A^{-1}(A\mathbf x)=(A^{-1}A)\mathbf x \\]

\\[ =I\mathbf x=\mathbf x \\]

오차가 없다면 원래의 벡터를 정확하게 복원할 수 있다.

왼쪽의 원래 벡터를 복제하여 오른쪽의 복원된 벡터 위에 겹친다.

두 벡터의 끝점과 방향이 정확하게 일치하는 것을 보여주고 초록색 체크 표시를 추가한다.

수식에서는 행렬과 역행렬의 곱이 항등행렬로 바뀌도록 연출한다.

이 장면에서는 이상적인 수학적 상황을 보여주며, 아직 오차는 등장시키지 않는다.

**화면 구성 및 애니메이션**

# **Part 4. 최소 특잇값과 오차 증폭의 관계**

## **Scene 15. 수축했던 방향은 역변환에서 팽창한다**

01:08–01:15 · 7초

**나레이션**

> 즉, 원래 행렬이 특정 방향의 길이를 강하게 줄일수록, 역행렬은 그 방향의 길이를 강하게 늘리게 됩니다.

구체적인 숫자 0.01과 100을 일반적인 특잇값 기호로 변환한다.

\\[ \sigma \longrightarrow \frac1{\sigma} \\]

특잇값이 감소할수록 역변환의 길이 배율이 증가하는 모습을 보여준다.

기존의 대각행렬 예시에서 한 단계 일반화하여 다음 관계를 화면에 표시할 수 있다.

\\[ A\mathbf v_i=\sigma_i\mathbf u_i \\]

\\[ A^{-1}\mathbf u_i =\frac1{\sigma_i}\mathbf v_i \\]

입력 공간의 특이벡터가 출력 공간의 특이벡터로 변환되고, 역변환에서는 반대 과정이 일어난다는 의미다.

작은 특잇값은 복원 문제의 민감도를 증가시킬 수 있지만, 정확히 0인 특잇값은 복원 자체를 불가능하게 만든다는 차이를 보여준다.

## **Manim 구현 핵심**

### **1. 데이터 벡터와 오차 벡터를 별도의 객체로 관리**

이번 장에서는 정확한 데이터와 오차가 포함된 데이터를 독립적인 객체로 생성하되, 반드시 동일한 행렬에 의해 변환되도록 구성한다.

```
import numpy as npfrom manim import *B = np.diag([1.0, 0.01])B_inv = np.linalg.inv(B)x = np.array([1.0, 1.0])y = B @ xdelta_y = np.array([0.0, 0.002])y_noisy = y + delta_yx_recovered = B_inv @ yx_noisy = B_inv @ y_noisydelta_x = x_noisy - x_recovered
```

다음 관계를 검증한다.

```
assert np.allclose(x_recovered, x)assert np.allclose(    delta_x,    B_inv @ delta_y)assert np.allclose(    delta_x,    [0.0, 0.2])
```

정확한 벡터와 오차가 포함된 벡터의 차이를 항상 오차 객체의 시작점과 끝점으로 사용한다.

\\[ \Delta\mathbf x =B^{-1}\Delta\mathbf y \\]

이렇게 구성하면 데이터의 복원과 오차의 증폭이 서로 독립적으로 움직이는 연출 오류를 방지할 수 있다.

### **2. 역변환 애니메이션의 연속적인 진행**

```
progress = ValueTracker(0.0)def current_inverse():    p = progress.get_value()    return np.diag([        1.0,        100.0 ** p    ])def current_exact():    return current_inverse() @ ydef current_noisy():    return current_inverse() @ y_noisydef current_error():    return (        current_noisy()        - current_exact()    )
```

### **3. 균일한 변환과 불균일한 변환의 상대 오차 비교**

조건수의 최대 증폭률이 실제로 나타나는 간단한 예시를 사용한다.

```
B = np.diag([1.0, 0.01])C = np.diag([0.01, 0.01])x = np.array([1.0, 0.0])delta_y = np.array([0.0, 0.002])def error_analysis(A, x, delta_y):    y = A @ x    delta_x = np.linalg.solve(        A, delta_y    )    relative_input_error = (        np.linalg.norm(delta_y)        / np.linalg.norm(y)    )    relative_output_error = (        np.linalg.norm(delta_x)        / np.linalg.norm(x)    )    amplification = (        relative_output_error        / relative_input_error    )    return (        relative_input_error,        relative_output_error,        amplification    )
```

예상 결과는 다음과 같다.

```
B: (0.002, 0.2, 100.0)
C: (0.2,   0.2,   1.0)
```

이 장면에서는 앞서 사용했던 입력 벡터 \\((1,1)\\) 대신 \\((1,0)\\)을 선택한다.

입력 벡터를 최대 특잇값에 대응하는 방향으로, 오차 벡터를 최소 특잇값에 대응하는 출력 방향으로 설정하면 조건수에 해당하는 최대 상대 오차 증폭률을 정확하게 보여줄 수 있기 때문이다.

영상에서는 새로운 비교 실험임을 명확히 표시한다.

## **영상 전체에서 6장이 갖는 의미**

1·2장

**개별 특잇값**

\\(\sigma_i\\)방향별 길이 변화 배율

3장

**특잇값의 수학적 정의**

\\(\sqrt{\lambda_i(A^TA)}\\)길이 변화에 대한 수학적 분석

4장

**양의 특잇값 개수**

\\(\\#\\{i:\sigma_i>0\\}\\)랭크와 정보의 소실

5장

**모든 특잇값의 곱**

\\(\prod_i\sigma_i\\)행렬식과 공간의 부피 변화

6장

**최대·최소 특잇값의 비율**

\\(\frac{\sigma\_{\max}}{\sigma\_{\min}}\\)조건수와 오차에 대한 민감도

6장까지 진행하면 특잇값이라는 수학적 개념이 왜 중요한지 충분히 전달할 수 있어.

특히 이번 영상에서는 SVD라는 행렬 분해 방법 자체를 중심으로 설명하지 않고, **특잇값이라는 숫자들의 크기, 개수, 곱, 비율을 관찰하는 것만으로 행렬의 다양한 성질을 발견할 수 있다**는 흐름을 유지했다는 점이 중요해.

마지막 7장에서는 새로운 수식이나 개념을 추가하지 않고, 지금까지 살펴본 내용들을 하나의 공간 변환에서 추출할 수 있는 여러 종류의 정보로 정리하면 좋겠다.

# 7장 제작 기준

확정 대본 12문장, 사용자 문장 종료 시각 5·12·19·25·33·39·46·51·60·72·82·90초. 90초, 1920×1080, 30fps. TTS 미제공으로 무음·화면 자막.

A=[[1,2],[0,1]]를 일관되게 사용한다. σ=(1+√2,√2−1), AᵀA 고윳값=3±2√2, rank=2, det=1, κ₂=3+2√2. A 자체의 고윳값 (1,1)과 AᵀA의 고윳값을 구별한다.

양의 특잇값 개수만 랭크에 포함하며 정확한 0에서만 차원이 감소한다. 랭크 시연은 별도 가변 예시임을 표시한다. 곱·행렬식은 정사각행렬, 조건수는 가역 정사각행렬과 2-노름 기준. 조건수는 상대 오차의 최악 상한이며 실제 증폭과 동일시하지 않는다.

25–60초 결과 카드를 누적하고 60–72초 하나의 변환에 연결한다. 72–82초 격자·단위 원·기저벡터를 같은 전단변환으로 함께 이동한다. 최종 화면은 확정 내레이션을 유지하며 정리한다. 별도 예고·엔드카드 없음.

# 감마함수 3장 — 팩토리얼에서 왜 원주율이 등장할까?

절반의 팩토리얼을 가우스 적분으로 바꾼 뒤 적분값의 제곱을 곡면 아래의 부피로 해석한다. 원형 고리의 둘레에서 π가 등장하는 과정을 보여 준다. 제공된 44문장, 독립 장면 11개, 212초, 1920×1080, 30fps. 음원 미제공으로 무음이며 화면 자막을 포함한다.

```powershell
python longforms/gamma_chapter_03/build.py --preview --scene 05
python longforms/gamma_chapter_03/build.py
```

최종 영상은 `exports/gamma_chapter_03_long.mp4`에 저장한다. 가우스 곡면과 위에서 본 등고선은 같은 표본의 직교 투영을 사용한다. 2장의 마지막 장면에서 절반의 팩토리얼 배치를 이어받는다.

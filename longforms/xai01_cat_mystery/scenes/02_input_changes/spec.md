# 2막 — 입력을 바꿔보면 차이가 보인다

- 목적: 입력 변형으로 판단의 안정성을 관찰하고, 이 관찰과 내부 원인 규명을 구분한다.
- 핵심 주장: 입력 변형은 어떤 조건에서 판정이 흔들리는지 알려주지만, 특정 내부 요소의 역할을 그 결과만으로 분리하기 어렵다.
- 앞 장면: 같은 정답이 같은 판단 기준을 뜻하지 않는다는 1막의 질문.
- TTS 원문: script.txt. 사용자 측정 총길이: 146초. 문장별 시간: 대본 문자 수와 문장부호를 기준으로 추정, 음원 정렬 미확인.
- 화면: 1920×1080, 30fps, 1막 사진 스타일 고양이 재사용. 배경 변형은 같은 고양이를 유지한다. 색 변화는 화면 필터, 질감은 기존 무늬 변형 이미지로 시각화한다.
- 애니메이션: 배경·색·질감·가림·노이즈·패턴 → 변형별 판단 비교 → 안정성 → 배경과 판정의 관계 가설 → 학습 사진에서 함께 나타난 패턴 → 경계·대비·주변 관계 → 여러 층의 표현 변화 → 원인 미확정 → 내부 개입으로 질문 전환.
- 시간대: timing.json의 24개 구간을 scene.py와 captions.srt가 공유한다. 총 146초이며 처음부터 사진과 대본이 시작한다.
- 화면 텍스트: 입력 x → x′, 같은 판단을 얼마나 안정적으로 유지하는가, 배경에 의존했다?, 경계·명암 대비·주변과의 관계, 언제 흔들리는가, 무엇이 판단을 지탱했는가?, 입력 고정.
- 시작: 1막 고양이와 입력 변화 질문을 이어받는다.
- 종료: 입력을 고정한 상태에서 내부 노드를 강조하고 3막으로 넘긴다.
- 정확성: 막대와 모델 출력은 대본의 가정된 상황을 시각화하며 실제 실험 수치는 사용하지 않는다. 내부 격자는 activation의 개념적 표현이다. 배경 변경이 언제나 모든 내부 값을 바꾼다고 주장하지 않는다. 특정 배경과 라벨의 동시 등장이 실제 모델에서 확인된 결과라고 주장하지 않는다.
- 생성물: 무음 MP4와 별도 SRT. CSV는 생성하지 않는다.

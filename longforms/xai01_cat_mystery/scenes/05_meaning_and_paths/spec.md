# 5막 — feature의 의미와 계산 경로, 처음 질문으로 회귀

- 목적: 기능적 영향과 의미 해석을 구분하고, 여러 입력의 비교와 내부 경로 추적으로 설명을 확장한다.
- 핵심 주장: 판정에 영향을 주는 방향을 찾았다는 사실만으로 그 방향의 의미를 확정할 수 없으며, 표현의 조건과 정보·기능·연결을 함께 조사해야 한다.
- 앞 장면: 개입한 방향을 고양이 feature라고 불러도 되는지 묻는 4막.
- TTS 원문: script.txt. 사용자 측정 총길이: 226초. 문장별 시간: 대본 문자 수와 문장부호에 따른 추정, 실제 음원 정렬 미확인. 메시지 앞의 ‘연우’는 화자 표기로 간주하며 낭독 대본에서 제외했다.
- 화면: 1920×1080, 30fps. 고양이·강아지·여우 사진 스타일 입력, 다른 고양이와 자세 변형, 의미 후보와 복합 패턴, 층별 계산 경로, 처음 CAT 장면과 제목 회귀.
- 시간대: timing.json의 24개 구간에 77개 문장을 배분한다. captions.srt와 경계를 공유하며 총 226초.
- 애니메이션: 점수 하락과 의미 질문 → 기능·의미 구분 → 특징 후보 → 다른 동물의 공통 특징 → 이름·내부 패턴 구분 → 복합 방향 → 두 질문 → 반복 개입 → 다양한 입력·모습·배경·자세·효과 비교 → 조건·정보·역할 좁히기 → 여러 feature의 결합 → 층별 생성·결합·전달 경로 → XAI의 확인 범위 → CAT 회귀 → 네 질문 → 내부 구조에 대한 개입 → 제목과 암전.
- 시작: 4막의 개입 방향과 고양이 점수 하락을 이어받는다.
- 종료: 첫 제목을 회수하고 어둡게 끝난다. 이 막이 최종 막이며 별도 6·7막을 제작하지 않는다.
- 정확성: 입력 이미지와 막대·패턴·계산 경로는 설명용 가정이다. 실제 모델 분석 결과나 기능적 중요도의 보편 순위가 아니다. 공통 특징의 존재만으로 모델이 그 특징을 썼다고 확정하지 않는다. 복합 방향에 붙인 단어 역시 의미 후보다. 개입의 영향은 조사한 입력·개입 방식과 조건 범위 안에서 해석한다. XAI의 여러 접근 중 내부 표현과 경로 검증을 중심으로 다룬다.
- 생성물: 무음 MP4와 별도 SRT. CSV는 생성하지 않는다.

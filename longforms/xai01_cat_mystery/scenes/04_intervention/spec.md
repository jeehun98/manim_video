# 4막 — 개입하고, 반응의 모양을 본다

- 목적: activation의 크기와 개입 민감도를 비교하고, 국소 변화율과 곡률을 시각화한다.
- 핵심 주장: 관찰한 값의 크기만으로 영향력을 알 수 없으며, 개입 효과는 방향·현재 상태·다른 방향의 상태에 따라 달라질 수 있다.
- 앞 장면: 큰 activation A와 작은 B 중 어느 쪽 개입이 고양이 판단을 더 흔들지 묻는 3막.
- TTS 원문: script.txt. 사용자 측정 총길이: 193초. 문장별 시각: 대본 문자 수와 문장부호를 기준으로 추정, 음원 정렬 미확인.
- 화면: 1920×1080, 30fps. 사진 스타일 고양이, A/B activation 막대, 출력 점수 막대, 2D 반응 곡선, 3D 설명용 곡면.
- 타임라인: timing.json의 26개 구간에 64개 문장을 배분한다. captions.srt와 경계를 공유한다.
- 애니메이션: 사진·가중치 고정 → A만 낮추고 점수 관찰 → 원래 상태 복구 → B만 낮추고 점수 관찰 → 크기·영향 비교 → h에서 h′로 방향 이동 → 개입 크기별 반응 → 빠른·완만한·구간별 변화 → gradient의 접선 → 이동에 따른 경사 변화 → 두 방향의 곡면 → Hessian의 국소 곡률 → 다른 방향의 상태에 따른 단면 비교 → 반복 검증 → 의미 문제.
- 시작: 3막의 A/B 비교 화면을 이어받는다.
- 종료: 개입한 방향에서 고양이 점수가 떨어졌다는 기능적 관찰과, 고양이 feature라는 의미 이름 사이의 질문을 남긴다.
- 화면 텍스트: 가중치 고정, h′ = h + αv, ∇h s, Hh s, 같은 방향·다른 출발 상태·다른 경사, 개입 크기·여러 입력·다른 방향과 함께.

## 수학과 정확성

- 전체 실험은 대본의 가정이며, 실제 모델의 activation·출력 측정 결과가 아니다. 막대에 확률 수치를 넣지 않는다.
- A/B 실험은 동일한 입력·가중치에서 원래 상태로 복구한 후 각 activation을 같은 절대량만큼 낮추는 예시다. 좌표 스케일과 개입 정의가 바뀌면 민감도 비교도 달라질 수 있으므로 보편적 순위를 주장하지 않는다.
- h는 고정된 층의 내부 표현, v는 선택한 방향, s는 고양이 스칼라 점수다. h′ = h + αv의 v는 점수를 낮추는 방향을 포함할 수 있다.
- 1D 곡선은 실제 모델 적합 결과가 아닌 설명용 함수다. gradient와 연결되는 특정 방향의 변화율은 ∇s(h)·v이다. ∇s는 국소적인 최대 증가 방향이며 최대 감소는 반대 방향이다.
- 곡면은 두 선택 방향 a,b의 설명용 단면 g(a,b) = s(h + av + bw)이다. 전체 모델이나 전체 내부 공간을 그린 지도가 아니다.
- 설명용 곡면 함수: g(a,b) = 3 + 0.4a + 0.2b − 0.45a² − 0.15b² + 0.4ab. a방향 기울기는 0.4 − 0.9a + 0.4b이므로 b에 따라 달라진다. 두 평행 단면의 기울기 차이를 실제 기하로 보여준다.
- Hessian은 내부 표현에 대한 선택한 점수 함수의 국소 2차 미분이다. 파라미터에 대한 loss Hessian과 구분한다. 혼합 항은 선택한 좌표에서의 국소 결합 반응이며 feature 의미나 계산 회로를 독자적으로 입증하지 않는다.
- 미분 가능한 근방을 전제로 한다. ReLU망의 logit은 같은 선형 영역에서 Hessian이 0일 수 있으며 확률 변환의 곡률이 곧 내부 회로의 비선형성은 아니다.
- 큰 개입은 평소 만나지 않는 내부 상태를 만들 수 있다. 결과의 범위를 입력·개입 크기·방향별로 확인한다.
- 생성물: 무음 MP4와 별도 SRT. CSV는 생성하지 않는다.

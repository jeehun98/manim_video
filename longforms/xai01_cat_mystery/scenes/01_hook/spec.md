# 1막 — 같은 정답, 아직 알 수 없는 판단 기준

- 상태: 음성 없는 화면 프로토타입. 사용자 요청에 따라 TTS 길이 확정은 뒤로 미룬다.
- 목적: 고양이라고 맞혔다는 사실과 판단에 사용한 정보를 구분한다.
- 핵심 주장: 같은 정답만으로 같은 판단 기준을 사용했다고 알 수 없다.
- 앞 장면: 없음.
- TTS 원문: script.txt. 확정 길이: 미정.
- 화면: 가로형 16:9, 어두운 배경, 사람은 금색, AI는 청록색, 고양이는 AI 생성 사진 스타일 이미지.
- 화면 흐름: 제목 → 같은 이미지와 CAT 두 개 → 배경 교체 → 무늬·가림·작은 패턴의 세 카드 → 동일한 출력 아래 미지의 기준 → 두 질문으로 종료.
- 화면 텍스트: 점수 하락?, 같은 정답, 판단의 기준은?, 그 판단을 지탱한 정보는 무엇일까?
- 타임라인: scene.py의 next_section별 임시 배분. TTS 확정 후 변경.
- 시작: 새 제목. 종료: 내부 판단 정보를 확인하는 방법을 묻고 어둡게 전환.
- 다음 연결: 2막의 입력 변형 실험.
- 정확성: 실제 모델 실험 결과를 주장하지 않는다. 변화에 대한 반응은 모델·데이터·변형 방식에 의존한다. 고정 확률 수치는 사용하지 않는다.
- 후속 개선: 사람이 알아보기 어려운 입력에 대한 별도 예시 화면, TTS 동기화.

- 수정본 렌더: 1920×1080, 30fps. 원본 고양이의 자세·얼굴을 유지한 무늬 변형 이미지 사용.

- 이미지 아래 생성·설명 문구는 사용자 요청으로 제거했다.
- captions.srt: script.txt 전체를 현재 화면에 배분한 임시 자막. 전체 0–111초에 대본을 배분하며 제목은 첫 문장에 겹친다. 음성에 맞춘 낭독 타이밍이 아니므로 이후 재배분한다.
- CSV는 사용자 요청으로 제거했다. timing.json의 문장 길이 기반 시간 배분을 화면과 SRT가 공유한다.

- 음성 총길이: 사용자 측정 111초. 문장별 시간은 대본 길이로 추정하며 실제 음원 정렬은 미확인.

## 화면 정보 보강 v2

대본과 SRT는 유지하고 24개 구간마다 화면 변화를 배정한다. 단순한 시간 늘이기 대신 다음 관찰 단계를 추가한다.

- 0–23.8초: 같은 사진에서 사람과 AI의 응답을 순차 표시하고, 결과와 알 수 없는 판단 기준을 분리한다. 첫 문장부터 사진을 보여준다.
- 23.8–39.067초: 배경 A/B를 동시에 비교하고 고양이를 고정한다. 숫자가 없는 점수 막대의 변화와 동일한 고양이 강조를 보여준다.
- 39.067–50.4초: 털 무늬, 얼굴 가림, 작은 패턴을 해당 발화 구간에 맞춰 차례로 적용한다.
- 50.4–60.467초: 사람은 CAT 유지·AI는 흔들림, 그 반대의 경우를 별도 화면 상태로 보여준다. 추상 패턴에서 AI가 CAT로 강하게 반응할 수 있는 경우는 설명용 가정이며 실제 실험이 아니다.
- 60.467–69.667초: 모델 A/B/C의 서로 다른 반응과 모델 구조·학습 데이터·변형 방식의 세 조건을 단계적으로 보여준다.
- 69.667–87.3초: 경쟁 구도를 걷어내고 형태·털 무늬·배경 후보와 CAT 사이의 미확정 경로를 보여준다.
- 87.3–99.8초: 정답과 사용한 정보를 순서대로 강조하고 기대한 특징과 실제 사용한 특징의 차이를 묻는다.
- 99.8–111초: 출력 뒤의 내부 계산으로 관심을 옮기고, 노드 하나를 강조하며 다음 실험 질문으로 연결한다.

기존 화면 소스는 scene_v1.py에 보존한다. 시간은 문장별 음원 정렬 전의 추정값이다. 점수 막대와 AI 반응은 가정된 경우를 시각화하며 측정 수치를 넣지 않는다.

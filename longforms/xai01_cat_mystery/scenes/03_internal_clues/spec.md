# 3막 — 내부에서 단서를 찾는다

- 목적: activation의 관찰과 판정에 대한 기능적 영향력을 구분하고 개입 실험을 준비한다.
- 핵심 주장: 특정 입력에서 activation이 크다는 사실만으로 최종 판단에 대한 중요성을 알 수 없다.
- 앞 장면: 입력을 고정하고 내부 일부를 바꾸면 어떨지 묻는 2막의 끝.
- TTS 원문: script.txt. 사용자 측정 총길이: 154초. 문장별 시간: 대본 길이와 문장부호에 따른 추정, 실제 음원 정렬 미확인.
- 화면: 1920×1080, 30fps. 원본 고양이 사진 스타일 이미지에 다른 고양이·강아지 입력 이미지를 추가한다.
- 애니메이션: 입력 고정 → 여러 층의 숫자 → 내부 표현 h → 여러 사진별 반응 → 반복되는 activation 패턴 → 크기와 영향의 구분 → A/B activation → 미확정 영향 경로 → 여러 뉴런에 걸친 feature → 의미 후보 → 개입으로 역할 확인 → A/B 개입 비교 질문.
- 시간대: timing.json의 22개 구간에 47개 대본 문장을 배분한다. captions.srt와 같은 경계를 사용하며 총 154초.
- 화면 텍스트: 내부 표현 h, activation A/B, 영향?, 여러 뉴런에 걸친 방향·패턴, 고양이 전체?, 털·귀?, 얼굴 배치?, 함께 등장한 특징?, 바꾸면 판정이 달라지는가?, 약화?.
- 시작: 원본 고양이로 돌아와 입력을 고정한다.
- 종료: 큰 A와 작은 B, 미확정 출력 경로와 약화 버튼을 함께 보여주며 다음 막의 개입을 준비한다. 결과는 미리 공개하지 않는다.
- 정확성: 숫자·막대·패턴·이미지는 설명용 가정이며 실제 모델 관측이 아니다. 서로 다른 activation의 스케일만으로 중요성을 비교하지 않는다. 방향·패턴으로서의 feature는 여러 좌표에 분산될 수 있으며 양·음의 성분을 포함할 수 있다. feature가 언제나 분산돼 있거나 단일 뉴런에 개념이 전혀 없다고 단정하지 않는다. 의미 후보는 확정된 해석이 아니다.
- 생성물: 무음 MP4와 별도 SRT. CSV는 생성하지 않는다.

# 04 — relation

## 핵심 주장
π의 핵심은 C=πd=2πr라는 관계다.

## 확정 시간
28–38초, 10초. 사용자 제공 문장 종료 시각.

## TTS
파이는 약 삼 점 일사일오구로 시작하는 무한한 소수이지만, 중요한 것은 숫자의 자릿수가 아닙니다.

어떤 크기의 원이든, 둘레의 길이가 지름의 파이 배라는 사실입니다.

## 화면과 전환
../../storyboard.md의 동일 시간 구간을 구현한다. 실제 구현은 ../../visuals.py의 relation 메서드. 배경 #10151F, 자막 y≈−3.35, 시각 요소는 y>−2.7. 시작은 앞 씬 종료와 같은 원·각도·좌표 상태이며 기존 도형을 변형한다.

## 정확성
유클리드 평면의 원. 두 원의 반지름은 정확히 1:2. θ와 호·점·좌표는 하나의 ValueTracker로 계산한다. 1라디안은 θ=1이며 60도로 대체하지 않는다. 단위원의 x·y 축척은 동일하고 음수 성분을 0 기준으로 표시한다. π는 항등원이 아니다. 마지막은 i²=−1의 정의를 제시하며 회전과의 관계는 증명하지 않는다.

# 03 — ratio

## 핵심 주장
원의 크기에 관계없이 C/d=π다.

## 확정 시간
17–28초, 11초. 사용자 제공 문장 종료 시각.

## TTS
그런데 두 원의 둘레를 각각의 지름으로 나누면 어떻게 될까요?

놀랍게도 원의 크기와 관계없이 언제나 같은 비율이 나타납니다.

이 비율이 바로 원주율, 파이입니다.

## 화면과 전환
../../storyboard.md의 동일 시간 구간을 구현한다. 실제 구현은 ../../visuals.py의 ratio 메서드. 배경 #10151F, 자막 y≈−3.35, 시각 요소는 y>−2.7. 시작은 앞 씬 종료와 같은 원·각도·좌표 상태이며 기존 도형을 변형한다.

## 정확성
유클리드 평면의 원. 두 원의 반지름은 정확히 1:2. θ와 호·점·좌표는 하나의 ValueTracker로 계산한다. 1라디안은 θ=1이며 60도로 대체하지 않는다. 단위원의 x·y 축척은 동일하고 음수 성분을 0 기준으로 표시한다. π는 항등원이 아니다. 마지막은 i²=−1의 정의를 제시하며 회전과의 관계는 증명하지 않는다.

# 4장 제작 기준

사용자 확정 대본 46문장과 종료 시각을 유지한 202초, 1920×1080·30fps 롱폼 장이다. 기존 장과 같은 프레임률로 연결하며 음원 미제공으로 무음이다. 별도 쇼츠·합본은 제작하지 않는다.

3장 마지막 e → 반복 곱셈 → 분수 지수 → 양의 제곱근 → 실수 지수와 연속성 → 2^x,e^x,3^x 비교 → 미분 계수 1 → 함수값과 변화율 일치 → 10% 비례 성장 → 고정 구간에서 반복 횟수 증가 → e^x의 극한 → 계단 근사 → 현재 값에 비례하는 변화 → 수직 방향 iz → 세 번의 유한 변화와 e^(iθ)의 질문.

배경·폰트·자막·수식·복소평면은 기존 장 도구를 재사용한다. e^x #66CFC1, 2^x #7DA8F9, 3^x·접선 #F3BA61, i·수직 변화 #B69CF8. 주요 시각 영역과 하단 자막을 분리한다.

첨부 콘티의 2^(1/2) 위치는 2^0과 2^1 사이로 바로잡는다. 실수 지수는 양의 밑에서 지수법칙과 연속성을 유지하는 확장이다. 일반 미분식은 a>0 조건이다. 접선은 그래프의 데이터 좌표에서 dy/dx=e^x를 계산한다.

극한에서는 x를 고정한다. 숫자 예시는 x=1, 0≤t≤1, t_k=k/n, y_k=(1+1/n)^k다. 유한 n의 다른 결과를 표시하고 극한값과 구별한다. x<0은 충분히 큰 n에서 1+x/n>0인 경우로 해석한다. 10%를 세 번 곱하는 예시는 그 자체로 e의 극한이라고 표시하지 않는다.

마지막은 z_new=z+h·iz, h=0.18의 세 번의 유한 단계다. 길이가 조금 늘어나는 실제 끝점을 그대로 사용하며 원으로 정규화하지 않는다. z′=iz나 오일러 공식의 답을 먼저 제시하지 않는다. 5장 소스와 음원은 아직 없다.

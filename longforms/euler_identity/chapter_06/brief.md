# 6장 제작 기준

- 확정 대본: 사용자 제공 36문장, 종료 시각 7초부터 143초까지. 문장 순서·발화시간 유지.
- 학습 목표: θ=π의 기하학적·대수적 의미를 이해하고 오일러 항등식이 일반적인 오일러 공식의 특수한 결과임을 확인한다.
- 11개 독립 씬, 콘티 구간 0–14–27–42–52–60–76–89–104–116–134–143초를 사용한다.
- 가로·세로 눈금의 실제 단위를 일치시킨 원에서 양의 회전을 반시계 방향으로 보여준다. π에서 끝점은 (−1,0).
- cosπ=−1, sinπ=0을 대입하고 양변에 같은 1을 더한다. 0과 1이 회전을 생성하는 인자인 것처럼 연결하지 않는다.
- 성장 곡선을 원으로 변형하지 않는다. 복소수 확장과 허수 지수를 화면에 명시한다.
- 0장 identity()를 재사용해 마지막 수식의 색·크기·위치를 일치시킨다. 5장 마지막 장면의 formula_end()를 재사용한다.
- 사용자 요청 콘티의 복습 문장은 유지한다. 따로 예고·인사·엔드카드를 추가하지 않는다.
- native 1920×1080 60fps. 음원이 없으므로 무음. 자막은 전체 문장, TTS 원고는 발음 표기, 시간은 timing.json에만 기록.
- 대표 씬 저해상도 확인 후 최종 렌더, 핵심 프레임과 자동 길이·프레임·자막 범위 검수.

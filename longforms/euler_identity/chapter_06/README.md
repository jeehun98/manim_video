# 오일러 항등식 — 6장 · 다섯 숫자가 하나로 연결되는 순간

사용자 확정 36문장 종료 시각 기준 143초. 11개 독립 씬, 1920×1080, 60fps, 16:9 롱폼 전용. 음원 미제공으로 무음·전체 문장 자막.

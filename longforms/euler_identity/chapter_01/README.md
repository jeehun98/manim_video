# 오일러 항등식 — 1장 · 0과 1, 수학의 기준점

- 사용자 확정 대본 21문장, 종료 시각 기준 83초.
- 16:9 1920×1080, 30fps. TTS 음원 미제공으로 무음·전체 자막.
- 12개 독립 씬. 0장 색상·수식·자막·타이밍·렌더 도구 재사용.
- 0장 끝과 동일한 0·1·작은 항등식 배치로 시작한다.
- 영벡터/행렬의 시각적 전환은 콘티의 58초. 해당 문장 자막은 사용자 경계 54–61초를 그대로 유지하며 발화 중간 시각을 추정하지 않는다.
- 행렬은 2×2 A와 I₂, 도형의 불변은 I₂x=x로 구분한다.
- 마지막 원과 π는 2장 연결 기준이며 2장 영상·음원은 아직 없다.

실행: `py -3.12 longforms/euler_identity/chapter_01/build.py`

대표 씬: `py -3.12 longforms/euler_identity/chapter_01/build.py --preview --scene 9`

결과: `exports/euler_identity_ch01_83s_longform_final.mp4`

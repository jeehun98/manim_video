# 1장 제작 기준

확정 대본·21문장 종료 시각을 변경하지 않고 83초의 독립 롱폼 장을 제작한다. 쇼츠나 전체 합본은 추가 제작하지 않는다. 음원 미제공으로 무음이다.

0·1은 0장과 동일한 회백색·흰색, 덧셈 강조선은 #8AA9FF, 곱셈 강조선과 원은 #F3BA61. 자막과 수학 기호는 실제 숫자·영문을 사용하고 발음 원고만 한글 표기한다.

순서: 0장 끝 화면 → +0의 정지 → 자기 자신을 빼서 원점 복귀 → 덧셈 항등원 → ×0의 수축과 ×1의 유지 → 곱셈 항등원 → 대상 확장 → 영벡터 → 단위행렬 → 연산 속의 역할 → 원 → C/d=π.

수직선은 0–10과 0–200의 범위를 라벨까지 함께 바꾸고, 5와 100을 같은 축에 잘못 놓지 않는다. 영벡터는 화살표로 길이를 만들지 않는다. 단위행렬 시각화에서는 모든 꼭짓점을 고정하며 AI₂=A와 벡터 변환 I₂x=x를 구분한다. π는 항등원이 아니라 원의 일정한 비율이다.

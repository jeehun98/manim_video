# 3장 제작 기준

사용자가 제공한 40문장과 종료 시각을 유지한 171초, 1920×1080·30fps 롱폼 장이다. 0~2장과 같은 프레임률로 연결하며 TTS 음원 미제공으로 무음이다. 쇼츠나 합본은 추가 제작하지 않는다.

2장 끝의 단위원·i²=−1 → 실수선 → 제곱함수와 실수해의 부재 → i의 정의 → a+bi → (a,b) → 숫자 1 → 네 번의 ×i → 일반 복소수의 전개 → 정확한 90° 회전 → 두 번의 회전과 부호 반전 → 연속적인 각도의 질문 → e와 희미한 지수곡선.

실수축 #DCE3EE, 허수축과 i #B69CF8, 현재 벡터 #7DA8F9, 결과 벡터 #F3BA61, 궤적 #66CFC1. 2장의 UnitCircleVisual과 기존 자막·폰트·렌더 도구를 재사용한다. 양 축의 축척을 동일하게 유지하고, 일반 복소수 예시의 좌표 (2,3)는 정확히 (−3,2)로 보낸다.

복소수 a+bi에서 a와 b는 실수이며 허수부는 b다. 모든 a,b에 대한 대수 전개를 먼저 제시하고, 양의 두 성분을 가진 예시로 기하학적 움직임을 보여준다. 수치 검사는 다른 사분면과 0도 포함한다. 정수 거듭제곱 iⁿ이 90° 단위로 반복된다고 화면에 한정하며, 작은 회전이 복소수 곱셈으로 불가능하다는 문구는 넣지 않는다.

# 05 — repeat_steps

## 핵심 주장
새 위치에서도 동일한 수직 변화가 반복된다.

## 확정 시간
58–71초, 13초. 사용자 문장 종료 시각 기준.

## TTS
이번에는 방금 얻은 새로운 복소수에 같은 수를 다시 곱해 보겠습니다.

그러면 새로운 위치에서도 현재 벡터에 수직인 방향으로 작은 변화가 추가됩니다.

이 과정을 반복하면 벡터는 조금씩 방향을 바꾸며 움직이기 시작합니다.

## 화면·전환
../../storyboard.md의 구간과 ../../visuals.py의 repeat_steps 메서드가 구현 기준이다. 원·수식·좌표 상태를 이어받는다. 시각 요소는 y>−2.7, 자막은 y≈−3.35. 시작은 4장 끝 화면, 마지막은 오일러 공식과 단위원이다. 6장 소스·음원은 아직 없다.

## 정확성
복소 지수함수는 전 평면에서 수렴하는 멱급수로 확장할 수 있고 그 확장은 극한식과 일치하며 항별 미분을 보존한다. 단순한 실수식의 기호 대입만을 증명으로 삼지 않는다. θ 고정, 실제 점 z_k=(1+iθ/n)^k를 선분으로 연결하고 단위원으로 정규화하지 않는다. n=10의 실제 길이는 약 1.600987이다. 유한 단계의 길이 증가와 각도 부족을 각각 확인한다. z′=iz에서 d|z|²/dθ=2Re(conj(z)iz)=0, z(0)=1, |z′|=|z|=1이다. 반시계 방향과 라디안 정의로 회전각을 확인한다. 삼각함수 좌표는 수학적 논증 후반에 공개하며 내부 애니메이션 좌표 계산을 그 증명으로 사용하지 않는다.

# 5장 제작 기준

사용자 확정 대본 49문장과 종료 시각을 유지한 224초, 1920×1080·60fps 롱폼 장이다. 첨부 콘티의 60fps를 적용하며 미리보기만 저해상도 30fps로 제작한다. 음원 미제공으로 무음이다. 별도 쇼츠나 합본은 만들지 않는다.

4장 마지막 화면 → 실제 복소수 반복 곱셈 → 수직 변화량과 벡터 덧셈 → 유한 단계의 길이 증가 → θ=π 고정, n=4·10·100·1000 비교 → 극한의 단위원 → 정확한 각도의 질문 → 복소 지수함수 미분 → z′=iz → 반지름·속력 1 → 라디안 → 좌표와 복소수 → 오일러 공식.

현재 벡터 #7DA8F9, 변화량 #B69CF8, 결과 #F3BA61, 경로·e #66CFC1, 기준 원 #738197. 기존 자막·폰트·지수 그래프·색상·렌더 도구를 재사용하고 복소수 반복과 매개변수화한 원운동 객체만 추가한다.

유한 반복 경로는 실제 값 (1+iθ/n)^k를 선분으로 연결한다. θ=π인 비교에서 축척을 유지한다. n=10의 길이는 콘티의 1.606 대신 실제 1.600986994…를 표시한다. 유한 단계에서 반지름을 1로 정규화하거나 끝점을 −1로 옮기지 않는다. 정확한 단위원은 n→∞로 명시한 뒤 별도로 표시한다.

실수식에 기호를 대입한 것만으로 복소 지수함수의 정의나 미분을 증명했다고 하지 않는다. 복소 지수함수의 전 평면 수렴 멱급수 확장이 극한식과 일치하고 미분을 보존한다는 사실을 사용한다. 화면에는 복소 지수함수로의 확장과 연쇄법칙을 표시한다.

길이 수렴과 각도 수렴은 구별한다. z′=iz에서 d|z|²/dθ=2Re(conj(z)iz)=0, 초기값 z(0)=1, |z′|=1이므로 단위원을 반시계 방향 단위 속력으로 움직인다. 라디안 정의에 의해 회전각은 θ다. 화면 좌표에 삼각함수를 사용하는 것은 애니메이션 계산이며 논증의 근거로 삼지 않는다. 6장 소스·음원은 아직 없다.

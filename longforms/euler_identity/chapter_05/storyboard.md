### **Scene 01. 두 성질을 하나로 결합 (00:00–00:15)**

> 앞서 우리는 지수함수를 아주 작은 변화의 반복으로 이해할 수 있다는 사실을 살펴봤습니다. 그리고 허수 아이를 곱하면, 복소평면에서 숫자의 방향이 90도 회전한다는 것도 알게 되었습니다. 그렇다면 이 두 성질을 하나로 결합하면 어떻게 될까요?

\\[ e^x \\]

연속적인 변화

\\[ \times i \\]

90° 회전

- 수식이 분리되며 왼쪽에 \\(e^x\\), 오른쪽에 \\(i\\)가 나타남.

**00:05–00:11**

- 왼쪽에서는 작은 증가가 여러 번 반복되는 연출.

### **Scene 02. 지수의 극한에 허수를 넣는다 (00:15–00:32)**

> 먼저 자연상수 이를 밑으로 하는 지수함수의 극한식을 다시 살펴보겠습니다. 이의 엑스제곱은, 1 더하기 엑스 나누기 엔을 엔 번 곱하고, 엔을 무한히 크게 만든 결과입니다. 여기서 엑스 대신 아이 세타를 넣어보겠습니다. 그러면 1 더하기 아이 세타 나누기 엔을 엔 번 곱하는 식이 됩니다.

\\[ e^x=\lim\_{n\to\infty}\left(1+\frac{x}{n}\right)^n \\]

\\[ e^{i\theta}=\lim\_{n\to\infty}\left(1+\frac{i\theta}{n}\right)^n \\]

**00:15–00:19**

- 화면 중앙에 4장에서 배운 극한식 등장.
- \\(e^x\\)와 \\((1+x/n)^n\\)을 서로 다른 밝기로 강조.
- 전체 수식은 최대한 크게 배치.

**00:19–00:25**

- 분모의 \\(n\\)과 지수의 \\(n\\)을 같은 색상으로 연결.
- `한 단계의 변화`, `반복 횟수` 라벨을 잠깐 표시.
- \\(n\to\infty\\)를 강조.

**00:25–00:28**

- 식의 \\(x\\)가 보라색 \\(i\theta\\)로 변형.
- 왼쪽 지수와 오른쪽 분자에 동일한 변형 적용.

**00:28–00:32**

- 최종 복소 지수 극한식 완성.
- 나머지 수식의 투명도를 낮추고 \\((1+i\theta/n)\\)만 강조.
- 수식이 화면 위쪽으로 이동하며 복소평면을 위한 공간 확보.

**Manim 구현:** `TransformMatchingTex`로 원래 식의 구조를 유지합니다. \\(\theta\\)는 이후 실제 회전각을 나타내므로 주황색, \\(i\\)는 보라색을 적용합니다.

### **Scene 03. 복소평면 위의 숫자 1 (00:32–00:42)**

\\[ z_0=1 \\]

**00:32–00:36**

- 앞 장면의 수식이 상단에 고정.
- 좌표축과 원점 생성.
- 실수축 `(1,0)` 위치에 작은 점 등장.

**00:36–00:38**

- 원점에서 1까지 파란색 벡터 생성.
- 위쪽에 `z₀=1` 표시.

**00:38–00:42**

- 화면 오른쪽에 곱셈 인자 \\(1+i\theta/n\\) 표시.
- 허수 성분 \\(i\theta/n\\)만 보라색으로 강조.
- 다음 장면에서 사용할 수직 변화 화살표가 점의 위쪽에 희미하게 등장.

### **Scene 04. 첫 번째 작은 변화 (00:42–00:58)**

> 실수 성분은 1이고, 허수 성분은 세타 나누기 엔인 복소수입니다. 이 수를 곱하면 원래 숫자에, 현재 숫자를 90도 회전시키고 크기를 세타 나누기 엔만큼 줄인 변화가 더해집니다. 따라서 처음에는 오른쪽을 가리키던 벡터가 조금 위쪽으로 기울어집니다.

이 장면에서는 실제 복소수 곱셈을 **벡터의 덧셈**으로 해석합니다.

\\[ z_1=z_0\left(1+\frac{i\theta}{n}\right) \\]

\\[ z_1=z_0+\frac{i\theta}{n}z_0 \\]

**00:42–00:46**

- \\(1+i\theta/n\\)의 실수·허수 부분을 구분.
- 일반적인 복소수 곱셈을 전개하는 식 등장.
- 파란 벡터는 제자리에 유지.

**00:46–00:53**

- 보라색 화살표가 파란 벡터의 끝점에서 위쪽으로 생성.
- 보라색 화살표는 현재 벡터와 정확히 수직.
- 직각 표시 등장.
- 보라색 화살표 길이는 \\(\theta/n\\)에 비례하도록 설정.

**00:53–00:58**

- 원점에서 새 끝점까지 주황색 벡터 생성.
- 파란색 원래 벡터와 보라색 변화 벡터가 직각삼각형을 구성.
- 주황색 벡터가 새로운 위치 \\(z_1\\)이 됨.
- 새 벡터가 파란색으로 변형되면서 다음 단계 준비.

**중요:** 회전 자체를 바로 보여주지 않고, 먼저 **현재 벡터 + 수직 변화 벡터 = 새로운 벡터**라는 구조를 확실하게 보여줍니다.

### **Scene 05. 새로운 위치에서도 같은 연산 반복 (00:58–01:11)**

> 이번에는 방금 얻은 새로운 복소수에 같은 수를 다시 곱해 보겠습니다. 그러면 새로운 위치에서도 현재 벡터에 수직인 방향으로 작은 변화가 추가됩니다. 이 과정을 반복하면 벡터는 조금씩 방향을 바꾸며 움직이기 시작합니다.

\\[ z\_{k+1}=z_k+\frac{i\theta}{n}z_k \\]

**00:58–01:02**

- \\(z_1\\)을 현재 벡터로 설정.
- 직전의 보라색 화살표는 제거.
- 새 벡터 \\(z_1\\)에 수직인 방향으로 보라색 화살표 생성.

**01:02–01:07**

- 새로운 변화가 추가되어 \\(z_2\\) 생성.
- 이어 \\(z_2\rightarrow z_3\\)를 빠르게 표시.
- 각 단계에서 수직 변화의 방향도 같이 바뀜.

**01:07–01:11**

- 반복된 끝점들을 청록색 선으로 연결.
- 경로가 조금씩 휘어지는 모습 강조.
- 화면 오른쪽에는 일반화한 반복식 유지.

이 장면부터 개별 수직 벡터는 짧게 표시하고, 전체 경로를 중심으로 연출합니다.

### **Scene 06. 왜 원이 아니라 바깥으로 퍼질까? (01:11–01:25)**

> 그런데 여기서 한 가지 이상한 점이 있습니다. 각 단계에서 수직인 성분을 더하면 벡터의 길이도 아주 조금 증가합니다. 따라서 반복 횟수가 유한할 때는 정확히 원을 그리지 않고, 바깥쪽으로 조금씩 퍼지는 경로가 만들어집니다.

\\[ \left|1+\frac{i\theta}{n}\right|=\sqrt{1+\frac{\theta^2}{n^2}}>1 \\]

**01:11–01:14**

- 지금까지의 경로가 잠시 정지.
- 회전 전과 회전 후의 벡터를 나란히 강조.
- 길이가 조금 증가한 부분을 확대.

**01:14–01:19**

- 직각삼각형의 빗변을 강조.
- 각 변에 `1`, `θ/n` 라벨 표시.
- 피타고라스 정리로 새 길이가 1보다 크다는 사실을 표현.

**01:19–01:25**

- 실제 반복 경로를 다시 보여줌.
- 반지름 1인 기준 원을 점선으로 추가.
- 유한한 반복 경로가 원 바깥쪽으로 퍼지는 모습이 드러남.
- 차이를 주황색 얇은 간격선으로 표시.

이때 핵심은 **각 단계가 현재 벡터에 정확히 수직인 변화를 더하는 연산**이라는 점입니다. 유한한 단계에서는 원을 따라 움직이는 것이 아니라, 접선 방향으로 한 걸음씩 이동하기 때문에 반지름이 증가합니다.

### **Scene 07. 반복 횟수를 늘리면 어떻게 될까? (01:25–01:38)**

> 그렇다면 반복 횟수를 늘리면 어떻게 될까요? 예를 들어 전체 회전의 기준을 파이로 고정하고, 먼저 이 변화를 네 번 반복해 보겠습니다. 벡터는 여러 번 방향을 바꾸지만, 원보다 바깥쪽으로 크게 벗어납니다.

이 장면부터는 \\(\theta=\pi\\)로 고정합니다. 비교 대상은 모두 동일한 식이며 \\(n\\)만 달라집니다.

\\[ z_n=\left(1+\frac{i\pi}{n}\right)^n \\]

**01:25–01:28**

- 이전 장면의 수식을 상단으로 이동.
- \\(\theta\\)가 \\(\pi\\)로 바뀌는 애니메이션.
- `θ = π`, `n = 4`를 화면 오른쪽에 표시.
- 중심을 원점으로 하는 단위원 등장.

**01:28–01:33**

- 시작점 \\(z_0=1\\)에서 출발.
- 첫 번째 보라색 수직 변화 벡터 생성.
- 변화가 적용되면서 첫 번째 선분 완성.
- 이후 세 번의 변화를 차례대로 적용.
- 단계마다 새로운 벡터와 변화량의 방향을 보여줌.

**01:33–01:38**

- 네 번의 변화로 형성된 경로 전체 표시.
- 기준 단위원과 반복 경로를 비교.
- 최종점이 원의 바깥쪽에 있음을 강조.
- 최종점에 작은 주황색 원 생성.

연출 개념도 — 실제 경로는 복소수 반복 계산으로 생성

참고로 실제 \\(n=4\\)의 최종 벡터 길이는 약 2.614입니다. 따라서 제작에서는 기준 원과 최종점을 한 화면에 담을 수 있도록 좌표계의 범위를 충분히 넓혀야 합니다.

### **Scene 08. n=10, 100, 1000으로 증가 (01:38–01:52)**

> 이번에는 변화를 열 번으로 나눠보겠습니다. 한 번에 더해지는 변화는 작아지고, 경로는 원에 조금 더 가까워집니다. 반복 횟수를 백 번, 천 번으로 늘리면 어떻게 될까요? 각 단계에서 증가하는 길이는 점점 작아지고, 전체 경로는 원에 가까워집니다.

여기서는 **동일한 좌표계에서 반복 횟수만 변경하는 애니메이션**이 가장 중요합니다.

n = 4

n = 10

n = 100

n = 1000

전환 레이아웃 예시. 최종 애니메이션의 꼭짓점은 실제 계산값을 사용합니다.

**01:38–01:42**

- 이전 `n=4` 경로가 희미해짐.
- `n=10` 경로를 새로 그림.
- 단계당 변화가 줄어들었다는 것을 보여주기 위해 선분을 더 촘촘하게 표시.
- 마지막 끝점을 강조.

**01:42–01:46**

- `n=100`으로 변경.
- 수많은 작은 선분이 나타남.
- 선분 개별 생성 대신 `VMobject` 경로를 점진적으로 드러냄.
- 경로가 단위원과 가까워짐.

**01:46–01:52**

- `n=1000`으로 변경.
- 복잡한 꼭짓점 표시는 생략.
- 하나의 부드러운 선처럼 보이는 경로 생성.
- 단위원과 거의 겹치는 모습 강조.

실제 최종 거리 차이도 짧게 표시하면 좋습니다.

| 반복 횟수            | 최종 벡터의 길이 |
| ---------------- | --------- |
| 4                | 약 2.614   |
| 10               | 약 1.606   |
| 100              | 약 1.050   |
| 1,000            | 약 1.005   |
| \\(n\to\infty\\) | 1         |

다만 시청자가 표의 수치를 읽는 데 시간을 쓰지 않도록 **실제 영상에서는&#x20;**`n`**과 최종 벡터의 길이만 표시**하는 편을 추천합니다.

### **Scene 09. 극한에서는 회전만 남는다 (01:52–02:02)**

> 결국 반복 횟수를 무한히 늘리는 극한에서는 길이의 증가가 사라지고, 방향의 변화만 남습니다. 이것이 허수를 지수에 넣었을 때 회전이 나타나는 이유입니다.

\\[ \lim\_{n\to\infty}\left|1+\frac{i\theta}{n}\right|^n=1 \\]

**01:52–01:58**

- `n` 값이 1000에서 더 큰 값으로 빠르게 증가.
- 기준 원과 실제 경로의 차이가 줄어드는 모습.
- 원 바깥으로 퍼져 있던 경로가 기준 원과 겹침.

**01:58–02:02**

- 기준 원과 극한 경로가 하나의 원으로 합쳐짐.
- 원점에서 점까지 길이 1인 화살표만 남김.
- 화면 상단에 `|z| = 1` 표시.

여기서 유한 단계의 계산에서는 실제 경로가 기준 원과 일치하지 않는다는 점을 유지해야 합니다. **정확한 원은 극한에서 얻어지는 결과**입니다.

### **Scene 10. 정확히 θ만큼 회전하는가? (02:02–02:10)**

> 하지만 여기서 한 가지를 더 확인해야 합니다. 이 움직임이 단순히 원을 따라가는 것뿐 아니라, 정확히 세타만큼 회전한다는 사실입니다.

- 원과 현재 벡터를 그대로 유지.
- 원호의 일부를 주황색으로 강조.
- 중앙에 `θ = ?` 표시.
- 최종 위치의 각도를 표시하는 호 생성.
- 원을 따라가는 움직임을 잠시 멈춤.

앞선 극한으로 벡터의 길이가 1에 가까워진다는 사실은 보여주었습니다. 하지만 정확히 어느 각도만큼 움직이는지는 별도로 확인해야 합니다.

**선택적 보조 수식**

\\[ \text{한 단계의 각도}= \arctan\left(\frac{\theta}{n}\right) \\]

\\[ n\arctan\left(\frac{\theta}{n}\right) \longrightarrow \theta \\]

이 계산을 짧은 보조 수식으로 넣을 수 있지만, 내레이션에는 없으므로 화면 한쪽에 2초 정도만 보여주는 것이 좋습니다. 본격적인 설명은 다음 미분방정식으로 진행합니다.

### **Scene 11. 지수함수의 변화율을 다시 가져온다 (02:10–02:24)**

> 이를 위해 지수함수의 변화율을 다시 생각해 보겠습니다. 이의 엑스제곱을 미분하면 자기 자신이 됩니다. 그리고 복소수까지 확장한 지수함수에서, 이의 아이 세타 제곱을 세타에 대해 미분하면 아이가 곱해진 자기 자신이 됩니다.

\\[ \frac{d}{dx}e^x=e^x \\]

\\[ \frac{d}{d\theta}e^{i\theta}=ie^{i\theta} \\]

**02:10–02:13**

- 원과 복소평면이 화면 왼쪽으로 축소.
- 오른쪽에는 4장에서 사용한 \\(e^x\\) 그래프를 간단하게 재등장시킴.
- 접선과 현재 값을 보여주며 미분의 의미를 환기.

**02:13–02:17**

- 화면 오른쪽에 \\(d(e^x)/dx=e^x\\) 표시.
- 함수값과 변화율이 같다는 부분을 강조.
- 그래프는 사라지고 수식만 유지.

**02:17–02:24**

- 수식이 \\(e^{i\theta}\\)로 변형.
- 미분 변수도 \\(x\\)에서 \\(\theta\\)로 변경.
- 연쇄법칙에 의해 \\(i\\)가 앞에 등장.
- 최종 식을 확대해 표시.

**중요:** 이 장면은 복소 지수함수까지 확장한 뒤에도 미분 규칙이 성립한다는 사실을 사용합니다. 이전의 실수 지수함수 미분 공식에 단순히 기호만 대입한 것처럼 연출하지 않도록, 화면에는 `복소 지수함수로 확장`이라는 짧은 표시를 추가해도 좋습니다.

### **Scene 12. 현재 위치와 속도의 관계 (02:24–02:40)**

이 장면은 극한으로 설명했던 회전을 **미분방정식이라는 새로운 관점에서 확인하는 부분**입니다.

\\[ \boxed{z'(\theta)=iz(\theta)} \\]

**02:24–02:31**

- \\(z'=iz\\) 완성.
- 복소평면을 전체 화면 중앙으로 확대.
- 원점에서 현재 위치까지 파란색 벡터 생성.

**02:31–02:36**

- 현재 벡터에 \\(i\\)를 곱하는 애니메이션.
- 파란색 벡터를 90도 회전시킨 보라색 벡터 생성.
- 보라색 벡터를 현재 점의 끝으로 평행이동.
- 현재 위치에서의 순간적인 이동 방향을 보여줌.

**02:36–02:40**

- 이동하는 동안 보라색 벡터는 매 순간 원에 접함.
- 반지름 벡터와 접선 벡터 사이의 직각 표시를 유지.
- 시청자가 두 방향이 항상 수직이라는 사실을 관찰하도록 구성.

### **Scene 13. 원점과의 거리가 유지된다 (02:40–02:53)**

**02:45–02:49**

## **4. Manim 핵심 구현 설계**

이번 장은 특히 수학적 정확성이 중요하기 때문에, 애니메이션 좌표를 임의로 지정하지 않고 **실제 복소수 곱셈의 계산 결과에서 모든 위치를 생성**하는 방식이 적합합니다.

### **A. 유한 반복 계산**

```
import numpy as npdef complex_exp_steps(theta, n):    multiplier = 1 + 1j * theta / n    z = 1 + 0j    points = [z]    for _ in range(n):        z *= multiplier        points.append(z)    return points
```

복소수 \\(z\\)의 실수부와 허수부를 복소평면의 좌표로 사용합니다.

```
def complex_to_point(axes, z):    return axes.c2p(z.real, z.imag)
```

이렇게 계산한 위치들을 순서대로 연결하면 유한 반복 경로가 만들어집니다.

### **B. 반복 횟수별 경로**

```
theta = np.pifor n in [4, 10, 100, 1000]:    points = complex_exp_steps(theta, n)    coordinates = [        complex_to_point(axes, z)        for z in points    ]    path = VMobject()    path.set_points_as_corners(coordinates)    path.set_stroke(        color=TEAL,        width=3    )
```

여기서 중요한 것은 `set_points_as_corners`입니다. 유한 단계의 실제 반복은 곡선이 아니라 각 단계의 결과를 연결한 **다각형 경로**이기 때문에, 부드러운 곡선으로 보간하지 않는 편이 더 정확합니다.

\\(n\\)이 충분히 커지면 자연스럽게 원처럼 보이게 됩니다.

### **C. 극한과 비교하는 정확한 원**


### **E. 미분방정식의 접선 방향**

후반부에서는 실제 위치를

\\[ z(\theta)=\cos\theta+i\sin\theta \\]

로 계산하고, 해당 위치의 변화율을

\\[ z'(\theta)=iz(\theta) \\]

로 계산합니다.

이렇게 하면 회전하는 점, 반지름 벡터, 접선 벡터가 정확하게 동기화됩니다.

### **한 가지 보완하면 좋은 부분**

현재 대본의 118초 부근에서는 길이의 증가가 사라지고 회전만 남는다고 설명합니다. 이는 올바른 직관이지만, **길이가 1로 수렴한다는 사실만으로 회전각이&#x20;**\\(\theta\\)**라고 결론낼 수는 없습니다.**

따라서 5장 영상에서는 두 사실을 구분해서 보여주는 것이 좋습니다.

\\[ \underbrace{\left(1+\frac{\theta^2}{n^2}\right)^{n/2}\to1}\_{\text{길이}} \\]

\\[ \underbrace{n\arctan\left(\frac{\theta}{n}\right)\to\theta}\_{\text{회전각}} \\]

그다음 미분방정식 \\(z'=iz\\)으로 넘어가면, 시청자가 앞서 관찰한 원운동을 더욱 명확하게 이해할 수 있습니다.

## **6. 다음 6장으로 이어지는 마지막 프레임**

\\[ e^{i\theta}=\cos\theta+i\sin\theta \\]

여기서 영상을 마무리하고, 6장에서는 다음 질문으로 시작하면 됩니다.

**“그렇다면 이 회전을 정확히 반 바퀴만큼 진행하면 어떻게 될까요?”**

이후 \\(\theta=\pi\\)를 대입하면서 원 위의 점이 \\((1,0)\\)에서 \\((-1,0)\\)으로 이동하고,

\\[ e^{i\pi}=-1 \\]

을 거쳐 마침내

\\[ \boxed{e^{i\pi}+1=0} \\]

에 도달하게 됩니다.

**5장의 핵심은 오일러 공식을 외우는 것이 아니라, 앞서 따로 배웠던 지수함수와 허수, 회전과 삼각함수가 실제로 동일한 움직임을 설명한다는 사실을 발견하는 것입니다.**

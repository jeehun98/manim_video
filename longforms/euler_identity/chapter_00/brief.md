# 0장 제작 기준

사용자가 제공한 58초 내레이션과 상세 콘티를 구현한다. 영상은 독립 롱폼의 도입이며 별도 쇼츠는 제작하지 않는다.

수학의 기호들 → 다섯 상수 → 각 상수의 성질 → 분리된 수학 영역 → 상수들이 항등식으로 이동 → 연결 원리에 대한 질문 → 0과 1.

배경 #10151F, 0 #B8C2D1, 1 흰색, π #F3BA61, i #B69CF8, e #66CFC1. 수식 MathTex, 한글 Malgun Gothic. 시각 요소 y>−2.7, 자막 y≈−3.35.

π=C/d, i²=−1, i의 곱셈을 두 번의 반시계 90° 회전으로 표현. 지수곡선은 실제 exp(x). e^(iπ)+1=0의 의미와 증명은 본문에 남겨 둔다. 마지막 문장의 허수는 앞서 소개한 i를 가리키며 모든 허수의 제곱이 −1이라는 설명을 추가하지 않는다.

음원 미제공. 발음 원고와 SRT를 별도 보관하며 임의 합성 음성이나 추정 타이밍을 사용하지 않는다.

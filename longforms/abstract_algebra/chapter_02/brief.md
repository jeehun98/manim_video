# 제작 기준

목표: 정사각형 회전에서 군의 네 조건을 발견하고, 정수 덧셈에서 같은 조건을 확인한다. 사용자 확정 원문·34개 종료 시각·155초를 유지한다. 상세 화면은 storyboard.md. 전체 대칭 8개와 회전만의 4개 군을 구분한다. 대칭 비교 시 점 미표시. 같은 공리와 동형을 구분한다. 대칭의 정의는 화면의 ‘이 대상을 보존하는 변환’ 문구로 특정 변환에 한정한다. 방정식 예시는 Q(√2)의 유리수를 고정하는 켤레 자기동형. 임의 변환 집합이 아닌 고정된 구조의 모든 가역적 구조 보존 변환에 관한 주장. 이전·다음 장 언급은 사용자 확정 원문 범위만 유지.

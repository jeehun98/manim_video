# 07 modulo

## 목적과 핵심 주장
회전 합성과 mod 4 덧셈의 결과가 대응한다.

## 확정 시간
47–53초, 6초. 사용자 제공 문장 종료 시각. 음원 미제공으로 무음.

## TTS
그러면 회전을 합성하는 과정은, 숫자들을 더한 뒤 4로 나눈 나머지를 구하는 과정과 같아집니다.

## 화면·애니메이션·시작과 종료
첨부 콘티 storyboard.md SCENE 07를 구현한다. visuals.py의 modulo 메서드가 초 단위 실행 명세이며 공유 상태 생성 함수로 이전 종료 상태를 그대로 재현한다. 상단 제목 y=3.35, 본문 y=-2.5~2.8, 자막 y=-3.35. 16:9, 1920×1080, 60fps. 암전 전환 없이 객체를 변환한다.

## 정확성
숫자의 보통 덧셈이 아닌 mod 4 덧셈과 회전만 대응한다. 꼭짓점 점은 방향 추적용 표식이며 대칭 조건을 바꾸지 않는다. 회전은 반시계방향·중심 고정. 0은 0° 회전. (S, ★) 자체가 특정 공리를 뜻하지 않는다.

## 화면 텍스트와 연결
storyboard.md의 해당 SCENE 화면 구성을 따른다. 다음 씬은 같은 객체 상태에서 시작하며 내레이션을 추가하지 않는다. 마지막은 군 카드 강조 상태로 종료한다.

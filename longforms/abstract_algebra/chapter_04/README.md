# 추상대수학 — 4장 체(Field)

사용자 확정 29문장·128초·10개 독립 씬. 16:9 1920×1080·60fps, 음원 미제공으로 무음·전체 자막.

최종 렌더: `py -3.12 longforms/abstract_algebra/chapter_04/build.py`
대표 씬: `py -3.12 longforms/abstract_algebra/chapter_04/build.py --preview --scene 7`

결과: `exports/abstract_algebra_ch04_128s_longform_final.mp4`

1장 테마·자막·시간 검증과 3장 집합 영역 도형을 재사용하고 두 소스 모두 해시에 포함한다. 3장 실제 종료 화면을 복원해 시작한다. 합본과 5장 영상은 만들지 않는다.

응용 사실 확인: [NIST AES 표준](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.197-upd1.pdf), [CMU Reed–Solomon 개요](https://www.cs.cmu.edu/~realworld/reedsolomon/reed_solomon_codes.html). 응용 화면은 알고리즘을 특정하지 않는 개념도다.

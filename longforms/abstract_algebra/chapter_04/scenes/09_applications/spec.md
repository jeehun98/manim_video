## **유한체**

\\(\mathbb F_5\\)

다섯 개의 원소

\\(2\cdot3\equiv1\pmod5\\)

서로 다른 원소와 연산, 공통된 체의 공리

**세부 애니메이션**

- 103\~108초: 유리수체와 유한체의 곱셈 역원 예시를 나란히 비교한다.
- 108\~114초: 두 집합의 구체적인 숫자들을 흐리게 처리하고, 공통된 구조를 중앙으로 모은다.
- 114\~120초: 응용 분야를 상징하는 간단한 그래픽으로 확장한다.

응용 분야는 아래처럼 표현하면 좋아.

| 분야     | Manim 화면                    |
| ------ | --------------------------- |
| 방정식    | \\(x^2-2=0\\)과 두 근          |
| 오류정정부호 | 데이터 비트 → 부호화 → 손상 → 복원      |

오류정정부호는 데이터가 일부 손상되어도 복원할 수 있도록 여분의 정보를 추가하는 구조로 간단하게 보여주면 돼.

이때 특정 알고리즘의 세부 원리를 설명하지 말고, `유한체 연산이 실제 계산에 사용됨` 정도의 연결만 보여주는 것이 적절해.



## 정확성
곱셈군은 0 제외, 0≠1 명시. mod 5 이전의 정수 6과 16은 F5 내부 결과로 넣지 않는다. F5의 1↔1, 2↔3, 4↔4 전부 표시하며 0의 곱셈 역원 없음. 덧셈·곱셈 나머지 연산의 나머지 체 조건도 성립함을 명시. 유리수체와 유한체를 동형으로 합치지 않는다. 응용 그래픽은 개념도이며 F5만으로 실제 암호 알고리즘을 구현한 것으로 표시하지 않는다.

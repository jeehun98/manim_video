# 제작 기록

- 템플릿을 복사해 시작, 대본·16개 씬별 spec·33개 발화 시각을 화면보다 먼저 확정.
- 두 시스템 독립 적분 출력 오차 약 3.11×10⁻¹⁵. 차이 방향 자율 감쇠와 동일 전달함수 검증 통과.
- 합과 차이 축의 단위 길이는 같으며 두 방향이 직교.
- 출력 비교는 같은 실제 좌표계의 계산된 두 곡선으로 표현.
- 일반 영 초기 동등성과 예시의 대응 초기값 일치를 별도 패널로 명시.
- 내부 서술 자막 없이 렌더 후 ASS 한 트랙으로 합성.

## 완료 검증

- 세로 1080×1920, 가로 1920×1080, 각각 154.000초·30fps·4,620프레임.
- 두 최종본 전체 FFmpeg 디코딩 통과.
- 각 영상 33개 문장 경계 전후 99프레임, 총198프레임의 자막 검증 통과. 최저 문자 마스크 일치도 세로0.98018, 가로0.97776.
- 주요 시점20개씩과 출력 비교 장면을 육안 검토. 입력 파형·두 출력 수치·파란 실선과 노란 점선 중첩 확인.
- 점선 세그먼트를 미리 구성하고 표시 범위를 조절해 Manim 자식 교체 캐시 문제를 방지.
- 세로360×640와 가로854×480 미리보기는 검증된 최종본에서 축소 생성. 각각154초·15fps·2,310프레임.
- TTS 음원 미제공으로 두 최종본은 자막 포함 무음 영상.

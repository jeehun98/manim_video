어떤 시스템에 내부 상태가 두 개 있다면, 그 시스템을 설명하는 데도 반드시 두 개의 상태가 필요할까요?

예를 들어 외부에서 입력을 받으면 움직이고, 그 결과를 출력하는 시스템을 생각해 보겠습니다.

시스템 내부에는 두 개의 상태, 엑스 원과 엑스 투가 있습니다.

두 상태는 입력을 받으면 같은 방식으로 변화하고, 출력은 두 상태를 더한 값으로 결정됩니다.

그런데 여기서 이상한 점이 발견됩니다.

우리가 외부에서 관찰하는 것은 두 상태 각각의 값이 아니라, 두 상태의 합이라는 것입니다.

그렇다면 두 상태를 따로 추적할 필요가 있을까요?

새로운 상태 제트를 정의해 보겠습니다.

제트는 엑스 원과 엑스 투를 더한 값입니다.

이제 원래 두 상태의 변화 방정식을 더해 보겠습니다.

그러면 제트의 변화는 제트 자신과 입력만으로 표현됩니다.

출력 역시 제트 하나로 결정됩니다.

원래는 두 개의 상태를 가진 시스템이었지만, 이제 하나의 상태만으로 동일한 출력 변화를 재현할 수 있습니다.

실제로 두 시스템에 같은 입력을 주면, 같은 초기 출력에서 출발하는 한 시간에 따른 출력도 정확히 일치합니다.

여기서 중요한 것은 단순히 상태 하나를 삭제한 것이 아니라는 점입니다.

두 상태를 결합해 새로운 상태를 만들었고, 그 상태만으로 외부 동작을 설명할 수 있게 된 것입니다.

이것이 제어이론에서 다루는 최소 실현, 미니멀 리얼라이제이션의 핵심 아이디어입니다.

시스템의 외부 입출력 관계를 유지하면서, 이를 표현하는 데 필요한 상태 차원을 최소화하는 것입니다.

그렇다면 어떤 상태가 정말 필요한지는 어떻게 판단할까요?

여기에는 두 가지 중요한 개념이 등장합니다.

첫 번째는 제어 가능성, 컨트롤러빌리티입니다.

외부 입력을 이용해 시스템의 상태를 원하는 방향으로 움직일 수 있는지를 나타냅니다.

두 번째는 관측 가능성, 옵저버빌리티입니다.

시스템의 출력을 관찰해서 서로 다른 내부 상태를 구별할 수 있는지를 나타냅니다.

앞의 예시에서는 두 상태의 차이를 생각해 볼 수 있습니다.

엑스 원에서 엑스 투를 뺀 값은 외부 입력으로 변화시킬 수 없고, 출력에도 나타나지 않습니다.

반면 두 상태의 합은 입력에 반응하고 출력에도 직접 나타납니다.

따라서 외부 입출력 동작을 재현하려면 합에 해당하는 상태 하나만 남기면 됩니다.

선형 시불변 시스템에서는 제어 가능성과 관측 가능성을 모두 만족하는 실현이 최소 실현입니다.

다만 여기서 보존하는 것은 일반적으로 초기 상태를 영으로 둔 입력과 출력의 관계입니다.

모든 내부 상태를 복원하거나, 임의의 초기 상태까지 같은 방식으로 표현한다는 뜻은 아닙니다.

결국 시스템 내부에 존재하는 모든 변수가 외부 동작을 설명하는 데 필요한 것은 아닙니다.

중요한 것은 상태를 몇 개 가지고 있느냐가 아니라, 동일한 입출력 관계를 유지하기 위해 최소 몇 개의 독립적인 상태가 필요한가입니다.

# 13 · 합은 입력과 출력을 연결한다

## 목적과 주장

z 방향은 입력에 반응하며 출력에 직접 나타난다

## 앞 장면에서 받은 내용

d=x₁−x₂는 입력항 없이 감쇠하고 출력에 나타나지 않는다

## 확정 TTS

- 사용자 제공 구간 114–124초, 길이 10초.
- 음원 미제공: 위 시각을 실제 발화 기준으로 사용, 무음 영상과 TTS 원고 제공.

반면 두 상태의 합은 입력에 반응하고 출력에도 직접 나타납니다.
따라서 외부 입출력 동작을 재현하려면 합에 해당하는 상태 하나만 남기면 됩니다.

## 화면과 시간

- 114–118초: 반면 두 상태의 합은 입력에 반응하고 출력에도 직접 나타납니다.
- 118–124초: 따라서 외부 입출력 동작을 재현하려면 합에 해당하는 상태 하나만 남기면 됩니다.

세로와 가로를 각각 배치. 입력 u 청록, x₁·x₂ 파랑, z·y 노랑, d 빨강. 축과 수식, 실제 모델 계산을 일치시킨다.

## 시작과 종료

첫 문장의 핵심 대상을 받아 마지막 문장의 주장으로 완료. 주요 상태 변환은 두 블록→z, 곡선 비교는 같은 축에서 중첩.

## 다음 장면의 시각적 연결

동일한 시스템과 색상 유지. 영상 내 복습·다음 편 예고 없음.

## 정확성

ẋ₁=−x₁+u, ẋ₂=−x₂+u, y=x₁+x₂; ż=−z+2u; ḋ=−d. 차이는 정지 상태가 아니라 자율 감쇠한다. 합과 차이 축은 (1,1), (1,−1)로 직교. 일반 최소 실현은 영 초기 입출력 기준, 이번 예시의 더 강한 초기 출력 일치와 구분한다.

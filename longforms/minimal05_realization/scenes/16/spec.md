# 16 · 필요한 독립 상태는 몇 개인가?

## 목적과 주장

내부 변수 수와 최소 독립 상태 차원을 구별한다

## 앞 장면에서 받은 내용

일반적 기준은 영 초기 상태의 입출력 관계이다

## 확정 TTS

- 사용자 제공 구간 141–154초, 길이 13초.
- 음원 미제공: 위 시각을 실제 발화 기준으로 사용, 무음 영상과 TTS 원고 제공.

결국 시스템 내부에 존재하는 모든 변수가 외부 동작을 설명하는 데 필요한 것은 아닙니다.
중요한 것은 상태를 몇 개 가지고 있느냐가 아니라, 동일한 입출력 관계를 유지하기 위해 최소 몇 개의 독립적인 상태가 필요한가입니다.

## 화면과 시간

- 141–146초: 결국 시스템 내부에 존재하는 모든 변수가 외부 동작을 설명하는 데 필요한 것은 아닙니다.
- 146–154초: 중요한 것은 상태를 몇 개 가지고 있느냐가 아니라, 동일한 입출력 관계를 유지하기 위해 최소 몇 개의 독립적인 상태가 필요한가입니다.

세로와 가로를 각각 배치. 입력 u 청록, x₁·x₂ 파랑, z·y 노랑, d 빨강. 축과 수식, 실제 모델 계산을 일치시킨다.

## 시작과 종료

첫 문장의 핵심 대상을 받아 마지막 문장의 주장으로 완료. 주요 상태 변환은 두 블록→z, 곡선 비교는 같은 축에서 중첩.

## 다음 장면의 시각적 연결

동일한 시스템과 색상 유지. 영상 내 복습·다음 편 예고 없음.

## 정확성

ẋ₁=−x₁+u, ẋ₂=−x₂+u, y=x₁+x₂; ż=−z+2u; ḋ=−d. 차이는 정지 상태가 아니라 자율 감쇠한다. 합과 차이 축은 (1,1), (1,−1)로 직교. 일반 최소 실현은 영 초기 입출력 기준, 이번 예시의 더 강한 초기 출력 일치와 구분한다.

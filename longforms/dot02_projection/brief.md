# Dot Pro LEVEL 02 — 제작 기준

## 목표
내적값이 실제 방향벡터로 재구성되는 과정을 이해한다. 내적은 측정, 정사영은 추출.

## 제작 범위
사용자 확정 원고와 실제 문장 종료 시각23개, 101초. 9:16 1080×1920 쇼츠와16:9 1920×1080 롱폼, 각각30fps. 음원 미제공으로 무음 자막 영상. 영상 길이를 임의로 늘리지 않는다. 9개 독립 씬으로 교체 가능.

## 핵심 조건
x=(4,2)와 원점·좌표 스케일 고정. u=(1/√2,1/√2), 실제 길이1. 스칼라3√2는35초에 공개. p=(3,3)은58초에 좌표 공개. 54–58초 숫자 곱셈과 화살표 길이 증가를 동기화. 초록u 원본은 유지하고 복제한 화살표를 주황p로 확대. 71–78초 수선과 직각 표시. 마지막 공식은 단위벡터 조건과 함께 표시.

## 서사
사용자 원문은 그대로 사용한다. 이전 편을 언급하는 복습·다음 편 예고는 추가하지 않는다. 78–89초는 본편에서 수행한 두 연산의 결합이다.

## 시각 구분
파란 원래벡터 / 초록 기준 방향 / 주황 스칼라와정사영 / 회색 수선. 선분은 측정 구간, 화살표는 벡터.

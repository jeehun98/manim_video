# 15 1,000 → 1,000,000

- 핵심 주장: 1,000 → 1,000,000
- 사용자 확정 전체 시각 52–56초, 길이 4초.
- 입력 상태: 같은 최소제곱 문제와 좌표계·색상을 유지한다.
- 화면: storyboard.md 컷 15, visuals.py INDEX 14.
- 시작→종료: 해당 기하학/수식의 등장→관찰→변화→해석. 끝에는 같은 문제의 다음 계산 단계로 시각적으로 연결한다.
- TTS: 상위 timing.json의 겹치는 문장; 컷 경계에서 중복 발화하지 않는다.
- 수학적 조건: ε>0, A는 열 전체 계수, 축약 Q는 QᵀQ=I인 3×2 행렬.
- 평면은 ε가 작아져도 고정. κ₂(AᵀA)=κ₂(A)²와 κ₂(R)=κ₂(A)는 실제 오차 배율과 구분한다.
- 안정적인 Householder QR 기준. 실제 음원 미제공으로 무음 영상·별도 자막.

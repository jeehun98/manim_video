# 상태값으로 실행 단계를 구분한다

주장: 00/01/10/11상태와 실제 활성 장치를 함께 보여준다.

확정 구간: 77–90초 (13초).

77–85초: 예를 들어 00은 명령어 인출, 01은 주소 결정, 10은 데이터 읽기, 11은 결과 기록을 의미하도록 정하는 것입니다.
85–90초: 이제 레지스터에 저장된 값만 확인해도 현재 어느 단계에 있는지 구분할 수 있습니다.

화면: scene_engine.py의 state에서 구현. 짙은 남색 배경, 기존 데이터 경로 파랑, 추가 저장회로 초록, 메모리 보라, 제어 주황. 기능이 필요한 시점에만 새 회로를 공개한다. FSM은 상태값·활성 장치·결과를 함께 보여준다. PC 주소와 실행 상태 번호를 구분한다. 하단 단일 자막 전용 영역. 9:16/16:9 각각 배치한다. 제어 비활성은 전원 차단을 뜻하지 않는다. 네 상태는 교육용 LOAD 예시이며 모든 명령·프로세서의 보편 구조가 아니다. 메모리 응답이 해당 읽기 단계 내 준비된 예시를 가정한다. 본편은 지연이 아니라 실행 순서에 집중한다. 원문·발화시간을 변경하거나 추가 엔드카드를 넣지 않는다.

# 하나의 명령어를 여러 클럭에

주장: 완성회로로한LOAD를재시연하고R1=5를확인한다.

확정 구간: 133–143초 (10초).

133–138초: 이제 각 회로는 정해진 순서에 따라 동작하고, 다음 단계에 필요한 정보도 유지할 수 있습니다.
138–143초: 이처럼 하나의 명령어를 여러 클럭에 나누어 실행하도록 구성한 것을 다중 사이클 실행 구조라고 합니다.

화면: scene_engine.py의 complete에서 구현. 짙은 남색 배경, 기존 데이터 경로 파랑, 추가 저장회로 초록, 메모리 보라, 제어 주황. 기능이 필요한 시점에만 새 회로를 공개한다. FSM은 상태값·활성 장치·결과를 함께 보여준다. PC 주소와 실행 상태 번호를 구분한다. 하단 단일 자막 전용 영역. 9:16/16:9 각각 배치한다. 제어 비활성은 전원 차단을 뜻하지 않는다. 네 상태는 교육용 LOAD 예시이며 모든 명령·프로세서의 보편 구조가 아니다. 메모리 응답이 해당 읽기 단계 내 준비된 예시를 가정한다. 본편은 지연이 아니라 실행 순서에 집중한다. 원문·발화시간을 변경하거나 추가 엔드카드를 넣지 않는다.

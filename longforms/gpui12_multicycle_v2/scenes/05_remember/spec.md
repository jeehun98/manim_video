# 현재 단계도 기억해야 한다

주장: 기존 저장 회로에 실행 단계 정보를 보관한다.

확정 구간: 62–77초 (15초).

62–66초: 하지만 이렇게 동작을 나누려면 새로운 정보가 필요합니다.
66–70초: 프로세서는 지금 어느 과정을 실행하고 있는지 어떻게 알 수 있을까요?
70–74초: 우리는 앞서 여러 비트의 값을 기억하는 레지스터를 만들었습니다.
74–77초: 여기에 현재 실행 단계를 나타내는 값을 저장하면 어떨까요?

화면: scene_engine.py의 remember에서 구현. 짙은 남색 배경, 기존 데이터 경로 파랑, 추가 저장회로 초록, 메모리 보라, 제어 주황. 기능이 필요한 시점에만 새 회로를 공개한다. FSM은 상태값·활성 장치·결과를 함께 보여준다. PC 주소와 실행 상태 번호를 구분한다. 하단 단일 자막 전용 영역. 9:16/16:9 각각 배치한다. 제어 비활성은 전원 차단을 뜻하지 않는다. 네 상태는 교육용 LOAD 예시이며 모든 명령·프로세서의 보편 구조가 아니다. 메모리 응답이 해당 읽기 단계 내 준비된 예시를 가정한다. 본편은 지연이 아니라 실행 순서에 집중한다. 원문·발화시간을 변경하거나 추가 엔드카드를 넣지 않는다.

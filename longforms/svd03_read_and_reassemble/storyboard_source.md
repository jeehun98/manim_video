# SVD — 3편 상세 영상화 콘티

행렬은 하나의 입력을 어떻게 읽어낼까? | 152초 · 2분 32초

3편은 앞선 두 편과 시각화 방식이 달라야 합니다.

1편은 관찰자가 입력의 차이를 구별하는 실험, 2편은 모든 방향을 탐색해 특별한 방향을 발견하는 실험이었습니다.

이번에는 발견한 방향을 가지고 실제 입력 하나를 처리합니다. 기존 SVD 영상에서 흔히 사용하는 회전 → 확대 → 회전 설명보다, 입력 하나에 숨어 있는 두 성분을 읽어내고, 각 성분이 어떤 출력을 만들어내는지 추적하는 과정을 중심으로 제작하는 것이 좋습니다.

## 1. 전체 영상 설계

개념적 장면 배치. 실제 영상에서는 2편에서 사용한 특이벡터 방향과 수치를 그대로 유지합니다.

이번 편에서 중요한 제작 규칙은 처음 등장한 입력 벡터 \\(x\\)를 영상 끝까지 변경하지 않는 것입니다.

시청자는 하나의 벡터가 다음과 같은 변화를 겪는 모습을 따라갑니다.

입력 벡터 \\(x\\)

아직 두 성분이 함께 존재하는 상태

방향별 성분 읽기

\\(c_1=v_1^Tx,\quad c_2=v_2^Tx\\)

서로 다른 배율 적용

\\(\sigma_1c_1,\quad \sigma_2c_2\\)

출력 방향으로 조립

\\(\sigma_1c_1u_1+\sigma_2c_2u_2=Ax\\)

중요한 점은 각 단계를 단순히 기호로 설명하지 않고, 각 성분의 숫자와 그에 대응하는 화살표를 일관되게 연결하는 것입니다.

## 2. 장면별 상세 콘티

### 시퀀스 A — 하나의 입력에 여러 성분이 들어 있다 (0\~26초)

목표: 특별한 방향 하나만 다루던 2편에서 임의의 입력으로 문제를 확장한다.

장면 01 | 0\~7초 — 두 특별한 방향을 다시 불러온다

내레이션: “지난 실험에서 우리는 행렬이 가장 강하게 반응하는 입력 방향과 가장 약하게 반응하는 입력 방향을 찾아냈습니다.”

2편의 마지막 좌표평면을 그대로 가져옵니다.

입력 공간에 \\(v_1\\), \\(v_2\\) 두 방향만 남기고 다른 보조선을 제거합니다.

최대 반응 방향을 금색으로, 최소 반응 방향을 보라색으로 강조합니다. 두 방향이 직교한다는 표시도 유지합니다.

장면 02 | 7\~13초 — 입력과 출력 방향을 다시 대응시킨다

내레이션: “각 방향에 길이 1의 벡터를 넣으면, 행렬은 그에 대응하는 출력 방향으로 특잇값만큼 크기를 바꿨습니다.”

화면을 입력과 출력 두 공간으로 분할합니다.

입력의 \\(v_1\\) 벡터를 강조하면 출력에 \\(2u_1\\)이 나타납니다. 이어서 \\(v_2\\)를 강조하면 \\(0.5u_2\\)가 나타납니다.

상단에는 각각 `×2`, `×0.5`를 짧게 표시합니다.

장면 03 | 13\~22초 — 어느 특별한 방향에도 놓이지 않은 입력

내레이션: “그런데 실제 입력이 이 특별한 방향들 중 하나에 놓이지 않는다면 어떻게 될까요? 두 방향 사이에 놓인 임의의 입력 벡터를 생각해보겠습니다.”

기존 \\(v_1\\), \\(v_2\\)는 가는 선으로 남기고, 두 방향의 성분을 모두 가진 새로운 주황색 입력 벡터 \\(x\\)가 등장합니다.

\\(x\\)를 방향 사이의 임의 위치에 놓고, 다음 장면에서도 고정합니다.

이때 입력 벡터를 두 개로 쪼개서 서로 다른 입력처럼 보이게 만들지 않는 것이 중요합니다. 원래 입력은 하나입니다.

장면 04 | 22\~26초 — 두 방향을 함께 포함한다

내레이션: “이 벡터에는 우리가 찾아낸 두 방향의 성분이 함께 들어 있습니다.”

\\(x\\)의 끝점에서 두 특이벡터 축으로 점선 투영선을 내립니다.

두 축 위에 각각 짧은 성분 화살표가 나타납니다.

주황색 원본 \\(x\\)를 계속 유지해 두 성분의 합이 원래 벡터라는 관계를 예고합니다.

### 시퀀스 B — 입력을 질문으로 읽어낸다 (26\~46초)

목표: 내적을 단순 계산 공식이 아니라 입력에서 특정 방향의 좌표를 추출하는 연산으로 표현한다.

장면 05 | 26\~33초 — 첫 번째 방향의 성분

내레이션: “먼저 첫 번째 방향으로 얼마나 뻗어 있는지 측정해보겠습니다. 입력 벡터를 그 방향에 투영하면 하나의 값이 나옵니다.”

주황색 벡터 \\(x\\)에서 \\(v_1\\) 방향으로 수직 투영선을 내립니다.

축 위에 첫 번째 성분 벡터가 나타납니다.

투영 과정이 끝나면 벡터 옆에 \\(c_1=v_1^Tx\\)를 표시합니다.

이때 \\(c_1\\)은 방향을 포함한 벡터가 아니라, 방향에 대한 부호 있는 스칼라 계수라는 사실을 연출에서 구분합니다.

장면 06 | 33\~36초 — 두 번째 방향의 성분

내레이션: “이번에는 두 번째 방향에 투영합니다. 또 다른 값이 나옵니다.”

이번에는 \\(v_2\\) 방향으로 동일한 작업을 수행합니다.

\\(c_2=v_2^Tx\\)가 나타납니다.

화면 아래에 두 계수를 나란히 배치합니다.

첫 번째 질문

\\(v_1^Tx=c_1\\)

첫 번째 방향의 성분

두 번째 질문

\\(v_2^Tx=c_2\\)

두 번째 방향의 성분

장면 07 | 36\~42초 — 두 값만으로 입력을 복원한다

내레이션: “두 방향은 서로 직교하기 때문에, 이 두 값만 알면 원래 입력 벡터를 정확히 표현할 수 있습니다.”

두 축 위에 나타난 성분 화살표를 평행이동시켜 평행사변형을 완성합니다.

평행사변형의 대각선이 원래 입력 벡터 \\(x\\)와 정확히 일치하도록 합니다.

\\[ x=c_1v_1+c_2v_2 \\]

장면 08 | 42\~46초 — 입력은 바뀌지 않았다

내레이션: “우리는 입력을 바꾸지 않았습니다. 같은 입력을 다른 기준으로 읽어낸 것입니다.”

일반적인 \\(x,y\\) 좌표축을 잠시 강조했다가 특이벡터 \\(v_1,v_2\\) 축으로 전환합니다.

주황색 입력 벡터의 물리적 위치와 끝점은 움직이지 않습니다.

표시되는 좌표 성분만 달라집니다.

화면 문구: 벡터는 그대로, 표현하는 기준만 달라졌다.

### 시퀀스 C — 성분마다 다른 반응이 나타난다 (46\~67초)

목표: SVD의 가운데 단계인 특잇값의 역할을 두 성분의 독립적인 배율 변화로 보여준다.

장면 09 | 46\~50초 — 읽어낸 성분을 변환한다

내레이션: “그렇다면 이렇게 읽어낸 값들을 행렬에 통과시키면 어떻게 될까요?”

\\(c_1,c_2\\)를 화면 중앙의 별도 패널로 이동시킵니다.

이 시점에서는 두 값을 입력 공간의 원래 좌표가 아닌, 특이벡터 기준 좌표로 표시합니다.

두 값이 서로 다른 처리 경로로 나뉩니다.

장면 10 | 50\~58초 — 서로 다른 특잇값

내레이션: “첫 번째 방향의 성분은 그 방향에 대응하는 특잇값만큼 확대됩니다. 두 번째 방향의 성분에도 또 다른 특잇값이 적용됩니다.”

첫 번째 계수 \\(c_1\\)에 2를 곱하고, 두 번째 계수 \\(c_2\\)에 0.5를 곱하는 애니메이션을 보여줍니다.

성분

\\(c_1\\)

배율

\\(\times 2\\)

결과

\\(2c_1\\)

성분

\\(c_2\\)

배율

\\(\times 0.5\\)

결과

\\(0.5c_2\\)

장면 11 | 58\~62초 — 배율의 차이를 비교한다

내레이션: “중요한 것은 두 방향이 서로 다른 배율을 가진다는 사실입니다.”

변환 전의 두 계수와 변환 후의 두 계수를 동시에 보여줍니다.

화살표 길이로 계수의 크기를 표현하되, 숫자값도 함께 표시합니다.

원래 입력의 각 성분이 서로 다른 정도로 확대 또는 축소된다는 사실이 핵심입니다.

장면 12 | 62\~67초 — 아직 출력 벡터는 완성되지 않았다

내레이션: “하지만 여기까지는 각 성분이 얼마나 커지거나 작아지는지만 계산했습니다.”

두 개의 스칼라 계수 \\(2c_1\\)과 \\(0.5c_2\\)만 화면에 남깁니다.

오른쪽 출력 좌표평면은 아직 비워 둡니다.

화면 문구: 크기는 계산했다. 방향은 어디일까?

이 질문이 다음 시퀀스를 자연스럽게 열어줍니다.

### 시퀀스 D — 출력 공간에서 다시 조립한다 (67\~87초)

목표: 배율이 적용된 계수들이 실제 출력 방향의 벡터가 되고, 그 합이 직접 계산한 Ax와 일치함을 보여준다.

장면 13 | 67\~77초 — 계수에 출력 방향을 부여한다

내레이션: “행렬은 이 성분들을 출력 공간의 방향으로도 바꿉니다. 첫 번째 값은 첫 번째 출력 특이벡터 방향으로, 두 번째 값은 두 번째 출력 특이벡터 방향으로 나타납니다.”

두 성분이 출력 특이벡터 방향의 벡터가 됩니다. 그림은 개념적 예시이며 실제 길이는 해당 계수에 비례하도록 계산합니다.

출력 좌표평면에 두 벡터를 원점에서 각각 그립니다.

첫 번째 출력 기여는 금색, 두 번째는 보라색으로 구분합니다. 이 색상을 2편의 최대·최소 반응 표시와 연결합니다.

여기서 두 벡터를 아직 합치지 않습니다. 방향이 다르고 기여 크기도 다른 두 결과가 동시에 존재한다는 점을 먼저 보여줍니다.

장면 14 | 77\~80초 — 벡터 덧셈 시작

내레이션: “이제 두 출력 벡터를 더해보겠습니다.”

두 번째 출력 벡터를 평행이동시켜 첫 번째 출력 벡터의 끝점에 붙입니다.

벡터의 방향과 길이는 변하지 않아야 합니다.

그 결과 원점에서 최종 끝점으로 향하는 새로운 청록색 벡터가 등장합니다.

장면 15 | 80\~87초 — 직접 계산한 결과와 비교

내레이션: “서로 다른 방향에서 만들어진 두 벡터가 하나로 합쳐지면서, 처음 입력에 행렬을 직접 곱했을 때와 정확히 같은 출력이 만들어집니다.”

먼저 두 성분의 합으로 얻은 출력 벡터를 보여줍니다.

이어서 원래 입력 \\(x\\)에 행렬 \\(A\\)를 직접 적용한 결과를 점선 화살표로 겹쳐 표시합니다.

두 화살표의 끝점이 정확히 일치하면 점선이 실선에 흡수됩니다.

\\[ Ax=(\sigma_1c_1)u_1+(\sigma_2c_2)u_2 \\]

두 계산의 출력이 정확히 일치

이 장면이 이번 영상의 첫 번째 핵심 발견입니다. 복잡한 하나의 행렬곱이 방향별 두 계산의 합과 같다는 것을 눈으로 확인할 수 있어야 합니다.

### 시퀀스 E — SVD라는 구조가 드러난다 (87\~110초)

목표: 공식부터 보여주는 것이 아니라, 이미 수행한 계산을 세 단계로 정리했더니 SVD가 된다는 사실을 보여준다.

장면 16 | 87\~99초 — 세 과정 다시 보기

내레이션: “복잡해 보였던 하나의 행렬곱을 세 과정으로 나누어 본 것입니다. 입력을 특별한 방향들의 성분으로 읽고, 각 성분에 서로 다른 배율을 적용하고, 그 결과를 출력 공간에서 다시 조립합니다.”

지금까지의 애니메이션을 하나의 가로 흐름으로 압축합니다.

읽기

방향별 좌표 추출

\\(V^Tx\\)

배율

성분마다 크기 변화

\\(\Sigma V^Tx\\)

조립

출력 방향으로 합성

\\(U\Sigma V^Tx\\)

영상에서는 세 패널이 순차적으로 밝혀지며, 앞서 보여준 벡터 애니메이션이 각 패널 안에서 짧게 재생됩니다.

장면 17 | 99\~108초 — SVD 공식의 발견

내레이션: “이 세 과정을 각각 브이 전치, 시그마, 유로 나타낼 수 있습니다. 그리고 이를 하나로 합치면, 에이는 유, 시그마, 브이 전치의 곱이 됩니다.”

화면에는 먼저 입력 \\(x\\)가 다음 과정을 통과하는 모습이 나타납니다.

\\[ x \\;\longrightarrow\\; V^Tx \\;\longrightarrow\\; \Sigma V^Tx \\;\longrightarrow\\; U\Sigma V^Tx \\]

처음에는 각 단계가 분리되어 있지만, 점점 간격이 좁아지면서 하나의 행렬 \\(A\\)로 묶입니다.

\\(A=U\Sigma V^{\mathsf T}\\)

\\(A=\begin{bmatrix}4&1&2&0\\\1&4&0&2\\\2&0&4&1\\\0&2&1&4\end{bmatrix}\\)

\\(A\_{2}=\begin{bmatrix}3&0.5&3&0.5\\\0.5&3&0.5&3\\\3&0.5&3&0.5\\\0.5&3&0.5&3\end{bmatrix}\\)\\(\text{error}=\lVert A-A\_{2}\rVert=3.162\\)

피드백 보내기

공식이 등장하는 부분에 활용할 수 있는 SVD 시각화. 실제 영상은 앞서 선택한 하나의 입력에 대한 계산을 중심으로 연출합니다.

장면 18 | 108\~110초 — 발견의 이름

내레이션: “이것이 특잇값 분해, 에스브이디입니다.”

복잡한 수식 애니메이션을 잠시 멈추고 제목만 짧게 표시합니다.

Singular Value Decomposition

여기서 별도의 긴 설명을 추가하지 않습니다. 이미 시청자는 세 단계가 무엇을 하는지 알고 있으므로 이름만 부여하면 됩니다.

### 시퀀스 F — 큰 특잇값이 반드시 큰 기여를 뜻하지는 않는다 (110\~138초)

목표: SVD의 구조적 성질과 특정 입력에 대한 실제 기여를 구별한다. 이번 편에서 가장 차별화할 수 있는 부분입니다.

장면 19 | 110\~119초 — 특잇값은 큰데 기여는 0

내레이션: “그런데 여기서 한 가지 흥미로운 사실이 있습니다. 어떤 방향의 특잇값이 매우 크더라도, 입력에 그 방향의 성분이 없다면 그 방향이 만드는 출력은 0입니다.”

입력 벡터 \\(x\\)를 \\(v_2\\) 방향으로 회전시킵니다.

이때 \\(x\\)는 \\(v_1\\)에 수직이므로 첫 번째 성분은 0입니다.

\\[ v_1^Tx=0 \\]

따라서 첫 번째 특잇값이 2여도 첫 번째 출력 기여는 0입니다.

\\[ 2(v_1^Tx)u_1=0 \\]

영상에서는 길이 2를 나타내는 배율 계기가 그대로 유지되지만, 그 계기로 들어오는 성분이 0이기 때문에 출력 화살표가 나타나지 않습니다.

핵심 화면 문구: 배율이 커도 입력 성분이 없으면 기여는 0

장면 20 | 119\~125초 — 작은 특잇값도 실제 출력에 기여한다

내레이션: “반대로 특잇값이 작더라도 입력에 해당 성분이 충분히 있다면 출력에 기여할 수 있습니다.”

입력 벡터를 계속 \\(v_2\\) 방향으로 유지합니다.

두 번째 성분 \\(c_2\\)는 0이 아니므로 특잇값 0.5가 적용되어 실제 출력 벡터가 생성됩니다.

첫 번째 기여는 0이고, 두 번째 기여만 남습니다.

첫 번째 성분

\\(2\times0=0\\)

두 번째 성분

\\(0.5\times1=0.5\\)

두 번째 성분만 출력에 남는다

장면 21 | 125\~138초 — 반응 능력과 실제 기여는 다르다

내레이션: “따라서 특잇값만 보고 특정 입력의 출력에서 어떤 성분이 가장 크게 기여하는지 결정할 수는 없습니다. 행렬이 어떤 방향에 강하게 반응하는지와, 실제 입력이 어떤 방향의 성분을 가지고 있는지는 서로 다른 문제입니다.”

화면을 두 개의 영역으로 나눕니다.

왼쪽은 행렬에 내재된 특잇값 \\(\sigma_1,\sigma_2\\)를 고정해서 보여줍니다.

오른쪽에서는 입력 \\(x\\)를 여러 방향으로 회전시키면서 \\(c_1,c_2\\)와 실제 기여 크기를 변화시킵니다.

왼쪽: 행렬의 성질은 고정.

오른쪽: 입력이 달라지면 각 성분의 실제 기여가 달라짐.

이 장면에서는 입력 방향을 바꾸더라도 행렬과 특잇값은 변경하지 않는 것이 중요합니다.

### 시퀀스 G — 방향을 거꾸로 되돌릴 수 있을까? (138\~152초)

목표: 순방향 계산에서 역방향 복원으로 문제를 전환하고, 다음 편의 오차 증폭 문제를 자연스럽게 제시한다.

장면 22 | 138\~146초 — 계산의 방향을 뒤집는다

내레이션: “그렇다면 반대로 생각해보겠습니다. 행렬이 어떤 방향의 성분을 아주 작게 전달했다면, 출력만 보고 그 성분을 다시 알아낼 수 있을까요?”

지금까지 사용한 계산 흐름의 화살표를 반대 방향으로 바꿉니다.

입력 \\(x\\)는 가리고 출력 \\(Ax\\)만 남깁니다.

작은 특잇값이 적용된 성분을 별도로 강조합니다.

예를 들어 \\(c_2=1\\), \\(\sigma_2=0.5\\)라면 출력의 해당 성분은 0.5입니다.

이것을 원래 1로 되돌리려면 2배 해야 합니다.

장면 23 | 146\~152초 — 작은 오차가 들어온다면

내레이션: “특히 출력에 작은 오차가 섞여 있다면, 원래 입력을 복원하는 과정에서는 어떤 일이 벌어질까요?”

출력 벡터의 끝점에 아주 작은 오차 화살표를 추가합니다.

화면을 확대하지 않고, 수학적 오차량을 숫자로 표시합니다.

출력의 해당 성분이 원래 값보다 조금 달라진 상태로 멈춥니다.

마지막 문구는 다음과 같이 구성합니다.

> 작게 전달한 성분을 다시 확대하면, 오차는 어떻게 될까?

바로 다음 편에서 역변환과 Condition Number의 이야기로 이어집니다.

## 3. 실제 영상 제작용 좌표와 행렬

이 편에서는 구체적인 값이 매우 중요합니다. 입력 성분을 잘못 투영하거나 벡터 합이 맞지 않으면, 시청자가 SVD를 이해하는 대신 잘못된 직관을 얻을 수 있기 때문입니다.

2편과 연결할 추천 행렬은 다음과 같습니다.

\\[ A=R(60^\circ) \begin{bmatrix} 2&0\\\ 0&0.5 \end{bmatrix} R(-30^\circ) \\]

여기서

\\[ v_1=(\cos30^\circ,\sin30^\circ) \\]

\\[ v_2=(\cos120^\circ,\sin120^\circ) \\]

이며 출력 방향은

\\[ u_1=(\cos60^\circ,\sin60^\circ) \\]

\\[ u_2=(\cos150^\circ,\sin150^\circ) \\]

입니다.

이번 편의 메인 입력은 계산이 직관적으로 보이도록

\\[ x=v_1+v_2 \\]

로 설정하는 것이 좋습니다. 두 성분이 각각 1이므로 벡터의 분해·배율 적용·재조립을 명확하게 보여줄 수 있습니다.

| 단계       | 첫 번째 성분    | 두 번째 성분      |
| -------- | ---------- | ------------ |
| 입력 성분 읽기 | 1          | 1            |
| 특잇값      | 2          | 0.5          |
| 배율 적용 결과 | 2          | 0.5          |
| 출력에서의 기여 | \\(2u_1\\) | \\(0.5u_2\\) |

실제 입력 벡터와 출력 벡터는 다음처럼 계산됩니다.

\\[ x\approx \begin{bmatrix} 0.3660\\\ 1.3660 \end{bmatrix} \\]

\\[ Ax\approx \begin{bmatrix} 0.5670\\\ 1.9821 \end{bmatrix} \\]

직접 행렬을 곱한 결과와 성분을 따로 계산해 더한 결과가 동일해야 합니다.

마지막 110\~125초의 반례 구간에서는 입력을 \\(x=v_2\\)로 바꿔서 첫 번째 성분이 정확히 0이 되는 모습을 보여주면 됩니다.

| 구간 | 시간        | 내용             |
| -- | --------- | -------------- |
| A  | 0\~26초    | 특별한 방향 밖의 입력   |
| B  | 26\~46초   | 방향별 성분 추출      |
| C  | 46\~67초   | 서로 다른 배율 적용    |

## 5. 이번 편에서 특히 신경 쓸 부분

영상의 시각적 핵심은 26\~87초입니다.

같은 입력 벡터 하나를 사용하면서 그 벡터가 가진 두 성분을 추출하고, 각각에 배율을 적용하고, 두 출력 벡터를 합치는 과정입니다. 시청자는 매 단계에서 원래 벡터와 현재 계산된 값을 비교할 수 있어야 합니다.

그리고 110\~138초가 기존 SVD 설명과 가장 차별화되는 부분입니다.

큰 특잇값이 특정 입력의 출력에 반드시 큰 기여를 만드는 것은 아니라는 사실은, SVD를 무조건적인 정보 중요도 순위로 이해하는 오해를 줄여줍니다.

이번 편이 끝날 때 시청자가 갖게 되는 이해는 다음과 같습니다.

SVD는 행렬의 반응을 방향별로 분해하고, 그 방향별 반응을 다시 합쳐 실제 출력을 구성하는 방법이다.

여기까지 이해했다면 다음 편에서 작게 전달된 정보가 왜 역변환에서는 불안정해지는가라는 질문으로 이어지는 것이 자연스럽습니다.

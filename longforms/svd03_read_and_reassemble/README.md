# SVD 3막 — 행렬은 하나의 입력을 어떻게 읽어낼까?

- 기준: 사용자 제공 콘티와 내레이션, 31개 문장 종료 시각.
- 길이: 정확히152초. 23개 독립 씬을 렌더한 뒤 결합한다.
- 최종: 1920×1080, 30fps. 미리보기: 854×480, 15fps.
- 음원 미제공: 무음 영상에 내레이션 자막을 포함하며 SRT를 별도로 제공한다.

## 계산 기준

2편과 동일한 행렬과 직교 기준을 유지한다.

A = UΣVᵀ = R(60°) diag(2, 0.5) R(−30°)

| 요소 | 첫 번째 방향 | 두 번째 방향 |
|---|---|---|
| 입력 단위 방향 | v₁:30° | v₂:120° |
| 출력 단위 방향 | u₁:60° | u₂:150° |
| 특잇값 | 2 | 0.5 |
| 주 입력의 계수 vᵢᵀx | 1 | 1 |
| 배율 적용 후 계수 | 2 | 0.5 |
| 출력 기여 | 2u₁ | 0.5u₂ |

주 실험은 x=v₁+v₂로 고정한다. x≈(0.3660,1.3660), Ax≈(0.5670,1.9821). 두 기여의 합과 직접 행렬곱을 실제 계산해 비교한다. cᵢ는 스칼라이고 cᵢvᵢ는 투영 벡터다. 배율 적용 이후에는 가운데 패널의 제목도 σᵢcᵢ로 변경하여 계수와 결과를 혼동하지 않게 한다.

왼쪽 주 입력 x의 물리적 위치와 길이는 변하지 않는다. 110–138초 비교는 별도 입력 z로 명시하고, 주 입력 x를 왼쪽에 계속 유지한다. z=v₂일 때 c₁=0, c₂=1, 첫 출력 기여0, 두 번째 기여0.5u₂다. 125–138초에는 z만 방향을 바꾸며 A와 특잇값은 고정한다. 138초부터 주 입력을 가리고 역방향 질문으로 전환한다.

146초부터 출력 u₂ 성분0.50에 +0.01 오차를 더해0.51로 표시한다. 실제 오차 벡터도0.01u₂로 그리며, 카메라를 확대하거나 오차 화살표를 과장하지 않는다. 복원 오차의 해설은 추가하지 않고 사용자 질문으로 끝낸다.

콘티의 '주 입력 고정' 원칙과 후반 입력 회전 예시를 별도 z 실험으로 구분했다. 중간에 포함된4×4 행렬·rank-2 근사 위젯은 본편의 선택된2×2 실험과 무관하므로 화면에 넣지 않는다. 사용자 제공 복습 문장과 마지막 질문을 그대로 반영하며 별도 안내 문구는 추가하지 않는다.

## 실행

프로젝트 루트에서:

```powershell
python longforms/svd03_read_and_reassemble/build.py --preview
python longforms/svd03_read_and_reassemble/build.py
```

씬 교체 후 결합:

```powershell
python longforms/svd03_read_and_reassemble/build.py --scene 15
python longforms/svd03_read_and_reassemble/build.py --concat-only
```

여러 씬은 `--scenes 15 19 21`로 지정할 수 있다. 기본 동시 렌더3개이며 `--jobs 1`로 순차 실행할 수 있다. Manim0.21.0, FFmpeg9.0.1, PyAV, Malgun Gothic 사용. 씬마다 같은 절대시간 상태를 재현하고, 지정 프레임 수와 한 프레임 시계로 결합한다. 사후 속도 변경은 하지 않는다.

최종 렌더에서 미리보기를 동기화하려면:

```powershell
python longforms/svd03_read_and_reassemble/sync_preview.py
```

출력: exports/svd03_read_and_reassemble_152s_1080p30.mp4 및 .srt.

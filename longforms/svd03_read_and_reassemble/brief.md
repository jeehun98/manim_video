# 제작 기준 — 하나의 고정 입력을 세 단계로 추적한다

- 사용자 원문31개 문장과 종료 시각을 그대로 적용한다. 총152초.
- 주 입력 x=v₁+v₂, c=(1,1)는 고정한다. 좌표 읽기를 입력 벡터의 물리적 변형으로 표현하지 않는다.
- 입력 투영→스칼라 계수→배율 적용→출력 방향 부여→벡터 합 순서로 구성한다.
- 스칼라 cᵢ와 투영 벡터 cᵢvᵢ, 가중 좌표 σᵢcᵢ와 출력 벡터 σᵢcᵢuᵢ를 구분한다.
- 두 번째 성분을 평행이동할 때 방향과 길이를 유지한다. 결과는 직접 계산한 Ax와 같은 좌표에 놓인다.
- 세 과정의 의미를 먼저 보여주고99초에 Vᵀ·Σ·U, 103초에 A=UΣVᵀ, 108초에 SVD 이름을 표시한다.
- 110–138초는 별도 반례 z다. z=v₂에서 첫 기여는 정확히0. 이후 z만 변화하고 주 입력과 행렬은 유지한다.
- 138초에 입력을 가리고 흐름 화살표를 뒤집는다. 146초에 관측 출력의 u₂ 성분에0.01 오차를 더한다.
- 입력·출력 좌표계는 동일 척도, 카메라는 고정한다. 실제 계산량과 그림의 수치가 일치해야 한다.
- 주 입력 주황, 첫 성분 금색, 두 번째 성분 보라, 최종 출력 청록으로 구분한다.
- 4×4 예시 위젯은 사용하지 않고2편의2×2 행렬만 사용한다.
- 음원이 없어 무음 영상·내레이션 자막·SRT를 제공한다. 음성이 포함된 완성본으로 표기하지 않는다.

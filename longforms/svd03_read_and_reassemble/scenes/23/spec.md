# 23 — 출력에 작은 오차가 있다면

## 목적과 핵심 주장
출력 기저 성분0.50에0.01 오차를 더하고 질문으로 종료한다

## 앞 장면에서 받은 내용
입력을 숨기고 출력에서 성분을 복원하는 문제를 묻는다

## TTS 원문과 길이
특히 출력에 작은 오차가 섞여 있다면, 원래 입력을 복원하는 과정에서는 어떤 일이 벌어질까요?

사용자 제공 146–152초, 길이6초. 음원 미제공.

## 화면과 시간대별 동작
../../storyboard_source.md 장면23. 공통 scene_engine.py에서 절대시간146–152초를 독립 재현한다. 입력 x는 왼쪽에 고정, 가운데 스칼라 계수, 오른쪽 출력 벡터를 구분한다.

## 화면 텍스트
출력에 작은 오차가 있다면. 수식과 정확한 수치는 ../../README.md 기준.

## 시작·종료 상태
절대시간 경계의 계산 상태. 다음 씬은 같은 상태와 축 척도로 이어간다.

## 다음 장면 연결
같은 입력의 읽기→배율→조립 흐름을 유지한다. 별도 반례는 z로 명시한다.

## 정확성 및 과장 방지
A=R(60°)diag(2,0.5)R(−30°), 주 입력 x=v₁+v₂, c=(1,1). 스칼라 계수와 투영 벡터를 구분한다. 직접 행렬곱과 두 출력 기여의 합을 실제 계산한다. 110초 이후 반례 z와 주 입력 x를 혼동하지 않는다.

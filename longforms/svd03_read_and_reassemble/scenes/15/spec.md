# 15 — 직접 계산 Ax와 일치

## 목적과 핵심 주장
2u₁+0.5u₂는 직접 계산한 Ax와 일치한다

## 앞 장면에서 받은 내용
두 번째 벡터의 방향과 길이를 유지한 채 평행이동한다

## TTS 원문과 길이
서로 다른 방향에서 만들어진 두 벡터가 하나로 합쳐지면서, 처음 입력에 행렬을 직접 곱했을 때와 정확히 같은 출력이 만들어집니다.

사용자 제공 80–87초, 길이7초. 음원 미제공.

## 화면과 시간대별 동작
../../storyboard_source.md 장면15. 공통 scene_engine.py에서 절대시간80–87초를 독립 재현한다. 입력 x는 왼쪽에 고정, 가운데 스칼라 계수, 오른쪽 출력 벡터를 구분한다.

## 화면 텍스트
직접 계산 Ax와 일치. 수식과 정확한 수치는 ../../README.md 기준.

## 시작·종료 상태
절대시간 경계의 계산 상태. 다음 씬은 같은 상태와 축 척도로 이어간다.

## 다음 장면 연결
같은 입력의 읽기→배율→조립 흐름을 유지한다. 별도 반례는 z로 명시한다.

## 정확성 및 과장 방지
A=R(60°)diag(2,0.5)R(−30°), 주 입력 x=v₁+v₂, c=(1,1). 스칼라 계수와 투영 벡터를 구분한다. 직접 행렬곱과 두 출력 기여의 합을 실제 계산한다. 110초 이후 반례 z와 주 입력 x를 혼동하지 않는다.

# 03 — 고정 입력 x

## 목적과 핵심 주장
주 실험 x=v₁+v₂를 끝까지 변경하지 않는다

## 앞 장면에서 받은 내용
Av₁=2u₁, Av₂=0.5u₂

## TTS 원문과 길이
그런데 실제 입력이 이 특별한 방향들 중 하나에 놓이지 않는다면 어떻게 될까요?

두 방향 사이에 놓인 임의의 입력 벡터를 생각해보겠습니다.

사용자 제공 13–22초, 길이9초. 음원 미제공.

## 화면과 시간대별 동작
../../storyboard_source.md 장면03. 공통 scene_engine.py에서 절대시간13–22초를 독립 재현한다. 입력 x는 왼쪽에 고정, 가운데 스칼라 계수, 오른쪽 출력 벡터를 구분한다.

## 화면 텍스트
고정 입력 x. 수식과 정확한 수치는 ../../README.md 기준.

## 시작·종료 상태
절대시간 경계의 계산 상태. 다음 씬은 같은 상태와 축 척도로 이어간다.

## 다음 장면 연결
같은 입력의 읽기→배율→조립 흐름을 유지한다. 별도 반례는 z로 명시한다.

## 정확성 및 과장 방지
A=R(60°)diag(2,0.5)R(−30°), 주 입력 x=v₁+v₂, c=(1,1). 스칼라 계수와 투영 벡터를 구분한다. 직접 행렬곱과 두 출력 기여의 합을 실제 계산한다. 110초 이후 반례 z와 주 입력 x를 혼동하지 않는다.

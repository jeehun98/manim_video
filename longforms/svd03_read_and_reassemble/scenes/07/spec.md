# 07 — 두 성분의 합은 x

## 목적과 핵심 주장
완비 직교 기준에서 x=c₁v₁+c₂v₂

## 앞 장면에서 받은 내용
c₂=v₂ᵀx=1은 별도의 스칼라 계수다

## TTS 원문과 길이
두 방향은 서로 직교하기 때문에, 이 두 값만 알면 원래 입력 벡터를 정확히 표현할 수 있습니다.

사용자 제공 36–42초, 길이6초. 음원 미제공.

## 정확성 및 과장 방지
A=R(60°)diag(2,0.5)R(−30°), 주 입력 x=v₁+v₂, c=(1,1). 스칼라 계수와 투영 벡터를 구분한다. 직접 행렬곱과 두 출력 기여의 합을 실제 계산한다. 110초 이후 반례 z와 주 입력 x를 혼동하지 않는다.

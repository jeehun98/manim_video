# 21 — 반응 능력과 실제 기여

## 목적과 핵심 주장
특잇값은 고정이지만 입력별 실제 기여는 달라진다

## 앞 장면에서 받은 내용
z=v₂의 두 번째 출력 기여는0.5u₂다

## TTS 원문과 길이
따라서 특잇값만 보고 특정 입력의 출력에서 어떤 성분이 가장 크게 기여하는지 결정할 수는 없습니다.

행렬이 어떤 방향에 강하게 반응하는지와, 실제 입력이 어떤 방향의 성분을 가지고 있는지는 서로 다른 문제입니다.

사용자 제공 125–138초, 길이13초. 음원 미제공.

같은 입력의 읽기→배율→조립 흐름을 유지한다. 별도 반례는 z로 명시한다.

## 정확성 및 과장 방지
A=R(60°)diag(2,0.5)R(−30°), 주 입력 x=v₁+v₂, c=(1,1). 스칼라 계수와 투영 벡터를 구분한다. 직접 행렬곱과 두 출력 기여의 합을 실제 계산한다. 110초 이후 반례 z와 주 입력 x를 혼동하지 않는다.

# 16 — 읽기 배율 조립

## 목적과 핵심 주장
이미 수행한 계산을 세 단계로 정리한다

## 앞 장면에서 받은 내용
2u₁+0.5u₂는 직접 계산한 Ax와 일치한다

## TTS 원문과 길이
복잡해 보였던 하나의 행렬곱을 세 과정으로 나누어 본 것입니다.

입력을 특별한 방향들의 성분으로 읽고, 각 성분에 서로 다른 배율을 적용하고, 그 결과를 출력 공간에서 다시 조립합니다.

사용자 제공 87–99초, 길이12초. 음원 미제공.

## 화면과 시간대별 동작
../../storyboard_source.md 장면16. 공통 scene_engine.py에서 절대시간87–99초를 독립 재현한다. 입력 x는 왼쪽에 고정, 가운데 스칼라 계수, 오른쪽 출력 벡터를 구분한다.

## 화면 텍스트
읽기 배율 조립. 수식과 정확한 수치는 ../../README.md 기준.

## 시작·종료 상태
절대시간 경계의 계산 상태. 다음 씬은 같은 상태와 축 척도로 이어간다.

## 다음 장면 연결
같은 입력의 읽기→배율→조립 흐름을 유지한다. 별도 반례는 z로 명시한다.

## 정확성 및 과장 방지
A=R(60°)diag(2,0.5)R(−30°), 주 입력 x=v₁+v₂, c=(1,1). 스칼라 계수와 투영 벡터를 구분한다. 직접 행렬곱과 두 출력 기여의 합을 실제 계산한다. 110초 이후 반례 z와 주 입력 x를 혼동하지 않는다.

# 02 — 방향과 배율의 대응

## 목적과 핵심 주장
Av₁=2u₁, Av₂=0.5u₂

## 앞 장면에서 받은 내용
직교하는 입력30°와120°를 고정 기준으로 삼는다

## TTS 원문과 길이
각 방향에 길이 1의 벡터를 넣으면, 행렬은 그에 대응하는 출력 방향으로 특잇값만큼 크기를 바꿨습니다.

사용자 제공 7–13초, 길이6초. 음원 미제공.

## 화면과 시간대별 동작
../../storyboard_source.md 장면02. 공통 scene_engine.py에서 절대시간7–13초를 독립 재현한다. 입력 x는 왼쪽에 고정, 가운데 스칼라 계수, 오른쪽 출력 벡터를 구분한다.

## 화면 텍스트
방향과 배율의 대응. 수식과 정확한 수치는 ../../README.md 기준.

## 시작·종료 상태
절대시간 경계의 계산 상태. 다음 씬은 같은 상태와 축 척도로 이어간다.

## 다음 장면 연결
같은 입력의 읽기→배율→조립 흐름을 유지한다. 별도 반례는 z로 명시한다.

## 정확성 및 과장 방지
A=R(60°)diag(2,0.5)R(−30°), 주 입력 x=v₁+v₂, c=(1,1). 스칼라 계수와 투영 벡터를 구분한다. 직접 행렬곱과 두 출력 기여의 합을 실제 계산한다. 110초 이후 반례 z와 주 입력 x를 혼동하지 않는다.

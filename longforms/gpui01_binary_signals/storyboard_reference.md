# GPU 개론 01 — 컴퓨터는 왜 0과 1을 사용할까?

113초 · 9:16 YouTube Shorts · Manim 기반 영상화 콘티

이번 영상의 핵심은 0과 1을 처음부터 등장시키지 않는 것이야.

시청자는 처음에는 연속적인 전압으로 정보를 표현하는 방법을 관찰하고, 잡음이라는 문제를 발견한 뒤, 그 해결책으로 두 가지 논리 상태와 비트라는 개념에 도달해야 해.

따라서 영상 전체를 하나의 실험처럼 구성하는 걸 추천해.

전체 영상의 시각적 흐름

표현

전압에 의미 부여

문제

잡음과 오인식

해결

두 논리 상태

표현의 자유도 → 신호의 불안정성 → 안정성 확보 → 표현력 회복

## 영상 디자인 규칙

- 배경: 검정에 가까운 남색. 화면 대부분은 기하학적 선과 도형으로 구성.
- 전압 신호: 파란색. 초기에는 연속적으로 변화하는 곡선.
- 잡음과 오류: 주황색 또는 빨간색. 문제가 발생할 때만 등장.
- 안정적인 논리 상태: 낮은 상태는 파랑, 높은 상태는 초록.
- 텍스트: 최소화. 수식과 숫자는 장면의 일부로 사용하고 설명 문장은 가급적 내레이션에 맡김.

영상 전반에 걸쳐 동일한 좌표축, 동일한 전압 신호, 동일한 색상 체계를 유지하는 것이 중요해. 화면이 매번 완전히 바뀌면 하나의 실험이 발전한다는 느낌이 사라지거든.

## 구현 시 중요한 기술적 주의점

첫째, 잡음이 발생하는 장면에서는 무작정 파형을 흔들기보다는 인접한 전압 수준 사이의 판정 경계를 실제로 넘도록 만들어야 해. 그래야 신호가 변했다는 것과 잘못 해석되었다는 것의 차이를 정확하게 보여줄 수 있어.

둘째, 처음에 0.1V를 1, 0.2V를 2로 지정하는 장면은 실제 반도체의 표준 전압 체계가 아니라 설명을 위한 가상의 정보 표현 방법이라는 점이 드러나야 해.

셋째, 2진법의 장점을 표현할 때는 두 상태만 사용하기 때문에 무조건 오류가 적어진다고 단정하지 않아야 해. 전압 간격, 노이즈 마진, 회로의 임계값 및 잡음 환경이 함께 영향을 미쳐.

넷째, 비트 조합은 가능하면 2가지 → 4가지 → 8가지 → 16가지로 실제 가지가 분기하는 형태를 사용해. 이는 나중에 컴퓨터의 비트 폭, 주소 공간, 데이터 표현을 설명할 때 재사용할 수 있는 애니메이션이야.

마지막으로 전체 영상을 관통할 시각적 원칙은 다음과 같아.

하나의 전압 그래프를 출발점으로 잡고, 기존 장면을 수정하고 확장하면서 다음 개념이 등장하도록 만들 것.

이렇게 하면 단순히 지식을 나열하는 영상이 아니라, 실제로 시청자가 새로운 계산 장치의 표현 체계를 설계하고 있다는 느낌을 줄 수 있어.

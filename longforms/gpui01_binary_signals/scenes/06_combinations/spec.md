# 06 · 신호 조합 확장

## 목적과 주장
독립 신호 하나를 추가할 때 조합 수가 두 배가 된다.

## TTS와 확정 길이
사용자 문장 종료 시각 기준 66–81초, 15초. 음원 미제공으로 현재 무음. 원문은 script.txt, 문장별 경계는 ../../timing.json.

## 화면과 타임라인
사용자 콘티 ../../storyboard_reference.md의 SCENE 06를 기준으로 한다. 상세 이벤트는 ../../scene_engine.py의 combinations 메서드에 구현한다. 자막은 사용자 문장별 시간 그대로 표시한다.

| 전체 시각(초) | 화면 변화 |
| --- | --- |
| 66–69 | LOW·HIGH를 임시 기호 0·1로 표시 |
| 69–74 | 기존 두 조합이 각각 분기하여 네 조합 |
| 74–77 | 네 조합 각각이 분기하여 여덟 조합 |
| 77–81 | 여덟 조합 각각이 분기하여 열여섯 조합과 2ⁿ |

## 시작·종료 상태와 연결
시작: 표현력의 한계에서 도달한 개념.
종료: 독립 신호 하나를 추가할 때 조합 수가 두 배가 된다.
연결: 같은 색·좌표계 또는 데이터 조합을 다음 씬에서 유지.

## 화면 텍스트·조건
긴 설명은 하단 전체 문장 자막에 둔다. 전압·숫자·LOW/HIGH·경우의 수는 중심 화면에 표시한다. 초기 전압 대응은 가상 규칙이다. 0과 1이라는 논리 기호는 조합 소개 이전에 표시하지 않는다. LOW/HIGH 사이에는 판정 보장 밖의 구간을 유지한다. 0/1은 정확한 0V/1V라는 뜻이 아니다. 실제 소자 규격·잡음 내성의 실측을 주장하지 않는다. 마지막 질문은 사용자 확정 대본과 콘티의 명시적 요청에 따라 유지한다.

## 원문
그런데 여러 신호를 함께 사용하면 어떨까요?

두 가지 상태를 가진 신호 두 개를 조합하면 네 가지 경우가 만들어집니다.

세 개라면 여덟 가지, 네 개라면 열여섯 가지입니다.

이처럼 신호를 추가할 때마다 표현할 수 있는 조합은 두 배로 늘어납니다.

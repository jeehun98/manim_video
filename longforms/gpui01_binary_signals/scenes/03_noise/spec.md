# 03 · 잡음과 오인식

## 목적과 주장
신호 변동과 판정 경계를 넘는 오류를 구별한다.

## TTS와 확정 길이
사용자 문장 종료 시각 기준 28–42초, 14초. 음원 미제공으로 현재 무음. 원문은 script.txt, 문장별 경계는 ../../timing.json.

## 화면과 타임라인
사용자 콘티 ../../storyboard_reference.md의 SCENE 03를 기준으로 한다. 상세 이벤트는 ../../scene_engine.py의 noise 메서드에 구현한다. 자막은 사용자 문장별 시간 그대로 표시한다.

| 전체 시각(초) | 화면 변화 |
| --- | --- |
| 28–31 | 0.20V 기준선 주변의 작은 변동 |
| 31–36 | 0.15V 판정 경계와 현재 판정 2 표시 |
| 36–38 | 선택 지점 0.17V는 경계 안에 있어 2 유지 |
| 38–42 | 0.13V로 이동해 경계를 넘는 순간 판정 1로 변경 |

## 시작·종료 상태와 연결
시작: 전압에 의미 부여에서 도달한 개념.
종료: 신호 변동과 판정 경계를 넘는 오류를 구별한다.
연결: 같은 색·좌표계 또는 데이터 조합을 다음 씬에서 유지.

## 화면 텍스트·조건
긴 설명은 하단 전체 문장 자막에 둔다. 전압·숫자·LOW/HIGH·경우의 수는 중심 화면에 표시한다. 초기 전압 대응은 가상 규칙이다. 0과 1이라는 논리 기호는 조합 소개 이전에 표시하지 않는다. LOW/HIGH 사이에는 판정 보장 밖의 구간을 유지한다. 0/1은 정확한 0V/1V라는 뜻이 아니다. 실제 소자 규격·잡음 내성의 실측을 주장하지 않는다. 마지막 질문은 사용자 확정 대본과 콘티의 명시적 요청에 따라 유지한다.

## 원문
하지만 실제 회로에서는 문제가 발생합니다.

전기적 신호에는 잡음이 섞일 수 있고, 전압도 완벽하게 일정하게 유지되지 않습니다.

0.2볼트로 전달하려던 신호가 조금만 달라져도, 다른 값으로 잘못 해석될 수 있는 것입니다.

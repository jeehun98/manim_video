# 01 · 전기 신호와 전압

## 목적과 주장
연속적인 전압으로 정보를 표현하는 문제를 제시한다.

## TTS와 확정 길이
사용자 문장 종료 시각 기준 0–12초, 12초. 음원 미제공으로 현재 무음. 원문은 script.txt, 문장별 경계는 ../../timing.json.

## 화면과 타임라인
사용자 콘티 ../../storyboard_reference.md의 SCENE 01를 기준으로 한다. 상세 이벤트는 ../../scene_engine.py의 signal 메서드에 구현한다. 자막은 사용자 문장별 시간 그대로 표시한다.

| 전체 시각(초) | 화면 변화 |
| --- | --- |
| 0–4 | 발광점에서 파란 신호선이 확장 |
| 4–7 | 동일 신호가 Voltage–Time 그래프로 전환 |
| 7–12 | 전압 표시점·수평 가이드·전압 수치가 연속 변화 |

## 시작·종료 상태와 연결
시작: 전압 신호가 나타나기 전의 어두운 실험 화면.
종료: 연속적인 전압으로 정보를 표현하는 문제를 제시한다.
연결: 같은 색·좌표계 또는 데이터 조합을 다음 씬에서 유지.

## 화면 텍스트·조건
긴 설명은 하단 전체 문장 자막에 둔다. 전압·숫자·LOW/HIGH·경우의 수는 중심 화면에 표시한다. 초기 전압 대응은 가상 규칙이다. 0과 1이라는 논리 기호는 조합 소개 이전에 표시하지 않는다. LOW/HIGH 사이에는 판정 보장 밖의 구간을 유지한다. 0/1은 정확한 0V/1V라는 뜻이 아니다. 실제 소자 규격·잡음 내성의 실측을 주장하지 않는다. 마지막 질문은 사용자 확정 대본과 콘티의 명시적 요청에 따라 유지한다.

## 원문
전기를 이용해 정보를 전달하고, 계산하는 장치를 만든다고 생각해 보겠습니다.

가장 먼저 필요한 것은 정보를 표현하는 방법입니다.

전기는 전압이라는 물리량을 가지고 있고, 이 전압은 연속적인 값을 가질 수 있습니다.

# 04 · 두 논리 상태의 발견

## 목적과 주장
같은 전압 범위에서 상태 간격을 넓혀 변동 여유를 확보한다.

## TTS와 확정 길이
사용자 문장 종료 시각 기준 42–61초, 19초. 음원 미제공으로 현재 무음. 원문은 script.txt, 문장별 경계는 ../../timing.json.

## 화면과 타임라인
사용자 콘티 ../../storyboard_reference.md의 SCENE 04를 기준으로 한다. 상세 이벤트는 ../../scene_engine.py의 binary 메서드에 구현한다. 자막은 사용자 문장별 시간 그대로 표시한다.

| 전체 시각(초) | 화면 변화 |
| --- | --- |
| 42–44 | 다수준 기준선과 잡음 상태를 관찰 |
| 44–50 | 촘촘한 상태 표시를 약화하고 두 기준 수준으로 정리 |
| 50–53 | 두 유효 영역과 중간의 판정 보장 밖 구간 |
| 53–55 | LOW·HIGH 명명 |
| 55–61 | 같은 크기의 변동에도 LOW 범위 안에서 판정 유지 |

## 시작·종료 상태와 연결
시작: 잡음과 오인식에서 도달한 개념.
종료: 같은 전압 범위에서 상태 간격을 넓혀 변동 여유를 확보한다.
연결: 같은 색·좌표계 또는 데이터 조합을 다음 씬에서 유지.

## 화면 텍스트·조건
긴 설명은 하단 전체 문장 자막에 둔다. 전압·숫자·LOW/HIGH·경우의 수는 중심 화면에 표시한다. 초기 전압 대응은 가상 규칙이다. 0과 1이라는 논리 기호는 조합 소개 이전에 표시하지 않는다. LOW/HIGH 사이에는 판정 보장 밖의 구간을 유지한다. 0/1은 정확한 0V/1V라는 뜻이 아니다. 실제 소자 규격·잡음 내성의 실측을 주장하지 않는다. 마지막 질문은 사용자 확정 대본과 콘티의 명시적 요청에 따라 유지한다.

## 원문
이 문제를 해결하려면 어떻게 해야 할까요?

전압을 더욱 정밀하게 측정할 수도 있겠지만, 반대로 구분해야 하는 상태의 개수를 줄일 수도 있습니다.

예를 들어 전압을 크게 두 영역으로 나누는 것입니다.

낮은 전압과 높은 전압.

이렇게 하면 전압에 작은 변화가 발생하더라도 동일한 상태로 해석할 수 있는 여유가 생깁니다.

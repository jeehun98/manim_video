# 02 · 전압에 의미 부여

## 목적과 주장
전압과 숫자의 대응은 정한 해석 규칙이다.

## TTS와 확정 길이
사용자 문장 종료 시각 기준 12–28초, 16초. 음원 미제공으로 현재 무음. 원문은 script.txt, 문장별 경계는 ../../timing.json.

## 화면과 타임라인
사용자 콘티 ../../storyboard_reference.md의 SCENE 02를 기준으로 한다. 상세 이벤트는 ../../scene_engine.py의 levels 메서드에 구현한다. 자막은 사용자 문장별 시간 그대로 표시한다.

| 전체 시각(초) | 화면 변화 |
| --- | --- |
| 12–16 | 0.1V→1, 0.2V→2, 0.3V→3의 가상 대응을 순차 제시 |
| 16–23 | 한 전압 신호가 세 수준을 이동하며 대응 카드 강조 |
| 23–28 | 0.05V·0.35V 수준을 추가해 표현 상태 수 확대 |

## 시작·종료 상태와 연결
시작: 전기 신호와 전압에서 도달한 개념.
종료: 전압과 숫자의 대응은 정한 해석 규칙이다.
연결: 같은 색·좌표계 또는 데이터 조합을 다음 씬에서 유지.

## 화면 텍스트·조건
긴 설명은 하단 전체 문장 자막에 둔다. 전압·숫자·LOW/HIGH·경우의 수는 중심 화면에 표시한다. 초기 전압 대응은 가상 규칙이다. 0과 1이라는 논리 기호는 조합 소개 이전에 표시하지 않는다. LOW/HIGH 사이에는 판정 보장 밖의 구간을 유지한다. 0/1은 정확한 0V/1V라는 뜻이 아니다. 실제 소자 규격·잡음 내성의 실측을 주장하지 않는다. 마지막 질문은 사용자 확정 대본과 콘티의 명시적 요청에 따라 유지한다.

## 원문
그렇다면 전압의 크기에 서로 다른 의미를 부여하면 어떨까요?

예를 들어 0.1볼트는 1, 0.2볼트는 2, 0.3볼트는 3을 나타내도록 정하는 것입니다.

이론적으로는 더 많은 전압 수준을 구분할수록 하나의 신호로 더 많은 정보를 표현할 수 있습니다.

# 07 · 비트의 도입

## 목적과 주장
두 논리 상태를 조합하는 이진 정보 표현에 도달한다.

## TTS와 확정 길이
사용자 문장 종료 시각 기준 81–98초, 17초. 음원 미제공으로 현재 무음. 원문은 script.txt, 문장별 경계는 ../../timing.json.

## 화면과 타임라인
사용자 콘티 ../../storyboard_reference.md의 SCENE 07를 기준으로 한다. 상세 이벤트는 ../../scene_engine.py의 bit 메서드에 구현한다. 자막은 사용자 문장별 시간 그대로 표시한다.

| 전체 시각(초) | 화면 변화 |
| --- | --- |
| 81–85 | LOW·HIGH를 논리 기호 0·1에 대응 |
| 85–88 | Binary Digit를 Bit으로 축약·정보 단위 정의 |
| 88–95 | 촘촘한 한 신호와 두 상태의 여러 신호 비교 |
| 95–98 | 적은 상태×여러 신호=다양한 정보 표현으로 정리 |

## 시작·종료 상태와 연결
시작: 신호 조합 확장에서 도달한 개념.
종료: 두 논리 상태를 조합하는 이진 정보 표현에 도달한다.
연결: 같은 색·좌표계 또는 데이터 조합을 다음 씬에서 유지.

## 화면 텍스트·조건
긴 설명은 하단 전체 문장 자막에 둔다. 전압·숫자·LOW/HIGH·경우의 수는 중심 화면에 표시한다. 초기 전압 대응은 가상 규칙이다. 0과 1이라는 논리 기호는 조합 소개 이전에 표시하지 않는다. LOW/HIGH 사이에는 판정 보장 밖의 구간을 유지한다. 0/1은 정확한 0V/1V라는 뜻이 아니다. 실제 소자 규격·잡음 내성의 실측을 주장하지 않는다. 마지막 질문은 사용자 확정 대본과 콘티의 명시적 요청에 따라 유지한다.

## 원문
이제 이 두 상태를 각각 0과 1이라고 부르고, 하나의 상태를 나타내는 단위를 비트라고 정의해 보겠습니다.

우리는 연속적인 전압을 정밀하게 구분하는 대신, 구별하기 쉬운 두 상태를 여러 개 조합해 정보를 표현하는 방법을 얻었습니다.

이것이 이진 디지털 표현의 기본적인 아이디어입니다.

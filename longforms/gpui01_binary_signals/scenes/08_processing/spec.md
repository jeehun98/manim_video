# 08 · 표현에서 계산으로

## 목적과 주장
표현과 입력을 변환하는 회로의 역할을 구별한다.

## TTS와 확정 길이
사용자 문장 종료 시각 기준 98–113초, 15초. 음원 미제공으로 현재 무음. 원문은 script.txt, 문장별 경계는 ../../timing.json.

## 화면과 타임라인
사용자 콘티 ../../storyboard_reference.md의 SCENE 08를 기준으로 한다. 상세 이벤트는 ../../scene_engine.py의 processing 메서드에 구현한다. 자막은 사용자 문장별 시간 그대로 표시한다.

| 전체 시각(초) | 화면 변화 |
| --- | --- |
| 98–102 | 0101 비트 배열을 유지 |
| 102–108 | 입력 배열이 미지의 처리 장치로 이동 |
| 108–112.4 | 처리 장치의 물음표 강조 |
| 112.4–113 | 주요 도형을 암전하며 종료 |

## 시작·종료 상태와 연결
시작: 비트의 도입에서 도달한 개념.
종료: 표현과 입력을 변환하는 회로의 역할을 구별한다.
연결: 완성된 표현 체계에서 입력을 변환하는 미지의 장치로 시선 이동.

## 화면 텍스트·조건
긴 설명은 하단 전체 문장 자막에 둔다. 전압·숫자·LOW/HIGH·경우의 수는 중심 화면에 표시한다. 초기 전압 대응은 가상 규칙이다. 0과 1이라는 논리 기호는 조합 소개 이전에 표시하지 않는다. LOW/HIGH 사이에는 판정 보장 밖의 구간을 유지한다. 0/1은 정확한 0V/1V라는 뜻이 아니다. 실제 소자 규격·잡음 내성의 실측을 주장하지 않는다. 마지막 질문은 사용자 확정 대본과 콘티의 명시적 요청에 따라 유지한다.

# 05 · 표현력의 한계

## 목적과 주장
한 신호가 표현하는 상태 수를 줄이는 대가가 있다.

## TTS와 확정 길이
사용자 문장 종료 시각 기준 61–66초, 5초. 음원 미제공으로 현재 무음. 원문은 script.txt, 문장별 경계는 ../../timing.json.

## 화면과 타임라인
사용자 콘티 ../../storyboard_reference.md의 SCENE 05를 기준으로 한다. 상세 이벤트는 ../../scene_engine.py의 tradeoff 메서드에 구현한다. 자막은 사용자 문장별 시간 그대로 표시한다.

| 전체 시각(초) | 화면 변화 |
| --- | --- |
| 61–62 | 넓은 두 유효 영역 유지 |
| 62–66 | 중간 상태 추가 시도 후 한 신호·두 상태의 대가 표시 |

## 시작·종료 상태와 연결
시작: 두 논리 상태의 발견에서 도달한 개념.
종료: 한 신호가 표현하는 상태 수를 줄이는 대가가 있다.
연결: 같은 색·좌표계 또는 데이터 조합을 다음 씬에서 유지.

## 화면 텍스트·조건
긴 설명은 하단 전체 문장 자막에 둔다. 전압·숫자·LOW/HIGH·경우의 수는 중심 화면에 표시한다. 초기 전압 대응은 가상 규칙이다. 0과 1이라는 논리 기호는 조합 소개 이전에 표시하지 않는다. LOW/HIGH 사이에는 판정 보장 밖의 구간을 유지한다. 0/1은 정확한 0V/1V라는 뜻이 아니다. 실제 소자 규격·잡음 내성의 실측을 주장하지 않는다. 마지막 질문은 사용자 확정 대본과 콘티의 명시적 요청에 따라 유지한다.

## 원문
물론 여기에는 대가가 있습니다.

하나의 신호로는 단 두 가지 상태밖에 표현할 수 없다는 것입니다.

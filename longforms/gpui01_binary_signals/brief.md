# 제작 기준 — GPU 개론 01

- 제목: 컴퓨터는 왜 0과 1을 사용할까?
- 사용자 확정 대본 26문장과 문장 종료 시각을 사용한다. 길이 113초. 추정 타이밍 없음.
- 첨부 콘티 원문은 storyboard_reference.md에 보존한다. 8개 씬은 각각 독립적으로 렌더·교체한다.
- 가로 1920×1080 / 세로 1080×1920, 30fps. 미리보기는 640×360 / 360×640, 15fps.
- 원문과 전체 문장 자막은 사용자 표기를 유지한다. 한국어 발음 표기는 tts_script.txt에만 둔다.
- 음원 미제공: 두 결과물 모두 무음, 전체 문장 자막을 영상에 포함하고 SRT도 별도 제공한다.
- 연속 전압 → 가상의 다수준 대응 → 경계 초과 오류 → 두 유효 상태 → 독립 신호 조합 → Bit → 미지의 처리 장치 순서.
- 처음에는 정답을 노출하지 않는다. 66초 이전에는 논리 기호 0/1을 표시하지 않는다. 초기 제목도 ‘0과 1’을 선공개하지 않는다.
- 잡음은 기준 값 0.20V에서 0.15V 경계 아래의 0.13V로 이동해 판정이 2→1로 바뀌는 설명 모형이다. 파형 변동과 실제 오인식 시점을 구별한다.
- 전압 그래프 범위는 0–0.4V로 고정한다. 이진 예시는 LOW 유효 범위 0–0.18V, HIGH 0.26–0.4V이며 중간은 판정을 보장하지 않는 구간이다. 특정 반도체 제품의 표준 규격이 아니다.
- 이진 기준점 0.10V와 0.30V의 구분을 보여준다. 잡음 진폭이 크면 이진 신호도 오류 가능하다고 표시한다. 실제 논리 소자의 출력 보장값을 사용한 엄밀한 noise margin 측정은 아니다.
- 조합 확대는 모든 기존 조합을 두 갈래로 복제한다. 1–4개 독립 신호에 대해 2·4·8·16개 조합을 전부 표시한다.
- 대본은 그대로 유지하고, Bit의 화면 정의는 ‘두 상태 중 하나를 나타내는 정보의 단위’로 명확히 한다. 0/1과 0V/1V를 동일시하지 않는다.
- 마지막 질문은 이번 사용자 대본과 첨부 콘티에 명시적으로 포함되어 있으므로 유지한다. 트랜지스터·게이트를 미리 보여주지 않는다.
- 자막 겹침 수정: 문장별 객체를 겹쳐 두지 않고 초기화된 Text 객체 하나만 교체한다. 사용자 문장 경계에서 즉시 교체하고 자막 Fade는 사용하지 않는다. 별도 SRT는 자동 이중 표시를 방지하도록 `_captions.srt` 파일명으로 제공한다. `inspect_caption_boundaries.py`로 모든 경계의 전·해당·후 프레임을 검수한다.

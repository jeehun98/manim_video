# **Scene 01. 확률밀도함수에서 넓이가 가지는 의미**

00:00\~00:21 · 21초

### **00:00\~00:05 | 3장의 마지막 화면에서 시작**

나래이션:\
*앞서 우리는 가우스 함수 아래의 전체 넓이가 원주율의 제곱근과 같다는 사실을 발견했습니다.*

3장의 마지막 프레임을 그대로 사용합니다.

화면 중앙에는 가우스 함수와 초록색으로 채워진 적분 영역이 존재합니다.

\\[ f(x)=e^{-x^2} \\]

\\[ \int\_{-\infty}^{\infty}e^{-x^2}\\,dx=\sqrt{\pi} \\]

상단의 챕터 번호와 제목만 변경하고, 이전 장에서 이미 유도했던 가우스 적분을 다시 계산하지 않습니다.

### **00:05\~00:10 | 확률분포의 조건**

나래이션:\
*그런데 이 함수를 확률을 표현하는 데 사용하려면 한 가지 조건을 만족해야 합니다.*

기존 가우스 함수를 화면 왼쪽으로 이동시키고 오른쪽에 확률밀도함수의 조건을 등장시킵니다.

\\[ p(x)\geq0 \\]

\\[ \int\_{-\infty}^{\infty}p(x)\\,dx=1 \\]

현재 가우스 함수는 음이 아닌 함수라는 조건을 만족하지만, 전체 넓이가 1이라는 조건은 아직 만족하지 않습니다.

### **00:10\~00:17 | 특정 구간의 넓이는 확률이다**

나래이션:\
*연속적인 확률분포에서는 특정 구간에 해당하는 곡선 아래의 넓이가, 그 구간에 값이 존재할 확률을 의미합니다.*

이 부분에서는 설명용으로 이미 정규화된 확률밀도함수를 별도로 등장시킵니다.

확률을 계산하는 구간

\\([-1.0,\\;1.0]\\)

\\[ P(-1.0\leq X\leq 1.0)\approx0.8427 \\]

Manim에서는 먼저 임의의 구간 \\([a,b]\\)을 설정하고 해당 영역만 파란색으로 채웁니다.

\\[ P(a\leq X\leq b) =\int_a^b p(x)\\,dx \\]

구간의 양 끝을 움직이면 채워진 영역이 변화하고, 확률값 역시 변화하도록 구현합니다.

여기서 함수의 특정 지점의 **높이 자체가 확률인 것은 아니라는 점**을 시각적으로 전달해야 합니다.

### **00:17\~00:21 | 전체 확률은 1**

나래이션:\
*따라서 가능한 모든 구간의 넓이를 더하면 반드시 1이 되어야 합니다.*

확률을 계산하는 구간을 양쪽으로 확장합니다.

\\[ [a,b]\longrightarrow(-\infty,\infty) \\]

전체 영역이 채워지면서 다음 수식이 등장합니다.

\\[ \boxed{P(-\infty\<X<\infty)=1} \\]

실제 영상에서는 그래프의 양쪽 꼬리가 화면 밖으로 이어지는 방향을 표시하여 유한한 화면 범위가 전체 정의역은 아니라는 점을 유지합니다.

# **Scene 02. 함수의 넓이를 1로 조정하다**

### **00:21\~00:25 | 기존 가우스 함수의 문제**

나래이션:\
*하지만 현재 가우스 함수의 전체 넓이는 1이 아닙니다.*

설명용 확률밀도함수를 제거하고, 3장에서 계산했던 원래 가우스 함수를 다시 강조합니다.

\\[ \int\_{-\infty}^{\infty}e^{-x^2}\\,dx =\sqrt{\pi}\approx1.77245 \\]

화면 오른쪽에 전체 확률의 조건과 비교합니다.

\\[ \sqrt{\pi}\neq1 \\]

### **00:25\~00:30 | 모든 높이를 넓이로 나누기**

나래이션:\
*그렇다면 함수의 모든 높이를 기존 넓이로 나누어 보면 어떨까요?*

기존 함수에 새로운 곱셈 계수를 추가합니다.

\\[ e^{-x^2} \longrightarrow \frac{1}{\sqrt{\pi}}e^{-x^2} \\]

계수 \\(1/\sqrt{\pi}\\)를 노란색으로 강조합니다.

그래프 위에 여러 개의 수직선들을 배치한 뒤, 모든 수직선이 동일한 비율로 짧아지는 모습을 보여줍니다.

### **00:30\~00:35 | 넓이의 변화**

원래 함수

정규화 완료

함수의 높이 배율

# **0.7385**

# **1.3090**

나래이션:\
*곡선의 전체적인 형태는 유지하면서, 전체 넓이를 정확히 1로 만들 수 있습니다.*

가로축은 그대로 유지하고, 세로 방향의 크기만 감소시킵니다.

기존 곡선을 회색 점선으로 남겨두면 정규화 전후의 차이가 명확하게 전달됩니다.

### **00:35\~00:40 | 정규화의 이름**

나래이션:\
*이렇게 함수의 전체 적분값을 1로 조정하는 과정을 확률분포의 정규화라고 부릅니다.*

구체적인 가우스 함수에서 일반적인 관계로 확장합니다.

\\[ Z=\int f(x)\\,dx \\]

\\[ \boxed{p(x)=\frac{f(x)}{Z}} \\]

단, \\(f(x)\geq0\\)이고 전체 적분값 \\(Z\\)가 유한한 양수인 경우입니다.

화면 하단에 개념명을 표시합니다.

**Normalization — 전체 적분값을 1로 조정**

### **00:40\~00:47 | 이전 장에서 계산했던 값의 활용**

나래이션:\
*앞서 계산한 가우스 함수의 적분값이, 이제는 확률분포를 구성하기 위한 정규화 상수로 활용되는 것입니다.*

\\[ p(x)= \frac{e^{-x^2}}{\underbrace{\sqrt{\pi}}\_{\text{정규화 상수}}} \\]

분모의 \\(\sqrt{\pi}\\)에 `Brace`를 적용합니다.

이어서 실제 전체 적분값을 확인합니다.

\\[ \int\_{-\infty}^\infty p(x)\\,dx =\frac{\sqrt{\pi}}{\sqrt{\pi}}=1 \\]

3장에서 수행했던 긴 가우스 적분 계산이 이제는 하나의 정규화 상수로 사용된다는 점을 강조합니다.

### **00:47\~00:51 | 감마함수로의 연결**

나래이션:\
*그렇다면 감마함수의 적분 표현도 이와 비슷하게 활용할 수 있지 않을까요?*

지금까지 살펴본 정규화 상수

\\[ \int\_{-\infty}^{\infty}e^{-x^2}\\,dx=\color{#F6C85F}{\sqrt{\pi}} \\]

2장에서 구성했던 적분

\\[ \int_0^\infty t^{\alpha-1}e^{-t}\\,dt=\color{#F6C85F}{\Gamma(\alpha)} \\]

# **Scene 04. 첫 번째 사건의 대기 시간**

가능하다면 여러 번의 도착 시뮬레이션에서 첫 번째 대기 시간을 기록하고, 히스토그램을 형성한 뒤 이론적인 지수분포 곡선을 겹쳐 표시합니다.

### **03:29\~03:38 | 전체 넓이를 계산하고 조정하는 도구**

나래이션:\
*연속적으로 변화하는 함수의 전체 넓이를 계산하고, 그것을 확률이라는 공통된 기준으로 조정할 수 있도록 만들어 주는 수학적 도구이기도 합니다.*

감마함수의 적분 정의를 화면 중앙에 배치합니다.

\\[ \Gamma(\alpha) =\int_0^\infty t^{\alpha-1}e^{-t}\\,dt \\]

위쪽에는 정규화되지 않은 함수, 아래쪽에는 정규화된 함수를 등장시킵니다.

\\[ t^{\alpha-1}e^{-t} \\]

\\[ \Downarrow\quad\div\Gamma(\alpha) \\]

\\[ \frac{t^{\alpha-1}e^{-t}}{\Gamma(\alpha)} \\]

하단 문구:

**함수의 형태는 유지하고, 전체 넓이는 1로 조정한다.**

| 항목             | 주의할 표현                               |
| -------------- | ------------------------------------ |
| 확률과 확률밀도       | 함수의 높이가 아니라 구간의 적분값이 확률              |
| 확률분포의 전체 넓이    | 서로 겹치지 않는 전체 영역에 대한 적분값이 1           |
| 단위 시간당 발생률 1   | 일정한 간격으로 발생한다는 뜻이 아님                 |
| 첫 번째 사건까지      | 지수분포                                 |
| \\(n\\)번째 사건까지 | \\(n\\)개의 독립적인 지수 대기 시간의 합           |
| 감마함수의 입력       | 거듭제곱의 지수보다 1만큼 큰 값                   |
| 감마분포의 실수 매개변수  | \\(\alpha>0\\)                       |
| 분수 단위의 사건      | 실수 형태 매개변수가 실제 사건의 분수 단위 발생을 의미하지 않음 |
| 정규화 이전의 함수     | 전체 적분값이 1이 아니면 확률밀도함수가 아님            |
| 유한 범위의 그래프     | 화면에 표시된 넓이는 무한 구간 적분의 일부             |

현재 나래이션에서는 발생률을 1로 고정했으므로 대부분의 화면에서 다음 형태만 사용하면 됩니다.

\\[ p(t;\alpha)= \frac{t^{\alpha-1}e^{-t}}{\Gamma(\alpha)} \\]

일반적인 감마분포는 발생률 매개변수 \\(\beta\\)를 포함합니다.

\\[ p(t;\alpha,\beta)= \frac{\beta^\alpha}{\Gamma(\alpha)} t^{\alpha-1}e^{-\beta t} \\]

이번 장에서는 감마함수의 역할을 중심으로 설명하기 때문에 \\(\beta\\)에 대한 별도의 설명과 애니메이션은 제외했습니다.

또한 두 번째 사건의 대기 시간 분포가 나타나는 이유를 보충하기 위해 합성곱 시각화를 추가했습니다. 원래 나래이션에는 없는 설명이므로 99\~105초 구간에서 수식을 과도하게 전개하지 않도록 주의합니다.

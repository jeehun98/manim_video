# 제작 기준 — 자연의 최적화 01

목표: 분자 상호작용의 직관에서 표면 자유에너지와 경계 조건을 거쳐, 국소 힘의 평형과 면적의 첫 변분을 연결한다.

사용자 확정 대본·문장 종료 시각 0~174초를 따른다. 본 작업은 해당 대본으로 영상 제작을 요청받은 단계다. 음원은 제공되지 않았다.

시각: 어두운 남색 배경, 청록 반투명 실제 3D 곡면, 은색 고리, 파란 분자, 금색 상호작용과 선택 패치, 초록 평형. 실제 표면과 공간 관계는 3D, 공식과 주석은 카메라에 고정한 2D 오버레이다.

핵심 효과: 동일 경계의 원기둥·중간 후보·카테노이드와 적분 면적 비교 / 국소 패치 접평면에서 작용하는 경계 장력 / 경계 보존 변형의 실제 면적 그래프와 수평 접선.

두 화면비에서 제목·3D 대상·공식·자막 영역을 분리한다. 자막은 원문 표기와 시각을 유지한다. 실제 시간 변화와 ε 변형의 비교를 구분한다. 자연이 후보를 모두 계산하거나 항상 전역 최소에 도달한다고 설명하지 않는다.

마지막은 비눗막의 결론으로 독립 완결한다. 원문 마지막 문장은 보존하며 다음 현상의 시각적 예고는 넣지 않는다.

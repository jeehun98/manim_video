# Scene 04 — 작게 볼수록 하나의 곱셈에 가까워진다

## 목적과 핵심 주장
정규화된 실제 출력은 미분의 선형 근사에 가까워진다.

## 앞 장면에서 받은 내용
비균일 확대는 복소수 곱셈과 다르다.

## TTS 원문과 확정 길이
- 사용자 제공 종료 시각: 61–81초, 20초. 음원 미제공, 무음.

복소미분이 가능하다는 것은 한 점 주변의 작은 변화를 이러한 하나의 곱셈으로 근사할 수 있다는 뜻입니다.

따라서 미분값이 0이 아닌 점 주변에서는, 원을 작게 그릴수록 변형된 모습도 회전하고 크기만 달라진 원에 가까워집니다.

각 점 주변에서 방향마다 서로 다른 확대 비율을 적용하는 변형은 허용되지 않는 것입니다.

## 정확성
- 복소평면 양 축 단위 동일. f(z)=z², w=1+i.
- 국소 확대는 실제 곡선과 선형 근사를 동일 추가 배율로 비교.

- 분할은 구르사 논증의 직관이며 단순 분할만으로 오차가 사라진다고 주장하지 않음.

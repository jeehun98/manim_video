# 복소평면에 숨겨진 기하학 — 구간 01

사용자 확정 203초, 38개 문장 종료 시각, 11개 독립 씬. 1920×1080, 30fps. 음원 미제공: 전체 자막 포함 무음. 이후 구간과 결합할 독립 파트이며 엔드카드 없음.

- 최종 렌더·조립·검증: `python longforms/complex_geometry_01/build.py`
- 대표 씬: `python longforms/complex_geometry_01/build.py --preview --scene 04 09 10 11`
- 결과: `exports/complex_geometry_01.mp4`
- 전체 자막: `captions.srt`, 원고: `master_script.md`, 시각: `timing.json`, 씬별 제작 기준: `scenes/*/spec.md`.
- 공통 자막·정확한 프레임 타이밍은 longforms/qcs01_speed의 기존 도구를 재사용.
- Atlas 검색은 기존 sources.json 누락으로 불가. 외부 수학 참고는 storyboard와 씬 spec에 기록.
- 원본 참고 이미지 15장은 references/에 제공 순서대로 보존. 디자인·움직임 참고이며 렌더에는 수학적 좌표로 재구성한 벡터를 사용.

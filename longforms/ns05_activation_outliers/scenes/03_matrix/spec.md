## TTS 원문과 확정 길이
신경망은 입력을 처리하면서 각 층에서 숫자들을 만들어냅니다.

어떤 층의 표현을, 토큰마다 한 줄씩 나열해 보겠습니다.

행은 토큰이고, 열은 특징 차원입니다.

한 칸은 특정 토큰의 특정 차원에 있는 활성값입니다.

이제 공간의 속도 화살표 대신, 이 숫자들의 분포를 살펴보겠습니다.

- TTS: 사용자 측정 18초
- 화면: 18초. 원래 화면 기준은 30초.
## 화면 구성과 시간대별 애니메이션
속도장 → 토큰 행/특징 열 행렬 → 한 칸 확대 → 색으로 값 표현
문장 순서대로 timing.json의 ends에 맞춰 cue를 진행한다.
## 화면 텍스트
토큰과 특징 차원에 숫자를 놓다, 영역·속도, 활성 행렬, 양자화 눈금과 복원값, 연구 출처, 문장 자막. 영문과 숫자 기호는 화면에 원 표기를 쓴다.

## 수학 조건·과장 방지
X는 T×D 행렬, 배치 생략. 특징 차원 하나가 사람에게 해석 가능한 의미 하나와 반드시 대응한다고 하지 않는다. 숫자들은 설명용이다.
모든 단순 모형과 개념도는 실제 NS 해나 신경망의 측정값이 아니다. 실제 해의 정확한 항 수치를 시뮬레이션하지 않는다. 유한 활성 행렬의 이상치를 유체 특이점과 동일시하지 않는다.

# Scene 07 — 큰 값 하나가, 다른 값의 차이를 지운다
## 목적과 핵심 주장
큰 값 하나가, 다른 값의 차이를 지운다를 한 장면에서 이해시킨다.
## 앞 장면에서 받은 내용
숫자를, 정해진 눈금에 올리다
## TTS 원문과 확정 길이
최대 절댓값이 일일 때와, 백일 때를 비교하겠습니다.

같은 정수 범위로 백까지 담으려면, 눈금 간격이 백 배 넓어집니다.

영 점 일과 영 점 이는 모두 영으로 바뀝니다. 영 점 사와 영 점 팔도 같은 정수로 바뀝니다.

큰 값 하나를 표현하는 과정에서, 원래 다른 작은 값들의 차이가 사라진 것입니다.

이 현상은 같은 눈금을 공유할 때의 예시입니다. 양자화 묶음과 방법이 달라지면 영향도 달라집니다.

- TTS: 사용자 측정 25초
- 화면: 25초. 원래 화면 기준은 38초.
## 화면 구성과 시간대별 애니메이션
M1/100 비교 → 국소 눈금 .007874/.787402 → 정확한 반올림 복원 표 → q0/1 합침 강조
문장 순서대로 timing.json의 ends에 맞춰 cue를 진행한다.
## 화면 텍스트
큰 값 하나가, 다른 값의 차이를 지운다, 영역·속도, 활성 행렬, 양자화 눈금과 복원값, 연구 출처, 문장 자막. 영문과 숫자 기호는 화면에 원 표기를 쓴다.
## 시작·종료 상태
첫 대상에서 마지막 대상으로 연속 변형한다. 상단 제목과 하단 자막 영역을 확보한다.

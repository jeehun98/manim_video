# 14 · 서로 다른 구조에 남는 핵심

## 목적·핵심 주장

규모를 바꾸어도 남는 핵심 구조가 보편성을 설명한다

## 앞 장면에서 받은 내용

거시 임계 법칙에 모든 미시적 세부가 필요하지는 않다

## 확정 발화

149–160초, 11초. 사용자 종료 시각 기준. 음원 미제공으로 무음 영상.

서로 다른 물질이 같은 법칙을 따르는 이유는, 처음부터 내부 구조가 같아서가 아닙니다.
규모를 바꾸어 바라보았을 때, 서로 다른 구조에서 동일한 핵심적인 성질이 남을 수 있기 때문입니다.

## 화면과 애니메이션

- 149–154초: 서로 다른 물질이 같은 법칙을 따르는 이유는, 처음부터 내부 구조가 같아서가 아닙니다.
- 154–160초: 규모를 바꾸어 바라보았을 때, 서로 다른 구조에서 동일한 핵심적인 성질이 남을 수 있기 때문입니다.

입자 도식·실제 Ising 표본·블록화·유효 이론 흐름을 구분. 청록 ↑, 분홍 ↓, 노랑 블록과 법칙, 보라 고정점. 세로와 가로 각각 배치.

## 시작·종료 상태와 연결

첫 문장의 대상을 받아 마지막 문장의 주장으로 완료. 공통 색과 격자/고정점 도식 유지. 복습·다음 편 예고 없음.

## 정확성

2D Ising 유한 격자는 설명용이며 3D 유체/자석의 수치 임계 지수 측정이 아님. 동률은 고정 시드의 공정 ±1 추첨. RG는 (r,g)→(2r,g/2)의 고정점 근방 개념 모형이며 Ising 결합상수 실측값이 아님. 임계면 r=0 위 접근과 r≠0 이탈을 구분. 같은 지수와 서로 다른 진폭을 구분.

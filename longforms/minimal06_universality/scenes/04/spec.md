# 04 · 작은 자석들이 만든 격자

## 목적·핵심 주장

2D Ising은 두 방향 스핀과 이웃 상호작용의 설명 모형이다

## 앞 장면에서 받은 내용

같은 보편성 부류의 임계 지수는 같을 수 있다

## 확정 발화

38–48초, 10초. 사용자 종료 시각 기준. 음원 미제공으로 무음 영상.

이번에는 작은 자석들이 격자 위에 배열되어 있다고 생각해 보겠습니다.
각 자석은 위쪽 또는 아래쪽을 향하고, 이웃한 자석들은 서로 영향을 주고받습니다.

## 화면과 애니메이션

- 38–42초: 이번에는 작은 자석들이 격자 위에 배열되어 있다고 생각해 보겠습니다.
- 42–48초: 각 자석은 위쪽 또는 아래쪽을 향하고, 이웃한 자석들은 서로 영향을 주고받습니다.

입자 도식·실제 Ising 표본·블록화·유효 이론 흐름을 구분. 청록 ↑, 분홍 ↓, 노랑 블록과 법칙, 보라 고정점. 세로와 가로 각각 배치.

## 시작·종료 상태와 연결

첫 문장의 대상을 받아 마지막 문장의 주장으로 완료. 공통 색과 격자/고정점 도식 유지. 복습·다음 편 예고 없음.

## 정확성

2D Ising 유한 격자는 설명용이며 3D 유체/자석의 수치 임계 지수 측정이 아님. 동률은 고정 시드의 공정 ±1 추첨. RG는 (r,g)→(2r,g/2)의 고정점 근방 개념 모형이며 Ising 결합상수 실측값이 아님. 임계면 r=0 위 접근과 r≠0 이탈을 구분. 같은 지수와 서로 다른 진폭을 구분.

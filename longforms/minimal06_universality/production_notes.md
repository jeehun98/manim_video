# 제작 기록

- 템플릿을 복사한 뒤 확정 대본·33개 발화 시각·14개 씬별spec을 먼저 작성.
- Wolff 표본과 블록 스핀은 실제 계산. RG흐름과 유체·스케일링 그림은 개념도.
- 블록 동률 ±1 공정 추첨 재현,5000회 시험에서 위쪽 비율0.4998.
- 임계면 r=0의 접근과 관련 방향 r≠0의 이탈을 함께 표현.
- 2D 설명 모형과 실제 물질의 임계 지수 비교를 구분하며 물질의 수치 지수는 표시하지 않음.
- 최종 concat 이후 한 ASS 트랙으로 자막 합성. 음성 없음.

## 완료 검증

- 세로1080×1920·가로1920×1080, 각160.000초·30fps·4,800프레임.
- 최종본 두 개의 전체 FFmpeg 디코딩 통과.
- 각33개 문장 경계 전후99프레임, 총198프레임의 자막 검사 통과. 최저 마스크 일치도 세로0.97819·가로0.97428.
- 각20개 주요 시점의 화면과 반복 블록화의 전환을 육안 확인.
- 반복 블록화는 축소·교체·재척도화로 전환하고, 상호작용 표기는 단계별로 선명하게 교체. 고정점 편차와 관련 방향의 뜻을 추가 표시. 수정 씬 재렌더 후 concat 및 최종 검증 완료.
- 최종본에서 다시 생성한 미리보기: 세로360×640·가로854×480, 각160초·15fps·2,400프레임.
- 두 영상 모두 서술 자막 포함 무음. TTS 원고와SRT 별도 제공.

# 알고 싶은 것은 공장의 평균

- 확정 구간: 7–19초 (12초), 사용자 제공 발화 종료 시각 기준.
- 주장: 독립·동일 정규분포와 알려진 분산을 가정한다
- 화면: 관측값은 고정하고 후보 평균만 이동. 두 레이아웃 각각 배치.
- 보존 조건: n 고정, 독립·동일 정규분포, 알려진 같은 분산. 분산 미지 구간은 가정을 명시적으로 변경.
- 자막: 최종 concat 이후 단일 ASS 트랙, 인접 이벤트 겹침 없음.

우리가 알고 싶은 것은 개별 부품의 길이가 아니라, 이 공장에서 생산되는 부품의 평균 길이입니다.
측정값이 서로 독립이고, 같은 정규분포를 따르며, 분산은 이미 알려져 있다고 가정하겠습니다.

# 평균 후보에서 데이터까지의 거리

- 확정 구간: 62–74초 (12초), 사용자 제공 발화 종료 시각 기준.
- 주장: 알려진 동일 분산에서는 제곱거리 합이 작을수록 더 그럴듯하다
- 화면: 관측값은 고정하고 후보 평균만 이동. 두 레이아웃 각각 배치.
- 보존 조건: n 고정, 독립·동일 정규분포, 알려진 같은 분산. 분산 미지 구간은 가정을 명시적으로 변경.
- 자막: 최종 concat 이후 단일 ASS 트랙, 인접 이벤트 겹침 없음.

정규분포에서는 후보 평균과 각 측정값 사이의 거리를 제곱해 모두 더한 값이 중요합니다.
이 값이 작을수록, 다른 조건이 같다면 해당 평균 후보가 데이터를 더 그럴듯하게 설명합니다.

# 제작 기준

확정 수정 대본과 사용자 문장 종료 시각 158초 준수. 153초 원본은 상위 폴더에 보존. 수식 전개 대신 서로 다른 두 기록과 이동하는 평균 후보로 충분성을 발견한다. A=(1,2,3,4,5), B=(0,0,3,6,6), n=5, 알려진 공통 분산 4. 평균 후보 3에서 점수 10/36, 5에서 30/56. 점수의 차이 26이 일정하므로 후보들의 상대적 지지는 같음. 점수 자체나 원래 우도의 절대값이 같다고 표현하지 않음. 최소충분성은 저장량·계산량 최소와 구분. 복습·다음 편 예고 없음. 음원 미제공으로 무음 영상과 자막·TTS 원고 제작.

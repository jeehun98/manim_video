# 제작 기록

- 153초 이전 버전은 보존. 본 수정본은 새 대본의 158초만 사용.
- 사용자 제공 종료 시각 37개와 15개 독립 씬의 구간을 먼저 고정.
- 후보 평균 이동 실험에서 점수 10/36→30/56과 일정한 차이 26을 강조.
- 상대적 그럴듯함은 같은 데이터에서 후보를 비교한 값이며 확률로 정규화한 사후확률이 아님.
- 최종 concat 이후 단일 ASS 자막 합성. Manim 내부 서술 자막 없음.
- TTS 음원은 제공되지 않아 무음 영상으로 제작.

## 완료 검증

- 세로 1080×1920, 가로 1920×1080, 각각 30fps·158.000초·4,740프레임.
- 미리보기는 최종본에서 축소 생성: 360×640 및 854×480, 15fps·2,370프레임.
- 두 최종본의 전체 FFmpeg 디코딩 오류 없음.
- 각 영상에서 37개 문장 경계 전후 111프레임 검사, 총 222프레임 통과. 자막 마스크 일치도 최저 0.97396 이상.
- 각 레이아웃 20개 주요 시점의 최종본 화면을 콘택트 시트로 육안 확인.
- 후보 평균 3→5에서 점수 10/36→30/56, 차이 26 및 상대 후보 지지 일치 수학 검증 통과.
- 세로 평균 이동 구간의 안내 문구 수정 후 해당 씬 재렌더와 concat 완료.

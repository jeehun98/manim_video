# 02 · 알고 싶은 것은 모집단 평균

## 목적·핵심 주장
모집단 평균 μ는 미지 모수이고 표본평균 x̄와 구별. 독립·동일 정규분포·알려진 분산 조건을 표시.

## 앞 장면과 연결
절대 시각7초에서 시작. 같은 데이터와 모형 조건을 유지하거나 조건 변경을 명시한다.

## TTS 원문·확정 길이
우리가 알고 싶은 것은 개별 부품의 길이가 아니라, 이 공장에서 생산되는 부품의 평균 길이입니다. 측정값이 서로 독립이고, 같은 정규분포를 따르며, 분산은 이미 알려져 있다고 가정하겠습니다.

구간7–19초, 12초. 사용자 발화 시각, 음원 없음.

## 화면·애니메이션
7–13초 길이가 다른 부품과 모집단 평균 μ 질문; 13–19초 독립·정규·분산 알려짐 조건.

scene_engine.py part_01. 세로·가로 별도 배치.

## 화면 텍스트
제목 알고 싶은 것은 모집단 평균. μ와 x̄, 밀도와 우도, 원자료와 통계량을 구별.

## 시작·종료 상태
해당 주장의 대상을 관찰하고 보존되는 정보 또는 모형 조건을 남겨 종료. 다음 편 예고 없음.

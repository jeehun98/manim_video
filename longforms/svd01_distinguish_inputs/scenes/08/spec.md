# 08 — 배율을 줄인다

## 목적과 핵심 주장
입력을 고정하고 행렬의 세로 배율만 줄인다

## 앞 장면에서 받은 내용
입력 거리가 같아도 방향에 따라 출력 차이가 다르다

## TTS 원문과 길이
이제 세로 방향을 더 강하게 압축해보겠습니다.

0.1이었던 배율을 0.01로, 다시 0.001로 줄입니다.

사용자 발화시간: 56–63초, 길이 7초. 음원 미제공.

## 화면·타임라인·텍스트
공통 scene_engine.py의 절대시간 실험 상태 사용. 상세 콘티: ../../storyboard_source.md 장면 08. 입력/출력 축 단위 1.65 동일, 카메라 고정. 자막은 사용자 문장 시각으로 표시.

## 시작·종료 상태
절대시간 56초와 63초의 실험 상태를 독립 재현한다.

## 정확성 조건
A_s=diag(1,s), x_A=(0,0), x_B=(cosθ,sinθ). 출력 B=(cosθ,s sinθ). 0.001 확대는 별도 명시, 본 좌표 척도 불변. 배율 0에서 x좌표가 같은 점들만 겹친다. 115초부터 s=0.1.

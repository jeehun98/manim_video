# 07 — 같은 거리 다른 방향

## 목적과 핵심 주장
입력 거리가 같아도 방향에 따라 출력 차이가 다르다

## 앞 장면에서 받은 내용
세로 입력 거리 1은 출력 거리 0.1이다

## TTS 원문과 길이
두 실험 모두 입력은 같은 거리만큼 달라졌습니다. 그런데 출력에 남은 차이는 10배나 다릅니다.

왜 이런 차이가 생겼을까요?

바뀐 것은 두 입력 사이의 거리가 아니라, 두 입력이 서로 떨어진 방향입니다.

사용자 발화시간: 43–56초, 길이 13초. 음원 미제공.

## 화면·타임라인·텍스트
공통 scene_engine.py의 절대시간 실험 상태 사용. 상세 콘티: ../../storyboard_source.md 장면 07. 입력/출력 축 단위 1.65 동일, 카메라 고정. 자막은 사용자 문장 시각으로 표시.

## 시작·종료 상태
절대시간 43초와 56초의 실험 상태를 독립 재현한다.

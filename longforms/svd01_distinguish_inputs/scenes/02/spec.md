# 02 — 출력만으로 구별할 수 있을까

## 목적과 핵심 주장
출력으로 입력 차이를 추론한다

## 앞 장면에서 받은 내용
관찰자는 입력에 접근할 수 없다

## TTS 원문과 길이
두 입력이 서로 달랐다는 사실을 출력만으로 알아낼 수 있을까요?

사용자 발화시간: 8–11초, 길이 3초. 음원 미제공.

## 화면·타임라인·텍스트
공통 scene_engine.py의 절대시간 실험 상태 사용. 상세 콘티: ../../storyboard_source.md 장면 02. 입력/출력 축 단위 1.65 동일, 카메라 고정. 자막은 사용자 문장 시각으로 표시.

## 시작·종료 상태
절대시간 8초와 11초의 실험 상태를 독립 재현한다.

## 다음 장면 연결

## 정확성 조건
A_s=diag(1,s), x_A=(0,0), x_B=(cosθ,sinθ). 출력 B=(cosθ,s sinθ). 0.001 확대는 별도 명시, 본 좌표 척도 불변. 배율 0에서 x좌표가 같은 점들만 겹친다. 115초부터 s=0.1.

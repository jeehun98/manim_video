# 03 — 실험 공간 공개

## 목적과 핵심 주장
시청자와 관찰자의 접근 범위를 구분한다

## 앞 장면에서 받은 내용
출력으로 입력 차이를 추론한다

## TTS 원문과 길이
먼저 실험을 위해 입력 공간을 공개하겠습니다. 화면 왼쪽에는 실제 입력을, 오른쪽에는 관찰자가 볼 수 있는 출력만 표시합니다.

사용자 발화시간: 11–19초, 길이 8초. 음원 미제공.

## 화면·타임라인·텍스트
공통 scene_engine.py의 절대시간 실험 상태 사용. 상세 콘티: ../../storyboard_source.md 장면 03. 입력/출력 축 단위 1.65 동일, 카메라 고정. 자막은 사용자 문장 시각으로 표시.

## 시작·종료 상태
절대시간 11초와 19초의 실험 상태를 독립 재현한다.

## 다음 장면 연결
같은 실험 화면을 유지하며 다음 주장으로 이동한다. 후속 영상 예고 문구 없음.

## 정확성 조건
A_s=diag(1,s), x_A=(0,0), x_B=(cosθ,sinθ). 출력 B=(cosθ,s sinθ). 0.001 확대는 별도 명시, 본 좌표 척도 불변. 배율 0에서 x좌표가 같은 점들만 겹친다. 115초부터 s=0.1.

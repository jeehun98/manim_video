# 15 — 같은 거리로 방향 탐색

## 목적과 핵심 주장
s=0.1로 복귀해 입력 거리 1을 유지하며 방향만 바꾼다

## 앞 장면에서 받은 내용
입력 차이는 모든 방향에 존재한다

## TTS 원문과 길이
그렇다면 입력 사이의 거리를 똑같이 고정한 채 방향만 바꾸면 어떨까요?

어떤 방향의 차이가 출력에서 가장 크게 나타나고, 어떤 방향의 차이가 가장 작게 나타날까요?

사용자 발화시간: 115–125초, 길이 10초. 음원 미제공.

## 화면·타임라인·텍스트
공통 scene_engine.py의 절대시간 실험 상태 사용. 상세 콘티: ../../storyboard_source.md 장면 15. 입력/출력 축 단위 1.65 동일, 카메라 고정. 자막은 사용자 문장 시각으로 표시.

## 시작·종료 상태
절대시간 115초와 125초의 실험 상태를 독립 재현한다.

## 정확성 조건
A_s=diag(1,s), x_A=(0,0), x_B=(cosθ,sinθ). 출력 B=(cosθ,s sinθ). 0.001 확대는 별도 명시, 본 좌표 척도 불변. 배율 0에서 x좌표가 같은 점들만 겹친다. 115초부터 s=0.1.

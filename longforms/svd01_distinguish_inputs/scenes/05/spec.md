# 05 — 가로 방향 실험

## 목적과 핵심 주장
가로 입력 거리 1은 출력 거리 1이다

## 앞 장면에서 받은 내용
가로는 보존하고 세로는 0.1배 전달한다

## TTS 원문과 길이
첫 번째 실험에서는 두 입력을 가로 방향으로 1만큼 떨어뜨립니다. 출력에서도 두 점은 1만큼 떨어져 있습니다.

사용자 발화시간: 25–31초, 길이 6초. 음원 미제공.

## 화면·타임라인·텍스트
공통 scene_engine.py의 절대시간 실험 상태 사용. 상세 콘티: ../../storyboard_source.md 장면 05. 입력/출력 축 단위 1.65 동일, 카메라 고정. 자막은 사용자 문장 시각으로 표시.

## 시작·종료 상태
절대시간 25초와 31초의 실험 상태를 독립 재현한다.

A_s=diag(1,s), x_A=(0,0), x_B=(cosθ,sinθ). 출력 B=(cosθ,s sinθ). 0.001 확대는 별도 명시, 본 좌표 척도 불변. 배율 0에서 x좌표가 같은 점들만 겹친다. 115초부터 s=0.1.

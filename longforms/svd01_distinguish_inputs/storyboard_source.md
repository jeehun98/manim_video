# SVD — 1편 상세 영상화 콘티

서로 다른 입력을 행렬은 구별할 수 있을까? | 총 133초 · 2분 13초

이번 영상은 일반적인 선형대수 강의처럼 좌표평면과 행렬 수식을 중심으로 전개하기보다, 관찰자가 볼 수 없는 입력을 출력으로 추론하는 실험처럼 연출하는 것이 좋겠습니다.

핵심은 0.001에서 0으로 변화하는 순간입니다. 단순히 출력 점들이 가까워지는 애니메이션이 아니라, 구별할 수 있었던 두 입력이 수학적으로 구별 불가능해지는 경계를 시각적으로 보여줘야 합니다.

## 1. 영상의 시각적 설계

기본 화면 레이아웃 예시. 입력과 출력의 좌표계는 동일한 척도로 유지합니다. 설명의 핵심은 위치가 아니라 두 점 사이의 거리 변화입니다.

제작 기준은 다음과 같이 통일합니다.

- 화면 비율: 16:9, 1920×1080 또는 3840×2160.
- 색상: 입력 A는 파랑, 입력 B는 주황, 출력 공간은 청록 계열로 구분. A와 B의 식별 색상은 양쪽 공간에서 유지.
- 좌표계: 실험 내에서 입력과 출력에 같은 공간 척도를 사용하며, 거리 비교 때 카메라 배율을 바꾸지 않음.
- 관찰자 시점: 오른쪽 출력 공간에만 접근할 수 있음. 왼쪽 입력 공간은 시청자의 이해를 위한 공개 정보.
- 숫자 표현: `1`, `0.1`, `0.01`, `0.001`, `0`을 실제 계산값으로 표시하며 애니메이션의 표시 해상도와 수학적 값은 구분.
- 수학 표현: 영상 초반에는 SVD 용어를 숨기고, 필요한 경우 행렬 \\(A=\operatorname{diag}(1,s)\\) 정도만 보조적으로 표시.

전체 영상은 16개의 장면으로 나누되, 독립된 컷들을 계속 교체하기보다는 하나의 실험 화면이 단계적으로 변화하는 방식으로 설계합니다.

### 시퀀스 B — 같은 거리, 다른 결과 (19\~56초)

목표: 시청자가 방향에 따른 반응의 차이를 직접 비교하도록 한다.

장면 04 | 19\~25초 — 행렬의 규칙

“가로 방향의 값은 그대로 전달하고, 세로 방향의 값은 10분의 1로 줄이는 행렬…”

입력과 출력 사이에 작은 행렬 상자를 표시합니다.

\\[ A=\begin{bmatrix}1&0\\\0&0.1\end{bmatrix} \\]

상자의 위아래로 `가로 ×1`, `세로 ×0.1`을 배치합니다.

사각형 격자가 가로 폭을 유지하면서 세로 높이만 10분의 1로 압축되는 짧은 미리보기를 보여줍니다.

장면 05 | 25\~31초 — 첫 번째 실험: 가로 방향

입력 점 A를 \\((0,0)\\), B를 \\((1,0)\\)에 배치합니다.

두 점 사이에 길이 1의 수평선이 나타납니다. 행렬을 적용하면 출력에서도 A, B는 동일한 거리로 떨어져 있습니다.

출력의 거리 숫자가 `1`로 확정되며 가볍게 강조됩니다.

입력 거리 1 → 출력 거리 1

장면 06 | 31\~43초 — 두 번째 실험: 세로 방향

“두 번째 실험에서는 두 입력을 세로 방향으로 1만큼 떨어뜨립니다…”

가로 실험의 B 점을 기준점 A 주위로 90도 회전시킵니다. 두 점 사이의 선분 길이는 계속 1로 고정합니다.

B의 입력 위치는 \\((0,1)\\)이 됩니다. 출력에서는 B가 \\((0,0.1)\\)로 이동합니다.

이전 가로 실험의 출력 간격을 회색 점선으로 남겨서 두 결과를 비교합니다.

가로 방향

## 1 → 1

세로 방향

## 1 → 0.1

이때 출력의 두 점을 지나치게 작게 그리면 겹쳐 보이므로 거리 라벨 `0.1`과 짧은 치수선을 함께 표시합니다.

장면 07 | 43\~56초 — 차이를 만든 것은 무엇인가?

“두 실험 모두 입력은 같은 거리만큼 달라졌습니다. 그런데 출력에 남은 차이는 10배나 다릅니다…”

화면을 가로 실험과 세로 실험으로 나눠 동일한 시간에 비교합니다.

첫 번째 장면에서는 두 실험의 입력 거리 `1`을 동기화해서 점등합니다.

두 번째 장면에서는 출력 거리 `1`과 `0.1`을 강조합니다.

마지막으로 입력 공간에서 B의 위치가 수평에서 수직으로 이동하는 곡선을 보여줍니다.

화면에 남기는 핵심 문구:

> 거리의 변화가 아니라, 방향의 변화

정확히는 입력 거리 자체는 고정되어 있고, 입력 변화의 방향이 달라진 것입니다. 시각적으로도 길이 1의 선분을 유지해야 합니다.

### 시퀀스 C — 작지만 남아 있는 차이 (56\~82초)

목표: 관측값이 0에 가까워지는 것과 실제로 0이 되는 것을 명확하게 구분한다.

장면 08 | 56\~63초 — 배율을 줄이는 실험

기존의 입력 점 두 개는 고정한 상태에서 출력만 변화시킵니다.

세로 배율을 변경할 때 출력 B가 A를 향해 이동합니다.

장면 동작 테스트: 배율 변화에 따른 실제 출력 간격. 0.001에서는 도형이 겹쳐 보일 수 있어도 숫자는 다르게 남습니다.

위 동작을 영상에서는 `0.1 → 0.01 → 0.001` 세 단계의 짧은 애니메이션으로 표현합니다.

장면 09 | 63\~71초 — 두 점이 점점 가까워진다

입력 두 점은 움직이지 않습니다. 오직 출력 B만 출력 A로 접근합니다.

배율이 작아질수록 화면상 두 점은 사실상 겹쳐 보일 수 있습니다.

여기서 일반적인 확대 애니메이션과 차별화할 부분이 있습니다.

화면의 픽셀 해상도 때문에 구별되지 않는 것과, 수학적으로 정확히 동일한 점은 서로 다르다는 것을 보여줘야 합니다.

따라서 두 점의 좌표값을 `y_A=0`, `y_B=0.001`처럼 고정된 숫자 표시로 함께 노출합니다.

장면 10 | 71\~82초 — 0.001은 0이 아니다

“출력의 차이가 아무리 작아도… 0.001은 0이 아닙니다.”

출력의 거의 겹친 두 점 주변에 확대경이 등장합니다.

확대경 안에서 두 점의 간격을 크게 보여줍니다. 화면 아래에 실제 거리 `0.001`이 유지됩니다.

이후 출력값 비교 연산을 등장시킵니다.

출력 A

# 0.000

출력 B

# 0.001

정확한 출력이라면 구별 가능

이 장면에서는 잡음, 오차, 불확실성은 도입하지 않습니다. 정확한 관측이라는 가정을 유지합니다.

### 시퀀스 D — 차이가 완전히 사라지는 순간 (82\~106초)

목표: 이 영상의 시각적 클라이맥스. 0에 가까운 상태와 정확히 0인 상태의 차이를 보여준다.

장면 11 | 82\~89초 — 배율 0

“그렇다면 배율이 정확히 0이 되면 어떻게 될까요? 이제 세로 방향으로 떨어진 모든 점은 출력에서 같은 위치에 놓입니다.”

화면에 마지막으로 `0.001 → 0`이 표시됩니다.

이번에는 확대경을 사용하지 않습니다.

출력 점 A와 B의 좌표값이 모두 \\((0,0)\\)으로 확정됩니다.

이후 입력 공간에 세로 방향으로 배열된 여러 개의 점을 추가합니다. 이 점들이 모두 출력의 동일한 위치로 이동합니다.

화면 문구: 서로 다른 입력 → 같은 출력

장면 12 | 89\~98초 — 관찰자는 구별할 수 없다

입력 영역을 다시 숨겨 관찰자의 화면만 보여줍니다.

오른쪽 출력 좌표계에는 점 하나만 보입니다.

그 옆에 가능한 입력 후보를 의미하는 여러 개의 물음표를 띄우되, 이 물음표들은 관찰자가 실제로 보는 측정 데이터가 아니라 출력 하나에 대응할 수 있는 여러 입력의 가능성을 나타냅니다.

## 출력은 동일하다

입력 A였을까? 입력 B였을까? 다른 입력이었을까?

관찰자가 정확한 출력값을 측정해도 이 후보들을 구별할 추가 정보가 없다는 사실을 강조합니다.

장면 13 | 98\~106초 — 축소와 소실의 차이

지금까지의 배율 변화를 매우 짧게 되감아 비교합니다.

| 배율    | 출력의 차이 | 수학적 구별 |
| ----- | ------ | ------ |
| 0.1   | 0.1    | 가능     |
| 0.01  | 0.01   | 가능     |

마지막 행의 `0`만 남기고 나머지 숫자는 흐리게 처리합니다.

\*\*“작아진 차이”와 “사라진 차이”\*\*를 화면 양쪽에 나누어 대비시킵니다.

이때 0에서의 완전한 소실을 폭발이나 파괴 같은 효과로 표현하기보다는, 두 점의 위치가 정확히 동일해져 하나의 출력 좌표만 남는 절제된 연출이 더 적절합니다.

### 시퀀스 E — 방향을 탐색하는 새로운 질문 (106\~133초)

목표: 가로와 세로의 비교를 모든 방향으로 일반화하면서 2편의 필요성을 만든다.

장면 14 | 106\~115초 — 가로와 세로를 넘어

입력 공간으로 돌아옵니다.

점 A는 원점에 고정하고 B를 반지름 1인 원을 따라 움직입니다.

처음에는 가로, 세로 두 방향을 강조하지만, 이어서 B가 대각선 방향으로도 이동합니다.

아직 원의 전체 외곽선은 약하게만 표시합니다. 입력 변화 벡터의 길이는 모든 방향에서 1로 유지합니다.

화면 문구: 방향은 무한히 많다

장면 15 | 115\~125초 — 모든 방향을 비교한다

“그렇다면 입력 사이의 거리를 똑같이 고정한 채 방향만 바꾸면 어떨까요?”

B를 원점을 중심으로 회전시키면서 오른쪽에 출력 B의 움직임을 동기화합니다.

이 장면부터 다시 세로 배율이 `0.1`인 원래 행렬을 사용합니다. 배율 0 실험의 결과가 그대로 이어지는 것으로 보이지 않도록 행렬 값을 다시 표시합니다.

영상에서는 입력 벡터의 길이를 일정하게 유지하며 방향을 회전시킵니다. 출력 벡터는 행렬의 방향별 반응에 따라 변합니다.

다음 편의 핵심인 출력 끝점의 전체 궤적은 아직 그리지 않습니다.

장면 16 | 125\~133초 — 발견을 예고하는 마지막 질문

“그리고 그 방향들을 찾을 수 있다면… 하나의 지도로 나타낼 수 있지 않을까요?”

화면 왼쪽에는 길이 1인 입력 변화 벡터가 천천히 회전하고, 오른쪽에는 출력 변화 벡터가 따라서 움직입니다.

출력 벡터의 길이가 변하는 장면에서 잠시 정지합니다.

마지막 질문은 크게 나타납니다.

> 어떤 방향의 차이가 가장 크게 남을까?

그 아래 작은 문구:

`같은 입력 거리 · 서로 다른 방향 · 서로 다른 출력`

마지막 1초에는 회전하는 입력 벡터를 정지시킨 뒤, 2편에서 회전을 이어갈 수 있는 프레임으로 마무리합니다.

## 3. 영상 제작에 필요한 수학적 기준

애니메이션을 직접 계산해 만드는 경우, 모든 장면에서 같은 모델을 유지하면 좌표 불일치가 발생하지 않습니다.

기준 행렬은

\\[ A_s= \begin{bmatrix} 1&0\\\ 0&s \end{bmatrix} \\]

이고, 기준점 \\(x_A=(0,0)\\)에 대해 입력 B를

\\[ x_B(\theta)= \begin{bmatrix} \cos\theta\\\ \sin\theta \end{bmatrix} \\]

로 설정합니다.

출력에서 두 점 사이의 거리는

\\[ d\_{\mathrm{out}}(\theta) = \sqrt{\cos^2\theta+s^2\sin^2\theta} \\]

입니다.

이 식은 이번 영상에서는 화면에 직접 표시하지 않아도 됩니다. 제작 과정에서 정확한 애니메이션을 만들기 위한 기준입니다.

| 장면     | \\(s\\) | \\(\theta\\) | 출력 거리  |
| ------ | ------- | ------------ | ------ |
| 가로 실험  | 0.1     | 0°           | 1      |
| 세로 실험  | 0.1     | 90°          | 0.1    |
| 강한 압축  | 0.001   | 90°          | 0.001  |
| 완전한 소실 | 0       | 90°          | 0      |
| 방향 탐색  | 0.1     | 0\~360°      | 0.1\~1 |

마지막 방향 탐색에서는 \\(s=0.1\\)을 고정합니다. 이렇게 해야 1편 마지막이 자연스럽게 2편의 단위원 탐색과 연결됩니다.

## 4. 제작 시 피해야 할 연출

| 피해야 할 연출                       | 이유 및 대안                                      |
| ------------------------------ | -------------------------------------------- |
| 0.001에서 두 점이 겹치자마자 구별 불가능으로 표시 | 화면 해상도 문제와 수학적 동일성을 혼동하게 함. 숫자와 확대 장면으로 구별   |
| 입력 공간을 공개하면서 관찰자도 입력을 보는 듯한 구성 | 실험의 전제가 약해짐. 관찰자와 시청자의 정보 접근을 분리             |

| 배율 0 실험에서 출력의 모든 점이 원점으로 이동    | 가로 성분은 여전히 보존됨. 세로 방향으로만 떨어진 점들이 동일한 출력에 대응함 |
| 마지막에 SVD의 타원을 완성               | 2편의 발견을 미리 설명하게 됨. 방향 탐색의 문제만 남기기            |

## 5. 전체 타임라인 요약

0:19 – 0:56

작지만 남은 차이

0:56 – 1:22

1:22 – 1:46

1:46 – 2:13

이번 1편은 SVD의 개념을 설명하지 않아도 SVD가 왜 필요한지 이해할 수 있도록 만드는 영상입니다.

특히 71\~106초의 `0.001 → 0` 구간에는 다른 구간보다 명확한 숫자 비교와 시각적 대비를 주는 것이 좋겠습니다.

그리고 마지막 115\~133초에서는 같은 입력 거리를 유지하면서 방향만 연속적으로 변화시키는 실험을 보여줍니다. 2편은 바로 이 실험을 이어받아, 모든 방향의 출력 끝점을 추적했을 때 왜 타원이라는 구조가 나타나는지를 발견하는 내용으로 전개할 수 있습니다.

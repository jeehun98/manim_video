# 11 · 대체 경로와 유일한 다리

## 목적·핵심 주장
내부 한 간선 삭제 시 대체 경로 존재. 다리까지 삭제하면 두 연결 성분. 위치 고정과 단절의 관계를 유지.

## 前 장면·연결
절대 시각 108초에서 시작. 같은 노드 배치를 이어받거나 명시적으로 다른 예제로 전환. 다음 편 예고 없음.

## TTS 원문과 길이
집단 내부의 연결 하나를 제거해도 다른 길로 이동할 수 있습니다. 반면 두 집단을 잇는 유일한 연결을 제거하면, 네트워크가 둘로 분리됩니다. 모든 연결이 똑같이 중요한 것은 아니라는 뜻입니다.

108–120초, 확정 길이 12초. 사용자 발화 시각 기준, 음원 없음.

## 화면·애니메이션
108–111초 내부 간선 삭제와 대체 경로; 111–116초 다리 삭제와 단절; 116–120초 성분2개.

scene_engine.py part_10. 세로·가로 별도 배치.

## 화면 텍스트
제목 대체 경로와 유일한 다리. 노드 값/간선 가중치/에너지 구분.

## 시작·종료 상태
해당 대상에서 시작하여 검증한 결과 또는 보존 조건으로 종료.

# 20 — 층을 얇게 만들면 곡선이 된다

## 주장
층을 얇게 만들면 곡선이 된다

## 확정 대본·길이
사용자 종료 시각 120–126초. 음원 미제공.

이때 빛의 속력 분포를 중력 아래 물체의 속력과 같게 설정하면, 두 문제의 이동 시간 식도 같아집니다.

## 화면
첨부 콘티 reference/storyboard.txt의 시퀀스 20. visuals.py INDEX=19. 진입, 물리량 또는 후보 경로 비교, 결론 유지. 자막은 전체 원문 시각을 유지한다.

## 조건
균일 중력, 마찰 없는 점입자, 정지 출발, 같은 A·B. 깊이 y는 아래가 양수. 구슬은 위치 표식이며 구르는 강체가 아니다. 후보 비교는 물체가 스스로 트랙을 만드는 과정이 아니다. 가상 매질의 y=0은 극한이고 유한층은 중간 깊이 속력을 쓴다.

## 시작·종료
독립적으로 좌표와 대상 제시 → 해당 주장 관찰. 다음 편 예고 없음.

## 구체적 화면 진행
N=6→12→24→48. 각 N마다 끝점 조건과 Snell 법칙으로 계산한 새 광선을 표시한다. 마지막에 연속 광선을 겹친다. 변환은 계산 결과 간 시각 전환이다.

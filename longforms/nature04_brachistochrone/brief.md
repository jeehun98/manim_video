# 자연의 최적화 04 — 제작 기준

사용자 확정 원문 38문장, 문장 종료 시각 4–165초를 보존한다. 콘티의 26개 구간을 독립적인 Manim 씬으로 제작한다. 세로 1080×1920과 가로 1920×1080, 30fps, 각각 165초. 음원 미제공으로 자막 포함 무음 영상이다.

관찰 → 에너지로 속력 결정 → 경로 전체 시간의 최소화 → 사이클로이드 → 가상 매질의 굴절과 대응 → 실제 운동과 경로 설계의 차이 순서다. 사용자가 이번 원고에 포함한 빛과의 비교는 유지하고 별도의 복습·예고는 넣지 않는다.

## 수학과 물리

- 균일한 중력, 마찰 없는 미끄러지는 점입자, 정지 출발. 구슬은 위치 표식이며 회전 관성을 갖는 강체가 아니다.
- 동일한 A=(0,0), B=(4,3), g=1의 상대 단위. 깊이 y는 아래가 양수다. 끝점 조건에서 사이클로이드 매개변수를 푼다.
- 사이클로이드와 직선은 해석적인 시간별 위치를 사용한다. 깊은 경로는 y=3x/4+5.5sin(πx/4), 시간 적분과 단조 보간으로 위치를 구한다. 세 트랙 모두 같은 평면이며 임의의 레인 간격은 없다.
- 같은 높이의 속력 비교는 서로 다른 도달 시점의 스냅샷이다. 도착 후 정지 표식은 기록 표시이며 실제 제동 과정이 아니다.
- 광선은 가상 매질 v(y)=√(2gy)의 연속 굴절 법칙을 독립 적분한다. 유한층은 중간 깊이의 양수 속력을 쓰고 Snell 상수를 각 N의 끝점 조건에서 푼다. N=6,12,24,48은 실제 계산한 꺾은선이며, 유한층과 연속 극한을 구별한다. y=0의 v=0은 극한이다.
- 회전 원의 중심은 (aθ,a), 반지름 a, 추적점은 (a(θ−sinθ),a(1−cosθ)). 원의 기하학적 생성법과 미끄러지는 입자의 운동을 혼동하지 않는다.
- δT=0은 일차 정지 조건이며 모든 정지 경로가 최소라는 일반화는 하지 않는다. 이번 고정 끝점의 사이클로이드는 최속강하선이다.

## 검증

verify.py는 끝점, 시간 순서, 에너지와 속력, 층별 Snell 법칙, 층 세분화 수렴, 별도 광선 적분과 사이클로이드의 일치, 자막·씬 길이를 검사한다. 최종 영상의 실제 디코딩 프레임 수·해상도·무음 스트림을 추가 검사한다. 미리보기와 최종 컨택트시트로 화면 배치를 점검한다.

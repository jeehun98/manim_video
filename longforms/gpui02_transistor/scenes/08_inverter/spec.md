# 08 · 입력과 반대인 출력

## 목적·주장
상보적인 pMOS·nMOS 연결이 반전을 구현한다.

## 앞 장면과 시작 상태
출력 노드를 VDD 또는 GND에 연결해 전압 상태를 만든다.
동일 색상·기능 배치로 이전 씬의 개념을 유지한다.

## TTS 원문과 확정 길이
사용자 종료 시각 109–120초, 11초. 음원 미제공. 추정 타이밍을 사용하지 않는다.

예를 들어 입력 전압이 낮을 때는 출력이 높아지고, 입력 전압이 높을 때는 출력이 낮아지도록 만드는 것입니다.

이것이 입력을 반전시키는 회로인 인버터의 기본적인 원리입니다.

## 화면·타임라인·텍스트
| 전체 시각(초) | 화면 |
| --- | --- |
| 109–113 | 입력 LOW: pMOS ON·nMOS OFF·출력 HIGH |
| 113–116 | 입력 HIGH: pMOS OFF·nMOS ON·출력 LOW |
| 116–119 | 입출력 대응표와 반전 관계 |
| 119–120 | NOT / INVERTER 명명 |

핵심 용어는 단면/회로 옆에, 설명은 전용 하단 자막에 둔다. 동작은 ../../scene_engine.py의 inverter 메서드에서 구현한다. 원문 콘티: ../../storyboard_reference.md.

## 종료 상태와 다음 연결
종료 주장: 상보적인 pMOS·nMOS 연결이 반전을 구현한다.
다음 씬은 이 기능 구조를 유지하며 연결 구조가 정하는 규칙로 확장한다.

## 조건·과장 방지
Gate 입력과 Source–Drain 경로를 연결하지 않는다. 절연막을 통과하는 전자 이동을 그리지 않는다. 전도 경로는 빛나는 선으로 표시하며 입자 이동으로 전류 속도를 표현하지 않는다. MOSFET은 n채널 강화형의 개념 단면이며 몸체 접속 등은 생략한다. VGS는 Source 기준, VDS>0의 예시다. CMOS는 정적 상보 상태를 표시하고 출력 전압 전환은 설명용 시간으로 확대한다. 기계 접점과 MOSFET 채널 형성을 동일 물리 현상으로 표현하지 않는다. 사용자의 도입·마지막 질문은 확정 원문 그대로 유지한다.

# 05 · 접점 대신 전도성 변화

## 목적·주장
기계적인 접촉 이동 없이 경로의 전도성을 바꿀 수 있다.

## 앞 장면과 시작 상태
절연된 전극의 전기장이 반도체 전하 분포와 전도성을 바꾼다.
동일 색상·기능 배치로 이전 씬의 개념을 유지한다.

## TTS 원문과 확정 길이
사용자 종료 시각 62–68초, 6초. 음원 미제공. 추정 타이밍을 사용하지 않는다.

즉, 물리적인 접점을 붙였다 떼지 않고도 전기적 신호만으로 통로의 전도성을 바꿀 수 있는 것입니다.

## 화면·타임라인·텍스트
| 전체 시각(초) | 화면 |
| --- | --- |
| 62–65 | 움직이는 접점과 움직이지 않는 반도체를 비교 |
| 65–68 | 반도체 구조를 중심으로 확대 |

핵심 용어는 단면/회로 옆에, 설명은 전용 하단 자막에 둔다. 동작은 ../../scene_engine.py의 electronic 메서드에서 구현한다. 원문 콘티: ../../storyboard_reference.md.

## 종료 상태와 다음 연결
종료 주장: 기계적인 접촉 이동 없이 경로의 전도성을 바꿀 수 있다.
다음 씬은 이 기능 구조를 유지하며 이 장치의 이름, MOSFET로 확장한다.

## 조건·과장 방지
Gate 입력과 Source–Drain 경로를 연결하지 않는다. 절연막을 통과하는 전자 이동을 그리지 않는다. 전도 경로는 빛나는 선으로 표시하며 입자 이동으로 전류 속도를 표현하지 않는다. MOSFET은 n채널 강화형의 개념 단면이며 몸체 접속 등은 생략한다. VGS는 Source 기준, VDS>0의 예시다. CMOS는 정적 상보 상태를 표시하고 출력 전압 전환은 설명용 시간으로 확대한다. 기계 접점과 MOSFET 채널 형성을 동일 물리 현상으로 표현하지 않는다. 사용자의 도입·마지막 질문은 확정 원문 그대로 유지한다.

# 01 · 표현에서 신호 제어로

## 목적·주장
정보 표현과 입력에 따른 출력 생성은 구별된다.

## 앞 장면과 시작 상태
LOW/HIGH로 표현한 정보에서 시작한다.
동일 색상·기능 배치로 이전 씬의 개념을 유지한다.

## TTS 원문과 확정 길이
사용자 종료 시각 0–16초, 16초. 음원 미제공. 추정 타이밍을 사용하지 않는다.

앞서 우리는 전압을 두 가지 논리 상태로 구분해 정보를 표현하는 방법을 살펴봤습니다.

하지만 이렇게 표현한 신호를 이용해 계산하려면, 단순히 정보를 전달하는 것만으로는 부족합니다.

입력된 신호에 따라 다른 신호를 만들어내거나, 전류의 흐름을 제어할 수 있어야 합니다.

## 화면·타임라인·텍스트
| 전체 시각(초) | 화면 |
| --- | --- |
| 0–5 | LOW/0·HIGH/1 표현 상자 |
| 5–11 | 입력 상자와 미지의 처리 장치·출력선 |
| 11–16 | 입력이 바뀌어도 출력은 아직 미정 |

핵심 용어는 단면/회로 옆에, 설명은 전용 하단 자막에 둔다. 동작은 ../../scene_engine.py의 need 메서드에서 구현한다. 원문 콘티: ../../storyboard_reference.md.

## 종료 상태와 다음 연결
종료 주장: 정보 표현과 입력에 따른 출력 생성은 구별된다.
다음 씬은 이 기능 구조를 유지하며 전류 경로를 여닫는 스위치로 확장한다.

## 조건·과장 방지
Gate 입력과 Source–Drain 경로를 연결하지 않는다. 절연막을 통과하는 전자 이동을 그리지 않는다. 전도 경로는 빛나는 선으로 표시하며 입자 이동으로 전류 속도를 표현하지 않는다. MOSFET은 n채널 강화형의 개념 단면이며 몸체 접속 등은 생략한다. VGS는 Source 기준, VDS>0의 예시다. CMOS는 정적 상보 상태를 표시하고 출력 전압 전환은 설명용 시간으로 확대한다. 기계 접점과 MOSFET 채널 형성을 동일 물리 현상으로 표현하지 않는다. 사용자의 도입·마지막 질문은 확정 원문 그대로 유지한다.

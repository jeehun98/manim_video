# 03 · 손 대신 전기 신호로

## 목적·주장
제어 입력은 별도의 전류 경로를 제어한다.

## 앞 장면과 시작 상태
닫힌 회로는 전류가 흐를 수 있는 경로를 만든다.
동일 색상·기능 배치로 이전 씬의 개념을 유지한다.

## TTS 원문과 확정 길이
사용자 종료 시각 28–43초, 15초. 음원 미제공. 추정 타이밍을 사용하지 않는다.

그런데 이 스위치를 손으로 움직이는 대신, 또 다른 전기적 신호로 제어할 수 있다면 어떨까요?

예를 들어 한쪽에 전압을 가하면 통로가 열리고, 전압을 낮추면 통로가 닫히는 것입니다.

이렇게 하면 하나의 전기적 신호를 이용해 다른 전류 경로를 제어할 수 있습니다.

## 화면·타임라인·텍스트
| 전체 시각(초) | 화면 |
| --- | --- |
| 28–33 | 동일 접점 아래에 별도의 보라색 제어 입력 |
| 33–38 | 입력 HIGH/LOW에 따라 접점 연결·차단 |
| 38–43 | 제어 입력과 전류 경로를 명확히 분리해 표시 |

핵심 용어는 단면/회로 옆에, 설명은 전용 하단 자막에 둔다. 동작은 ../../scene_engine.py의 control 메서드에서 구현한다. 원문 콘티: ../../storyboard_reference.md.

## 종료 상태와 다음 연결
종료 주장: 제어 입력은 별도의 전류 경로를 제어한다.
다음 씬은 이 기능 구조를 유지하며 움직이지 않는 스위치로 확장한다.

## 조건·과장 방지
Gate 입력과 Source–Drain 경로를 연결하지 않는다. 절연막을 통과하는 전자 이동을 그리지 않는다. 전도 경로는 빛나는 선으로 표시하며 입자 이동으로 전류 속도를 표현하지 않는다. MOSFET은 n채널 강화형의 개념 단면이며 몸체 접속 등은 생략한다. VGS는 Source 기준, VDS>0의 예시다. CMOS는 정적 상보 상태를 표시하고 출력 전압 전환은 설명용 시간으로 확대한다. 기계 접점과 MOSFET 채널 형성을 동일 물리 현상으로 표현하지 않는다. 사용자의 도입·마지막 질문은 확정 원문 그대로 유지한다.

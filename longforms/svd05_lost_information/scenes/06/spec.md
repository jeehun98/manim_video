# 06 — Null Space와 해 집합

## 목적과 핵심 주장
원점을 지나는 ker(A)와 x=1의 해 집합을 구분

## 앞 장면에서 받은 내용
원래 입력이 아니라 추가한 차이 v가 Av=0

## TTS 원문과 확정 길이
이처럼 행렬을 통과했을 때 0이 되는 모든 입력 벡터들의 공간을 널 스페이스, Null Space라고 합니다.

널 스페이스에 속하는 벡터를 원래 입력에 더해도 출력은 달라지지 않습니다.

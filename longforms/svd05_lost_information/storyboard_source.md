## 2. 시퀀스 A — 하나의 출력에 얼마나 많은 입력이 대응할까? (0\~58초)

### 장면 01 | 0\~11초 — 지난 실험에서 시작

내레이션:

> 지난 실험에서 우리는 행렬이 한 방향의 차이를 완전히 지워버리면, 서로 다른 입력이 같은 출력으로 나타날 수 있다는 사실을 확인했습니다. 그렇다면 하나의 출력에 대응하는 입력은 얼마나 많을까요?

4편 마지막 장면을 그대로 이어받습니다.

입력 공간에는 서로 다른 두 점 \\(x_1,x_2\\)가 있습니다. 출력 공간에서는 두 점이 하나의 좌표로 겹칩니다.

카메라가 출력 공간의 점을 확대합니다.

확대한 출력 점 주변에 물음표가 등장하고, 입력 후보의 개수를 묻는 문구를 표시합니다.

화면 문구: 하나의 출력은 몇 개의 입력에서 만들어질까?

### 장면 02 | 11\~17초 — 실험 행렬 설정

내레이션:

> 가로 방향의 값은 그대로 전달하고 세로 방향의 값은 완전히 지우는 행렬을 생각해보겠습니다.

행렬을 명확하게 표시합니다.

\\[ A=\begin{bmatrix} 1&0\\\ 0&0 \end{bmatrix} \\]

화면에는 `가로 ×1`, `세로 ×0`이라는 두 개의 규칙도 함께 제시합니다.

왼쪽 입력 좌표계에는 격자가 나타나고, 오른쪽에서는 세로 방향 격자선들이 가로축 위로 겹쳐지는 짧은 변환 미리보기를 보여줍니다.

### 장면 03 | 17\~25초 — 입력만 움직인다

내레이션:

> 입력 하나를 선택하고, 그 입력을 세로 방향으로 조금씩 움직여 보겠습니다. 입력의 위치는 계속 바뀌지만 출력은 변하지 않습니다.

입력의 기준점을 \\((1,0)\\)으로 설정합니다.

점을 위아래로 이동시킵니다.

입력의 세로 위치만 바뀌며 출력은 언제나 (1, 0)으로 유지됩니다. 해당 움직임을 영상에서 연속 애니메이션으로 사용합니다.

### 장면 04 | 25\~37초 — 하나의 출력에 직선 전체가 대응한다

내레이션:

> 세로 방향으로 얼마나 이동하든 가로 좌표가 같다면 결과는 항상 같습니다. 따라서 하나의 출력에 대응하는 입력은 두세 개가 아닙니다. 세로 방향으로 이어진 직선 전체가 같은 출력을 만들어냅니다.

입력의 점이 이동한 경로를 선으로 남깁니다.

경로를 위아래로 계속 확장하면 입력 공간에 세로 직선 \\(x=1\\)이 완성됩니다.

오른쪽 출력 공간에는 오직 \\((1,0)\\) 하나만 표시됩니다.

강조: 여러 점이 하나의 점으로 모이는 애니메이션과 달리, 이번에는 왼쪽의 직선 전체와 오른쪽의 점 하나를 나란히 유지해 서로 다른 입력이 무한히 많다는 사실을 보여줍니다.

### 장면 05 | 37\~44초 — 왜 이런 일이 가능한가?

내레이션:

> 왜 이런 일이 가능할까요? 처음 입력에 더해진 세로 방향의 변화가 행렬을 통과하면서 0이 되기 때문입니다.

입력의 한 점에서 다른 점으로 이동한 변화량 \\(\Delta x\\)를 별도의 보라색 화살표로 분리합니다.

이 변화량을 행렬에 통과시키면 길이가 0이 되는 모습을 보여줍니다.

\\[ A\begin{bmatrix}0\\\t\end{bmatrix} =\begin{bmatrix}0\\\0\end{bmatrix} \\]

여기서 원래 입력 전체가 0으로 변환되는 것이 아니라, 두 입력 사이의 차이만 0으로 변환된다는 점이 중요합니다.

### 장면 06 | 44\~54초 — Null Space 발견

내레이션:

> 이처럼 행렬을 통과했을 때 0이 되는 모든 입력 벡터들의 공간을 널 스페이스, Null Space라고 합니다. 널 스페이스에 속하는 벡터를 원래 입력에 더해도 출력은 달라지지 않습니다.

입력 공간의 세로 방향 직선을 원점을 지나도록 평행이동하여 Null Space 자체를 보여줍니다.

이 예시에서 Null Space는

\\[ \ker(A)=\left\\{ \begin{bmatrix}0\\\t\end{bmatrix} :t\in\mathbb R \right\\} \\]

입니다.

이후 원래의 입력 후보 직선 \\(x=1\\)을 다시 표시합니다.

두 직선의 차이

이 두 직선을 혼동하지 않게 하는 것이 이번 장면의 핵심입니다.

### 장면 07 | 54\~58초 — 보이지 않는 방향

내레이션:

> 행렬은 그 방향으로 얼마나 움직였는지 구별할 수 없는 것입니다.

입력의 후보 직선 위에서 점이 다시 움직입니다.

출력 공간에는 아무 변화가 없습니다.

마지막에는 입력 직선의 세로 방향을 강조하고, 화면 문구를 남깁니다.

행렬에게 보이지 않는 방향 — Null Space

## 3. 시퀀스 B — 살아남은 방향은 몇 개일까? (58\~85초)

목표: Null Space를 반대 방향에서 바라보며 Rank를 발견한다. 2차원에서 3차원으로 자연스럽게 확장한다.

### 장면 08 | 58\~65초 — 구별할 수 있는 방향을 세어본다

내레이션:

> 그렇다면 반대로, 행렬을 통과한 뒤에도 살아남는 독립적인 방향은 몇 개일까요? 3차원 공간을 생각해보겠습니다.

기존 2차원 입력 좌표계를 카메라가 천천히 회전시키면서 3차원 좌표계로 확장합니다.

원점에서 출발하는 서로 직교한 세 개의 화살표 \\(v_1,v_2,v_3\\)가 나타납니다.

각 방향에 특잇값을 표시합니다.

\\[ \sigma_1=1,\qquad \sigma_2=0.7,\qquad \sigma_3=0.4 \\]

세 값 모두 양수이므로 모든 방향의 차이가 출력에 남습니다.

이 장면에서는 입체 내부까지 표시할 수 있도록 반투명한 단위공을 생성합니다.

### 장면 09 | 65\~76초 — 3차원이 하나씩 사라진다

내레이션:

> 세 방향의 특잇값이 모두 0이 아니라면, 단위공은 부피를 가진 타원체로 변환됩니다. 한 방향의 특잇값이 0이 되면 출력은 평면 위에 놓이고, 두 방향이 사라지면 선분 위에만 남습니다.

이번 구간은 3D 애니메이션을 사용해야 합니다.

시각화 구조 예시. 실제 영상에서는 3D 단위공의 부피가 점차 줄어 평면 위의 타원판, 선분, 점으로 변하는 과정을 연속적으로 보여줍니다.

실제 애니메이션은 다음 순서로 변화시킵니다.

\\[ (1,\ 0.7,\ 0.4)\rightarrow(1,\ 0.7,\ 0)\rightarrow(1,\ 0,\ 0) \\]

시각적으로는 타원체의 두께가 점차 0이 되고, 이후 타원판의 짧은 축까지 0이 되는 것입니다.

주의: 수학적으로는 단위공의 변환이 타원체의 표면만이 아니라 내부까지 포함합니다. 따라서 Rank 2에서 타원 둘레만 남기지 말고 면적을 가진 타원판을 표시해야 합니다.

## 4. 시퀀스 C — 복원할 수 없다면 무엇을 선택할까? (85\~131초)

목표: 사라진 정보를 복원하는 대신, 여러 후보 중 하나를 선택하는 규칙으로서 Pseudoinverse를 발견한다.

### 장면 11 | 85\~96초 — 다시 무한한 입력 후보로

내레이션:

> 이제 처음의 복원 문제로 돌아가 보겠습니다. 같은 출력을 만드는 입력이 무한히 많다면, 그중 무엇을 원래 입력이라고 선택해야 할까요? 출력만으로는 실제 입력이 무엇이었는지 알 수 없습니다.

3차원 애니메이션이 축소되면서 다시 2차원 좌표계로 전환됩니다.

초반에 사용한 행렬로 돌아갑니다.

\\[ A=\begin{bmatrix}1&0\\\0&0\end{bmatrix}, \qquad y=\begin{bmatrix}1\\\0\end{bmatrix} \\]

입력 공간에는 \\(x=1\\)을 만족하는 세로 직선이 나타납니다.

이 직선 위에 후보 입력 다섯 개를 표시합니다.

\\[ (1,-2),\ (1,-1),\ (1,0),\ (1,1),\ (1,2) \\]

이 다섯 개는 임의로 선택한 대표점일 뿐입니다. 실제 후보는 직선 전체에 무한히 많습니다.

출력 공간에서는 다섯 후보가 모두 \\((1,0)\\)에 대응한다는 것을 보여줍니다.

### 장면 12 | 96\~103초 — 선택 규칙이 필요하다

내레이션:

> 하지만 가능한 입력들 가운데 하나를 선택하는 규칙은 만들 수 있습니다. 그중 하나가 의사역행렬, Pseudoinverse입니다.

관찰자의 출력값 \\((1,0)\\)은 그대로 유지합니다.

입력 후보들이 있는 직선 위에서 선택 커서가 이동합니다.

각 후보 옆에는 원점으로부터의 거리 표시가 나타납니다.

여기서 새로운 질문을 화면에 표시합니다.

“모두 같은 출력이라면, 어떤 입력을 선택할까?”

### 장면 13 | 103\~110초 — 0이 아닌 방향만 되돌린다

내레이션:

> 의사역행렬은 0이 아닌 특잇값에 대해서는 역수를 적용하고, 0인 특잇값은 되돌리려 하지 않습니다.

기존 SVD의 특잇값 두 개를 다시 표시합니다.

\\[ \Sigma= \begin{bmatrix}1&0\\\0&0\end{bmatrix}, \qquad \Sigma^+= \begin{bmatrix}1&0\\\0&0\end{bmatrix} \\]

이번 예시에서는 역수를 취한 후에도 숫자가 같지만, 원리는 다릅니다.

일반적인 특잇값에 대해서는 다음 규칙을 화면에 보여줍니다.

양의 특잇값

\\(\sigma_i>0\\)

\\(\frac1{\sigma_i}\\)

0인 특잇값

\\(\sigma_i=0\\)

0

0인 성분을 거꾸로 계산하려는 화살표는 등장하지 않습니다.

사라진 방향을 추정하려고 하는 것이 아니라, 해당 입력 성분을 0으로 두는 선택이라는 점을 보여줍니다.

### 장면 14 | 110\~117초 — 가장 짧은 입력을 찾는다

내레이션:

> 그리고 주어진 출력을 정확히 만들어내는 입력이 존재한다면, 가능한 입력들 중 길이가 가장 짧은 것을 선택합니다.

입력 후보의 세로 위치

1.2

후보 입력의 길이

## 1.562

최소 노름 해 선택후보가 (1,t)라면 원점에서의 거리는 √(1+t²)입니다. 최소 거리는 t=0에서 얻어집니다.

영상에서는 후보점이 직선을 따라 이동하며 원점에서 후보까지 연결된 화살표의 길이가 달라집니다.

가장 짧은 순간에 금색 마커가 나타납니다.

\\[ x^+=\begin{bmatrix}1\\\0\end{bmatrix} \\]

### 장면 15 | 117\~124초 — 정확한 해가 없는 경우

내레이션:

> 정확히 일치하는 입력이 없다면 출력과의 오차를 최소화하고, 그런 입력들 중 길이가 가장 짧은 것을 선택합니다.

이번에는 관측 출력을 \\((1,0.3)\\)으로 바꿉니다.

현재 행렬은 모든 출력의 세로 좌표를 0으로 만들기 때문에 정확히 \\((1,0.3)\\)을 만드는 입력은 존재하지 않습니다.

출력 공간에서 관측값 \\((1,0.3)\\)과 가장 가까운 실현 가능한 출력 \\((1,0)\\)을 표시합니다.

### 장면 18 | 141\~152초 — 행렬을 여러 성분으로 분리한다

내레이션:

> 하나의 행렬을 에스브이디로 분해하면, 서로 다른 특잇값에 대응하는 여러 성분의 합으로 나타낼 수 있습니다. 이 가운데 큰 특잇값의 성분만 남기고 작은 성분들을 제거해 보겠습니다.

3편에서 배운 방향별 분해와 조립을 다시 사용합니다.

하지만 이번에는 입력 벡터 하나가 아니라 행렬 자체를 여러 랭크 1 행렬의 합으로 표현합니다.

\\[ A=\sigma_1u_1v_1^T+\sigma_2u_2v_2^T+\cdots \\]

각 \\(\sigma_i u_iv_i^T\\)를 독립적인 행렬 성분으로 분리해서 보여줍니다.

각 성분이 하나의 단순한 방향 구조를 나타내도록 작은 격자형 이미지로 시각화합니다.

이후 가장 작은 성분부터 회색으로 처리하고 제거합니다.

### 장면 19 | 152\~161초 — 더 적은 성분으로 근사한다

내레이션:

> 그러면 원래 행렬과 완전히 같지는 않지만, 더 적은 수의 성분으로 비슷한 행렬을 만들 수 있습니다. 이것이 저랭크 근사, Low-Rank Approximation입니다.

원래 행렬을 왼쪽에, 일부 성분만 남긴 근사 행렬을 오른쪽에 표시합니다.

\\[ A_k=\sum\_{i=1}^{k}\sigma_i u_iv_i^T \\]

두 행렬을 비교하면서 다음 두 요소를 동시에 표시합니다.

- 남아 있는 특이 성분의 개수 \\(k\\)
- 원래 행렬과 근사 행렬의 차이 \\(A-A_k\\)

여기서 작은 성분을 버린다고 해서 항상 중요한 의미가 사라지지 않는다는 식의 단정은 하지 않습니다.

\\(\Sigma\\)

## 8. 제작 시 반드시 검증할 사항

| 검증 대상         | 정확한 기준                                  |
| ------------- | --------------------------------------- |
| Null Space    | \\(Av=0\\)인 벡터들의 공간                     |
| 같은 출력의 해 집합   | 해가 존재하면 \\(x_0+\ker(A)\\)               |
| Rank          | 0이 아닌 특잇값 개수                            |
| Pseudoinverse | 최소 노름 최소제곱해                             |
| 저랭크 근사        | 큰 특잇값부터 \\(k\\)개 유지                     |
| 최적성           | Frobenius norm 기준 Rank \\(k\\) 이하 최적 근사 |
| 이미지 시각화       | 블러 효과가 아닌 실제 절단 SVD 계산 결과               |

특히 Null Space와 해 집합을 구분하는 장면, 의사역행렬이 복원 대신 해를 선택하는 장면은 수학적으로 정확하게 제작해야 합니다.

## 9. 최종편에서 가장 중요한 연출

이번 영상에서 가장 많은 시각적 비중을 줄 부분은 85\~131초의 의사역행렬과 131\~205초의 저랭크 근사입니다.

앞부분에서 무한히 많은 입력 후보 중 최소 노름 해를 선택하는 모습은, 일반적인 의사역행렬 공식 설명보다 시청자에게 훨씬 명확한 의미를 전달할 수 있습니다.

그리고 그다음에 나타나는 저랭크 근사는 지금까지의 관점을 전환합니다.

정보를 잃는 것은 언제나 문제가 되는가?

우리는 복원을 위해서는 잃어버린 정보가 문제라는 사실을 보았습니다. 하지만 행렬을 근사하려면 일부 정보를 버려야 하고, SVD는 어떤 성분을 버리는 것이 수치적으로 가장 유리한지 알려줍니다.

이 두 이야기가 연결되는 순간이 최종편의 핵심입니다.

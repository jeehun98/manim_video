# 제작 기준

## 학습 목표와 주장

반복 변환에서 고윳값 크기 차이가 고유성분의 상대적 비중과 전체 방향을 결정함을 관찰한다. 현상 → 특별한 방향 발견 → 용어 정의 → 성분 성장 → 초기 조건과 결론 순서를 지킨다.

## 시간과 포맷

사용자 제공 콘티의 0,3,12,19,26,34,45,55,74,80,84,96,105,114,119초 경계를 사용한다. 대본 글자 수로 발화시간을 추정하지 않는다. 동일 대본의 세로 쇼츠와 가로 롱폼을 각각 배치한다. 확정 대본을 수정하지 않는다.

## 화면 기준

현재 벡터 #458EFA, 첫 고유방향 #20BCA5, 둘째 고유방향 #F0A34E. 초반에는 고유방향과 원소를 공개하지 않는다. 34초 이후 행렬 원소 공개. 길이 정규화는 표시 목적. 성장률은 별도 동일 척도 막대. 성분합 정규화는 모든 성분에 동일 배율 적용. 고유성분 0인 예외를 같은 행렬로 설명한다. 이전 편 복습이나 다음 편 예고를 넣지 않는다.

## 전달 상태

실제 TTS 음원 미제공. 무음 영상과 씬 구간 단위의 별도 자막을 제공한다. 문장별 발화 싱크는 음원 수령 후 확인한다.

## 추가 자막

사용자 요청에 따라 내레이션 핵심 발췌 19개를 두 최종 영상에 직접 포함한다. 기존 수식 아래 별도 영역에 표시하며, 세로 두 줄·가로 한 줄을 사용한다. 자막 타이밍은 사용자 콘티의 구간 경계 및 정의·성장률 세부 시각을 따른다.

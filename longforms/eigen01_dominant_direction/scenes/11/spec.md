# 11. 서로 다른 성장률

- 확정 구간: 84–96초 (사용자 콘티 기준)
- 길이: 12초
- 음성: 미제공. 문장별 종료 시각은 추정하지 않음.
- 시작·종료 상태 및 화면 지시: 아래 사용자 콘티 준수
- 연결: 별도 복습·예고 없이 독립 결론과 시각적 연결만 사용
- 수학: A=((2,1),(1,2)), x₀=(1,0), v₁=(1,1), v₂=(1,−1). 정규화는 표시 목적.

서로 다른 성장률

01:24–01:36 · 수렴 원인 설명

내레이션

> 길이를 맞추기 전의 변화를 보면, 행렬을 한 번 적용할 때 첫 번째 성분은 3배가 되고, 두 번째 성분은 그대로입니다. 두 번 적용하면 첫 번째 성분은 처음의 9배, 세 번 적용하면 27배가 됩니다.

화면 연출

앞선 정규화 화면과 완전히 다른 레이아웃을 사용한다.

이번에는 고유성분 자체의 성장만 보여준다.

고유성분의 실제 성장

적용 3회

고윳값 3

27배

고윳값 1

1배

&#x20;이전\\(\lambda_1^k=3^k,\quad\lambda_2^k=1^k\\)다음&#x20;

초기 크기가 같은 두 고유성분의 상대적 성장률. 화면에서는 최대 27배까지 동일한 척도를 유지한다.

타임라인

| 시점  | 첫 번째 고유성분 | 두 번째 고유성분 |
| --- | --------- | --------- |
| 84초 | 3배        | 1배        |
| 88초 | 9배        | 1배        |
| 92초 | 27배       | 1배        |

가능하면 수치가 증가할 때 막대의 길이를 부드럽게 증가시키고, 주황색 막대는 계속 고정해.

여기서 표시하는 배율은 각 성분의 초기 크기를 기준으로 한 배율이야. 정규화 이전의 성장이라는 사실을 화면 상단에 짧게 표시하면 좋아.

# 10. 하나의 벡터를 두 고유성분으로 분해

- 확정 구간: 80–84초 (사용자 콘티 기준)
- 길이: 4초
- 음성: 미제공. 문장별 종료 시각은 추정하지 않음.
- 시작·종료 상태 및 화면 지시: 아래 사용자 콘티 준수
- 연결: 별도 복습·예고 없이 독립 결론과 시각적 연결만 사용
- 수학: A=((2,1),(1,2)), x₀=(1,0), v₁=(1,1), v₂=(1,−1). 정규화는 표시 목적.

하나의 벡터를 두 고유성분으로 분해

01:20–01:24 · 원래 벡터로 돌아오기

내레이션

> 지금 선택한 벡터에는 이 두 고유방향의 성분이 섞여 있습니다.

화면 연출

이번 장면부터는 다시 처음의 파란색 벡터 \\(x_0\\)에 집중한다.

\\[ x_0=\frac12v_1+\frac12v_2 \\]

애니메이션 순서

1. 파란색 초기 벡터만 표시한다.
2. 청록색·주황색 고유방향을 다시 등장시킨다.
3. 파란 벡터가 두 고유방향 성분의 합으로 표현된다.
4. 두 성분의 벡터합을 점선 평행사변형으로 보여준다.

이 장면에서의 핵심은 벡터를 실제로 잘라 두 조각으로 만드는 것이 아니라, 서로 다른 두 방향의 벡터를 더하면 원래 벡터가 된다는 의미를 보여주는 거야.

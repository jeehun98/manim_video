# 08. 고유방향·고유벡터·고윳값 정의

- 확정 구간: 55–74초 (사용자 콘티 기준)
- 길이: 19초
- 음성: 미제공. 문장별 종료 시각은 추정하지 않음.
- 시작·종료 상태 및 화면 지시: 아래 사용자 콘티 준수
- 연결: 별도 복습·예고 없이 독립 결론과 시각적 연결만 사용
- 수학: A=((2,1),(1,2)), x₀=(1,0), v₁=(1,1), v₂=(1,−1). 정규화는 표시 목적.

고유방향·고유벡터·고윳값 정의

00:55–01:14 · 핵심 개념 정리

내레이션

> 이처럼 행렬을 적용해도 같은 직선 위에 남는 특별한 방향을 고유방향이라고 합니다. 그 방향을 따라 놓인 영벡터가 아닌 벡터를 고유벡터라고 합니다. 그리고 행렬이 고유벡터를 몇 배로 바꾸는지 나타내는 수를 고윳값이라고 합니다. 첫 번째 고유방향의 고윳값은 3, 두 번째 고유방향의 고윳값은 1입니다.

화면 구성

고유방향

변환 후에도 같은 직선

고유벡터

그 직선 위의 영벡터가 아닌 벡터

\\[ Av=\lambda v,\quad v\ne0 \\]

\\(v\\): 고유벡터

\\(\lambda\\): 고윳값

세부 타이밍

| 구간      | 화면 변화                                  |
| ------- | -------------------------------------- |
| 55\~60초 | 점선의 고유직선을 강조하고 `고유방향` 표시               |
| 60\~64초 | 직선 위의 하나의 화살표를 강조하고 `고유벡터` 표시          |
| 64\~69초 | 화살표가 배율만큼 늘어나는 애니메이션과 \\(\lambda\\) 등장 |
| 69\~74초 | `고윳값 3`, `고윳값 1`을 두 방향에 각각 배치          |

정의가 등장할 때마다 불필요한 요소를 숨기고 현재 설명하는 대상만 밝게 표시하자.

## 4. Manim 구현 시 중요한 사항

첫째, 하나의 좌표 변환 로직을 모든 장면에서 공유하자.

수학적 계산은 원본 벡터를 기준으로 진행하고, 실제 좌표계 표시와 길이 정규화 표시만 별도 처리해야 해.

```
import numpy as npA = np.array([[2, 1],              [1, 2]], dtype=float)x0 = np.array([1, 0], dtype=float)def transformed(k):    return np.linalg.matrix_power(A, k) @ x0def normalized_direction(k):    x = transformed(k)    return x / np.linalg.norm(x)
```

둘째, 길이가 과도하게 커질 때는 카메라를 계속 확대·축소하는 대신 장면 목적에 맞게 표현을 바꾸자. 0\~19초는 실제 벡터의 방향 변화가 보이는 범위에서 연출하고, 19초부터는 정규화된 벡터로 방향을 비교한다. 84\~96초에서는 고유성분의 배율 자체를 별도 막대그래프로 보여주는 편이 훨씬 명료해.

셋째, 행렬 적용과 정규화의 순서를 정확히 유지해야 해. 장면별로 \\(A^kx_0\\)를 계산한 다음 길이를 정규화해 표시하면 된다. 이 행렬과 초기 조건에서는 매 단계 정규화 후 다음 행렬을 적용해도 같은 방향이 나오지만, 실제 크기를 설명하는 장면에는 반드시 정규화 전 값을 사용해야 해.

넷째, 공통 시각 언어를 다음 영상에서도 유지하자. 파랑은 현재 벡터, 청록은 첫 번째 고유방향, 주황은 두 번째 고유방향으로 고정해. 그러면 3막의 벡터 분해, 4막의 기저 변경, 5막의 대각화에서 별도의 색상 설명 없이도 동일한 수학적 대상을 추적할 수 있어.

## 5. 최종 연출 방향

이번 1편에서는 크게 세 가지 화면만 기억에 남으면 성공이야.

1. 처음의 이상한 현상: 여러 벡터가 반복 변환 후 특정 직선에 가까워진다.
2. 중간의 발견: 행렬에는 3배와 1배로 작용하는 두 고유방향이 있다.
3. 마지막의 설명: 두 성분의 성장률 차이가 전체 벡터의 방향을 결정한다.

119초를 모두 빠르게 화면 전환하는 것보다, 벡터가 실제로 움직이는 시간을 충분히 확보하는 편이 좋아. 특히 26\~33초의 다중 벡터 수렴과 84\~105초의 고유성분 성장 장면은 시청자가 현상을 직접 관찰해야 하는 구간이므로 애니메이션을 너무 빠르게 진행하지 않는 것을 추천해.

이 영상은 고윳값의 정의를 설명하는 강의라기보다, 행렬을 반복하는 실험에서 고윳값과 고유벡터를 발견하는 수학적 관찰 영상으로 제작하는 것이 핵심이야.

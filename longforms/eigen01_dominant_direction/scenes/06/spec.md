# 06. 행렬 자체에 주목하다

- 확정 구간: 34–45초 (사용자 콘티 기준)
- 길이: 11초
- 음성: 미제공. 문장별 종료 시각은 추정하지 않음.
- 시작·종료 상태 및 화면 지시: 아래 사용자 콘티 준수
- 연결: 별도 복습·예고 없이 독립 결론과 시각적 연결만 사용
- 수학: A=((2,1),(1,2)), x₀=(1,0), v₁=(1,1), v₂=(1,−1). 정규화는 표시 목적.

행렬 자체에 주목하다

00:34–00:45 · 탐구 대상 전환

내레이션

> 행렬은 벡터의 방향에 따라 서로 다른 변환 결과를 만들어냅니다. 대부분의 벡터는 이 행렬을 적용하면 방향이 달라집니다. 그런데 어떤 방향에서는 벡터가 원래의 직선 위에 남습니다.

화면 연출

- 반복 변환을 멈추고 좌표 격자를 초기 상태로 복원한다.
- 행렬 \\(A\\)를 상단 중앙에 제시한다.
- 원점 주변에 12\~16개의 벡터를 방사형으로 배치한다.
- 모든 벡터에 한 번만 행렬을 적용한다.
- 대부분의 벡터는 원래 직선에서 벗어난다.
- 두 특별한 직선 위의 벡터만 각각 원래 직선 위에 남는다.

\\[ A=\begin{pmatrix}2&1\\\1&2\end{pmatrix} \\]

이 시점부터 실제 행렬 원소를 공개한다.

시각적 강조

다른 벡터는 투명도를 낮추고, 두 고유방향만 청록색과 주황색으로 남긴다.

이 장면이 영상 전체에서 가장 중요한 발견 순간 중 하나야.

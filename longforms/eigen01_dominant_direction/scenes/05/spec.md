# 05. 서로 다른 초기 벡터를 비교

- 확정 구간: 26–34초 (사용자 콘티 기준)
- 길이: 8초
- 음성: 미제공. 문장별 종료 시각은 추정하지 않음.
- 시작·종료 상태 및 화면 지시: 아래 사용자 콘티 준수
- 연결: 별도 복습·예고 없이 독립 결론과 시각적 연결만 사용
- 수학: A=((2,1),(1,2)), x₀=(1,0), v₁=(1,1), v₂=(1,−1). 정규화는 표시 목적.

서로 다른 초기 벡터를 비교

00:26–00:34 · 현상 일반화

내레이션

> 처음에 서로 다른 방향을 향하던 벡터들도, 같은 행렬을 반복해서 적용하면 점차 하나의 직선 방향으로 정렬됩니다. 왜 이런 일이 일어날까요?

화면 연출

- 원점에서 출발하는 6\~8개의 벡터를 배치한다.
- 각각 다른 각도를 갖되, 고윳값 3인 성분이 0이 아닌 벡터들로 설정한다.
- 모든 벡터에 동일한 행렬을 반복 적용하고 단계마다 정규화한다.
- 최종적으로 벡터들이 \\(y=x\\) 직선 쪽으로 모인다.
- 첫 번째 고유성분의 부호가 서로 다르면 직선의 반대쪽으로 모이는 것도 보여준다.

화면 중앙 메시지

## 서로 다른 시작점, 같은 고유직선

다만 모든 벡터가 한쪽을 향해 정렬되게 연출하려면 초기 벡터를 \\(x+y>0\\)인 영역에서 선택하면 돼.

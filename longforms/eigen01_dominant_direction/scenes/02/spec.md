# 02. 같은 행렬을 반복 적용

- 확정 구간: 3–12초 (사용자 콘티 기준)
- 길이: 9초
- 음성: 미제공. 문장별 종료 시각은 추정하지 않음.
- 시작·종료 상태 및 화면 지시: 아래 사용자 콘티 준수
- 연결: 별도 복습·예고 없이 독립 결론과 시각적 연결만 사용
- 수학: A=((2,1),(1,2)), x₀=(1,0), v₁=(1,1), v₂=(1,−1). 정규화는 표시 목적.

같은 행렬을 반복 적용

00:03–00:12 · 행렬 작용 관찰

동일한 행렬 A를 적용할 때마다 벡터의 방향이 달라진다.

내레이션

> 이제 이 벡터에 같은 행렬을 반복해서 적용해 보겠습니다. 첫 번째 변환에서 벡터의 방향이 바뀝니다. 두 번째 변환에서도 방향이 달라집니다.

화면 연출

- 우측 상단에 행렬 \\(A\\)를 작게 표시한다.
- \\(x_0\to x_1\to x_2\\) 순서로 파란 화살표를 변형한다.
- 각 단계에서는 실제 행렬곱 결과를 사용한다.
- 벡터의 끝점이 이동하고, 길이와 기울기가 함께 변한다.
- 화면 측면에 `A 적용 횟수: 0 → 1 → 2`를 표시한다.

Manim 구현: `Arrow` 객체를 `Transform` 혹은 `ReplacementTransform`으로 변화시키고, 좌표 격자는 고정한다.

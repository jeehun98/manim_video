# 자연의 최적화 05 — 제작 기준

사용자 확정 38문장과 종료 시각, 총 162초를 유지한다. 27개 독립 씬으로 제작하고 세로 1080×1920·가로 1920×1080, 각 30fps로 출력한다. 음원이 없으므로 자막 포함 무음 영상이다. 일반적인 복습·예고는 넣지 않으며 원고에 명시된 143–152초의 네 현상 비교는 유지한다.

## 핵심

동일한 공의 운동을 국소적인 힘과 전체 이력의 변분 조건으로 설명한다. 공간 곡선의 모양만 비교하지 않으며 q(t)와 시간 재매개화 q(t²/4)를 구별한다. 가상 이력은 실제로 중력 아래에서 가능한 자유비행이라고 주장하지 않는다.

실제 궤적은 x=t, y=.5+2t−t²/2, 0≤t≤4, m=g=1. 처음과 끝의 높이가 .5이고 정점은 2.5다. 전체 운동 에너지에는 수평 속도 항도 포함한다. 유도 구간에서는 수직 성분에 집중하며 수평 작용은 고정한 x(t)에 대해 공통인 상수임을 명시한다.

변형 yε=y*+εsin(πt/4)는 끝점 위치·시간을 지킨다. 속도 역시 ẏε=ẏ*+επcos(πt/4)/4로 계산한다. 초기 속도는 가상 후보 전체에 고정하는 제약이 아니다. 작용은 Sε=S0+π²ε²/16으로 실제 최소이며 유한 변화량이 0이라는 표현은 쓰지 않는다. 안장점은 별도의 일반 수학 예시 f(u,v)=u²−v²로 표시한다. 최댓값 도식 역시 일반 정지점이며 이 공의 작용으로 제시하지 않는다.

L(t)는 양·음 구간이 있고 S는 부호 있는 누적값이다. 뉴턴 초기값 적분과 작용에서 유도한 고정 끝점 차분식의 해를 별도로 구해 일치 여부를 확인한다. 부분적분의 경계항이 η(0)=η(4)=0으로 사라지고 임의의 η에 대해 mÿ+mg=0이라는 핵심을 보여준다.

검증은 동일 운동 데이터, 에너지 보존, 변형의 끝점, 작용 적분·해석식 일치, 일차 변화, 두 해법·초기 조건 일치, 장면·자막 연속 시각, 실제 디코딩 프레임 수를 포함한다. 최종 출력은 각 4860프레임이다.

# 25 — 최소화만이 전부는 아니다

## 목적과 핵심 주장
최소화만이 전부는 아니다

## 앞 장면에서 받은 내용
운동 전체를 하나의 조건으로

## TTS 원문과 확정 길이
사용자 확정 143–152초, 9초.

지금까지는 표면에너지, 위치에너지, 이동 시간을 최소화하는 문제를 살펴봤습니다.
하지만 자연의 운동이 언제나 어떤 값을 최소화하는 것은 아닙니다.

## 화면과 시간별 애니메이션
원고에 명시된 비눗막·현수선·굴절·사이클로이드 아이콘과 대상량을 간결하게 표시한다. 추가 복습·다음 편 예고는 넣지 않는다.
남는 구간은 결론 상태를 유지한다. 코드에서 누적 시간을 검사해 길이를 초과하지 않는다.

## 화면 텍스트
제목: 최소화만이 전부는 아니다. 수식과 수치는 visuals.py 및 physics.py를 따른다. 전체 자막은 timing.json 기준이다.

## 시작·종료 상태
대상을 독립 제시 → 관찰·변화 → 제목에 해당하는 결론 상태.

## 다음 시각적 연결
더 일반적인 조건 · 일차 변분 0

## 조건·과장 방지
균일 중력 g=1, 질량 m=1, 공기 저항 없음, t=0..4, x=t, y=.5+2t−t²/2. 모든 장면에서 동일 데이터. 끝점 시간·위치는 고정하며 가상 후보의 초기 속도는 고정하지 않는다. ε 변형에 위치와 속도를 함께 재계산한다. V=mgy, S는 부호 있는 적분. 포물선의 S는 최소이며 일반 정지점 도식과 구별한다. 음원 미제공, 영상 내 자막 시각은 사용자 원문 기준.

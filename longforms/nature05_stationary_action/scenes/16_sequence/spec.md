# 16 — 정지작용 ≠ 항상 최소작용

## 목적과 핵심 주장
정지작용 ≠ 항상 최소작용

## 앞 장면에서 받은 내용
작용의 일차 변화량이 0

## TTS 원문과 확정 길이
사용자 확정 84–94초, 10초.

흔히 최소작용 원리라고 부르지만, 실제 운동이 반드시 작용을 최소화하는 것은 아닙니다.
최솟값뿐 아니라 다른 정지점에서도 일차 변화량은 0이 될 수 있기 때문입니다.

## 화면과 시간별 애니메이션
이 포물선의 S는 최소라는 점을 먼저 확인. 별도의 수학적 f(u,v)=u²−v² 안장점을 표시한다. 안장점은 공의 작용 그래프가 아니다.
남는 구간은 결론 상태를 유지한다. 코드에서 누적 시간을 검사해 길이를 초과하지 않는다.

## 화면 텍스트
제목: 정지작용 ≠ 항상 최소작용. 수식과 수치는 visuals.py 및 physics.py를 따른다. 전체 자막은 timing.json 기준이다.

## 시작·종료 상태
대상을 독립 제시 → 관찰·변화 → 제목에 해당하는 결론 상태.

## 조건·과장 방지
균일 중력 g=1, 질량 m=1, 공기 저항 없음, t=0..4, x=t, y=.5+2t−t²/2. 모든 장면에서 동일 데이터. 끝점 시간·위치는 고정하며 가상 후보의 초기 속도는 고정하지 않는다. ε 변형에 위치와 속도를 함께 재계산한다. V=mgy, S는 부호 있는 적분. 포물선의 S는 최소이며 일반 정지점 도식과 구별한다. 음원 미제공, 영상 내 자막 시각은 사용자 원문 기준.

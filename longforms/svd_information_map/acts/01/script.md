# 1막 — 검토용 대본

상태: 사용자 검토 전 초안. 발화시간 미확정.

## 01. 같은 변화, 다른 반응

같은 거리만큼 떨어진 두 입력은, 행렬을 통과한 뒤에도 같은 거리만큼 떨어져 있을까요? 가로로 조금 움직인 입력과 세로로 조금 움직인 입력을 생각해보겠습니다. 두 변화의 길이는 같습니다. 그런데 어떤 행렬은 가로의 차이를 크게 벌리고, 세로의 차이는 거의 붙여 놓습니다.

행렬은 숫자를 바꾸는 동시에 입력 사이의 차이를 바꿉니다. 어떤 차이는 선명하게 드러내고, 어떤 차이는 거의 보이지 않게 만듭니다. 행렬은 어떤 차이를 남기고, 어떤 차이를 잃을까요?

## 02. 단위원은 반응의 지도다

입력의 길이를 일로 고정하고 방향만 돌려보겠습니다. 각 방향에 같은 행렬을 적용하고 출력 화살표의 끝점을 표시합니다. 이차원에서는 이 점들이 타원을 그립니다.

타원의 긴 축은 큰 출력이 나오는 방향을, 짧은 축은 작은 출력이 나오는 방향을 보여줍니다. 입력 방향과 출력 방향은 구별해야 합니다. 행렬은 길이뿐 아니라 방향도 바꾸기 때문입니다. 이 타원은 모든 단위 입력 방향에 대한 반응을 모은 지도입니다.

## 03. 방향과 배율을 짝짓는다

특별한 입력 방향들을 고르면 이 방향들은 서로 직교하고, 영이 아닌 출력들도 서로 직교하는 방향에 놓입니다. 각 입력 방향에 길이 일의 벡터를 넣었을 때 출력의 길이가 바로 특잇값입니다.

입력 방향을 브이, 출력 방향을 유, 그 사이의 배율을 시그마라고 부르겠습니다. 특잇값이 삼이면 세 배로 전달되고, 영 점 일이면 십분의 일로 줄어듭니다. 특잇값 분해, 에스브이디는 이 입력 방향과 배율, 출력 방향의 짝을 찾아줍니다.

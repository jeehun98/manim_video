# 제작 기준

- 핵심 질문: 행렬은 어떤 입력 차이를 남기고 어떤 차이를 잃는가?
- 학습 목표: SVD의 방향별 전달로 복원 민감도, 정보 소실, 근사를 설명한다.
- 전제: 벡터와 행렬곱의 기초. SVD 사전 지식은 요구하지 않는다.
- 독립 씬 15개를 5막으로 묶는다. 한 씬은 주장 하나로 제작한다.
- 이전 쇼츠 복습과 후속 영상 예고를 넣지 않는다. 마지막 씬은 현재 질문의 결론이다.
- 원본 숫자·영문·수식은 화면에 유지한다. 발음용 표기는 TTS 원고에서만 쓴다.
- 대본 검토 → 대본 확정 → 실제 TTS 길이 → 화면·자막 → 미리보기 → 최종 렌더·mux·concat 순서를 따른다.
- 추정 시간, 이전 쇼츠 길이, 글자 수 비례로 새 대본의 타이밍을 확정하지 않는다.

## 정확성 및 화면 기준

| 씬 | 조건 및 화면 표기 |
|---|---|
| 01 | Δy=AΔx. 같은 크기의 두 입력 변화를 비교한다. |
| 02 | ||x||₂=1. 비특이 2×2 예시에서 시작한다. 특이한 경우 타원은 퇴화한다. |
| 03 | Avᵢ=σᵢuᵢ. 영벡터의 출력 방향은 정의하지 않는다. |
| 04 | cᵢ=vᵢᵀx. 실수 행렬의 직교 기준. |
| 05 | A=UΣVᵀ; Ax=Σᵢσᵢ(vᵢᵀx)uᵢ. 직교변환은 반사도 포함한다. |
| 06 | A=diag(1,0.1); δy=(0,0.01) → δx=(0,0.1). |
| 07 | κ₂(A)=σmax/σmin. 가역 정사각행렬과 2-노름. 절대오차 증폭과 상대오차 조건수를 구분한다. |
| 08 | x+y=1, x+1.01y=1.01. 두 번째 우변을 1.02로 바꾸면 교점 (0,1)→(−1,2). |
| 09 | Av=0 ⇒ A(x+tv)=Ax. |
| 10 | rank(A)=양의 특잇값의 개수. 내부를 포함하는 단위공을 쓴다. 수치 Rank는 허용오차에 의존한다. |
| 11 | A⁺=VΣ⁺Uᵀ. 최소제곱해 중 최소 2-노름 해. 작은 양의 특잇값의 역수도 오차를 증폭한다. |
| 12 | Aₖ=Σᵢ₌₁ᵏσᵢuᵢvᵢᵀ; σ₁≥…≥σᵣ>0. 작은 성분을 무조건 잡음으로 규정하지 않는다. |
| 13 | mn 대 k(m+n+1). 동일 자료형의 수치 개수 비교다. 실제 파일 압축률로 단정하지 않는다. 이미지 선정 후 실제 복원을 확인한다. |
| 14 | ||A−Aₖ||F²=Σᵢ₌ₖ₊₁ʳσᵢ²; rank≤k 최적. 동률이면 최적해가 유일하지 않을 수 있다. Eₖ=Σᵢ₌₁ᵏσᵢ²/Σᵢ₌₁ʳσᵢ², A≠0. 상대 Frobenius 오차는 √(1−Eₖ). |
| 15 | 입력 방향 → 배율 → 출력 방향으로 중심 질문을 회수한다. |

수학적 범위는 실수 유한차원 행렬이다. 영상은 2차원 예시에서 시작하며 3차원 Rank 시각화와 이미지 행렬로 확장한다. 씬별 시간대와 전환은 실제 발화시간 확보 후 설계한다.

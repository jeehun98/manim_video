# SVD — 행렬이 남기는 차이의 지도

> 현재 1막 제작본은 [svd01_distinguish_inputs](../svd01_distinguish_inputs/README.md)이다. 아래 5막·15씬 자료는 관점 전환 전 초안이며 현재 1막의 대본·타이밍으로 사용하지 않는다.

- 상태: 대본 초안, 사용자 검토 전. 실제 발화시간 미확정.
- 화면 기본안: 1920×1080, 30fps.
- 제작: 독립 씬별 렌더·mux → 5개 막별 결합 → 전체 concat.
- 길이는 확정 대본의 TTS 또는 사용자 발화 시각으로 결정한다.

사용자가 붙인 쇼츠 제목·설명을 바탕으로 롱폼 대본을 새로 작성했다. 현재 episodes/와 archive/에서는 해당 SVD 쇼츠 소스를 찾지 못했다. 붙여넣은 설명에는 잘린 문장이 있어 전체 쇼츠 발화 대본으로 간주하지 않는다.

master_script.md가 검토 기준이다. 수정 시 막별·씬별 원고를 함께 갱신한다. scenes.yaml은 씬 순서와 막 소속을 기록한다. scene.py, 자막, 타이밍, 렌더 등록은 대본 및 실제 발화시간 확정 후 만든다. 현재 실행 가능한 렌더 명령은 없다.

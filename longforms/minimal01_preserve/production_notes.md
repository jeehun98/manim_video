# 제작·검토 기록

## 입력과 타이밍

사용자 확정 대본 36문장, 마지막 종료 154초. 이전 기획의 ETH 대본을 사용하지 않았다. 새 발화의 시작은 직전 문장의 제공 종료 시각으로 기록했으며 문장 내부에 추정 자막 분할을 넣지 않았다. 음원은 제공되지 않아 무음으로 제작한다.

## 주요 시각 변화의 절대 시각

| 구간 | 화면 변화 |
| --- | --- |
| 0–2 | 200개 숫자가 행 단위로 등장 |
| 2–7 | 첫 쌍과 전체 반복 패턴 강조 |
| 7–13 | `[1, 2] × 100`으로 변환 |
| 13–17 | 숫자열을 펼치고 원본 복원 가능 표시 |
| 17–34 | 표현의 이점, 계산 자원 절감의 조건, 보존 질문 |
| 34–41 | 전체 복원 / 특정 결과 보존 두 관점 |
| 41–51 | `[1,2] × 3`을 여섯 숫자로 복원 |
| 51–59 | 같은 숫자열을 `1의 개수 = 3`으로 요약 |
| 59–65 | A–D 네 지점과 길이 1인 네 도로 |
| 65–73 | 연결 조건에서 AB를 제거하고 A–D–C–B 경로 확인 |
| 73–83 | 동일한 삭제 상태에서 최단거리 조건으로 변경, A–B 1→3 |
| 83–88 | 동일 삭제에 대한 연결성 유지 / 거리 변화 비교 |
| 88–100 | HHHHHTTTTT에서 앞면 다섯 개 강조 후 횟수 요약 |
| 100–114 | 질문 변경, HHHHHTTTTT와 HTHTHTHTHT의 최대 연속 5/1 |
| 114–123 | 질문과 필요한 정보의 관계 |
| 123–132 | 조건 정의 → 구조 축소 → 결과 확인 |
| 132–143 | 가상 100→30, 더 작은 미지 후보와 최소성 구분 |
| 143–154 | 세 사례의 짧은 표식과 같음의 정의에 대한 결론 |

## 내용 검산

- `[1,2]`를 100회 반복한 200항 원본과 실제 화면 숫자가 일치한다.
- AB 제거 뒤 모든 네 지점이 연결되며 A–B 최단거리는 3이다. 삭제 전은 1이다.
- 두 동전 배열은 모두 앞면 5개이며 최대 연속 앞면은 각각 5와 1이다.
- 가상 숫자는 화면에 가상 예시라고 명시한다. 절대 최소라는 주장을 하지 않는다.
- 문장 시각 연속성, 씬 15개 길이 합 154초를 확인했다.

## 시각 검토

세로·가로 미리보기의 각 20개 표본 프레임에서 숫자, 도로, 동전, 결론을 확인했다. 가로판의 마지막 질문·보조 문구, 가상 예시의 점선 상자·보조 문구 간격을 수정했다. 가로 도로의 A/B 표식이 조건 카드와 겹치지 않도록 크기를 조정했다. 도로의 길이 1은 지속 표시하며 도로 삭제 직후 개수도 4→3으로 갱신한다.

최종본의 프레임 수·해상도·길이는 `verification_final.json`, 검토용 이미지들은 Git 제외 경로 `media/minimal01_review/`에 둔다. 실제 음성이 없으므로 발화와의 청각적 동기 검토는 수행하지 않았다. 제공 시각과 화면·자막의 일치를 기준으로 제작했다.

## 최종 확인 결과

- 세로: 1080×1920, 30fps, 4,620프레임, 154.000000초.
- 가로: 1920×1080, 30fps, 4,620프레임, 154.000000초.
- 두 최종 MP4 모두 FFmpeg 전체 디코딩 검사에서 오류 없이 통과했다.
- 수정 후 최종본에서 화면비별 20개 표본 프레임을 다시 추출해 도로의 길이·개수, 동전 비교, 결론의 간격을 확인했다.
- 미리보기 파일은 수정된 최종본을 축소해 갱신한다.

## 자막 전환 오류 수정

사용자 확인으로 문장 전환 직후 이전 자막이 남아 겹치는 문제를 발견했다. 최초 표본 프레임 검토는 전환 경계를 충분히 확인하지 못했다. 원인은 Manim Cairo의 애니메이션 중 자막 그룹 자식 객체 교체와 캐시 사이의 불일치였다.

전체 발화 자막을 Manim 씬에서 분리하고 concat 후 단일 ASS 트랙으로 합성한다. 시작 포함·종료 제외 시각으로 설정해 같은 프레임에 두 문장이 표시되지 않게 한다. 기존 렌더의 자막 전용 영역도 초기화해 잔상을 제거한다. 154초 타이밍과 도형·애니메이션은 유지한다.

36개 문장 시작 시각의 직전·정각·직후 및 마지막 프레임을 화면비별 108개 추출해 깨끗한 기준 자막과 비교했다. 텍스트 픽셀 마스크 최소 IoU는 세로 0.978, 가로 0.971로, 이전 문장의 잔상 없이 단일 기준 자막과 일치함을 확인했다. 주요 경계는 이미지로도 재검토했다. 상세 결과는 `caption_boundary_verification_shorts.json`, `caption_boundary_verification_longform.json`에 기록한다.

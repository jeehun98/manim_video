# 14 — 전체 배열의 인덱스

- 목적·주장: 전역 index는 Block 위치와 내부 위치를 결합한다.
- 입력 상태: Block 내부의 위치
- 확정 구간: 121–128초 (7초), 사용자 문장 종료 시각. 음원 미제공.
- TTS 원문: [script.txt](script.txt). 실제 음원 길이는 미측정.
- 화면·타임라인: 공통 visuals.py의 INDEX=13 분기. 문장 종료 시각에 따라 코드 강조·값·연결 변화.
- 화면 텍스트: 전체 배열의 인덱스; 해당 CUDA 식과 실제 배열 값.
- 시작·종료 상태: 해당 주장 대상 등장 → 동작 시각화 → 주장이 드러난 상태 유지.
- 연결: 좌표는 논리적인 위치
- 정확성: 논리 실행 문맥과 물리 연산기를 구별. Register 배치는 개념도이며 기계 명령 trace가 아님. 세로·가로 레이아웃 공통 주장.

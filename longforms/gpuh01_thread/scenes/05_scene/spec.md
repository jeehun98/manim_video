# 05 — 코드와 실행 문맥

- 목적·주장: CUDA 코드 표현은 Thread의 동작과 대응한다.
- 입력 상태: 반복문에서 Thread로
- 확정 구간: 36–48초 (12초), 사용자 문장 종료 시각. 음원 미제공.
- TTS 원문: [script.txt](script.txt). 실제 음원 길이는 미측정.
- 화면·타임라인: 공통 visuals.py의 INDEX=4 분기. 문장 종료 시각에 따라 코드 강조·값·연결 변화.
- 화면 텍스트: 코드와 실행 문맥; 해당 CUDA 식과 실제 배열 값.
- 시작·종료 상태: 해당 주장 대상 등장 → 동작 시각화 → 주장이 드러난 상태 유지.
- 연결: Block 안의 네 Thread
- 정확성: 논리 실행 문맥과 물리 연산기를 구별. Register 배치는 개념도이며 기계 명령 trace가 아님. 세로·가로 레이아웃 공통 주장.

## 확정 화면 동작

36–40초 kernel 정의 강조. 40–44초 __global__ 강조 유지. 44–48초 threadIdx.x와 Block 내부 Thread 1 연결.

## 문장별 종료 시각과 원문

36–40초: 화면의 코드는 GPU에서 실행되는 CUDA 커널입니다.

40–48초: 여기서 __global__은 GPU에서 실행할 커널 함수를 정의하고, threadIdx.x는 블록 내부에서 현재 스레드의 인덱스를 나타냅니다.

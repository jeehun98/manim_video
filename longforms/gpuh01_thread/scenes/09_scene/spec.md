# 09 — 읽기 · 계산 · 저장

- 목적·주장: Thread는 읽기·계산·저장 중 중간 상태를 유지한다.
- 입력 상태: 하나의 코드, 네 실행
- 확정 구간: 70–81초 (11초), 사용자 문장 종료 시각. 음원 미제공.
- TTS 원문: [script.txt](script.txt). 실제 음원 길이는 미측정.
- 화면·타임라인: 공통 visuals.py의 INDEX=8 분기. 문장 종료 시각에 따라 코드 강조·값·연결 변화.
- 화면 텍스트: 읽기 · 계산 · 저장; 해당 CUDA 식과 실제 배열 값.
- 시작·종료 상태: 해당 주장 대상 등장 → 동작 시각화 → 주장이 드러난 상태 유지.
- 연결: SM의 Register File
- 정확성: 논리 실행 문맥과 물리 연산기를 구별. Register 배치는 개념도이며 기계 명령 trace가 아님. 세로·가로 레이아웃 공통 주장.

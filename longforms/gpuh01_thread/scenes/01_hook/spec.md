# 01 — GPU에서 Thread로

- 목적·주장: Thread는 논리적인 실행 단위다.
- 입력 상태: GPU 전체 지도
- 확정 구간: 0–8초 (8초), 사용자 문장 종료 시각. 음원 미제공.
- TTS 원문: [script.txt](script.txt). 실제 음원 길이는 미측정.
- 화면·타임라인: 공통 visuals.py의 INDEX=0 분기. 문장 종료 시각에 따라 코드 강조·값·연결 변화.
- 화면 텍스트: GPU에서 Thread로; 해당 CUDA 식과 실제 배열 값.
- 시작·종료 상태: 해당 주장 대상 등장 → 동작 시각화 → 주장이 드러난 상태 유지.
- 연결: 논리적인 실행 문맥
- 정확성: 논리 실행 문맥과 물리 연산기를 구별. Register 배치는 개념도이며 기계 명령 trace가 아님. 세로·가로 레이아웃 공통 주장.

## 확정 화면 동작

0–3초 GPU의 여러 작업 칸 활성화. 3–7초 실행 범위를 좁히는 논리 지도. 7–8초 Thread 카드로 확대.

## 문장별 종료 시각과 원문

0–3초: GPU는 수많은 계산을 병렬로 처리합니다.

3–7초: 그렇다면 그 계산을 수행하는 가장 기본적인 실행 단위는 무엇일까요?

7–8초: 바로 스레드입니다.

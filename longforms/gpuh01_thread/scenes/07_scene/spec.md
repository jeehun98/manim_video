# 07 — 서로 다른 데이터

- 목적·주장: 각 Thread가 다른 입력과 출력을 담당한다.
- 입력 상태: Block 안의 네 Thread
- 확정 구간: 55–62초 (7초), 사용자 문장 종료 시각. 음원 미제공.
- TTS 원문: [script.txt](script.txt). 실제 음원 길이는 미측정.
- 화면·타임라인: 공통 visuals.py의 INDEX=6 분기. 문장 종료 시각에 따라 코드 강조·값·연결 변화.
- 화면 텍스트: 서로 다른 데이터; 해당 CUDA 식과 실제 배열 값.
- 시작·종료 상태: 해당 주장 대상 등장 → 동작 시각화 → 주장이 드러난 상태 유지.
- 연결: 하나의 코드, 네 실행
- 정확성: 논리 실행 문맥과 물리 연산기를 구별. Register 배치는 개념도이며 기계 명령 trace가 아님. 세로·가로 레이아웃 공통 주장.

## 확정 화면 동작

55–57초 Thread 0: 1+10. 57–59초 Thread 1: 2+20. 59–60.5초 Thread 2: 3+30. 60.5–62초 Thread 3: 4+40.

## 문장별 종료 시각과 원문

55–59초: 스레드 0은 1과 10을 더하고, 스레드 1은 2와 20을 더합니다.

59–62초: 나머지 스레드도 각자 다른 원소를 계산합니다.

# A 1편 — 행렬곱의 계산량은 왜 n³보다 작아질 수 있을까?

- 시리즈: AI가 도전한 수학의 난제
- ID: aimath_a01
- 상태: 대본·콘티 초안 v0.1
- 편집 목표: 약 7–9분, TTS 실측 후 길이 확정
- 화면 제안: 1920×1080, 30fps

## 학습 목표

표준 n³ 비용, 중간 결과 공유·소거, Strassen의 재귀 구조, 상한과 최적값의 차이를 이해한다.

## 핵심 결론

계산을 공동으로 재조합하면 행렬곱의 성장률을 낮출 수 있다. 새 상한은 최적값이나 GPU 속도의 확정과 다르다.

## 제작 상태

master_script.md, scenes.yaml, 14개 씬의 spec.md·script.txt, sources.md를 작성했다. 시간은 실측 전 null이며 애니메이션은 상대 구간으로 제안한다. Manim·TTS·자막·영상은 아직 제작하지 않았다.

새 9/4 원고의 본문 접근이 실패하여 구체적인 새 증명 기법은 설명하지 않는다. 공개 목록과 형식화 안내의 주장 범위까지만 반영한 문제 이해 중심 초안이다.

## 다음 단계

대본 검토 → 새 원고 본문 조사·검증 상태 갱신 → TTS 생성·길이 측정 → 씬 타임라인 확정 → Manim → mux → concat.

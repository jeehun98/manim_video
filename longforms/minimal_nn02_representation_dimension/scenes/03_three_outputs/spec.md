# 03 — 세 뉴런의 세 출력을 독립적으로 조절한다

## 목적·핵심 주장
세 뉴런의 세 출력을 독립적으로 조절한다

## 앞 장면에서 받은 내용
뉴런 수보다 낮은 측정 차원이 보고되었다

## TTS 원문과 확정 길이
세 개의 뉴런이 각각 하나의 숫자를 출력한다고 생각해 보겠습니다.

일반적으로 세 숫자를 독립적으로 변경하려면 세 개의 변수가 필요합니다.

사용자 종료 시각 기준 18–27초, 9초. 전체 timing.json의 문장 경계를 그대로 적용한다. 문장 중간 씬 경계가 있으면 문장을 끊지 않고 자막을 이어 표시한다. 음원 미제공.

## 화면·애니메이션·텍스트
18–22초 뉴런 3개와 각 출력 h1,h2,h3, 22–27초 값을 독립적으로 바꾸고 자유도 3을 표시한다.

## 시작·종료 상태와 연결
독립 교체 가능한 영상으로 완결하고, 다음 씬에서 같은 곡선 또는 그래프를 동일 배치로 이어받는다.

## 정확성·출처
Ansuini et al., NeurIPS 2019; Schulte & Rügamer, AISTATS 2026. 층별 곡선은 보고된 경향을 설명하는 정성 도식이며 정량 재현이 아니다. 변위 실험은 해당 논문의 직접 반례 재현이 아니다. 수학적 구조와 표본 추정을 구분한다. 사용자의 최신 요청에 따라 영상 내부에는 도식·원문 데이터 여부에 관한 안내 자막을 넣지 않고 제작 문서에만 기록한다.

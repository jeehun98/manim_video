# 05 — 좌표 세 개와 독립 변수 하나를 구분한다

## 목적·핵심 주장
좌표 세 개와 독립 변수 하나를 구분한다

## 앞 장면에서 받은 내용
세 출력 t, t², t³는 한 곡선 위에서 움직인다

## TTS 원문과 확정 길이
이처럼 데이터를 표현하는 데 필요한 독립적인 변수의 수를 내재 차원, Intrinsic Dimension이라고 합니다.

사용자 종료 시각 기준 42–49초, 7초. 전체 timing.json의 문장 경계를 그대로 적용한다. 문장 중간 씬 경계가 있으면 문장을 끊지 않고 자막을 이어 표시한다. 음원 미제공.

## 화면·애니메이션·텍스트
42–45초 3개 좌표축 강조. 45–49초 축을 어둡게 하고 곡선과 내재 차원 1 강조. 이 수학적 예시의 미분은 (1,2t,3t²)로 항상 영벡터가 아니다.

## 시작·종료 상태와 연결
독립 교체 가능한 영상으로 완결하고, 다음 씬에서 같은 곡선 또는 그래프를 동일 배치로 이어받는다.

## 정확성·출처
Ansuini et al., NeurIPS 2019; Schulte & Rügamer, AISTATS 2026. 층별 곡선은 보고된 경향을 설명하는 정성 도식이며 정량 재현이 아니다. 변위 실험은 해당 논문의 직접 반례 재현이 아니다. 수학적 구조와 표본 추정을 구분한다. 사용자의 최신 요청에 따라 영상 내부에는 도식·원문 데이터 여부에 관한 안내 자막을 넣지 않고 제작 문서에만 기록한다.

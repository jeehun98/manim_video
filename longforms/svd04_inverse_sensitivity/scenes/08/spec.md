# 08 — 복원된 절대 오차

## 목적과 핵심 주장
절대 출력 오차0.0001이 절대 입력 오차0.1이 된다

## 앞 장면에서 받은 내용
관측값에도 같은÷0.001을 적용하면1.1

## TTS 원문과 확정 길이
원래 입력 성분은 1이었지만, 복원한 값은 1.1이 되었습니다.

출력에서는 0.0001에 불과했던 절대 오차가, 입력을 복원한 뒤에는 0.1로 커진 것입니다.

사용자 종료 시각 기준 60–70초, 10초. 음원 미제공.

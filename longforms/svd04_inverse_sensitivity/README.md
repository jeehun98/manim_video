## 계산과 실험의 구분

0–16초는 이전 A=R(60°)diag(2,0.5)R(−30°)의 계산 구조를 사용한다. 16초에 새 실험 A=diag(1,0.001)임을 명시한다. 85–114초에는 A₁=0.001I와 A₂=diag(1,0.001)를 비교한다. 114초에는 같은 A₂에서 기준 입력을(1,0)으로 바꾼 별도 상대오차 실험임을 표시한다. 161초에 정확히 A₀=diag(1,0)으로 바뀐다.

| 실험 | 정확한 입력 x | 정확한 출력 y | 관측 오차 δy | 복원 입력 |
|---|---|---|---|---|
| 정확 복원 | (0,1) | (0,0.001) | 0 | (0,1) |
| 절대 오차 증폭 | (0,1) | (0,0.001) | (0,0.0001) | (0,1.1) |
| 상대 오차의 최악 사례 | (1,0) | (1,0) | (0,0.001) | (1,1) |
| 같은 크기의 가로 오차 | (1,0) | (1,0) | (0.001,0) | (1.001,0) |
| 완전한 소실 | (1,0), (1,1) | 모두(1,0) | 오차를 추가하지 않음 | 유일한 복원 불가 |

첫 오차 실험에서 절대 오차는0.0001→0.1로1000배지만, 출력과 입력의 상대 오차는 모두10%다. 이 실험을 조건수1000의 상대증폭 사례로 쓰지 않는다.

별도 상대오차 사례는 |x|₂=|y|₂=1이다. 세로 오차에서 출력 상대0.1%→입력 상대100%, 가로 오차에서는0.1%→0.1%다. κ₂(A₂)=1000은 이 상대 민감도의 최악 상한이다. A₁의 κ₂는1이지만 역변환의 절대 오차 증폭은1000배일 수 있다.

행렬은 정확히 알고 고정되어 있으며 오차는 출력에만 더한다. 가역 정사각행렬과2-노름, x≠0, y≠0 조건에서 δx=A⁻¹δy 및 |δx|/|x| ≤ κ₂(A)|δy|/|y|를 검증한다. 행렬 자체의 오차를 포함하는 문제로 확대하지 않는다.

## 좌표와 시각적 정확성

입력과 출력의 수학적 척도를 동일하게 유지하며 카메라를 확대하지 않는다. 44–53초의 별도 확대창은 출력 세로 차이×10,000이다. 실제0.0001 차이가 확대창에서 길이1로 보인다. 153–161초의 중앙 세로 단면은 별도 척도×1000으로, 실제 지름2×0.001을 길이2로 표시한다. 본 좌표계에서는 미세한 차이가 픽셀상 겹쳐 보여도 수치로 구별한다.

161초 이전까지 배율은0.001이며 반올림하여0으로 표시하지 않는다. 161초부터 정확히0이다. 163초 이후에는 단위 원의 출력 선분 강조를 제거하고, 선택된 입력 후보들의 출력(1,0) 하나만 강조한다. 마지막 입력 집합은 x=(1,t), t∈R로 같은 가로 성분을 가진 수직선이다. 평면 전체가 한 점으로 붕괴하는 것으로 표현하지 않는다.

주어진 내레이션의 이전 실험 언급과 마지막 질문을 그대로 반영한다. 별도의 복습·후속 예고 문구는 추가하지 않는다.

## 실행

프로젝트 루트에서:

```powershell
python longforms/svd04_inverse_sensitivity/build.py --preview
python longforms/svd04_inverse_sensitivity/build.py
```

씬 교체 후 결합:

```powershell
python longforms/svd04_inverse_sensitivity/build.py --scene 15
python longforms/svd04_inverse_sensitivity/build.py --concat-only
```

여러 씬은 `--scenes 11 12 13 14`처럼 지정한다. 기본 동시 렌더3개, `--jobs 1`로 순차 실행 가능. 각 씬이 같은 절대시간 상태를 재현한다. 같은 프레임 시계로 결합하고 사후 속도 변경을 하지 않는다. Manim0.21.0, FFmpeg9.0.1, PyAV, Malgun Gothic 사용.

최종 렌더에서 미리보기를 동기화하려면 `python longforms/svd04_inverse_sensitivity/sync_preview.py`를 실행한다.

출력: exports/svd04_inverse_sensitivity_176s_1080p30.mp4 및 .srt.

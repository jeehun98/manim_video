# Scene 02 — 흐름에서 필요한 힘으로
## 목적과 핵심 주장
흐름에서 필요한 힘으로를 한 장면에서 이해시킨다.
## 앞 장면에서 받은 내용
원하는 모양이면 충분할까?
## TTS 원문과 확정 길이
보통은 힘을 가한 뒤, 물이 어떻게 움직이는지 생각합니다.

이번에는 생각의 방향을 뒤집어 보겠습니다. 먼저 만들고 싶은 흐름을 정합니다.

그리고 그 흐름을 이루려면 어떤 힘이 필요한지 거꾸로 따져봅니다.

이 관점은 출발점입니다. 원하는 흐름을 정했다고 모든 조건이 저절로 맞는 것은 아닙니다.

- TTS: 사용자 측정 19초
- 화면: 19초. 원래 화면 기준은 28초.
## 화면 구성과 시간대별 애니메이션
힘→흐름 화살표 → 방향 반전 → 원하는 흐름→필요한 힘 → 조건 확인
문장 순서대로 timing.json의 ends에 맞춰 cue를 진행한다.
## 화면 텍스트
흐름에서 필요한 힘으로, 에너지·속도·부피 지표, 수식, 출처·날짜, 문장 자막. 영문과 숫자 기호는 화면에 원 표기를 쓴다.
## 시작·종료 상태
첫 대상에서 마지막 대상으로 연속 변형한다. 상단 제목과 하단 자막 영역을 확보한다.

## 수학 조건·과장 방지
외력 역산의 직관이다. 압력과 비압축성 조건, 외력 매끄러움 등 실제 구성의 모든 조건을 생략해 자동으로 증명됐다고 하지 않는다.
모든 단순 모형과 개념도는 실제 NS 해나 신경망의 측정값이 아니다. 실제 해의 정확한 항 수치를 시뮬레이션하지 않는다. 외력이 있는 3막에서는 2막의 curl f=0 조건을 가정하지 않는다.

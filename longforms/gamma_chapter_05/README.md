# 감마함수 5장 — 수학적 개념을 확장한다는 것

팩토리얼의 재귀 관계가 연속적인 적분 표현, 원주율, 확률분포로 이어지는 과정을 관계도로 정리한다. 제공된 9문장, 독립 장면 9개, 65초, 1920×1080, 30fps. 음원 미제공으로 무음이며 화면 자막을 포함한다.

```powershell
python longforms/gamma_chapter_05/build.py --preview --scene 09
python longforms/gamma_chapter_05/build.py
```

최종 영상은 `exports/gamma_chapter_05_long.mp4`에 저장한다. 첫 화면은 4장의 마지막 구도를 사용한다. 마지막 메시지는 65초 발화 구간 안에서 화면에 남긴다.

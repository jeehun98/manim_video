# 2. 상세 영상화 콘티

## ACT 1. 계산은 한 번으로 끝나지 않는다 (00:00–00:31)

목표: 중간 결과의 존재와, 계산 단계마다 회로를 추가하는 방식의 비용을 직관적으로 보여준다.

### 00:00–00:06 | 기존 ALU에서 출발

나레이션: 앞서 우리는 여러 연산 기능을 하나의 ALU에 통합하고, 필요한 연산을 선택하는 방법을 살펴봤습니다.

화면 연출

이전 5편의 마지막 ALU 회로 모습을 간략하게 재구성해 시작해.

화면 중앙에 `ALU`라고 적힌 직사각형 블록이 있고, 왼쪽에는 입력 A와 B 두 개가 연결되어 있어. 내부에는 `ADD`, `SUB`, `AND`, `OR`가 작게 배치되어 있다가 하나의 ALU 블록으로 통합돼.

왼쪽 아래의 연산 선택 신호가 바뀌면 활성화되는 내부 경로가 순서대로 달라지고, 오른쪽 결과값이 변해.

마지막 1초에는 ALU 블록만 남겨 이후 장면의 기준 회로로 사용해.

### 00:06–00:11 | 새로운 질문

나레이션: 그렇다면 이 장치로 여러 단계의 계산을 수행하려면 어떻게 해야 할까요?

화면 연출

중앙 ALU를 왼쪽으로 이동시키고, 오른쪽에 빈 공간을 확보해.

상단에 `여러 단계의 계산`이라는 문구가 등장하고, ALU 출력에서 오른쪽으로 길게 이어지는 경로가 나타나.

경로 끝은 아직 아무 회로에도 연결되지 않은 상태로 남겨둬. 시청자가 계산 결과의 다음 사용처를 궁금해하도록 만드는 장면이야.

### 00:11–00:16 | (5+3)+2라는 문제

나레이션: 예를 들어 5와 3을 더하고, 그 결과에 다시 2를 더한다고 생각해 보겠습니다.

화면 연출

중앙에 수식이 크게 나타나.

\\[ (5+3)+2 \\]

첫 번째 계산인 `(5+3)`에 파란색 테두리를 두르고, 두 번째 `+2`에는 보라색 강조를 적용해.

이후 수식이 두 단계로 분리돼.

5 + 3

8 + 2

첫 번째 계산의 결과가 다음 계산의 입력이 된다

### 00:16–00:20 | 가산기 두 개 연결

나레이션: 가장 간단한 방법은 두 개의 덧셈 회로를 연속으로 연결하는 것입니다.

화면 연출

숫자 수식이 회로 블록으로 전환돼.

왼쪽 `ADDER 1`의 입력에 5와 3이 들어가고, 오른쪽 `ADDER 2`에는 왼쪽 가산기의 출력과 상수 2가 입력돼.

두 가산기 사이의 배선은 하나의 선이 아니라 결과값을 전달하는 여러 비트의 데이터 버스임을 표현해. 이 시점에서는 선 하나에 `8`이라고 적고, 작은 `n-bit` 표기를 추가하는 방식이면 충분해.

### 00:20–00:26 | 실제 계산 과정

나레이션: 첫 번째 회로에서 나온 8이 두 번째 회로로 전달되면 최종 결과인 10을 얻을 수 있습니다.

화면 연출

먼저 `ADDER 1`이 밝아지면서 출력 버스에 `8`이 나타나.

이 값이 오른쪽 가산기로 전달되고, 두 번째 입력 `2`가 함께 강조돼.

이후 `ADDER 2`의 출력에 `10`이 크게 나타나고, 전체 계산 과정이 짧게 정지해.

화면의 핵심은 회로 두 개가 직렬로 연결되어 있고, 첫 번째 결과가 두 번째 회로의 입력으로 사용된다는 물리적 연결 관계야.

### 00:26–00:31 | 계산 단계가 증가하면?

나레이션: 하지만 계산 단계마다 새로운 회로를 추가해야 한다면, 회로의 규모도 계속 커지게 됩니다.

화면 연출

기존 가산기 두 개 오른쪽에 세 번째, 네 번째, 다섯 번째 가산기가 순서대로 나타나.

화면 너비가 부족해지면 카메라가 살짝 축소되면서 회로 전체가 작아져.

하단에는 간단한 비교 문구를 표시해.

`계산 단계 증가 → 필요한 회로 증가`

이는 모든 계산에 별도의 회로가 반드시 필요한 것처럼 표현하는 게 아니라, 지금 선택한 직렬 조합논리 구현 방식에서 회로가 증가한다는 의미로 보여줘.

## ACT 2. 하나의 ALU를 반복해서 사용하려면? (00:31–00:56)

목표: 회로를 추가하는 대신 시간에 따라 재사용하려면 중간 결과를 유지해야 한다는 필요성을 도출한다.

### 00:31–00:36 | 여러 개의 가산기를 하나로

나레이션: 그렇다면 이미 만들어 놓은 하나의 ALU를 반복해서 사용할 수는 없을까요?

화면 연출

앞 장면에서 추가된 여러 가산기가 서서히 흐려지고, 중앙에 하나의 ALU만 크게 남아.

화면 상단에는 `하나의 ALU, 여러 번의 계산`을 표시해.

가산기가 사라질 때는 기존 물리 회로가 실제로 합쳐지는 연출보다는, 두 설계 대안을 비교하다 단일 ALU 설계안을 선택하는 화면 전환이 적합해.

### 00:36–00:42 | 중간 결과를 유지할 공간

나레이션: 이를 위해서는 첫 번째 계산의 결과인 8을 다음 계산에 사용할 때까지 보관해야 합니다.

화면 연출

ALU에 5와 3이 들어가고 출력 8이 표시돼.

출력 아래에 비어 있는 작은 상자가 나타나고, ALU 출력선이 이 상자에 연결돼.

상자 안에 `8`이 저장되면 강조색이 초록색으로 바뀌어.

이후 입력 5와 3이 사라지고, ALU 입력이 8과 2로 변경돼. 저장 상자에 있는 8은 그대로 유지돼.

여기서는 아직 저장 장치의 내부 구조를 설명하지 않기 때문에 상자에 `REGISTER`라는 이름을 붙이지 말고 \*\*`중간 결과`\*\*라고만 표시하면 좋아.

### 00:42–00:46 | 기존 논리 회로의 한계

나레이션: 그런데 지금까지 살펴본 논리 회로에는 이러한 기능이 없습니다.

화면 연출

저장 상자를 잠시 화면 밖으로 이동시키고 ALU만 남겨.

앞 장면의 `8`이 ALU 출력에 유지되어 있는 것처럼 보이다가, 새로운 입력을 적용하는 순간 해당 값이 사라지고 새로운 출력으로 대체되는 장면을 준비해.

상단에는 `이전 결과를 유지할 수 있을까?`를 표시해.

### 00:46–00:52 | 입력이 바뀌면 출력도 바뀐다

나레이션: 논리 게이트의 출력은 현재 입력에 따라 결정되기 때문에, 입력이 바뀌면 이전 결과도 달라집니다.

화면 연출

같은 ALU에서 입력을 두 차례 바꿔 보여줘.

첫 번째 입력두 번째 입력

## 5

## 3

ALU

ADD

# 8

출력

입력을 바꾸면 ALU의 현재 출력은 새 계산 결과로 바뀐다. 이전 값은 별도로 보존되지 않는다.

첫 번째 입력일 때 출력은 8, 두 번째 입력일 때 출력은 10이야. 이때 8이 별도로 남지 않는다는 사실을 보여줘.

### 00:52–00:56 | 새로운 설계 질문

나레이션: 그렇다면 기존의 논리 게이트만으로 값을 기억하는 회로를 만들 수 있을까요?

화면 연출

ALU 블록이 축소되어 왼쪽 아래로 이동하고, 중앙에는 단일 논리 게이트가 크게 등장해.

출력선 끝에 `?`를 짧게 표시해.

이후 입력과 출력선을 제외한 불필요한 요소는 제거하고 다음 장면으로 연결해.

## ACT 3. 회로의 방향을 바꾸다 — Feedback (00:56–01:19)

목표: 일반적인 논리 회로와 되먹임 회로의 구조적 차이를 보여주되, 되먹임만으로 무조건 기억이 만들어진다고 오해하지 않도록 한다.

### 00:56–00:59 | 연결 구조를 다시 살펴보기

나레이션: 여기서 회로의 연결 방식을 조금 바꿔보겠습니다.

화면 연출

논리 게이트 세 개가 왼쪽에서 오른쪽으로 연결된 단순한 회로를 보여줘.

입력선과 출력선을 구분해 표시하고 모든 연결은 기본적으로 왼쪽에서 오른쪽을 향해 있어.

전체 회로를 정지시킨 다음, 출력 부분을 주황색으로 강조해.

### 00:59–01:03 | 기존 회로의 신호 전달

나레이션: 지금까지는 입력에서 출력으로 신호가 전달되도록 회로를 구성했습니다.

화면 연출

파란색 활성 신호가 왼쪽 입력에서 첫 번째 게이트, 두 번째 게이트, 세 번째 게이트를 거쳐 오른쪽 출력까지 전달되는 모습을 순서대로 표현해.

이때 신호는 실제 회로의 모든 곳을 입자처럼 이동하는 방식보다, 전압 변화가 연결된 경로를 따라 전파되어 출력이 결정되는 표현이 더 적절해.

하단에는 `입력 → 논리 회로 → 출력`을 짧게 표시해.

### 01:03–01:08 | 출력선을 다시 입력으로 연결한다면?

나레이션: 하지만 출력된 신호를 다시 다른 게이트의 입력으로 연결하면 어떨까요?

화면 연출

오른쪽 출력선 끝에서 주황색 선이 아래쪽으로 연장돼.

선이 회로 아래를 지나 왼쪽으로 돌아온 뒤, 기존 회로의 입력 쪽으로 연결돼.

기존에는 한 방향으로 끝났던 경로가 이제 닫힌 연결 구조를 갖게 돼.

연결이 완성된 직후 카메라를 약간 축소해 회로 전체의 반복 경로가 잘 보이도록 해.

### 01:08–01:11 | Feedback 명칭 소개

나레이션: 이러한 구조를 되먹임, 즉 Feedback이라고 합니다.

화면 연출

주황색 되먹임 경로에 빛이 한 번 순환하는 모습을 보여줘.

경로 옆에 `Feedback`이라는 글자를 크게 표시하고, 아래에 작게 `되먹임`을 추가해.

주의할 점은 이 장면에서 곧바로 값이 저장됐다고 표현하지 않는 것이야. 되먹임은 상태를 유지하는 회로를 만들기 위한 구조적 요소이지만, 아무 되먹임 회로나 안정적으로 1비트를 기억하는 것은 아니거든.

### 01:11–01:15 | 두 개의 NOR 게이트

나레이션: 대표적인 예로 두 개의 NOR 게이트를 생각해 보겠습니다.

화면 연출

이전 회로를 화면에서 정리하고, 중앙에 NOR 게이트 두 개를 세로로 배치해.

위쪽은 파란색, 아래쪽은 보라색 테두리로 표현해.

처음에는 각각 독립적인 게이트로 배치하고, 입력 A와 B가 모두 0일 때 출력이 1이 된다는 NOR 동작을 아주 짧게 보여줘.

오른쪽 상단에는 작게 다음 식을 표시할 수 있어.

\\[ Y=\neg(A\lor B) \\]

### 01:15–01:19 | 교차 연결 완성

나레이션: 각 게이트의 출력이 상대방 게이트의 입력에 영향을 주도록 연결하는 것입니다.

화면 연출

위쪽 NOR의 출력선을 아래쪽 NOR의 피드백 입력으로 연결해.

그다음 아래쪽 NOR의 출력선을 위쪽 NOR의 피드백 입력으로 연결해.

주황색 배선을 사용하고 교차하는 지점에는 연결점이 없는 경우 점이나 접합 표시를 추가하지 않아.

외부 입력은 위쪽 `R`, 아래쪽 `S`로 표기해. 출력은 위쪽 `Q`, 아래쪽 `Q̅`로 표시하면 이후 상태 설명이 쉬워져.

## ACT 4. 두 가지 안정된 상태 — SR 래치 (01:19–01:54)

목표: 같은 입력 조건에서도 이전 상태에 따라 출력이 달라질 수 있다는 사실을 논리적으로 보여준다.

이 구간은 전체 영상에서 가장 중요한 장면이므로, 배선을 지나치게 꾸미지 않고 실제로 올바른 NOR 기반 SR 래치 구조를 고정해서 사용하는 것이 좋아.

NOR 기반 SR 래치의 논리적 연결

회로 기준

위쪽 NOR 출력은 \\(Q=\neg(R\lor\overline Q)\\), 아래쪽 NOR 출력은 \\(\overline Q=\neg(S\lor Q)\\)를 만족해.

설명용 블록 회로도. 피드백선은 서로 교차하지만 전기적으로 접합되지 않으며, 각 출력이 반대편 NOR 입력에 연결된다.

### 01:19–01:24 | 첫 번째 상태 만들기

나레이션: 이때 한쪽 출력이 1이고 다른 쪽 출력이 0인 상태가 만들어졌다고 생각해 보겠습니다.

화면 연출

R=0, S=1을 잠깐 입력해 위쪽 출력 Q가 1이 되고 아래쪽 출력 Q̅가 0이 되도록 해.

외부 입력 S를 활성화할 때는 보라색 선이 밝아지고, 그 결과 아래쪽 Q̅가 0이 됨을 먼저 표시해.

이어서 Q̅=0이 위쪽 NOR의 입력으로 전달되어 Q=1이 성립한다는 점을 순차적으로 보여줘.

화면에는 `Q=1`, `Q̅=0`이 나타나.

### 01:24–01:30 | 외부 입력을 0으로 되돌려도 유지

나레이션: 외부 입력을 모두 0으로 유지하면, 두 게이트는 서로의 출력을 통해 이 상태를 계속 유지할 수 있습니다.

화면 연출

S 신호를 1에서 0으로 내리고 R도 0인 상태로 유지해.

그런데 Q=1과 Q̅=0은 바뀌지 않아.

이때 두 게이트의 관계를 하나씩 표시해.

- 위쪽 NOR: 입력 `(R=0, Q̅=0)` → 출력 `Q=1`
- 아래쪽 NOR: 입력 `(S=0, Q=1)` → 출력 `Q̅=0`

서로가 서로의 현재 출력을 지탱하고 있음을 주황색 피드백 배선으로 강조해.

### 01:30–01:35 | 반대 상태도 가능하다

나레이션: 반대로 한쪽 출력을 0, 다른 쪽 출력을 1로 만든 상태 역시 유지할 수 있습니다.

화면 연출

이번에는 R에 짧게 1을 입력해 위쪽 Q를 0으로 만들어.

Q=0이 아래쪽 NOR로 전달되면서 Q̅가 1이 돼.

다시 R을 0으로 되돌려도 Q=0, Q̅=1이 계속 유지돼.

이 장면에서는 색깔만 바꾸지 말고, R 입력의 변화 → Q의 변화 → Q̅의 변화 → 입력 복귀 후 유지 순서가 드러나야 해.

### 01:35–01:42 | 같은 입력, 서로 다른 결과

나레이션: 즉, 같은 외부 입력이 주어져도 이전에 어떤 상태였는지에 따라 서로 다른 출력이 유지될 수 있는 것입니다.

화면 연출

전체 화면을 좌우로 나누고, 양쪽에 동일한 NOR 래치 회로를 배치해.

상태 A

# Q = 1

Q̅ = 0

R = 0, S = 0

상태 B

# Q = 0

Q̅ = 1

R = 0, S = 0

두 회로는 외부 입력이 완전히 동일하지만 출력 상태가 서로 달라.

이 장면에서는 다른 설명을 많이 추가하지 않고, `같은 입력, 다른 상태`라는 문구만 강조하는 게 좋아.

영상에서 가장 중요한 시각적 발견이 바로 이 순간이야.

### 01:42–01:46 | 하나의 비트를 기억한다

나레이션: 이렇게 두 가지 안정된 상태를 이용하면 0과 1을 기억할 수 있습니다.

화면 연출

앞 장면의 좌우 회로를 하나의 래치로 합쳐.

회로 오른쪽에는 큰 `Q` 출력 표시가 있고, 내부 상태가 0과 1 사이에서 전환되는 짧은 모습을 보여줘.

이후 `Q=1` 상태에서 화면을 멈춰.

하단에는 `두 가지 안정된 상태 → 1비트 저장`을 표시해.

### 01:46–01:52 | Set과 Reset

나레이션: 그리고 외부 입력을 통해 저장된 상태를 1로 설정하거나, 0으로 초기화할 수도 있습니다.

화면 연출

회로를 조금 위로 옮기고 하단에 S, R 두 개의 입력 제어를 배치해.

먼저 S 신호를 잠깐 활성화하면 Q가 1이 되고, 다시 S=0으로 돌아와도 Q=1이 유지돼.

이어서 R 신호를 잠깐 활성화하면 Q가 0이 되고, 다시 R=0으로 돌아와도 Q=0이 유지돼.

실제 동작을 보여주면서 아래 표의 해당 행만 순서대로 밝게 만들어.

| S | R | Q의 동작         |
| - | - | ------------- |
| 0 | 0 | 이전 값 유지       |
| 1 | 0 | 1로 설정         |
| 0 | 1 | 0으로 초기화       |
| 1 | 1 | 사용하지 않는 입력 조합 |

마지막 행은 이번 영상에서 상세히 설명하지 않아도 돼. 다만 두 입력을 동시에 1로 만드는 장면은 사용하지 않는 것이 좋겠어.

### 01:52–01:54 | SR 래치

나레이션: 이것이 SR 래치의 기본적인 원리입니다.

화면 연출

두 NOR 게이트가 완성된 회로를 유지한 채, 아래에 `SR Latch`라는 명칭이 등장해.

그다음 NOR 회로 주변에 하나의 외곽선이 그려지면서 하나의 저장 기능 블록으로 묶여.

내부 배선이 실제로 없어지거나 교체되는 것이 아니라, 시각적으로 하나의 기능 단위로 묶인다는 느낌을 줘.

### 01:54–02:02 | 기존 게이트에서 새로운 기능으로

# 3. 제작 시 특히 중요한 기술적 정확성

이번 영상에서 연출 오류가 발생하기 쉬운 부분은 세 군데야.

첫째, ALU 재사용과 Feedback을 동일한 회로로 표현하면 안 돼.

초반의 ALU 재사용은 중간 결과를 저장하고 다시 연산 입력으로 가져오는 구조에 관한 이야기야. 반면 SR 래치의 Feedback은 기억 회로 내부에서 상태를 유지하는 연결이야.

둘 다 이전 결과를 활용하지만, 물리적으로 의미하는 연결은 달라.

둘째, NOR 래치의 신호 전환 순서를 지켜야 해.

Q를 1로 설정하려면 S를 활성화하고, Q를 0으로 초기화하려면 R을 활성화해. 모두 0으로 돌아왔을 때 이전 값이 유지된다는 사실이 핵심이지.

화면에는 매 순간 다음 조건이 성립하도록 상태를 설계해야 해.

\\[ Q=\neg(R\lor\overline Q) \\]

\\[ \overline Q=\neg(S\lor Q) \\]

셋째, 안정된 상태를 유지한다는 것이 전원 없이 영구적으로 기억한다는 의미는 아니야.

SR 래치는 회로에 전원이 공급되고 정상적으로 동작하는 조건에서 상태를 유지하는 휘발성 저장 구조야. 저장된 비트를 비휘발성 메모리처럼 표현하는 연출은 피해야 해.

# 제작 기준

핵심 주장: 하나의 ALU를 시간에 따라 재사용하려면 중간 결과가 필요하며, 논리 게이트의 교차 되먹임으로 두 안정 상태를 유지할 수 있다.

140초·29문장 원문을 유지한다. 독립14씬, 가로/세로 모두 전체 대본·자막. 추정 발화시간을 사용하지 않는다. 사용자 제공 도입·마지막 문장은 그대로, 추가 복습·예고는 없음.

A/일반 입력 파랑, 보조 입력 보라, 활성 출력 초록, 피드백 주황, 비활성 회색. n비트 ALU 데이터 버스와 1비트 래치선을 구분한다. 중간 결과 상자에 REGISTER라고 미리 이름 붙이지 않는다.

NOR R/Qbar→Q 및 S/Q→Qbar의 실제 핀을 준수. 비접합 교차점 브리지. S1→Qbar0→Q1, R1→Q0→Qbar1, 입력0으로 복귀해도 Hold. 초기 상태는 가정이지 자동 초기화가 아니다. 전파 지연 중과 안정 상태를 구분한다. S=R=1은 시연하지 않는다. 전원 공급·정상 동작 조건의 휘발성 기억이다. 임의 피드백을 곧바로 메모리라 부르지 않는다. 최종 시간 개념도를 실제 D래치·클럭 회로로 오해시키지 않는다.

검증: 1458개 합법 입력열·6전환·안정식·배선 불변. 140.000초·4200프레임/레이아웃. 대표 프레임과29문장 경계 전후를 실제 인코딩 영상에서 검토한다.

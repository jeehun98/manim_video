# 5편 제작 기준 — 미래 예측

확정 대본은 사용자 원문, 문장 종료 시각은 1–130초 제공값을 그대로 사용한다. 내레이션 길이를 글자 수로 추정하지 않는다. 사용자가 영상 제작을 요청한 확정 원문이다.

핵심 질문: 같은 행렬을 반복할 때 각 분해가 미래의 변화를 어떻게 드러내는가?

- 예시 A: A_E=diag(2,0.5), x₀=(0.25,1). 고유성분별 실제 거듭제곱과 궤적. 수평 파랑, 수직 보라, 결과 금색.
- 예시 B: A_S=[[0,-1],[2,0]]. 예시 교체를 화면에 명시. e₁→2e₂→−2e₁, 배율2 다음1. 특이값[2,1], 제곱행렬의 특이값[2,2].
- 일반식 Aⁿ=PDⁿP⁻¹는 대각화 가능 조건을 표시. 예시 A는 P=I임을 명시.
- 한계: 전단은 독립고유방향 하나, 별도 B=[[0.8,2],[0,0.7]]는 실제 ‖Bⁿe₂‖로 과도 성장과 장기 감소를 시각화.
- 19개 독립 씬. 9:16과16:9를 별도 배치. 자막은 실제 종료 시각, 주요 화면 변화별 TTS 원고 빈 줄.
- 이전 편 복습·후속 예고 없음. 판정은 이번 비교 기준에 한함. 최종 스코어3:2.
- TTS 음원 미제공: 기본 최종본은 자막 포함 무음.

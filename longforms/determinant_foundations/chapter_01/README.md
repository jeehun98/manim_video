# 1장 · 방정식에서 나타나는 특별한 숫자

사용자 확정 25문장·126초. 16:9 1920×1080·30fps. 음원 미제공으로 무음·전체 문장 자막.

- 일반식 우변은 문자 e. 106초에 행렬식 이름을 처음 표시.
- 계수 변화와 우변 변화를 구분하며 그래프·수치 동기화.
- 12개 독립 씬, 문장 종료 시각은 timing.json 기준.
- 마지막 행렬·평행사변형을 남기며 종료. 다음 장 영상은 아직 없음.

## 실행

`py -3.12 longforms/determinant_foundations/chapter_01/build.py`

대표 씬 확인: 위 명령에 `--preview --scene 3` 또는 `--preview --scene 6` 추가.

결과: `exports/determinant_ch01_126s_longform_final.mp4`

소스·설정 해시가 같은 씬만 재사용하며, 수정 씬만 다시 렌더한 뒤 조립한다.

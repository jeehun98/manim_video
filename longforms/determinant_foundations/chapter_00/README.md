# 0장 · 행렬식은 왜 등장했을까?

사용자 확정10문장·71초, 독립 씬9개. 1920×1080 30fps, 무음·전체 자막.

실행: `py -3.12 longforms/determinant_foundations/chapter_00/build.py`

문장 종료 시각: 6,13,23,31,40,48,54,57,67,71초.

인물은 이름·연도·연구 주제 카드로 표현한다. 초상화는 사용하지 않았다. 방정식·행렬·크라메르 공식은 현대 표기로 재구성했다. 세키의 다항식 소거와 라이프니츠의 연립방정식 연구를 구별하며, 부피 해석이 19세기에 처음 등장했다고 표현하지 않는다. 분모가 0이 아닌 경우를 명시한다.

역사 검증: [MacTutor — Matrices and determinants](https://mathshistory.st-andrews.ac.uk/HistTopics/Matrices_and_determinants/), 2026-11-19 확인. 1683 세키,1693 라이프니츠 서신,1750 크라메르 일반 규칙,1850 실베스터의 용어,1858 케일리의 이론.

확정 대본에 포함된 본편 안내를 유지했다. 71초에 종료하며 합본은 별도 제작하지 않는다.

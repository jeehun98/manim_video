## **Scene 3. 왜 행렬식이 변하지 않을까?**

00:42–01:11 · 다중선형성과 교대성의 활용

### **00:42\~00:47 — 기하학에서 대수학으로**

앞선 도형을 화면 왼쪽으로 이동시킨다.

오른쪽에 다음 수식을 나타낸다.

\\[ \det(\mathbf u+k\mathbf v,\mathbf v) \\]

3장에서 등장했던 다중선형성의 공식을 잠시 복원한다.

\\[ \det(\mathbf a+\mathbf b,\mathbf c) = \det(\mathbf a,\mathbf c) + \det(\mathbf b,\mathbf c) \\]

새로운 성질을 추가하는 것이 아니라 이미 이해한 성질을 다시 활용하는 구조다.

### **00:47\~00:53 — 두 개의 행렬식으로 분해**

\\[ \begin{aligned} \det(\mathbf u+k\mathbf v,\mathbf v) &=\det(\mathbf u,\mathbf v)\\\ &\quad+k\det(\mathbf v,\mathbf v) \end{aligned} \\]

\\(\det(\mathbf u+k\mathbf v,\mathbf v)\\)

\\(\det(\mathbf u,\mathbf v)\\)

\\(k\det(\mathbf v,\mathbf v)\\)

\\[ \underbrace{\det(\mathbf u+k\mathbf v,\mathbf v)}\_{\text{변형된 행렬식}}=\underbrace{\det(\mathbf u,\mathbf v)}\_{\text{원래 행렬식}}+0 \\]

수식의 성분들이 두 갈래로 분리되면서 각각의 행렬식에 대응하는 기하학적 그림이 생성된다.

세 번째 그림에서는 \\(k\\)를 행렬식 바깥으로 꺼낸 뒤, 동일한 두 벡터만 남기는 방식으로 표현한다.

### **00:53\~00:59 — 추가된 항이 0이 되는 이유**

두 번째 항을 확대한다.

\\[ k\det(\mathbf v,\mathbf v) \\]

동일한 두 벡터가 만드는 평행사변형은 한 직선 위에 놓인다.

앞선 3장에서 사용한 중복 방향 제거 애니메이션과 동일한 효과를 적용한다.

\\[ \det(\mathbf v,\mathbf v)=0 \\]

추가된 항은 회색으로 변한 뒤 사라진다.

### **00:59\~01:01 — 원래 행렬식만 남는다**

마지막 등식을 나타낸다.

\\[ \boxed{ \det(\mathbf u+k\mathbf v,\mathbf v) = \det(\mathbf u,\mathbf v) } \\]

화면의 왼쪽과 오른쪽에 있는 두 도형이 서로 다른 모양임에도 동일한 행렬식 값을 갖는다는 사실을 강조한다.

이 장면은 단순한 기하학적 관찰이 대수학적 성질로 정당화되는 순간이다.

### **01:01\~01:06 — 열에서 행으로 확장**

열 연산

\\[ \begin{pmatrix}\color{#378FD9}{a+kb}&\color{#E6AA50}{b}\\\\\color{#378FD9}{c+kd}&\color{#E6AA50}{d}\end{pmatrix} \\]

\\(C_1\leftarrow C_1+kC_2\\)

\\[ \begin{pmatrix}\color{#378FD9}{a+kc}&\color{#378FD9}{b+kd}\\\\\color{#E6AA50}{c}&\color{#E6AA50}{d}\end{pmatrix} \\]

\\(R_1\leftarrow R_1+kR_2\\)

\\[ \det(A^T)=\det(A) \\]

행렬식은 전치에 대해 변하지 않으므로 열에 성립하는 성질을 행에도 적용할 수 있다.

나레이션에서는 행과 열에 대해 같은 성질이 성립한다고만 설명한다.

### **01:06\~01:11 — 계산에 활용할 규칙 확정**

\\[ R_i\leftarrow R_i+kR_j \qquad(i\ne j) \\]

\\[ \boxed{\det(A')=\det(A)} \\]

### **01:51\~01:56 — 대각선의 곱만 남는다**

\\[ \det(U)=2+0+0-0-0-0 \\]

\\[ \boxed{\det(U)=2\times1\times1=2} \\]

\\[ U= \begin{pmatrix} u\_{11}&u\_{12}&\cdots&u\_{1n}\\\ 0&u\_{22}&\cdots&u\_{2n}\\\ \vdots&\ddots&\ddots&\vdots\\\ 0&\cdots&0&u\_{nn} \end{pmatrix} \\]

대각선 원소를 차례대로 강조한다.

\\[ \det(U)=\prod\_{i=1}^{n}u\_{ii} \\]

여기서 일반적인 경우에도 대각선 항만 남는 이유를 작은 애니메이션으로 보강한다.

첫 번째 열에서는 첫 번째 행만 선택해야 0인 위치를 피할 수 있다. 첫 번째 행을 이미 선택했으므로, 두 번째 열에서는 두 번째 행을 선택해야 한다. 이 과정을 반복하면 대각선 선택만 남는다.

대각선 원소 자체가 0이라면 최종 행렬식도 0이 된다.

`Row Swaps: 0 → 1`

## **Scene 8. LU 분해와 행렬식의 곱셈 성질**

02:10–02:21 · 소거 과정을 행렬의 곱으로 표현

### **02:10\~02:15 — 소거 과정에서 사용한 배수**

Scene 5의 3×3 행렬을 다시 등장시킨다.

앞서 사용했던 소거 연산들을 작은 기록 카드로 표시한다.

\\[ \begin{aligned} R_2&\leftarrow R_2-2R_1\\\ R_3&\leftarrow R_3-R_1\\\ R_3&\leftarrow R_3-R_2 \end{aligned} \\]

여기에 사용된 배수 2, 1, 1을 각각 추출한다.

이 숫자들이 하삼각행렬의 대각선 아래 위치로 이동한다.

\\[ L=\begin{pmatrix} 1&0&0\\\ 2&1&0\\\ 1&1&1 \end{pmatrix} \\]

앞에서 만들어진 상삼각행렬 \\(U\\)도 함께 나타낸다.

### **02:15\~02:21 — 두 삼각행렬의 곱**

\\[ A=\begin{pmatrix}2&1&1\\\4&3&3\\\2&2&3\end{pmatrix} \\]

LU 분해

L — 하삼각행렬

\\[ \begin{pmatrix}1&0&0\\\\\color{#378FD9}{2}&1&0\\\\\color{#378FD9}{1}&\color{#378FD9}{1}&1\end{pmatrix} \\]

\\(1\times1\times1\\)

## **det(L) = 1**

U — 상삼각행렬

\\[ \begin{pmatrix}2&1&1\\\0&1&1\\\0&0&1\end{pmatrix} \\]

\\(2\times1\times1\\)

## **det(U) = 2**

\\[ \begin{aligned} A&=LU\\\ \det(A)&=\det(L)\det(U)\\\ &=1\times2=2 \end{aligned} \\]

이 부분에서 중요한 것은 LU 분해의 알고리즘을 가르치는 것이 아니다.

복잡한 행렬을 두 개의 단순한 구조로 분해하고, 행렬식의 곱셈 성질을 활용하면 전체 행렬식도 쉽게 구할 수 있다는 사실을 전달하는 것이다.

가능하면 작은 삽화로 다음 개념을 표현한다.

공간을 한 번 변환한 뒤 다시 변환하면 각 단계의 부피 변화율이 곱해진다.

\\[ \det(AB)=\det(A)\det(B) \\]

이 관계를 기하학적인 관점에서 이해할 수 있도록, 단위 정사각형의 두 차례 변환을 약 2초 정도 보여준다.

행 교환이 필요한 일반적인 LU 분해에서는 다음과 같은 표현이 사용된다는 점을 작은 자막으로 보완한다.

\\[ PA=LU \\]

\\[ \det(A)=\det(P)\det(L)\det(U) \\]

여기서 \\(P\\)는 순열행렬이다.

| LU 분해    | `Matrix`, `TransformFromCopy`       | 소거 배수를 L에 기록       |
| 복잡도 비교   | `Axes`, `plot_line_graph`           | 로그 척도 성장률 비교       |
| 다음 장 전환  | `Rectangle`, `Transform`            | 넓이는 같고 형태는 다른 도형   |

## **데이터 기반 소거 과정 구현**

행렬의 원소를 수동으로 지정하기보다는 실제 행 연산을 적용하고, 각 단계의 행렬 상태를 저장하는 방식이 좋다.

```
import numpy as npA = np.array([    [2., 1., 1.],    [4., 3., 3.],    [2., 2., 3.]])U = A.copy()L = np.eye(3)operations = [    (1, 0, 2),    (2, 0, 1),    (2, 1, 1),]states = [U.copy()]for target, pivot, factor in operations:    L[target, pivot] = factor    U[target] -= factor * U[pivot]    states.append(U.copy())assert np.allclose(A, L @ U)assert np.allclose(np.linalg.det(A), np.linalg.det(U))
```

이 코드는 이번 영상의 고정 예시에 대한 소거 과정을 생성하기 위한 것이다. 일반적인 행렬에 대응하는 LU 분해 알고리즘 전체를 구현한 것은 아니다.

생성된 `states`를 이용해 원소의 변화, 기준 행의 강조, 0의 등장, 소거 연산 표시를 일관되게 관리할 수 있다.

## **순열 항의 소멸 검증**

3장에서 작성한 순열 생성 로직을 그대로 재사용한다.

```
from itertools import permutationsfrom math import proddef permutation_sign(p):    inversions = sum(        p[i] > p[j]        for i in range(len(p))        for j in range(i + 1, len(p))    )    return (-1) ** inversionsfor p in permutations(range(3)):    entries = [        U[row, col]        for col, row in enumerate(p)    ]    term = permutation_sign(p) * prod(entries)    print(p, entries, term)
```

동일한 순열 데이터를 사용했을 때 원래 행렬에서는 여섯 개의 항이 등장하지만, 상삼각행렬에서는 대각선 원소에 해당하는 항만 0이 아닌 값을 갖는다.

이 로직을 이용해 3장과 4장의 시각적인 연속성도 유지할 수 있다.

# **6. 구현 시 수학적 주의사항**

**① 기하학적 불변성을 설명할 때 밑변을 정확히 설정한다.**

첫 번째 벡터에 두 번째 벡터의 배수를 더한다면, 고정된 두 번째 벡터를 밑변으로 설정해야 밑변과 높이가 모두 유지된다는 설명이 정확해진다.

**② 모든 행 연산이 행렬식을 유지하는 것은 아니다.**

| 행 연산                | 행렬식의 변화  |
| ------------------- | -------- |
| 다른 행의 배수를 더하거나 빼기   | 변하지 않음   |
| 두 행 교환              | 부호 반전    |
| 한 행에 상수 \\(k\\) 곱하기 | \\(k\\)배 |

현재 나레이션에서는 세 번째 연산을 다루지 않으므로 실제 애니메이션에서도 대각선 원소를 1로 만들기 위해 행 전체를 나누는 연산을 사용하지 않는다.

**③ 팩토리얼 항의 개수와 실제 산술연산 복잡도를 구분한다.**

라이프니츠 공식에는 \\(n!\\)개의 항이 존재하지만, 각 항의 곱셈까지 직접 수행하는 단순 구현의 산술연산 복잡도는 \\(O(n\cdot n!)\\)로 표현할 수 있다.

반면 일반적인 가우스 소거법을 이용한 행렬식 계산은 \\(O(n^3)\\)이다.

현재 나레이션은 유지하되 화면의 표기에서 이 차이를 구별하는 것이 좋다.

**④ 소거 과정과 순열 항 제거의 관계를 정확하게 표현한다.**

가우스 소거법은 실제로 모든 순열 항을 생성한 다음 0인 항을 제거하는 알고리즘이 아니다.

순열 항이 사라지는 애니메이션은 상삼각행렬에서 왜 대각선의 곱만 계산하면 되는지를 설명하기 위한 수학적 표현이다.

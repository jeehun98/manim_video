# GPU 개론 10 최종 검수

- 확정 35문장, 15개 독립 씬, 165초. 제공된 문장 종료 시각과 대본을 유지했다. 발화자 표기로 보이는 연우는 자막·발음 원고에서 제외했다.
- 프로그램 모델: ADD00110110으로 R3=8, SUB01111101으로 R3=3. PC=0→1→2, 원래 R1=5/R2=3과 명령어 메모리 유지. PC 선택·쓰기 허용·에지2048조건 및 분기32조건 통과.
- PC는 주소, 명령어 메모리는 비트열, 일반 레지스터는 계산값을 저장하도록 구분했다. PC+1은 가상 슬롯 주소다.
- 분기는 별도 예시다. 조건 판정·대상 주소 계산 이후 MUX의 두 고정 후보2/3을 선택하고 유효 에지에서 PC1→3. 명령어는 삭제되지 않는다.
- 두 미리보기의 대표41시점을 추출해 PC·메모리·해독·데이터 경로와 분기 선택을 검토했다.
- 최종 검수에서08번씬의 뺄셈 완료 표시를 수정했다. 계산 당시8−5=3을 보여준 뒤 R3=3기록, 입력·결과표시완료,WE=0,PC=2로 갱신한다. 해당씬만 두 레이아웃에서 다시렌더한후 최종합본을재결합했다. 기존 미리보기는 수정 전이며 최종본과 혼동하지 않는다.
- 최종 전체 문장경계 이전/현재/다음프레임을가로4장·세로4장접촉시트로검토했다. 자막 겹침이나 이중 출력은 발견되지 않았다. 최대높이는세로1.683<2.25,가로1.001<1.4.
- 음원 미제공으로 무음. 전체 자막을 영상에 포함하고 별도 SRT도 제공한다.
- 인코딩 정보·프레임수 및 SHA-256은 ../verification_final.json에 기록한다.

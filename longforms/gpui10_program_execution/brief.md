# 제작 기준

학습목표: 명령어저장,PC주소선택,인출·해독·실행,PC갱신,분기주소선택이하나의기본프로세서구조로연결됨을이해한다.

165초35문장,15씬. 초록PC·저장,파랑명령어메모리,보라해독·연산,주황다음PC선택. 첫순차예시는ADD8→SUB3으로고정한다. 57–63초PC주소와명령어내용구별,107–120초MUX후보선택과유효저장에지,137–148초통합회로실행을중심장면으로둔다.

PC D/Q/CLK를표시하고후보2/3의선택과실제PC갱신을분리한다. 분기는조건과목표가정해진뒤의별도예시임을표시한다. 명령어삭제·배선재구성·산술ISA에존재하지않는분기인코딩을만들지않는다. 단계별설명은실제명령어사이클수주장이아니다. 가상슬롯주소+1전제를표시한다.

사용자가제공한요약과마지막문장은보존하되추가예고타이틀은생성하지않는다. 화면은회로연결중심이며자막은단일Text교체,최대높이제한으로중첩을방지한다. TTS원고는장면변화별빈줄을두고타임코드·발화자명은제외한다.

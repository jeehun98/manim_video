# 09 · 항상 다음 위치만 실행할까?

목적·주장: 별도의 분기 예시로 순차 후보2와 목표3을 구별한다.

시작: 인출 · 해독 · 실행

확정길이: 94–107초(13초). 사용자 문장 종료 시각을 그대로 사용한다.

## 확정 대본·화면 변화 시각
- 94–98초: 그런데 컴퓨터가 항상 다음 위치의 명령어만 실행해야 할까요?
- 98–103초: 예를 들어 어떤 계산 결과가 0일 때, 특정 명령어를 건너뛰고 싶을 수도 있습니다.
- 103–107초: 이때는 PC를 단순히 증가시키는 대신, 다른 주소로 변경하면 됩니다.

## 화면과 텍스트
../../storyboard_reference.md의해당구간,../../scene_engine.py의condition참조. 가로1920×1080/세로1080×1920별도배치.30fps. PC와저장초록,메모리파랑,해독·연산보라,분기·제어주황. PC입출력D/Q·CLK,Address,InstructionMemory,Fetch/Decode/Execute,PC+1,BranchTarget,BranchTaken을일관되게사용한다. 자막한객체를문장경계에서교체하고세로최대높이1.95로제한한다.

## 정확성·전제
가상슬롯주소는명령어1개당+1이며실제ISA의바이트주소증분을일반화하지않는다.명령어형식OP|RD|RS1|RS2각2비트. ADD00110110,SUB01111101.초기R1=5,R2=3,R3=0→ADD후8→SUB후3. PC는주소,메모리는명령어,레지스터는계산데이터를보관한다. PC와일반레지스터쓰기에는해당유효갱신에지가필요하다.단계애니메이션은설명순서이지특정마이크로아키텍처의사이클수주장이아니다. 분기는별도예시로조건판정·목표주소계산후의선택을보여주며8비트산술ISA에분기명령인코딩을임의로추가하지않는다.조건거짓PC1→2,참PC1→3.명령어메모리는변하지않는다.후보두입력과MUX배선은고정한다. 사용자제공요약·마지막문장은유지하되추가GPU11예고·NEXT타이틀은넣지않는다.성능배율·현대CPU/GPU완성주장은없다.

연결: MUX로 다음 PC를 선택한다

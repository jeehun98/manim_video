# GPU 메모리 시스템의 물리적 연결

## 주장과 확정 길이
153–164초, 사용자 문장 종료시각 기준. 음원 미제공.

## 대본
GPU의 메모리 계층은 에스엠과 캐시에서 끝나는 것이 아닙니다.
그 뒤에는 메모리 요청을 처리하는 컨트롤러와, 실제 데이터를 보관하는 디램의 물리적 구조가 존재합니다.

## 화면 타임라인
- 153초: 전체SM Cache Controller DRAM경로
- 157초: 컨트롤러DRAM강조

## 시작/종료와 지속 요소
상단 SM0/Warp0/Register·L1·L2·Controller·DRAM을 유지한다. 요청과 값이 실제로 이동하고, DRAM 확대시 같은 Bank0/Row 식별을 유지한다. Global은 물리상자 밖의논리오버레이. 코드줄번호없음,별도자막영역. 다음영상예고없음.

## 정확성
사용자 문장 종료시각을 고정한다. Global은 논리 주소 공간, DRAM은 일반적 물리 저장 장치이며 주소 변환은 GPU 메모리 시스템에 걸친 과정이다. A[i]를 Bank/Row/Column에 직접 산술 대응시키거나 컨트롤러만 주소를 변환한다고 표현하지 않는다. 캐시 Miss와 요청 경로는 설명용 가정, 측정된 GPU 트레이스가 아니다. 요청은 주황, 반환 데이터는 초록. 컨트롤러 수·캐시 분할·칩 배치는 아키텍처별로 다르다. DRAM 모형은4Bank×4Row×8Column이며 각Bank의 열린Row는최대하나. 초기닫힘→ACTIVATE→READ,동일행→READ,다른열린행→PRECHARGE→ACTIVATE→READ의단순모형. 실제사이클/ns나정확한타이밍비율을제시하지않으며자동precharge·refresh등은생략한다. GDDR보드배치와HBM동일패키지적층은개념도이며속도/레이턴시순위가아니다. HBM스택은GPU다이위가아니라옆에배치한다. CUDA예제값A5=6,B5=12만실제로검증한다.

# EP.02 · 양자컴퓨터도 빠르지 못한 문제가 있다

사용자 확정 대본 31문장과 제공 종료 시각을 원본으로 사용한다. 총 161초·20씬·60fps·9,660프레임. 첨부 콘티의 178초 가배치는 사용하지 않는다. 앞부분의 복습 문장은 사용자가 직접 제공한 대본이므로 유지하며, 별도의 복습·예고·엔드카드는 추가하지 않는다.

가로 1920×1080 / 세로 1080×1920, 전체 내레이션 자막 포함. 음원 미제공으로 무음. 1편의 QCSScene 자막·타이밍·프레임 검증·AmplitudeChart·그로버 데이터·팔레트를 재사용한다. QCSScene의 데이터 원본만 클래스 속성으로 교체할 수 있도록 최소 확장했으며 1편의 기본 대본·연산·애니메이션은 바꾸지 않는다. 배치는 1편 layouts.py를 재사용하고 수열의 행 수·비교 패널 방향을 화면비별로 정한다.

핵심 주장: 양자 가속에는 중첩·간섭과 함께 문제의 수학적 구조를 효율적으로 활용하는 방법이 중요하다.

그로버 하한은 정답 여부만 판별하는 비구조적 블랙박스 검색·정답 하나·일정 성공률의 오라클 질의 복잡도 Ω(√N)에 한정한다. 모든 양자 계산 문제에 대한 하한이나 실제 실행시간으로 일반화하지 않는다.

소인수분해 예는 a=2, M=15. 2ˣ mod15 수열은 1,2,4,8 반복, 최소 양의 주기는 4. 2⁴−1=(2²−1)(2²+1)=3×5. 일반적인 조건과 gcd를 코드로 검증한다. 시행 나눗셈은 단순한 방법의 예일 뿐 모든 고전 알고리즘을 대표하지 않는다. 콘티의 '차이의 제곱'은 수식에 맞는 용어 '제곱의 차'로 화면에 표기한다.

QFT에서는 함숫값을 직접 푸리에 변환하지 않는다. Q=8인 설명용 레지스터에서 함수 레지스터 값 1을 조건으로 선택하면 입력은 (|0⟩+|4⟩)/√2가 된다. 정규화된 QFT 행렬을 적용한 결과는 짝수 인덱스 0,2,4,6에서 진폭 0.5·관측 확률 25%다. 실제 쇼어의 입력 레지스터는 더 크며 이 도식은 전체 쇼어 회로의 실행 결과를 뜻하지 않는다.

측정 k=2에서 2/8=1/4로 후보 주기 4를 얻고 거듭제곱 나머지로 검증하는 성공 사례를 사용한다. k=0,4는 같은 방식으로 주기를 바로 식별하지 못한다. 일반적으로 연분수·후보 검증·반복 측정이 필요하다.

쇼어의 효율은 입력 정수의 비트 수를 기준으로 설명한다. 검색 후보 수 N과 같은 성능축을 쓰지 않는다. 알려진 고전 소인수분해 알고리즘 대비 개선이며, 고전적 소인수분해의 다항시간 불가능성이 증명되었다고 주장하지 않는다.

마지막 154–161초의 무작위 입력 질문과 배경 비트 배열을 유지한다. 다음 편 소스·음원이 있는 것으로 표시하지 않는다. standalone/join 종료 모두 전체 대본·자막·길이를 보존한다.

# 09 · 주기가 알려주는 나눗셈 관계

## 목적과 주장

주기가 알려주는 나눗셈 관계를 도형과 수식으로 설명한다.

## 확정 대본·길이

78–84초, 360프레임. 문장 경계와 겹치는 원문은 아래와 같으며 실제 자막 시각은 timing.json을 따른다.

그런데 주기가 4라는 것은 2의 4제곱에서 1을 뺀 값이 15로 나누어떨어진다는 뜻입니다.

## 화면·연산·정확성

2⁴ mod 15=1 → 2⁴−1=15. 이 예제의 정확한 등식과 일반적인 배수 관계를 구별한다.

## 연결

앞 장면: 최소 양의 주기 r = 4. 다음: 제곱의 차로 분해하기. direction.py의 s09가 독립 렌더 진입점이다. 하단에는 내레이션 자막을 유지한다.

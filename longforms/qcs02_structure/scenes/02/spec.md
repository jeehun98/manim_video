# 02 · 모든 문제에서 더 빠를까?

## 목적과 주장

모든 문제에서 더 빠를까?를 도형과 수식으로 설명한다.

## 확정 대본·길이

7–12초, 300프레임. 문장 경계와 겹치는 원문은 아래와 같으며 실제 자막 시각은 timing.json을 따른다.

그렇다면 양자컴퓨터는 모든 문제에서 기존 컴퓨터보다 빠를 수 있을까요?

## 화면·연산·정확성

주기·그래프·무작위 점의 서로 다른 모양에서 도입 질문을 제시한다. 모든 문제에 대한 보편적 가속을 주장하지 않는다.

## 연결

앞 장면: 간섭으로 조회 횟수를 줄인다. 다음: 그로버의 검색. direction.py의 s02가 독립 렌더 진입점이다. 하단에는 내레이션 자막을 유지한다.

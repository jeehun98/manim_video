# 13 · 함수의 반복에서 입력 진폭으로

## 목적과 주장

함수의 반복에서 입력 진폭으로를 도형과 수식으로 설명한다.

## 확정 대본·길이

104–106초, 120프레임. 문장 경계와 겹치는 원문은 아래와 같으며 실제 자막 시각은 timing.json을 따른다.

그리고 양자 푸리에 변환을 이용해, 주기에 관한 정보가 측정 결과에 나타나도록 만듭니다.

## 화면·연산·정확성

104–106초는 104–109초 문장 내부의 화면 변화다. f(x)=1에 대응하는 입력 위치 0,4를 선택하는 조건부 입력 레지스터 예를 보여준다. 함수 출력값 자체를 진폭으로 사용하지 않는다.

## 연결

앞 장면: 찾아야 하는 것은 주기. 다음: QFT가 주기 정보를 드러낸다. direction.py의 s13가 독립 렌더 진입점이다. 하단에는 내레이션 자막을 유지한다.

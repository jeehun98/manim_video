# 07 · 나머지가 만드는 반복 수열

## 목적과 주장

나머지가 만드는 반복 수열를 도형과 수식으로 설명한다.

## 확정 대본·길이

66–76초, 600프레임. 문장 경계와 겹치는 원문은 아래와 같으며 실제 자막 시각은 timing.json을 따른다.

예를 들어 15를 소인수분해한다고 생각해 보겠습니다.

2의 거듭제곱을 15로 나눈 나머지는 1, 2, 4, 8, 그리고 다시 1, 2, 4, 8로 반복됩니다.

## 화면·연산·정확성

66–69초 예제 정수 15. 69–76초 실제 modular_sequence로 생성한 1,2,4,8,1,2,4,8. 함수 자체를 매끄러운 정현파로 표시하지 않는다.

## 연결

앞 장면: 인수분해를 주기 찾기로. 다음: 최소 양의 주기 r = 4. direction.py의 s07가 독립 렌더 진입점이다. 하단에는 내레이션 자막을 유지한다.

# 쌍곡 거리의 유도와 푸앵카레 원판

사용자 확정 49문장·243초, 14개 독립 씬. 1920×1080 30fps, 무음·전체 내레이션 자막. 원판을 자기 자신으로 보내는 실제 뫼비우스 변환과 표준 곡률 -1 계량을 사용한다.

실행: `py -3.12 longforms/complex_geometry_04/build.py`

선택 검수: `py -3.12 longforms/complex_geometry_04/build.py --preview --scene 02 05 10 12`

결과: `exports/complex_geometry_04.mp4`. 앞 세 영상과 별도의 파일이며, 마지막 화면을 포함하여 정확히 243초. 문서의 추가 2–3초 제안은 적용하지 않았다. 화면에서 유한한 원과 국소 미분 배율을 구분하고, 반분 구간의 거리는 정확히 계산한다.

# 제작·검증 기록

- 사용자 제공33문장·종료 시각을 수정 없이 사용. 163초.
- 14개 독립 씬. 콘티의103–137초 화면 분할은 발화 우선으로 조정.
- 기존 02–07의 실제 영상 프레임 재사용: assets/provenance.json. 기존07의 network·실측 XOR 곡선도 직접 재사용. 새 원논문 재현으로 표현하지 않음.

- 마지막은 동일한 두 은닉 뉴런 아키텍처의 파라미터 배열을 다르게 보여주고 모든 입력의 함수 동일성을 질문으로 제시. 증명은 없음. 유한 입력 테스트 한계 표시.
- 원본 대본의 표현 수 질문은 표현의 동등성에 대한 문제 제기이며 연속 자유도 감소·최소 크기 존재의 증명이 아님.
- 하단 자막 영역은 전체 concat 뒤 단일 ASS로 렌더. 이벤트는 [시작, 종료)이며 전환 페이드 없음.
- 최종 결과는 무음. TTS 음원 없이 발화시간 기준으로 제작.

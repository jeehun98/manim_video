# 11 정확한 보존과 근사 보존

目的・주장: 정확한 함수 동등성과 오차 허용 보존을 구분. 곡선은 설명용.

확정 구간: 121–127초 (6초), 사용자 문장 종료 시각 기준. TTS 음원 미제공, 무음.

입력: 앞 장면의 질문. 시작: 제목과 주제 도형. 종료: 보존 조건과 결론.

화면: 기존 시리즈 팔레트, 청록=보존, 회색=제거, 노랑=질문. 전역 단일 자막 트랙은 하단 전용 영역.

# 02 그래프 · 무엇을 보존할까?

目的・주장: 8정점 그래프에서 연결성 유지 / 최단거리 증가를 실제 경로로 비교.

확정 구간: 8–23초 (15초), 사용자 문장 종료 시각 기준. TTS 음원 미제공, 무음.

입력: 앞 장면의 질문. 시작: 제목과 주제 도형. 종료: 보존 조건과 결론.

화면: 기존 시리즈 팔레트, 청록=보존, 회색=제거, 노랑=질문. 전역 단일 자막 트랙은 하단 전용 영역.

대본
여러 지점을 연결한 그래프에서 일부 연결을 제거하더라도, 모든 지점 사이의 이동 가능성은 유지할 수 있었습니다.
하지만 최단거리까지 보존하려면 이야기는 달라졌습니다.
같은 그래프에서도 무엇을 유지하려는지에 따라 필요한 연결이 달라진 것입니다.

## 확정 화면 타임라인

- 8초: 원래 그래프와 7간선 트리 비교
- 16초: 0번–7번 직접 간선과 7단계 경로 강조
- 19초: 연결성과 최단거리 보존을 구분

자막: narration_timing.json 문장 종료 시각을 전역 ASS 단일 트랙으로 적용. 전환 이전/이후 자막 크로스페이드 없음.

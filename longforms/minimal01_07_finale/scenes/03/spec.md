# 03 최소 유전체 · 조건에 따른 필수성

目的・주장: 같은 유전자 제거, 영양분 공급 조건별 생존 차이.

확정 구간: 23–33초 (10초), 사용자 문장 종료 시각 기준. TTS 음원 미제공, 무음.

입력: 앞 장면의 질문. 시작: 제목과 주제 도형. 종료: 보존 조건과 결론.

화면: 기존 시리즈 팔레트, 청록=보존, 회색=제거, 노랑=질문. 전역 단일 자막 트랙은 하단 전용 영역.

대본
생명체에서도 비슷한 질문을 던졌습니다.
어떤 유전자는 제거해도 생존할 수 있었지만, 다른 유전자의 존재나 주변 환경이 달라지면 필수적인 유전자가 될 수도 있었습니다.

## 확정 화면 타임라인

- 23초: 유전자 배열 등장
- 26초: 동일 유전자 제거, 환경 A/B 결과 병치

자막: narration_timing.json 문장 종료 시각을 전역 ASS 단일 트랙으로 적용. 전환 이전/이후 자막 크로스페이드 없음.

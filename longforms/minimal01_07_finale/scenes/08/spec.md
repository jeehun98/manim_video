# 08 서로 다른 보존 대상

目的・주장: 분야별 보존 대상 6개를 서로 구분.

확정 구간: 63–87초 (24초), 사용자 문장 종료 시각 기준. TTS 음원 미제공, 무음.

입력: 앞 장면의 질문. 시작: 제목과 주제 도형. 종료: 보존 조건과 결론.

화면: 기존 시리즈 팔레트, 청록=보존, 회색=제거, 노랑=질문. 전역 단일 자막 트랙은 하단 전용 영역.

대본
이 사례들은 모두 무언가를 줄이거나 단순화한다는 점에서 닮아 있습니다.
하지만 자세히 보면, 서로 다른 것을 보존하고 있습니다.
그래프에서는 연결성과 같은 구조적 성질을, 생명체에서는 특정 환경에서의 생존을, 통계학에서는 추론에 필요한 정보를 보존합니다.
제어이론에서는 입출력 동작을, 물리학에서는 특정한 거시적 법칙을, 신경망에서는 학습 성능을 살펴봤습니다.

## 확정 화면 타임라인

- 63초: 분야별 카드
- 67초: 보존 대상 카드 추가
- 71초: 그래프·생명·통계 강조
- 80초: 제어·물리·신경망 강조
- 84초: 구조 라벨 흐림, 보존 대상 유지

자막: narration_timing.json 문장 종료 시각을 전역 ASS 단일 트랙으로 적용. 전환 이전/이후 자막 크로스페이드 없음.

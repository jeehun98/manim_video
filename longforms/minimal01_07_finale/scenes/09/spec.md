# 09 공통 질문 · 무엇을 유지할까?

目的・주장: 추상 네트워크는 비유이며 통일 정리 아님. 조건 변경으로 필요한 간선 변화.

확정 구간: 87–103초 (16초), 사용자 문장 종료 시각 기준. TTS 음원 미제공, 무음.

입력: 앞 장면의 질문. 시작: 제목과 주제 도형. 종료: 보존 조건과 결론.

화면: 기존 시리즈 팔레트, 청록=보존, 회색=제거, 노랑=질문. 전역 단일 자막 트랙은 하단 전용 영역.

대본
그렇다면 여기서 하나의 공통된 원리를 발견할 수 있을까요?
전체를 이루는 모든 부분이, 우리가 관찰하려는 결과에 똑같이 중요한 것은 아니라는 것입니다.
그러나 어떤 부분이 불필요한지는 그 자체만 보고 결정할 수 없습니다.
먼저 무엇을 유지할 것인지 정해야 합니다.

## 확정 화면 타임라인

- 87초: 추상 그래프와 목표 성질
- 90초: 간선 축소, 목표 성질 유지
- 96초: 필요성은 조건 의존
- 100초: 무엇을 유지할지 질문

자막: narration_timing.json 문장 종료 시각을 전역 ASS 단일 트랙으로 적용. 전환 이전/이후 자막 크로스페이드 없음.

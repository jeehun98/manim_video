# 04 충분통계량 · 추론 정보 보존

目的・주장: 독립·동일 정규분포·알려진 분산·고정 표본 수에서 평균 추론.

확정 구간: 33–41초 (8초), 사용자 문장 종료 시각 기준. TTS 음원 미제공, 무음.

입력: 앞 장면의 질문. 시작: 제목과 주제 도형. 종료: 보존 조건과 결론.

화면: 기존 시리즈 팔레트, 청록=보존, 회색=제거, 노랑=질문. 전역 단일 자막 트랙은 하단 전용 영역.

대본
통계학에서는 수많은 관측값을 하나의 숫자로 줄이더라도, 특정 조건에서는 모수에 대한 추론 정보를 모두 보존할 수 있었습니다.

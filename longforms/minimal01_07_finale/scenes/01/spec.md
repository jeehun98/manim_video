# 01 모든 것이 정말 필요할까?

目的・주장: 여섯 분야의 실제 기존 장면을 축소 카드로 회수하고 중심 질문 제시.

확정 구간: 0–8초 (8초), 사용자 문장 종료 시각 기준. TTS 음원 미제공, 무음.

입력: 앞 장면의 질문. 시작: 제목과 주제 도형. 종료: 보존 조건과 결론.

화면: 기존 시리즈 팔레트, 청록=보존, 회색=제거, 노랑=질문. 전역 단일 자막 트랙은 하단 전용 영역.

대본
지금까지 우리는 서로 다른 분야에서 하나의 질문을 살펴봤습니다.
모든 것이 정말 필요할까요?
처음에는 단순한 구조에서 출발했습니다.

## 확정 화면 타임라인

- 0초: 6개 분야의 기존 실제 영상 프레임 카드 등장
- 4초: 카드가 작아지고 중심 질문 등장
- 6초: 질문 유지, 그래프 전환 준비

자막: narration_timing.json 문장 종료 시각을 전역 ASS 단일 트랙으로 적용. 전환 이전/이후 자막 크로스페이드 없음.

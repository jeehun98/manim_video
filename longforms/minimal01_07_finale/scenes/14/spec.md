# 14 다른 파라미터, 같은 함수?

目的・주장: 같은 아키텍처, 뉴런 위치와 연결 대응만 달리 배치. 전 입력 함수 동등성은 질문으로 남기며 유한 테스트는 증명 아님. 순열 대칭성은 크기나 연속 차원 감소를 보장하지 않음.

확정 구간: 146–163초 (17초), 사용자 문장 종료 시각 기준. TTS 음원 미제공, 무음.

입력: 앞 장면의 질문. 시작: 제목과 주제 도형. 종료: 보존 조건과 결론.

화면: 기존 시리즈 팔레트, 청록=보존, 회색=제거, 노랑=질문. 전역 단일 자막 트랙은 하단 전용 영역.

대본
서로 다른 파라미터를 가진 두 신경망이, 사실은 완전히 같은 함수를 표현하고 있다면 어떨까요?
그렇다면 우리가 줄여야 할 것은 연결의 개수만이 아닐지도 모릅니다.
신경망이 가진 수많은 파라미터 속에서, 실제로 서로 다른 표현이 몇 개나 존재하는지부터 다시 살펴봐야 할 것입니다.

## 확정 화면 타임라인

- 146초: 다른 뉴런 배열 병치
- 150초: −1,0,1의 입력 테스트 시각화
- 152초: 모든 x의 함수 동일성은 질문으로 표시
- 156초: 최종 질문 유지

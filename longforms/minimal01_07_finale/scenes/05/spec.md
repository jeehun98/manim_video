# 05 최소 실현 · 같은 입출력

目的・주장: ż=−z+2u, y=z 예시. 대응 초기값에서 같은 출력.

확정 구간: 41–48초 (7초), 사용자 문장 종료 시각 기준. TTS 음원 미제공, 무음.

입력: 앞 장면의 질문. 시작: 제목과 주제 도형. 종료: 보존 조건과 결론.

화면: 기존 시리즈 팔레트, 청록=보존, 회색=제거, 노랑=질문. 전역 단일 자막 트랙은 하단 전용 영역.

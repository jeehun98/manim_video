# 06 보편성 · 같은 거시적 법칙

目的・주장: 같은 보편성 부류, 임계점 근방의 점근적 스케일링.

확정 구간: 48–55초 (7초), 사용자 문장 종료 시각 기준. TTS 음원 미제공, 무음.

입력: 앞 장면의 질문. 시작: 제목과 주제 도형. 종료: 보존 조건과 결론.

화면: 기존 시리즈 팔레트, 청록=보존, 회색=제거, 노랑=질문. 전역 단일 자막 트랙은 하단 전용 영역.

대본
그리고 물리학에서는 서로 다른 미시적 구조를 가진 물질들이 같은 거시적 법칙을 따를 수 있다는 사실을 확인했습니다.

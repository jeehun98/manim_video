# 완료 검증

- 가로 1920×1080 / 세로 1080×1920, H.264, 30fps, 175.000초, 각각 5250프레임. 오디오 트랙 없음.
- 원문 35문장·문장 종료 시각 유지, 연속 자막 구간 35개, 독립 씬 16개. TTS는 제목·시각 없이 빈 줄 구분 35개 문단.
- ADD/SUB 512개, 비교 256개, ALU/MUX 1024개 입력 검증 통과. 부호 있는 overflow 사례 포함.
- 5−3 결과0010, Cout1. 네 선택 출력1000/0010/0001/0111. 산술 경로는 가산기 하나를 공유한다.
- 최종 두 비율 대표 화면과 모든 35개 자막 경계의 직전·정확한 시점·직후 프레임 확인. 겹침·프레임 이탈 없음.
- 제어 전환마다 동일한 ALUDiagram 객체의 고정 배선·MUX 핀 좌표를 실행 중 검사. 물리 재배선 없음.
- 미리보기에서 가로 회로 확대 및 도형 변환 렌더 오류 수정 후 최종 전 씬 재렌더 완료.
- 재현 명령은 README.md, 메타데이터·SHA256은 verification_final.json, 산술 검증은 alu_verification.json에 보관.

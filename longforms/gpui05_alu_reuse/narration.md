# GPU 개론 05 — 하나의 회로로 여러 연산을 수행하는 방법

확정 원문 35문장·사용자 문장 종료 시각 175초. 음원 미제공.

## 0–14초 · 연산마다 회로가 필요할까?

0–5초: 앞서 우리는 논리 게이트를 연결해 실제 숫자의 덧셈을 구현하는 방법을 살펴봤습니다.

5–10초: 그렇다면 뺄셈이나 비교처럼 다른 연산이 필요할 때는 어떻게 해야 할까요?

10–14초: 가장 단순한 방법은 연산마다 새로운 회로를 만드는 것입니다.

## 14–23초 · 기존 회로를 활용할 수 있다면

14–19초: 하지만 연산의 종류가 늘어날수록 더 많은 트랜지스터와 배선이 필요하게 됩니다.

19–23초: 그렇다면 이미 만들어 놓은 회로를 다른 연산에도 활용할 수는 없을까요?

## 23–41초 · 뺄셈을 덧셈으로 바꾸기

23–25초: 먼저 뺄셈을 생각해 보겠습니다.

25–30초: 우리는 두 숫자의 차이를 구할 때, 덧셈과는 다른 연산이라고 생각합니다.

30–33초: 그런데 이진수에서는 뺄셈을 덧셈의 형태로 바꿀 수 있습니다.

33–39초: 일정한 비트 수를 정하고, 빼려는 숫자의 각 비트를 반전한 다음 1을 더하는 것입니다.

39–41초: 이것을 2의 보수라고 합니다.

## 41–57초 · 4비트로 5 − 3을 계산하면

41–44초: 예를 들어 4비트에서 5에서 3을 빼보겠습니다.

44–47초: 5는 0101, 3은 0011입니다.

47–51초: 3의 비트를 반전하면 1100이고, 여기에 1을 더하면 1101이 됩니다.

51–57초: 이 값을 0101에 더하고 하위 4비트만 남기면 0010, 즉 2가 됩니다.

## 57–69초 · 하나의 가산기로 ADD와 SUB

57–61초: 결국 별도의 뺄셈 회로 없이도 기존 덧셈 회로를 활용할 수 있는 것입니다.

61–69초: 더 나아가 입력 비트를 반전할지 결정하는 제어 신호를 추가하면, 하나의 가산기로 덧셈과 뺄셈을 모두 수행할 수 있습니다.

## 69–83초 · 뺄셈 결과를 비교에 활용하기

69–73초: 그렇다면 비교 연산도 기존 회로를 활용할 수 있을까요?

73–78초: 두 숫자가 같은지 확인하려면, 두 숫자를 뺀 결과가 0인지 살펴보면 됩니다.

78–83초: 크기 비교 역시 뺄셈에서 발생하는 결과와 상태 신호를 활용해 구현할 수 있습니다.

## 83–93초 · 계산 경로를 공유하는 설계

83–89초: 이처럼 새로운 연산이 필요하다고 해서 언제나 완전히 독립적인 계산 회로를 추가할 필요는 없습니다.

89–93초: 이미 구현한 연산을 다른 방식으로 활용할 수 있는 것입니다.

## 93–101초 · 다른 기능에는 다른 논리 구조

93–97초: 하지만 모든 연산을 하나의 덧셈 회로로 처리할 수 있는 것은 아닙니다.

97–101초: AND나 OR 같은 논리 연산에는 다른 논리 구조를 사용할 수 있습니다.

## 101–111초 · 여러 기능을 한 장치 안에

101–106초: 그렇다면 이런 여러 연산 기능을 하나의 장치 안에 모아두면 어떨까요?

106–111초: 덧셈과 뺄셈을 수행하는 회로, 논리 연산을 수행하는 회로를 미리 구성하는 것입니다.

## 111–120초 · 여러 결과 중 하나를 선택

111–115초: 그리고 어떤 연산의 결과를 사용할지 선택하는 회로를 추가합니다.

115–120초: 이때 여러 입력 중 하나를 선택해 출력하는 회로를 멀티플렉서, 줄여서 MUX라고 합니다.

## 120–129초 · 같은 입력, 다른 선택 신호

120–129초: 예를 들어 제어 신호가 00이면 덧셈, 01이면 뺄셈, 10이면 AND, 11이면 OR의 결과를 선택하도록 설계할 수 있습니다.

## 129–135초 · 산술논리장치 ALU

129–135초: 이러한 산술 연산과 논리 연산을 수행하는 장치를 ALU, 산술논리장치라고 합니다.

## 135–148초 · 배선은 고정, 신호는 변화

135–141초: 여기서 중요한 것은 제어 신호가 바뀐다고 트랜지스터의 물리적인 연결이 바뀌는 것은 아니라는 점입니다.

141–148초: 연산에 필요한 회로들은 미리 설계되어 있고, 입력 신호에 따라 그 회로들의 동작이나 결과 선택이 달라지는 것입니다.

## 148–156초 · 회로 재사용과 기능 통합

148–156초: 이렇게 하면 매번 새로운 계산 장치를 만드는 대신, 기존의 회로를 재사용하고 여러 연산 기능을 하나의 장치에서 활용할 수 있습니다.

## 156–161초 · 구현된 기능에는 범위가 있다

156–161초: 물론 지원할 수 있는 연산과 성능은 실제로 구현된 회로 구조에 따라 제한됩니다.

## 161–175초 · 재사용하고, 통합하고, 선택한다

161–167초: 결국 컴퓨터의 연산 장치를 설계한다는 것은 가능한 모든 회로를 무작정 추가하는 일이 아닙니다.

167–175초: 어떤 연산을 공통된 회로로 처리하고, 어떤 기능을 별도로 구현하며, 그중 필요한 결과를 어떻게 선택할지 결정하는 과정입니다.

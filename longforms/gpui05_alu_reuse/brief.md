# 제작 기준

핵심 주장: 공통 계산 구조를 재사용하고, 별도 기능을 통합하고, 필요한 결과를 선택하도록 연산 장치를 설계한다.

확정 원문 35문장·175초를 변경하지 않는다. 사용자가 제공한 도입을 유지하고 복습·예고를 추가하지 않는다. 두 비율 모두 전체 대본을 유지한다.

색상: A 파랑, B 보라, 제어 주황, 선택 결과 초록, 비선택 회색. 4비트 결과와 Cout을 분리한다. 5−3은 0101+1101=1|0010이다. 실제 공유 회로는 0101+1100+Cin1로 계산한다.

SUB는 B의 네 XOR와 Cin을 함께 제어한다. 비교에는 결과·상태 플래그를 해석하는 추가 논리가 필요하다. SIGN만으로 비교하지 않는다. 공통 A/B는 산술 및 AND/OR 경로로 분기한다. 공유 산술 결과는 하나이다. 00/01은 같은 MUX 핀이며 SUB만 다르고, 10/11은 논리 핀을 선택한다. 네 코드는 예시이다.

제어 변경 시 모든 물리 배선은 고정한다. 비선택 회로 전체가 정지한다고 주장하지 않는다. 면적·전력 절약이나 성능 개선 수치를 추정하지 않는다. DIV는 이 예시 ALU에서 직접 미구현이라는 뜻이다.

최종 검증: 175.000초·5250프레임·30fps, 1920×1080/1080×1920, 무음. 대표 프레임과 35문장 경계 직전/시점/직후 검사. 자막 Text 하나를 경계에서 즉시 교체하며 중첩 페이드를 사용하지 않는다.

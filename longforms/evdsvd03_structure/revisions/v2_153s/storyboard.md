# 행렬 분해 이상형 월드컵 ③ — EVD vs SVD | 분해 구조

수정 영상화 콘티 · 좌표·그래프 애니메이션 중심 · 9:16 세로 영상

이번 버전은 수식을 계산하는 영상이 아니라, 좌표계가 바뀌고 벡터가 변환되는 모습을 관찰하는 영상으로 설계하자.

특히 이전 영상에서 눈에 잘 들어오지 않았던 행렬 원소, 수치 대입, 내적값 비교는 제거하고, 한 장면에서 만들어진 시각적 요소를 다음 장면까지 유지하는 방식으로 바꾸는 게 좋아.

## 1. 전체 영상의 시각적 원칙

## EVD

하나의 기저

기울어진 두 고유방향에서 성분을 분리하고, 같은 방향들로 다시 조합

## SVD

두 직교기저

입력 원의 직교축을 출력 타원의 다른 직교축에 대응

연출 원칙: 화면에는 한 번에 하나의 주요 수식과 하나의 주요 움직임만 남긴다.

### 공통 디자인

- 배경: 짙은 남색, 얇은 회색 좌표격자.
- 원본 입력 벡터: 금색.
- EVD 고유방향: 파랑과 보라.
- SVD 입력 특이방향: 파랑과 보라.
- SVD 출력 특이방향: 청록과 연녹색.
- 실제 변환 결과: 금색 실선.
- 좌표 표현 변경: 격자와 축이 바뀌되 동일한 벡터의 위치는 유지한다.
- 실제 선형변환: 벡터 끝점이 이동하고 길이·방향이 변한다.

## 2. 좌표 애니메이션에 사용할 행렬

이번에는 수치 자체를 화면에 보여주지 않지만, 정확한 애니메이션을 만들기 위해 내부 계산에는 구체적인 행렬이 필요해.

### EVD 예시

\\[ A_E=\begin{pmatrix}2&1\\\0&1\end{pmatrix} \\]

고유방향은 수평 방향과 대각선 방향이야.

\\[ p_1=(1,0)^T,\qquad p_2=(1,-1)^T \\]

두 방향은 서로 직교하지 않고, 변환 후에도 각각 자기 직선 위에 남아.

### SVD 예시

\\[ A_S= R(30^\circ) \begin{pmatrix}2&0\\\0&1\end{pmatrix} R(-25^\circ) \\]

입력의 두 특이방향은 25도와 115도, 출력의 두 특이방향은 30도와 120도가 돼.

입력 방향과 출력 방향이 다르면서 각각 직교하므로, 두 기저의 차이를 선명하게 보여줄 수 있는 예시야.

이 행렬로 단위원을 변환하면 반축 길이 2와 1을 가진, 30도 기울어진 타원이 만들어져.

내레이션

화면

애니메이션

## SCENE 03. 고유방향은 변환 전후에 유지된다

13–23초

내레이션

“좌표평면에 두 고유벡터를 표시해 보겠습니다. 고유벡터에 행렬 A를 적용하면, 길이가 변하거나 방향이 반전되더라도 원래 직선 위에 남습니다. 이것이 A 곱하기 V는 람다 곱하기 V라는 관계입니다.”

두 고유벡터의 직선은 고정하고, 변환 시 각 벡터의 길이만 달라지도록 연출한다.

세부 움직임

- 13\~16초: 수평 고유벡터 \\(p_1\\) 등장.
- 16\~19초: 대각선 고유벡터 \\(p_2\\) 등장.
- 19\~21초: \\(p_1\\)은 원래 수평 직선을 따라 길어진다.
- 21\~23초: \\(p_2\\)는 같은 대각선 위에 남는다. 고유벡터 관계식 표시.

실제 예시의 고윳값은 양수이므로 방향 반전은 시연하지 않는다. 음의 고윳값에서 반전될 수도 있다는 사실은 내레이션과 보조 자막만으로 처리하자.

## SCENE 04. 두 고유벡터를 새로운 좌표축으로 사용

23–30초

내레이션

“이제 두 고유벡터를 새로운 좌표축으로 사용해 보겠습니다. 입력 벡터를 이 좌표축의 성분으로 나누고, 각 성분에 고윳값을 곱합니다.”

화면 구성

기존 직교 좌표격자가 서서히 사라지고, 두 고유벡터를 기준으로 하는 비스듬한 격자가 나타난다.

실제 변환을 적용하기 전, 동일한 입력 벡터를 고유기저에서 새롭게 표현한다.

애니메이션

- 23\~25초: 두 고유벡터가 좌표축으로 길게 확장된다.
- 25\~27초: 비스듬한 평행사변형 격자가 등장.
- 27\~30초: 금색 입력 벡터를 두 고유방향의 성분 화살표로 분리한다.

이때 입력 벡터 끝점은 움직이면 안 돼. 좌표 표현이 바뀌었을 뿐, 벡터 자체는 동일하다는 점이 중요해.

## SCENE 05. 성분별 확대 후 원래 좌표로 표현

30–34초

내레이션

“그리고 변환된 성분들을 원래 좌표계로 표현합니다. 이것이 P 역행렬, D, P가 수행하는 과정입니다.”

애니메이션

- 수평 고유성분은 길이가 2배로 늘어난다.
- 다른 고유성분은 길이가 유지된다.
- 두 성분을 다시 합쳐 최종 출력 벡터를 만든다.
- 비스듬한 격자를 원래 직교격자로 교체해 결과를 표현한다.

상단에 작게 표시한다.

\\[ P^{-1}\ \longrightarrow\ D\ \longrightarrow\ P \\]

여기서 \\(D\\)만 실제 성분 길이 변화로 보여주고, \\(P^{-1}\\)와 \\(P\\)는 좌표 표현의 변환으로 보여주자.

## SCENE 06. 왜 역행렬이 필요한가?

34–49초 · 수정 대본 기준 예상 배치

내레이션

“여기서 고유기저의 두 축은 반드시 직교할 필요가 없습니다. 따라서 일반적으로 좌표를 변환할 때 고유벡터와의 내적만으로는 충분하지 않고, P 역행렬을 사용합니다.”

추천 연출

수식 계산을 하지 않고 두 종류의 좌표 성분 분해를 비교한다.

직교 좌표축

각 축의 직교 투영으로 성분 추출

기울어진 고유축

비스듬한 두 축을 기준으로 성분 분해

실제 애니메이션 설계

- 34\~38초: 직교 좌표축에서는 벡터를 수평·수직으로 투영하여 성분을 찾는다.
- 38\~43초: 두 축을 비스듬한 고유기저로 바꾸면 같은 방식의 직교 투영으로는 정확한 좌표 성분을 얻지 못한다.
- 43\~49초: 비스듬한 격자를 따라 평행사변형을 구성하여 정확한 두 기저 성분을 찾아낸다. 화면에 \\(P^{-1}\\) 표시.

수학적으로 \\(P^{-1}\\)는 쌍대기저를 사용한 좌표 추출에 해당하지만, 이 영상에서는 쌍대기저까지 설명하지 않아도 돼.

# 4. SVD 파트 — 입력과 출력에서 서로 다른 방향을 선택한다

SVD 구간에서는 하나의 좌표평면에서 변환 과정을 보여주다가, 필요할 때만 입력과 출력 화면을 분리하는 방식을 추천해.

단위원의 점들이 타원으로 이동하는 모습을 먼저 보여주고, 이후에는 원과 타원을 좌우에 고정해 특이방향의 대응을 살펴보는 거야.

## SCENE 08. 단위원에서 타원으로

약 54–64초

내레이션

“그렇다면 SVD는 어떨까요? 이번에는 단위원에 행렬 A를 적용해 보겠습니다. 원 위의 벡터들이 변환되면서 타원이 만들어집니다.”

영상 구성

- 화면에 직교 좌표평면 하나만 표시한다.
- 원점을 중심으로 반지름 1의 원을 그린다.
- 원 둘레에 24\~48개의 작은 점을 배치한다.
- 각 점에 행렬 \\(A\\)를 적용해 타원 위의 대응 위치까지 연속적으로 이동시킨다.
- 원은 점차 희미해지고 최종 타원이 강조된다.

애니메이션 핵심

원에서 타원으로 바뀌는 모습을 단순한 모양 보간으로 처리하지 말고, 각 점이 실제 선형변환

\\[ x(t)=(1-t)x+tAx \\]

에 따라 움직이도록 만들자.

이렇게 하면 시각적으로는 부드러운 형태 변화지만, 최종 위치는 실제 행렬에 의해 계산된 결과가 돼.

화면 자막

`단위원 → 선형변환 → 타원`

## SCENE 09. 어떤 입력 방향이 타원의 긴 축을 만들까?

약 64–73초

내레이션

“그런데 원 위의 어떤 방향이 타원의 가장 긴 축으로 변환될까요? SVD는 바로 그 입력 방향을 찾아냅니다.”

화면

입력 단위원과 출력 타원을 좌우로 분리한다.

입력 원 위의 점을 이동시키면 출력 타원의 대응점도 함께 이동한다.

세부 움직임

1. 입력 원 위의 벡터 하나를 금색으로 표시한다.
2. 입력 벡터를 원 둘레를 따라 천천히 회전시킨다.
3. 출력 타원 위의 대응 벡터가 동시에 움직인다.
4. 출력 벡터가 가장 길어지는 순간 움직임을 멈춘다.
5. 입력 방향에 \\(v_1\\) 라벨을 붙인다.

이 장면에서는 수치나 각도를 표시하지 말고, 출력 벡터의 길이를 눈으로 비교할 수 있도록 움직임을 설계하자.

## SCENE 10. 오른쪽 특이벡터와 왼쪽 특이벡터

약 73–85초

내레이션

“이 방향을 첫 번째 오른쪽 특이벡터, V 원이라고 하겠습니다. 변환된 결과가 향하는 타원의 긴 축 방향은 첫 번째 왼쪽 특이벡터, U 원입니다. 입력 벡터의 길이는 1이고, 변환된 결과의 길이는 첫 번째 특이값, 시그마 원입니다.”

화면

- 왼쪽 단위원: 파란색 \\(v_1\\) 강조.
- 오른쪽 타원: 청록색 \\(u_1\\) 강조.
- 실제 출력 벡터는 \\(u_1\\)보다 길게 그리며 \\(\sigma_1u_1\\)으로 표시.

\\[ Av_1=\sigma_1u_1 \\]

\\(v_1\\)

입력의 단위방향

\\(u_1\\)

출력의 단위방향

애니메이션

- 입력 벡터의 길이는 고정한다.
- 출력 타원의 긴 반축을 따라 \\(u_1\\) 단위벡터가 나타난다.
- \\(u_1\\)을 확대해 실제 출력 \\(Av_1\\)까지 늘린다.
- 늘어난 길이에 \\(\sigma_1\\) 라벨을 표시한다.

중요한 점은 \\(u_1\\)과 실제 출력 \\(Av_1\\)의 길이를 구별하는 거야.

## SCENE 11. 두 번째 입력 특이방향 등장

약 85–96초

내레이션

“따라서 A 곱하기 V 원은 시그마 원 곱하기 U 원입니다. 이제 입력 방향을 90도 돌려 보겠습니다. 두 번째 입력 특이방향은 타원의 짧은 축에 대응합니다.”

애니메이션

- 첫 번째 입력 특이벡터 \\(v_1\\)을 유지한다.
- 입력 원에서 \\(v_1\\)과 90도를 이루는 방향에 \\(v_2\\)를 그린다.
- 출력 타원에서는 짧은 반축 방향의 \\(u_2\\)가 나타난다.
- \\(v_1\to u_1\\), \\(v_2\to u_2\\) 두 대응을 차례로 강조한다.

수학적 주의사항

타원의 축 두 개와 입력의 특이축 두 개는 각각 정확히 직교해야 해.

또한 실제 애니메이션에서는 왼쪽 원 위의 \\(v_2\\)가 오른쪽 타원의 \\(u_2\\)로 이동할 때, 두 점의 위치가 정확히 \\(Av_2=\sigma_2u_2\\)를 만족하도록 계산해야 해.

## SCENE 12. SVD의 핵심 — 두 직교기저는 서로 다르다

약 96–109초

내레이션

“여기서 중요한 특징이 나타납니다. 입력의 두 특이방향은 서로 직교하고, 변환된 출력 방향들도 서로 직교합니다. 하지만 입력과 출력의 기저는 서로 다른 방향을 향할 수 있습니다.”

추천 애니메이션

이번 영상에서 가장 강조해야 할 장면이야.

1. 원과 타원의 윤곽을 서서히 숨긴다.
2. 입력의 두 특이축 \\(v_1,v_2\\)만 남긴다.
3. 출력의 두 특이축 \\(u_1,u_2\\)도 남긴다.
4. 두 축 세트를 동일한 원점에 겹쳐서 비교한다.
5. 두 세트의 방향이 서로 다름을 보여준다.

## 7. 이번 버전에서 반드시 지켜야 할 구현 원칙

이번 콘티에서 주의할 사항은 세 가지야.

첫째, 좌표를 바꾸는 과정과 벡터를 실제로 변환하는 과정을 구별하자. \\(P^{-1}\\) 또는 \\(V^T\\)로 좌표를 바꿀 때는 기준축과 좌표 표현을 변경하는 것이고, \\(D\\) 또는 \\(\Sigma\\)를 적용할 때는 성분별 배율을 변경하는 것이야. 마지막 \\(P\\)와 \\(U\\)는 다시 원래 좌표계 또는 출력 기저에서 결과 벡터를 구성하는 역할을 해.

둘째, SVD에서는 입력과 출력의 특이방향을 정확히 대응시키자. 입력의 두 특이축과 출력의 두 특이축은 각각 직교해야 하고, 같은 인덱스의 \\(v_i\\), \\(u_i\\)가 연결되어야 해. 입력 원의 점과 출력 타원의 점은 반드시 하나의 행렬 \\(A\\)로 대응하도록 계산해야 하고.

셋째, 9:16 화면을 복잡한 수식으로 채우지 말자. 상단에는 현재 연산 기호 하나, 중앙에는 벡터와 좌표계, 하단에는 짧은 설명만 두는 방식이 가장 적합해.

이렇게 수정하면 이전처럼 실제 수치 계산을 따라가야 하는 영상이 아니라, 고유방향은 왜 그대로 유지되고, 특이방향은 왜 입력과 출력에서 각각 선택되는지를 눈으로 이해하는 영상이 될 거야.

그리고 실제 영상에서 가장 긴 시간을 할애해야 할 부분은 SVD의 \\(v_1,v_2\\)와 \\(u_1,u_2\\) 대응 장면이야. 이 차이가 명확하게 전달되면 \\(A=U\Sigma V^T\\)의 구조도 훨씬 자연스럽게 이해할 수 있어.

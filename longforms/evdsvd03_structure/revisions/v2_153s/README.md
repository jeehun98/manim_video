## 학습 목표

숫자 행렬이나 내적값 비교 없이, 같은 고유기저와 서로 다른 입력·출력 직교기저를 그래프로 구분한다.

## 핵심 결론

EVD는 동일한 고유방향에서 성분을 분리·변환·복원하고, SVD는 입력과 출력의 서로 다른 정규직교 방향을 연결한다.

## 작업 순서

1. 사용자 수정 대본·문장 종료 시각 보존.
2. 시간·주장·시작/종료 상태를18개spec으로 확정.
3. 그래프와 화면 자막을 만들고 두 미리보기 검토.
4. 최종 렌더·concat·프레임 수·전체 디코딩 검증.

## 수학·시각 기준

- 화면에서 숫자 행렬·좌표 대입·내적값 비교를 제거. 주요수식 하나와 그래프를 유지.
- EVD 내부 A_E=[[2,1],[0,1]], P=[[1,1],[0,-1]]. 좌표 격자 변경에서는 입력 벡터 고정. D에서만 실제 성분 길이 변경.
- 비직교축의 개별 직교투영과 올바른 평행사변형 성분을 회색/파랑·보라로 구분. 수치 비교 없음.
- SVD 내부 A=R30 diag(2,1) R(-25), V=R25,U=R30. 입력25/115도, 출력30/120도. 각도는 화면에 표시하거나 과장하지 않음.
- 단위원48점은 각 프레임 (1-t)x+tAx로 이동. 타원 반축2,1의 방향은 실제 U 사용.
- 원·타원의 분리 표시에서도 동일 척도 사용. u1은 단위방향이고 Av1은 그2배 길이인 실제 출력.
- 두 직교기저는 동일 원점으로 겹쳐 비교. 실제5도 차이를 금색 틈과 별도 색상으로 표시.
- SVD 임의 입력은 c=(1.15,-.75), x=Vc. 음의 둘째 성분도 화살표 방향으로 유지.
- Σ 단계의 화면 임베딩은 VΣc, U 단계에서는 성분을 U방향으로 재조합하여 UΣc=Ax. 세계좌표 벡터에 U를 다시 곱하는 것으로 혼동하지 않음.
-153초와4590프레임 검증. 기존149초 시간 재사용·속도 변경 없음. 최대1프레임 반올림만 보정.
- 취향 판정: 같은 고유기저의 구조적 간결함.143초 EVD,150초점수2:1,152초리드,153초종료.

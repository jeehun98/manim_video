# 어떤 입력 방향일까?

## 목적·핵심 주장
원·타원 분리 후 동일한 A로 대응하는 화살표를 회전. 입력25도에서 정지, 출력30도 장축. 각도·수치 표시 금지

## 앞 장면에서 받은 내용
공통 원점·격자·색과 해당 벡터 상태를 그대로 재구성해 컷 경계에서 연속성을 유지한다.

## TTS 원문·확정 길이
그런데 원 위의 어떤 방향이 타원의 가장 긴 축으로 변환될까요? SVD는 바로 그 입력 방향을 찾아냅니다.

사용자 확정 63–70초, 7초. 콘티의 예상 구간보다 이 시각을 우선한다.

## 화면·시간대별 애니메이션
원·타원 분리 후 동일한 A로 대응하는 화살표를 회전. 입력25도에서 정지, 출력30도 장축. 각도·수치 표시 금지
9:16과16:9 각각 배치. 숫자행렬·수치대입·내적값비교 제거. 주요수식 하나와 주요움직임 하나만 표시.

## 시작·종료 상태
전장면의 그림을 이어받아 현재 연산을 강조하고 다음 단계 상태를 남긴다.

## 다음 장면 연결
같은 시각객체의 위치·색을 유지한다. 물리적벡터변환과 좌표표현변경을 구분. 회상·예고 없음.

## 정확성
원·타원 분리 후 동일한 A로 대응하는 화살표를 회전. 입력25도에서 정지, 출력30도 장축. 각도·수치 표시 금지
SVD는 동일한 가역행렬의 계산값 사용. 투영은 부호를 보존한다. 승패는 구조적간결성에 대한 취향판정.

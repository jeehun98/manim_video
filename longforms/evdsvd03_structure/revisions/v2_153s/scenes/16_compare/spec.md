# 하나의 고유기저 vs 두 직교기저

## 목적·핵심 주장
133–136초 EVD 같은축강조,136–141초 SVD 다른두기저강조. 수치 없음

## 앞 장면에서 받은 내용
공통 원점·격자·색과 해당 벡터 상태를 그대로 재구성해 컷 경계에서 연속성을 유지한다.

## TTS 원문·확정 길이
결국 EVD는 하나의 고유기저로 변환을 표현하고, SVD는 입력과 출력의 서로 다른 직교기저 사이에서 변환을 표현합니다.

사용자 확정 133–141초, 8초. 콘티의 예상 구간보다 이 시각을 우선한다.

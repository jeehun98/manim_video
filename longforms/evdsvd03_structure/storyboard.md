# 행렬 분해 이상형 월드컵 ③ — EVD vs SVD | 분해 구조

전체 영상화 콘티 · 2분 29초(149초) · 9:16 세로 영상 · 내레이션 타임스탬프 기준

이번 편은 같은 선형변환을 EVD와 SVD가 서로 다른 방식으로 해석한다는 사실을 영상으로 보여주는 것이 핵심이야.

2편에서 분해가 가능한 행렬의 범위를 비교했다면, 이번에는 실제로 벡터를 변환하고, 기저를 바꾸고, 내적으로 성분을 추출하는 과정을 보여주자.

## 1. 전체 영상의 시각적 방향

MATRIX DECOMPOSITION WORLD CUP

ROUND 03

# EVD

\\(A=PDP^{-1}\\)하나의 고유기저

# SVD

\\(A=U\Sigma V^T\\)입력·출력 직교기저

현재 스코어

# 1 : 1

연출은 세 부분에 집중하면 좋아.

- EVD(5\~58초): 고유방향을 유지하는 변환 → 같은 기저에서 좌표를 추출하고 복원
- SVD(58\~105초): 단위원이 타원으로 변환 → 입력 특이방향과 출력 특이방향의 대응
- 분해식(105\~137초): 내적으로 입력 좌표를 추출 → 크기를 조정 → 출력 기저에서 조합

### 수학 예시를 먼저 고정하자

이번 영상은 두 행렬을 사용하자.

EVD 예시

비스듬한 고유기저

\\[ A_E=\begin{pmatrix}2&1\\\0&1\end{pmatrix} \\]

\\[ P=\begin{pmatrix}1&1\\\0&-1\end{pmatrix},\qquad D=\begin{pmatrix}2&0\\\0&1\end{pmatrix} \\]

고유방향은 \\((1,0)^T\\)와 \\((1,-1)^T\\). 서로 직교하지 않아.

SVD 예시

회전과 방향별 확대

\\[ A_S=\begin{pmatrix}0&-1\\\3&0\end{pmatrix} \\]

\\[ V=I,\quad \Sigma=\begin{pmatrix}3&0\\\0&1\end{pmatrix},\quad U=\begin{pmatrix}0&-1\\\1&0\end{pmatrix} \\]

입력의 수평·수직 방향이 출력의 수직·왼쪽 수평 방향으로 대응해.

이 두 예시의 차이를 명확하게 보여주면 충분해. EVD에서는 고유기저가 비직교할 수 있다는 사실, SVD에서는 입력과 출력의 기저가 다르면서도 각각 정규직교한다는 사실을 강조할 수 있어.

### SCENE 03. 고유벡터는 원래 직선을 유지한다

00:13–00:23

내레이션

“고유벡터에 A를 적용하면, 길이가 달라지거나 방향이 반전되더라도 원래 직선 위에 남습니다. 이것이 A 곱하기 V는 람다 곱하기 V라는 관계입니다.”

\\[ Ap_i=\lambda_i p_i \\]

세부 움직임

- 13\~16초: 고유벡터 \\(p_1\\)이 나타난다.
- 16\~19초: 같은 직선 위에서 길이가 2배로 늘어난다.
- 19\~23초: \\(Ap_1=2p_1\\)과 일반식 \\(Ap_i=\lambda_i p_i\\)를 연결.

네 원고에는 \\(V\\)라고 발음되어 있지만 EVD 시각화에서는 \*\*\\(p_i\\)\*\*로 통일하자. SVD의 \\(v_i\\)와 혼동을 줄일 수 있어.

참고로 선택한 행렬은 고윳값이 2와 1로 양수이기 때문에 실제 연출에서는 방향 반전이 발생하지 않아. 내레이션에서 말하는 방향 반전은 음의 고윳값이 가능한 일반적인 성질로, 작은 보조 예시만 표시하면 충분해.

### SCENE 04. 고유기저로 분해하고 다시 돌아온다

00:23–00:34

내레이션

“선형독립인 고유벡터들을 기저로 모으면, 입력을 고유기저의 좌표로 바꾸고 각 성분에 고윳값을 곱할 수 있습니다. 그 결과를 원래 좌표계로 되돌리는 것이죠. 이 과정이 P 역행렬, D, P의 역할입니다.”

\\(P^{-1}x\\)고유기저 좌표

\\(D(P^{-1}x)\\)성분별 배율

\\(PD(P^{-1}x)\\)원래 좌표

실제 계산 예시

\\[ P=\begin{pmatrix}1&1\\\0&-1\end{pmatrix}, \quad P^{-1}=\begin{pmatrix}1&1\\\0&-1\end{pmatrix} \\]

\\[ x=\begin{pmatrix}2\\\\-1\end{pmatrix} =p_1+p_2 \\]

\\[ P^{-1}x=\begin{pmatrix}1\\\1\end{pmatrix} \\]

\\[ D\begin{pmatrix}1\\\1\end{pmatrix} =\begin{pmatrix}2\\\1\end{pmatrix} \\]

\\[ P\begin{pmatrix}2\\\1\end{pmatrix} =\begin{pmatrix}3\\\\-1\end{pmatrix} =Ax \\]

애니메이션

- 23\~27초: 비스듬한 두 고유벡터를 기준축으로 사용. 입력 벡터가 두 축 성분으로 분리된다.
- 27\~30초: 고유기저 좌표 \\((1,1)\\)이 \\(D\\)를 거쳐 \\((2,1)\\)로 바뀐다.
- 30\~32초: 결과 성분을 \\(p_1,p_2\\) 방향으로 다시 합친다.
- 32\~34초: \\(P^{-1}\rightarrow D\rightarrow P\\)라는 흐름이 분해식 위에 연결된다.

영상 제작 주의: 기저를 바꾼다는 것을 실제 벡터가 물리적으로 회전했다는 뜻처럼 표현하지 말자. 벡터의 좌표 표현이 바뀐다는 의미로, 같은 벡터를 다른 격자와 숫자로 표현하는 연출이 좋아.

### SCENE 05. 행렬과 벡터의 곱은 내적들로 이루어진다

00:34–00:42

내레이션

“그런데 좌표를 바꾼다는 것은 무엇일까요? 행렬과 벡터의 곱에서는 각 행과 입력 벡터의 내적이 출력 성분을 만듭니다.”

\\[ \begin{pmatrix} a&b\\\ c&d \end{pmatrix} \begin{pmatrix}x_1\\\x_2\end{pmatrix} = \begin{pmatrix} ax_1+bx_2\\\ cx_1+dx_2 \end{pmatrix} \\]

\\((a,b)\cdot x\\)첫 번째 출력 성분

\\((c,d)\cdot x\\)두 번째 출력 성분

애니메이션

- 34\~37초: 좌표변환 흐름이 잠시 멈추고 행렬곱을 확대.
- 37\~39초: 행렬 첫 행과 입력 벡터를 연결하고 \\(ax_1+bx_2\\)를 생성.
- 39\~41초: 둘째 행도 동일하게 수행.
- 41\~42초: 두 계산 결과가 세로로 쌓이며 하나의 출력 벡터가 완성.

내적은 벡터 하나를 출력하는 것이 아니라 각 행의 내적값들이 모여 출력 벡터를 구성하는 것으로 표현하자.

### SCENE 06. EVD의 고유기저는 일반적으로 직교하지 않는다

00:42–00:53

내레이션

“P 역행렬도 이러한 내적을 통해 고유기저의 좌표를 구합니다. 다만 고유벡터들은 일반적으로 직교하지 않으므로, 고유벡터 자체와의 내적만으로는 좌표를 구할 수 없습니다.”

이번 구간에서는 수학적으로 한눈에 차이가 드러나는 예시가 필요해.

\\[ p_1=\begin{pmatrix}1\\\0\end{pmatrix}, \qquad p_2=\begin{pmatrix}1\\\\-1\end{pmatrix} \\]

\\[ x=p_1+p_2=\begin{pmatrix}2\\\\-1\end{pmatrix} \\]

고유벡터와 직접 내적

\\[ p_1^Tx=2 \\]

\\[ p_2^Tx=3 \\]

실제 기저 좌표와 불일치

역행렬을 사용

\\[ P^{-1}x=\begin{pmatrix}1\\\1\end{pmatrix} \\]

실제 고유기저 좌표

애니메이션

- 42\~46초: \\(P^{-1}\\)의 두 행이 차례로 입력과 내적. 좌표 \\((1,1)\\) 등장.
- 46\~50초: 원래 고유벡터 \\(p_1,p_2\\)와 직접 내적하면 \\((2,3)\\)이 나오는 것을 보여준다.
- 50\~53초: 잘못된 방법에는 빨간 X, \\(P^{-1}x\\)에는 초록 체크.

핵심 연출: 단순히 `비직교 → 역행렬 필요`라고 텍스트만 보여주기보다, 실제 두 결과가 다르다는 것을 확인시키는 장면이 훨씬 설득력 있어.

## 3. SVD 파트 — 입력과 출력의 서로 다른 직교기저

이 구간은 영상의 중심이야. 단위원과 타원을 화면 양쪽에 유지하고, 입력 원의 한 점을 선택하면 출력 타원의 대응하는 점이 함께 움직이는 구조로 연출하자.

특히 특이벡터는 임의의 방향이 아니라, 입력과 출력에서 각각 직교하는 축으로 대응한다는 점을 분명하게 보여줘야 해.

### SCENE 08. SVD로 전환 — 단위원이 타원으로

00:58–01:06 · 58\~66초

내레이션

“그렇다면 SVD는 어떨까요? 단위원에 행렬 A를 적용하면, 일반적인 가역 이차원 변환에서는 타원이 만들어집니다.”

메인 화면

\\[ A=\begin{pmatrix}0&-1\\\3&0\end{pmatrix} \\]

애니메이션

- 58\~61초: 화면을 EVD의 파랑에서 SVD의 청록으로 전환한다.
- 61\~63초: 왼쪽에 단위원 등장. 원 위에 일정 간격으로 24\~48개 점 표시.
- 63\~66초: 모든 점에 \\(A\\)를 적용한다. 오른쪽에서는 세로로 긴 타원이 형성된다.

수학적 조건

선택한 행렬은

\\[ A(x,y)=(-y,3x) \\]

이므로 단위원의 출력은 세로 반축 3, 가로 반축 1인 타원이야.

이후 장면에서도 타원의 세로 반축이 항상 길어야 하고, 입력의 가로 방향이 출력의 세로 방향으로 대응해야 해.

### SCENE 09. 입력 방향에 따라 결과가 달라진다

01:06–01:10 · 66\~70초

내레이션

“원 위의 입력 방향에 따라 출력의 길이와 방향이 달라집니다.”

연출

좌우 화면을 유지하면서 점 하나를 이동시켜.

- 입력 벡터 \\(x(\theta)=(\cos\theta,\sin\theta)^T\\)가 단위원을 따라 회전.
- 출력 벡터 \\(Ax(\theta)=(-\sin\theta,3\cos\theta)^T\\)는 타원 위를 따라 움직인다.
- 두 벡터 끝점을 같은 색 점으로 표시하고 가느다란 연결선으로 대응 관계를 보여준다.
- 출력 벡터 옆에는 실시간 길이 \\(\\|Ax(\theta)\\|\\)를 표시.

\\[ \\|Ax(\theta)\\| =\sqrt{\sin^2\theta+9\cos^2\theta} \\]

각도에 따라 출력 길이가 1에서 3 사이로 변하는 모습을 보여줄 수 있어.

### SCENE 10. 타원의 가장 긴 축에 대응하는 입력 방향

01:10–01:17 · 70\~77초

내레이션

“SVD는 그중 타원의 가장 긴 축에 대응하는 입력 방향을 찾아냅니다. 이것이 첫 번째 오른쪽 특이벡터, V 원입니다.”

세부 애니메이션

- 70\~73초: 입력 단위벡터가 회전하다가 가로 오른쪽 방향에서 멈춘다. 출력 벡터는 타원의 가장 위쪽 끝에 도달한다.
- 73\~75초: 타원 세로 장축을 금색 점선으로 강조. `최대 출력 길이` 라벨.
- 75\~77초: 입력 수평 벡터만 파란색으로 강조하면서 \\(v_1\\) 라벨을 붙인다.

입력 특이벡터 \\(v_1\\)을 타원 위의 벡터로 그리지 말고, 입력 원 위의 수평 벡터로 표시해야 해.

### SCENE 11. 출력 특이벡터와 특이값

01:17–01:26 · 77\~86초

내레이션

“A를 적용한 결과의 단위방향은 왼쪽 특이벡터, U 원입니다. 입력 길이가 1이므로 출력 길이는 특이값, 시그마 원이 됩니다.”

\\[ v_1=\begin{pmatrix}1\\\0\end{pmatrix} \\]

\\[ Av_1=\begin{pmatrix}0\\\3\end{pmatrix} \\]

\\[ u_1=\begin{pmatrix}0\\\1\end{pmatrix},\qquad \sigma_1=3 \\]

애니메이션

- 77\~79초: 출력 벡터 \\(Av_1\\)를 타원 중앙에서 위로 길게 표시.
- 79\~82초: 그 벡터와 동일한 방향의 길이 1짜리 \\(u_1\\)를 겹쳐 표시. `단위 출력 방향`이라는 라벨.
- 82\~84초: 실제 출력 벡터 \\(Av_1\\)의 길이 3을 자로 측정하는 연출.
- 84\~86초: 단위 방향 \\(u_1\\)에 3을 곱하면 출력 \\(Av_1\\)이 됨을 보여준다.

핵심: \\(u_1\\)은 타원의 장축 자체가 아니라 그 방향을 나타내는 단위벡터야. 타원 반축 길이 3은 \\(\sigma_1u_1\\)에서 \\(\sigma_1\\)가 담당해.

### SCENE 12. 특이벡터 한 쌍의 대응식

01:26–01:29 · 86\~89초

화면 중앙에 다음 식을 크게 표시한다.

\\[ \boxed{Av_1=\sigma_1u_1} \\]

### SCENE 13. 임의의 단위벡터에서도 가능한 관계 아닌가?

01:29–01:34 · 89\~94초

내레이션

“그런데 임의의 단위벡터도 출력의 길이와 방향으로 표현할 수 있지 않을까요?”

연출

- 타원의 장축에 대응하던 \\(v_1\\) 강조를 해제.

## 4. SVD 분해식 — 내적으로 좌표를 추출한다

105초부터는 원과 타원 장면을 축소하고, 앞서 찾은 입력 특이벡터 두 개를 행렬의 열로 모으는 애니메이션으로 전환하자.

여기서 중요한 것은 \\(V^T\\)가 갑자기 등장하는 것이 아니라, 입력 특이벡터들을 행렬로 모은 뒤 전치하여 내적에 활용한다는 연결이야.

원과 타원 테두리는 서서히 사라지고, 벡터만 행렬의 열로 이동한다.

### SCENE 17. \\(V^T\\)의 각 행에는 입력 특이벡터가 있다

01:46–01:50 · 106\~110초

내레이션

“V 전치의 각 행에는 입력 특이벡터가 들어 있습니다.”

\\[ V= \begin{pmatrix} |&|\\\ v_1&v_2\\\ |&| \end{pmatrix} \\]

\\[ V^T= \begin{pmatrix} \text{---}\ v_1^T\ \text{---}\\\ \text{---}\ v_2^T\ \text{---} \end{pmatrix} \\]

애니메이션

- 106\~108초: 파란 \\(v_1\\), 청록 \\(v_2\\)가 \\(V\\)의 첫 번째·두 번째 열로 들어간다.
- 108\~110초: `Transpose` 연출로 각 열이 행으로 바뀌어 \\(V^T\\)를 만든다.

선택한 예시에서는 \\(V=I\\)라 전치해도 숫자가 바뀌지 않아. 따라서 숫자만 보여주면 전치의 의미가 잘 전달되지 않으니, 기호 \\(v_1,v_2\\)의 열·행 배치 변화를 먼저 보여주는 것이 좋아.

### SCENE 18. 행렬곱으로 각 입력 방향과 내적한다

01:50–01:55 · 110\~115초

\\[ V^Tx= \begin{pmatrix} v_1^T\\\ v_2^T \end{pmatrix}x = \begin{pmatrix} v_1^Tx\\\ v_2^Tx \end{pmatrix} \\]

\\[ x=\begin{pmatrix}2\\\1\end{pmatrix} \quad\Longrightarrow\quad V^Tx=\begin{pmatrix}2\\\1\end{pmatrix} \\]

애니메이션

- 110\~112초: 첫 행 \\(v_1^T\\)가 입력 \\(x\\)와 연결되며 내적값 2 생성.
- 112\~114초: 둘째 행 \\(v_2^T\\)가 입력 \\(x\\)와 연결되며 내적값 1 생성.
- 114\~115초: 값 2와 1이 세로로 쌓여 새로운 좌표 벡터가 된다.

여기서 출력은 아직 행렬 \\(A\\)의 최종 출력이 아니라, 입력 벡터를 \\(V\\) 기저에서 나타낸 좌표라는 라벨을 붙이자.

### SCENE 19. 왜 내적값이 곧 좌표 성분인가?

## 7. 영상 제작 시 우선순위

이번 영상은 아래 세 장면에 제작 역량을 집중하는 것을 추천해.

첫 번째는 23\~34초의 EVD 좌표 변환. 실제 벡터를 그대로 두고 기준 좌표계만 바꾸는 과정을 보여줘야 해. \\(P^{-1}\\), \\(D\\), \\(P\\)를 단순히 수식으로 나열하는 것보다 이해도가 높아질 거야.

두 번째는 70\~105초의 SVD 입력·출력 방향 대응. 단위원을 움직이는 입력 벡터와 타원 위의 출력 벡터를 연결하고, 특이방향 한 쌍만으로는 충분하지 않으며 두 직교방향이 함께 대응한다는 구조를 보여줘야 해.

세 번째는 106\~125초의 실제 계산. \\(V^Tx\\)의 내적, \\(\Sigma\\)의 배율, \\(U\\)의 출력 조합을 숫자 \\((2,1)\rightarrow(6,1)\rightarrow(-1,6)\\)로 보여주면 앞에서 설명한 추상적인 기저 개념이 구체적인 계산으로 연결돼.

최종적으로 시청자가 기억해야 할 장면은 두 개야.

\\[ \underbrace{A=PDP^{-1}}\_{\text{하나의 고유기저}} \qquad\text{vs}\qquad \underbrace{A=U\Sigma V^T}\_{\text{입력·출력의 두 직교기저}} \\]

EVD는 같은 고유기저에서 성분별 변환을 설명하고, SVD는 서로 다른 두 정규직교기저 사이에서 성분별 변환을 설명한다. 이 대비만 마지막 화면에 선명하게 남기면 이번 라운드의 목적을 충분히 달성할 수 있어.

# 05 — 활성화 복원만으로 성능 보존을 보장할 수 없다

## 목적·핵심 주장
활성화 복원만으로 성능 보존을 보장할 수 없다

## 앞 장면에서 받은 내용
IMPACT는 활성화의 구조를 관찰한다

## TTS·확정 길이
하지만 활성화값을 최대한 비슷하게 복원하는 것만으로도 충분하지 않았습니다.

모든 활성화 방향이 최종 예측에 똑같이 중요한 것은 아니기 때문입니다.

사용자 문장 종료 시각 기준 78–88초, 10초. 음원 미제공.

## 화면·시간별 애니메이션·텍스트
78–84초 활성화 점이 평면 근처에 모이는 3D 투영. 84–88초 복원에 중요한 방향을 질문. 평면 자체를 특정 LLM의 관측 결과로 표시하지 않는다. 영상 안내성 자막은 생략하고 이 문서에만 제작 방식을 기록한다.

## 시작·종료 상태·연결
씬 하나의 주장을 완결하고 동일 행렬·오차 방향을 다음 장면에서 이어받는다. 가로는 좌우, 세로는 상하 배치.

## 정확성·출처
ACL2026 IMPACT 최종본을 기준으로 한다. 단순행렬·활성화·민감도 계산은 제작용 수학적 예시이며 논문 실험의 수치 재현이 아니다. 결과의55.4%만 원문 보고 수치이다. 이 구분은 제작 문서에 기록하며 사용자의 이전 요청대로 영상 내부의 안내성 자막은 생략한다.

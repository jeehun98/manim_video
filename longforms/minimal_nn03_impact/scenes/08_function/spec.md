# 08 — 원본 복원과 기능 보존은 다른 목표다

## 목적·핵심 주장
원본 복원과 기능 보존은 다른 목표다

## 앞 장면에서 받은 내용
비교 방법 대비 최대 55.4% 더 큰 모델 크기 감소

## TTS·확정 길이
하지만 중요한 차이는 분명했습니다.

원래 행렬을 가장 정확하게 복원하는 것과, 신경망의 기능을 가장 잘 유지하는 것은 같은 문제가 아니었습니다.

신경망의 최소 표현을 찾기 위해 반드시 모든 정보를 보존할 필요는 없습니다.

중요한 것은 어떤 정보를 제거했을 때 실제 기능이 달라지는가입니다.

사용자 문장 종료 시각 기준 128–146초, 18초. 음원 미제공.

## 화면·시간별 애니메이션·텍스트
128–130초 기능 보존 강조. 130–137초 실제 행렬 차이 격자와 예측 보존 비교. 137–141초 기능 쪽 강조. 141–146초 어떤 정보를 제거하면 기능이 달라지는가 질문. 단순 복원과 기능 보존의 평가 대상을 구분한다.

## 시작·종료 상태·연결
씬 하나의 주장을 완결하고 동일 행렬·오차 방향을 다음 장면에서 이어받는다. 가로는 좌우, 세로는 상하 배치.

## 정확성·출처
ACL2026 IMPACT 최종본을 기준으로 한다. 단순행렬·활성화·민감도 계산은 제작용 수학적 예시이며 논문 실험의 수치 재현이 아니다. 결과의55.4%만 원문 보고 수치이다. 이 구분은 제작 문서에 기록하며 사용자의 이전 요청대로 영상 내부의 안내성 자막은 생략한다.

# 제작 기준 — 관측에서 특이방향을 발견한다

- 사용자 확정 원문과 29개 문장 종료 시각을 적용하며 총154초를 늘리지 않는다.
- 순서: 거리1 고정 → 출력 거리 측정 → 극값 발견 → 끝점 기록 → 타원 발견 → 대응 입력 역추적 → 특이벡터·특잇값 명명 → 임의 입력의 성분.
- 첫 실험에서 새 행렬로 바뀌는 시점은27초로 명시한다. 그 뒤 행렬은 고정한다.
- 타원은70초 전에는 표시하지 않는다. 66–70초에는 측정 방식이 바뀌고70–78초에 실제 궤적이 누적된다.
- 입력30°/출력60°, 입력120°/출력150°를 구분하며 출력 축을 입력에 그대로 복사하지 않는다.
- 단위벡터 uᵢ와 길이가 σᵢ인 실제 출력 σᵢuᵢ를 구분한다.
- 모든 좌표·길이·그래프·타원·투영은 README.md의 동일 행렬에서 계산한다.
- 영상에는 제공 내레이션 외의 복습·다음 영상 안내를 추가하지 않는다.
- 사용자 음원 미제공으로 무음 영상과 내레이션 자막을 만든다. SRT와 발음 원고는 별도 관리한다.
- 씬20개를 독립 교체할 수 있게 렌더한 뒤 같은 프레임 시계로 결합한다.

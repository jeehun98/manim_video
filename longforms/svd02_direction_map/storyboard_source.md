# SVD — 2편 상세 영상화 콘티

행렬이 가장 잘 구별하는 방향은 어디일까? | 154초 · 2분 34초

이번 편은 1편의 서로 다른 입력을 관찰자가 구별할 수 있는가라는 문제를 이어받아, 행렬의 방향별 반응을 직접 탐색하는 과정으로 구성합니다.

중요한 것은 타원을 처음부터 그리지 않는 것입니다. 입력 방향을 하나씩 바꾸며 출력의 거리를 측정하고, 최댓값과 최솟값을 발견한 다음, 출력 위치를 기록했더니 타원이 나타나는 순서가 좋습니다.

## 1. 전체 시각화 설계

2편에서는 1편의 입력·출력 좌표계 구성을 유지하되, 한 가지 실험을 추가합니다.

가로와 세로가 아닌 비스듬한 방향에서 최대·최소 반응이 나타나는 행렬입니다.

1편의 대각행렬만 계속 사용하면 가로와 세로가 특별한 방향이라는 인상이 남을 수 있기 때문입니다.

최종적으로 도달할 화면의 개념도. 처음부터 타원이 표시되는 것이 아니라, 시퀀스 C에서 궤적을 기록하면서 완성됩니다.

시각화의 고정 규칙은 다음과 같습니다.

- 입력의 원점 A는 고정하고 B만 반지름 1인 원을 따라 이동합니다.
- 입력 벡터는 파랑, 출력 벡터는 청록, 최대 반응은 금색, 최소 반응은 보라색으로 구분합니다.
- 타원의 장축과 단축은 출력 공간에, 오른쪽 특이벡터는 입력 공간에 표시합니다.
- 같은 행렬에 대해 각도, 출력 좌표, 출력 거리, 최대·최소 반응이 실제 계산과 일치하도록 합니다.
- 0\~66초에는 출력 끝점의 이동 궤적을 남기지 않고, 거리만 측정합니다. 66초 이후부터 궤적을 기록합니다.

## 2. 장면별 상세 콘티

## 시퀀스 A — 방향을 바꾸는 실험 (0\~35초)

1편의 결론을 가져와 입력 변화의 크기를 고정하는 실험 조건을 수립하는 구간

장면 01 | 0\~9초 — 같은 거리, 다른 출력

지난 편 마지막 화면의 가로·세로 비교를 짧게 재현합니다.

왼쪽 입력 공간에는 원점 A와 길이 1만큼 떨어진 B를 표시하고, B를 가로 방향에서 세로 방향으로 회전시킵니다.

오른쪽에서는 출력 거리가 `1 → 0.1`로 변화합니다. 1편에서 사용한 대각행렬임을 작은 라벨로 표시합니다.

마지막에 두 입력 벡터를 겹쳐 두 길이가 같다는 것을 다시 보여줍니다.

화면 문구: 같은 입력 거리 · 다른 출력 거리

장면 02 | 9\~12초 — 새로운 질문

양쪽 좌표계를 일시적으로 어둡게 처리합니다.

화면 중앙에 질문을 표시합니다.

## 가장 잘 구별되는 방향은 어디일까?

질문이 사라지면서 입력 좌표계의 원점만 남습니다.

장면 03 | 12\~21초 — 거리 1을 고정

점 A를 \\((0,0)\\)에 놓고, 점 B를 \\((1,0)\\)에 배치합니다.

B를 원점 중심으로 천천히 회전시키면서 B의 이동 가능한 위치를 점선 원으로 표시합니다.

점선 원의 반지름에는 `1`을 고정합니다.

원 전체는 입력의 이동 가능한 위치를 나타내며, 아직 출력 타원과 연결하지 않습니다.

화면 문구: \\(\\|\Delta x\\|=1\\)

주의: 이 원은 입력 점 B의 가능한 위치 집합이며, SVD 결과를 미리 보여주는 도형이 아닙니다.

장면 04 | 21\~27초 — 오직 방향만 바뀐다

입력 벡터를 약 45도까지 회전시킵니다.

원점에서 B까지의 거리는 변하지 않으며, 각도 \\(\theta\\)만 업데이트됩니다.

화면 한쪽에 두 계측값을 배치합니다.

입력 거리

1.000 · 고정

입력 방향

θ · 변화

장면 05 | 27\~35초 — 첫 출력과 회전 시작

가로 방향으로 B를 복귀시킵니다.

새로운 행렬 \\(A\\)가 화면 중앙에 등장하며, 가로와 세로축에 정렬되지 않은 출력 벡터가 나타납니다.

B가 조금씩 회전하자 출력 벡터도 움직이고 길이가 변화합니다.

중요: 여기서 사용하는 두 번째 행렬은 뒤에서 타원의 장축이 기울어지도록 만드는 행렬입니다. 시청자에게는 복잡한 원소 대신 `새로운 행렬 A`로만 표시해도 됩니다.

## 시퀀스 B — 최대 반응과 최소 반응 발견 (35\~66초)

목표: 입력 방향에 따른 출력 길이를 조사하고, 극값을 먼저 발견한다.

여기서는 위치 궤적을 그리기 전에 방향별 반응의 크기를 계측하는 것이 핵심입니다.

장면 06 | 35\~45초 — 출력 거리의 변화

입력 벡터가 일정한 각속도로 한 바퀴 회전합니다.

오른쪽 출력 벡터는 회전에 따라 길이가 늘었다 줄어듭니다.

화면 하단에는 각도에 따른 출력 거리를 표시하는 그래프가 생성됩니다.

방향 탐색 시뮬레이션

0°

최대 방향최소 방향

제작용 예시. 입력 방향 30°와 120°에서 각각 최대·최소 반응이 나타나도록 설정한 선형변환입니다.

장면 07 | 45\~49초 — 최댓값과 최솟값 찾기

출력 거리 그래프 위에서 가장 높은 지점과 가장 낮은 지점에 마커를 표시합니다.

입력 방향이 각각의 지점으로 이동할 때, 오른쪽 출력 벡터의 길이가 달라집니다.

같은 크기의 입력을 넣었으므로 거리 비교가 정당하다는 사실을 `입력 길이 = 1`로 다시 강조합니다.

장면 08 | 49\~57초 — 극값 방향 발견

입력 좌표계에 최대 반응 방향과 최소 반응 방향을 동시에 표시합니다.

최대 반응 방향은 금색, 최소 반응 방향은 보라색으로 구별합니다.

입력의 두 방향 사이에 직각 표시를 추가합니다.

출력 공간에는 길이가 다른 두 벡터가 함께 표시됩니다.

최대 출력 거리

2.0

최소 출력 거리

0.5

장면 09 | 57\~66초 — 거리만 측정했다는 사실

출력 공간의 벡터들은 잠시 사라지고, 각도별 길이를 기록한 그래프만 남습니다.

그 뒤 그래프가 위로 축소되면서 두 좌표계가 다시 나타납니다.

화면 중앙에 다음 질문을 표시합니다.

> 길이만이 아니라, 출력의 위치까지 기록한다면?

이제 영상의 시각적 중심이 길이 그래프에서 출력 좌표평면으로 이동합니다.

## 시퀀스 C — 출력의 궤적을 기록하다 (66\~93초)

목표: 타원이라는 도형을 알려주는 대신, 측정 결과로부터 타원이 자연스럽게 나타나게 한다.

### 장면 10 | 66\~70초 — 측정 방식을 바꾼다

내레이션: “이번에는 거리뿐 아니라 출력이 어디에 놓이는지도 기록해 보겠습니다.”

기존의 출력 거리 그래프가 작아져 화면 상단으로 이동합니다.

출력 좌표평면을 확대하고, 현재 출력 벡터의 끝점에 작은 발광 마커를 추가합니다.

화면에 `출력 거리 측정`이라는 문구가 `출력 위치 기록`으로 바뀝니다.

중요한 연출은 새로운 실험을 시작하는 것이 아니라 이전과 동일한 실험에서 기록하는 정보만 바꾼다는 것입니다.

### 장면 11 | 70\~78초 — 궤적이 타원으로 나타난다

내레이션: “입력 방향을 한 바퀴 회전시키면서 출력 벡터의 끝점을 계속 남깁니다. 그러면 놀랍게도, 이 점들은 하나의 타원 궤적을 만듭니다.”

탐색 각도

270° / 360°

궤적 완성초기화

콘티 동작 예시. 입력 방향을 회전시키면 출력 벡터의 끝점이 누적되고, 한 바퀴를 완료하면 타원이 나타납니다.

실제 영상에서는 0\~180도 회전까지는 경로를 상대적으로 천천히 그리고, 180\~360도 구간에서는 속도를 높여 타원을 완성하는 방식이 좋겠습니다.

### 장면 12 | 78\~86초 — 타원은 발견된 결과다

내레이션: “우리가 처음부터 타원을 그리려고 했던 것은 아닙니다. 같은 크기의 입력 변화를 모든 방향에서 시험했더니 타원이 나타난 것입니다.”

출력의 타원 궤적이 완성되면 입력 쪽의 점선 원과 나란히 보여줍니다.

입력의 원에는 `같은 크기의 모든 변화`, 출력의 타원에는 `그 변화에 대한 모든 반응`이라는 문구를 표시합니다.

여기서 타원을 회전시키거나 임의로 찌그러뜨리는 연출을 사용하지 않는 것이 중요합니다. 모양은 처음 설정한 행렬에 의해 결정되고, 그 자체가 측정 결과입니다.

### 장면 13 | 86\~93초 — 장축과 단축

내레이션: “이 타원의 긴 축은 출력의 차이가 가장 크게 나타나는 방향을, 짧은 축은 가장 작게 나타나는 방향을 보여줍니다.”

타원의 장축과 단축은 출력 벡터가 가질 수 있는 최대·최소 길이를 나타냅니다. 두 축은 출력 공간에서 정의됩니다.

이 장면에서는 두 축을 한꺼번에 등장시키기보다 장축을 먼저 강조하고, 이어서 단축을 표시합니다. 최대·최소 반응에 대응하는 출력 벡터를 각각 한 번씩 재생하면 좋습니다.

## 시퀀스 D — 입력 방향과 출력 방향은 다르다 (93\~129초)

목표: 타원을 발견한 뒤에도 아직 해결되지 않은 문제를 보여주고, 그 문제에서 특이벡터와 특잇값을 도입한다.

### 장면 14 | 93\~102초 — 타원의 축은 입력의 축이 아니다

내레이션: “하지만 한 가지 주의할 점이 있습니다. 타원의 축은 출력 공간의 방향입니다. 우리가 처음 찾으려던 것은 그 축을 만들어내는 입력 공간의 방향입니다.”

화면을 두 좌표평면으로 다시 분할합니다.

출력 공간의 장축을 강조한 뒤, 같은 각도의 선을 입력 공간에 그대로 복사하는 연출은 피합니다.

대신 출력 장축 위의 끝점 하나를 선택하고, 그 출력 끝점을 실제로 만들어냈던 입력 벡터를 추적해 보여줍니다.

화면 중앙에는 다음 대응 관계만 남깁니다.

입력에서의 방향 → 출력에서의 방향

### 장면 15 | 102\~108초 — 원인을 역추적한다

내레이션: “따라서 가장 긴 출력 벡터가 나타났을 때, 그 벡터를 만들어낸 입력 방향도 함께 기록해야 합니다.”

입력 원 위에서 가장 큰 출력을 만들었던 점 B를 다시 강조합니다.

해당 입력 벡터와 출력의 장축 벡터를 같은 금색으로 연결합니다.

최소 반응도 보라색으로 짧게 확인합니다.

이번 예시에서는 입력과 출력의 주요 축 방향을 일부러 다르게 설정할 수 있습니다. 이렇게 하면 시청자가 두 종류의 특이벡터를 구별하는 데 도움이 됩니다.

### 장면 16 | 108\~120초 — 특이벡터와 특잇값의 등장

내레이션: “이렇게 찾은 특별한 입력 방향이 오른쪽 특이벡터, 그에 대응하는 출력 방향이 왼쪽 특이벡터입니다. 그리고 길이가 1인 입력 변화가 출력에서 얼마나 커졌는지를 나타내는 값이 특잇값입니다.”

# \\(v_i\\)

오른쪽 특이벡터

입력 방향

# \\(\sigma_i\\)

특잇값

변화의 배율

# \\(u_i\\)

왼쪽 특이벡터

출력 방향

\\[ Av_i=\sigma_i u_i \\]

입력 벡터의 길이를 1로 정규화했을 때의 관계입니다. 이번 예시에서는 특잇값이 양수이므로 출력 방향이 명확하게 정의됩니다.

화면에는 세 기호를 한꺼번에 띄우지 않고, \\(v_i\\), \\(\sigma_i\\), \\(u_i\\) 순서로 등장시킵니다.

### 장면 17 | 120\~129초 — 하나의 관계로 정리

내레이션: “입력 방향을 브이, 출력 방향을 유, 특잇값을 시그마라고 하면, 행렬은 브이를 시그마 배의 유로 보냅니다. 이것이 에이 브이는 시그마 유라는 관계입니다.”

오른쪽 특이벡터에 대응하는 길이 1의 화살표가 행렬 상자를 통과하고, 출력 방향 \\(u_i\\)를 향해 길이 \\(\sigma_i\\)의 화살표로 변환됩니다.

이 과정을 최대 반응 방향과 최소 반응 방향에서 각각 보여줍니다.

하나의 행렬에서 서로 다른 두 방향·두 배율을 발견했다는 사실을 시각적으로 확인하는 장면입니다.

## 시퀀스 E — 다음 질문으로 확장 (129\~154초)

목표: 특이벡터 발견을 끝으로 만들지 않고, 임의의 입력을 처리하는 문제로 확장한다.

### 장면 18 | 129\~140초 — 우리가 실제로 발견한 것은?

내레이션: “여기서 중요한 것은 타원이라는 모양 자체가 아닙니다. 우리는 행렬에 같은 크기의 변화를 여러 방향으로 넣었고, 그 결과를 비교해 가장 강한 반응과 가장 약한 반응을 찾아냈습니다.”

완성된 타원 위의 궤적을 잠시 흐리게 처리합니다.

대신 입력 공간에서 선택한 두 특별한 방향과 그에 대응하는 출력 벡터만 남깁니다.

타원은 결과를 요약한 지도이고, 우리가 실제로 찾은 것은 특정 입력 방향과 그 방향에 대한 행렬의 반응이라는 점을 강조합니다.

### 장면 19 | 140\~149초 — 특별한 방향에 놓이지 않은 입력

내레이션: “그런데 실제 입력이 이 특별한 방향들 중 하나에 정확히 놓이지 않는다면 어떨까요? 임의의 입력은 여러 방향의 성분을 동시에 가지고 있습니다.”

입력 공간에 임의의 벡터 \\(x\\)를 표시합니다.

두 특이벡터 방향이 기준축처럼 나타나지만, 입력 \\(x\\)는 어느 한 축 위에도 놓이지 않습니다.

벡터 \\(x\\)에서 두 축을 향해 점선 투영선을 내려 각각의 성분을 표시합니다.

여기서는 각 성분의 값이나 내적 공식까지 설명하지 않습니다.

### 장면 20 | 149\~154초 — 다음 편으로 이어지는 마지막 장면

내레이션: “그렇다면 행렬은 그 성분들을 어떻게 읽고, 하나의 출력으로 만들어낼까요?”

입력 벡터가 두 방향의 성분으로 분해된 상태에서 정지합니다.

그 다음 각 성분이 행렬 상자 쪽으로 이동하려는 순간 화면을 마무리합니다.

마지막 화면 문구:

“하나의 입력을 여러 방향으로 나눠 읽을 수 있을까?”

다음 편에서는 바로 이 프레임을 이어받아 \\(V^T\\)가 방향별 성분을 읽고, \\(\Sigma\\)가 배율을 적용하며, \\(U\\)가 출력 방향으로 조립하는 과정으로 진행하면 됩니다.

## 3. 좌표 및 계산 기준 — 실제 제작용

이 편에서는 입력과 출력의 축이 우연히 같아 보이지 않도록 다음 행렬을 추천합니다.

\\[ A= R(30^\circ) \begin{bmatrix} 2&0\\\ 0&0.5 \end{bmatrix} R(-30^\circ) \\]

즉, 약

\\[ A\approx \begin{bmatrix} 1.625&0.6495\\\ 0.6495&0.875 \end{bmatrix} \\]

입니다.

이 행렬은 타원이 30도 기울어지며, 최대·최소 특잇값은 각각 2와 0.5입니다. 다만 이 행렬에서는 오른쪽 특이벡터와 왼쪽 특이벡터가 같은 방향입니다.

입력·출력 방향의 차이를 더 명확히 보여주려면, 실제 제작용으로는 다음 행렬이 더 좋습니다.

\\[ \boxed{ A= R(60^\circ) \begin{bmatrix} 2&0\\\ 0&0.5 \end{bmatrix} R(-30^\circ) } \\]

이 경우:

| 요소                    | 값    |
| --------------------- | ---- |
| 최대 반응 입력 방향 \\(v_1\\) | 30°  |
| 최소 반응 입력 방향 \\(v_2\\) | 120° |
| 최대 반응 출력 방향 \\(u_1\\) | 60°  |
| 최소 반응 출력 방향 \\(u_2\\) | 150° |
| 최대 특잇값 \\(\sigma_1\\) | 2    |
| 최소 특잇값 \\(\sigma_2\\) | 0.5  |

최종 영상에는 두 번째 행렬을 사용하는 것을 추천합니다. 위의 시뮬레이션 예시도 이 목적에 맞게 구현한다면, 출력 방향을 입력 방향과 분명히 다르게 보여줄 수 있습니다.

이때 제작상의 가장 중요한 규칙은 한 번 정한 행렬을 2편 내에서 바꾸지 않는 것입니다. 1편 복습에서 새로운 행렬로 넘어가는 지점만 명확히 표시하고, 이후 측정 그래프와 타원, 특이벡터와 특잇값은 모두 동일한 행렬에서 계산해야 합니다.

이 장면이 있어야 일반적인 SVD 시각화와 다른 탐구 중심의 이야기가 됩니다.

# SVD 2막 — 행렬이 가장 잘 구별하는 방향은 어디일까?

- 기준: 사용자 제공 상세 콘티와 내레이션, 29개 문장 종료 시각.
- 길이: 154초. 독립 씬 20개를 결합한다.
- 최종: 1920×1080, 30fps. 미리보기: 854×480, 15fps.
- 음원 미제공: 무음 영상에 내레이션 자막을 포함하며 SRT 별도 제공.
- [내레이션](narration.md), [발음 원고](tts_script.txt), [문장 시각](timing.json), [콘티 원문](storyboard_source.md), [씬 인덱스](manifest.json).

## 수학적 계약

0–27초에는 기존 기준 실험 diag(1,0.1)을 사용한다. 27초에 '새 행렬 A'임을 표시하고 아래 행렬로 전환한 뒤 끝까지 유지한다.

A = R(60°) diag(2, 0.5) R(−30°)

A ≈ [[1.0825317547, 0.125], [1.375, 1.0825317547]]

| 항목 | 최대 반응 | 최소 반응 |
|---|---|---|
| 입력 단위 방향 | v₁, 30° | v₂, 120° |
| 출력 단위 방향 | u₁, 60° | u₂, 150° |
| 출력 길이 / 특잇값 | σ₁ = 2 | σ₂ = 0.5 |
| 대응 관계 | Av₁ = 2u₁ | Av₂ = 0.5u₂ |

원점 A는 고정하고 입력 B=(cosθ,sinθ)를 회전시킨다. 두 입력 사이의 거리는 항상1이다. 출력은 매 프레임 실제 행렬곱으로 계산한다. 입력과 출력 좌표계의 단위 및 카메라 배율은 동일하게 고정한다.

35–66초에는 방향별 출력 거리 그래프를 보여주며 출력 위치 궤적을 남기지 않는다. 66초에는 측정 방식 변경을 안내하고, 70–78초에 출력 끝점을 기록한다. 0–180°는 5초, 180–360°는 3초에 기록한다. 타원은 사전에 임의 변형한 도형이 아니라 실제 Ax의 궤적이다. 동적으로 보여주는 거리·각도 숫자는 반올림 근삿값(≈)이며, 측정 화면은 5Hz로 갱신하고 벡터는 영상 프레임마다 갱신한다.

108초 이후 vᵢ와 uᵢ는 단위벡터임을 명시한다. 길이 σᵢ인 실제 출력 화살표와 출력 단위 방향을 혼동하지 않도록 단위 위치 표시와 정의를 구분한다. 최대·최소 방향은 양·음 양쪽에 존재하며, 화면에는 대표 방향 한 쌍을 표시한다. 마지막에는 입력75°의 벡터를 두 오른쪽 특이벡터 방향에 투영한다. 내적 수치와 조립 공식은 아직 설명하지 않는다.

이번 사용자 원문에 포함된 이전 실험 언급과 마지막 질문을 그대로 반영한다. 별도의 복습·후속 예고 문구를 추가하지 않는다.

## 실행 및 교체

프로젝트 루트에서:

```powershell
python longforms/svd02_direction_map/build.py --preview
python longforms/svd02_direction_map/build.py
python longforms/svd02_direction_map/build.py --scene 16
python longforms/svd02_direction_map/build.py --concat-only
```

Manim 0.21.0, FFmpeg 9.0.1, PyAV, Malgun Gothic 사용. 기본 동시 렌더3개, `--jobs 1`로 순차 실행할 수 있다. 각 씬은 절대시간 상태를 독립 재현한다. 개별 씬의 프레임 수를 맞춘 뒤 하나의 프레임 시계로 결합하며 사후 속도 변경은 하지 않는다.

출력: exports/svd02_direction_map_154s_1080p30.mp4 및 .srt.

씬 여러 개를 교체하고 즉시 결합하려면 `--scenes 8 9 13`처럼 지정한다. 모든 원본 씬이 이미 존재하는 경우에 사용한다. 최종 렌더에서 동일한 미리보기를 다시 만들려면 `python longforms/svd02_direction_map/sync_preview.py`를 실행한다.

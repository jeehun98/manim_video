# 16 — 특이벡터와 특잇값

## 목적과 핵심 주장
입력과 출력의 단위 방향 및 배율을 구별한다

## 앞 장면에서 받은 내용
출력 60°에 대응하는 입력은 30°이다

## TTS 원문과 확정 길이
이렇게 찾은 특별한 입력 방향이 오른쪽 특이벡터, 그에 대응하는 출력 방향이 왼쪽 특이벡터입니다.

그리고 길이가 1인 입력 변화가 출력에서 얼마나 커졌는지를 나타내는 값이 특잇값입니다.

사용자 제공 108–120초, 12초.

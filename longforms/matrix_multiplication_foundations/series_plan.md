# 행렬곱의 계산량은 어디까지 줄일 수 있을까?

## 현재 구성 — 2026-10-11 새 3막 반영

사용자의 새 3막을 기준으로, 2막에서 곧바로 계산 구조와 텐서 랭크로 넘어간다. 기존 Laderman 중심 3막은 현재 본편에서 제외한다. 이전 계획은 series_plan_before_tensor_revision.md, 최초 사용자 원문은 source_document.md에 보존한다.

1. **표준 계산과 Strassen** — 같은 입력에서 8곱과 7곱의 출력이 같음을 확인한다.
2. **성장률과 두 경계** — 말단 곱셈 수, 전체 산술 연산량, 상한·하한과 ω를 구분한다.
3. **계산을 텐서로 표현한다** — 입력 두 선형 조합과 출력 분배 규칙을 세 계수 벡터로 표현한다. 표준 8항과 Strassen 7항의 계수 합이 같음을 확인한 뒤 랭크를 정의한다. 7항 분해의 상한과 별도의 하한 정리를 구분한다.
4. **정확한 분해와 극한 분해** — 낮은 랭크 집합과 폐포의 개념도로 보더 랭크를 도입한다. 미포함 목표에 접근하는 경로로 정확한 최소 개수와 극한의 최소 개수를 구분하고, 정확한 계산과 연결할 때 복원 비용이 필요함을 설명한다.
5. **한 텐서 안의 독립적인 행렬곱** — 세 변수 그룹의 독립 직합을 실제 작은 예제로 확인한다. 점근적 합 부등식이 묶음 비용을 지수 상한으로 연결하는 역할을 설명한다.
6. **텐서 거듭제곱과 구조 증폭** — 번호 쌍을 따라 결합하면서 문제 수와 크기의 증가를 확인한다. 거듭제곱만으로 독립 직합이 자동 확보되지는 않음을 보여준다.
7. **레이저 방법의 목적** — 낮은 분해 비용을 가진 거대한 구조에서 독립 행렬곱들을 추출해 성장 지수 상한으로 연결한다.
8. **AI와 더 좋은 행렬곱 지수 상한** — 조합 손실 분석의 최적화 문제 재구성, 경사 기반 최적화, AlphaEvolve의 프로그램 개선과 엄밀 검증으로 기존 증명 체계 안에서 더 좋은 상한을 찾는 과정을 설명한다.
9. **왜 수백만 개 변수를 조절하는가?** — 다음 편 예정. Combination Loss Analysis의 선택 변수와 규모를 더 깊이 다룬다.

## 장면 원칙

주장 하나마다 독립 씬을 만든다. 숫자 이동과 계수 변화로 먼저 확인하고 용어를 도입한다. 특정 숫자 검산과 모든 입력의 항등식 검증은 다르다. 텐서는 특정 숫자 답이 아닌 계수 구조다. 출력 분배 벡터는 세 번째 입력이 아니다.

3막에서는 2×2 복소수 행렬곱의 랭크가 7이라는 알려진 결과를 사용하되 하한 정리를 직접 증명했다고 표현하지 않는다. 마지막 극한 그림은 일반 텐서 공간의 개념도이며 2×2의 랭크나 보더 랭크가 7 미만이라는 주장이 아니다.

전체 대본 → 씬 명세 → TTS 실측 → 화면 → 음성 결합의 제작 순서를 따른다. 음성이 미제공인 영상은 임시 길이의 무음 콘티로 명시한다. 제공된 문장별 시간은 추정값 대신 우선 적용한다.

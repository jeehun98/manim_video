# 7막 — 레이저 방법

목적 중심 개정: 이미 낮은 분해 비용을 가진 구조에서 독립적인 행렬곱들을 추출하고, 그 개수·크기·비용 상한을 통해 더 좋은 성장 지수 상한을 증명한다.

6개 독립 씬, 1920×1080 30fps. 새 TTS 실측 전이며 기존 170초는 화면 배치용 임시 타이밍이다. exports의 170초 영상은 목적 중심 개정 화면으로 렌더했다. 새 대본의 발화 시각을 받은 뒤 화면 타이밍·SRT를 갱신한다. 현재 무음 영상은 발화 길이에 동기화된 결과가 아니다.

- tts_script.txt: 화면 전환·강조 단위 빈 줄, 읽을 문장만 수록. 각 구간 아래 실제 누적 발화 종료 시각을 기록한다.
- master_script.md 및 씬별 script.txt/spec.md: 같은 개정 대본과 목적을 반영.
- captions.srt: 임시 씬 제목 카드이며 문장별 실측 자막이 아니다.
- revisions/v1_procedure_170s/: 기존 절차 중심 소스 보존.

두 번째 작은 예제를 제거했다. 작은 세 항 모형은 변수 제거의 원리만 보여주며, 실제 잔여 블록이 행렬곱인지 별도로 확인한다. 보더 랭크 상한은 실제 실행 시간과 구분한다. 일부를 버린다는 사실만으로 상한이 개선되는 것은 아니며, 추출한 행렬곱의 규모와 비용 상한의 비교가 필요하다.

실측 반영 후 실행:
python longforms/mm07_laser_method/build.py --preview
python longforms/mm07_laser_method/build.py

개정 화면 렌더 확인: exports/mm07_laser_method_170s_1080p30.mp4 · 1920×1080 · 30fps · 5,100프레임 · 170초 · 오디오 없음. 도입, 예제 대체 장면, 결론의 주요 프레임을 확인했다.

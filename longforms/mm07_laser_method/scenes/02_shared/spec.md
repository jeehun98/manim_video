# 같은 변수를 공유한다면

目的: 같은 변수를 공유한다면

핵심 주장: 같은 변수를 공유한다면

앞 장면: 얽힌 계산에서 독립적인 계산으로

TTS: 먼저 세 항으로 된 작은 예제를 보겠습니다. 첫째 항과 둘째 항은 엑스 일을 공유합니다. 두 계산에 들어가는 이 값을 서로 다르게 선택할 수 없습니다. 반면 첫째 항과 셋째 항은 엑스, 와이, 제트가 모두 다릅니다. 여기서 제트는 세 번째 입력이 아니라 출력 위치를 표시하는 형식적인 변수입니다. 이 예제는 행렬곱이 아니라 독립성을 관찰하는 작은 모형입니다.

확정 음성 길이: 미정. 임시 화면 길이 28초. 실제 음성 없음.

화면: 세 항의 X/Y/Z 연결. X1 공유 강조

시작/종료: 연결 구조에서 다음 주장의 카드로 전환.
다음 장면: 항 대신 변수를 제거한다

조건: 복소수 위. 예시 항은 행렬곱이 아닌 스칼라 모형. Z는 출력 좌표. 항의 임의 삭제 금지. 일반 텐서에서 성공 보장 없음.

## 화면 타임라인
0–6초: 전체 지지 구조. 6–13초: 공유 X. 13–18초: 독립한 첫째/셋째. 18–28초: 해석.
화면 텍스트는 visuals.py의 해당 part를 기준으로 한다. 실제 TTS가 도착하면 재조정.

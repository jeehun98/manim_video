# 많은 조합이 곧 독립적인 계산은 아니다

## 목적과 주장
기존 세 항 모형 하나만 사용. x1 공유와 첫째·셋째의 분리를 대비한다.

## 앞 장면
낮은 비용의 구조에서 무엇을 꺼낼까?

## TTS
먼저 세 항으로 된 작은 텐서를 보겠습니다.

첫째 항과 둘째 항은 엑스 일을 공유합니다.

두 항은 같은 변수를 사용하기 때문에, 이 상태 그대로는 서로 독립적인 계산으로 분리되지 않습니다.

반면 첫째 항과 셋째 항은 엑스, 와이, 제트의 어떤 변수도 공유하지 않습니다.

사용자 제공 발화 길이: 16초. 전체 누적 23–39초. 음성 파일은 미제공.

## 화면과 전환
기존 세 항 모형 하나만 사용. x1 공유와 첫째·셋째의 분리를 대비한다.

narration_timing.json의 사용자 제공 종료 시각을 적용한다.

## 시작·종료와 다음 연결
시작: 낮은 비용의 구조에서 무엇을 꺼낼까?
종료: 많은 조합이 곧 독립적인 계산은 아니다
다음: 일부를 버려 독립성을 얻는다

## 수학적 조건
복소수 위. 작은 세 항 예제는 행렬곱 알고리즘이 아닌 독립성 모형이며 Z는 출력 좌표다. 변수 제거는 관련 항 전체를 제거한다. 실제 잔여 구조가 정확한 행렬곱 직합인지 별도 확인한다. 보더 랭크는 극한 분해의 대수적 비용 지표이며 실행 시간이 아니다. q>=1, n>=2인 같은 크기의 정사각 행렬곱을 표시한다. 좋은 추출이나 상한 개선을 일반 텐서에서 보장하지 않는다.

## 적용한 발화 구간
- 23–25초: 먼저 세 항으로 된 작은 텐서를 보겠습니다.
- 25–28초: 첫째 항과 둘째 항은 x₁을 공유합니다.
- 28–34초: 두 항은 같은 변수를 사용하기 때문에, 이 상태 그대로는 서로 독립적인 계산으로 분리되지 않습니다.
- 34–39초: 반면 첫째 항과 셋째 항은 X, Y, Z의 어떤 변수도 공유하지 않습니다.

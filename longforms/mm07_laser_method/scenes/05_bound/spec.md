# 추출한 구조에 비용 상한을 넘긴다

目的: 추출한 구조에 비용 상한을 넘긴다

핵심 주장: 추출한 구조에 비용 상한을 넘긴다

앞 장면: 무엇을 남길지 선택한다

TTS: 이제 실제 행렬곱 구조로 돌아오겠습니다. 원래 텐서의 보더 랭크가 알 이하라면, 케이 번 결합한 구조의 보더 랭크는 알의 케이제곱 이하입니다. 변수를 영으로 만드는 제한은 이 상한을 늘리지 않습니다. 그 결과 엔 대 엔 행렬곱 큐 개의 독립 직합을 얻었다면, 이 직합에도 같은 상한을 사용할 수 있습니다. 독립성뿐 아니라 남은 각 블록이 정말 행렬곱인지도 확인해야 합니다.

확정 음성 길이: 미정. 임시 화면 길이 32초. 실제 음성 없음.

화면: 텐서 거듭제곱→변수 제한→행렬곱 직합

시작/종료: 연결 구조에서 다음 주장의 카드로 전환.
다음 장면: 개수 · 크기 · 비용을 함께 비교한다

조건: 복소수 위. 예시 항은 행렬곱이 아닌 스칼라 모형. Z는 출력 좌표. 항의 임의 삭제 금지. 일반 텐서에서 성공 보장 없음.

## 화면 타임라인
0–6초: 원래 비용. 6–13초: 거듭제곱 상한. 13–19초: 제한의 단조성. 19–32초: 행렬곱 직합 상한.
화면 텍스트는 visuals.py의 해당 part를 기준으로 한다. 실제 TTS가 도착하면 재조정.

# 내적 LEVEL 08 — SVD

사용자 확정 원고33문장, 제공 종료시각 기준147초.

하나의 행렬은 모든 방향의 벡터를 똑같이 변환할까요?
이번에는 내적을 이용해 행렬이 각 방향에 어떻게 작용하는지 살펴보겠습니다.
행렬은 입력 벡터의 크기뿐 아니라 방향도 바꿀 수 있습니다.
그런데 복잡한 변환도 특별한 입력 방향들을 기준으로 나누면 단순하게 표현할 수 있습니다.

이것이 특이값 분해, 영어로 SVD의 핵심 원리입니다.
SVD는 행렬 A를 세 행렬, U와 시그마, V의 전치행렬의 곱으로 분해합니다.
그렇다면 이 세 행렬은 각각 무엇을 의미할까요?

하나의 예제를 살펴보겠습니다.
첫 번째 행에는 0과 음수 1, 두 번째 행에는 3과 0이 있는 행렬입니다.
이 행렬에 가로 방향의 단위벡터를 입력하면 세로 방향으로 길이가 3인 벡터가 나옵니다.
반대로 세로 방향의 단위벡터를 입력하면 왼쪽으로 길이가 1인 벡터가 나옵니다.
즉, 입력 방향에 따라 확대되는 크기와 출력 방향이 달라집니다.

이번 행렬에서는 가로와 세로 방향이 바로 특별한 입력 방향입니다.
이 두 방향을 열벡터로 가진 행렬이 V입니다.

먼저 입력 벡터를 가로로 2, 세로로 1이라고 하겠습니다.
V의 각 열벡터와 입력 벡터를 내적하면 첫 번째 방향의 성분은 2, 두 번째 방향의 성분은 1입니다.
이렇게 입력 벡터의 방향별 성분을 측정하는 것이 V의 전치행렬이 하는 일입니다.

이제 시그마 행렬을 살펴보겠습니다.
시그마는 특이값을 대각성분으로 가진 행렬입니다.
이번 예제에서는 첫 번째 방향의 특이값이 3, 두 번째 방향의 특이값이 1입니다.
따라서 앞에서 측정한 성분 2와 1에 각각 곱하면 6과 1이 됩니다.

마지막으로 U 행렬이 등장합니다.
U의 열벡터들은 각 성분이 향할 출력 방향을 나타냅니다.
첫 번째 출력 방향은 위쪽이고, 두 번째 출력 방향은 왼쪽입니다.
따라서 첫 번째 성분 6을 위쪽 방향으로, 두 번째 성분 1을 왼쪽 방향으로 배치합니다.
이 두 벡터를 더하면 음수 1과 6인 벡터가 됩니다.

실제로 원래 행렬 A에 입력 벡터 2와 1을 직접 곱해도 같은 결과가 나옵니다.
즉, 행렬의 변환을 방향별 성분의 측정, 크기 조절, 출력 방향의 결합으로 나누어 계산한 것입니다.

이 구조는 다른 행렬에도 적용할 수 있습니다.
입력 벡터를 각 입력 특이벡터와 내적하고, 해당 특이값을 곱한 다음, 출력 특이벡터 방향으로 합하면 됩니다.

앞서 PCA에서는 데이터가 가장 크게 퍼지는 방향을 찾았습니다.
반면 SVD에서는 행렬 자체가 입력 방향에 따라 얼마나 확대하고, 어떤 출력 방향으로 보내는지 분해합니다.

결국 내적으로 방향의 성분을 측정하는 원리가, 행렬 전체의 변환을 방향별로 이해하는 방법으로 확장된 것입니다.

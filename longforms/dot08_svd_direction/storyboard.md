# 내적 LEVEL 08 — 상세 영상화 콘티

총 147초 · 9:16 세로 영상 · 특이값 분해(Singular Value Decomposition, SVD) · 입력 방향 측정 → 특이값 적용 → 출력 방향 재구성

이번 영상에서는 SVD를 단순히 세 행렬의 곱으로 설명하지 않고, 입력 벡터 하나가 행렬을 통과해 출력 벡터로 바뀌는 과정을 내적을 중심으로 분해하는 것이 목표야.

기존 LEVEL 01\~07에서 다룬 방향 측정, 직교기저, 벡터 재구성의 원리가 모두 등장하지만, 이번에는 입력 방향과 출력 방향이 서로 다를 수 있다는 것이 중요한 차이야.

# 3. 구간별 상세 콘티

## Scene 01. 행렬은 모든 방향을 똑같이 변환할까? (0\~17초)

0\~3초 — 도입 질문

검은색 또는 짙은 남색 배경에 2차원 좌표평면이 나타난다. 원점에서 서로 다른 방향으로 뻗어 있는 여러 벡터를 보여준다.

상단에는 다음 질문을 표시한다.

"행렬은 모든 방향을 똑같이 변환할까?"

3\~8초 — 방향에 따른 반응

벡터들이 동일한 행렬 \\(A\\)를 통과하면서 서로 다른 방향과 길이로 변하는 모습을 보여준다.

여기서는 정확한 숫자보다 각 입력이 서로 다른 결과를 만든다는 사실을 전달하자.

8\~12초 — 행렬의 작용

모든 벡터를 잠시 숨기고 임의의 입력 벡터 \\(x\\) 하나만 남긴다.

\\[ x\xrightarrow{\ A\ }Ax \\]

입력 벡터와 출력 벡터를 나란히 표시하고, 두 벡터 사이에 방향 변화와 길이 변화가 존재할 수 있음을 강조한다.

12\~17초 — 특별한 방향에 대한 질문

행렬 변환을 다시 보여주면서 일부 입력 방향을 강조한다.

`특별한 입력 방향을 찾으면?`

그 방향에서는 복잡한 행렬의 변환을 방향별로 측정하고, 크기를 바꾸고, 결과를 합치는 연산으로 이해할 수 있다는 점을 예고한다.

## Scene 02. SVD의 세 가지 역할 (17\~29초)

17\~21초 — SVD 소개

화면 중앙에 `Singular Value Decomposition`을 표시한다.

21\~26초 — 분해 공식

\\[ \boxed{A=U\Sigma V^T} \\]

공식을 세 영역으로 분리한다.

# \\(V^T\\)

입력 성분 측정

# \\(\Sigma\\)

성분 크기 조절

# \\(U\\)

출력 방향 구성

벡터에 실제로 작용하는 순서는 오른쪽부터 Vᵀ → Σ → U

26\~29초 — 예제로 전환

공식을 화면 상단으로 축소하고 아래에 빈 2×2 행렬을 등장시킨다.

영상에서 숫자가 채워지면 바로 다음 장면의 예제가 완성되도록 연결하자.

## Scene 03. 행렬이 두 입력 방향에 어떻게 작용할까? (29\~50초)

29\~35초 — 예제 행렬 등장

\\[ A= \begin{bmatrix} 0&-1\\\ 3&0 \end{bmatrix} \\]

각 원소를 나레이션에 맞춰 순서대로 등장시킨다.

35\~41초 — 첫 번째 입력 방향

가로 방향 단위벡터 \\(e_1=(1,0)\\)을 행렬에 입력한다.

\\[ A\begin{bmatrix}1\\\0\end{bmatrix} = \begin{bmatrix}0\\\3\end{bmatrix} \\]

수평 오른쪽으로 향하던 벡터가 위쪽으로 향하는 길이 3의 벡터로 변한다.

41\~46초 — 두 번째 입력 방향

이번에는 세로 방향 단위벡터 \\(e_2=(0,1)\\)을 입력한다.

\\[ A\begin{bmatrix}0\\\1\end{bmatrix} = \begin{bmatrix}-1\\\0\end{bmatrix} \\]

위쪽을 향하던 벡터가 왼쪽을 향하는 길이 1의 벡터로 변한다.

가로 입력 → 위쪽 3배

세로 입력 → 왼쪽 1배

46\~50초 — 비교

두 변환을 나란히 보여준다.

| 입력 방향         | 출력 방향        | 배율 |
| ------------- | ------------ | -- |
| 오른쪽 \\(v_1\\) | 위쪽 \\(u_1\\) | 3  |
| 위쪽 \\(v_2\\)  | 왼쪽 \\(u_2\\) | 1  |

여기서 같은 행렬이라도 입력 방향에 따라 반응이 달라진다는 점을 확실하게 전달하자.

## Scene 04. 특별한 입력 방향을 V로 정리한다 (50\~57초)

50\~54초

두 입력 단위벡터를 다시 좌표평면에 표시한다.

\\[ v_1=(1,0),\qquad v_2=(0,1) \\]

두 벡터를 각기 다른 열에 배치해 행렬 V를 만든다.

\\[ V=\begin{bmatrix}1&0\\\0&1\end{bmatrix} \\]

54\~57초

두 벡터가 서로 직교하고 길이가 1이라는 점을 짧게 강조한다.

이 예제에서는 입력 특이벡터가 기존의 가로·세로축과 일치하기 때문에 \\(V=I\\)라는 보조 자막을 넣으면 좋아.

다만 모든 행렬에서 \\(V=I\\)인 것은 아니므로, 최종 정리 장면에서 일반적인 회전 기저와의 차이를 짧게 보여주자.

## Scene 05. Vᵀ는 입력 벡터의 방향별 성분을 측정한다 (57\~73초)

이 구간은 이번 영상이 내적 시리즈라는 점을 가장 직접적으로 보여줘야 하는 장면이야.

57\~61초 — 입력 벡터 설정

\\[ x=\begin{bmatrix}2\\\1\end{bmatrix} \\]

원점에서 오른쪽으로 2, 위쪽으로 1만큼 향하는 파란색 입력 벡터를 그린다.

61\~68초 — 내적으로 성분 계산

첫 번째 입력 방향과의 내적:

\\[ v_1^Tx=(1,0)\cdot(2,1)=2 \\]

두 번째 입력 방향과의 내적:

\\[ v_2^Tx=(0,1)\cdot(2,1)=1 \\]

입력 벡터를 두 직교 방향의 성분으로 읽는다.

68\~73초 — Vᵀ의 의미

두 내적 결과를 행렬 형태로 합친다.

\\[ V^Tx= \begin{bmatrix} v_1^Tx\\\ v_2^Tx \end{bmatrix} = \begin{bmatrix}2\\\1\end{bmatrix} \\]

화면 상단에는 `Vᵀ = 입력 방향별 내적`이라고 표시한다.

이 예제에서는 숫자 자체는 변하지 않지만, 기존 좌표를 다시 적은 것이 아니라 특이벡터 방향에서 성분을 측정한 결과라는 점을 시각적으로 보여주는 것이 중요해.

## Scene 06. Σ는 방향마다 다른 배율을 적용한다 (73\~89초)

73\~75초: \\(V^Tx=(2,1)\\)을 화면 중앙에 표시하고, 다음 단계인 \\(\Sigma\\)를 강조한다.

75\~78초: 대각행렬이 등장한다.

\\[ \Sigma= \begin{bmatrix} 3&0\\\ 0&1 \end{bmatrix} \\]

78\~84초: 첫 번째 성분에는 3을, 두 번째 성분에는 1을 곱한다.

84\~89초: 두 결과가 각각 6과 1로 바뀐다.

\\[ \begin{bmatrix}2\\\1\end{bmatrix} \xrightarrow{\ \Sigma\ } \begin{bmatrix}6\\\1\end{bmatrix} \\]

첫 번째 성분

## 2 × 3 = 6

두 번째 성분

## 1 × 1 = 1

이 구간에서는 출력 방향을 아직 적용하지 않아야 해.

즉, Σ는 성분들의 크기만 조절하는 단계라는 점을 분명히 표현하자.

## Scene 07. U가 출력 방향을 결정한다 (89\~108초)

여기가 이번 영상에서 가장 중요한 재구성 장면이야.

89\~91초 — U 등장

\\[ U= \begin{bmatrix} 0&-1\\\ 1&0 \end{bmatrix} \\]

91\~94초 — 출력 방향 소개

두 열벡터를 각각 출력 공간에 표시한다.

\\[ u_1=(0,1),\qquad u_2=(-1,0) \\]

첫 번째는 위쪽, 두 번째는 왼쪽 방향이야.

94\~99초 — 방향별 성분 배치

앞서 계산한 두 성분을 각각 출력 방향으로 배치한다.

\\[ 6u_1=(0,6) \\]

\\[ 1u_2=(-1,0) \\]

99\~104초 — 벡터의 덧셈

먼저 위쪽으로 길이 6의 벡터를 그린다. 그 끝점에서 왼쪽으로 길이 1의 벡터를 연결한다.

원점에서 최종 끝점까지 새 벡터를 그려준다.

\\[ 6u_1+u_2=(0,6)+(-1,0)=\boxed{(-1,6)} \\]

104\~108초 — 최종 출력 확정

완성된 벡터에 `Ax = (−1,6)`이라는 이름을 붙인다.

이번 장면에서 가장 중요한 것은 출력 벡터가 한 번에 등장하는 것이 아니라, 두 출력 방향의 성분을 더하는 과정으로 만들어진다는 사실이야.

## Scene 08. 원래 행렬곱과 비교한다 (108\~120초)

108\~113초 — 직접 행렬곱

화면을 좌우로 나눈다.

왼쪽에서는 원래 행렬을 입력 벡터에 직접 곱한다.

\\[ \begin{bmatrix} 0&-1\\\ 3&0 \end{bmatrix} \begin{bmatrix}2\\\1\end{bmatrix} = \begin{bmatrix}-1\\\6\end{bmatrix} \\]

오른쪽에서는 지금까지 수행한 SVD 계산을 보여준다.

\\[ U\Sigma V^Tx= \begin{bmatrix}-1\\\6\end{bmatrix} \\]

113\~120초 — 계산 흐름 비교

원래 행렬 계산

\\[ Ax=(-1,6) \\]

SVD로 분해한 계산

\\[ U\Sigma V^Tx=(-1,6) \\]

두 계산의 결과가 정확히 일치한다.

여기서는 결과가 같다는 것만으로 끝내지 말고, SVD가 왜 유용한 표현인지 설명해야 해.

원래 계산은 행렬의 원소를 직접 곱하는 것이지만, SVD는 행렬이 입력의 각 방향에 어떻게 반응하는지 분리해서 해석할 수 있는 표현이야.

## Scene 09. SVD의 일반식으로 확장한다 (120\~129초)

120\~123초: 지금까지의 예제를 정리한 뒤 입력과 출력 방향의 개수를 일반화한다.

123\~129초: 다음 식을 단계별로 완성한다.

\\[ \boxed{Ax=\sum_i\sigma_i u_i(v_i^Tx)} \\]

\\(v_i^Tx\\)

내적

입력 방향의 성분 측정

\\(\sigma_i\\)

특이값

방향별 크기 조절

\\(u_i\\)

출력 특이벡터

조절된 성분을 출력 방향으로 배치

이 구간은 시리즈 전체에서 가장 중요한 일반식 중 하나야.

LEVEL 01에서 배웠던 내적값 \\(v_i^Tx\\)가 이번에는 전체 행렬 변환을 구성하는 기본 요소가 되었다는 것을 강조하면 좋아.

## Scene 10. PCA와 SVD는 무엇이 다를까? (129\~140초)

129\~134초 — PCA 회상

이전 편의 데이터 분포와 첫 번째 주성분을 짧게 보여준다.

PCA에서는 데이터가 가장 크게 퍼진 방향을 찾았어.

134\~140초 — SVD와 비교

이번에는 같은 행렬에 여러 방향의 벡터를 입력했을 때 출력이 어떻게 달라지는지 보여준다.

PCA

데이터 분포를 분석

가장 큰 투영 분산을 갖는 방향

SVD

행렬의 작용을 분석

입력·출력 특이방향과 확대·축소 비율

PCA와 SVD가 완전히 무관한 개념처럼 보이지 않도록, 중심화된 데이터 행렬의 SVD에서 PCA의 주성분 방향을 얻을 수 있다는 사실을 작은 자막으로 넣어도 좋아.

`중심화된 데이터 행렬 X의 오른쪽 특이벡터 → PCA 주성분 방향`

### 가장 주의할 세 가지

첫째, V와 U는 서로 다른 방향을 나타낸다. 이번 예제에서 V의 두 열은 오른쪽·위쪽이지만 U의 두 열은 위쪽·왼쪽이야. 수식의 순서와 실제 애니메이션을 일치시켜야 해.

둘째, Σ는 특이값이 음수가 아닌 대각행렬이야. 이 예제의 특이값은 3과 1이고, 왼쪽을 향하는 출력은 음수 특이값 때문이 아니라 \\(u_2=(-1,0)\\)이라는 출력 특이벡터 때문이야.

셋째, \\(V=I\\)라는 사실이 SVD 일반 구조를 오해하게 만들 수 있어. 영상 마지막에 V가 회전된 기저를 갖는 일반적인 경우를 잠깐 보여주되, 이번 예제의 실제 계산은 변경하지 않는 것이 좋아.

## 5. 이번 편에서 가장 강조할 부분

61\~108초가 영상의 중심이야.

하나의 벡터 \\(x=(2,1)\\)에서 두 개의 내적값 2와 1을 얻고, 특이값에 의해 6과 1로 바뀌고, 이 값을 각각 위쪽·왼쪽 출력 방향으로 배치해 \\((-1,6)\\)을 만들어내는 과정이지.

이 장면이 제대로 구현되면 SVD는 단순히

\\[ A=U\Sigma V^T \\]

라는 암기 공식이 아니라,

\*\*“행렬이 입력 벡터의 방향별 성분을 어떻게 출력으로 변환하는지 드러내는 분해”\*\*로 이해될 수 있어.

그리고 이것이 LEVEL 01에서 출발한 내적의 의미가 LEVEL 08에서 도달하는 핵심적인 확장이야.

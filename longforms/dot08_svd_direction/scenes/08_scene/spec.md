# 08 — 직접 곱해도 같은 결과

## 목적과 핵심 주장
Ax와 UΣVᵀx가 모두(−1,6)이다.

## 앞 장면에서 받은 내용
6u₁+u₂=(−1,6)이며 음수는 왼쪽 출력 방향에서 나온다.

## TTS와 확정 길이
사용자 제공 108–120초, 12초. 음원 미제공.

실제로 원래 행렬 A에 입력 벡터 2와 1을 직접 곱해도 같은 결과가 나옵니다.
즉, 행렬의 변환을 방향별 성분의 측정, 크기 조절, 출력 방향의 결합으로 나누어 계산한 것입니다.

## 화면 구성
입력·출력 공간을 별도 좌표평면에 표시. 세로 도형 위·수식 아래, 가로 도형 왼쪽·수식 오른쪽. 각 공간은 고정축과 동일한 단위배율 사용. 성분 확대는 숫자 막대로 표시. 자막 영역 별도.

## 구간별 애니메이션·텍스트
108–113초 직접 원소곱 계산. 113–120초 내적→크기조절→출력방향의 계산 흐름과 결과 비교.

## 시작·종료 상태와 다음 연결
Ax=Σᵢσᵢuᵢ(vᵢᵀx).

## 수학적 조건
A=[[0,−1],[3,0]], x=(2,1), V=I₂, Σ=diag(3,1), U=[[0,−1],[1,0]]. v₁=(1,0),v₂=(0,1),u₁=(0,1),u₂=(−1,0). U,V는 직교정규이고 σ₁≥σ₂≥0. Vᵀx=(2,1), ΣVᵀx=(6,1), 출력(−1,6). Σ단계는 숫자 성분의 배율만 바꾸며 출력공간에 배치하지 않는다. 왼쪽 출력은 음수 특이값이 아니라 u₂의 방향이다. 입력·출력 좌표계의 축은 고정하고 단위길이 표시를 제공. 일반화 예제는 A′로 명시하고 V′≠I. 행이 샘플인 중심화 데이터 X에서 오른쪽 특이벡터가 PCA의 특성공간 방향이다.

# 02 — 두 항 이하로 정확히 만드는 집합

## 목적과 주장
두 항 이하로 정확히 만드는 집합. 원래 행렬곱의 최소 곱셈 수 질문에서 벗어나지 않고 정확한 집합과 폐포의 차이를 보여준다.

## 앞뒤 연결
master_script.md 순서에 따라 계산 관계의 점→낮은 랭크 집합→외부 목표에 접근→소거의 가능성→두 최소값→정확한 계산의 연결로 진행한다.

## TTS
단순항 하나로 표현할 수 있는 텐서들을 모아보겠습니다. 두 항 이하로 표현할 수 있는 텐서들도 모아봅니다.

한 항으로 만드는 구조는 두 항 이하의 집합에도 포함됩니다.

이 집합의 점 하나를 고르면, 두 입력 조합의 곱을 최대 두 번 사용해 그 계산 관계를 정확히 표현할 수 있습니다.

그렇다면 정확히 두 항으로 만들 수 없는 점에는 얼마나 가까이 갈 수 있을까요?

실측 전. 화면 임시 배정 24초.

## 화면·애니메이션
0–7초 한 항 집합 / 7–12초 두 항 이하로 확장 / 12–18초 내부 점의 두 곱 표현 / 18–24초 외부 목표 질문. 고정된 같은 목표 T, 청록색 정확한 집합, 초록색 접근 경로, 금색 목표를 유지한다.

## 시작과 종료
각 제목 질문에서 출발해 다음 단계로 대상을 이동한다. 화면 문구와 수식은 visuals.py part2에 정의한다.

## 정확성
집합 도형은 포함관계 개념도이며 실제 차원·형상·거리나 충실한 기하학적 투영이 아니다. R1도 일반적으로 비선형이고 R2 전체를 유계 영역으로 주장하지 않는다. 특정 목표 T가 R2에 미포함이지만 폐포에 포함됨을 표현한다. 경계 전체가 R2 바깥이라는 주장도 하지 않는다. 예시는 검증된 W와 동형이며 rank3, border rank2 하한을 별도 검증한다. 계수 화살표는 성분 소거의 개념도이며 랭크를 평면 그림으로 판정하지 않는다. 복원 비용 없이 정확한 2곱 알고리즘이나 행렬곱 지수 개선을 주장하지 않는다.

## 폐포 수정본
현재 원고는 script.txt가 기준. 새 화면 임시 배정 24초, 실제 음성 길이는 미확정. 원판의 폐포를 먼저 설명하고 텐서 집합에는 개념도로 적용한다. 행렬과 텐서의 폐포 비교는 별도 강조한다. 원래 포함된 극한점은 다시 추가할 필요가 없으며 빠져 있던 점만 보충한다. 새 타임라인은 visuals.py 참조.

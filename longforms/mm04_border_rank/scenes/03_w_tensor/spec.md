# 03 — 집합 밖의 점에 한없이 가까워진다

## 목적과 주장
집합 밖의 점에 한없이 가까워진다. 원래 행렬곱의 최소 곱셈 수 질문에서 벗어나지 않고 정확한 집합과 폐포의 차이를 보여준다.

## 앞뒤 연결
master_script.md 순서에 따라 계산 관계의 점→낮은 랭크 집합→외부 목표에 접근→소거의 가능성→두 최소값→정확한 계산의 연결로 진행한다.

## TTS
목표점은 두 항 이하의 집합에 포함되지 않습니다. 그런데 집합 안의 점들이 이 목표에 계속 가까워질 수 있습니다.

각 점은 여전히 두 항으로 표현됩니다. 아무리 가까워져도 목표와 정확히 같지는 않습니다.

하지만 극한의 목표에는 세 항이 필요할 수 있습니다. 실제로 이런 예제가 존재합니다.

정확히 표현할 수 없다는 사실이, 한없이 가까워질 수 없다는 뜻은 아닙니다.

집합 자체에는 없지만, 접근 가능한 점까지 포함한 폐포에는 들어가는 것입니다.

실측 전. 화면 임시 배정 30초.

## 화면·애니메이션
0–8초 미포함 목표 / 8–18초 내부 경로 / 18–24초 정확히 못 만들어도 접근 가능 / 24–30초 폐포. 고정된 같은 목표 T, 청록색 정확한 집합, 초록색 접근 경로, 금색 목표를 유지한다.

## 시작과 종료
각 제목 질문에서 출발해 다음 단계로 대상을 이동한다. 화면 문구와 수식은 visuals.py part3에 정의한다.

## 정확성
집합 도형은 포함관계 개념도이며 실제 차원·형상·거리나 충실한 기하학적 투영이 아니다. R1도 일반적으로 비선형이고 R2 전체를 유계 영역으로 주장하지 않는다. 특정 목표 T가 R2에 미포함이지만 폐포에 포함됨을 표현한다. 경계 전체가 R2 바깥이라는 주장도 하지 않는다. 예시는 검증된 W와 동형이며 rank3, border rank2 하한을 별도 검증한다. 계수 화살표는 성분 소거의 개념도이며 랭크를 평면 그림으로 판정하지 않는다. 복원 비용 없이 정확한 2곱 알고리즘이나 행렬곱 지수 개선을 주장하지 않는다.

## 폐포 수정본
현재 원고는 script.txt가 기준. 새 화면 임시 배정 48초, 실제 음성 길이는 미확정. 원판의 폐포를 먼저 설명하고 텐서 집합에는 개념도로 적용한다. 행렬과 텐서의 폐포 비교는 별도 강조한다. 원래 포함된 극한점은 다시 추가할 필요가 없으며 빠져 있던 점만 보충한다. 새 타임라인은 visuals.py 참조.

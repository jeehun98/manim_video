# 05 — 199,210개 파라미터와 약 750개 학습 변수

## 목적·핵심 주장
199,210개 파라미터와 약 750개 학습 변수

## 앞 장면과 연결
직전 장면에서 제시한 가중치와 학습 변수의 구분을 이어받는다.

## TTS 원문·확정 길이
MNIST 손글씨 숫자 분류 실험에서, 199,210개의 파라미터를 가진 신경망이 약 750개의 학습 변수만으로도 원래 모델 정확도의 90퍼센트 이상에 도달했습니다.

전체 파라미터 수의 약 0.38퍼센트에 해당하는 자유도만 사용한 것입니다.

사용자 문장 종료 시각 기준 59–76초, 17초. 음원 미제공.

## 화면·애니메이션·텍스트
첨부 콘티 SCENE 05 및 scene_engine.py의 해당 메서드를 따른다. 가로형은 좌우, 세로형은 상하 배치. timing.json의 문장 경계에 자막을 교체한다.

## 시작·종료 상태
주장을 설명할 도형이 등장하고 핵심 문장을 유지한다. 독립 교체 가능한 완성 씬.

## 정확성
199,210은 편향을 포함한 전체 파라미터 수. 750은 MNIST 완전연결망의 d_int90 측정값. 성능 곡선은 개념도이며 실제 측정 데이터가 아니다. 3차원 좌표계는 세 가중치 예시에만 사용한다. 복습과 다음 편 예고는 넣지 않는다.

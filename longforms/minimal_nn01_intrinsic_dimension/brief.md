# 제작 기준

사용자 제공 대본·29개 문장 종료 시각을 확정 기준으로 129초 제작. 요청 명칭은 최소 조건 2부 신경망 시리즈 1편이며, 첨부 콘티 제목의 02편보다 현재 요청을 우선한다. 가로 1920×1080·세로 1080×1920, 모두 60fps. 음원 미제공이므로 무음·전체 대본 자막 영상.

핵심: 파라미터 수, 학습 자유도, 특정 성능을 달성하는 무작위 부분공간의 차원을 구분한다. 세 가중치 예시는 (1,2,3)+t(2,−1,1)로 실제 계산한다. 비율 막대는 750/199210 그대로 그린다. 성능 그래프는 개념도 표기. 750개의 뉴런으로 그리지 않는다. 연결을 제거하지 않는다. 끝 질문은 해당 주제의 열린 질문이며 후속편 예고 문구는 넣지 않는다.

출처: Li, Farkhoor, Liu, Yosinski (2018), Measuring the Intrinsic Dimension of Objective Landscapes. https://arxiv.org/abs/1804.08838

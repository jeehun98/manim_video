# 이름과 성질의 연결

## 목적과 주장
고유하다는 이름이 고유직선의 성질을 연상시킨다.

## 앞 장면과 연결
독립 씬. 동일한 EVD/SVD 헤더와 색상으로 연결한다.

## TTS 원문
이름만으로도 수학적 특징을 어느 정도 짐작할 수 있습니다.

확정 길이: 3초 (21–24초). 사용자 문장 종료 시각, 음원 미제공.

## 화면과 애니메이션
첨부 콘티 SCENE 05 기준. 블루 EVD, 청록 SVD, 남색 배경. 시작 0.3초 이내 등장, 구간 내 변화 후 종료.
세로는 제목 아래 중앙 실험, 가로는 왼쪽 설명과 오른쪽 실험으로 재배치.

## 화면 텍스트
이름과 성질의 연결

## 시작·종료 상태
고정 비교 헤더 → 해당 주장 시각화 완성.

## 다음 장면 연결
컷으로 연결, 연결 내레이션과 다음 편 예고 없음.

## 정확성
고유하다는 이름이 고유직선의 성질을 연상시킨다.
이름의 직관성은 이번 영상의 평가 관점이다. 수학적 우열이 아니다.

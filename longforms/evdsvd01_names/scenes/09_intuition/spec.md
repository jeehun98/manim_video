# 이름만으로 떠올리기는?

## 목적과 주장
특이값의 정의가 틀렸다는 뜻이 아닌 이름의 직관성 평가다.

## 앞 장면과 연결
독립 씬. 동일한 EVD/SVD 헤더와 색상으로 연결한다.

## TTS 원문
하지만 '특이하다'는 이름만으로 이러한 수학적 특징을 떠올리기는 쉽지 않습니다.

확정 길이: 5초 (39–44초). 사용자 문장 종료 시각, 음원 미제공.

## 화면과 애니메이션
첨부 콘티 SCENE 09 기준. 블루 EVD, 청록 SVD, 남색 배경. 시작 0.3초 이내 등장, 구간 내 변화 후 종료.
세로는 제목 아래 중앙 실험, 가로는 왼쪽 설명과 오른쪽 실험으로 재배치.

## 화면 텍스트
이름만으로 떠올리기는?

## 시작·종료 상태
고정 비교 헤더 → 해당 주장 시각화 완성.

## 다음 장면 연결
컷으로 연결, 연결 내레이션과 다음 편 예고 없음.

## 정확성
특이값의 정의가 틀렸다는 뜻이 아닌 이름의 직관성 평가다.
이름의 직관성은 이번 영상의 평가 관점이다. 수학적 우열이 아니다.

# 방향에 따른 길이 변화

## 목적과 주장
A=diag(2,0.7), 단위원의 상은 반축 2,0.7인 타원이다.

## 앞 장면과 연결
독립 씬. 동일한 EVD/SVD 헤더와 색상으로 연결한다.

## TTS 원문
특이값은 행렬이 특정 방향의 길이를 얼마나 확대하거나 축소하는지 나타냅니다.

확정 길이: 5초 (34–39초). 사용자 문장 종료 시각, 음원 미제공.

## 화면과 애니메이션
첨부 콘티 SCENE 08 기준. 블루 EVD, 청록 SVD, 남색 배경. 시작 0.3초 이내 등장, 구간 내 변화 후 종료.
세로는 제목 아래 중앙 실험, 가로는 왼쪽 설명과 오른쪽 실험으로 재배치.

## 화면 텍스트

## 시작·종료 상태
고정 비교 헤더 → 해당 주장 시각화 완성.

## 다음 장면 연결

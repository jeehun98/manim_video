# 제작 기준

- 목표: EVD와 SVD 이름의 직관성을 비교하는 52초 수학 예능.
- 확정 대본: master_script.md. 사용자 문장 종료 1,3,5,8,13,18,21,24,28,32,34,39,44,46,47,52초.
- 화면: 블루 EVD, 청록 SVD, 남색 배경. 한글 Malgun Gothic.
- 9:16 쇼츠와 16:9 가로형을 각각 레이아웃하여 제작한다.
- 중앙 실험: 고유벡터를 같은 직선 위에서 3배 확대. 일반 벡터와 대비.
- SVD: 실제 diag(2,0.7) 변환을 원과 단위벡터에 적용.
- 평가는 이름의 직관성에 한정. 빨간 X와 분해법 전체의 우열 주장 없음.
- 사용자 내레이션 수정 없음. 음원은 미제공이며 영상 무음, 자막 포함.
- 최종 0.5초 유지, 영상 전체 길이 확장 없음.

# 02 — 경계에서 방향이 꺾인다

## 목적·핵심 주장
이미 전파한 광선 중 하나와 법선·굴절각을 관찰한다.

## 앞 장면에서 받은 내용
물속으로 전파되는 빛

## TTS와 확정 길이
사용자 구간 4–10초, 6초. timing.json의 원문·문장 종료 시각을 따른다. 음원 미제공.

공기 중에서 물을 향해 빛을 비추면, 빛은 경계면에서 방향이 꺾입니다.
이것을 굴절이라고 합니다.

## 화면·애니메이션
reference/storyboard.txt 시퀀스 02, visuals.py INDEX=1. 진입 약 0~0.5초, 구간 중간에 대상의 전파·비교·변화, 마지막에 결론 상태 유지. 애니메이션 실제 합계는 코드가 확정 길이 초과를 검사한다.

## 화면 텍스트
경계에서 방향이 꺾인다. 물리 수치와 함수는 physics.py, 자막은 사용자 원문이다.

## 시작·종료 상태
동일한 매질과 좌표로 독립 구성하고 관찰 또는 분석 결과로 종료한다.

## 다음 시각적 연결

## 조건·정확성
이미 전파한 광선 중 하나와 법선·굴절각을 관찰한다.
정지·균일·등방성·비분산 매질의 이상화. 반사와 진폭 전달 계수는 생략한다. 위상합은 기하광학의 정지위상 직관이며 완전한 장 적분이나 입자의 경로 탐색으로 제시하지 않는다.

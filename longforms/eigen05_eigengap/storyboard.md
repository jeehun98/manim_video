# 05. 고윳값 간격(Eigengap) — PCA의 주성분 방향이 불안정해지는 이유

고윳값과 고유벡터 시리즈 · 5편 · 146초 · 9:16 세로 영상 · 상세 영상화 콘티

이번 영상은 시청자가 먼저 이상한 현상을 관찰한 다음, 그 이유가 고윳값의 크기뿐 아니라 고윳값 사이의 간격에 있다는 사실을 발견하는 구조로 제작하는 것이 좋아.

가장 중요한 연출은 데이터 점들이 거의 그대로인데 PCA가 찾은 주성분 직선은 크게 회전하는 장면이야.

## 1. 전체 시각 설계

Eigengap이 큰 경우

한 방향이 뚜렷함

Eigengap이 작은 경우

어느 방향이 주축인지 모호함

개념적 스타일 가이드. 실제 영상의 점과 주성분은 계산된 데이터에서 생성하고, 두 주성분 방향은 서로 다른 데이터 상태임을 색상과 범례로 구별한다.

이번 편에서는 수식이 나올 때마다 데이터를 화면에서 없애는 대신, 수식을 위쪽에 작게 배치하고 데이터의 움직임을 계속 보여주는 편이 좋아.

## 2. 장면별 상세 콘티

### SCENE 01 — 거의 그대로인 데이터, 크게 회전하는 방향

00:00–00:06

내레이션

> 데이터의 위치가 아주 조금만 달라졌는데, 인공지능이 찾아낸 데이터의 주요 방향은 크게 바뀔 수 있을까요?

화면 연출

- 원형에 가까운 파란 점 구름을 화면 중앙에 표시한다.
- 그 위에 청록색 직선 하나를 표시한다.
- 일부 데이터 점이 매우 짧은 거리만큼 움직인다.
- 청록색 직선은 30\~40도 정도 크게 회전한다.
- 이전 방향을 회색 점선으로 남겨 차이를 강조한다.

화면 문구

`데이터 변화: 작음` / `주요 방향 변화: 큼`

도입에서는 원인을 설명하지 않고 결과의 대비만 보여준다. 이후 동일한 장면을 더 엄밀한 방식으로 재현하게 돼.

### SCENE 02 — PCA라는 방법

00:06–00:13

내레이션

> 주성분 분석, PCA에서는 이런 현상이 나타날 수 있습니다. 평면에 여러 데이터 점들이 놓여 있다고 생각해 보겠습니다.

화면 연출

- 가운데 `PCA — Principal Component Analysis` 등장.
- 약 80개의 점이 평면에 생성된다.
- 점들은 처음에는 무작위로 흩어져 있다가 서서히 길쭉한 분포를 이룬다.
- 좌표축은 표시하되 수치 눈금은 최소화한다.

의도: PCA를 처음 접하는 시청자도 데이터 점들에서 특정 방향을 찾는 방법임을 바로 이해하도록 한다.

### SCENE 03 — 길쭉한 분포에서 찾는 방향

00:13–00:23

내레이션

> 점들이 길쭉한 타원 모양으로 퍼져 있다면, 데이터가 가장 넓게 퍼진 방향을 비교적 쉽게 찾을 수 있습니다. PCA는 바로 이런 방향을 찾는 방법입니다.

화면 연출

- 점 구름을 감싸는 반투명 타원 윤곽이 등장한다.
- 분포를 관통하는 여러 후보 방향의 직선을 회전시킨다.
- 각 후보 방향으로 점들을 투영한 모습을 작은 보조 눈금에서 보여준다.
- 투영값이 가장 크게 퍼지는 방향에서 직선이 멈춘다.
- `첫 번째 주성분 PC1` 표시.

시청자에게 PCA를 단순히 타원의 긴 축을 찾는 마법으로 보여주기보다, 방향을 선택하고 데이터를 그 방향으로 투영했을 때 얼마나 퍼져 있는지 비교하는 방법으로 보여주는 것이 좋아.

### SCENE 04 — 평균과 공분산행렬

00:23–00:29

내레이션

> 데이터의 평균을 기준으로 각 점의 위치를 나타내고, 방향에 따른 퍼짐의 정도를 공분산행렬에 담습니다.

화면 연출

- 데이터의 평균 위치에 노란색 작은 점 등장.
- 각 관측점과 평균을 연결하는 얇은 선이 나타난다.
- 좌표 원점이 데이터 평균으로 이동한다.
- 오른쪽 위에 공분산행렬 \\(C\\)를 작게 배치한다.
- 데이터가 퍼지는 모양에 따라 행렬 원소가 계산되어 나타난다.

\\[ C=\begin{pmatrix} \operatorname{Var}(x)&\operatorname{Cov}(x,y)\\\ \operatorname{Cov}(x,y)&\operatorname{Var}(y) \end{pmatrix} \\]

이 장면에서 각 원소를 모두 읽게 할 필요는 없어. 평균을 기준으로 데이터를 바라보고, 그 퍼짐이 행렬로 요약된다는 사실만 보여주면 충분해.

### SCENE 05 — 공분산행렬의 고유벡터

00:29–00:38

내레이션

> 그리고 이 행렬의 고유벡터를 이용해 데이터가 가장 크게 퍼진 방향을 찾습니다. 가장 큰 고윳값에 대응하는 고유벡터가 첫 번째 주성분 방향입니다.

화면 연출

- 공분산행렬에서 두 고윳값과 두 고유벡터가 계산된다.
- 첫 번째 고유벡터를 데이터 공간에 가져와 청록색 직선으로 표시한다.
- 두 번째 고유벡터는 주황색 점선으로 표시한다.
- 각 방향으로 투영된 데이터의 분산을 짧은 막대로 비교한다.
- 큰 분산에 대응하는 방향만 밝게 남긴다.

주요 레이블

\\[ Cv_1=\lambda_1v_1,\qquad \lambda_1\ge\lambda_2 \\]

`PC1 = 가장 큰 고윳값에 대응하는 방향`

고윳값 자체는 분산의 단위를 갖는 수치이고, 고유벡터는 그 방향을 나타낸다는 차이를 시각적으로 유지하자.

### SCENE 06 — 타원이 원형에 가까워진다면

00:38–00:43

내레이션

> 그런데 데이터가 길쭉한 타원이 아니라, 원형에 가까운 모습으로 퍼져 있다면 어떨까요?

화면 연출

- 길쭉한 점 구름이 서서히 원형에 가까워진다.
- 청록색 PC1과 주황색 PC2는 계속 표시한다.
- 처음에는 PC1이 명확하지만, 분포가 원형이 되어 갈수록 두 방향의 분산 차이가 줄어든다.

여기서 임의로 타원 윤곽만 원으로 바꾸지 않고, 실제 점 좌표 자체를 변환하여 공분산행렬도 함께 갱신하는 방식으로 제작한다.

### SCENE 07 — 고윳값 간격이 줄어든다

00:43–00:53

내레이션

> 가로 방향과 세로 방향의 퍼짐이 비슷해지면서, 공분산행렬의 두 고윳값도 가까워집니다. 이때는 어느 방향이 가장 크게 퍼져 있는지 구분하기 어려워집니다.

화면 연출

- 데이터 점 구름을 유지하면서 아래쪽에 고윳값 막대 두 개를 표시한다.
- 타원이 길쭉할 때는 두 막대 높이가 다르다.
- 분포가 원형에 가까워지면서 두 막대의 높이가 비슷해진다.
- PC1의 표시 강도를 조금 낮추어 방향의 구별이 약해지는 인상을 준다.

중요: 원형에 가까워졌다는 이유만으로 PC1을 실제 계산 없이 무작위로 회전시키지 않는다. 이 장면에서는 단지 두 고윳값의 차이가 좁아지는 현상만 표현한다.

### SCENE 08 — 일부 데이터를 바꿔보는 실험

00:53–01:01

내레이션

> 이제 데이터 점 몇 개를 조금 움직이거나, 새로운 데이터를 소수 추가해 보겠습니다. 전체적인 점들의 분포는 거의 달라지지 않았습니다.

화면 연출

- 변경 전 데이터를 파란색으로 고정한다.
- 수정되는 점 4\~6개를 보라색으로 강조한다.
- 해당 점들이 짧게 이동하고, 움직인 거리만큼 얇은 선을 남긴다.
- 전체 점 구름의 외형은 거의 유지된다.
- 화면 아래에 `데이터 일부 수정` 표시.
- 공분산행렬은 변경된 데이터에서 다시 계산한다.

데이터 변경은 가능한 한 한 가지 방식으로 통일하는 것이 좋겠어. 실제 콘티에서는 기존 점 일부의 위치를 변경하는 방식을 기본으로 사용하고, 데이터 추가는 보조 연출로만 두는 편이 명확해.

### SCENE 09 — PCA의 주성분이 크게 회전한다

01:01–01:07

내레이션

> 그런데 PCA를 다시 계산하면 첫 번째 주성분을 나타내는 직선이 크게 회전할 수 있습니다.

화면 연출

- 점들은 거의 같은 위치에 남아 있다.
- 변경 전 PC1을 회색 점선으로 표시한다.
- 변경 후 새 PC1이 청록색으로 나타난다.
- 새 방향과 기존 방향 사이에 각도 호를 그린다.
- 변화량이 약 30도인 검증된 예시를 사용한다.
- 이때 주성분을 설명하는 고윳값 막대는 거의 같다는 것을 함께 보여준다.

이 장면이 이번 영상의 첫 번째 절정이야. 데이터는 거의 그대로인데 주성분만 크게 달라졌다는 대비가 즉시 보여야 해.

### SCENE 10 — 길쭉한 분포에서는?

01:07–01:14

내레이션

> 반대로 길쭉한 타원형 데이터에서는 비슷한 크기의 변화를 주어도 주성분 방향이 비교적 안정적으로 유지됩니다.

화면 연출

화면을 좌우로 분할한다.

- 왼쪽: 길쭉한 분포.
- 오른쪽: 원형에 가까운 분포.
- 양쪽에서 같은 크기로 공분산에 영향을 주는 교란 실험을 수행한다.
- 왼쪽 PC1은 약간 회전한다.
- 오른쪽 PC1은 크게 회전한다.

이 비교는 두 분포에 동일한 공분산 변화 행렬을 가한 실험과, 실제 데이터 점을 수정하는 실험을 혼동하지 않도록 구성해야 해.

실제 점 데이터를 사용할 경우에는 두 경우에 동일한 데이터 수정 절차를 적용하고, 결과로 발생한 공분산 변화량도 함께 확인하는 방식이 좋다.

### SCENE 11 — 왜 같은 변화에 다르게 반응할까?

01:14–01:21 · 74\~81초

내레이션

> 왜 이런 차이가 발생할까요? 핵심은 공분산행렬의 가장 큰 고윳값과 두 번째 고윳값 사이의 간격입니다.

화면 연출

- 앞서 비교한 두 데이터 분포를 화면에 그대로 유지한다.
- 각각의 공분산행렬에서 두 고윳값을 꺼내 막대로 표현한다.
- 길쭉한 분포에서는 막대 높이 차이가 크고, 원형에 가까운 분포에서는 작다.
- 각 막대 사이에 노란색 괄호를 넣어 차이를 표시한다.
- 주성분의 회전 각도도 아래에 함께 표시한다.

핵심은 고윳값 자체보다 두 고윳값의 차이를 시청자의 시선이 따라가게 하는 것이야.

### SCENE 12 — Eigengap의 정의

01:21–01:28 · 81\~88초

내레이션

> 이 간격을 아이겐갭, Eigengap이라고 합니다. 고윳값은 각 주성분 방향으로 데이터가 얼마나 퍼져 있는지를 나타냅니다.

화면 연출

- 화면 중앙에 두 고윳값 \\(\lambda_1,\lambda_2\\)를 배치한다.
- 두 수치 사이의 거리를 강조하며 `Eigengap`이라는 용어가 나타난다.
- 이어서 각각의 고윳값을 대응하는 주성분 방향의 분산 막대와 연결한다.

\\[ \boxed{\text{Eigengap}=\lambda_1-\lambda_2} \\]

2차원 PCA에서 고윳값은 \\(\lambda_1\geq\lambda_2\\) 순서로 정렬한다.

이 장면에서 고윳값 = 분산, 고윳값의 간격 = 두 주성분의 분산 차이를 확실하게 연결해 주면 좋아.

### SCENE 13 — 고윳값 간격은 무엇을 알려주는가?

01:28–01:37 · 88\~97초

내레이션

> 그렇다면 고윳값의 간격은 무엇을 알려줄까요? 간격이 크다면 첫 번째 주성분 방향의 분산이 다른 방향보다 뚜렷하게 큽니다.

화면 연출

- 데이터의 첫 번째 주성분 방향으로 점들을 투영한다.
- 다음으로 두 번째 주성분 방향에 투영한다.
- 두 투영 분포의 퍼짐을 화면 아래에서 비교한다.
- 첫 번째 분산 막대가 두 번째보다 훨씬 크게 나타난다.
- `PC1이 뚜렷하게 구별됨`이라는 문구를 표시한다.

시각적으로는 PC1 직선을 크게 그리는 것보다, 각 방향으로 투영된 점들의 분포가 실제로 얼마나 다른지 보여주는 것이 중요해.

### SCENE 14 — 간격이 작으면 방향이 민감해진다

01:37–01:45 · 97\~105초

내레이션

## 4. 실제 제작용 수학 데이터

이번 영상은 단순히 예쁜 점 구름을 만든 뒤 주성분 직선을 임의로 회전시키면 안 돼. PCA를 실제로 다시 계산한 결과를 시각화해야 설득력이 생겨.

특히 61\~74초의 두 분포 비교는 다음 공분산행렬을 기준으로 구현하는 것을 추천해.

분산 차이가 큰 경우

\\[ C\_{\text{large}}= \begin{pmatrix}2&0\\\0&1\end{pmatrix} \\]

분산 차이가 작은 경우

\\[ C\_{\text{small}}= \begin{pmatrix}1.01&0\\\0&1\end{pmatrix} \\]

두 경우에 동일한 공분산 교란을 가한다.

\\[ E=\begin{pmatrix}0&0.01\\\0.01&0\end{pmatrix} \\]

이때 첫 번째 주성분 방향의 회전량은 다음과 같아.

| 조건           | 초기 Eigengap | PC1 회전량  |
| ------------ | ----------- | -------- |
| 분산 차이가 큰 경우  | 1.00        | 약 0.57°  |
| 분산 차이가 작은 경우 | 0.01        | 약 31.72° |

영상 제작에서는 고정된 점 데이터에서 시작해 각각의 목표 공분산행렬과 교란 후 공분산행렬을 재현하도록 데이터를 생성하면 좋아. 모든 프레임에서 데이터 평균과 공분산, 고유벡터를 실제 계산하도록 한다.

```
import numpy as npdef pca_2d(points):    centered = points - points.mean(axis=0)    covariance = centered.T @ centered / (len(points) - 1)    values, vectors = np.linalg.eigh(covariance)    order = np.argsort(values)[::-1]    values = values[order]    vectors = vectors[:, order]    return {        "covariance": covariance,        "eigenvalues": values,        "eigenvectors": vectors,        "eigengap": values[0] - values[1],    }
```

실제 데이터의 작은 변화라는 표현을 사용하려면, 점들의 변위량도 함께 측정하는 것이 정확해. 공분산 변화가 작다고 해서 개별 점들의 변화가 모두 작다는 뜻은 아니기 때문이야.

## 5. 연출에서 특별히 주의할 세 가지

첫째, PCA의 방향은 화살표보다 직선으로 표현하는 것이 정확해. 고유벡터 \\(v\\)와 \\(-v\\)는 같은 주성분 축을 나타내므로, 단순한 부호 반전이 180도 회전한 것처럼 보이면 안 돼. 회전각은 두 방향을 직선으로 보아 0\~90도 사이의 작은 각도로 측정하자.

둘째, 원형에 가까운 데이터와 고윳값이 정확히 같은 데이터는 구분해야 해. 거의 원형인 경우에는 PC1이 존재하더라도 민감할 수 있고, 공분산이 정확히 \\(cI\\)인 경우에는 특정한 PC1 방향이 수학적으로 정해지지 않아.

셋째, 고윳값 간격이 클수록 무조건 안정적이라고 단정하지 말자. 안정성에는 행렬의 변화량도 함께 작용해. 이번 영상의 메시지는 같은 수준의 작은 변화에 대해 고윳값 간격이 좁으면 방향이 더 민감해질 수 있다는 것이야.

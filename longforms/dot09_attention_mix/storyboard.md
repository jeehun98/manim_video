## Scene 06. 내적 점수를 스케일링한다 (70\~79초)

70\~73초 — 점수에서 가중치로 전환

화면에 내적 점수 3과 2를 나란히 배치한다. 두 숫자 위에 아직 `Attention Weight`라는 이름을 붙이지 않아야 해.

73\~77초 — 스케일링

Key의 차원이 2이므로 두 점수를 \\(\sqrt2\\)로 나눈다.

\\[ s_1=\frac3{\sqrt2}\approx2.121 \\]

\\[ s_2=\frac2{\sqrt2}\approx1.414 \\]

두 숫자를 화면에서 동시에 변환한다.

77\~79초 — 스케일링 결과

Scaled Dot-Product

\\[ s_i=\frac{q\cdot k_i}{\sqrt{d_k}} \\]

스케일링은 단순히 점수를 확률로 만드는 과정이 아니야. 차원이 커질 때 내적값의 크기가 커지는 경향을 완화하기 위한 연산이지.

이번 예제에서는 두 점수 모두 양수이므로, 스케일링 이후에도 첫 번째 점수가 더 커.

## Scene 07. Softmax로 Attention 가중치를 얻는다 (79\~93초)

79\~82초 — Softmax 적용

스케일링된 두 점수가 Softmax 블록으로 들어간다.

\\[ \alpha_i=\frac{e^{s_i}}{\sum_j e^{s_j}} \\]

82\~85초 — 가중치로 변환

Softmax 블록을 통과한 결과를 퍼센트 막대로 나타낸다.

이전 장면에서는 막대가 3:2의 비율이었지만, 이번에는 약 67:33의 비율이라는 점을 명확히 보여줘.

또한 Softmax의 중요한 성질은 두 가중치의 합이 1이라는 것이야.

연출 제안: 두 막대를 각각 보여준 뒤 하나의 전체 막대로 합치면, 전체 100%를 두 정보에 나누어 배정한다는 느낌을 전달할 수 있어.

두 벡터를 동일한 원점에서 그린다.

101\~104초 — 가중치 적용

앞에서 계산한 가중치 0.67과 0.33이 각각의 Value에 연결된다.

두 벡터의 길이가 서로 다른 비율로 줄어드는 애니메이션을 보여준다.

104\~109초 — 각 Value의 가중 결과

\\[ 0.67v_1=(2.68,0) \\]

\\[ 0.33v_2=(0,0.66) \\]

첫 번째 벡터는 오른쪽으로 2.68, 두 번째 벡터는 위쪽으로 0.66만큼 향한다.

109\~115초 — 최종 출력 생성

첫 번째 가중 Value 벡터의 끝점에 두 번째 가중 Value를 이어 붙인다.

두 벡터를 합한 뒤 원점에서 최종 끝점까지 새로운 밝은 파란색 벡터를 그린다.

\\[ \begin{aligned} o&=\alpha_1v_1+\alpha_2v_2\\\ &\approx(2.68,0)+(0,0.66)\\\ &=\boxed{(2.68,0.66)} \end{aligned} \\]

여기서 가장 중요한 사실은 내적을 계산한 Key 벡터들을 합치는 것이 아니라, 별도의 Value 벡터들을 가중합한다는 점이야.

화면에서도 Key와 Value가 명확하게 구별되어야 해.

## Scene 09. Attention 전체 계산 구조를 정리한다 (115\~123초)

115\~120초 — 전체 연산을 다시 연결

지금까지 계산한 세 단계를 빠르게 재생한다.

Query–Key 내적

\\[ [q\cdot k_1,\ q\cdot k_2]=[3,2] \\]

스케일링 + Softmax

\\[ \alpha\approx(0.67,0.33) \\]

Value 가중합

\\[ o=\alpha_1v_1+\alpha_2v_2 \\]

120\~123초 — Attention 전체 수식

\\[ \boxed{ \operatorname{Attention}(Q,K,V) = \operatorname{softmax} \left(\frac{QK^T}{\sqrt{d_k}}\right)V } \\]

이 공식은 예제에서 Query 하나로 계산했던 과정을 여러 Query로 확장한 형태야.

영상에서는 공식 전체를 외우게 하기보다 내적 → 가중치 → 결합이라는 순서를 한 번 더 강조하는 정도면 충분해.

## Scene 10. 정사영과 Attention은 무엇이 다를까? (123\~146초)

이 구간은 「내적 LEVEL」 시리즈의 수학적 정확성을 위해 꼭 필요한 장면이야.

126\~131초: 정사영에서는 단위벡터와의 내적값을 다시 그 단위벡터에 곱한다는 사실을 강조한다.

\\[ p=(x\cdot u)u \\]

137\~142초 — 정사영과의 구별

정사영에서는 잔차가 기준 방향과 직교하지만, Attention의 출력은 일반적으로 그런 직교 조건을 만족하지 않아.

영상에는 다음처럼 간결하게 표시하자.

`정사영의 내적 ≠ Attention 점수의 역할`

142\~146초 — 내적의 크기와 각도

두 벡터 사이의 내적이 방향뿐 아니라 길이에도 영향을 받는다는 점을 짧게 보여준다.

\\[ q\cdot k=\\|q\\|\\|k\\|\cos\theta \\]

같은 각도를 유지하면서 Key의 길이만 늘리면 내적 점수가 커지는 모습을 보여주면 충분해.

이 장면은 Attention의 점수를 단순한 코사인 유사도로 오해하지 않게 만드는 역할을 해.

## 4. 이번 영상의 제작 핵심

가장 중요한 구간은 53\~115초야.

여기서 한 번의 내적 계산으로 끝나는 것이 아니라, 결과가 다음 연산으로 전달되는 흐름을 일관되게 표현해야 해.

53\~70초 — 내적으로 점수 계산

\\(q\cdot k_1=3\\), \\(q\cdot k_2=2\\)라는 숫자가 어떻게 만들어지는지 보여준다.

70\~93초 — 점수가 가중치로 변화

스케일링과 Softmax를 거쳐 합이 1인 두 가중치가 만들어진다.

93\~115초 — Value 결합

두 가중치가 각각 다른 Value에 적용되고, 최종 출력 벡터 하나가 만들어진다.

특히 이전의 내적 시리즈에서 정사영과 직교기저를 다뤘기 때문에, 이번에는 Attention을 또 다른 형태의 정사영이라고 설명하지 않는 것이 중요해.

두 연산 모두 내적을 사용하지만 목적과 결과가 달라. 정사영은 벡터의 방향 성분을 추출하고, Attention은 학습된 벡터들 사이의 점수를 이용해 여러 Value를 결합하는 연산이야.

이렇게 연출하면 LEVEL 09는 내적이 신경망의 정보 처리에 어떻게 활용되는지를 보여주는 독립적인 영상으로 완결되면서, 마지막 LEVEL 10에서 기울기와 이동 방향의 내적을 이용해 손실의 변화를 이해하는 과정으로 자연스럽게 이어질 수 있어.

# 내적 LEVEL 07 — 상세 영상화 콘티

총 149초 · 9:16 세로 영상 · 주성분 분석(PCA, Principal Component Analysis) · 정사영 · 재구성 오차 · 분산 최대화

이번 영상의 핵심은 내적과 정사영으로 정의한 재구성 오차의 최소화가 어떻게 분산 최대화라는 문제로 바뀌는지 시각적으로 증명하는 거야.

단순히 데이터가 길게 퍼진 방향을 찾는 모습을 보여주는 것보다, 시청자가 다음 관계를 직접 발견하도록 구성하는 게 좋아.

\\[ \boxed{\text{재구성 오차 최소화}\iff\text{투영 분산 최대화}} \\]

특히 60\~111초가 이번 영상의 중심이야. 피타고라스 정리로 오차와 보존된 성분을 연결한 뒤, 기준 방향을 회전시키면서 두 값이 반대로 변하는 모습을 보여줘야 해.

## 1. 영상의 공통 시각 구성

예시 데이터는 가로·세로 방향 모두에 변화가 있지만, 오른쪽 위 방향으로 더 길게 퍼져 있다.

주황색

정사영된 위치 pᵢ

보라색

### 제작 원칙

- 데이터 점들의 위치는 중심화 이후 고정한다. 바뀌는 것은 투영 방향과 정사영된 위치뿐이야.
- 정사영은 초록색 직선 위의 주황색 점 또는 벡터로 표시한다.
- 재구성 오차는 원래 데이터 점과 정사영된 점을 연결하는 보라색 수선으로 표현한다.
- 전체 오차는 `잔차 길이 제곱합`, 보존된 정보량은 `내적값 제곱합`으로 구분한다.
- 모든 데이터에서 동일한 좌표계와 스케일을 사용한다. 방향에 따라 그래프 자체를 늘리거나 회전해서는 안 돼.

실제 영상에서는 데이터가 충분히 퍼져 보이도록 10\~20개의 점을 사용하는 것이 좋아. 너무 많은 점을 사용하면 수선과 정사영이 겹쳐서 복잡해지므로, 상세한 계산에서는 대표 점 1\~3개만 강조하자.

## Scene 03. 데이터를 중심화한다 (29\~38초)

29\~33초: 데이터 점들이 하나의 방향으로 길게 퍼져 있는 모습을 다시 표시하고, 최적 방향을 찾을 것이라는 질문을 던진다.

33\~38초: 모든 데이터의 평균 위치를 주황색 점으로 표시한다. 그 평균이 원점과 일치하도록 데이터 전체를 동일한 크기와 방향으로 평행이동한다.

중심화(Centering)

\\[ \widetilde{x}\_i=x_i-\bar{x} \\]

모든 데이터에서 동일한 평균 벡터를 빼서 데이터 중심을 원점으로 옮긴다.

중요: 데이터 하나하나의 위치를 제멋대로 이동시키는 것이 아니라, 모든 점에 같은 이동을 적용해야 해. 점들 사이의 상대적인 위치와 분포 모양은 그대로 유지돼야 하지.

중심화 이후에는 좌표계 원점과 데이터 평균이 일치해야 하고, 이 상태를 영상 끝까지 유지하자.

## Scene 04. 한 점을 내적으로 측정하고 정사영한다 (38\~55초)

이 구간은 앞선 LEVEL 01\~03의 연산을 다시 연결하는 역할을 해.

38\~41초: 중심화된 데이터 중 한 점 \\(x_i\\)를 선택하고, 원점을 지나는 초록색 단위 방향 \\(u\\)를 표시한다.

41\~46초: 데이터 점에 대응하는 벡터와 단위 방향을 내적한다.

\\[ c_i=x_i\cdot u \\]

내적값을 초록색 직선 위의 부호 있는 거리로 표시한다.

46\~50초: 측정값에 다시 단위벡터를 곱해 정사영을 만든다.

\\[ p_i=(x_i\cdot u)u \\]

50\~55초: 원래 점과 정사영된 점을 연결하는 보라색 잔차를 그린다.

\\[ r_i=x_i-p_i \\]

실제 제작에서는 잔차가 기준선과 정확히 수직이 되도록 정사영 좌표를 계산해야 한다. 위 그림은 요소 배치 개념도다.

## Scene 05. 모든 데이터의 오차를 하나의 값으로 만든다 (55\~63초)

55\~60초: 하나의 점에 대해 만든 보라색 잔차를 모든 데이터에 확장한다. 각 데이터 점에서 초록색 직선으로 수직선을 내린다.

모든 잔차에 대해 길이의 제곱을 계산하고 합산한다.

\\[ \boxed{E(u)=\sum\_{i=1}^{n}\\|r_i\\|^2} \\]

화면 오른쪽에 오차 게이지를 배치하고, 투영 방향을 조금씩 회전하면서 값이 변화하도록 한다.

60\~63초: 데이터를 모두 흐리게 처리하고 대표 벡터 하나를 확대한다.

"그런데 여기서 중요한 관계가 나타납니다."

이 장면을 통해 다음 피타고라스 정리로 자연스럽게 이동한다.

## Scene 06. 피타고라스 정리로 잔차와 정사영을 연결한다 (63\~79초)

이번 영상에서 가장 중요한 수학적 설명이 시작되는 장면이야.

63\~67초: 대표 데이터 벡터 하나만 남긴다. 파란색 원래 벡터를 주황색 정사영 벡터와 보라색 잔차로 분해한다.

\\[ x_i=p_i+r_i \\]

정사영과 잔차가 정확히 직교하므로 두 벡터 사이에 90도 표시를 추가한다.

67\~73초: 원래 벡터를 빗변으로 하는 직각삼각형을 강조한다. 각각의 변에 대응하는 길이의 제곱을 표시한다.

\\[ \\|x_i\\|^2=\\|p_i\\|^2+\\|r_i\\|^2 \\]

내적으로 얻은 정사영과 잔차가 직교하므로 피타고라스 정리를 적용할 수 있다.

73\~79초: 수식의 항을 이동시켜 잔차를 중심으로 다시 표현한다.

\\[ \boxed{\\|r_i\\|^2=\\|x_i\\|^2-(x_i\cdot u)^2} \\]

이때 주황색 정사영의 길이 제곱을 내적값의 제곱으로 바꾸는 애니메이션을 보여줘.

\\(u\\)가 단위벡터이기 때문에

\\[ \\|p_i\\|^2=(x_i\cdot u)^2 \\]

가 성립한다는 점이 중요해.

## Scene 07. 최소화 문제가 최대화 문제로 바뀐다 (79\~91초)

79\~82초: 대표 점에서 다시 전체 데이터로 화면을 확장한다. 모든 데이터의 잔차 제곱합을 표시한다.

\\[ E(u)=\sum_i\\|x_i\\|^2-\sum_i(x_i\cdot u)^2 \\]

82\~85초: 첫 번째 항인 원래 데이터의 길이 제곱합을 강조한다.

데이터가 고정되어 있으므로 이 값은 선택한 방향 \\(u\\)와 관계없이 일정해.

85\~91초: 두 번째 항인 내적값 제곱합이 커지면 전체 오차가 작아진다는 관계를 보여준다.

전체 크기는 일정하다

보존한 성분의 제곱합

증가

주황 · 보존

보라 · 손실

\\[ \boxed{ \min E(u)\iff \max\_{\\|u\\|=1}\sum_i(x_i\cdot u)^2 } \\]

영상에서 이 막대는 단순한 그래픽이 아니라 실제 데이터의 계산값으로 갱신해야 해.

정사영으로 보존한 성분과 잔차로 잃은 성분의 제곱합이 일정하다는 관계를 시각적으로 전달하는 것이 이 장면의 핵심이야.

## Scene 08. 내적값의 제곱합이 왜 분산일까? (91\~106초)

91\~96초: 각 데이터의 정사영 벡터 대신 내적값 \\(c_i=x_i\cdot u\\)를 직선 위에 숫자 하나로 표시한다.

이때 내적이 음수인 데이터는 기준 방향의 반대쪽에 놓이게 해야 해.

96\~99초: 중심화된 데이터라는 조건을 다시 보여준다.

\\[ \frac1n\sum_i x_i=0 \\]

따라서 같은 방향과의 내적값 평균도 0이야.

\\[ \frac1n\sum_i(x_i\cdot u)=0 \\]

99\~106초: 내적값들을 원점을 기준으로 제곱해 평균을 구하면 투영 분산이 된다는 사실을 보여준다.

\\[ \boxed{ \operatorname{Var}(x\cdot u) =\frac1n\sum_i(x_i\cdot u)^2 } \\]

개념도: 정사영된 데이터의 위치를 부호 있는 스칼라 좌표로 나타낸다. 실제 영상에서는 중심화된 데이터의 내적값을 사용해야 한다.

여기서 단순히 점들이 넓게 퍼져 있는 모습을 보여주는 것만으로 끝내지 말고, 내적으로 측정한 수치들의 제곱 평균이 분산이라는 것을 연결해야 해.

## Scene 09. PCA의 핵심 원리 완성 (106\~114초)

106\~111초: 앞서 등장했던 두 목적을 좌우로 표시한다.

손실 최소화

\\[ \min E(u) \\]

재구성 오차

보존 최대화

\\[ \max\operatorname{Var}(x\cdot u) \\]

투영 분산

이 두 목적 사이에 등호 또는 양방향 연결 표시를 등장시켜.

111\~114초: 데이터 점들이 가장 길게 분포한 방향으로 초록색 직선이 회전한다. 해당 방향에서 보라색 잔차들의 제곱합은 최소가 되고 내적값들의 분산은 최대가 된다.

화면 중앙에 다음 명칭을 표시한다.

주성분 분석 — Principal Component Analysis (PCA)

여기서 PCA의 목적을 확정한 뒤, 다음 장면에서는 그 방향을 실제로 어떻게 계산할 것인지로 넘어가면 돼.

## Scene 10. 최적의 방향은 어떻게 계산할까? (114\~129초)

114\~117초: 초록색 기준 방향을 여러 각도로 회전시킨다. 각도마다 투영 분산이 달라지는 모습을 보여준다.

117\~123초: 데이터 점들이 공분산행렬이라는 하나의 행렬로 요약되는 장면을 표현한다.

\\[ \Sigma=\frac1n\sum_i x_ix_i^T \\]

그다음 선택한 단위벡터 \\(u\\)에 대해 다음 식을 보여준다.

\\[ \operatorname{Var}(x\cdot u)=u^T\Sigma u \\]

123\~129초: 가장 큰 분산을 만드는 방향이 공분산행렬의 가장 큰 고윳값에 대응하는 고유벡터라는 결론을 보여준다.

PCA의 최적화 문제

\\[ \max\_{\\|u\\|=1}u^T\Sigma u \\]

최적 방향

\\[ \boxed{\Sigma u_1=\lambda\_{\max}u_1} \\]

첫 번째 주성분(First Principal Component)

여기서는 고윳값을 직접 계산하는 긴 과정보다, 공분산행렬의 고유벡터가 데이터의 최적 투영 방향과 연결된다는 사실만 전달하면 충분해.

또한 가장 큰 고윳값이 중복되는 경우 첫 번째 주성분 방향이 유일하지 않을 수 있으므로, 영상에서는 하나의 뚜렷하게 긴 데이터 분포를 사용하자.

## Scene 11. 최소제곱과 PCA의 차이 (129\~141초)

앞선 LEVEL 06과 직접 연결되는 장면이야.

129\~131초: 방금 구한 최적 방향에 `첫 번째 주성분`이라는 이름을 표시한다.

131\~137초: LEVEL 06에서 다룬 3차원 평면과 목표 벡터를 다시 보여준다.

## 4. 실제 제작용 계산 및 애니메이션 규칙

이번 편은 모든 점의 정사영과 잔차를 실시간으로 갱신해야 하므로, 시각화에 사용하는 수학적 계산이 일관되어야 해.

| 요소        | 계산 기준                               |
| --------- | ----------------------------------- |
| 데이터 중심화   | \\(\tilde x_i=x_i-\bar x\\)         |
| 기준 단위벡터   | \\(u=(\cos\theta,\sin\theta)\\)     |
| 내적 좌표     | \\(c_i=\tilde x_i^Tu\\)             |
| 정사영       | \\(p_i=c_i u\\)                     |
| 잔차        | \\(r_i=\tilde x_i-p_i\\)            |
| 재구성 오차    | \\(E(\theta)=\sum_i\\\|r_i\\\|^2\\) |
| 보존 성분 제곱합 | \\(V(\theta)=\sum_i c_i^2\\)        |
| 전체 제곱합    | \\(T=\sum_i\\\|\tilde x_i\\\|^2\\)  |
| 검증 조건     | \\(E(\theta)+V(\theta)=T\\)         |

모든 방향에서 마지막 관계가 성립해야 해. 즉, 기준 방향을 아무리 회전시켜도 전체 제곱합은 일정해야 하지.

## 5. 이번 영상에서 가장 중요한 연출

첫 번째 핵심 — 63\~79초: 피타고라스 관계

정사영과 잔차가 직교하는 모습을 보여주고, 원래 크기 제곱이 두 성분의 제곱합으로 분리된다는 사실을 설명한다.

두 번째 핵심 — 79\~111초: 최소화와 최대화의 연결

데이터의 투영 방향을 바꾸면 재구성 오차는 작아지고, 보존된 성분의 제곱합은 커진다. 이 제곱합이 중심화된 데이터의 투영 분산과 연결된다는 사실까지 보여준다.

세 번째 핵심 — 114\~129초: 공분산행렬의 고유벡터

내적과 정사영으로 정의한 최적화 문제의 답이 공분산행렬의 고유벡터라는 것을 보여준다.

이 중 가장 시간을 들여 제작할 부분은 79\~111초야.

단순히 초록색 직선을 회전시키는 데서 그치지 않고, 화면 한쪽에 재구성 오차와 보존된 성분의 제곱합을 동시에 표시하면 좋아. 한 값이 줄어드는 만큼 다른 값이 늘어나고, 두 값의 합은 항상 일정하다는 사실을 보여주는 거지.

그다음 중심화된 데이터에서는 보존 성분의 제곱합이 투영 분산과 연결된다는 사실을 설명하면, 시청자가 PCA의 목적함수를 자연스럽게 이해할 수 있어.

이번 LEVEL 07은 “가장 좋은 방향은 무엇인가?”라는 질문에 내적, 정사영, 직교성, 피타고라스 정리로 답하는 영상이 되어야 해. 이 구조를 유지하면 다음 LEVEL 08의 SVD로도 자연스럽게 이어질 수 있어.

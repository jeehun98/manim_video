# 원환면을 펼친 보편피복

주장: 평면의 두 독립 이동이 원환면을 감아 돈 횟수를 기록한다.

사용자 확정 대본·문장 종료 시각. 153–178초, 25초, 750프레임. TTS 미제공, 무음.

16:9 1920×1080 30fps. 본문 y ≥ -2.6, 전체 내레이션 자막 별도 하단 영역. 화면 경계와 자막 영역 매 프레임 검사.

- 153–157초: 원환면에서는 한 방향으로 한 바퀴 돌면 출발점에 도착합니다.

- 157–160초: 하지만 펼친 평면에서는 옆의 직사각형에 도착합니다.

- 160–166초: 같은 위치로 돌아온 것으로 처리했던 움직임이, 펼친 공간에서는 다른 복사본으로 이동한 것으로 나타납니다.

- 166–170초: 앞서 제곱근을 위해 두 겹을 구분했던 것과 비슷한 발상입니다.

- 170–175초: 이번에는 가로와 세로로 몇 번 감아 돌았는지가 펼친 평면의 위치에 반영됩니다.

- 175–178초: 이 평면이 원환면의 보편피복공간입니다.

수학 조건: 연결 리만 곡면, 가역 정칙 동치. 두 겹은 절단선 교차 연결 개념도이며 원점의 실제 좌표는 w. 원환면 3D 임베딩은 위상 설명이며 유클리드 등거리·등각 임베딩 주장이 아님. 원판 변환은 실제 Cayley 변환의 유한 뷰포트.

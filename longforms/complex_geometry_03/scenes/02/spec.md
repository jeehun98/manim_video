# 입력의 회전과 제곱근

주장: 연속적으로 선택한 제곱근의 회전각은 입력의 절반이다.

사용자 확정 대본·문장 종료 시각. 11–23초, 12초, 360프레임. TTS 미제공, 무음.

16:9 1920×1080 30fps. 본문 y ≥ -2.6, 전체 내레이션 자막 별도 하단 영역. 화면 경계와 자막 영역 매 프레임 검사.

- 11–15초: 입력값 1에서 출발하고, 그 제곱근으로는 1을 선택합니다.

- 15–20초: 이제 입력을 원점을 중심으로 회전시키면서 제곱근도 끊기지 않게 따라가 보겠습니다.

- 20–23초: 입력이 90도 회전하면 제곱근은 45도 회전합니다.

수학 조건: 연결 리만 곡면, 가역 정칙 동치. 두 겹은 절단선 교차 연결 개념도이며 원점의 실제 좌표는 w. 원환면 3D 임베딩은 위상 설명이며 유클리드 등거리·등각 임베딩 주장이 아님. 원판 변환은 실제 Cayley 변환의 유한 뷰포트.

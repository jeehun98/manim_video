# 원점에서는 w를 좌표로

주장: S={(z,w):z=w²}는 w 좌표에서 매끄럽고 F(w)=w는 정칙이다.

사용자 확정 대본·문장 종료 시각. 77–104초, 27초, 810프레임. TTS 미제공, 무음.

16:9 1920×1080 30fps. 본문 y ≥ -2.6, 전체 내레이션 자막 별도 하단 영역. 화면 경계와 자막 영역 매 프레임 검사.

- 77–82초: 두 겹을 연결할 때도 각 점 주변에서는 복소좌표를 사용할 수 있도록 만듭니다.

- 82–91초: 두 겹이 만나는 원점에서는 기존의 입력값 대신 제곱근의 값 자체를 좌표로 사용하면, 주변을 다시 하나의 복소평면처럼 표현할 수 있습니다.

- 91–98초: 그 결과 새롭게 만들어진 공간 위에서는 제곱근을 각 점에 하나의 값이 대응하는 정칙함수로 다룰 수 있습니다.

- 98–104초: 이처럼 수학에서는 함수의 규칙을 바꾸는 대신, 함수가 정의되는 공간을 바꾸어 문제를 해결하기도 합니다.

수학 조건: 연결 리만 곡면, 가역 정칙 동치. 두 겹은 절단선 교차 연결 개념도이며 원점의 실제 좌표는 w. 원환면 3D 임베딩은 위상 설명이며 유클리드 등거리·등각 임베딩 주장이 아님. 원판 변환은 실제 Cayley 변환의 유한 뷰포트.

# 직사각형에서 원환면으로

주장: 반대 변의 연결과 평면의 반복 타일은 같은 연결 규칙을 설명한다.

사용자 확정 대본·문장 종료 시각. 129–153초, 24초, 720프레임. TTS 미제공, 무음.

16:9 1920×1080 30fps. 본문 y ≥ -2.6, 전체 내레이션 자막 별도 하단 영역. 화면 경계와 자막 영역 매 프레임 검사.

- 129–131초: 하나의 직사각형을 생각해 보겠습니다.

- 131–138초: 왼쪽과 오른쪽 변을 연결하고, 남은 두 변도 서로 연결하면 도넛 모양의 원환면을 얻습니다.

- 138–143초: 이 연결은 한쪽 변을 넘어가면 반대쪽 변으로 이어지는 규칙으로 생각할 수도 있습니다.

- 143–149초: 이번에는 반대쪽으로 되돌아오게 하는 대신, 바로 옆에 같은 직사각형을 하나 더 놓아 보겠습니다.

- 149–153초: 가로와 세로 방향으로 이 작업을 끝없이 반복하면 평면을 채울 수 있습니다.

수학 조건: 연결 리만 곡면, 가역 정칙 동치. 두 겹은 절단선 교차 연결 개념도이며 원점의 실제 좌표는 w. 원환면 3D 임베딩은 위상 설명이며 유클리드 등거리·등각 임베딩 주장이 아님. 원판 변환은 실제 Cayley 변환의 유한 뷰포트.

# 한 바퀴로는 돌아오지 않는다

주장: 입력은 한 바퀴, 제곱근은 두 바퀴의 입력 후 돌아온다.

사용자 확정 대본·문장 종료 시각. 23–44초, 21초, 630프레임. TTS 미제공, 무음.

16:9 1920×1080 30fps. 본문 y ≥ -2.6, 전체 내레이션 자막 별도 하단 영역. 화면 경계와 자막 영역 매 프레임 검사.

- 23–29초: 복소수를 제곱하면 회전 각도가 두 배가 되므로, 제곱근의 회전은 입력의 절반인 것입니다.

- 29–35초: 입력이 한 바퀴를 돌아 다시 1에 도착했을 때, 제곱근은 반 바퀴만 돌아 마이너스 1에 도착합니다.

- 35–41초: 입력은 출발점으로 돌아왔는데, 연속적으로 따라간 제곱근은 다른 값에 도착했습니다.

- 41–44초: 입력을 한 바퀴 더 돌려야 제곱근도 처음의 값으로 돌아옵니다.

수학 조건: 연결 리만 곡면, 가역 정칙 동치. 두 겹은 절단선 교차 연결 개념도이며 원점의 실제 좌표는 w. 원환면 3D 임베딩은 위상 설명이며 유클리드 등거리·등각 임베딩 주장이 아님. 원판 변환은 실제 Cayley 변환의 유한 뷰포트.

# 출처와 확인 기준

확인: 2026-10-08. 논문 관찰과 설명용 수치 모형을 구별한다. 실제 선형 모형의 궤적과 특잇값을 계산한다. 유체 리프트업과 RNN 그림은 선형화 구조의 개념 비교이며 실제 전체 NS 해나 대형 모델의 측정값이 아니다.

- Dettmers et al. (2022), LLM.int8(): https://arxiv.org/abs/2208.07339

# EP.03 제작 기준

사용자 확정 28문장과 종료 시각을 보존한다. 총 155초, 20개 독립 씬, 60fps 9,300프레임. 가로 1920×1080과 세로 1080×1920을 같은 로직과 각각의 배치로 제작한다. 음원 미제공으로 무음이며 전체 내레이션 자막을 넣는다. ‘연우’는 화자 표기로 취급하여 읽을 본문에서 제외한다. 사용자 도입 복습 문장은 유지하고 추가 복습·편 순서·다음 편 타이틀은 넣지 않는다.

핵심은 입력→양자 알고리즘→YES 확률 p(x)와 일부 비트 조회→고전 근삿값의 관계다. 양자 조회는 Uₓ|i,b⟩=|i,b XOR xᵢ⟩의 선형 작용으로, 모든 비트를 한 번에 읽어낸다고 표현하지 않는다. 고정 시드의 균등 독립 비트를 격자 예시로 재사용한다.

근사는 알고리즘을 알고 입력 x에 대한 조회만 세는 모델이다. 균등 분포에서 1−δ 이상의 입력에 대해 |p̃(x)−p(x)|≤ε를 달성하는 문제이며, 조회 횟수는 poly(T,1/ε,1/δ). ε와 δ를 고정하면 poly(T)이다. 양자 내부 상태의 재현, 모든 입력에 대한 정확한 예측, 총 실행시간의 다항 상한을 주장하지 않는다. 임의의 몇 비트를 읽으면 된다는 뜻도 아니다.

확률 .70/.30, .40/.60, 근삿값 .68과 색 카드 비율은 콘티가 지정한 개념 예시이며 실제 회로나 정리의 수치 보장이 아니다. T²,2ᵀ 비교도 성장의 설명용이다. 다항식 차수≤2T는 내부 모델에 준비하되 본편에서 강조하지 않는다.

서사는 2008년 추측 제안과 그 조건부 귀결에서 출발한다. 원논문 arXiv 공개는 2009년, 저널판은 2014년이다. ‘오랫동안 증명되지 않았다’는 과거 서술을 보존하되 현재도 미해결이라고 표시하지 않는다. 연구자 직함은 화면에서 덧붙이지 않는다. 사용자 원문의 ‘물리학자’는 확정 내레이션 그대로이며 두 연구자의 주 전공은 이론 컴퓨터과학이다.

자료: [Aaronson–Ambainis 원논문](https://arxiv.org/abs/0911.0996), [2026년 연구 발표의 수학 설명](https://psi.inc/research/aaronson-ambainis/). 본편은 발표의 증명을 설명하거나 독립 검증했다고 주장하지 않는다.

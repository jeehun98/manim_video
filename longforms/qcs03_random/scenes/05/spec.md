# 05 · 고전 조회: 특정 위치의 비트

## 목적과 주장

고전 조회: 특정 위치의 비트를 도형과 수식으로 설명한다.

## 확정 대본·길이

26–31초, 300프레임. 문장 경계와 겹치는 원문은 아래와 같으며 실제 자막 시각은 timing.json을 따른다.

일반적인 컴퓨터는 데이터를 확인할 때 특정 위치의 비트를 읽습니다.

## 화면·연산·정확성

위치 i를 선택해 x_i 한 값을 읽는 조회.

## 연결

앞 장면: 수많은 비트로 이루어진 입력. 다음: 양자 조회: 중첩된 위치에 연산. direction.py의 s05가 독립 렌더 진입점이다. 하단에는 내레이션 자막을 유지한다.

# 16 · 출력 확률을 다항식으로 바라보다

## 목적과 주장

출력 확률을 다항식으로 바라보다를 도형과 수식으로 설명한다.

## 확정 대본·길이

119–125초, 360프레임. 문장 경계와 겹치는 원문은 아래와 같으며 실제 자막 시각은 timing.json을 따른다.

아론슨과 암바이니스는 이러한 가능성을 낮은 차수의 다항식에 관한 수학적 추측과 연결했습니다.

## 화면·연산·정확성

p(x)∈[0,1]인 Boolean cube 다항식. 차수≤2T는 모델 내부 검증만, 다음 내용 선행 강조 금지.

## 연결

앞 장면: 입력 대부분과 작은 오차. 다음: 추측이 성립한다면 가능한 근사. direction.py의 s16가 독립 렌더 진입점이다. 하단에는 내레이션 자막을 유지한다.

# 07 · 입력이 무작위라면?

## 목적과 주장

입력이 무작위라면?를 도형과 수식으로 설명한다.

## 확정 대본·길이

41–52초, 660프레임. 문장 경계와 겹치는 원문은 아래와 같으며 실제 자막 시각은 timing.json을 따른다.

그런데 입력 데이터가 무작위로 주어진다면 어떨까요?

특정한 반복이나 규칙을 기대하기 어려운 상황에서도 양자컴퓨터는 지수적으로 적은 조회만으로 문제를 해결할 수 있을까요?

## 화면·연산·정확성

균등 무작위 입력 조건, 지수 가속은 질문으로만 제시.

## 연결

앞 장면: 양자 조회: 중첩된 위치에 연산. 다음: 계산의 속도에서 예측의 문제로. direction.py의 s07가 독립 렌더 진입점이다. 하단에는 내레이션 자막을 유지한다.

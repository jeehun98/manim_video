# 제작 기준

질문: 레지스터에없는숫자는어떻게계산할까? 결론: 데이터메모리읽기→쓰기MUX→레지스터→ALU→레지스터→Store경로를추가하면외부데이터를계산하고보관할수있다.

사용자37문장종료시각으로174초를고정한다. 14개독립씬. 9:16과16:9는공유된동작로직과별도배치·크기로렌더하고늘리거나자르지않는다. 제공음원이없어무음이다.

핵심57–93초는기존ALU결과와새메모리읽기결과를직접합치지않고서로다른MUX입력으로연결한다. 선택·목적지·쓰기허용은각각별개다. 109–132초Load/Store의방향및RegWE와MemWE를구별한다.132–143초네명령을차례로실행한다.153초이후Ready=0이면R1갱신을막고주소·목적지·동작정보를유지한다.

초록레지스터,파랑ALU,보라데이터메모리,주황주소·제어. 단일자막객체를문장경계에서교체하고전용하단영역을확보한다. 마지막예고타이틀·추가복습은넣지않는다.

# GPU 계층 구조 LEVEL 03 — Block

사용자 확정 원문·39개 문장 종료 시각 기준 178초.

### 0–5초

GPU에서는 32개의 스레드가 하나의 워프로 묶여 명령을 실행합니다.

### 5–10초

그렇다면 서로 다른 워프에 속한 스레드들이 하나의 계산을 함께 수행하려면 어떻게 해야 할까요?

### 10–12초

여기서 등장하는 것이 블록입니다.

### 12–17초

블록은 여러 스레드를 하나의 그룹으로 묶는 논리적인 실행 단위입니다.

### 17–19초

하나의 블록을 살펴보겠습니다.

### 19–23초

이번에는 128개의 스레드로 구성된 블록을 생각해 보겠습니다.

### 23–28초

워프 하나는 32개의 스레드로 구성되므로, 이 블록에는 네 개의 워프가 포함됩니다.

### 28–34초

블록의 크기는 쿠다 커널을 실행할 때 지정할 수 있으며, 반드시 128개의 스레드로 구성되어야 하는 것은 아닙니다.

### 34–38초

그렇다면 스레드들을 하나의 블록으로 묶으면 무엇이 가능해질까요?

### 38–43초

가장 중요한 특징 중 하나는 데이터를 공유하고 실행을 동기화할 수 있다는 것입니다.

### 43–45초

간단한 계산을 살펴보겠습니다.

### 45–48초

128개의 숫자를 모두 더하려고 합니다.

### 48–51초

각 스레드가 숫자 하나씩을 읽는 것은 어렵지 않습니다.

### 51–56초

하지만 최종 합계 하나를 만들려면 서로 다른 스레드가 읽어온 값들을 합쳐야 합니다.

### 56–60초

이때 사용할 수 있는 것이 공유, Shared Memory입니다.

### 60–62초

실제 쿠다 코드를 살펴보겠습니다.

### 62–67초

셰어드 로 선언한 배열은 같은 블록에 속한 스레드들이 함께 사용할 수 있는 메모리 공간입니다.

### 67–73초

각 스레드는 자신의 인덱스를 이용해 입력값을 읽고, 공유 메모리의 서로 다른 위치에 저장합니다.

### 73–77초

이제 공유 메모리에는 128개의 값이 들어갑니다.

### 77–79초

그런데 여기서 문제가 발생합니다.

### 79–83초

모든 스레드가 정확히 같은 순간에 데이터를 기록하는 것은 아닙니다.

### 83–89초

어떤 스레드가 다른 스레드의 값을 읽으려고 할 때, 해당 값이 아직 기록되지 않았을 수도 있습니다.

### 89–92초

이 문제를 해결하기 위해 사용하는 것이 싱크 스레드 입니다.

### 92–97초

이 명령을 만나면 같은 블록의 스레드들은 동기화 지점에 도달할 때까지 기다립니다.

### 97–102초

그리고 동기화 이전의 메모리 기록을 다른 스레드들이 올바르게 확인할 수 있도록 보장합니다.

### 102–106초

이제 공유 메모리에 저장된 값들을 합쳐 보겠습니다.

### 106–108초

처음에는 128개의 값이 있습니다.

### 108–115초

스레드 0부터 63까지가 각각 다른 위치의 값을 더하면, 64개의 부분 합계가 만들어집니다.

### 115–119초

다음 단계에서는 32개, 그다음에는 16개로 줄어듭니다.

### 119–123초

이 과정을 반복하면 마지막에는 하나의 합계가 남습니다.

### 123–127초

이처럼 여러 값을 단계적으로 하나로 합치는 연산을 리덕션이라고 합니다.

### 127–135초

여기서 주목할 점은 서로 다른 워프에 속한 스레드들이 같은 공유 메모리를 사용해 하나의 결과를 만들었다는 사실입니다.

### 135–139초

그렇다면 블록은 실제 GPU 하드웨어에서 어디에 배치될까요?

### 139–143초

쿠다의 블록은 실행될 때 하나의 에스엠에 배치됩니다.

### 143–148초

같은 블록의 워프들은 해당 에스엠의 실행 자원과 공유 메모리를 사용합니다.

### 148–152초

다만 일반적인 블록 내부 동기화 명령은 서로 다른 블록까지 동기화하지는 않습니다.

### 152–158초

즉, 블록은 내부적으로 협력할 수 있지만, 다른 블록과는 기본적으로 독립적인 실행 그룹입니다.

### 158–169초

결국 스레드는 각자의 명령과 데이터를 처리하고, 워프는 32개의 스레드를 묶어 명령을 실행하며, 블록은 여러 스레드가 데이터를 공유하고 동기화하며 협력할 수 있는 단위입니다.

### 169–178초

GPU의 병렬 계산은 단순히 많은 스레드를 실행하는 것뿐 아니라, 필요한 계산을 위해 이 스레드들이 어떻게 협력하도록 구성되는지도 중요합니다.

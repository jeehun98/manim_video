이번 영상은 두 가지 역할을 수행해야 해.

첫째, 왜 신경망이 기울기의 반대 방향으로 학습하는지 내적만으로 설명하는 것.

영상의 가장 중요한 연출은 기울기 벡터를 고정하고 이동 방향만 회전시키면서, 내적값과 손실 변화율이 함께 달라지는 모습이야.

### 화면의 기본 구성

초반에는 3차원 손실 곡면을 사용하고, 내적을 설명하는 구간부터는 동일한 함수의 2차원 등고선으로 전환하는 것을 추천해.

3차원 곡면은 손실의 높낮이를 이해하기 좋지만, 두 벡터의 각도와 내적을 정확하게 보여주려면 2차원 등고선이 더 효과적이기 때문이야.

고정할 예제

\\[ L(\theta_1,\theta_2)=\theta_1^2+4\theta_2^2 \\]

\\[ \theta=(2,1),\qquad \nabla L=(4,8) \\]

영상 내내 이 함수를 유지하고, 계산에 등장하는 기울기와 등고선을 동일한 함수에서 생성해야 해.

# 3. 구간별 상세 콘티

## Scene 01. 신경망은 어느 방향으로 학습해야 할까? (0\~8초)

0\~4초

화면에 신경망의 간단한 구조가 등장한다. 연결선마다 서로 다른 파라미터 \\(\theta_1,\theta_2,\ldots,\theta_n\\)가 표시된다.

각 파라미터 옆에서 서로 다른 방향을 가리키는 작은 화살표가 등장한다.

중앙 질문:

“어느 방향으로 움직여야 손실이 줄어들까?”

4\~8초

신경망 구조를 파라미터 공간으로 변환한다. 여러 화살표가 하나의 이동 벡터 \\(\Delta\theta\\)로 정리된다.

화면 한편에 `Dot Product`라는 문구와 내적 기호를 잠깐 등장시킨다.

이때 아직 음의 기울기 방향을 보여주지 말고, 이동 방향을 결정해야 한다는 문제만 제시하자.

## Scene 02. 손실함수는 하나의 지형을 만든다 (8\~23초)

8\~12초 — 두 파라미터 소개

수많은 파라미터 대신 두 개의 파라미터를 사용하는 단순화된 예제를 소개한다.

2차원 좌표계의 두 축에 \\(\theta_1,\theta_2\\)를 표시한다.

12\~18초 — 손실함수 등장

\\[ \boxed{L(\theta_1,\theta_2)=\theta_1^2+4\theta_2^2} \\]

수식에서 \\(\theta_1^2\\)와 \\(4\theta_2^2\\)를 순차적으로 강조한다.

18\~23초 — 3차원 곡면으로 전환

평면 위의 위치마다 손실값을 높이로 표현한다. 그 결과 아래가 둥근 그릇 형태의 곡면이 만들어진다.

손실이 낮은 중앙은 청록색, 높은 외곽은 주황색 계열로 표현하면 직관적이야.

곡면의 단면 개념도. 실제 3D 장면에서는 \\(z=\theta_1^2+4\theta_2^2\\)를 렌더링한다.

주의: 영상의 지형이 실제 함수의 결과처럼 보이려면 중심이 원점인 타원형 포물면을 사용해야 해. 두 축의 곡률이 서로 같지 않다는 점도 보여주면 좋아.

## Scene 03. 기울기는 어떻게 만들어질까? (23\~44초)

23\~28초 — 현재 위치 표시

3D 곡면 위에 현재 파라미터 위치 \\((2,1)\\)를 파란색 점으로 표시한다.

화면을 확대하면서 질문을 띄운다.

`현재 위치에서 어느 방향으로 내려갈까?`

28\~32초 — 편미분

손실함수를 각각의 파라미터에 대해 미분한다.

\\[ \frac{\partial L}{\partial\theta_1}=2\theta_1 \\]

\\[ \frac{\partial L}{\partial\theta_2}=8\theta_2 \\]

두 수식이 좌우에 나타난 뒤 하나의 벡터 형태로 결합된다.

32\~37초 — 기울기 정의

\\[ \nabla L= \begin{bmatrix} 2\theta_1\\\ 8\theta_2 \end{bmatrix} \\]

화면에 `Gradient = 각 파라미터 방향의 순간 변화율`이라는 설명을 표시한다.

37\~40초 — 현재 위치에서 계산

\\[ \nabla L(2,1)= \begin{bmatrix}4\\\8\end{bmatrix} \\]

기울기 벡터를 현재 위치에서 주황색 화살표로 그린다.

40\~44초 — 다음 질문으로 전환

3D 곡면을 위에서 내려다보는 장면으로 바꿔서 2D 등고선 화면으로 전환한다.

현재 위치와 기울기 벡터가 그대로 남는다.

화면 중앙에는 다음 질문을 표시한다.

“왜 이 벡터가 학습 방향을 결정할까?”

## Scene 04. 이동 방향과 기울기를 내적한다 (44\~59초)

이번 영상에서 첫 번째로 중요한 장면이야.

44\~45초 — 내적 등장

등고선 위의 현재 위치에 주황색 기울기 벡터 \\(\nabla L=(4,8)\\)를 고정한다.

중앙에 내적 기호를 표시한다.

45\~49초 — 이동 벡터 설정

같은 시작점에서 초록색 이동 벡터 \\(\Delta\theta\\)를 추가한다.

이동 벡터는 처음에는 오른쪽을 향하게 하고, 이후 자유롭게 회전할 수 있도록 만든다.

49\~54초 — 손실 변화의 일차 근사

\\[ \boxed{\Delta L\approx\nabla L\cdot\Delta\theta} \\]

두 벡터를 내적하면 해당 이동에 따른 손실 변화량을 근사할 수 있다는 사실을 설명한다.

54\~59초 — 이동 방향을 회전

기울기는 고정하고 초록색 이동 벡터만 천천히 회전시킨다.

내적값이 양수이면 손실 증가, 음수이면 손실 감소로 표시한다.

이동 방향 회전

이 시연은 크기가 1인 방향벡터에 대한 순간 변화율을 나타낸다. 실제 이동량이 충분히 작을 때 손실 변화량의 일차 근사로 사용된다.

실제 영상에서는 회전 애니메이션을 자동으로 실행하고, 내적값을 실시간으로 갱신하면 돼.

특히 내적의 부호가 바뀌는 순간을 강조하면 시청자가 기울기와 이동 방향의 관계를 쉽게 이해할 수 있어.

## Scene 05. 오른쪽과 왼쪽 이동을 비교한다 (59\~69초)

59\~64초 — 오른쪽 이동

이동 방향을 오른쪽 단위벡터로 설정한다.

\\[ u=(1,0) \\]

\\[ \nabla L\cdot u=(4,8)\cdot(1,0)=4 \\]

결과가 양수이므로 화면에 `손실 증가 방향`이라는 문구를 표시한다.

64\~69초 — 왼쪽 이동

이동 벡터를 반대 방향으로 회전시킨다.

\\[ u=(-1,0) \\]

\\[ \nabla L\cdot u=(4,8)\cdot(-1,0)=-4 \\]

결과가 음수로 바뀐다.

이 장면에서는 실제 위치를 크게 이동시키기보다 현재 위치에서 특정 방향으로 움직이려는 작은 화살표를 보여주는 것이 좋아.

이 수치는 실제로 한 단위 길이를 이동했을 때의 정확한 손실 변화량이 아니라, 그 방향에 대한 순간 변화율이기 때문이야.

## Scene 06. 가장 빠른 감소 방향을 찾는다 (69\~94초)

이번 영상의 핵심 수학적 장면이야.

69\~74초 — 방향 탐색

현재 위치를 중심으로 여러 방향의 초록색 후보 화살표를 원형으로 배열한다.

질문을 표시한다.

“어느 방향에서 내적값이 가장 작을까?”

74\~78초 — 내적의 기하학적 표현

\\[ \nabla L\cdot\Delta\theta =\\|\nabla L\\|\\|\Delta\theta\\|\cos\phi \\]

주황색 기울기 벡터와 초록색 이동 벡터 사이에 각도 \\(\phi\\)를 표시한다.

78\~83초 — 같은 이동 거리라는 제약

모든 후보 이동 벡터의 길이를 동일하게 만든다.

화면에 다음 조건을 표시한다.

\\[ \\|\Delta\theta\\|=\varepsilon \\]

87\~91초 — 코사인 최솟값

\\(\cos\phi=-1\\)이 되는 순간을 강조한다.

이때 두 벡터가 서로 반대 방향을 향한다.

91\~94초 — 최적 방향 확정

기울기의 반대 방향에 있는 초록색 벡터만 남기고 나머지 후보를 사라지게 한다.

\\[ \boxed{u\_{\min}=-\frac{\nabla L}{\\|\nabla L\\|}} \\]

이 장면의 핵심은 음의 기울기 방향을 먼저 외워서 사용하는 것이 아니라, 내적을 가장 작게 만드는 방향을 찾았더니 그 결과가 음의 기울기였다는 순서야.

# 6. 영상 제작 시 계산 검증 사항

| 항목           | 정확한 값                          |
| ------------ | ------------------------------ |
| 손실함수         | \\(L=\theta_1^2+4\theta_2^2\\) |
| 현재 파라미터      | \\((2,1)\\)                    |
| 현재 기울기       | \\((4,8)\\)                    |
| 기울기 크기       | \\(\sqrt{80}=4\sqrt5\\)        |
| 최적 단위 감소 방향  | \\((-1/\sqrt5,-2/\sqrt5)\\)    |
| 학습률 0.1 업데이트 | \\((1.6,0.2)\\)                |
| 업데이트 전 손실    | \\(8\\)                        |
| 업데이트 후 손실    | \\(2.72\\)                     |
| 학습률 0.4 업데이트 | \\((0.4,-2.2)\\)               |
| 학습률 0.4 손실   | \\(19.52\\)                    |

특히 다음 세 가지는 정확하게 구현해야 해.

1. 2D 등고선은 실제 손실함수에서 생성해야 한다. \\(\theta_2\\) 방향의 계수가 더 크므로 등고선은 \\(\theta_2\\) 축 방향으로 더 좁은 타원이 되어야 해.
2. 기울기는 현재 위치에 고정하고 이동 방향을 회전시켜야 한다. 방향별 내적값의 변화가 무엇을 의미하는지 분명하게 보여줄 수 있어.
3. 음의 기울기는 국소적인 최적 감소 방향이다. 큰 이동에서도 항상 손실이 감소한다는 표현은 피해야 해.

## 7. 이번 영상에서 가장 중요한 연출

가장 공들여야 할 부분은 69\~94초의 방향 탐색 장면이야.

기울기 벡터는 움직이지 않고, 이동 방향 벡터만 회전하는데 내적값이 변하는 모습을 보여주자.

그 결과 가장 작은 내적값을 갖는 방향이 기울기와 정확히 반대라는 사실을 발견하게 만들면 돼.

그 이후 실제 경사하강법 공식은 이미 이해한 원리의 자연스러운 결과로 등장하게 되지.

그리고 마지막 40초 동안 이전 LEVEL들의 장면을 회수하면, 이번 10편은 단순한 경사하강법 소개가 아니라 내적 하나에서 출발한 수학적 구조들이 어떻게 연결되는지 보여주는 시리즈의 결론으로 완성될 수 있어.

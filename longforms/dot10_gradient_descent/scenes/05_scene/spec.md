# 05 — 같은 위치 · 오른쪽과 왼쪽

## 목적과 핵심 주장
단위방향(1,0)의순간변화율4,(-1,0)은−4다.

## 앞 장면에서 받은 내용
작은 δ에 대해 ΔL≈∇L·δ이고 δ=εu이다.

## TTS와 확정 길이
사용자제공59–69초,10초. 음원미제공.

예를 들어 오른쪽으로 이동하면 내적값은 양수가 되어 손실이 증가하는 방향입니다.
반대로 왼쪽으로 이동하면 내적값은 음수가 되어 손실이 감소하는 방향입니다.

## 화면 구성
같은L의3D곡면과2D등고선. 고정θ와기울기·회전단위방향. 세로도형위·수식아래,가로도형왼쪽·수식오른쪽. 파랑현재점,주황기울기,초록이동,보라손실변화. 자막영역별도.

## 구간별 애니메이션·텍스트
59–64초오른쪽u와+4. 64–69초왼쪽으로회전해−4. θ=(2,1)과기울기고정,실제위치이동없음.

## 시작·종료 상태와 다음 연결
고정된유클리드길이에서음의기울기가일차변화를최소화한다.

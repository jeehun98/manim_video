# 01 · 어디까지 줄여도 살아 있을까?

## 목적·핵심 주장
블록은 실제 물리적 배치가 아닌 유전체 구성 개념도. 수십 개만 대표 표시하며 인체 유전체를 473개로 줄였다는 뜻이 아님.

## 앞 장면에서 받은 내용
절대 시각 0초의 설명을 이어받으며 독립 교체 가능.

## TTS 원문·확정 길이
생명체에서 유전자를 하나씩 제거한다면, 어디까지 줄여도 살아 있을 수 있을까요? 우리 몸의 세포는 수많은 유전자의 작용으로 유지됩니다. 그런데 생명체가 살아가는 데 이 모든 유전자가 반드시 필요한 것은 아닙니다.

구간 0–12초, 12초. 사용자 문장 종료 시각 기준. 음원 없음.

## 화면·애니메이션
0–4초 세포와 30개 대표 블록 등장; 4–8초 일부 선택; 8–12초 제거 후 생존 윤곽 유지.

세로/가로 별도 배치. scene_engine.py part_00에서 구현.

## 화면 텍스트
어디까지 줄여도 살아 있을까?. 개념 모델/실제 연구 구분, 유전자 블록은 추상화.

## 시작·종료 상태와 연결
해당 주장의 대상을 관찰한 뒤 결과 상태로 종료. 다음 씬은 사용자 발화 시각에 시작하며 예고 문구 없음.

# 03 · 설계한 유전체를 세포에

## 목적·핵심 주장
기존 세균 유전체의 설계·합성과 수용 세포로의 도입을 구분. 세포 전체를 무에서 만든 것이 아님.

## 앞 장면에서 받은 내용
절대 시각 21초의 설명을 이어받으며 독립 교체 가능.

## TTS 원문·확정 길이
연구진은 기존 세균의 유전체를 바탕으로 유전자를 제거하고 재설계한 뒤, 합성 유전체를 세포에 도입했습니다.

구간 21–28초, 7초. 사용자 문장 종료 시각 기준. 음원 없음.

## 화면·애니메이션
21–25초 기존 유전체→재설계→합성; 25–28초 합성 유전체가 수용 세포로 이동.

세로/가로 별도 배치. scene_engine.py part_02에서 구현.

## 화면 텍스트
설계한 유전체를 세포에. 개념 모델/실제 연구 구분, 유전자 블록은 추상화.

## 시작·종료 상태와 연결
해당 주장의 대상을 관찰한 뒤 결과 상태로 종료. 다음 씬은 사용자 발화 시각에 시작하며 예고 문구 없음.

## 정확성 확인
기존 세균 유전체의 설계·합성과 수용 세포로의 도입을 구분. 세포 전체를 무에서 만든 것이 아님.

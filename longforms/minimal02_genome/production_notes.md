# 제작·검토 기록

## 확정 입력

총 164초, 33문장. 사용자가 제공한 원문과 문장 종료 시각을 그대로 적용했다. 편집 목표 길이나 글자 수로 타이밍을 추정하지 않았다. 이전 ETH·최소 표현 대본과 분리된 새 에피소드다. 음원 미제공으로 무음 제작한다.

## 과학적 구분

1. 2016년 JCVI-syn3.0의 473개 유전자와 149개 기능 미해명은 실제 발표 수치다.
2. 기능 보완 A/B, 환경 공급 비교, 연결망은 설명용 개념 모델이다.
3. 합성 유전체를 수용 세포에 도입하는 장면은 세포 전체를 무에서 만드는 과정이 아니다.
4. JCVI-syn3A의 분열 특성 개선은 2021년 Cell 논문을 근거로 하며 형태만 개념적으로 비교한다.
5. 확인된 축소 유전체와 전역적 최소성의 증명을 구분한다. 현재 최소 기록이라는 주장은 하지 않는다.

## 시각 검토와 수정

세로·가로 미리보기 각 20개 표본 프레임을 검토했다. 세로 설계 단계의 첫 카드가 조건 표시와 가까운 부분을 낮췄다. 기능 상실 장면은 사각형 전체를 빨강으로 채우지 않고 윤곽·글자만 빨강으로 바꿔 읽을 수 있게 했다. 최종 결론의 세 화살표는 관계·환경·기능의 색으로 표시한다. 가로판은 유전자 배열과 분열 조건 카드의 상단 여백을 확보했다.

1편에서 발견된 자막 캐시 문제를 방지하기 위해 Manim 씬에는 전체 발화 자막 객체를 만들지 않는다. 모든 씬을 concat한 다음 단일 ASS 트랙으로 합성하고 문장 경계 프레임을 기준 영상과 비교한다.

## 확인 대상

- 33문장의 시간 연속성 및 총 164초
- 17개 독립 씬의 길이 합과 30fps 기준 최종 4,920프레임
- 473칸 중 149칸 강조, 비율 149/473≈31.5%
- 가상 기능 보완 모델의 네 조건: 원본·A만 제거·B만 제거는 생존, A+B 제거는 생존 불가
- 모든 문장 시작 시각의 직전·정각·직후와 마지막 프레임: 화면비별 99프레임
- 두 파일의 전체 디코딩과 주요 장면의 최종 화면 검토

최종 수치 결과는 `verification_final.json`과 `caption_boundary_verification_shorts.json`, `caption_boundary_verification_longform.json`에 기록한다. 시각 검토 이미지는 Git 제외 경로 `media/minimal02_review/`, `media/minimal02_caption_verify/`에 둔다.

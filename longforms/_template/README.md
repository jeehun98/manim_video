## 학습 목표

시청자가 영상이 끝난 뒤 이해하거나 설명할 수 있어야 하는 내용을 적는다.

## 핵심 결론

영상 전체가 도달할 한 문장을 적는다.

## 작업 순서

1. `master_script.md` 확정
2. `scenes.yaml`과 씬별 `spec.md` 작성
3. 씬별 `script.txt`로 TTS 생성 및 길이 기록
4. 씬별 Manim 렌더
5. 씬별 음성 결합
6. 전체 결합과 자막 검수

## 실행

자동화가 구현되면 실제 명령을 여기에 기록한다. 구현되지 않은 명령을 미리 적지 않는다.

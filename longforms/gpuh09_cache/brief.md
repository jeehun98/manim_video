# 제작 기준

169초 · 가로1920×1080/세로1080×1920 · 30fps · 무음·전체 자막. 사용자 대본과 문장 종료시각 확정. 명시 제공된 도입 유지, 추가 복습과 예고 없음.

Global은 논리 주소 공간이며 데이터가 캐시에 복사될 수 있다. L1/L2는 별도 CUDA 주소 공간이 아니다. Register는 스레드별 계산 자원, Shared는 Block별 명시적 공유 공간이다. 일부 GPU의 Unified L1/Shared는 물리 자원 공유이며 주소 공간의 통합이나 자동 Shared↔L1 복사가 아니다. 25/75·50/50·75/25는 개념 비율이며 실제 지원 구성이 아니다. 캐시 상태와 경로는 독립적으로 가정한 설명용 사례, 측정된 Hit/Miss·레이턴시·프로파일러 결과가 아니다. 일반 C++ Load가 항상 L1을 사용한다고 보장하지 않는다. L1 bypass는 별도 __ldcg 정책 예제이며 원래 코드가 바뀌지 않고 정책을 지정한 것처럼 보이지 않게 구분한다. L2 SM간 재사용은 입력에 쓰기가 없는 상태와 데이터 잔류를 가정하며 SM간 동기화나 직접 L1 공유를 뜻하지 않는다.

실제 CUDA readArray와sharedRead및__ldcg예제의값만GPU검증한다. 캐시애니메이션은명시적상태모형이며 실제GPU상태추적이아니다. A[i]=i+1,선택A5=6,B5=12. L1 Hit는L2/DRAM미접근, L2 Hit는DRAM미접근, bypass는L1미접근. 요청은주황/값은초록, Shared청록/Register보라/Global황금/L1파랑/L2진한파랑.

# 07 이전 자리의 올림수가 있다면?

목적·주장: 11₂+01₂에서는 이전 자리 올림수가 다음 자리 입력이다.

## 확정 대본·길이
54–62초, 8초. 사용자 문장 종료 시각 기준.

하지만 여러 자리의 숫자를 더하려면 이전 자리에서 발생한 올림수까지 고려해야 합니다.

예를 들어 이진수 11과 01을 더해 보겠습니다.

## 화면·타임라인

- 59–62초: 예를 들어 이진수 11과 01을 더해 보겠습니다.

scene_engine.py의 columns 메서드. 원본 콘티는 ../../storyboard_reference.md. 시작은 앞 씬의 결과이며 종료는 위 주장으로 완결한다. 가로는 넓은 비교, 세로는 중앙 세로 배치. 하단 전체 문장 자막은 하나씩 즉시 교체한다.

## 계산·표현 조건
LSB는 오른쪽. 합은 초록, 올림수는 주황. 반가산기 S=A XOR B,C=A AND B. 전가산기는 두 HA와 OR의 독립 입력. 11₂+01₂=100₂, 1111₂+0001₂=10000₂. 리플은 모든 A/B가 먼저 제공된 후 carry의 의존성을 보여준다. CLA는 G/P, 논리항, OR 결합 단계가 필요하며 즉시 출력하지 않는다. 속도는 정성 모형으로 실측 배율을 주장하지 않는다. 면적·에너지가 항상 증가한다는 단정은 하지 않는다. 검증은 check_arithmetic.py.

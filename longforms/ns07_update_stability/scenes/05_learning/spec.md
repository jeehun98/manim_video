# Scene 05 — 신경망에도 비슷한 제한이 있을까?
## 목적과 핵심 주장
신경망에도 비슷한 제한이 있을까?를 한 장면에서 이해시킨다.
## 앞 장면에서 받은 내용
가장 작은 공간 스케일이 전체 계산을 제한한다
## TTS 원문과 확정 길이
이제 신경망의 학습으로 넘어가 보겠습니다.

신경망은 손실을 줄이기 위해 파라미터를 조금씩 수정합니다.

가장 간단한 방법인 그래디언트 디센트에서는 현재 위치의 기울기를 계산하고, 그 반대 방향으로 이동합니다.

이때 한 번에 얼마나 이동할지를 결정하는 값이 학습률입니다.

학습률을 크게 하면 빠르게 움직일 수 있지만, 너무 크면 손실이 줄어들지 않고 진동하거나 발산할 수 있습니다.

그렇다면 적절한 학습률은 무엇이 결정할까요?

- TTS: 사용자 측정 28초
- 화면: 28초. 원래 화면 기준은 32초.
## 화면 구성과 시간대별 애니메이션
손실 등고선 → 기울기 반대 방향 → 두 학습률 궤적
문장 순서대로 timing.json의 ends에 맞춰 cue를 진행한다.
## 화면 텍스트
신경망에도 비슷한 제한이 있을까?, 격자 간격, 시간 눈금, 확산 모드, 손실 등고선, 학습률, 곡률 방향, 반복 배율, 문장 자막. 영문과 숫자 기호는 화면에 원 표기를 쓴다.
## 시작·종료 상태
첫 대상에서 마지막 대상으로 연속 변형한다. 상단 제목과 하단 자막 영역을 확보한다.
## 다음 장면 연결
모든 방향의 손실이 똑같이 변하지 않는다
## 수학 조건·과장 방지
양의 정부호 2D 이차 손실 H=diag(1,12), θ0=(.8,.1), η=.1/.2. GD는 θ←(I−ηH)θ; 8스텝. 실제 신경망 측정 궤적 아님.
모든 단순 모형과 개념도는 실제 NS 해나 신경망의 측정값이 아니다. 실제 해의 정확한 항 수치를 시뮬레이션하지 않는다. 유한 활성 행렬의 이상치를 유체 특이점과 동일시하지 않는다.

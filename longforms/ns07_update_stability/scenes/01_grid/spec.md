# Scene 01 — 실제 유체와 컴퓨터 속 유체는 다르다
## 목적과 핵심 주장
실제 유체와 컴퓨터 속 유체는 다르다를 한 장면에서 이해시킨다.
## 앞 장면에서 받은 내용
6막의 방향별 증폭과 Hessian에 관한 질문
## TTS 원문과 확정 길이
앞에서는 소용돌이가 회전축 방향으로 늘어나면서, 보티시티의 강도가 커질 수 있다는 사실을 살펴봤습니다.

그런데 이번에는 실제 유체가 아니라, 컴퓨터로 계산하는 유체를 생각해 보겠습니다.

나비에 스토크스 방정식은 연속적인 공간과 시간에서 정의됩니다.

하지만 컴퓨터에서는 모든 위치와 모든 순간을 직접 계산할 수 없습니다.

그래서 공간을 작은 격자로 나누고, 시간을 일정한 간격으로 건너뛰며 다음 상태를 계산합니다.

이때 두 가지 간격이 등장합니다.

공간의 간격과 시간의 간격입니다.

- TTS: 사용자 측정 31초
- 화면: 31초. 원래 화면 기준은 32초.
## 화면 구성과 시간대별 애니메이션
연속 흐름 → 공간 격자 → 시간 눈금 → 두 간격
문장 순서대로 timing.json의 ends에 맞춰 cue를 진행한다.
## 화면 텍스트
실제 유체와 컴퓨터 속 유체는 다르다, 격자 간격, 시간 눈금, 확산 모드, 손실 등고선, 학습률, 곡률 방향, 반복 배율, 문장 자막. 영문과 숫자 기호는 화면에 원 표기를 쓴다.
## 시작·종료 상태
첫 대상에서 마지막 대상으로 연속 변형한다. 상단 제목과 하단 자막 영역을 확보한다.
## 다음 장면 연결
공간을 더 자세히 보면 시간도 더 잘게 나눠야 할까?
## 수학 조건·과장 방지
격자 유체 개념도이며 NS 전체의 수치해가 아니다.
모든 단순 모형과 개념도는 실제 NS 해나 신경망의 측정값이 아니다. 실제 해의 정확한 항 수치를 시뮬레이션하지 않는다. 유한 활성 행렬의 이상치를 유체 특이점과 동일시하지 않는다.

# Scene 02 — 공간을 더 자세히 보면 시간도 더 잘게 나눠야 할까?
## 목적과 핵심 주장
공간을 더 자세히 보면 시간도 더 잘게 나눠야 할까?를 한 장면에서 이해시킨다.
## 앞 장면에서 받은 내용
실제 유체와 컴퓨터 속 유체는 다르다
## TTS 원문과 확정 길이
이번에는 유체의 한 부분을 더 자세히 계산해 보겠습니다.

격자 간격을 절반으로 줄입니다.

그러면 기존에는 하나의 칸으로 표현했던 영역을 여러 칸으로 나누어 계산할 수 있습니다.

그런데 문제가 생깁니다.

점성에 의한 확산을 간단한 명시적 방법으로 계산한다면, 공간 격자 간격에 따라 허용되는 시간 간격도 달라집니다.

한 차원의 단순한 확산 계산에서는 공간 간격을 절반으로 줄이면, 안정성을 위해 시간 간격을 사분의 일 이하로 줄여야 합니다.

공간을 두 배 더 촘촘하게 살펴보려 했을 뿐인데, 시간은 네 배 더 세밀하게 계산해야 하는 것입니다.

- TTS: 사용자 측정 32초
- 화면: 32초. 원래 화면 기준은 38초.
## 화면 구성과 시간대별 애니메이션
격자 1 → 1/2 · 시간 간격 1 → 1/4
문장 순서대로 timing.json의 ends에 맞춰 cue를 진행한다.
## 화면 텍스트
공간을 더 자세히 보면 시간도 더 잘게 나눠야 할까?, 격자 간격, 시간 눈금, 확산 모드, 손실 등고선, 학습률, 곡률 방향, 반복 배율, 문장 자막. 영문과 숫자 기호는 화면에 원 표기를 쓴다.
## 시작·종료 상태
첫 대상에서 마지막 대상으로 연속 변형한다. 상단 제목과 하단 자막 영역을 확보한다.
## 다음 장면 연결
왜 너무 큰 시간 간격에서는 계산이 불안정해질까?
## 수학 조건·과장 방지
1D 등간격 중앙차분 + Forward Euler, ν>0, r=νΔt/Δx²≤1/2. Δx/2이면 같은 r에서 Δt/4. 다른 차원/적분법 계수 다름.
모든 단순 모형과 개념도는 실제 NS 해나 신경망의 측정값이 아니다. 실제 해의 정확한 항 수치를 시뮬레이션하지 않는다. 유한 활성 행렬의 이상치를 유체 특이점과 동일시하지 않는다.

# 02 — 같은 재료, 다른 추출 구조

## 목적과 주장
행렬곱의 개수·크기·구성 비율과 손실을 함께 비교한다.

## 앞 장면
계산을 버렸는데, 무엇을 남겨야 할까?

## TTS
같은 텐서에서 출발하더라도, 어떤 구조를 얼마나 활용할지, 그리고 그 구조를 어떻게 분석할지에 따라 얻을 수 있는 상한이 달라집니다.

어떤 선택은 작은 행렬곱을 많이 남깁니다.

다른 선택은 개수는 적어도 더 큰 행렬곱을 남길 수 있습니다.

중요한 것은 어느 쪽이 더 좋은 계산 복잡도 상한을 증명할 수 있느냐입니다.

사용자 제공 발화 길이: 20초. 전체 누적 18–38초. 음성 파일 미제공.

## 화면·애니메이션·화면 표기
작은 블록 여러 개와 큰 블록 몇 개를 가상 비교한다. A·B 중 어느 쪽이 더 좋은지는 단순 개수만으로 정하지 않는다.
구체적인 임시 구간은 visuals.py의 part2에 둔다. narration_timing.json의 사용자 제공 구간을 적용한다.

## 정확성 조건
선택 A·B, 슬라이더와 최적화 지형·경로는 설명용 개념도다. 특정 연구의 분포나 실행 로그가 아니다. 가상 선택에 실제 연구 상한 숫자를 붙이지 않는다. 2026년 논문의 문제 재구성, 경사 기반 최적화, AlphaEvolve 프로그램 개선, 별도 엄밀 검증을 구분한다. AlphaEvolve 단독 성과나 새 레이저 방법 발명으로 표현하지 않는다. 결과는 점근적 지수의 이론적 상한이며 GPU 속도나 특정 크기 실행 시간 개선이 아니다. 본 작업에서 논문의 수치 인증을 독립 재현했다고 주장하지 않는다.

## 직관 보강 개정
블록 추출은 도입 비유다. 구조의 활용량과 분석 매개변수까지 다룬다. 하나의 선택이 여러 조건에 영향을 주므로 함께 최적화한다. 결론은 ω의 정확한 값이나 전역 최적점을 알아냈다는 주장이 아닌, 더 낮은 유효 상한의 증명이다.

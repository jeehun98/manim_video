앞서 우리는 논리 게이트로 값을 기억하는 회로를 만들고, 클럭을 이용해 저장 시점을 제어하는 방법을 살펴봤습니다.

그렇다면 저장한 값을 실제 계산에 다시 사용하려면 어떻게 해야 할까요?

먼저 우리가 만들었던 저장 회로를 생각해 보겠습니다.

하나의 저장 회로는 0 또는 1, 즉 하나의 비트를 기억할 수 있습니다.

그런데 에이 엘 유가 계산하는 숫자는 하나의 비트로 표현되지 않을 수도 있습니다.

예를 들어 숫자 5를 이진수로 나타내면 0101입니다.

이 값을 저장하려면 네 개의 비트를 각각 기억해야 합니다.

그렇다면 하나의 비트를 저장하는 회로 네 개를 나란히 배치하면 어떨까요?

각 회로가 하나의 비트를 담당하고, 공통된 클럭을 이용해 값을 갱신하도록 만드는 것입니다.

이렇게 여러 비트를 하나의 값으로 묶어 저장하는 회로를 레지스터라고 합니다.

이제 우리는 계산 결과인 숫자 8도 레지스터에 보관할 수 있습니다.

그런데 여기서 새로운 문제가 생깁니다.

앞서 살펴본 것처럼 하나의 에이 엘 유로 여러 단계의 계산을 수행하려면, 저장된 값을 다시 에이 엘 유의 입력으로 가져와야 합니다.

예를 들어 5와 3을 더한 다음, 그 결과에 다시 2를 더한다고 생각해 보겠습니다.

먼저 에이 엘 유가 5와 3을 계산하면 결과인 8이 나옵니다.

이 값을 레지스터에 저장합니다.

이제 두 번째 계산에서는 처음 입력했던 5 대신, 레지스터에 저장된 8을 사용해야 합니다.

그렇다면 에이 엘 유의 입력에 연결할 값을 어떻게 바꿀 수 있을까요?

여기서 앞서 살펴본 멀티플렉서, 즉 먹스를 다시 사용할 수 있습니다.

먹스는 여러 입력 중 제어 신호로 지정한 하나를 선택해 출력으로 전달하는 회로입니다.

처음에는 숫자 5를 선택하고, 다음 계산에서는 레지스터에 저장된 8을 선택하는 것입니다.

이렇게 하면 에이 엘 유 자체를 변경하지 않고도 서로 다른 데이터를 이용해 계산할 수 있습니다.

하지만 실제 계산에서는 하나의 값만 저장하는 것으로 충분하지 않을 수 있습니다.

5와 3, 그리고 계산 결과인 8을 동시에 보관하려면 여러 레지스터가 필요합니다.

이때 어느 레지스터의 값을 읽고, 계산 결과를 어느 레지스터에 기록할지도 결정해야 합니다.

이처럼 저장된 데이터를 선택해 연산 회로로 전달하고, 계산 결과를 다시 저장하는 연결 구조를 데이터 경로, 즉 데이터패스라고 합니다.

여기서 중요한 것은 에이 엘 유가 계산을 담당하고, 레지스터가 값을 보관하며, 데이터 경로가 이들을 연결한다는 점입니다.

이제 우리는 계산하는 회로와 기억하는 회로를 하나의 구조로 연결할 수 있게 되었습니다.

하지만 아직 한 가지 문제가 남아 있습니다.

어떤 값을 선택하고, 어떤 연산을 수행하며, 결과를 어디에 저장할지는 누가 결정하는 걸까요?

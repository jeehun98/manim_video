# 제작 기준

학습 목표: 비트 저장 요소를 묶은 레지스터와 MUX를 이용해 하나의 ALU를 여러 단계의 계산에 재사용하는 구조를 이해한다.

사용자 대본 31문장의 종료 시각을 그대로 사용한다. 153초, 14씬, 가로·세로 별도 배치. 원고의 도입과 마지막 문장을 유지하되 추가 복습 및 예고는 삽입하지 않는다.

화면: 파랑 읽기 A, 보라 읽기 B 및 ALU, 초록 저장 값과 결과, 주황 제어. 배선은 고정하고 선택된 경로만 강조한다. 두 입력 후보를 ALU 핀에 직접 단락하지 않는다. 전체 데이터 경로는 두 독립 읽기 선택기와 별도 쓰기 경로를 표시한다.

레지스터는 4개 저장 요소가 서로 다른 비트를 저장하고 공통 CLK를 공유한다. 하나의 레지스터에 여러 숫자를 동시에 저장하는 표현을 피한다. 계산 5+3→8 저장 후 8+2→10은 쓰기를 비활성화해 피드백 반복 계산을 방지한다.

자막은 단일 Text 객체를 문장 경계에서 교체한다. 이전·다음 자막의 교차 페이드는 없다. 화면 하단 자막 전용 영역을 확보한다.

# GPU 개론 08 — 저장된 값은 어떻게 다시 계산에 사용될까?

확정31문장·사용자종료시각153초. 음원미제공.

## 0–11초 · 저장한 값을 다시 계산하려면?

0–6초: 앞서 우리는 논리 게이트로 값을 기억하는 회로를 만들고, 클럭을 이용해 저장 시점을 제어하는 방법을 살펴봤습니다.

6–11초: 그렇다면 저장한 값을 실제 계산에 다시 사용하려면 어떻게 해야 할까요?

## 11–24초 · 하나의 저장 회로는 1비트

11–14초: 먼저 우리가 만들었던 저장 회로를 생각해 보겠습니다.

14–18초: 하나의 저장 회로는 0 또는 1, 즉 하나의 비트를 기억할 수 있습니다.

18–24초: 그런데 ALU가 계산하는 숫자는 하나의 비트로 표현되지 않을 수도 있습니다.

## 24–31초 · 숫자 5를 네 비트로

24–27초: 예를 들어 숫자 5를 이진수로 나타내면 0101입니다.

27–31초: 이 값을 저장하려면 네 개의 비트를 각각 기억해야 합니다.

## 31–45초 · 네 개의 저장 요소를 하나로

31–35초: 그렇다면 하나의 비트를 저장하는 회로 네 개를 나란히 배치하면 어떨까요?

35–41초: 각 회로가 하나의 비트를 담당하고, 공통된 클럭을 이용해 값을 갱신하도록 만드는 것입니다.

41–45초: 이렇게 여러 비트를 하나의 값으로 묶어 저장하는 회로를 레지스터라고 합니다.

## 45–60초 · 저장된 결과를 다음 입력으로

45–50초: 이제 우리는 계산 결과인 숫자 8도 레지스터에 보관할 수 있습니다.

50–52초: 그런데 여기서 새로운 문제가 생깁니다.

52–60초: 앞서 살펴본 것처럼 하나의 ALU로 여러 단계의 계산을 수행하려면, 저장된 값을 다시 ALU의 입력으로 가져와야 합니다.

## 60–77초 · 5+3의 결과를 다시 사용한다

60–65초: 예를 들어 5와 3을 더한 다음, 그 결과에 다시 2를 더한다고 생각해 보겠습니다.

65–69초: 먼저 ALU가 5와 3을 계산하면 결과인 8이 나옵니다.

69–72초: 이 값을 레지스터에 저장합니다.

72–77초: 이제 두 번째 계산에서는 처음 입력했던 5 대신, 레지스터에 저장된 8을 사용해야 합니다.

## 77–91초 · 여러 값 중 하나를 선택

77–81초: 그렇다면 ALU의 입력에 연결할 값을 어떻게 바꿀 수 있을까요?

81–86초: 여기서 앞서 살펴본 멀티플렉서, 즉 MUX를 다시 사용할 수 있습니다.

86–91초: MUX는 여러 입력 중 제어 신호로 지정한 하나를 선택해 출력으로 전달하는 회로입니다.

## 91–102초 · 같은 ALU, 다른 데이터

91–97초: 처음에는 숫자 5를 선택하고, 다음 계산에서는 레지스터에 저장된 8을 선택하는 것입니다.

97–102초: 이렇게 하면 ALU 자체를 변경하지 않고도 서로 다른 데이터를 이용해 계산할 수 있습니다.

## 102–112초 · 여러 값에는 여러 레지스터

102–107초: 하지만 실제 계산에서는 하나의 값만 저장하는 것으로 충분하지 않을 수 있습니다.

107–112초: 5와 3, 그리고 계산 결과인 8을 동시에 보관하려면 여러 레지스터가 필요합니다.

## 112–118초 · 어디서 읽고, 어디에 쓸까?

112–118초: 이때 어느 레지스터의 값을 읽고, 계산 결과를 어느 레지스터에 기록할지도 결정해야 합니다.

## 118–127초 · 선택 · 연산 · 다시 저장

118–127초: 이처럼 저장된 데이터를 선택해 연산 회로로 전달하고, 계산 결과를 다시 저장하는 연결 구조를 데이터 경로, 즉 Datapath라고 합니다.

## 127–139초 · 계산·저장·연결의 역할

127–134초: 여기서 중요한 것은 ALU가 계산을 담당하고, 레지스터가 값을 보관하며, 데이터 경로가 이들을 연결한다는 점입니다.

134–139초: 이제 우리는 계산하는 회로와 기억하는 회로를 하나의 구조로 연결할 수 있게 되었습니다.

## 139–148초 · 누가 이 동작을 결정할까?

139–142초: 하지만 아직 한 가지 문제가 남아 있습니다.

142–148초: 어떤 값을 선택하고, 어떤 연산을 수행하며, 결과를 어디에 저장할지는 누가 결정하는 걸까요?

## 148–153초 · 회로의 동작을 정하는 신호

148–153초: 다음에는 명령어가 실제 회로의 동작을 어떻게 제어하는지 살펴보겠습니다.

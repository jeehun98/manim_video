# GPU 개론 03 — 제작 기준

- 사용자 확정 원문 34문장과 종료 시각 기준 164초. 추정 배분이나 길이 확장 없음.
- 첨부 상세 콘티는 storyboard_reference.md에 보존한다. 14개 독립 Scene, 씬 하나당 하나의 주장으로 구성한다.
- 가로 1920×1080 / 세로 1080×1920, 30fps. 미리보기 640×360 / 360×640, 15fps.
- 음원 미제공으로 현재 무음·전체 문장 자막. TTS 파일은 발음 표기만 두고 화면 전환·주요 변화마다 빈 줄을 넣는다.
- 배경 #0B1020, 입력 A #60A5FA, 입력 B #A78BFA, 연결 가능 경로 #34D399, 차단 #64748B, 물리 비용 #F59E0B, 결과 #F8FAFC.
- 직렬·병렬은 같은 A·B 스위치의 Transform과 배선 교체로 비교한다. 경로 연결 여부를 실제 출력 전압 비트와 혼동하지 않는다. 전류 가능성은 전원·부하·귀환 경로가 있는 개념 회로로 표현한다.
- CMOS NAND는 상단 pMOS A·B 병렬, 하단 nMOS A·B 직렬, 공통 출력 Y로 구성한다. Gate 입력선은 전도 경로와 분리하고 출력선과 교차하지 않도록 바깥쪽으로 배선한다.
- pMOS Gate의 반전 원과 nMOS Gate를 구별한다. 각 소자의 전도 가능 상태와 네트워크 전체의 레일 연결을 구별한다. 정적 상태의 출력 Y는 VDD·GND 중 정확히 한 레일에 연결된다. 스위칭 과도 상태는 생략한 논리 모형임을 표시한다.
- NAND 네 입력 00/01/10/11, NAND만으로 구성한 NOT 1개·AND 2개·OR 3개·XOR 4개 게이트의 netlist를 logic_model.py에 기록한다. check_logic.py는 동일 netlist의 모든 입력, 레일 간 단락 없음, 사용자 시간 경계를 검증한다.
- 기능적 완전성은 유한한 수의 이진 입력에 대한 임의의 불 함수 구현 가능성이다. 임의 계산 문제의 무제한 해결·무비용 계산으로 표현하지 않는다.
- 고정 단일 기능 회로를 예로 들며 ALU의 미리 구현된 기능 선택과 구별한다. 입력 비트를 바꾸는 것과 트랜지스터 배선을 바꾸는 것을 동일시하지 않는다.
- 면적·지연·에너지는 정성적 모형이다. 소자 수에 따라 지연·에너지가 같은 비율로 증가한다고 그리지 않는다. 깊이·부하·배선·전환·누설을 구별한다.
- 지연 장면은 NAND의 두 입력을 묶은 반전 단계 연결로 상태 변화를 차례대로 표시한다. 지연은 설명용으로 크게 늘린 시간이다.
- 에너지 장면은 출력 부하의 등가 정전용량과 선택된 충전·방전 구동 경로를 표현한다. 전압 변화와 손실을 입자 속도로 표현하지 않는다. 수치·에너지 보존 정량 측정이나 실제 파형 시뮬레이션으로 주장하지 않는다.
- 자막은 초기화된 Text 하나만 문장 경계에서 즉시 교체한다. 대기 시간에도 갱신하며 Fade로 두 문장을 겹치지 않는다. 외부 자막은 `_captions.srt`로 두어 자동 이중 표시를 피한다.
- 도입 회상·마지막 산술 질문과 SUM/CARRY는 사용자 원문·콘티의 명시적 요청에 따라 유지한다. 추가 복습·예고는 만들지 않는다.

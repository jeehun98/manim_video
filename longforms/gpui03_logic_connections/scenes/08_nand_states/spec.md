# 08 · NAND의 출력은 왜 반대일까?

## 목적·주장
네 입력 조합에서 전원·접지 연결을 추적해 NAND 출력을 검증한다.

## 시작 상태·앞 장면
pMOS 병렬·nMOS 직렬 네트워크가 출력 노드를 공유한다.

## 확정 TTS와 길이
사용자 종료 시각 71–81초, 10초. 음원 미제공. 추정 길이를 사용하지 않는다.

NAND는 두 입력이 모두 1일 때만 0을 출력합니다.

이 역시 입력을 분석하는 프로그램이 아니라, 트랜지스터들의 연결 구조와 전기적 특성으로 구현된 결과입니다.

## 화면과 타임라인
| 전체 시각(초) | 화면 |
| --- | --- |
| 71–75 | A=B=1에서 pMOS 모두 OFF·nMOS 모두 ON·Y=0 |
| 75–81 | 00→01→10→11의 공급 경로와 진리표 동기화 |

구현: ../../scene_engine.py의 nand_states 메서드. 사용자 콘티 원문: ../../storyboard_reference.md. 화면에는 입력 A·B, 경로 상태 또는 OUTPUT Y와 핵심 용어만 표시하고 하단에는 전체 문장 자막을 둔다.

## 종료 상태·연결
네 입력 조합에서 전원·접지 연결을 추적해 NAND 출력을 검증한다.
이 상태를 이어 게이트를 다시 연결하면로 확장한다.

## 조건·과장 방지
직렬·병렬의 연결 조건과 CMOS의 출력 전압을 같은 비트로 취급하지 않는다. pMOS는 병렬, nMOS는 직렬이며 각 네트워크가 공통 출력에 연결된다. Gate 입력선은 전도 경로와 분리한다. 정적 논리 상태의 전원·접지 경로는 상보적이다. NAND의 네 입력과 모든 파생 네트워크의 진리표는 check_logic.py로 검증한다. 기능적 완전성은 유한 이진 입력의 불 함수에 관한 성질이다. 고정 기능 회로와 ALU의 기능 선택을 구별한다. 면적·지연·에너지는 정성 모형이며 실측 수치나 선형 비례를 제시하지 않는다. 사용자 도입·마지막 질문은 그대로 유지한다.

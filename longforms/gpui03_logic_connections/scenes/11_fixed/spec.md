# 11 · 구현 가능성과 효율은 다르다

## 목적·주장
고정 단일 기능 회로의 배선과 함수는 입력값만으로 임의 변경되지 않는다.

## 시작 상태·앞 장면
NAND는 유한 이진 입력의 임의 불 함수를 구성하는 기능적 완전성을 갖는다.

## 확정 TTS와 길이
사용자 종료 시각 95–119초, 24초. 음원 미제공. 추정 길이를 사용하지 않는다.

그렇다면 논리 게이트를 얼마든지 조합해 모든 계산 문제를 해결할 수 있을까요?

논리 함수를 구현할 수 있다는 것과, 실제 하드웨어에서 효율적으로 계산할 수 있다는 것은 다른 문제입니다.

우선 회로가 구현하는 규칙은 물리적인 연결 구조에 의해 결정됩니다.

일반적인 고정 기능 회로에서는 다른 연산을 수행하고 싶다고 해서, 소프트웨어 명령만으로 트랜지스터의 배선이 바뀌지는 않습니다.

## 화면과 타임라인
| 전체 시각(초) | 화면 |
| --- | --- |
| 95–100 | 기존 AND 회로의 네 입력 조합 |
| 100–106 | AND와 XOR의 01 입력 결과를 비교 |
| 106–111 | 고정된 배선을 강조 |
| 111–119 | 네 NAND로 구성한 다른 XOR 배선 표시 |

구현: ../../scene_engine.py의 fixed 메서드. 사용자 콘티 원문: ../../storyboard_reference.md. 화면에는 입력 A·B, 경로 상태 또는 OUTPUT Y와 핵심 용어만 표시하고 하단에는 전체 문장 자막을 둔다.

## 종료 상태·연결
고정 단일 기능 회로의 배선과 함수는 입력값만으로 임의 변경되지 않는다.
이 상태를 이어 회로에는 물리적 비용이 있다로 확장한다.

## 조건·과장 방지
직렬·병렬의 연결 조건과 CMOS의 출력 전압을 같은 비트로 취급하지 않는다. pMOS는 병렬, nMOS는 직렬이며 각 네트워크가 공통 출력에 연결된다. Gate 입력선은 전도 경로와 분리한다. 정적 논리 상태의 전원·접지 경로는 상보적이다. NAND의 네 입력과 모든 파생 네트워크의 진리표는 check_logic.py로 검증한다. 기능적 완전성은 유한 이진 입력의 불 함수에 관한 성질이다. 고정 기능 회로와 ALU의 기능 선택을 구별한다. 면적·지연·에너지는 정성 모형이며 실측 수치나 선형 비례를 제시하지 않는다. 사용자 도입·마지막 질문은 그대로 유지한다.

# 03 · 하나만 연결되어도 되는 배치

## 목적·주장
동일한 스위치를 병렬로 재배치하면 한쪽만 닫혀도 경로가 연결된다.

## 시작 상태·앞 장면
직렬 경로는 두 스위치가 모두 닫혀야 연결된다.

## 확정 TTS와 길이
사용자 종료 시각 19–33초, 14초. 음원 미제공. 추정 길이를 사용하지 않는다.

반대로 두 스위치를 병렬로 연결하면 어떨까요?

이번에는 둘 중 하나만 닫혀도 전류가 흐를 수 있습니다.

스위치 자체는 달라지지 않았습니다.

단지 연결하는 방식만 바꿨을 뿐인데, 전류가 흐를 수 있는 조건이 달라진 것입니다.

## 화면과 타임라인
| 전체 시각(초) | 화면 |
| --- | --- |
| 19–22 | 같은 A·B를 두 갈래로 재배열 |
| 22–26 | A만 닫아 첫 경로 연결 |
| 26–28 | 부품은 그대로임을 강조 |
| 28–33 | B만 닫기·둘 다 닫기로 병렬 조건 확인 |

구현: ../../scene_engine.py의 parallel 메서드. 사용자 콘티 원문: ../../storyboard_reference.md. 화면에는 입력 A·B, 경로 상태 또는 OUTPUT Y와 핵심 용어만 표시하고 하단에는 전체 문장 자막을 둔다.

## 종료 상태·연결
동일한 스위치를 병렬로 재배치하면 한쪽만 닫혀도 경로가 연결된다.
이 상태를 이어 연결 조건에 이름을 붙이면로 확장한다.

## 조건·과장 방지
직렬·병렬의 연결 조건과 CMOS의 출력 전압을 같은 비트로 취급하지 않는다. pMOS는 병렬, nMOS는 직렬이며 각 네트워크가 공통 출력에 연결된다. Gate 입력선은 전도 경로와 분리한다. 정적 논리 상태의 전원·접지 경로는 상보적이다. NAND의 네 입력과 모든 파생 네트워크의 진리표는 check_logic.py로 검증한다. 기능적 완전성은 유한 이진 입력의 불 함수에 관한 성질이다. 고정 기능 회로와 ALU의 기능 선택을 구별한다. 면적·지연·에너지는 정성 모형이며 실측 수치나 선형 비례를 제시하지 않는다. 사용자 도입·마지막 질문은 그대로 유지한다.

# 01 · 스위치 두 개로 무엇을 할까?

## 목적·주장
동일한 두 스위치에서 연결 조건을 탐구한다.

## 시작 상태·앞 장면
MOSFET의 채널 형성에서 시작한다.

## 확정 TTS와 길이
사용자 종료 시각 0–12초, 12초. 음원 미제공. 추정 길이를 사용하지 않는다.

앞서 우리는 전압으로 전류의 흐름을 제어하는 트랜지스터를 살펴봤습니다.

그런데 단순히 전류가 흐르는 통로를 열고 닫는 것만으로 어떻게 계산이 가능할까요?

두 개의 스위치가 있다고 생각해 보겠습니다.

## 화면과 타임라인
| 전체 시각(초) | 화면 |
| --- | --- |
| 0–4 | MOSFET의 전도 채널 형성 |
| 4–9 | 간단한 전압 제어 스위치로 단순화 |
| 9–12 | 같은 스위치를 복제해 A·B 표시 |

구현: ../../scene_engine.py의 switches 메서드. 사용자 콘티 원문: ../../storyboard_reference.md. 화면에는 입력 A·B, 경로 상태 또는 OUTPUT Y와 핵심 용어만 표시하고 하단에는 전체 문장 자막을 둔다.

## 종료 상태·연결
동일한 두 스위치에서 연결 조건을 탐구한다.
이 상태를 이어 두 조건이 모두 필요한 연결로 확장한다.

## 조건·과장 방지
직렬·병렬의 연결 조건과 CMOS의 출력 전압을 같은 비트로 취급하지 않는다. pMOS는 병렬, nMOS는 직렬이며 각 네트워크가 공통 출력에 연결된다. Gate 입력선은 전도 경로와 분리한다. 정적 논리 상태의 전원·접지 경로는 상보적이다. NAND의 네 입력과 모든 파생 네트워크의 진리표는 check_logic.py로 검증한다. 기능적 완전성은 유한 이진 입력의 불 함수에 관한 성질이다. 고정 기능 회로와 ALU의 기능 선택을 구별한다. 면적·지연·에너지는 정성 모형이며 실측 수치나 선형 비례를 제시하지 않는다. 사용자 도입·마지막 질문은 그대로 유지한다.

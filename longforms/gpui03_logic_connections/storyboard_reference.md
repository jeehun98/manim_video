# GPU 개론 03 — 스위치의 연결이 어떻게 논리 연산이 될까?

총 164초 · 9:16 세로 영상 · Manim / Codex 구현용 상세 콘티

이번 영상의 중심은 회로의 물리적인 연결 관계가 곧 계산 규칙이 된다는 사실이야.

처음에는 단순한 스위치 두 개만 등장하고, 연결 구조를 바꿔 논리적 조건을 발견한 뒤, 실제 CMOS NAND 회로로 발전시켜. 마지막에는 그러한 회로가 갖는 물리적 비용까지 보여주는 방식으로 구성하자.

이미지 없이 텍스트만 복사해 제작할 수 있도록 구도, 화면 요소, 움직임, 전환을 구체적으로 설명할게.

## 공통 제작 규칙

화면 및 색상

- 배경: `#0B1020` 검정에 가까운 남색
- 전류가 흐를 수 있는 활성 경로: `#34D399` 초록
- 차단된 경로: `#64748B` 회색
- 입력 A: `#60A5FA` 파랑
- 입력 B: `#A78BFA` 보라
- 논리 결과: `#F8FAFC` 흰색
- 물리적 한계 및 제약: `#F59E0B` 주황

연출 방식

모든 도형은 2D 벡터를 기반으로 하고, 이전 장면의 스위치를 복제하거나 재배열하면서 다음 장면으로 이어간다. 새로운 장면마다 화면을 완전히 지우는 전환은 최소화한다.

상단에는 핵심 개념, 중앙에는 회로, 하단에는 `A`, `B`, `OUTPUT` 등의 상태값을 표시한다. 자막과 겹치는 영역은 피한다.

## SCENE 01. 스위치 하나에서 계산의 가능성으로

00:00–00:12

내레이션

> 앞서 우리는 전압으로 전류의 흐름을 제어하는 트랜지스터를 살펴봤습니다.
>
> 그런데 단순히 전류가 흐르는 통로를 열고 닫는 것만으로 어떻게 계산이 가능할까요?
>
> 두 개의 스위치가 있다고 생각해 보겠습니다.

화면 연출

00–04초: 이전 영상의 MOSFET 단면이 화면 중앙에 등장한다. Gate의 전압이 LOW에서 HIGH로 변하면서 Source와 Drain 사이의 전도 채널이 형성된다.

04–09초: 복잡한 MOSFET 단면이 간단한 전자식 스위치 기호로 변형된다. 전압 입력이 바뀌면 스위치가 열리고 닫히는 동작을 두 번 반복한다.

09–12초: 스위치 기호가 복제되어 화면 중앙에 두 개가 나란히 배치된다. 왼쪽에는 `A`, 오른쪽에는 `B`라는 라벨이 나타난다.

핵심: 스위치가 두 개가 되어도 기본 기능은 달라지지 않는다는 사실을 유지해.

## SCENE 02. 직렬 연결 — 두 조건이 모두 필요하다

00:12–00:19

내레이션

> 먼저 두 스위치를 하나의 통로에 직렬로 연결해 보겠습니다.
>
> 이 경우 두 스위치가 모두 닫혀야 전류가 흐를 수 있습니다.

화면 구성

전원과 부하가 있는 하나의 폐회로를 단순화해서 그린다. 상단의 전류 경로에 스위치 A와 B를 직렬로 배치한다.

초기 상태에서는 A와 B가 모두 열려 있고, 회로가 회색으로 표시된다.

이후 A만 닫고, B만 닫고, A와 B를 모두 닫는 순서로 상태를 변경한다.

직렬 연결의 상태 변화

| 스위치 A | 스위치 B | 전체 경로 |
| ----- | ----- | ----- |
| 열림    | 열림    | 차단    |
| 닫힘    | 열림    | 차단    |
| 열림    | 닫힘    | 차단    |
| 닫힘    | 닫힘    | 연결    |

마지막 상태에서만 전체 경로가 초록색으로 밝아지도록 해.

중요한 건 스위치 하나가 닫혔다고 해서 나머지 경로까지 활성화되는 것처럼 표현하면 안 된다는 점이야.

## SCENE 03. 병렬 연결 — 하나만 연결되어도 된다

00:19–00:33

내레이션

> 반대로 두 스위치를 병렬로 연결하면 어떨까요?
>
> 이번에는 둘 중 하나만 닫혀도 전류가 흐를 수 있습니다.
>
> 스위치 자체는 달라지지 않았습니다.
>
> 단지 연결하는 방식만 바꿨을 뿐인데, 전류가 흐를 수 있는 조건이 달라진 것입니다.

화면 연출

19–22초: 직렬 연결 상태에서 A와 B를 모두 열고, 두 스위치를 위쪽과 아래쪽으로 이동시킨다.

22–26초: 하나의 경로가 두 갈래로 분기되고 각 경로에 스위치 A와 B가 하나씩 배치된다. 이후 두 경로가 다시 하나로 합쳐진다.

26–28초: A만 닫아 위쪽 경로가 활성화되는 모습을 보여준다.

28–33초: A를 열고 B를 닫으면 아래쪽 경로가 활성화된다. 마지막에는 두 스위치를 모두 닫고 두 경로가 함께 연결되는 모습을 보여준다.

중요한 시각적 대비

직렬과 병렬을 비교할 때는 반드시 동일한 두 스위치를 재배열하는 연출을 사용해.

새로운 부품을 추가하지 않았는데도 연결 조건이 달라졌다는 사실을 보여주는 것이 이번 영상의 첫 번째 핵심이야.

## SCENE 04. 물리적 연결 조건에서 논리 규칙으로

00:33–00:43

내레이션

> 이것을 논리적인 규칙으로 표현해 보겠습니다.
>
> 두 입력이 모두 참일 때만 참이 되는 규칙을 AND라고 합니다.
>
> 둘 중 하나 이상이 참이면 참이 되는 규칙은 OR입니다.

화면 구성

화면 왼쪽에 직렬 구조, 오른쪽에 병렬 구조를 나란히 배치한다.

두 구조 아래에 입력 A, B와 경로 연결 여부를 표시한다.

이때 `AND`와 `OR`라는 명칭이 처음 등장한다.

직렬

# AND

A와 B가 모두 참

병렬

# OR

A 또는 B가 참

기술적 주의: 여기서 참·거짓은 스위치가 연결되었는지에 대한 조건이야. CMOS NAND/NOR의 실제 출력 비트와 동일하게 표시해서는 안 돼.

## SCENE 05. 규칙을 계산하는 프로그램은 없다

00:43–00:55

내레이션

> 그런데 여기서 중요한 점이 있습니다.
>
> 이러한 규칙을 계산하는 별도의 소프트웨어가 실행되고 있는 것은 아닙니다.
>
> 스위치의 물리적인 연결 구조가 이미 특정한 입력과 출력의 관계를 결정하고 있는 것입니다.

화면 연출

43–45초: 직렬과 병렬 구조가 화면 중앙에 배치되고, 각 입력의 상태가 자동으로 변화한다.

45–50초: 화면 한쪽에 가상의 코드 창이 나타나지만, 해당 창이 흐려지고 사라진다. 회로는 코드 창과 무관하게 계속 동작한다.

50–55초: 스위치의 배선만 강조하고 주변 요소를 어둡게 한다.

화면 중앙에 다음 문구를 짧게 표시한다.

`Physical Connection → Logical Rule`

연출의 핵심은 프로그램이 사라졌는데도 입력에 따른 결과가 계속 만들어진다는 사실이야.

## SCENE 06. 연결 조건을 실제 출력 전압으로 바꾸기

00:55–01:03

내레이션

> 실제 디지털 회로에서는 트랜지스터들을 전원과 접지에 연결해, 입력에 따라 출력 전압이 달라지도록 설계할 수 있습니다.

화면 구성

이전의 스위치 두 개는 화면 왼쪽으로 이동하고, 화면 중앙에 전원과 접지가 있는 새로운 회로를 만든다.

상단에는 `VDD`, 하단에는 `GND`를 표시한다. 가운데에는 `OUTPUT Y`라는 출력 노드를 배치한다.

출력 노드에서 위쪽 전원으로 향하는 경로와 아래쪽 접지로 향하는 경로가 분리되어 있다는 점을 보여준다.

55–59초: 위쪽 경로만 연결하면 출력이 HIGH가 되는 모습을 보여준다.

59–63초: 아래쪽 경로만 연결하면 출력이 LOW가 되는 모습을 보여준다.

화면 문구

`전원 연결 → HIGH`

`접지 연결 → LOW`

여기서는 지난 2편에서 설명했던 인버터 원리를 짧게 재활용하면 돼. 스위치의 연결 조건과 실제 출력 전압이 구별된다는 점을 강조하자.

## SCENE 07. NAND 게이트의 물리적 구조 완성

01:03–01:11

내레이션

> 예를 들어 두 개의 nMOS를 직렬로 연결하고, 이에 대응하는 pMOS들을 병렬로 배치하면 NAND라는 논리 게이트를 구현할 수 있습니다.

화면 구성

이번 장면에서는 단순한 스위치 그림이 실제 트랜지스터 회로 기호로 변형돼.

구조는 정확히 다음과 같이 그려야 해.

CMOS NAND의 회로 배치 지시

VDD

pMOS A

pMOS B

병렬 경로 — 어느 한쪽으로도 VDD 연결 가능

OUTPUT Y

nMOS A

nMOS B

GND

기능적 배치도. 위쪽 pMOS 두 개는 병렬, 아래쪽 nMOS 두 개는 직렬이며, 두 네트워크는 가운데 출력 노드를 공유한다.

애니메이션 순서

63–66초: 두 개의 nMOS를 출력 노드 아래에 직렬로 배치한다. 각각의 Gate 입력에 A와 B를 연결한다.

66–69초: 두 개의 pMOS를 출력 노드 위에 병렬로 배치한다. pMOS에도 동일한 입력 A와 B를 각각 연결한다.

69–71초: 완성된 회로의 위쪽과 아래쪽 네트워크를 각각 다른 색상으로 잠시 강조한다.

여기서는 회로의 실제 연결 구조가 가장 중요하므로 전형적인 트랜지스터 회로도 형태로 그리는 것을 추천해. 추상적인 블록 그림만 사용하면 직렬과 병렬의 차이가 사라질 수 있어.

## SCENE 08. NAND의 출력은 왜 반대로 나타날까?

01:11–01:21

내레이션

> NAND는 두 입력이 모두 1일 때만 0을 출력합니다.
>
> 이 역시 입력을 분석하는 프로그램이 아니라, 트랜지스터들의 연결 구조와 전기적 특성으로 구현된 결과입니다.

화면 연출

71–75초: A=1, B=1을 입력한다. 위쪽 pMOS 두 개는 모두 꺼지고, 아래쪽 nMOS 두 개가 모두 켜진다. 출력 노드가 접지와 연결되고 출력이 0이 된다.

75–81초: 입력을 `00 → 01 → 10 → 11` 순서로 변경하면서 pMOS, nMOS의 상태와 출력이 자동으로 바뀌는 모습을 보여준다.

NAND 출력 검증

입력 A

01

입력 B

01

전원 연결 조건

차단됨

pMOS 병렬

접지 연결 조건

연결됨

nMOS 직렬

OUTPUT Y

# 0

안정된 논리 상태 기준. 실제 스위칭 중에는 전압 전이와 짧은 과도 상태가 존재할 수 있다.

핵심: NAND가 무엇인지 말로만 설명하지 말고, 실제 전원 경로와 접지 경로의 ON/OFF 상태로 출력값이 결정됨을 보여줘.

## SCENE 09. 논리 게이트를 다시 조합하면?

01:21–01:28

내레이션

> 그리고 이러한 논리 게이트들을 다시 조합하면 NOT, AND, OR를 비롯한 다양한 논리 연산을 구현할 수 있습니다.

화면 구성

81–84초: 완성된 트랜지스터 회로를 간단한 NAND 게이트 기호로 축소한다.

84–88초: NAND 게이트를 복제하고, 여러 게이트의 출력선을 다른 게이트의 입력선에 연결한다.

이때 다음 세 가지 구조를 순서대로 나타낸다.

- NAND의 두 입력을 묶어 NOT 생성
- NAND 뒤에 NOT을 연결해 AND 생성
- 입력을 각각 NOT으로 반전하고 NAND에 넣어 OR 생성

각 구조가 완성될 때 해당 연산 이름이 나타나도록 한다.

## SCENE 10. NAND만으로 모든 불 논리 함수를 구성할 수 있다

01:28–01:35

내레이션

> 실제로 NAND 게이트만으로도 모든 불 논리 함수를 구성할 수 있습니다.
>
> 이러한 성질을 기능적 완전성이라고 합니다.

화면 연출

88–91초: 기존에 등장했던 NOT, AND, OR 기호들이 모두 NAND로 구성된 작은 네트워크로 변형된다.

91–93초: NAND 하나에서 여러 논리 회로로 가지가 뻗어 나가는 장면을 보여준다.

93–95초: 화면 중앙에 기술 용어가 처음 등장한다.

`Functional Completeness`

여기서 '모든 불 논리 함수'는 유한한 수의 이진 입력에 대한 임의의 불 함수를 의미해. NAND만 있으면 아무 비용 없이 모든 계산을 처리할 수 있다는 뜻은 아니야.

## SCENE 11. 구현할 수 있다는 것과 자유롭게 바꿀 수 있다는 것은 다르다

01:35–01:59

내레이션

> 그렇다면 논리 게이트를 얼마든지 조합해 모든 계산 문제를 해결할 수 있을까요?
>
> 논리 함수를 구현할 수 있다는 것과, 실제 하드웨어에서 효율적으로 계산할 수 있다는 것은 다른 문제입니다.
>
> 우선 회로가 구현하는 규칙은 물리적인 연결 구조에 의해 결정됩니다.
>
> 일반적인 고정 기능 회로에서는 다른 연산을 수행하고 싶다고 해서, 소프트웨어 명령만으로 트랜지스터의 배선이 바뀌지는 않습니다.

상세 화면 구성

95–100초: 앞 장면에서 여러 NAND 게이트를 조합해 만든 회로가 화면 중앙에 남는다. 입력 비트가 계속 변경되며 회로가 정상적으로 동작한다.

100–106초: 화면을 좌우로 나눈다. 왼쪽에는 이미 설계된 AND 회로, 오른쪽에는 XOR의 입력·출력 진리표를 보여준다.

기존 AND 회로에 다른 입력을 넣어도 XOR의 모든 출력 규칙을 만족시킬 수 없다는 점을 비교한다.

106–111초: 회로를 구성하는 배선을 밝게 강조한 뒤 `Fixed Connections`라는 문구를 나타낸다.

111–119초: 오른쪽에는 새로운 XOR 회로를 그린다. 기존 회로와 다른 연결 구조가 필요하다는 것을 보여준다.

중요한 연출 제약

고정된 단일 기능 회로와 프로그래밍 가능한 프로세서를 혼동하면 안 돼.

실제 ALU는 여러 연산 기능을 미리 구현한 뒤 제어 신호로 기능을 선택할 수도 있어. 이번 영상은 하나의 고정된 논리 회로가 자신의 배선을 소프트웨어 명령으로 마음대로 변경하지는 못한다는 점에 집중해야 해.

화면 문구:

`Fixed Circuit ≠ Arbitrary Function`

## SCENE 12. 논리 회로를 확장하면 물리적인 비용이 발생한다

01:59–02:19

내레이션

> 또한 회로를 복잡하게 구성할수록 더 많은 트랜지스터와 배선이 필요합니다.
>
> 신호는 물리적인 회로를 통해 전달되기 때문에 출력이 즉시 결정되는 것도 아닙니다.
>
> 트랜지스터의 전도 상태가 변하고, 회로의 정전용량이 충전되거나 방전되는 데에는 시간이 필요합니다.
>
> 이 과정에서는 에너지가 소비되고, 일부는 열로 방출됩니다.

이 부분에서는 면적, 시간, 에너지라는 세 가지 비용을 각각 하나의 장면으로 표현하면 좋아.

### 119–124초 · 면적(Area)

처음에는 NAND 게이트 하나만 존재한다. 이후 동일한 게이트가 수십 개로 복제되고 복잡한 회로 네트워크를 형성한다.

각 게이트를 연결하는 선들도 함께 증가한다.

화면 전체를 칩 면적을 상징하는 직사각형 테두리로 감싸고, 내부 공간이 점차 채워지는 모습을 보여준다.

화면 문구: `Area / Transistors / Wiring`

### 124–129초 · 지연(Delay)

서로 연결된 게이트 네 개를 왼쪽에서 오른쪽으로 배치한다.

첫 번째 게이트의 입력을 변경하면 출력이 즉시 바뀌지 않고, 첫 번째 → 두 번째 → 세 번째 → 네 번째 순서로 상태 변화가 전달된다.

각 게이트를 지날 때 짧은 시간 간격을 둔다.

게이트 지연을 시각화하는 방식

화면 문구: `Propagation Delay`

### 129–139초 · 에너지(Energy)

기존 게이트 회로의 출력 노드를 확대한다.

출력과 접지 사이에 작은 커패시터 기호를 추가하고, 출력이 LOW에서 HIGH로 변할 때 전압이 상승하며 해당 정전용량이 충전되는 모습을 보여준다.

HIGH에서 LOW로 바뀔 때는 전압이 하강하고, 에너지 일부가 회로에서 소모된다는 사실을 시각화한다.

회로 주변에 작은 열기 또는 에너지 소모 그래픽을 표시한다.

화면 문구: `Charging / Discharging / Energy`

실제 CMOS에서는 스위칭 손실뿐 아니라 누설 전력도 존재한다. 따라서 에너지가 항상 동일하게 소모된다고 표현하지 않아야 해.

## SCENE 13. 회로 설계는 세 가지 물리적 제약을 고려한다

02:19–02:32

내레이션

> 결국 논리 회로를 설계한다는 것은 단순히 원하는 계산 규칙을 구현하는 것에서 끝나지 않습니다.
>
> 얼마나 많은 회로가 필요한지, 얼마나 빠르게 동작하는지, 얼마나 많은 에너지를 소비하는지도 함께 고려해야 합니다.

상세 화면 구성

139–145초: 앞선 세 장면이 하나의 화면으로 합쳐진다.

화면 중앙에는 NAND 게이트 네트워크를 배치하고, 그 주변에 세 가지 표시기를 위치시킨다.

- 왼쪽 상단: `Area`
- 오른쪽 상단: `Delay`
- 하단: `Energy`

145–152초: 회로를 확장하는 가상의 실험을 진행한다.

게이트 개수가 늘어나면서 Area 표시기가 증가한다. 신호가 지나는 게이트 단계와 부하도 달라질 수 있음을 보여주고 Delay, Energy 표시기를 강조한다.

여기서는 실제 수치를 보여주지 않는 편이 좋아. 트랜지스터 개수를 늘리면 지연과 에너지가 항상 동일한 비율로 증가하는 것은 아니기 때문이야.

성능은 논리 깊이, 게이트 크기, 팬아웃, 배선 길이, 스위칭 빈도 등에 따라 달라져.

화면 중앙 문구:

`Function + Area + Delay + Energy`

## SCENE 14. 작은 스위치에서 계산 장치로

02:32–02:44

내레이션

> 우리는 이제 단순한 전기적 스위치의 연결만으로 논리 연산을 구현할 수 있다는 사실을 확인했습니다.
>
> 그렇다면 이러한 논리 회로들을 조합해 실제 숫자의 덧셈까지 구현하려면 어떻게 해야 할까요?

상세 화면 구성

152–158초: 앞서 등장했던 회로가 단계적으로 단순화된다.

여러 트랜지스터가 하나의 NAND 게이트 기호로 변형되고, 여러 NAND 게이트가 하나의 논리 회로 블록을 구성한다.

158–161초: 서로 다른 논리 블록들이 화면 중앙으로 모인다. 블록의 기능은 아직 설명하지 않고, 전체를 하나의 새로운 연산 장치 형태로 배치한다.

161–164초: 회로 블록 왼쪽에 두 입력 `A`, `B`를 놓고, 오른쪽에는 `SUM`과 `CARRY`라는 두 출력 자리를 만든다.

두 출력에는 아직 값을 표시하지 않고 물음표만 남긴다.

마지막 문구는 다음처럼 마무리하면 좋아.

`논리 게이트 → 이진수 덧셈?`

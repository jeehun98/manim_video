# 1막 — 물은 왜 매끄러워야 하는가?

Navier–Stokes × 신경망의 수학적 패턴. 사용자 콘티의 7개 장면을 독립 영상으로 만든다.

- 길이: 155초(2:35), 사용자 제공 문장별 음성 종료 시각 기준. 원래 콘티 222초는 이전 버전이다.
- 화면: 1920×1080, 30fps. 미리보기: 854×480, 15fps.
- 산출물: 무음 영상, 화면 문장 자막, 별도 SRT, 씬별 소스·spec·발음용 대본.
- 상태: 40개 문장의 사용자 제공 시각에 화면·자막을 맞춘 무음 영상. 실제 음원 파일이 없어 음성 결합은 미진행.

## 학습 목표

이류의 운반·변형과 점성의 운동량 확산을 구별한다. 비선형 항이 항상 구조를 날카롭게 만든다는 인상을 피한다. 3차원 자기증폭은 다음 막으로 남긴다.

## 실행

프로젝트 루트에서 Python 3.12, Manim 0.21.0, FFmpeg, Malgun Gothic을 사용한다.

```powershell
python longforms/ns01_flow_patterns/prepare.py
python longforms/ns01_flow_patterns/build.py --preview
python longforms/ns01_flow_patterns/build.py
python longforms/ns01_flow_patterns/build.py --scene 6
python longforms/ns01_flow_patterns/build.py --concat-only
```

prepare.py는 대본·spec·인덱스·자막 시간을 재생성한다. voice_timing.json에 전체 시작부터의 문장별 누적 종료 시각을 보존하며, 이 값이 있으면 추정 시간 대신 적용한다. 해당 파일의 수동 수정을 덮어쓰므로 대본 변경은 prepare.py의 DATA에 먼저 반영한다.

각 scene.py는 공통 visuals.py의 해당 씬만 렌더한다. --scene으로 교체 렌더 후 --concat-only로 전체를 연결한다. 전체 프레임 수·해상도·fps·길이를 확인한다. --preview와 함께 사용하면 미리보기 씬을 연결한다.

## 정확성·표현

- 일정 밀도의 비압축성 유체. p는 밀도로 나눈 압력, f는 단위 질량당 외력이다.
- 색 영역은 수동 표지이며 속도 분포 자체와 구별된다. 전단 변형은 면적을 보존한다.
- 점성 예시는 가우시안 전단 속도의 열 방정식 확산이다. 최고값 감소와 폭 증가를 함께 표현한다.
- 두 경로 비교는 역할을 분리한 개념 시연이며 전체 방정식의 수치 해가 아니다.
- 마지막 장면은 매끄러움 유지에 관한 질문이다. 특이점이나 vortex stretching의 결과를 미리 보여주지 않는다.
- 문장 자막 시간과 화면 전환은 사용자 제공 종료 시각에 일치한다. 실제 음원을 분석한 결과는 아니며 제공 시각의 정밀도를 따른다.
- 도입 사진은 AI 생성 설명용 이미지다. 곡선과 화살표는 Manim 애니메이션이다.

## 파일

master_script.md는 화면용 원문, script.txt는 발음용 대본이다. scenes.yaml에서 TTS 길이와 콘티 길이를 별도로 관리한다. 이미지 생성 도구와 프롬프트는 assets/imagegen_prompt.txt에 기록한다.

tts_script.txt는 1막 전체를 한 번에 음성 합성할 수 있는 통합 대본이다. 화면 cue마다 빈 줄을 넣어 40개 문단으로 나눴다. 제목과 타임코드 없이 내레이션만 포함하며, Navier–Stokes는 ‘나비에 스토크스’, Velocity Field는 ‘벨로시티 필드’, 3차원은 ‘삼차원’으로 표기한다. 씬별 script.txt에도 같은 발음과 구간 구분을 적용했다.

최종: exports/ns01_act01_155s_1080p30.mp4와 같은 이름의 SRT.
이전 186초 미리보기와 186초·222초 통합 영상은 exports에 보존한다. 현재 시각의 최종본은 155초 영상이다.

## 검증 결과

40개 문장 종료 시각이 최신 사용자 제공 값과 모두 일치하며 마지막 자막은 155초에 끝난다. 영상 검증은 재렌더 완료 후 기록한다.

최종 검증: 1920×1080, 30fps, 4650프레임, 정확히 155초. 7개 씬의 대표 프레임을 검토했으며 전체 디코딩 오류가 없다. 무음본이다.

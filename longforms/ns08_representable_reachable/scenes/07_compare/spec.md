# Scene 07 — 이제 두 시스템을 다시 비교한다
## 목적과 핵심 주장
이제 두 시스템을 다시 비교한다를 한 장면에서 이해시킨다.
## 앞 장면에서 받은 내용
학습 규칙은 어떤 해를 선택하는가?
## TTS 원문과 확정 길이
이제 나비에 스토크스와 신경망을 다시 나란히 놓아보겠습니다.

유체에서는 속도가 폭주하는 함수를 만드는 것만으로 충분하지 않았습니다.

그 함수가 실제 운동 방정식과 초기 조건, 외력의 조건을 모두 만족해야 했습니다.

신경망에서는 낮은 손실을 가진 파라미터가 존재하는 것만으로 학습이 그곳에 도달한다고 보장할 수 없습니다.

주어진 초기값과 학습 규칙이 어떤 경로를 만드는지 살펴봐야 합니다.

여기서 두 문제는 엄밀히 다릅니다.

하나는 방정식과 조건을 만족하는 해가 존재하는지의 문제이고, 다른 하나는 학습 동역학이 어떤 해를 선택하는지의 문제입니다.

하지만 두 질문에는 공통된 관점이 있습니다.

가능한 상태들의 집합을 아는 것만으로는, 실제로 실현되는 상태를 설명할 수 없다는 것입니다.

- TTS: 사용자 측정 43초
- 화면: 43초. 원래 화면 기준은 46초.
## 화면 구성과 시간대별 애니메이션
후보 유체의 조건 검증 / 여러 해에서 학습 경로 선택 · 화살표 의미 구별
문장 순서대로 timing.json의 ends에 맞춰 cue를 진행한다.
## 화면 텍스트
이제 두 시스템을 다시 비교한다, 속도장 조건, 파라미터 공간, 손실 지형, 초기점과 학습 경로, 훈련점과 새로운 입력, 해 집합, 암묵적 편향, 문장 자막. 영문과 숫자 기호는 화면에 원 표기를 쓴다.
## 시작·종료 상태
첫 대상에서 마지막 대상으로 연속 변형한다. 상단 제목과 하단 자막 영역을 확보한다.
## 다음 장면 연결
시스템은 결과뿐 아니라 경로로 이해해야 한다
## 수학 조건·과장 방지
왼쪽 화살표는 조건 검증, 오른쪽은 동역학에 의한 선택. 후보 모양/유효 PDE 해/표현가능 함수/선택된 파라미터의 다른 수준을 혼동하지 않는다.
모든 단순 모형과 개념도는 실제 NS 해나 신경망의 측정값이 아니다. 실제 해의 정확한 항 수치를 시뮬레이션하지 않는다. 유한 활성 행렬의 이상치를 유체 특이점과 동일시하지 않는다.

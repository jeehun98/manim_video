# 경계와 내부를 연결하는 규칙

주장: 정칙함수의 코시 적분 공식이 경계와 내부를 연결함을 예고한다.

사용자 확정 대본·문장 종료 시각: 22–30초 · 240프레임. 음원 미제공, 무음·전체 자막.

16:9 1920×1080 30fps. 본문 y ≥ -2.6, 자막은 별도 하단 영역. 본편 01–04의 수학적 객체와 실제 계산 함수를 재사용한다.

- 22–30초: 그리고 복소미분이 가능하다는 조건이 함수에 어떤 특별한 성질을 부여하는지, 코시 적분 공식의 유도 과정을 따라가며 살펴보겠습니다.

조건: 정칙성·분기점 좌표·보편피복과 원래 곡면을 구분한다. 같은 쌍곡 반지름의 원은 엄밀한 타일링으로 표시하지 않는다. 기존 통합본은 수정하지 않으며 인트로 별도 파일을 생성한다.

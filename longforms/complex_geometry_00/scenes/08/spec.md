# 이야기의 출발점으로

주장: 복잡한 패턴에서 본편 첫 화면의 실수축으로 돌아온다.

사용자 확정 대본·문장 종료 시각: 66–69초 · 90프레임. 음원 미제공, 무음·전체 자막.

16:9 1920×1080 30fps. 본문 y ≥ -2.6, 자막은 별도 하단 영역. 본편 01–04의 수학적 객체와 실제 계산 함수를 재사용한다.

- 66–69초: 이 모든 이야기는 복소수라는 하나의 개념에서 시작됩니다.

조건: 정칙성·분기점 좌표·보편피복과 원래 곡면을 구분한다. 같은 쌍곡 반지름의 원은 엄밀한 타일링으로 표시하지 않는다. 기존 통합본은 수정하지 않으며 인트로 별도 파일을 생성한다.

# 4편 확정 원문 — 고윳값과 특이값

전체 발화시간 확정.

행렬 분해 이상형 월드컵! EVD 대 SVD. 대결 기준, 고윳값과 특이값입니다.

이번에는 하나의 행렬을 살펴보겠습니다. 정사각형에 이 행렬을 적용하면, 도형이 한쪽으로 기울어진 평행사변형으로 변합니다.

분명 변형이 일어났습니다. 그런데 이 행렬의 고윳값을 구하면, 놀랍게도 두 값 모두 1입니다. 고윳값이 모두 1인데, 도형은 왜 변한 걸까요?

고유벡터를 살펴보겠습니다. 수평 방향의 벡터에 이 행렬을 적용하면, 방향도 길이도 그대로 유지됩니다.

고윳값 1은 바로 이 고유방향에서의 배율이 1이라는 뜻입니다. 하지만 다른 방향까지 길이가 유지된다는 의미는 아닙니다.

이번에는 수직 방향의 벡터를 변환해 보겠습니다. 벡터가 옆으로 밀리면서 방향이 달라지고, 길이도 늘어납니다.

그렇다면 이 행렬이 벡터의 길이를 얼마나 변화시키는지는 어떻게 알 수 있을까요? 여기서 특이값이 등장합니다.

길이가 1인 벡터들을 모아 단위원을 만들어 보겠습니다.

이 원에 같은 행렬을 적용하면, 기울어진 타원이 만들어집니다.

타원의 가장 긴 축에 대응하는 입력 방향에서는 벡터의 길이가 약 2.414배로 늘어납니다.

반대로 가장 짧은 축에 대응하는 입력 방향에서는 약 0.414배로 줄어듭니다.

이 두 길이 배율이 바로 특이값입니다.

같은 행렬인데, 고윳값은 1과 1. 특이값은 약 2.414와 0.414입니다.

고윳값은 변환 후에도 같은 직선 위에 남는 고유방향에서의 배율을 나타냅니다.

반면 특이값은 특별한 입력 방향들에서 길이가 얼마나 늘어나거나 줄어드는지를 나타냅니다.

그렇다면 이번 대결의 승자는? SVD! 한 번의 변환에서 나타나는 길이 변화의 크기를 더 직접적으로 보여주기 때문입니다.

현재 스코어, EVD 2 대 SVD 2. 다시 동점입니다!

# 씬 01 — 세 계산을 하나의 직합으로

## 목적·주장
세 독립 계산을 묶은 직합을 짧게 소개한다.

## 앞 장면
4막 보더 랭크

## TTS 원문
지금까지는 하나의 행렬곱을 더 적은 항으로 표현하려고 했습니다.

이번에는 이 대 이 행렬곱 세 개를 준비하겠습니다. 입력도 출력도 서로 공유하지 않는 독립적인 계산입니다.

세 계산을 하나의 텐서에 나란히 담습니다. 서로 다른 블록 사이의 연결은 없습니다. 이런 구조가 직합입니다.

음성 길이 미측정. 무음 콘티 길이 22초, 전체 0–22초.

## 화면·큐·표시 텍스트
0–6초 세 2×2 카드. 6–12초 각 입력과 출력 구분. 12–18초 대각 블록 이동. 18–22초 직합 이름. 세 그룹 분리를 축약한 개념도.

## 시작·종료·연결
앞 씬의 세 독립 계산을 유지한다. 현재 주장 확인 후 다음 질문으로 연결한다.

## 수학적 조건
복소수 위. 독립 직합. r은 상한이며 임의 수치가 아니다. r=21은 정확한 7항 분해 세 개로 확보한다. r<21의 존재를 주장하지 않는다. 3·2^ω≤r은 별도 정리이며 반복 구조만으로 증명하지 않는다. 실제 실행 시간과 보더 랭크를 구분한다.


## 최종 발화 동기화
사용자 제공 시각 기준 0–17초, 길이 17초. 이전 임시 길이보다 이 값을 우선. 실제 음성 미제공, 무음 출력.

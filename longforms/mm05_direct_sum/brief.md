# 제작 기준

학습 목표: 직합 전체의 분해 정보가 점근적 합 부등식을 통해 행렬곱 성장 지수를 제한하는 이유를 구조로 이해한다.

한 씬 한 주장: 독립 변수 → 정확한 직합 → 묶음만으로 절약 없음 → 전체 보더 랭크 → 반복과 정리 → 연구 방향.

무음 콘티 176초. TTS 실측 전이다. 화면·자막은 실제 숫자와 영문 표기, 발화는 별도 tts_script.txt. 반복 구조는 같은 크기의 정사각 행렬곱 3개로 제한한다. 임의의 절약 수치와 GPU 성능 우위는 표시하지 않는다.

강조 장면: 두 묶음의 3×3 조합에서 9개의 계산 관계를 직접 추적한 뒤, 각 한 변의 크기가 m²로 바뀌는 태그를 보여준다. 결과 행렬을 다시 곱하는 애니메이션은 사용하지 않는다. 복소수 위에서 D의 보더 랭크 상한 R을 증명했다면 3m^ω≤R. 이 정리를 증명했다는 인상을 주지 않는다.

화면 검토: 전체 프레임 밖으로 벗어남과 텍스트 겹침을 주요 상태별 스냅샷으로 확인. 최종 1920×1080,30fps,5280프레임을 검사한다.


v2 피드백 반영: 176초 무음 콘티. 직합 정의 축소, 3개의2×2→9개의4×4→27개의8×8을 중심으로 배치. 보더 랭크 상한 r^k와 계산 규모를 표로 비교한 뒤 기준 r=21로 ω≤log₂7을 직접 계산한다. 이전165초 설명보다 이 계획을 우선한다.


최종 타이밍: 사용자 제공 27개 문장 종료 시각 적용, 151초(2분31초), 4530프레임. 가로형과 세로형 모두 무음이며 실제 음성 파일은 미제공.

# 5막 — 여러 행렬곱을 하나로 묶으면 무엇이 달라질까?

6개 독립 씬, 165초 무음 콘티, 1920×1080/30fps. 실제 음성 미제공이므로 TTS 길이와 자막은 임시 편집 배분이다.

직합 → 전체 분해 비용 → 보더 랭크 → 반복 결합 → 점근적 합 부등식. 가상의 절약 숫자는 사용하지 않는다.

`python longforms/mm05_direct_sum/build.py --preview`

`python longforms/mm05_direct_sum/build.py`

출력: exports/mm05_direct_sum_165s_1080p30.mp4

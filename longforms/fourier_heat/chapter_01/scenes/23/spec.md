# 23 — 복잡한 함수를 단순한 진동의 합으로

## 목적과 핵심 주장
복잡한 함수를 단순한 진동의 합으로

## 앞 장면에서 받은 내용
복잡한 초기 온도 분포

## TTS 원문·확정 길이
프랑스의 수학자 조제프 푸리에는 이 문제를 해결하기 위해 복잡한 온도 분포를 단순한 함수들의 합으로 표현하는 방법을 연구했습니다.

그리고 이 아이디어는 훗날 푸리에 해석이라는 거대한 수학 분야로 발전하게 됩니다.

155–169초, 14초. 사용자 종료 시각 기준. 음원 미제공.

## 화면·애니메이션
첨부 콘티 해당 컷을 공유 visuals.py의 geometry/labels로 구현. 본문 y=-2.45~2.8, 자막 y=-3.25. 시작에서 종료까지 해당 현상의 변화가 진행된다.

## 화면 텍스트
복잡한 함수를 단순한 진동의 합으로. 구체적인 수식·보조 표시는 visuals.py labels 참조.

## 시작·종료 상태와 연결
공통 남색 배경, 열·물·확률·기하 색상 유지. 여러 진동 성분과 합성 곡선을 유지하며 169초에 종료.

## 수학적 조건·과장 방지
brief.md의 조건 준수. 유체·자유경계·기하학적 변형은 개념도이며 수치해로 표기하지 않는다. 3차원 다양체와 2차원 구면은 구별한다. 열전도 해는 단열 경계의 코사인 모드 해석해를 사용한다.

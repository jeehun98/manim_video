# 05 — 합성에서 분해로 사고를 뒤집다

## 목적·핵심 주장
합성에서 분해로 사고를 뒤집다

## 앞 장면에서 받은 내용
세 성분으로 만든 복잡한 곡선

## 확정 대본과 길이
그런데 이렇게 여러 함수를 더해 새로운 곡선을 만드는 것과, 이미 주어진 복잡한 곡선을 다시 개별 함수들로 분해하는 것은 다른 문제입니다.

푸리에의 중요한 아이디어는 이러한 과정을 반대로 생각하는 것이었습니다.

복잡한 함수 속에 어떤 주파수의 진동이 얼마나 포함되어 있는지를 알아내는 것입니다.

49–67초, 18초. 사용자 문장 종료 시각 기준, 음원 없음.

## 화면 구성·애니메이션
storyboard_source.txt의 대응 구간. visuals.py의 labels/geometry에서 해당 씬 구현. 상단은 챕터와 현재 과정, 중앙은 곡선·계산, 하단은 원문 자막. 시작에서 종료까지 해당 수학적 변화를 단계적으로 표시한다.

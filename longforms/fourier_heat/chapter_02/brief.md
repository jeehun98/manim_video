# 제작 기준 — 열방정식 2장

사용자 확정 62문장·324초. timing.json의 문장 종료 시각을 그대로 적용한다. 16:9 1920×1080 30fps, 31개 독립 씬, 음원 미제공으로 무음·전체 원문 자막.

## 학습 목표와 시각 구조
합성 → 분해 → 직교성 → 계수 추출 → 고유함수 → 독립적인 감쇠 → 선형성 → 전체 해의 재결합. 마지막은 변화한 온도 곡선으로 끝나며 다음 편 예고·엔드카드 없음. 원문 첫 문장의 앞 장 언급은 사용자 확정 대본을 그대로 유지한다.

상단 챕터·현재 과정 안내는 1장과 같은 형태. 본문 제목과 수식, 도형, 하단 자막 영역을 분리한다. 배경 #10131C, 성분 색상은 파랑 #4A9EFF, 청록 #36C7A3, 주황 #F0A45D. 직교성은 보라, 시간 변화·미분은 노랑.

## 수학적 계약
- 대표 함수 f(x)=sin x+0.5 sin3x+0.25 sin5x, x∈[0,2π]. 같은 성분과 색을 이후 계산에 계속 사용한다.
- 도입의 첫 곡선은 1장 마지막의 함수 형태를 받아온 뒤, 6–11초에 이번 장의 대표 예제로 변환한다. 1장의 계수와 이번 예제의 계수를 같은 것으로 표시하지 않는다.
- 서로 다른 양의 정수 주파수 사인함수 내적은 0, 자기 내적은 π. 그림의 교차각이 직교를 의미하지 않는다. 곱의 부호 있는 넓이와 실제 누적 적분을 표시한다.
- a₁=1, a₃=0.5, a₅=0.25는 실제 수치적분으로 검증. 일반 푸리에 급수에서는 a₀+Σ(aₙ cos nx+bₙ sin nx) 표기, a₀는 상수항 자체. 예제의 사인 성분 계수 aₖ와 일반형의 bₙ는 표기 관례 차이이며 다른 수치가 아니다.
- 사각파 부분합은 실제 홀수 사인 급수 4/π Σ sin((2j+1)x)/(2j+1), N=1,3,10,30. 불연속점의 평균과 깁스 현상을 명시한다.
- 열방정식 u_t=κu_xx, κ=.12, 주기적 경계조건, 내부 열원 없음. 각 성분 Aₖ(0)e^(-κk²t)sin(kx)를 정확하게 계산한다.
- 온도 그래프 u는 기준 온도에 대한 편차. 실제 온도는 예를 들어 T=20+5u로 해석할 수 있으며 색은 동일한 편차를 사용한다. 단일 성분 장면의 막대는 단일 성분과 정확히 대응한다.
- 고유함수 장면에서 -9sin3x의 형상 비교는 -sin3x로 정규화했음을 명시. 선형성 장면의 미분 결과 그래프는 표시 배율 1/5.5를 명시한다.
- 중첩은 동차 열방정식과 동일한 주기적 경계조건 아래 적용. 상수배와 합을 허용하며, 서로 다른 고정 비동차 경계값을 그대로 유지한다고 주장하지 않는다.
- 고유함수는 성분별 계산을 단순하게 하고, 선형성은 그 해들의 합이 해가 되게 한다. 두 역할을 구별한다.

## 검증
mechanics.validate(): Gram 행렬, 계수, 주기 경계, PDE 잔차, 평균 보존, L² 에너지 감소, 사각파 부분합 L² 오차 감소. qa.py: 모든 문장 시작의 자막 배치 및 모든 씬 0.5초 간격 화면 이탈. build.py: 소스 해시, 씬·합본 프레임 수, 해상도·fps·총 길이·무음 검증.

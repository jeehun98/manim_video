# Scene 04

- 주장: 양의 해의 현재 값이 미래 값의 하한을 준다
- 확정 발화: 59–90초, 31초. 사용자 원문·종료 시각 유지.
- 세로 9:16. 자막 중심 y=-5.9, 본문 하단 y≥-4.65.
- 전체 실수 공간, κ=0.65, 양의 유계 계단 초기함수 f. 실제 가우스 합성곱 해 공유.
- 하르나크 비교는 0<t₁<t₂와 미래 값의 하한. 브라운 운동은 √(2κ)Bₜ. 유한 표본 평균은 근사로 표시.

# 열방정식 5장 — 열방정식은 공간의 모양까지 설명할 수 있을까?

사용자 확정 44문장·284초, 27개 독립 씬.16:9 1920×1080 30fps. 전체 원문 자막·상단 주제 안내. 음원 미제공으로 무음.

최종 렌더: `py -3.12 longforms/fourier_heat/chapter_05/build.py`

대표 씬: `py -3.12 longforms/fourier_heat/chapter_05/build.py --preview --scene 14`

검수: `py -3.12 longforms/fourier_heat/chapter_05/qa.py`

출력: `exports/heat_ch05_284s_longform_final.mp4`, 별도 `_captions.srt`.

구면 열핵의 스펙트럼 합, de Rham 열 흔적의 상쇄, 정확한 2차원 구면 리치 흐름을 사용한다. 특이점의 개념도와 3차원 푸앵카레 추측을 구별한다. 앞선 1–4장의 시각화 함수를 회고에 재사용한다. 대본·시각은 narration.md와 timing.json, 수학적 조건·출처는 brief.md, 콘티는 storyboard_source.txt.

Python 3.12, Manim 0.21, SciPy, FFmpeg, Malgun Gothic. 소스·타이밍·설정 해시가 일치하는 씬만 캐시를 재사용한다.

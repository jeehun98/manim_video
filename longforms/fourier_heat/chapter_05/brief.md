# 열방정식 5장 — 제작 기준

사용자 확정44문장·284초.27개 독립 씬,16:9 1920×1080 30fps. 음원 미제공으로 무음,원문 자막과 상단 안내 포함. 마지막 회고와 앞 장 언급은 이번 사용자 확정 대본이므로 유지한다. 임의 대본 수정·시간 연장·엔드카드 없음.

## 서사와 재사용

고정된 공간 위의 온도 변화 → 열핵으로 읽는 기하학 → 특정 작용소의 해석적 지표와 위상적 정보 → 계량 자체의 리치 흐름.139–162초에서 고정 격자의 온도 변화와 격자의 거리 변화를 대비한다. 회고는1장의 막대와 온도,2장의 동일한 세 사인 성분,3장의 동일 초기값과 비교 원리,4장의 동일 난수 경로·표본평균·위험중립 가격 계산을 직접 재사용한다.

## 수학적 조건

- Δ=div grad,κ=1. 단위 구면 S² 북극 점원 열핵은 Σ(l=0…60)(2l+1)exp(−l(l+1)t)P_l(cosθ)/(4π). 영상의t≥0.035에서 절단 오차는 수치 정밀도 이하. 구면 고정,색만 열핵 값에 따라 변화한다. 평면 열핵은exp(−r²/(4t))/(4πt). 화면 투영과 크기는 시각적 배치다.
- 평면→구면 모핑은 좌표 패치의 개념 전환이며 물리적 확산·위상동형 변형이 아니다. 단위 구면 계량ds²=dθ²+sin²θdφ². 곡면 위 경로와 공간 속 현을 구별한다.
- 경계 없는 매끄러운 리만 다양체에서 열핵의 대각 짧은 시간 점근식K(t,x,x)~(4πt)^(−n/2)(1+Scal(x)t/6+…).n은 차원,Scal은 스칼라 곡률. 단위S²에서2,평면에서0. 열 자료가 모든 모양을 유일하게 복원한다는 주장은 하지 않는다.
- 구면/도넛의 비특이 변형에서는 종수0/1과Euler 특성χ=2/0이 유지된다. 도넛의 열 확산을 임의로 계산한 것처럼 그리지 않는다.
- 적절한 타원형Fredholm 작용소의지표dim ker D−dim ker D*. 열 표현은Tr exp(−tD*D)−Tr exp(−tDD*). 일반 온도 그림으로 구멍을 세는 과정과 구별한다. 구체적 예는S²의de Rham 열 흔적:Tr₀=Tr₂=1+Σ(l≥1)(2l+1)exp(−l(l+1)t),Tr₁=2Σ…;따라서Tr₀−Tr₁+Tr₂=2=χ(S²). 양의 모드 상쇄와 영모드 잔류를 보여주는 예다.
- 리치 흐름∂tg=−2Ric(g)은 좌표 자유도를DeTurck 방식으로 조정하면 엄밀한 포물형 구조가 드러난다. 정확한 시각 예는2차원 둥근 구면g(t)=(1−2t)g₀,R(t)=sqrt(1−2t),0≤t<1/2. 모든 공간이 매끄럽게 둥근 구로 변한다는 주장을 하지 않는다.
-168–179초의 목이 가늘어지는 도형은 특이점의 개념도이며 실제Ricci 수치해나 수술 계산이 아니다. 푸앵카레 추측의 대상은 닫힌 단일연결3차원 다양체로,그림의2차원 표면과 구별한다. 해밀턴의 연구와 페렐만의 특이점 분석/해결을 분리한다.
- 회고는 기존 수학 조건을 유지한다. 최댓값 원리는 초기/경계 범위,하르나크는 양의 해의 시공간 값 비교. 금융은4장의 일정계수 무배당 모형,위험중립Q와 할인.

## 검증

mechanics.validate는 구면 열량 적분1,비음성,구면 열방정식 잔차,짧은 시간 곡률 계수1/3,de Rham supertrace2,정확한 리치 흐름 반지름 제곱의 미분−2를 확인한다.qa.py는 모든 문장 시작 자막과0.5초 간격 도형의 안전영역·대표 정지화면을 검사한다. 새 대표 씬12·14의 저해상도 움직임 확인 후 최종 렌더.build.py는 씬별 프레임·해상도·레이아웃,최종284초·8520프레임·무음을 확인한다.

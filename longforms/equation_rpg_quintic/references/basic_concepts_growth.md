# 방정식 RPG — 기초 개념을 다시 발견하는 성장 구성

기록일: 2026-11-19. 사용자 제작 방향을 기록한다. 아래 단계는 구성 초안이며 확정 대본·시간표가 아니다.

## 제작 방향

- 관객이 이미 아는 기초 개념도 당연하게 넘어가지 않는다. 화면 속 행동과 변화를 보며 각 연산과 개념의 의미를 다시 떠올리는 경험을 제공한다.
- 빠르게 고차 방정식에 도달하는 것만을 목표로 삼지 않는다. 다소 느리더라도 개념이 왜 필요하고 어떻게 이해되는지에 시간을 쓴다.
- 주인공의 성장은 수의 범위 확장뿐 아니라 문제를 해결하는 방식의 발전으로 보여준다.
- 처음 훈련에는 x나 미지수를 도입하지 않을 수 있다. 처음부터 이항을 알고 있는 인물로 설정하지 않는다.
- 덧셈·뺄셈·곱셈·나눗셈 각각의 의미와 관계를 화면에서 다룰 장면을 검토한다. 한 줄 계산이나 해금 메시지만으로 학습이 끝났다고 처리하지 않는다.
- 각 개념이 등장하는 필요와 역사적 맥락을 이야기 안에 연결하고, 관련 수학자를 스승으로 등장시키는 방향을 검토한다.

## 최초 도입 — 하나씩 세는 계산 (2026-11-19 사용자 방향)

- 첫 훈련은 1 + 1에서 시작한다. 주인공은 처음부터 덧셈 결과를 암산하거나 공식을 적용하지 않는다.
- 3 + 2도 세 개와 두 개의 낱개를 합쳐 1 + 1 + 1 + 1 + 1로 펼친 뒤, 하나씩 세어 5를 얻는다. 손가락을 펴서 수를 세는 듯한 구체적 경험이 출발점이다.
- 수식만 변환하지 않고, 화면의 낱개와 세는 순서가 대응되게 한다. 실제 손가락 그림 사용 여부와 낱개 오브젝트의 형태는 미확정이다.
- 숫자 3과 2가 각각 ‘하나가 세 개 있는 묶음’과 ‘하나가 두 개 있는 묶음’을 나타낸다는 의미를 먼저 보여준다. 펼친 뒤에도 원래 두 묶음의 구분을 잠시 유지하면 3 + 2와 다섯 낱개의 관계를 읽기 쉽다.
- 이후 ‘처음부터 전부 세기’에서 ‘이미 센 묶음의 수를 활용하기’로 발전시키는 장면을 검토한다. 첫 도입부터 이 단계를 자동으로 익힌 것으로 처리하지 않는다.
- 초기 주인공은 계산을 못하는 인물이 아니라, 구체적인 낱개와 하나씩 세기를 통해 계산하는 인물이다. 미지수·이항은 이보다 뒤에 둔다.

### 화면 진행 초안

| 순서 | 화면·행동 | 개념 |
| --- | --- | --- |
| 1 | 낱개 하나가 나타나고, 또 하나가 옆에 놓인다. 1 + 1을 표시한다. | 하나와 하나를 합친다. |
| 2 | 두 낱개를 순서대로 강조하며 누적 수 1, 2를 표시한다. 마지막에 1 + 1 = 2를 완성한다. | 세어서 합을 확인한다. |
| 3 | 낱개 세 개와 두 개를 구분해 놓고 3 + 2를 표시한다. | 숫자는 낱개의 개수를 나타낸다. |
| 4 | 세 개와 두 개를 각각 1 + 1 + 1과 1 + 1로 펼쳐 전체 1 + 1 + 1 + 1 + 1을 보여준다. | 두 묶음을 낱개로 풀어 합칠 수 있다. |
| 5 | 다섯 낱개를 차례로 강조하며 누적 수 1, 2, 3, 4, 5를 표시한다. 이후 3 + 2 = 5로 정리한다. | 덧셈의 결과를 하나씩 세어 얻는다. |

이 절은 사용자 방향을 보존한 도입 초안이다. 공격 모션·낱개 에셋·대사·재생시간은 별도 확정한다. 수학자 스승을 첫 세기 장면부터 반드시 등장시키는 것으로 정하지 않는다.

## 초기 성장 순서 초안

| 단계 | 주인공의 접근 | 관객이 다시 확인할 개념 |
| --- | --- | --- |
| 기초 계산 | 2 + 3 = ?처럼 주어진 수를 계산한다. | 연산 기호가 나타내는 실제 변화와 결과. 초기 훈련에 미지수는 필수가 아니다. |
| 빈칸 찾기 | □ + 3 = 5에서 가려진 수를 찾는다. | 결과를 구하는 문제와 출발값을 찾는 문제의 차이. |
| 대입과 확인 | 1을 넣으면 4, 2를 넣으면 5가 되어 성공한다. | 후보를 넣어 조건을 만족하는지 확인하는 방법. 시행착오는 유효한 풀이법이다. |
| 역연산의 필요 | □ + 3 = 98처럼 하나씩 시험하기 번거로운 문제를 만난다. | 더한 것을 되돌리는 뺄셈으로 98 − 3을 생각한다. 큰 수 자체가 기존 방법을 불가능하게 만드는 것은 아니다. |
| 미지수 표기 | 빈칸을 x로 나타낸다. | x는 찾아야 할 수를 가리키는 기호이며, 그 자체가 새 풀이법은 아니다. |
| 등식과 같은 조작 | x + 3 = 5의 양변에서 각각 3을 뺀다. | 등호는 두 값이 같다는 관계이며, 양변에 같은 수를 빼도 같음이 유지된다. |
| 이항으로 압축 | x + 3 − 3 = 5 − 3을 이해한 뒤 x = 5 − 3으로 줄여 쓴다. | 이항은 양변에 같은 연산을 적용하는 과정을 압축한 표현이다. |

이 표 전체를 짧은 몽타주로 소진하지 않는다. 각 단계에서 필요한 시도·질문·화면 검증을 대본으로 설계한다. 다른 연산과 그 역연산도 별도로 검토하며, 나눗셈에서는 0으로 나눌 수 없다는 조건 등을 생략하지 않는다.

## 스승과 발견 장면의 역할

- 문제를 만남 → 익숙한 접근 시도 → 한계나 번거로움 인식 → 스승의 질문·도구 → 주인공의 발견 → 검증 → 같은 문제에 적용하는 흐름을 기본으로 검토한다.
- 스승마다 새 공식만 지급하지 않는다. 주인공이 이미 시도한 방식에서 다음 생각을 끌어낼 수 있도록 돕는다.
- 실제 역사에서 개념이 발전한 과정과, 주인공이 개념을 배우는 창작 순서는 구분한다. 등장인물을 해당 개념의 단독 최초 발명자로 자동 지정하지 않는다.
- 수학자 후보와 역사적 기여는 대본 작성 시 자료를 확인해 결정한다. 이번 기록에서는 연산마다 담당 수학자를 임의 확정하지 않는다.
- 스승의 창작 대사는 역사적 인용문과 구분한다.

## 기존 콘티와의 관계

- 현재 화면의 x + 3 = 5 풀이·답 제출 시안은 이후 학습이 진행된 상태의 화면 참고로 유지한다. 도입부터 이항을 사용할 수 있다는 설정으로 해석하지 않는다.
- [데카르트 스승과 음수 발견 콘티](descartes_negative_numbers_storyboard.md)는 역연산과 등식 조작을 익힌 뒤의 장면 후보로 둔다. 해당 콘티 첫 장면의 “양쪽에서 3을 빼면 돼”는 선행 학습을 마친 상태를 전제로 한다.
- 기초 개념을 충분히 다루면 기존 12~15분 기획과 충돌할 수 있다. 개념을 생략하거나 대본을 급하게 압축하기 전에 전체 범위와 분량을 다시 검토한다. 이번 기록에서 분량 변경이나 추가 영상 제작을 확정하지 않는다.
- 확정 대본과 실제 발화·표시 조건이 정해지기 전에는 영상·자막·timing.json을 생성하지 않는다.

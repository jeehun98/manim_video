- ID: `equation_rpg_quintic`
- 상태: 기획 확인·작업 폴더 준비 (2026-11-18). 전체 대본 미작성·미확정.
- 형식: 16:9 수학 교육 롱폼, 목표 12~15분. 실제 길이는 확정된 화면 대사·음악·효과음의 진행에 따라 결정한다.

## 현재 연출 방향

Undertale 느낌의 픽셀 RPG 배경·전투창·대화창으로 통일한다. 기초 훈련에서 출발한 주인공이 수학자 스승들을 만나 성장하며, 최종전에서는 좌절과 스승들의 도움·희생으로 감정을 쌓는다. 음성 없이 화면 대사·BGM·효과음으로 진행하며 Undertale BGM 사용을 희망한다. 세부 스토리·곡·배치·사용 조건은 아직 확정하지 않았다. [현재 합의](plan.md)의 연출 방향 절을 우선한다.

큰 빈 대화창을 하단에 겹친다. 적의 오른쪽 위 원본 수식은 붉은 선으로 연결한다.
복사본은 주인공의 왼쪽 위에서 등호를 기준으로 정렬된 세 줄의 풀이로 누적한다.
답 `2`를 적 바로 앞까지 제출한 뒤 멈추며 원본·풀이 흔적은 유지한다.
피해와 적의 반응은 구현하지 않았다.

## 제작 기준

- ℚ → ℝ에서도 방정식과 수직선을 유지하며 유리수의 빈틈을 채우는 그림은 피한다.
- 함수 그래프의 세로축 f(x)와 복소평면의 허수축 Im z를 구별한다.
- 최종 보스는 x⁵−x−1=0. 근의 존재와 근호 표현 불가를 구분하고, 일반 5차 공식 부재와 개별 식의 판정을 구별한다.
- 갈루아 대칭은 대수적 관계를 보존하는 대칭으로 설명한다. 기하학적 회전으로 오해시키지 않는다.
- 약 20초 화면 테스트는 후보이며 제작하지 않았다. 화면 제작은 대본 검토·확정과 실제 발화시간 확보 뒤 진행한다.

## 작업 순서

스토리 구성 → 화면 대사 중심 전체 대본 작성·사용자 검토 → 대본 확정 → 씬 분할·spec → 읽기 시간과 음악·효과음 기준으로 길이 확정 → 화면 제작 → 씬별 음향 결합 → 최종 concat.

본편 음원·에셋·자막·타이밍·영상 렌더는 없다. 화면 구성 검토용 초기 화면 Manim 소스와 정지 렌더는 위 링크에 별도로 존재한다. 실행 명령과 렌더 ID는 구현 후 등록한다. 수학적 근거의 외부 출처 검증과 제작 환경 점검은 해당 제작 단계에서 수행한다.

# 전체 대본 — 작성 대기

현재 파일은 대본이 아닌 기획 흐름이다. 내레이션과 발화시간은 아직 정하지 않았다.

## 기획 흐름

1. 자연수 마을: x+3=5와 x+3=1, 정수로 확장.
2. 분수의 동굴: 2x=1, 유리수로 확장.
3. 제곱근 던전: x²−2=0, 실근의 존재와 ±√2라는 표현.
4. 허수의 탑: x²+1=0, 복소수와 ±i.
5. 고차 성채: 2·3·4차 근호 해법의 도구 조합.
6. 최종 보스: x⁵−x−1=0, 근의 존재·계산과 근호 표현 불가.
7. 결말: √2의 존재 질문을 어떤 연산으로 표현할 수 있는가라는 질문으로 회수.

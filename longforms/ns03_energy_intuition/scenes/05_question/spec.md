# Scene 05 — 실제 유체도 이렇게 움직일까?
## 목적과 핵심 주장
실제 유체도 이렇게 움직일까?를 한 장면에서 이해시킨다.
## 앞 장면에서 받은 내용
모두 합하기와, 가장 큰 것 찾기
## TTS 원문과 확정 길이
하지만 지금까지의 그림은 가능성을 설명하는 모형입니다.

빠른 영역이 좁아지는 모습을 그리는 것과, 실제 유체가 그렇게 움직이는 것은 다른 문제입니다.

실제 흐름은 주변으로 이동하고, 압력에 밀리고, 점성으로 퍼지는 과정을 함께 따라야 합니다.

그렇다면 이 조건들을 지키면서도 속도가 폭주하는 흐름을 만들 수 있을까요? 다음 막에서는 이 질문을 보겠습니다.

- TTS: 사용자 측정 22초
- 화면: 22초. 원래 화면 기준은 26초.
## 화면 구성과 시간대별 애니메이션
집중 개념도 → 이동/압력/퍼짐/외력의 네 조건 → 4막 질문
문장 순서대로 timing.json의 ends에 맞춰 cue를 진행한다.
## 화면 텍스트
실제 유체도 이렇게 움직일까?, 에너지·속도·부피 지표, 수식, 출처·날짜, 문장 자막. 영문과 숫자 기호는 화면에 원 표기를 쓴다.
## 시작·종료 상태
첫 대상에서 마지막 대상으로 연속 변형한다. 상단 제목과 하단 자막 영역을 확보한다.

## 수학 조건·과장 방지
수식의 항별 분석은 하지 않는다. 실제 해의 조건이 따로 필요함을 분명히 한다.
모든 단순 모형과 개념도는 실제 NS 해나 신경망의 측정값이 아니다. 실제 해의 정확한 항 수치를 시뮬레이션하지 않는다. 외력이 있는 3막에서는 2막의 curl f=0 조건을 가정하지 않는다.

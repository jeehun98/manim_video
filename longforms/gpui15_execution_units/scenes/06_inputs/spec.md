# 입력과 제어 정보도 각각 전달한다

주장: 입력과 제어 정보도 각각 전달한다. 확정시간58–71초.

58–64: 각 ALU에는 자신이 계산할 숫자와 어떤 연산을 수행할지 나타내는 제어 정보가 전달되어야 합니다.
64–71: 따라서 레지스터 파일에서 읽은 값과 명령어의 제어 정보를 각 ALU에 전달할 수 있도록 입력 경로를 확장합니다.

화면은 ../../storyboard_reference.md 해당부분과 ../../scene_engine.py의 inputs를따른다. A파랑,B보라,신규회로초록,제어주황. 도식과하단단일자막분리,화면비별위치조정.

A=ADD R3,R1,R2(R1=5,R2=3),B=SUB R6,R4,R5(R4=9,R5=2),초기R3=R6=0,목표R3=8/R6=7. 두 명령어는 이미 실행 대기 상태라고 가정하며 인출/해독대역폭·스케줄러를완성하지않는다. 두ALU는모두ADD/SUB지원,이번배정만각각ADD/SUB. ALU추가와입력/제어/결과경로완성을구분. 읽기포트2→4,쓰기포트1→2는교육용설계선택(뱅킹/미리읽기/버퍼/시간분할등대안존재). 결과값과목적지/유효쓰기정보를각각보관하고CLK에지에서서로다른목적지를원자갱신. 한쓰기포트에두결과를잘못합치거나둘다썼다고표현하지않음. 같은입력값을공유한다는이유만으로의존성을선언하지않고뒤명령이앞결과를사용하는별도예시에서대기. 비용은면적/배선/제어복잡도,프로그램전체2배성능단정없음. 후반명령어선택은질문만제시하고비순차실행정당성/정확한퇴직순서를구현한것처럼표시하지않음. 최신원문26문장141초엄수,추가엔드카드없음.

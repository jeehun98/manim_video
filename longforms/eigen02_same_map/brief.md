# 제작 기준

## 목표

다른 행렬 원소와 다른 좌표 계산 결과가 같은 선형변환을 나타낼 수 있음을 발견한다. 같은 좌표 숫자와 같은 실제 벡터를 구분한다.

## 확정 시간

사용자 문장 종료 시각 1,7,10,15,20,25,30,31,34,37,43,49,53,59,64,68,72,77,79,85,89,93,99,106,110,115,120초. 추정 배분 금지. 음원 미제공.

## 시각 기준

A 파랑#458EFA, D 보라#B68AFA, v1 청록#20BCA5, v2 주황#F0A34E, 실제 입력 흰색, 일치 출력 노랑. 세로는 두 패널 위아래, 가로는 좌우. 비교 패널의 원점과 물리적 척도는 동일. 단위 정사각형과 격자에는 정확한 행렬곱 적용. 기저 눈금1은 (1,1),(1,−1)에 표시. 좌표 표시 평면에서 실제 공간으로 이동할 때 기저와 출력에 동일한 P를 적용. 화살표를 임의 회전해 맞추지 않는다.

## 자막

기존 episodes 쇼츠와 1편 수정 기준의 세로60px·하단170px 여백, 두 줄 자막. 공식·보조 설명은 위에 작고 흐리게 둔다. 내레이션 핵심 문장27개를 제공 발화 구간에 표시한다. 별도 전체원문SRT도 보존한다.

## 독립성

복습·요약·다음편 예고 없이 같은 변환과 다른 표현이라는 결론으로 완결한다. 닮음 공식의 긴 전개는 넣지 않는다.

# 02. 숫자가 다른 두 행렬이 같은 변환일 수 있을까?

이번 편의 핵심은 서로 다른 두 행렬의 결과를 억지로 일치시키는 것이 아니라, 각 행렬이 사용하는 좌표계를 올바르게 해석했을 때 같은 기하학적 변환이 드러나는 과정이야.

영상은 다음 세 번의 시각적 전환을 중심으로 만들어야 해.

첫 번째 발견 — 서로 다른 변형

### SCENE 02 — 같은 숫자를 곱하면 다른 결과

00:07–00:15 · 최초의 의문

내레이션

> 두 행렬에 같은 좌표 숫자를 입력하면 서로 다른 결과가 나옵니다. 그렇다면 이 두 행렬은 반드시 서로 다른 변환을 나타낼까요?

화면 연출

- 두 행렬 아래에 동일한 좌표열 \\((1,0)\\)을 넣는다.
- 첫 행렬의 출력은 \\((2,1)\\).
- 둘째 행렬의 출력은 \\((3,0)\\).
- 숫자가 다른 결과를 동시에 강조한다.
- 질문이 등장할 때 두 출력 사이에 물음표를 표시한다.

\\[ A(1,0)=(2,1),\qquad D(1,0)=(3,0) \\]

주의: 이 구간은 아직 둘 다 표준 기저에서 해석하는 비교다. 같은 숫자를 넣었을 뿐, 서로 다른 기저에서 같은 실제 벡터를 비교한 것은 아니다.

### SCENE 03 — 같은 표준 좌표계에서 공간 변형 비교

00:15–00:31 · 서로 다른 작용

내레이션

> 먼저 두 행렬을 모두 같은 수평·수직 좌표계에서 해석해 보겠습니다. 첫 번째 행렬은 수평과 수직 방향의 성분을 서로 섞으며 공간을 변형합니다. 반면 두 번째 행렬은 수평 방향으로 3배 늘리고, 수직 방향은 그대로 유지합니다. 분명 서로 다른 모습입니다.

화면 연출

- 화면을 좌우로 분리해 동일한 정사각형 격자를 보여준다.
- 왼쪽에는 \\(A\\), 오른쪽에는 \\(D\\)를 배치한다.
- 두 화면의 격자는 동일한 크기·좌표 범위·카메라 비율로 고정한다.
- 각각의 행렬을 격자 전체에 적용해 공간이 변형되는 모습을 보여준다.

개념적 비교: A는 격자를 기울이고, D는 좌표축 방향으로 독립적인 배율을 적용한다.

중요한 구현 조건

실제 Manim 애니메이션에서는 개념적 스케치가 아니라 행렬의 열벡터를 기준으로 격자 전체를 정확히 변형해야 한다.

- \\(A e_1=(2,1)\\), \\(A e_2=(1,2)\\)
- \\(D e_1=(3,0)\\), \\(D e_2=(0,1)\\)

따라서 \\(A\\)의 단위 정사각형은 기울어진 평행사변형으로, \\(D\\)의 단위 정사각형은 가로가 3배인 직사각형으로 나타난다.

이때 격자 간격이 실제 배율을 보여주도록 카메라 자동 확대·축소는 사용하지 않는다.

### SCENE 05 — 새로운 좌표축 등장

00:43–00:53 · 기저 변경

내레이션

> 이번에는 오른쪽 위와 오른쪽 아래를 향하는 두 대각선 방향을 새로운 좌표축으로 선택하겠습니다. 각 좌표축의 단위 눈금도 새로운 기준에 맞춰 바꿉니다.

화면 연출

- 기존 수평·수직 축은 점차 희미해진다.
- 원점에서 오른쪽 위 방향으로 청록색 벡터 \\(v_1=(1,1)\\)이 등장한다.
- 오른쪽 아래 방향으로 주황색 벡터 \\(v_2=(1,-1)\\)가 등장한다.
- 새로운 좌표축은 두 직선의 전체 연장선으로 그린다.
- 각 축의 단위 눈금 `1`은 해당 기저벡터의 끝점에 배치한다.
- 축의 방향만 바꾼 것이 아니라, 좌표를 측정하는 기준 자체가 달라졌다는 것을 나타낸다.

\\[ v_1=(1,1),\qquad v_2=(1,-1) \\]

실제 공간 기준으로 두 기저벡터의 길이는 모두 \\(\sqrt2\\)이다. 따라서 새 좌표에서 1단위는 기존 표준 기저의 1단위보다 길다.

### SCENE 06 — 실제 벡터는 움직이지 않는다

00:53–01:04 · 좌표 표현의 변화

내레이션

> 벡터가 움직인 것은 아닙니다. 같은 벡터를 나타내는 기준과 좌표 숫자만 달라졌습니다. 표준 좌표에서 2, 1인 벡터는 새로운 좌표계에서 1.5, 0.5가 됩니다.

화면 연출

이 구간에서 가장 중요한 장면은 벡터의 화살표가 한 픽셀도 움직이지 않는 것이야.

- 흰색 실제 벡터 \\((2,1)\\)을 그대로 유지한다.
- 표준 좌표 레이블 `(2, 1)`을 표시한다.
- 새로운 두 고유기저 방향에서 벡터의 성분을 분해한다.
- 청록색 방향으로 1.5단위, 주황색 방향으로 0.5단위를 이동하면 같은 끝점에 도달한다.
- 좌표 레이블이 `(1.5, 0.5)`로 바뀐다.

\\[ (2,1)=1.5(1,1)+0.5(1,-1) \\]

실제 벡터는 하나이지만 좌표 표현은 두 가지다.

영상 구현에서는 위 개념도를 정확한 좌표 비율에 맞춰 다시 그려야 해. 특히 고유기저의 성분을 더하는 평행사변형이 원래 벡터의 끝점에서 정확히 닫혀야 한다.

### SCENE 07 — 서로 다른 좌표계에서 계산하기

01:04–01:17 · 두 계산의 병렬 진행

내레이션

> 이제 두 좌표계에서 각각의 행렬을 적용해 보겠습니다. 첫 번째 행렬을 적용하면 표준 좌표에서 5, 4가 나옵니다. 두 번째 행렬을 적용하면 새로운 좌표계에서 4.5, 0.5가 나옵니다.

화면 연출

화면을 좌우로 나누고, 같은 실제 입력 벡터를 각자의 좌표계에 표시한다.

표준 기저에서 계산

\\[ \begin{pmatrix}2&1\\\1&2\end{pmatrix} \\]

\\(\binom{2}{1}\\)\\(\binom{5}{4}\\)

출력 좌표 (5, 4)

고유벡터 기저에서 계산

\\[ \begin{pmatrix}3&0\\\0&1\end{pmatrix} \\]

\\(\binom{1.5}{0.5}\\)\\(\binom{4.5}{0.5}\\)

출력 좌표 (4.5, 0.5)

세부 애니메이션

- 64\~68초: 화면을 두 영역으로 나눈다. 흰색 입력 벡터는 각각의 좌표계에 같은 실제 방향과 길이로 배치한다.
- 68\~72초: 왼쪽에서 \\(A\\)를 적용한다. 벡터가 실제 위치 \\((5,4)\\)로 이동하며 길어진다.
- 72\~77초: 오른쪽에서 \\(D\\)를 적용한다. 새로운 좌표의 첫 번째 성분은 1.5에서 4.5로, 두 번째 성분은 0.5로 유지된다.

중요한 구현 차이

오른쪽 화면은 두 가지 방법 중 하나로 일관되게 제작해야 해.

1. 고유좌표를 좌표평면에 그대로 표시한다면, 벡터의 끝점은 좌표 숫자 \\((4.5,0.5)\\)에 놓인다.
2. 두 기저벡터를 실제 공간에 그린다면, 출력의 끝점은 물리적으로 \\((5,4)\\)에 해당하는 위치에 놓인다.

이번 편에서는 1번으로 숫자 차이를 먼저 보여주고, 이후 2번으로 대응시키는 연출이 발견의 효과가 가장 커.

### SCENE 08 — 다른 출력 숫자, 같은 실제 벡터

01:17–01:29 · 영상의 결정적 장면

내레이션

> 출력된 좌표 숫자는 서로 다릅니다. 하지만 새로운 좌표축을 기준으로 결과를 그려보면, 두 화살표는 실제 공간에서 정확히 겹칩니다. 서로 다른 숫자로 계산했지만, 같은 실제 벡터에 도달한 것입니다.

이 장면에는 가장 많은 시각적 집중도를 배정하자.

연출 흐름

- 두 성분의 합이 표준 좌표 \\((5,4)\\)에 정확히 도달한다.
- 좌우 화면의 기준 원점과 물리적 길이 척도를 일치시켜 두 출력을 같은 공간에 겹친다.
- 85초: 완전히 일치한 두 화살표를 하나의 노란색 벡터로 표시한다.

출력 벡터가 일치하는 과정

\\[ 4.5(1,1)+0.5(1,-1)=(5,4) \\]

## 두 계산, 하나의 실제 결과

개념적 구도이며, 실제 제작에서는 기저 성분과 출력 벡터의 좌표를 같은 척도로 정확하게 배치한다.

이 장면의 핵심은 화면을 돌려 결과를 억지로 겹치는 것이 아니라, 오른쪽 좌표계의 좌표 숫자를 실제 공간의 벡터로 변환하면 왼쪽 결과와 정확히 일치한다는 것을 보여주는 것이야.

가능하면 겹치는 순간에만 짧은 강조 효과를 주고, 다른 장면에서는 시각효과를 최소화하자.

### SCENE 09 — 한 벡터에서만 일어나는 우연일까?

01:29–01:39 · 일반성 확인

내레이션

> 그리고 이 일치는 지금 선택한 벡터에서만 일어나는 것이 아닙니다. 어떤 벡터를 선택해도, 좌표를 올바르게 바꾸어 계산하면 같은 실제 결과에 도달합니다.

화면 연출

- 출력이 겹친 상태를 유지한 뒤 입력 벡터를 다른 방향으로 변경한다.
- 예시로 표준 좌표 \\((1,0)\\), \\((0,1)\\), \\((-1,1)\\)을 순서대로 선택한다.
- 각각 오른쪽 화면에서는 고유기저 좌표로 자동 변환된다.
- 두 행렬의 출력을 계산한 뒤, 같은 실제 공간에 대응시킨다.

## 4. Manim 제작을 위한 구조 제안

이번 편에서는 단순한 좌표축 회전 애니메이션보다 실제 공간(world space)과 좌표 표현(coordinate space)을 분리하는 구조가 매우 중요해.

개념적으로 다음 관계를 모든 장면에서 유지해야 해.

\\[ x\_{\mathrm{world}}=Px\_{\mathrm{eigen}} \\]

그리고

\\[ Ax\_{\mathrm{world}}=PDx\_{\mathrm{eigen}} \\]

이렇게 해야 카메라나 좌표축을 어떻게 연출하더라도 실제 출력 벡터가 정확하게 대응돼.

### 구현용 수치 검증

```
import numpy as npA = np.array([[2, 1],              [1, 2]], dtype=float)D = np.diag([3, 1])P = np.array([[1, 1],              [1, -1]], dtype=float)x_world = np.array([2, 1], dtype=float)x_eigen = np.linalg.solve(P, x_world)y_world = A @ x_worldy_eigen = D @ x_eigenassert np.allclose(x_world, P @ x_eigen)assert np.allclose(y_world, P @ y_eigen)assert np.allclose(A @ P, P @ D)
```

애니메이션에서는 두 계산 결과가 다른 실제 위치에 나타나게 만드는 대신, 각 좌표계에서 올바른 위치를 계산한 뒤 같은 물리적 공간에 대응시키면 완전히 겹치도록 해야 해.

특히 31\~53초에서 축을 바꿀 때는 그 축을 실제로 회전시키는 것과 좌표의 수학적 기준을 변경하는 것을 혼동하지 않아야 한다. 이번 예시는 고유기저가 서로 직교하므로 축 회전으로 방향을 설명할 수 있지만, 새 단위 길이는 \\(\sqrt2\\)이므로 눈금도 함께 조정해야 해.

## 5. 가장 중요한 제작 판단

이번 편에서 가장 많은 시각적 노력을 투자해야 하는 곳은 53\~89초야.

53\~64초에는 같은 벡터가 서로 다른 좌표로 표현되는 사실을 충분히 보여주고, 64\~77초에는 서로 다른 숫자로 계산하는 과정을 보여주고, 77\~89초에는 결과가 정확하게 겹치는 장면을 완성해야 해.

이 세 장면이 정확하면 닮음 변환 공식은 짧게 제시해도 이해할 수 있어.

반대로 이 장면들이 불명확하면 시청자는 좌표축을 돌려 서로 다른 변환을 강제로 일치시킨 것으로 받아들일 수 있어.

마지막으로 영상의 결론은 다음 구분을 선명하게 유지해야 해.

같은 좌표계에서 두 행렬은 서로 다른 작용을 한다. 하지만 서로 다른 기저에서 같은 선형변환을 표현할 수 있다.

이 발견이 이번 2편의 독립적인 가치이자, 이후 고윳값의 좌표 불변성과 고유기저를 이용한 대각화로 이어지는 수학적 기반이야.

# 02. 같은 숫자를 곱하면 다른 결과

- 구간: 7–15초
- 시간 근거: 사용자 문장별 종료 시각, 총120초. 실제 음원 미제공.
- 내레이션: script.txt (확정 원문)
- 화면: 세로 위아래 / 가로 좌우 비교. 실제 공간과 좌표 표현 구별.
- 자막: 문장별 종료 시각에 맞춘 핵심 발췌.
- 시작·종료 및 화면·수학 조건: 아래 사용자 콘티 준수.
- 연결: 복습·예고 없이 독립 결론.

같은 숫자를 곱하면 다른 결과

00:07–00:15 · 최초의 의문

내레이션

> 두 행렬에 같은 좌표 숫자를 입력하면 서로 다른 결과가 나옵니다. 그렇다면 이 두 행렬은 반드시 서로 다른 변환을 나타낼까요?

화면 연출

- 두 행렬 아래에 동일한 좌표열 \\((1,0)\\)을 넣는다.
- 첫 행렬의 출력은 \\((2,1)\\).
- 둘째 행렬의 출력은 \\((3,0)\\).
- 숫자가 다른 결과를 동시에 강조한다.
- 질문이 등장할 때 두 출력 사이에 물음표를 표시한다.

\\[ A(1,0)=(2,1),\qquad D(1,0)=(3,0) \\]

주의: 이 구간은 아직 둘 다 표준 기저에서 해석하는 비교다. 같은 숫자를 넣었을 뿐, 서로 다른 기저에서 같은 실제 벡터를 비교한 것은 아니다.

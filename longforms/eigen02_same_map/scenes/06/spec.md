# 06. 실제 벡터는 움직이지 않는다

- 구간: 53–64초
- 시간 근거: 사용자 문장별 종료 시각, 총120초. 실제 음원 미제공.
- 내레이션: script.txt (확정 원문)
- 화면: 세로 위아래 / 가로 좌우 비교. 실제 공간과 좌표 표현 구별.
- 자막: 문장별 종료 시각에 맞춘 핵심 발췌.
- 시작·종료 및 화면·수학 조건: 아래 사용자 콘티 준수.
- 연결: 복습·예고 없이 독립 결론.

실제 벡터는 움직이지 않는다

00:53–01:04 · 좌표 표현의 변화

내레이션

> 벡터가 움직인 것은 아닙니다. 같은 벡터를 나타내는 기준과 좌표 숫자만 달라졌습니다. 표준 좌표에서 2, 1인 벡터는 새로운 좌표계에서 1.5, 0.5가 됩니다.

화면 연출

이 구간에서 가장 중요한 장면은 벡터의 화살표가 한 픽셀도 움직이지 않는 것이야.

- 흰색 실제 벡터 \\((2,1)\\)을 그대로 유지한다.
- 표준 좌표 레이블 `(2, 1)`을 표시한다.
- 새로운 두 고유기저 방향에서 벡터의 성분을 분해한다.
- 청록색 방향으로 1.5단위, 주황색 방향으로 0.5단위를 이동하면 같은 끝점에 도달한다.
- 좌표 레이블이 `(1.5, 0.5)`로 바뀐다.

\\[ (2,1)=1.5(1,1)+0.5(1,-1) \\]

실제 벡터는 하나이지만 좌표 표현은 두 가지다.

영상 구현에서는 위 개념도를 정확한 좌표 비율에 맞춰 다시 그려야 해. 특히 고유기저의 성분을 더하는 평행사변형이 원래 벡터의 끝점에서 정확히 닫혀야 한다.

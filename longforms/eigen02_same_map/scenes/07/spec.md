# 07. 서로 다른 좌표계에서 계산하기

- 구간: 64–77초
- 시간 근거: 사용자 문장별 종료 시각, 총120초. 실제 음원 미제공.
- 내레이션: script.txt (확정 원문)
- 화면: 세로 위아래 / 가로 좌우 비교. 실제 공간과 좌표 표현 구별.
- 자막: 문장별 종료 시각에 맞춘 핵심 발췌.
- 시작·종료 및 화면·수학 조건: 아래 사용자 콘티 준수.
- 연결: 복습·예고 없이 독립 결론.

서로 다른 좌표계에서 계산하기

01:04–01:17 · 두 계산의 병렬 진행

내레이션

> 이제 두 좌표계에서 각각의 행렬을 적용해 보겠습니다. 첫 번째 행렬을 적용하면 표준 좌표에서 5, 4가 나옵니다. 두 번째 행렬을 적용하면 새로운 좌표계에서 4.5, 0.5가 나옵니다.

화면 연출

화면을 좌우로 나누고, 같은 실제 입력 벡터를 각자의 좌표계에 표시한다.

표준 기저에서 계산

\\[ \begin{pmatrix}2&1\\\1&2\end{pmatrix} \\]

\\(\binom{2}{1}\\)\\(\binom{5}{4}\\)

출력 좌표 (5, 4)

고유벡터 기저에서 계산

\\[ \begin{pmatrix}3&0\\\0&1\end{pmatrix} \\]

\\(\binom{1.5}{0.5}\\)\\(\binom{4.5}{0.5}\\)

출력 좌표 (4.5, 0.5)

세부 애니메이션

- 64\~68초: 화면을 두 영역으로 나눈다. 흰색 입력 벡터는 각각의 좌표계에 같은 실제 방향과 길이로 배치한다.
- 68\~72초: 왼쪽에서 \\(A\\)를 적용한다. 벡터가 실제 위치 \\((5,4)\\)로 이동하며 길어진다.
- 72\~77초: 오른쪽에서 \\(D\\)를 적용한다. 새로운 좌표의 첫 번째 성분은 1.5에서 4.5로, 두 번째 성분은 0.5로 유지된다.

중요한 구현 차이

오른쪽 화면은 두 가지 방법 중 하나로 일관되게 제작해야 해.

1. 고유좌표를 좌표평면에 그대로 표시한다면, 벡터의 끝점은 좌표 숫자 \\((4.5,0.5)\\)에 놓인다.
2. 두 기저벡터를 실제 공간에 그린다면, 출력의 끝점은 물리적으로 \\((5,4)\\)에 해당하는 위치에 놓인다.

이번 편에서는 1번으로 숫자 차이를 먼저 보여주고, 이후 2번으로 대응시키는 연출이 발견의 효과가 가장 커.

## 4. Manim 제작을 위한 구조 제안

이번 편에서는 단순한 좌표축 회전 애니메이션보다 실제 공간(world space)과 좌표 표현(coordinate space)을 분리하는 구조가 매우 중요해.

개념적으로 다음 관계를 모든 장면에서 유지해야 해.

\\[ x\_{\mathrm{world}}=Px\_{\mathrm{eigen}} \\]

그리고

\\[ Ax\_{\mathrm{world}}=PDx\_{\mathrm{eigen}} \\]

이렇게 해야 카메라나 좌표축을 어떻게 연출하더라도 실제 출력 벡터가 정확하게 대응돼.

### 구현용 수치 검증

```
import numpy as npA = np.array([[2, 1],              [1, 2]], dtype=float)D = np.diag([3, 1])P = np.array([[1, 1],              [1, -1]], dtype=float)x_world = np.array([2, 1], dtype=float)x_eigen = np.linalg.solve(P, x_world)y_world = A @ x_worldy_eigen = D @ x_eigenassert np.allclose(x_world, P @ x_eigen)assert np.allclose(y_world, P @ y_eigen)assert np.allclose(A @ P, P @ D)
```

애니메이션에서는 두 계산 결과가 다른 실제 위치에 나타나게 만드는 대신, 각 좌표계에서 올바른 위치를 계산한 뒤 같은 물리적 공간에 대응시키면 완전히 겹치도록 해야 해.

특히 31\~53초에서 축을 바꿀 때는 그 축을 실제로 회전시키는 것과 좌표의 수학적 기준을 변경하는 것을 혼동하지 않아야 한다. 이번 예시는 고유기저가 서로 직교하므로 축 회전으로 방향을 설명할 수 있지만, 새 단위 길이는 \\(\sqrt2\\)이므로 눈금도 함께 조정해야 해.

## 5. 가장 중요한 제작 판단

이번 편에서 가장 많은 시각적 노력을 투자해야 하는 곳은 53\~89초야.

53\~64초에는 같은 벡터가 서로 다른 좌표로 표현되는 사실을 충분히 보여주고, 64\~77초에는 서로 다른 숫자로 계산하는 과정을 보여주고, 77\~89초에는 결과가 정확하게 겹치는 장면을 완성해야 해.

이 세 장면이 정확하면 닮음 변환 공식은 짧게 제시해도 이해할 수 있어.

반대로 이 장면들이 불명확하면 시청자는 좌표축을 돌려 서로 다른 변환을 강제로 일치시킨 것으로 받아들일 수 있어.

마지막으로 영상의 결론은 다음 구분을 선명하게 유지해야 해.

같은 좌표계에서 두 행렬은 서로 다른 작용을 한다. 하지만 서로 다른 기저에서 같은 선형변환을 표현할 수 있다.

이 발견이 이번 2편의 독립적인 가치이자, 이후 고윳값의 좌표 불변성과 고유기저를 이용한 대각화로 이어지는 수학적 기반이야.

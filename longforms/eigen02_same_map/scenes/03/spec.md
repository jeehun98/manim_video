# 03. 같은 표준 좌표계에서 공간 변형 비교

- 구간: 15–31초
- 시간 근거: 사용자 문장별 종료 시각, 총120초. 실제 음원 미제공.
- 내레이션: script.txt (확정 원문)
- 화면: 세로 위아래 / 가로 좌우 비교. 실제 공간과 좌표 표현 구별.
- 자막: 문장별 종료 시각에 맞춘 핵심 발췌.
- 시작·종료 및 화면·수학 조건: 아래 사용자 콘티 준수.
- 연결: 복습·예고 없이 독립 결론.

같은 표준 좌표계에서 공간 변형 비교

00:15–00:31 · 서로 다른 작용

내레이션

> 먼저 두 행렬을 모두 같은 수평·수직 좌표계에서 해석해 보겠습니다. 첫 번째 행렬은 수평과 수직 방향의 성분을 서로 섞으며 공간을 변형합니다. 반면 두 번째 행렬은 수평 방향으로 3배 늘리고, 수직 방향은 그대로 유지합니다. 분명 서로 다른 모습입니다.

화면 연출

- 화면을 좌우로 분리해 동일한 정사각형 격자를 보여준다.
- 왼쪽에는 \\(A\\), 오른쪽에는 \\(D\\)를 배치한다.
- 두 화면의 격자는 동일한 크기·좌표 범위·카메라 비율로 고정한다.
- 각각의 행렬을 격자 전체에 적용해 공간이 변형되는 모습을 보여준다.

개념적 비교: A는 격자를 기울이고, D는 좌표축 방향으로 독립적인 배율을 적용한다.

중요한 구현 조건

실제 Manim 애니메이션에서는 개념적 스케치가 아니라 행렬의 열벡터를 기준으로 격자 전체를 정확히 변형해야 한다.

- \\(A e_1=(2,1)\\), \\(A e_2=(1,2)\\)
- \\(D e_1=(3,0)\\), \\(D e_2=(0,1)\\)

따라서 \\(A\\)의 단위 정사각형은 기울어진 평행사변형으로, \\(D\\)의 단위 정사각형은 가로가 3배인 직사각형으로 나타난다.

이때 격자 간격이 실제 배율을 보여주도록 카메라 자동 확대·축소는 사용하지 않는다.

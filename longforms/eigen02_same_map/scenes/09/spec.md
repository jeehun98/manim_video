- 자막: 문장별 종료 시각에 맞춘 핵심 발췌.
- 시작·종료 및 화면·수학 조건: 아래 사용자 콘티 준수.
- 연결: 복습·예고 없이 독립 결론.

한 벡터에서만 일어나는 우연일까?

01:29–01:39 · 일반성 확인

내레이션

> 그리고 이 일치는 지금 선택한 벡터에서만 일어나는 것이 아닙니다. 어떤 벡터를 선택해도, 좌표를 올바르게 바꾸어 계산하면 같은 실제 결과에 도달합니다.

화면 연출

- 출력이 겹친 상태를 유지한 뒤 입력 벡터를 다른 방향으로 변경한다.
- 예시로 표준 좌표 \\((1,0)\\), \\((0,1)\\), \\((-1,1)\\)을 순서대로 선택한다.
- 각각 오른쪽 화면에서는 고유기저 좌표로 자동 변환된다.
- 두 행렬의 출력을 계산한 뒤, 같은 실제 공간에 대응시킨다.
- 세 번 모두 결과 화살표가 겹친다.
- 마지막에는 여러 출력 벡터를 작은 잔상으로 남겨 변환 전체의 일치를 강조한다.

| 표준 입력  | 고유기저 입력    | 표준 출력  | 고유기저 출력    |
| ------ | ---------- | ------ | ---------- |
| (1,0)  | (0.5,0.5)  | (2,1)  | (1.5,0.5)  |
| (0,1)  | (0.5,-0.5) | (1,2)  | (1.5,-0.5) |
| (-1,1) | (0,1)      | (-1,1) | (0,1)      |

이 표의 값은 제작 검증용이고, 실제 쇼츠에는 네 개의 숫자열을 전부 읽거나 표시할 필요가 없어.

화면 보조 수식

\\[ AP=PD \\]

이 수식은 다음 의미를 갖는다는 점을 화살표 다이어그램으로 보여주면 좋아.

경로 1

고유좌표

P로 실제 좌표 표현

A 적용

경로 2

고유좌표

D 적용

P로 실제 좌표 표현

두 경로는 언제나 동일한 출력

# 08. 다른 출력 숫자, 같은 실제 벡터

- 구간: 77–89초
- 시간 근거: 사용자 문장별 종료 시각, 총120초. 실제 음원 미제공.
- 내레이션: script.txt (확정 원문)
- 화면: 세로 위아래 / 가로 좌우 비교. 실제 공간과 좌표 표현 구별.
- 자막: 문장별 종료 시각에 맞춘 핵심 발췌.
- 시작·종료 및 화면·수학 조건: 아래 사용자 콘티 준수.
- 연결: 복습·예고 없이 독립 결론.

다른 출력 숫자, 같은 실제 벡터

01:17–01:29 · 영상의 결정적 장면

내레이션

> 출력된 좌표 숫자는 서로 다릅니다. 하지만 새로운 좌표축을 기준으로 결과를 그려보면, 두 화살표는 실제 공간에서 정확히 겹칩니다. 서로 다른 숫자로 계산했지만, 같은 실제 벡터에 도달한 것입니다.

이 장면에는 가장 많은 시각적 집중도를 배정하자.

연출 흐름

- 77초: 양쪽 출력 좌표 숫자 `(5,4)`와 `(4.5,0.5)`를 동시에 보여준다.
- 79초: 오른쪽의 결과를 고유기저 \\(v_1,v_2\\)를 기준으로 해석한다.
- 청록색 성분 \\(4.5v_1\\)을 그리고, 그 끝에서 주황색 성분 \\(0.5v_2\\)를 더한다.
- 두 성분의 합이 표준 좌표 \\((5,4)\\)에 정확히 도달한다.
- 좌우 화면의 기준 원점과 물리적 길이 척도를 일치시켜 두 출력을 같은 공간에 겹친다.
- 85초: 완전히 일치한 두 화살표를 하나의 노란색 벡터로 표시한다.

출력 벡터가 일치하는 과정

\\[ 4.5(1,1)+0.5(1,-1)=(5,4) \\]

## 두 계산, 하나의 실제 결과

개념적 구도이며, 실제 제작에서는 기저 성분과 출력 벡터의 좌표를 같은 척도로 정확하게 배치한다.

이 장면의 핵심은 화면을 돌려 결과를 억지로 겹치는 것이 아니라, 오른쪽 좌표계의 좌표 숫자를 실제 공간의 벡터로 변환하면 왼쪽 결과와 정확히 일치한다는 것을 보여주는 것이야.

가능하면 겹치는 순간에만 짧은 강조 효과를 주고, 다른 장면에서는 시각효과를 최소화하자.

# 제작 기준

- 주장은 하나: 뒤에 만든 직교 방향이 앞부분 공간에 수직인 관계가 R의 아래쪽 0으로 기록된다.
- 첫 열의 두 0, 둘째 열의 한 0을 개별 내적 결과에서 해당 행렬 원소로 연결한다.
- 원래 벡터는 흰색, q₁ 파랑·q₂ 초록·q₃ 주황, 투영·연결선 보라, 확정 순간의 0 빨강→회색.
- 원래 벡터 집합을 하나의 공통 회전으로 직교 기저로 바꾸지 않는다.
- 단위 직교 기저이므로 rᵢⱼ=qᵢᵀaⱼ. 대각 성분 양수 규약. 열들은 선형독립.
- 1편의 예시와 달리 a₃=(1,2,2)를 사용하며, 대각선 위의 세 계수 모두 0이 아니다.
- 부분공간 보존은 동일한 직선·평면·3차원 격자를 유지한 채 두 벡터 집합의 강조만 교체해 표현한다.
- 가로형은 왼쪽 공간·오른쪽 행렬, 세로형은 위쪽 공간·아래쪽 행렬·최하단 자막.
- 복습·예고 없음. 98초 종료 시각을 늘리지 않는다.

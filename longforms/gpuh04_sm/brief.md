# 제작 기준

178초 / 30fps / 독립 완결 / 9:16와 16:9. 사용자 확정 문장 및 종료 시각 준수. 음원 미제공, 무음·전체 대본 자막.

기존 GPU/SM/Block 관계도 유지. SM을 확대하고 Warp 좌표를 유지한다. Warp 0 파랑, 대기 주황, 발행 초록. 66–103초 코드·명령 발행·대기 겹침 연결. CPU식 문맥 저장·복원 금지. 스케줄러 하나만 그린 개념도, 실제 개수·배치는 세대별 차이. 자원 예시와 16/32=50%는 가상 설명 수치. 성능 숫자·배속 비교를 만들지 않는다.

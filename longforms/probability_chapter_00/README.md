# 확률분포 롱폼 0장 · 확률분포를 이해하기 위한 수학적 로드맵

0·1장 통합 롱폼의 첫 구간. 확정 38문장 · 221초 · 1920×1080 · 30fps. 제공된 문장 종료 시각을 화면 자막과 SRT에 사용한다. 현재 음원 미제공으로 0장 클립은 무음이다.

상단 안내는 열방정식 1장의 구성을 따라 왼쪽에 `CHAPTER 00 / PROBABILITY DISTRIBUTIONS`, 오른쪽에 현재 주제의 경로를 표시한다. 199초에 관측 데이터와 밀도 추정에서 갈라지는 전체 로드맵을 펼치고, 210초부터 베르누이 노드를 강조한다. 216–221초에 두 막대가 있는 베르누이 그래프로 전환한다. 1장 첫 화면에서 같은 그래프를 이어 받을 수 있다.

- `master_script.md` · 제공 대본
- `timing.json` · 문장과 씬의 구간
- `scenes/` · 씬별 원고와 제작 기준
- `captions.srt` · 0장 기준 자막
- `scene.py` · Manim 애니메이션

```powershell
python longforms/probability_chapter_00/build.py --preview --scene 09
python longforms/probability_chapter_00/build.py
```

통합용 클립은 `media/probability_chapter_00/final/probability_chapter_00_clip.mp4`에 저장된다. 이전 220초 영상은 이전 대본 기준의 산출물이다. 1장 확정 발화시간이 준비되면 221초 지점에 이어 붙여 통합 영상을 제작한다.

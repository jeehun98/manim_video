# 확률분포 1장 · 베르누이 분포에서 이항분포까지

1장 단독 영상. 107문장 · 10씬 · 547초. 동전 관측 기록, 로그가능도 항, 움직이는 접선으로 수식의 각 항을 화면에서 연결한다. 1920×1080 · 30fps · 무음.

0장과 겹치는 첫 문장과 3초를 제외한다. `timing.json`은 기존 렌더에서 재사용하는 시각이고, `publication_timing.json`은 첫 3초를 잘라낸 뒤의 최종 시각이다. 대본에서 239초 다음에 적힌 345초는 콘티에 맞춰 원래 시각 245초로 적용했으며, 최종 1장 시각은 242초다. 화면과 SRT는 X, μ, P(X = 1 | μ), MLE 같은 수학·영문 표기를 사용한다.

```powershell
python longforms/probability_chapter_01/build.py --preview --scene 06

```

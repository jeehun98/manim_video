## 목적과 핵심 주장
하나의 표현이 드러내는 성질를 수학적 객체의 변환으로 보여준다.

## 앞 장면에서 받은 내용
정의는 이해의 출발점

## TTS 원문과 길이
하지만 하나의 정의가 그 대상이 가지고 있는 모든 수학적 관계를 보여주는 것은 아닙니다.

- 사용자 확정 구간: 240–246초, 6초. 음원 미제공. 추정 길이나 임의 연장을 사용하지 않는다.

## 화면과 애니메이션
초반 0–0.7초에는 앞의 객체 또는 해당 수학적 대상을 받는다. 중간에는 scene.py의 해당 Shot에 명시된 시각에 생성·변환·분리·결합하며, 끝에는 확정 종료 시각까지 해석 가능한 상태를 유지한다. 16:9 4K30, 본문 y≥-2.8, 자막 y=-3.65의 별도 영역.

## 화면 텍스트
하나의 표현이 드러내는 성질와 해당 관계를 나타내는 정확한 LaTeX 수식.

## 시작·종료 상태와 연결
해당 Shot의 첫 객체에서 출발하여 마지막 수식 또는 도형을 다음 주장의 첫 상태로 연결한다. 암전이나 별도 예고를 삽입하지 않는다.

## 정확성 확인
반원은 f(x)=√(1−x²), -1≤x≤1. 길이 적분은 끝점에서 이상적분. 유한 멱급수와 무한급수는 구별하고 근삿값을 정확한 동치의 증명으로 사용하지 않는다. 영점과 운동의 종료점은 사인 멱급수의 수치적 근으로 계산한다. 라이프니츠 부분합과 오차는 실제 계산 값이다. 추가 조건·근거는 README.md 참조.

## 실제 구현 시각과 객체 변화
- 장면 내부 누적 기준 시각: 6초.
- 구현: scene.py의 Shot45.s45. 애니메이션의 run_time과 위 누적 시각을 함께 사용한다.
- 객체 동작: FadeIn.

## 최종 가독성 조정
제목과 수식의 간격을 분리한다. 관계망 카드는 높이 1.5, 제목을 위로 0.15 이동하고 수식은 70% 크기로 별도 하단에 둔다. 연결선은 카드 외곽 사이에 배치하여 수식과 교차하지 않는다. 47번의 하단 중앙 노드는 위로 0.15 옮겨 결론 문구와 분리한다.

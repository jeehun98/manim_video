## 제작 기준

- 0장의 공통 색·수식·글꼴·도형과 자막 틀을 재사용한다. π는 금색, 기하 파랑, 함수 보라, 적분 초록, 미분 주황.
- 본문 하단 y=-2.8, 별도 자막 중심 y=-3.65, 폭≤14.4·높이≤1.1. 화면·자막은 숫자와 수학 기호, tts_script.txt는 사용자 원문을 유지한다.
- 정확한 수식과 근삿값을 구별한다. 함수의 근사 그래프에서 화면 범위를 벗어난 부분은 클리핑하며, 전 실수축에서 적은 항으로 정확해졌다는 인상을 주지 않는다.
- 원은 유클리드 평면의 원이다. 확대율 λ>0에서 길이 C와 d는 함께 λ배가 된다.
- 반원 함수 f(x)=√(1−x²), -1≤x≤1. 도함수는 -1<x<1에서 정의되며 길이 적분은 끝점 ±1에서 수렴하는 이상적분이다.
- 넓이 직사각형은 중점 리만 합으로 실제 계산한다. 반원의 길이는 π, 넓이는 π/2다.
- S와 C는 무한 멱급수로 정의되는 함수다. 애니메이션의 좌표와 영점은 16항 부분합 및 (3,4) 구간 이분법으로 계산한다. np.pi를 운동의 종료값으로 넣지 않는다. 수치적 근은 정확한 동치의 증명을 대체하지 않는다.
- S′=C, C′=−S와 초기조건으로 C²+S²=1이 유지되며 γ=(C,S)의 속력이 1이다. 첫 양의 S 영점에 이르기 전 S>0이므로 위쪽 반원을 따라 반대편에 도달한다. 이동 시간 x₀가 반원의 길이 π와 같다. 이 장면은 연결의 핵심 결과를 보여주며 10초에 모든 엄밀한 유도를 담았다고 주장하지 않는다.
- 라이프니츠 부분합은 실제 유리수 항을 누적한다. 오차는 다음 항 1/(2N+1) 이하. 적은 항으로 여러 소수 자릿수를 정확하게 얻었다고 표시하지 않는다.
- 사인 멱급수에서 라이프니츠 급수로 직접 항별 변형하지 않는다. 적분을 통한 라이프니츠 급수 유도는 이번 장에서 수행하지 않았으므로 해당 연결은 점선이다.
- 1장의 마지막은 원문 결론으로 끝나며 추가 예고·엔드카드를 넣지 않는다. 다른 장의 제작 완료를 표시하지 않는다.

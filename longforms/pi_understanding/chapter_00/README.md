## 제작·정확성 기준

- longforms/_template/를 복사해 시작했다. 사용자 발화시간으로 장면 길이를 확정했으며 임의 연장·속도 변경·프레임 패딩을 사용하지 않는다.
- π는 금색, 기하·해석은 파랑, 복소·푸리에는 보라, 확률은 초록. 본문 y≥-2.8, 자막 중심 y=-3.65, 폭≤14.4, 높이≤1.1.
- 소수는 1보다 큰 자연수이며 짝수와 소수의 교집합은 {2}. ℙ는 소수 집합이다.
- 각도는 라디안. 푸리에 계수는 적분 가능한 2π주기 함수의 복소 계수다. 예시 파형은 sinθ+0.45sin3θ+0.25sin5θ.
- 표준정규분포는 그래프 일부만 표시하며 전체 실수축의 적분이 1이다.
- 유한 테일러 합은 근사다. 정확한 첫 양의 영점 정의에는 무한급수 S를 사용한다. 근삿값 일치를 동치의 증명으로 제시하지 않는다.
- BBP 예시는 16진수 3.243F6A…의 네 번째 소수 자릿수 F. Bₖ는 네 유리수 항 조합이다.
- 관계망의 선은 탐구할 연결이며 함의가 아니다. P(π)≠0은 영이 아닌 정수 계수 다항식 P에 대한 초월성이다.
- 90–104초 전체 탐구 안내와 타이틀은 사용자 확정 대본·콘티에 포함된 내용 그대로 사용한다.

# CHAPTER 02. 서로 다른 곳에서 등장하는 동일한 수

388초, 62문장, 55개 독립 렌더 단위. 277–347초는 연속 관계도. 4K30·16:9·무음·전체 자막.

실행: `python longforms/pi_understanding/chapter_02/build.py`
대표 씬: `--preview --scene 45`.

수학적 조건: 2π 주기 복소 푸리에 계수와 실수 사인 계수를 구별한다. 톱니파는 점프 이외 점에서 수렴하고 L² 수렴을 사용한다. 가우스 적분의 이차원 확장은 비음수 적분에 대한 Tonelli와 극좌표 Jacobian r을 사용한다. I>0이므로 양의 제곱근을 취한다. 유한 표시 창 밖으로 가우스 함수는 계속된다. 관계도의 연결은 각기 표현·계산·적용 관계이며 모든 개념의 동치나 하나의 공통 원인을 주장하지 않는다.

자료: [NIST DLMF Fourier series](https://dlmf.nist.gov/1.8), [Gaussian integrals, UPenn](https://www.hep.upenn.edu/~johnda/Papers/GausInt.pdf).

검증 완료: 388.000초, 11,640프레임, 영상 1스트림·음성 없음, 전체 디코딩 통과. 62문장 자막 범위 및 장면 연속성 통과. 출력: exports/pi_chapter_02.mp4.

# 회전에서 파동으로 — 3D 핵심 장면

사용자 확정: 52–60초, 8초.

3840×2160, 30fps. 음원 미제공으로 무음. 본문 y≥−2.8, 자막 −4.2≤y≤−3.1.



**00:52\~01:00 · 8초**

> 기하학에서는 단위원의 둘레를 나타냈던 원주율이, 복소지수함수에서는 함수의 값이 반복되는 주기를 결정하는 상수로 등장하는 것입니다.

이 장면은 이번 장에서 가장 중요한 공간적 애니메이션 중 하나입니다.

복소평면에 새로운 입력축 \\(t\\)를 추가하여 회전하는 점의 궤적을 3차원 나선으로 표현합니다.

3D 나선복소평면사인파 투영

\\[ \gamma(t)=(t,\cos t,\sin t) \\]

같은 3차원 나선을 서로 다른 방향으로 투영하면 원과 사인파가 나타난다.

### **실제 3D 연출**

| 시간        | 카메라 및 객체 변화                      |
| --------- | -------------------------------- |
| 52\~53.5초 | 복소평면을 유지한 채 카메라가 비스듬한 각도로 회전     |
| 53.5\~55초 | 복소평면에 수직인 입력축 \\(t\\)를 생성        |
| 55\~56.5초 | 회전하는 점이 입력축 방향으로 이동하며 나선형 궤적 생성  |
| 56.5\~58초 | 카메라가 입력축 방향에서 나선을 바라보며 원의 형태를 확인 |
| 58\~59초   | 카메라가 옆으로 회전하며 나선의 사인파 투영을 확인     |
| 59\~60초   | 파동의 반복 간격을 표시하고 \\(T=2\pi\\) 강조  |

화면 마지막에는 다음 관계가 완성됩니다.

\\[ \underbrace{2\pi}\_{\text{단위원의 둘레}} = \underbrace{2\pi}\_{\text{한 바퀴의 회전 각도}} = \underbrace{2\pi}\_{e^{ix}\text{의 기본 주기}} \\]

여기서 원의 둘레와 회전 각도는 단위원 및 라디안이라는 조건에서 수치적으로 일치합니다.

이 연출을 통해 원주율이 기하학에서 갑자기 파동으로 이동한 것이 아니라, 동일한 회전이 입력값에 따른 변화로 표현되면서 주기성이 나타났다는 사실을 직관적으로 전달합니다.

**Manim 구현:** `ThreeDScene`, `ThreeDAxes`, `ParametricFunction`, `TracedPath`, `move_camera`, `add_fixed_in_frame_mobjects`

# 수학적 관계가 새로운 문제 해결 방법이 된다

사용자 확정: 182–190초, 8초.

3840×2160, 30fps. 음원 미제공으로 무음. 본문 y≥−2.8, 자막 −4.2≤y≤−3.1.



**03:02\~03:10 · 8초**

> 하지만 이 두 문제 사이에 존재하는 수학적 관계를 이해함으로써, 하나의 문제를 해결하는 데 다른 분야의 수학적 방법을 활용할 수 있게 된 것입니다.

182\~184초에는 112초 시점에 생성했던 이름 없는 노드를 다시 보여줍니다.

184\~186초에는 해당 노드의 이름을 바젤 문제로 변경합니다.

186\~188초에는 푸리에 해석과 바젤 문제 사이에 파르세발 항등식이라는 연결선을 표시합니다.

188\~190초에는 카메라가 전체 관계망으로 줌아웃합니다.

**회전과 주기성**

\\[ e^{i(x+2\pi)}=e^{ix} \\]

**푸리에 해석**

주기함수를 진동 성분으로 분해한다.

**파르세발 항등식**

함수의 제곱 적분과 계수의 제곱합을 연결한다.

**바젤 문제**

\\[ \sum\_{n=1}^{\infty}\frac1{n^2}=\frac{\pi^2}{6} \\]

전체 관계망의 왼쪽 가지가 여기서 처음 완성됩니다.

이후 등장할 가우스 적분은 오른쪽의 별도 가지에서 전개합니다. 바젤 문제에서 가우스 적분이 직접 유도되는 것처럼 표현하지 않습니다.

# 하나의 성질로 모든 관계를 설명할 수는 없다

사용자 확정: 347–353초, 6초.

3840×2160, 30fps. 음원 미제공으로 무음. 본문 y≥−2.8, 자막 −4.2≤y≤−3.1.



**05:47\~05:53 · 6초**

> 물론 원주율이 등장하는 모든 수학적 관계를 하나의 공통된 성질만으로 설명할 수 있는 것은 아닙니다.

347\~349초에는 지금까지 설명한 회전과 주기성, 대칭성 노드를 강조합니다.

349\~351초에는 카메라가 한 번 더 줌아웃하면서 아직 다루지 않은 여러 성질들이 주변에 존재한다는 사실을 표시합니다.

351\~353초에는 기존에 설명한 연결선은 실선으로 유지하고, 아직 탐구하지 않은 관계는 낮은 밝기의 점선으로 남겨둡니다.

회전과 대칭성이 원주율에 관련된 모든 성질의 근본 원인이라는 인상을 주지 않도록 하기 위한 장면입니다.

# 복잡한 함수의 구성 요소

사용자 확정: 63–70초, 7초.

3840×2160, 30fps. 음원 미제공으로 무음. 본문 y≥−2.8, 자막 −4.2≤y≤−3.1.



**01:03\~01:10 · 7초**

> 푸리에 해석에서는 복잡한 형태의 함수를 서로 다른 진동수를 갖는 단순한 함수들의 결합으로 표현하고자 합니다.

성분 1개성분 2개성분 3개

\\[ f(x)=\sin x+0.5\sin3x+0.3\sin5x \\]

### **세부 애니메이션**

63\~65초에는 화면 중앙의 넓은 좌표계에 복잡한 주기함수를 그립니다.

65\~67초에는 복합 파형에서 첫 번째 저주파 성분이 분리되어 화면 아래로 이동합니다.

67\~68.5초에는 더 빠르게 진동하는 두 번째 성분과 세 번째 성분이 분리됩니다.

68.5\~70초에는 각각의 성분이 다시 합쳐지며 원래 함수와 일치하는 모습을 보여줍니다.

예시로 사용하는 함수는 다음과 같습니다.

\\[ f(x)=\sin x+\frac12\sin3x+\frac3{10}\sin5x \\]

이 예시는 실제 푸리에 계수를 이미 알고 있는 유한 삼각함수 합입니다. 임의의 복잡한 함수에 대해 단순한 애니메이션만으로 정확한 분해가 수행되는 것처럼 표현하지 않습니다.

## 4. Manim 제작 지침

첫째, 모든 기저 변경은 실제 계산에서 도출한 값을 사용해야 해.

\\[ M(P)=P^{-1}AP \\]

이 관계를 기준으로 격자와 행렬을 동시에 갱신해야 한다.

```
import numpy as npA = np.array([[2., 1.],              [1., 2.]])bases = [    np.eye(2),    np.array([[1., 1.], [1., -1.]]),    np.array([[1., 1.], [0., 1.]])]for P in bases:    M = np.linalg.solve(P, A @ P)    eigenvalues = np.linalg.eigvals(M)    assert np.allclose(np.sort(eigenvalues), [1., 3.])    assert np.isclose(np.trace(M), 4.)    assert np.isclose(np.linalg.det(M), 3.)
```

둘째, 고윳값의 불변성을 표현할 때는 실제 고유방향과 고유벡터의 좌표 표현을 구별해야 해.

기저가 바뀌면 실제 고유방향은 달라지는 것이 아니라, 그 방향을 표현하는 좌표 성분이 바뀌는 거야.

셋째, 행렬식은 단순한 양의 면적 비율이 아니라 부호까지 포함한 면적 배율이라는 점을 유지하자. 이번 예시에서는 행렬식이 3이므로 방향 뒤집힘 없이 면적이 세 배가 되지만, 음수인 경우에는 방향성의 반전까지 나타낸다.

넷째, 후반 반례의 행렬을 기존 행렬과 구분하자. 기존 \\(A\\)와 새로운 \\(B\\)가 혼동되지 않도록, 화면 상단에 `새로운 두 행렬의 비교`라는 작은 제목을 표시하는 편이 좋아.

다섯째, 7편에서 다시 전단행렬을 다룰 계획이므로 이번에는 조르당 표준형이나 일반화 고유벡터까지 확장하지 말자. 3편에서는 불변량이 같아도 닮음이 보장되지 않는다는 사실까지만 완결하면 돼.

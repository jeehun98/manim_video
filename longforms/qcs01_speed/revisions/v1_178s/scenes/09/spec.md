# 09 · 하나의 결과, 여러 기여

## 목적과 주장

하나의 결과, 여러 기여를 도형의 변화로 설명한다.

## 확정 대본과 길이

80–93초, 780프레임. 사용자 제공 문장 종료 시각을 유지한다.

하나의 결과에 도달하는 데 여러 양자적 경로가 기여할 수 있고, 각 경로의 확률 진폭은 서로 더해집니다.

이때 확률 진폭은 단순한 확률과 달리 양수와 음수, 나아가 복소수의 값을 가질 수 있습니다.

## 화면과 애니메이션

첨부 콘티 SCENE 09, direction.py의 s09. 쇼츠는 중앙·상하, 가로형은 별도 좌표·차트 축 간격 및 좌우 비교 배치. 하단은 내레이션 자막 전용이다.

## 연결과 정확성

앞 장면: 강화와 상쇄. 종료 시 본문의 설명 결과를 유지한다. 다음 장면: 진폭을 먼저 더한다. 예고나 엔드카드를 추가하지 않는다.
진폭·확률·그로버 연산의 조건은 brief.md와 verify.py를 따른다.

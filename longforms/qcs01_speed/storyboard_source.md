## PART 01. 일반 비트와 큐비트

### SCENE 01 — 0과 1로 표현하는 정보

00:00–00:07 · 나레이션 첫 두 문장

나레이션

> 일반적인 컴퓨터는 0과 1로 정보를 표현합니다. 양자컴퓨터 역시 0과 1을 이용하지만, 정보를 표현하는 방식에는 중요한 차이가 있습니다.

화면 연출

- 검은 화면에서 파란색 숫자 `0` 하나가 등장한다.
- 숫자가 `1`로 바뀌고, 다시 `0`으로 바뀐다.
- 숫자를 감싸는 네모난 테두리가 등장해 하나의 비트를 형성한다.
- 같은 비트가 8개로 복제돼 `01011010` 배열이 된다.
- 배열이 화면 상단으로 이동하며 하단에 `CLASSICAL BIT`가 등장한다.

Manim 구현

`Text`, `RoundedRectangle`, `Transform`, `LaggedStart`, `VGroup`.

전환 시 화면 전체를 지우지 말고 기존 비트 배열을 축소해 SCENE 02의 비교 대상이 되도록 유지한다.

### SCENE 02 — 큐비트의 중첩

00:07–00:15

나레이션

> 일반적인 비트는 0 또는 1의 상태를 갖지만, 양자컴퓨터의 큐비트는 두 상태가 중첩된 상태로 존재할 수 있습니다.

화면 연출

일반 비트의 `0`은 한순간에 하나의 값으로만 존재한다.

큐비트는 `|0⟩`과 `|1⟩`에 대응하는 두 진폭으로 표현하고, 두 상태를 하나의 수식으로 합친다.

\\[ |\psi\rangle=\alpha|0\rangle+\beta|1\rangle \\]

처음에는 `|0⟩`, `|1⟩`을 따로 보여준 뒤 `α`, `β`가 붙고 마지막에 하나의 수식으로 결합한다.

### SCENE 03 — 확률 진폭이란?

00:15–00:24

나레이션

> 이를 수학적으로 표현하면, 0과 1에 각각 확률 진폭을 부여한 형태가 됩니다.

화면 연출

중첩 수식의 `α`, `β`만 확대한다.

아래에 두 개의 막대를 배치한다.

- `|0⟩`에 대응하는 진폭
- `|1⟩`에 대응하는 진폭

예시로 두 진폭의 크기를 \\(1/\sqrt2\\)로 설정하고, 각 진폭의 크기 제곱이 50%라는 사실을 작은 숫자로 보여준다.

\\[ |\alpha|^2=50\\%,\qquad|\beta|^2=50\\% \\]

실수 진폭만 사용하는 예시라는 점을 화면에 작은 글씨로 표시한다.

### SCENE 05 — 20큐비트와 백만 개의 기저 상태

00:35–00:45

나레이션

> 20개의 큐비트는 약 100만 개의 계산 기저 상태에 대한 진폭을 하나의 양자 상태로 표현할 수 있습니다.

화면 연출

앞 장면의 여덟 개 블록이 작은 점으로 변환되고, 화면 중앙에 점들이 대량으로 복제된다.

10큐비트와 20큐비트에서 각각 숫자를 표시한다.

`2¹⁰ = 1,024`

`2²⁰ = 1,048,576`

점들은 점차 밀집해 하나의 사각형 영역처럼 보인다.

연출상 주의

백만 개의 도형을 실제로 생성할 필요는 없다. 약 1,000\~2,000개의 점을 표시하고 그 옆에 전체 기저 상태 수를 숫자로 표기한다.

백만 개의 독립적인 답이 저장돼 있다고 표현하지 말고, 백만 개의 기저 상태에 대한 진폭을 갖는다는 점만 전달한다.

00:52–01:02

화면 연출

4×4 배열의 기저 상태를 보여준다. 모든 상태가 일정한 확률을 가지고 있는 예시로 설정한다.

측정 장치가 배열 위로 내려온다.

짧은 점멸 이후, 16개 중 한 상태만 초록색으로 표시된다.

나머지 블록은 사라진다.

아래에 표시한다.

## PART 04. 양자 간섭과 확률 진폭

### SCENE 08 — 파동의 강화와 상쇄

01:02–01:10

나레이션

> 여기서 중요한 것이 양자 간섭입니다. 파동은 마루와 마루가 겹치면 강화되고, 마루와 골이 겹치면 상쇄됩니다.

Manim 구현

두 개의 사인파를 `ParametricFunction`으로 생성한다.

- 왼쪽: 위상이 같은 두 파동 → 두 배 진폭
- 오른쪽: 위상이 반대인 두 파동 → 0

수식은 짧게만 표시한다.

\\[ A+A=2A,\quad A-A=0 \\]

### SCENE 09 — 양자 상태도 진폭이 합쳐진다

01:10–01:17

나레이션

> 양자컴퓨터에서도 하나의 결과에 기여하는 여러 경로의 확률 진폭이 서로 더해질 수 있습니다.

화면 연출

앞 장면의 두 파동을 서로 다른 색상의 화살표 두 개로 변환한다.

두 화살표가 동일한 출력 상태 `|0⟩`로 향한다.

경로 1은 \\(a_1\\), 경로 2는 \\(a_2\\)로 표시한다.

출력 상태 위에는 \\(a_1+a_2\\)가 나타난다.

실제 공간의 두 길처럼 표현하기보다, 수학적으로 서로 다른 전이 항이 하나의 출력에 기여하는 모습으로 구성한다.

### SCENE 10 — 양수와 음수 진폭

01:17–01:24

나레이션

> 확률 진폭은 양수와 음수, 나아가 복소수의 값을 가질 수 있어 서로 강화되거나 상쇄될 수 있습니다. 그리고 합쳐진 진폭의 크기를 제곱하면, 그 결과가 관측될 확률이 됩니다.

화면 연출

양의 진폭을 위쪽 막대로, 음의 진폭을 아래쪽 막대로 표현한다.

\\[ +0.5+0.5=1 \\]

\\[ +0.5-0.5=0 \\]

그다음 합쳐진 진폭 아래에 확률 식을 표시한다.

\\[ P=|a|^2 \\]

복소수 표현을 위해 작은 복소평면을 잠깐 나타낸다. 두 화살표가 서로 다른 방향을 가질 수 있다는 정도만 보여주고 곧바로 다음 장면으로 넘어간다.

복소수의 위상 자체를 상세히 설명하는 것은 이번 영상의 범위를 넘어가므로 피한다.

### SCENE 12 — 중첩된 후보 전체에 연산하기

01:32–01:39

# 4. Manim에서 반드시 일치시켜야 할 수학적 계산

영상에서 가장 중요한 것은 SCENE 13\~16의 실제 계산과 애니메이션이 일치하는 것이야.

그로버 알고리즘의 예시를 다음 세 상태로 고정하자.

실제 진폭 변화 — 정답 `11`

| 상태    | 00  | 01  | 10  | 11   |
| ----- | --- | --- | --- | ---- |
| 초기    | 0.5 | 0.5 | 0.5 | 0.5  |
| 오라클   | 0.5 | 0.5 | 0.5 | −0.5 |
| 확산 연산 | 0   | 0   | 0   | 1    |

오라클 이후 평균 진폭은 0.25다.

\\[ \overline a=\frac{0.5+0.5+0.5-0.5}{4}=0.25 \\]

확산 연산은 각 진폭을 평균에 대해 반사한다.

\\[ a_i'=2\overline a-a_i \\]

\\[ 0.5\longrightarrow0,\qquad -0.5\longrightarrow1 \\]

영상에서는 이 계산을 한 화면에 전부 표시하지 말고, 다음처럼 분할하는 편이 좋아.

- SCENE 13: 네 진폭이 모두 `0.5`
- SCENE 14: 정답 진폭만 `-0.5`
- SCENE 15: 평균 `0.25`와 반사 과정
- SCENE 16: 정답의 관측 확률 `100%`

이렇게 해야 계산 과정을 처음 접하는 시청자도 앞 장면의 숫자를 기억한 채 다음 장면으로 넘어갈 수 있어.

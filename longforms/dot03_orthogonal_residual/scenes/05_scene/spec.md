# 05 — 다시 측정했을 때 0

## 목적과 핵심 주장
잔차와 기준은 직교하며 해당 방향의 투영은0이다.

## 앞 장면에서 받은 내용
r·(1,1)=1−1=0으로 제거 여부를 확인한다.

## TTS와 확정 길이
사용자 제공 문장 종료 시각 기준62–71초, 길이9초. 음원 미제공.

내적이 0이라는 것은 두 벡터가 서로 직교한다는 뜻입니다.
즉, 남은 벡터에는 45도 방향으로 측정되는 성분이 전혀 없습니다.
이것은 우연이 아닙니다.

## 화면 구성
2편과 같은 원점·스케일. x=(4,2) 파랑, u 초록, p=(3,3) 주황, r=(1,−1) 보라. 세로형 중앙 그래프·하단 계산, 가로형 좌측 그래프·우측 계산. 하단 자막 영역은 분리한다.

## 구간별 애니메이션·화면 텍스트
62–65초 원점에서r과u가90°임을 표시. 65–70초 r끝점에서 기준선에 내린 수선의 발은원점. 주황 측정 표시는 정확히 원점의 점이며 길이0으로 표시. 70–71초 우연이 아님을 제시.

## 시작·종료 상태
파란x는 위치를 고정하고 강조가 필요할 때 밝기만 바꾼다. 처음 보라잔차는p끝점에서x끝점으로 등장한다. 다음 컷에서 원점으로 옮길 때는 회전·크기 변경 없이 평행이동한다.

## 다음 장면 연결
잔차는 선택한 방향으로 설명되지 않는 성분이다.

## 수학적 조건
유클리드 내적, u=(1/√2,1/√2), ‖u‖=1. p=(x·u)u=(3,3). r=x−p=(1,−1). r·u=0, r·(1,1)=0. v=(1,1)의 길이는√2이며 직교 검사에 사용한다. p+r=x. 잔차 평행이동 전후 방향과길이는 동일. 주황 투영0은 실제 점으로 표시하며 양의 길이를 가진 선분을 그리지 않는다.

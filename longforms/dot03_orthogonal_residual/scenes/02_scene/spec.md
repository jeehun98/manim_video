# 02 — 제거할 성분을 먼저 추출한다

## 목적과 핵심 주장
u에 투영해 p=(3,3)을 얻는다.

## 앞 장면에서 받은 내용
정사영을 이용해 제거할 방향의 성분을 선택한다.

## TTS와 확정 길이
사용자 제공 문장 종료 시각 기준15–33초, 길이18초. 음원 미제공.

먼저 해당 방향의 성분을 구해야 합니다.
45도 방향의 단위벡터는 가로와 세로 성분이 모두 1 나누기 루트 2입니다.
원래 벡터와 이 단위벡터를 내적하면 3 루트 2가 나옵니다.
이 값에 다시 단위벡터를 곱하면, 가로로 3, 세로로 3만큼 향하는 정사영 벡터를 얻습니다.

## 화면 구성
2편과 같은 원점·스케일. x=(4,2) 파랑, u 초록, p=(3,3) 주황, r=(1,−1) 보라. 세로형 중앙 그래프·하단 계산, 가로형 좌측 그래프·우측 계산. 하단 자막 영역은 분리한다.

## 구간별 애니메이션·화면 텍스트
15–17초 초록 단위벡터 등장. 17–23초 u=(1/√2,1/√2), 길이1. 23–26초 내적3√2. 26–33초 복제한 기준벡터를 확대해 주황 p=(3,3) 생성. 원본u는 유지.

## 시작·종료 상태
파란x는 위치를 고정하고 강조가 필요할 때 밝기만 바꾼다. 처음 보라잔차는p끝점에서x끝점으로 등장한다. 다음 컷에서 원점으로 옮길 때는 회전·크기 변경 없이 평행이동한다.

## 다음 장면 연결
잔차 r=x−p=(1,−1)은 두 끝점 사이의 차이다.

## 수학적 조건
유클리드 내적, u=(1/√2,1/√2), ‖u‖=1. p=(x·u)u=(3,3). r=x−p=(1,−1). r·u=0, r·(1,1)=0. v=(1,1)의 길이는√2이며 직교 검사에 사용한다. p+r=x. 잔차 평행이동 전후 방향과길이는 동일. 주황 투영0은 실제 점으로 표시하며 양의 길이를 가진 선분을 그리지 않는다.

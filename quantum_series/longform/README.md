# 롱폼 Chapter 조립

`chapters.json`의 `chapters`에는 실제 제작된 연결용 16:9 파일만 기록한다. `planned_only`는 기획 참고이며 조립하지 않는다. 현재 EP.01(86초), EP.02(101초), EP.03(105초)이 등록되어 있으며, 세 편을 조립하면 292초다. EP.04는 미제작이다.

`python quantum_series/longform/assemble.py`

실제 파일·길이·코덱·화면비·프레임률·오디오 유무가 일치하는지 검사한 뒤 MP4 챕터 메타데이터와 통합 SRT를 만든다. 본문 영상에 챕터 타이틀을 삽입하지 않는다. EP.02는 EP.01과 파동·황금색 에너지 기호를 공유하되, 금속에 빛을 비추는 독립적인 질문으로 시작한다. 두 편 사이에 별도 내레이션이나 추가 시간을 삽입하지 않는다.

EP.03은 금박 실험에서 독립적으로 시작하여 원자의 안정성 질문으로 끝난다. `exports/quantum03_longform_ending.png`에 연결용 마지막 프레임을 저장했다. 마지막 나선은 고전적 궤도 모형의 문제를 상징하는 그림이며 실제 전자 궤도가 아니다. EP.04는 추후 대본·발화시간 확정 후 제작한다.

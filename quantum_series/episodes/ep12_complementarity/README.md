# EP.12 보어의 상보성 원리

178초 · 41문장 · 8개 독립 씬. 9:16 1080×1920 / 16:9 1920×1080, 30fps. 음원 미제공으로 무음·전체 문장 자막이다.

`python scripts/render.py quantum12 --preview` / `python scripts/render.py quantum12`. 개별 비율은 `quantum12_shorts`, `quantum12_longform`. 편별 `build.py --scene <ID>`로 씬을 독립 교체하며 `--ending standalone|join`에서도 본문과 길이는 같다.

`script.json`은 확정 대본·시각, `direction.py`는 공통 애니메이션, `layouts.py`는 화면비별 배치, `shared/complementarity.py`는 확률모형과 재사용 컴포넌트다. 씬별 주장은 `scenes/*/spec.md`에 기록한다.

## 모형과 구분

- 현대적인 이상적 두 경로 사고실험이다. 보어가 1927년에 이 형태의 단일전자 이중슬릿 실험을 했다는 뜻이 아니다. 슬릿 판은 정면 표시하여 A(왼쪽), B(오른쪽)를 구분하고, 장치의 나머지는 투영 축척을 생략한 배치 개념도다.
- 화면 좌표 x∈[−3,3], 포락선 E(x)=cos²(πx/6)/3, q=5π/3. ψA=√(E/2)exp(−iqx/2), ψB=√(E/2)exp(iqx/2). 각 경로 확률은 1/2, 두 경로 내적은 0이므로 모든 기록 내적에서 전체 확률이 1이다. 실제 유한 슬릿의 정밀 전파해를 주장하지 않는 교육용 모형이다.
- 기록 상태 |mA〉=(1,0), |mB〉=(γ,D), γ=√(1−D²)인 순수하고 동등한 두 경로를 사용한다. P=|ψA|²+|ψB|²+2Re(ψA*ψBγ). 이 예에서는 같은 위치에서 상대 위상을 변화시켜 정의하는 가시도 V=γ, D²+V²=1이다. 공간 포락선 때문에 생기는 세기 변화는 가시도에 포함하지 않는다. 일반적인 실험에서는 등호가 아니라 상한 관계가 된다.
- 전자만 집계하는 주변 확률을 그린다. γ=0이면 기록을 읽지 않아도 간섭항은 0이다. 전체 전자–기록 상태의 결맞음까지 반드시 사라진다는 뜻은 아니며, 기록을 특정 기저로 조건부 분류하는 양자 지우개는 다루지 않는다.
- 두 조건 모두 같은 수 N=2000의 검출점을 모형 확률의 역누적분포에서 추출한다. 세로 위치는 무관한 균일 잡음, 가로 위치는 P(x)이다. 막대는 실제 표본의 히스토그램이다. 실측 데이터가 아니다. 조건을 바꿀 때 기존 검출점을 이동시키지 않고 새 시행으로 초기화한다.
- 경로를 완전히 기록한 경우의 A/B 기록은 조건부 확률이 같은 대칭 모형에 맞춰 표본화한다. 기록 장치는 전자를 흡수하지 않는다. 전자의 슬릿 이후 고전적 궤도는 그리지 않으며 회색 공의 경로는 고전적 비교 예시에 한정한다.
- 기록 상태 화살표와 환경 아이콘은 추상적인 상태 공간·상관관계다. 물리적인 정보 입자가 이동한다는 뜻이 아니다. 상보성은 이중슬릿만으로 완전히 정의되는 개념이 아니라 실험 조건과 개념 적용에 관한 더 넓은 관점이다.

## 출처와 검증

[Englert, Fringe Visibility and Which-Way Information, Phys. Rev. Lett. 77, 2154 (1996)](https://doi.org/10.1103/PhysRevLett.77.2154)를 기록 구별도와 가시도 관계의 근거로 삼는다. 이 정량식을 1927년 보어가 제시한 식으로 표시하지 않는다.

`python quantum_series/episodes/ep12_complementarity/verify_physics.py`는 정규화·부분 추적·이중성 관계·2000회 표본 분포를 검사한다. `verify_videos.py`는 최종본의 178초·5340프레임·1080p30·전체 디코딩·마지막 1초 정지를 검사한다.

검수 완료: 두 화면비의 주요 장면·자막·수식 배치, 정규화와 기록 상태의 부분 추적, 2000개 표본 분포, 178.000초·5340프레임·전체 디코딩 및 마지막 1초 정지.

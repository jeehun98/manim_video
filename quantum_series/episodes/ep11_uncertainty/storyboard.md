# 양자역학의 발견 11 — 하이젠베르크의 불확정성 원리

상세 영상화 콘티 · 총 177초(2분 57초) · Manim 2D 애니메이션 · 9:16 쇼츠 / 16:9 롱폼 공용

이번 편은 수식보다 파동의 형태가 바뀌면서 위치와 운동량의 분포가 함께 변하는 과정을 중심으로 구성하는 것이 좋아.

앞선 10편이 전자 회절의 실험적 발견이었다면, 11편에서는 그 파동성이 고전적인 입자 개념에 어떤 제약을 가져오는지 보여주는 거야.

좁은 운동량 분포

운동량 분포의 폭

핵심 관계: 위치를 좁게 국소화할수록 운동량 분포가 넓어진다.

위 개념도는 위치 및 운동량 분포를 각각 설명하기 위한 도식이며, 실제 애니메이션에서는 가우스 파동묶음의 두 분포가 일관되게 변화하도록 구현한다.

### 실제 Manim 계산 모델

가우스 파동묶음을 사용하면 시각화와 물리적 계산을 연결하기 좋아.

예를 들어 초기 파동함수를 다음과 같이 설정할 수 있어.

\\[ \psi(x)=\frac{1}{(2\pi\sigma_x^2)^{1/4}} \exp\left(-\frac{x^2}{4\sigma_x^2}\right) \exp(ik_0x) \\]

이 경우 위치·운동량 표준편차는 다음 관계를 만족해.

\\[ \sigma_p=\frac{\hbar}{2\sigma_x} \\]

즉, `sigma_x`만 변화시키면 다른 값도 자동으로 결정되는 거야.

```
import numpy as npdef gaussian_wavepacket(x, sigma_x, k0=8.0, hbar=1.0):    norm = (2 * np.pi * sigma_x**2) ** (-0.25)    envelope = np.exp(-(x**2) / (4 * sigma_x**2))    phase = np.exp(1j * k0 * x)    return norm * envelope * phasedef momentum_std(sigma_x, hbar=1.0):    return hbar / (2 * sigma_x)
```

여기서는 \\(\hbar=1\\)인 무차원 단위를 시각화에 활용해도 좋아.

중요한 것은 애니메이션에서 그래프를 임의로 늘이거나 줄이는 것이 아니라 동일한 물리적 상태의 위치 표현과 운동량 표현을 연동시키는 거야.

# 6. 구현 시 물리적 정확성 체크

1. 파동함수와 확률밀도는 다르다. 파란색 파동함수의 진동 형태와 청록색 위치 확률밀도는 별도로 표시해야 해. 전자가 반드시 진동하는 실선 위에 놓여 있다는 식으로 표현하면 안 돼.
2. 파장을 하나로 정하면 진행 방향도 지정해야 해. 파장 자체는 운동량의 크기와 연결되고, 1차원 진행파에서 방향까지 지정하면 운동량 성분이 정해져. 이번 영상은 오른쪽 진행파를 기준으로 통일하면 충분해.
3. 위치를 좁히면 운동량이 무조건 정확히 같은 비율로 넓어지는 것은 아니야. 일반적인 원리는 불확정성의 곱에 하한이 존재한다는 것이고, 특정 가우스 파동묶음에서만 최소 불확정성 관계를 등호로 만족해.
4. 측정 교란과 상태 자체의 불확정성을 구별해야 해. 감마선 현미경은 역사적 사고실험이지만, 불확정성 관계는 측정 이전에 준비된 양자상태의 두 분포에도 성립해.
5. 개별 측정이 불가능하다는 뜻은 아니야. 전자의 위치 하나를 정밀하게 검출할 수 있어도, 그 상태의 운동량 분포까지 동시에 임의로 좁게 준비할 수는 없다는 뜻이야.
6. 파동묶음은 단순한 사인파를 잘라 붙이는 방식으로 구현하지 않아야 해. 여러 파수 성분의 중첩으로 생성하거나 가우스 파동함수와 그 푸리에 변환을 사용해야 물리적으로 일관된 시각화가 가능해.

# EP.11 하이젠베르크의 불확정성 원리

177초 · 42문장 · 9개 독립 씬. 두 화면비 1080p30, 무음·전체 자막. 사용자 표기 “연우”는 화자 메모로 보존했고 음원은 제공되지 않았다.

`python scripts/render.py quantum11 --preview` / `python scripts/render.py quantum11`. 개별 비율은 `quantum11_shorts`, `quantum11_longform`. 편별 `build.py --scene <ID>`로 해당 씬만 교체한다. `--ending standalone|join`은 본문과 길이를 유지한다.

`script.json`이 확정 대본·시각, `direction.py`는 애니메이션, `layouts.py`는 화면비별 배치, `shared/uncertainty.py`는 재사용 가능한 계산과 컴포넌트다. 씬별 주장은 `scenes/*/spec.md`에 기록한다.

## 모델과 주의점

- ħ=m=1인 무차원 단위. ψ=(2πσx²)^(-1/4) exp(−x²/(4σx²)) exp(ik₀x). 위치 확률밀도는 정규화된 분산 σx²의 가우스, 운동량은 σp=1/(2σx)의 가우스다. 그래프는 같은 고정 축을 쓰며 점선은 평균 ± 표준편차다.
- 그래프는 중심 좌표 x−〈x〉, pₓ−〈pₓ〉를 표시한다. 0은 평균 운동량이 0이라는 뜻이 아니다. 초기 가우스의 k₀=6으로 오른쪽 운동량이 우세하다. 실수부의 음수는 음의 확률이 아니다.
- 파동묶음은 가우스 푸리에 진폭의 81개 성분을 수치 합산하고 해석적 가우스와 비교한다. 단일 평면파는 비정규화 이상화이며 화면 양끝의 생략점은 무한 공간으로 이어짐을 뜻한다.
- 표시된 역비례와 등호는 위상에 이차항이 없는 최소 불확정성 가우스의 예다. 일반 상태의 관계는 ΔxΔpₓ≥ħ/2이고, Δ는 준비된 상태의 표준편차다.
- 감마선 현미경은 역사적 사고실험이다. 산란각의 불확정성이 운동량 전달에 영향을 준다는 개념도이며 정량 콤프턴 충돌 궤적을 재현하지 않는다. 측정 오차·교란과 준비 불확정성의 수식을 동일시하지 않는다.
- XP−PX=iħI는 연속 정준 연산자의 상징적 관계다. 유한 행렬의 실제 수치 곱으로 이 관계를 만족한다고 주장하지 않는다.
- 시간 변화는 자유입자 가우스의 해석적 해를 사용한다(σ₀=.65,k₀=1.2). 이 예에서는 이동과 퍼짐이 함께 나타난다. 개별 검출 도식은 같은 상태를 반복 준비한 샘플이다.
- 마지막 두 슬릿 장면은 경로 정보를 얻는 조건을 묻는다. 작동하는 경로 검출기와 완전한 간섭이 동시에 존재한다고 표시하지 않는다.

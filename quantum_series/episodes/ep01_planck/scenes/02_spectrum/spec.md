# 02_spectrum

## 목적·핵심 주장

빈 법칙의 긴 파장 한계를 플랑크 공식이 해결했다.

## 앞 장면에서 받은 내용

빛의 파장별 분포를 온도로부터 계산할 수 있을까?

## TTS·확정 길이

25초, 전체 24–49초. 사용자 문장 종료 시각 기준. 음원 미제공.

24–30초: 하지만 이러한 이론을 이용한 기존의 계산으로는 실제 관측되는 빛의 분포를 완전히 설명할 수 없었습니다.

30–37초: 특히 정밀한 실험이 진행되면서, 긴 파장 영역에서 기존 공식과 관측 결과 사이의 차이가 드러났습니다.

37–43초: 1900년, 독일의 물리학자 막스 플랑크는 관측된 분포를 설명할 수 있는 새로운 공식을 제시했습니다.

43–49초: 그런데 이 공식이 왜 성립하는지를 설명하는 과정에서 흥미로운 방법을 사용했습니다.

## 화면·애니메이션

24–30초 빈 법칙과 이론적 기준 분포 비교, 30–37초 5–12 μm와 세로축 확대, 37–43초 플랑크 곡선, 43–49초 이유를 묻고 진동자로 연결. 가로는 왼쪽 물체·오른쪽 그래프, 세로는 상단 물체·중앙 그래프.

## 화면 텍스트

기존 공식으로는 맞지 않았다 / 긴 파장 영역에서 드러난 차이 / 관측 분포를 설명하는 새로운 공식 / 이 공식은 왜 성립할까?

## 시작·종료 상태와 연결

기존 계산과 기준 분포에서 시작하여 진동자를 상징하는 네 점으로 끝난다. 다음 씬은 같은 청록색 네 진동자를 배치한다.

## 정확성

청록색 점·선은 이론적 분포이며 실측이 아니다. 파장축과 고정 정규화를 유지하고 확대 시 세로축 눈금을 표시한다. 블록은 광자가 아닌 에너지 분배량의 기호다. 에너지값의 단위와 공간의 분절을 구별한다. 자세한 식과 출처는 상위 README 참조.

# 01_thermal

## 목적·핵심 주장

빛의 파장별 분포를 온도로부터 계산할 수 있을까?

## 앞 장면에서 받은 내용

없음. 첫 관찰부터 독립적으로 시작.

## TTS·확정 길이

24초, 전체 0–24초. 사용자 문장 종료 시각 기준. 음원 미제공.

0–4초: 쇠를 가열하면 처음에는 붉게 빛나다가, 온도가 올라갈수록 점점 밝아집니다.

4–9초: 이처럼 뜨거운 물체가 빛을 방출하는 현상은 오래전부터 알려져 있었습니다.

9–13초: 19세기 말, 물리학자들은 한 가지 질문을 던졌습니다.

13–18초: 물체의 온도를 알고 있다면, 어떤 파장의 빛이 얼마나 방출되는지도 계산할 수 있을까?

18–24초: 당시에는 빛을 전자기파로 설명하고 있었고, 열과 에너지에 관한 이론도 발전해 있었습니다.

## 화면·애니메이션

0–4초 쇠 가열, 4–9초 열복사, 9–13초 질문, 13–18초 파장 분석과 좌표축, 18–24초 전자기학과 열운동. 세로는 중앙·수직 배치, 가로는 좌우 배치.

## 화면 텍스트

온도가 올라가면 빛이 변한다 / 열복사 · Thermal Radiation / 19세기 말 / 파장마다 얼마나 많은 빛이 나올까? / 빛과 열을 설명하던 물리학

## 시작·종료 상태와 연결

회색 쇠로 시작하여 빛의 분포를 계산하는 질문으로 끝난다. 다음 씬에서 같은 온도·파장축으로 실제 식의 분포를 비교한다.

## 정확성

청록색 점·선은 이론적 분포이며 실측이 아니다. 파장축과 고정 정규화를 유지하고 확대 시 세로축 눈금을 표시한다. 블록은 광자가 아닌 에너지 분배량의 기호다. 에너지값의 단위와 공간의 분절을 구별한다. 자세한 식과 출처는 상위 README 참조.

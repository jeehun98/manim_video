# 양자역학의 발견 09 — 보른의 확률 해석

상세 영상화 콘티 · 178초(2분 58초) · Manim 기반 2D 애니메이션 · 9:16 쇼츠 / 16:9 롱폼 공용

이번 편은 이전 회차와 달리 하나의 입자를 반복해서 측정하는 실험을 시각적 중심으로 삼는 것이 좋아.

8편에서는 슈뢰딩거 방정식으로 공간에 퍼진 파동함수를 구했지. 그런데 그 파동을 실제로 측정하면 한 위치에서 하나의 검출 결과가 나타나.

보른의 발견은 이 두 현상을 연결했다는 점에 있어.

파동함수

개별 검출

반복된 결과

확률분포

개별 측정 결과는 하나지만, 반복 측정의 통계에는 파동함수의 구조가 나타난다.

Manim

영상에서는 식 하나만 보여주는 것이 적절해.

\\[ \rho(x)=|\psi(x)|^2 \\]

위치에 대한 표현에서 이 값은 정확히 한 점에서 검출될 확률이 아니라 확률밀도야. 작은 영역을 잡고 그 안에서 발견될 확률을 계산한다는 점은 내부 구현에서 지켜주면 돼.

# 4. 영상의 핵심 시뮬레이션

## 시뮬레이션 A — 전자 한 개씩 검출하기

활용 구간 01:16–01:46 · 반복 측정의 분포 형성

아래는 실제 영상에서 구현할 시뮬레이션의 개념적인 미리보기야. 버튼을 누르면 동일한 확률분포를 따르는 검출점들이 누적돼.

전자 검출 누적

중앙 부근에서 더 자주 검출되는 예시 분포

N = 5

1회10회100회500회

설명용 모의 표본. 각 전자는 한 위치에서 검출되고, 표본 수가 늘어나면 검출 분포의 형태가 더 뚜렷해진다.

실제 Manim 구현에서는 검출 횟수를 일정한 속도로 늘리는 것보다, 시간이 지날수록 빠르게 늘리는 것이 시각적으로 효과적이야.

| 누적 구간       | 영상 속 처리            |
| ----------- | ------------------ |
| 1\~3회       | 검출점 하나씩 강조         |
| 4\~20회      | 서로 다른 위치의 검출 결과    |
| 21\~100회    | 점들의 밀집 영역이 서서히 나타남 |
| 101\~1,000회 | 빠른 점 누적            |
| 1,000회 이상   | 히스토그램과 이론 곡선 비교    |

이 시뮬레이션은 단순히 화면에서 무작위 좌표에 점을 생성하는 방식이 아니라, 미리 정해진 확률분포를 기준으로 검출 위치를 표본 추출하는 방식이어야 해.

예를 들어 설명용 가우스 형태의 확률밀도를 사용한다면:

```
import numpy as nprng = np.random.default_rng(1926)# 같은 준비 상태에서 반복 측정한 검출 위치positions = rng.normal(    loc=0.0,    scale=1.0,    size=3000)
```

이러한 표본 추출은 영상 속 확률밀도와 실제 검출점의 관계를 보여주기 위한 것이야.

수소 원자의 파동함수나 실제 산란 실험을 정확하게 재현한 결과로 설명하지는 않아야 해.

## 시뮬레이션 B — 확률진폭의 강화와 상쇄

활용 구간 02:18–02:38 · 확률진폭의 간섭

이번 영상에서는 두 경로를 단순히 연결하는 화살표가 아니라, 각 경로가 하나의 검출 위치에 기여하는 진폭을 보여주는 것이 좋아.

두 진폭의 상대 위상

0°

해당 결과의 상대 확률

## 100%

동일한 크기의 두 진폭을 가정한 정규화된 상대 강도. 전체 확률분포에서의 절대 검출 확률을 뜻하지는 않는다.

이 시각화의 핵심은 단순해.

- 위상이 같으면 진폭이 강화된다.
- 위상이 반대면 진폭이 상쇄된다.
- 확률은 진폭을 합친 다음 그 절댓값을 제곱해서 계산한다.

영상에서는 위상 수치 자체는 표시하지 않고, 파형을 이동시킬 때 검출 확률이 커지거나 작아지는 모습만 보여주어도 충분해.

# 6. 구현 전에 반드시 지켜야 할 물리적 구분

첫째, 보른의 최초 연구와 영상의 검출점 예시는 구별해야 해.

보른은 1926년 충돌 및 산란 문제에서 확률 해석을 제안했어. 이번 콘티의 후반부에 등장하는 검출 화면 시뮬레이션은 오늘날의 보른 규칙을 설명하기 위한 개념적 예시야. 실제 보른의 1926년 실험 장치를 재현한 것처럼 표시하면 안 돼.

둘째, 확률진폭과 확률밀도는 서로 달라.

파동함수는 음수나 복소수 값을 가질 수 있어. 확률밀도는 그 절댓값 제곱으로 계산되는 음수가 아닌 값이야. 따라서 파동 곡선이 바로 검출 확률 그래프처럼 변하는 장면에서는 반드시 이 변환을 보여줘야 해.

셋째, 간섭하는 것은 각각 계산한 확률이 아니라 진폭이야.

두 가능성이 구별되지 않는 경우에는 확률진폭을 먼저 합하고, 그 절댓값을 제곱해야 해. 반대로 두 경로가 측정으로 구별되는 경우에는 이러한 간섭이 유지되지 않을 수 있어.

넷째, 보른의 확률 해석 자체가 모든 숨은변수 이론을 반박한 것은 아니야.

보른 규칙은 측정 결과의 확률을 계산하는 규칙이고, 이 확률이 세계의 근본적 비결정성을 뜻하는지는 별도의 해석 문제야.

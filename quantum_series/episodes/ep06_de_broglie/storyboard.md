상세 영상화 콘티 · 161초(2분 41초) · Manim 기반 2D 과학 애니메이션 · 9:16 쇼츠 / 16:9 롱폼 공용

이번 6편은 앞선 영상들과 달리, 같은 원형 궤도에 파동을 배치했을 때 어떤 조건에서 일관된 상태가 만들어지는지를 시청자가 직접 비교하도록 제작하는 것이 핵심이야.

가장 중요한 장면은 65\~105초야. 단순히 정상적인 파동과 비정상적인 파동을 번갈아 보여주는 대신, 파동을 원의 둘레에 펼쳤다가 다시 연결하면서 위상이 일치하는지 확인하도록 구성하자.

이번 편에서는 원형 궤도와 파동을 한 객체에 합쳐버리지 않는 것이 중요해.

원형 궤도는 회색 기준선, 파동은 그 기준선을 중심으로 진동하는 별도 곡선으로 그려야 해. 파동의 진폭은 물리적인 전자의 궤도 반지름 변화가 아니라, 파동의 값을 구별하기 위한 시각적 표현이야.

화면 연출

4편의 원자 모형을 그대로 재사용한다.

이어서 대부분의 회색 궤도가 사라지고, 세 개의 허용된 궤도만 청록색으로 남는다.

- `Circle`로 궤도 후보 생성
- `LaggedStart(FadeOut(...))`으로 허용되지 않은 궤도 제거
- 전자 하나를 허용 궤도 위에 표시

주의: 여러 궤도를 보여주더라도 하나의 전자가 여러 궤도에 동시에 존재한다는 의미는 아니야. 서로 다른 허용 상태를 나타내는 표현이야.

## 5-1. 원형 파동 모델

원의 둘레를 따라 움직이는 위치를 각도 \\(\theta\\)로 표시하면, 파동의 위상을 다음과 같이 표현할 수 있어.

\\[ \phi(\theta)=m\theta \\]

여기서 \\(m\\)은 원의 둘레에 들어가는 파장의 개수야.

원이 한 바퀴 돌아 \\(\theta=2\pi\\)가 되면 위상 변화는

\\[ \Delta\phi=2\pi m \\]

이때 처음과 끝의 위상이 같으려면 그 차이가 \\(2\pi\\)의 정수배여야 하므로 \\(m\\)은 정수가 되어야 해.

## 3.5개

동일한 위치에서 위상이 불일치

영상용 사전 검증 도식. 슬라이더를 움직여 3개와 3.5개의 차이를 확인할 수 있어.

이 화면을 Manim으로 구현할 때 파동의 반지름 방향 진동은 다음 형태를 사용할 수 있어.

```
def circular_wave(theta, cycles, radius=2.0, amplitude=0.18):    r = radius + amplitude * np.cos(cycles * theta)    return np.array([        r * np.cos(theta),        r * np.sin(theta),        0.0,    ])
```

파동 위상 연결 조건은 별도 함수로 계산하자.

```
def is_phase_matched(cycles, tolerance=1e-9):    return abs(cycles - round(cycles)) < tolerance
```

주의할 점은 `cos` 곡선의 높이가 같다는 것만으로 모든 위상 조건을 검사했다고 판단하면 안 된다는 거야. 시작점과 끝점에서 복소 위상까지 일치하는지를 기준으로 판단하는 것이 더 정확해.

예를 들어 `cycles=3`이면 위상 변화는 \\(6\pi\\), `cycles=3.5`이면 \\(7\pi\\)가 돼. 앞의 값은 2π의 정수배지만 뒤의 값은 그렇지 않아.

## 5-2. 원형 파동을 펼치는 애니메이션

이번 영상에서는 `UnwrapCircularWave`를 별도 컴포넌트로 구현하는 것을 추천해.

원의 둘레를 따라 정의된 좌표 \\(s=r\theta\\)를 직선 좌표로 바꾸면 돼.

- 원형 표현: 핵을 중심으로 한 각도 \\(\theta\\)
- 펼친 표현: 수평 위치 \\(s\\)
- 파동값: 동일한 위상 함수 유지

즉, 화면에서 원형 파동이 직선으로 펼쳐지더라도 파장 개수와 위상 차이는 바뀌지 않아야 해.

이 변환을 활용하면 3.5개에서 위상이 맞지 않는 이유와 3개에서 위상이 일치하는 이유를 같은 애니메이션 방식으로 비교할 수 있어.

이번 편에서 특별히 지켜야 할 기준이 세 가지 있어.

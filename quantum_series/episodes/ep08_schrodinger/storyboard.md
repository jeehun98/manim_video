# 양자역학의 발견 08 — 슈뢰딩거의 파동역학

상세 영상화 콘티 · 176초(2분 56초) · Manim 2D 애니메이션 · 9:16 쇼츠 / 16:9 롱폼 공용

이번 8편은 이전 회차들과 달리, 파동이 어떤 조건에서 존재할 수 있는지를 보여주는 과정 자체가 이야기의 핵심이야.

4편 보어 모형에서는 에너지 준위를 먼저 가정했고, 6편 드브로이의 물질파에서는 원형 경로에 파장이 정수 개 들어맞는 조건을 설명했어.

이번에는 더 이상 원형 경로를 미리 설정하지 않아.

원자핵의 인력을 받는 파동이 어떤 상태를 형성할 수 있는지 계산했더니, 허용된 에너지들이 나타났다는 순서로 연출하는 것이 중요해.

## 1. 영상 전체의 시각적 구조

ACT 1 · 00:00–00:26

ACT 3 · 00:55–01:20

원자핵에 의한 인력과 전자의 운동에너지를 함께 고려하는 방정식이 등장한다.

ACT 4 · 01:20–02:15

허용된 파동과 에너지의 발견

특정한 정상상태에 정해진 에너지가 대응하고, 수소 원자에서 보어의 에너지 준위가 다시 나타난다.

ACT 5 · 02:15–02:56

정상상태와 파동함수의 의미

고전적인 원형 궤도에서 벗어나, 공간에 분포한 전자의 상태와 측정 문제를 제시한다.

# 5. 핵심 시뮬레이션과 Manim 구현

## 5-1. 정상파를 보여주는 장면

이번 편에서 26\~55초는 시청자의 직관을 형성하는 구간이야.

줄의 양끝은 고정하고, 파동의 모드 번호에 따라 나타나는 형태를 비교할 수 있도록 구성해.

줄의 정상모드 비교

n = 1

1차 모드2차 모드3차 모드

세 모드 모두 양끝이 고정되어 있지만, 내부 마디의 개수와 파형이 달라진다. 실제 영상에서는 시간에 따른 진폭 변화를 추가한다.

Manim에서는 위치 \\(x\\), 시간 \\(t\\), 모드 번호 \\(n\\)을 사용해 다음 형태로 구현할 수 있어.

```
import numpy as npdef standing_wave(x, t, n, length, amplitude, omega):    return (        amplitude        * np.sin(n * np.pi * x / length)        * np.cos(omega * t)    )
```

이 함수에서 `n`이 정수일 때 줄 양끝에서 변위가 0이 돼.

또한 마디의 위치가 변하지 않는 정상파가 만들어지므로, 45\~49초에서 줄이 제자리에서 진동하는 모습을 자연스럽게 구현할 수 있어.

## 5-2. 파동과 에너지 준위의 연결

80\~109초 구간에서는 파동의 모양과 에너지 준위가 일대일로 연결되는 모습을 보여주는 것이 핵심이야.

다만 한 에너지에 반드시 하나의 파동함수만 대응한다는 뜻으로 연출하면 안 돼. 수소 원자에서는 서로 다른 공간적 상태가 같은 에너지를 갖는 축퇴 현상도 나타나기 때문이야.

따라서 설명용 객체는 아래와 같이 구성하는 것이 좋아.

```
class AtomicState:    def __init__(        self,        quantum_numbers,        energy_ev,        wave_visual    ):        self.quantum_numbers = quantum_numbers        self.energy_ev = energy_ev        self.wave_visual = wave_visual
```

`quantum_numbers`로 상태를 구별하고, 같은 `energy_ev`를 갖는 여러 상태를 허용하는 구조야.

수소 원자의 에너지값을 표시할 때는 다음 값을 사용할 수 있어.

| 주양자수 | 에너지       |
| ---- | --------- |
| 1    | −13.60 eV |
| 2    | −3.40 eV  |
| 3    | −1.51 eV  |
| 4    | −0.85 eV  |

이 값은 비상대론적인 수소 원자 모형의 대표적인 근삿값으로 사용하면 돼.

## 5-3. 원형 궤도에서 파동함수로 전환

126\~135초는 앞선 4편, 6편, 7편을 연결하는 시각적으로 중요한 구간이야.

첫 장면에서는 원형 궤도를 도는 전자 점이 나타난다.

다음에는 점의 이동 궤적만 남는다.

이어서 궤도도 사라지며, 공간에 분포한 파동함수가 나타난다.

이때 화면 중심의 원자핵은 움직이지 않아야 해.

그러면 시청자는 동일한 원자를 서로 다른 이론으로 설명하고 있다는 사실을 쉽게 이해할 수 있어.

# 7. 물리적 정확성과 영상의 핵심 메시지

이번 영상에서 특히 주의할 점은 네 가지야.

첫째, 줄의 정상파와 원자의 파동함수는 같은 것이 아니야. 줄은 고정된 끝점이라는 경계조건을 갖지만, 수소 원자의 결합된 전자 상태는 원자핵의 쿨롱 퍼텐셜과 공간적 조건을 만족하는 파동함수로 설명해.

둘째, 슈뢰딩거 방정식이 언제나 불연속적인 에너지만 만들어내는 것은 아니야. 수소 원자에 묶여 있는 상태는 불연속적인 에너지를 가지지만, 이온화된 자유 상태에는 연속적인 에너지도 존재해.

셋째, 정상상태의 안정성과 원자의 자발방출은 구분해야 해. 원자의 바닥상태가 더 낮은 원자 내부 상태로 내려가지 않는다는 것과 들뜬 원자가 광자를 방출하는 과정은 서로 다른 설명을 요구해.

넷째, 파동함수의 물리적 의미를 이번 편에서 미리 확정하지 않는 것이 좋아. 공간에 퍼진 파동함수가 왜 특정한 측정 결과와 연결되는지는 다음 9편 보른의 확률 해석에서 설명해야 해.

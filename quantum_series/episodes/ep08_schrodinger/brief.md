# EP.08 제작 기준
확정35문장·176초·30fps. 사용자 문장과 종료 시각 유지. 음원 미제공으로 무음.
8개 독립 씬. 세로·가로 native 배치. standalone/join 본문과 길이 동일.
줄: 정수 모드의 고정된 양끝과 마디, 시간에 따른 진동을 실제 식으로 계산한다. 여러 모드 합도 허용됨을 표시한다.
원자: 줄을 원으로 감지 않는다. 쿨롱 퍼텐셜, 운동에너지, 정규화 가능한 결합 상태 조건을 구별한다. 물리적 벽을 추가하지 않는다.
수소 비상대론적 모형. 대표값 -13.60/n² eV. 수치 반지름 방정식의 고유값과 비교한다. 미세구조·스핀·핵의 유한질량 등은 생략한 근사.
원자에 묶인 상태의 에너지 불연속성과 E≥0 연속 영역을 함께 표시한다. 모든 에너지가 불연속이라고 일반화하지 않는다.
상태는(n,l,m)으로 구별하고2s·2p가 같은 에너지를 갖는 축퇴를 허용한다. 하나의 에너지에 하나의 파동함수만 있다고 표현하지 않는다.
파동함수 시각화는 실제 수소1s·2s·2p_z의 공간 부분2D 단면. 색=부호, 밝기=상대 |ψ|. 확률밀도나 전자의 물질 분포라고 부르지 않는다.
정상상태 전체 위상은 변할 수 있다. 고전적인 가속 점전하를 정상상태에 대입해 복사한다고 설명하지 않는다.
바닥상태에는 더 낮은 원자 내부 방출 전이가 없다. 들뜬 상태의 자발방출은 원자와 복사장의 상호작용을 필요로 함을 제작 자료에 기록한다.
측정 결과 점은 하나의 검출 사례이다. 분포의 국소 붕괴를 확정된 기계적 과정으로 그리지 않는다. 마지막1초 정지, 엔드카드 없음.

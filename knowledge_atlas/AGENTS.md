# Knowledge Atlas 작업 규칙

- 이 디렉터리는 기존 Manim 제작 환경과 독립적이다. 지식 데이터 작업을 이유로 기존 대본·장면·렌더 설정을 수정하지 않는다.
- 개념을 추가하기 전에 `data/concepts.json`을 확인하고 중복되면 기존 노드를 확장한다.
- 관계를 별도의 주장으로 기록한다. 설명·성립 조건·근거·한계·구체적 출처 구간을 함께 남긴다. 일반화/특수화와 동치/유사성을 구별한다.
- AI 제안은 `provenance: ai_suggestion`, `verificationStatus: proposed`로 시작한다. 근거를 읽지 않고 verified로 처리하지 않는다. 관계를 조사할 때 외부 문헌이 필요하면 원문·공식 자료를 확인한다.
- 개인의 학습 상태와 관계 검증 상태를 구분하고 사용자의 이해 수준을 임의로 추정하지 않는다.
- 파일 존재와 제작 완료를 구분한다. 대본만 확인했으면 콘텐츠 상태는 script_present다.
- 새 개념·관계는 JSON으로 추가한다. 새 범주가 필요할 때만 스키마와 표시 이름을 확장한다.
- 변경 후 `npm run validate`, `npm test`를 실행한다. UI 변경이면 `npm run build`와 변경된 대표 화면을 확인한다.
- 외부 API·클라우드·자동 관계 생성 기능은 별도 요청 없이 추가하지 않는다.

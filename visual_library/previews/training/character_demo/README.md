# 주인공 동작 예시

승인한 첫 번째 캐릭터의 외형을 참고해 내장 imagegen으로 3×2 동작 시트를 생성했다.
`hero_sheet.png`: 대기, 걷기 2종, 검 준비, 내려침, 웃는 표정.
`hero_animation.gif`와 `index.html`: 프레임 교체 및 위치 이동으로 동작을 확인하는 예시.
기존 수식 시안에는 적용하지 않았다. 걷기 프레임의 차이가 작고 프레임 사이
외형 차이가 있어 최종 스프라이트는 추가 정리가 필요하다. 본편 시간표가 아니다.

생성 프롬프트 요지: 첫 주인공의 갈색 머리·빨간 스카프·파란 옷·금색 버클·갈색 부츠·
보라 윤곽·아이보리 외곽선을 유지한 동일 캐릭터 6포즈, 투명 배경의 3×2 시트.

## 걷기 수정

걷기 B의 발 위치·무릎 굽힘을 내장 imagegen으로 수정했다. 기존 다른 포즈는 유지한다.
A → 발 모으기 → B → 발 모으기로 재생해 보폭 변화를 드러낸다.
현재 GIF는 `hero_animation_walk_v2.gif`, 수정 시트는 `hero_sheet_walk_v2.png`다.
아직 최종적인 좌우 다리 교대·접지 검증을 마친 게임 스프라이트는 아니다.

## 걷기 v3 (현재)

이전 걷기 v2는 폐기된 시안이다. 현재 `hero_animation_walk_v3.gif`를 재생한다.
발 모으기 프레임 없이 걷기 A/B만 교대한다. B의 화면 왼쪽 부츠는 아래로
뻗고 오른쪽 부츠는 위로 접혀 A와 반대가 된다. 칼은 같은 화면 왼쪽 손에
유지하고 자유로운 오른쪽 팔은 내려 뒤로 둔다. 나머지 포즈는 원본을 사용한다.
내장 imagegen으로 B만 수정했으며 원본과 수정 시트를 모두 보존한다.
프롬프트 핵심: top-right B only; screen-left boot lower/forward, screen-right boot
higher/tucked, sword in same screen-left hand, free screen-right arm back/down;
keep all other cells unchanged, transparent pixel art.
`build_preview.py`로 프레임 선택과 GIF 조립을 재현한다.

## 4프레임 걷기 (현재)

현재 재생 파일은 `hero_animation_walk4.gif`다. 이전 v2/v3를 대체한다.
`hero_walk_four_frames.png`에서 접지 A → 통과 A → 접지 B → 통과 B를
분리한 `walk4_0.png`~`walk4_3.png`를 교대한다. 차렷/발 모으기 자세는 없다.
접지 A는 검 손이 전방, 접지 B는 검 손이 후방으로 움직이고 통과 자세의
들린 무릎도 좌우 교대한다. 검은 팔의 움직임에 따라 위치와 각도가 바뀐다.
내장 imagegen으로 참조 캐릭터의 4프레임 걷기 시트를 생성했다.
프롬프트 핵심: 동일 손의 검, 반대 팔·다리 교대, 접지/통과 4종, 검은 배경,
동일 크기와 기준선. 최종 영상용 픽셀 접지·해부학 검수는 별도로 필요하다.

### 짧은 체형 조정 (현재)

걷기 프레임의 너비를 유지하고 세로 길이를 약 15% 줄여 대기 자세와 가까운
짧고 통통한 비율로 조정했다. 현재 재생 파일은 `hero_animation_walk4_short.gif`.
걷기 4자세와 팔·다리 교대는 유지한다.

### 하체만 단축 (현재)

전체 세로 축소는 취소했다. 원본 걷기 프레임의 머리·상체 픽셀 크기를 유지하고
허리 아래(y=153 이후) 영역만 71px에서 43px로 단축했다.
현재 파일은 `hero_animation_shortlegs.gif`, 분리 프레임은 `walk4_shortlegs_*.png`.


## 현재 주인공 애니메이션 기준 (2026-11-19 저장)

- 기준 미리보기: `hero_animation_shortlegs.gif`.
- 머리와 상체의 원래 비율을 유지하고 **하체 길이만 줄인다**. 전체 세로 축소 버전은 사용하지 않는다.
- 걷기는 접지 A → 통과 A → 접지 B → 통과 B의 네 자세다. 차렷식 발 모으기를 끼우지 않는다.
- 팔과 반대쪽 다리가 교대하고, 칼은 같은 손에 든 채 팔을 따라 움직인다.
- 현재 적용 수치: 224×224 원본에서 y=153 위는 유지, 아래 71px를 43px로 단축. 프레임 배치 오프셋은 y=10.
- 시안은 대기 → 이동 → 칼 휘두르기 → 웃는 표정 순서로 반복한다. 본편 수식 시안에는 아직 캐릭터를 교체 적용하지 않았다.
- 원본·이전 시안은 보존한다. `build_preview.py`는 현재 하체 단축 버전을 재생성하도록 갱신했다.

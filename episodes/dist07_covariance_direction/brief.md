# 분포의 수학 07 제작 기준

- 학습 목표: 두 변수의 개별 분산이 같아도 공분산에 따라 **함께 퍼지는 방향**이 달라짐을 보고, 세 수를 공분산 행렬로 묶는다.
- 수학적 구성: 평균 0, 분산 1, 공분산 0인 짝 좌표 `(U,V)`를 만든다. 모든 장면의 점은 `X=U`, `Y=ρU+√(1−ρ²)V`로 계산한다. 따라서 정확히 `Var(X)=Var(Y)=1`, `Cov(X,Y)=ρ`다. `ρ=0,0.2,0.5,0.8,−0.8`만 사용한다.
- `ρ>0`이면 `(+, +)`와 `(−, −)`의 기여가 우세하고, `ρ<0`이면 `(−, +)`와 `(+, −)`가 우세하다. `ρ=0`은 선형 공분산이 0이라는 뜻이지 독립성을 뜻하지 않는다.
- 각 점은 같은 가중치의 관측으로 표시한다. 모양 변화는 관측값의 짝을 바꾼 결과이며, 공분산 숫자가 원인이 되어 점이 움직인다는 뜻은 아니다.
- 2×2 공분산 행렬은 대각선에 `Var(X), Var(Y)`, 비대각선 두 칸에 같은 `Cov(X,Y)`를 넣어 대칭으로 만든다. 마지막 타원의 장축은 후속편의 질문으로만 제시한다.
- 순서 및 목표 시간: 원형 점구름 0–4초 → 두 분산 고정 4–8초 → 양의 공분산 8–13초 → 양의 기여 13–17초 → 공분산 증가 17–22초 → 음의 공분산 22–27초 → 세 모양 27–31초 → 세 숫자 31–35초 → 행렬 조립 35–40초 → 이름 40–44초 → 장축 질문 44–49초.
- 실제 TTS 음성은 아직 없어 49초 목표의 간결한 대본으로 제작한다. 영상은 1080×1920, 30fps, 무음이며 숫자·영문 표기는 원문으로, 한글 발음은 TTS 파일에만 둔다.

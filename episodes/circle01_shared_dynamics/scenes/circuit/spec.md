# 전하와 전류가 만드는 진동

확정 구간: 84–103초 (19초). 사용자 제공 문장 종료 시각 준수.

주장: 전하와 전류가 만드는 진동.

대본: 이번에는 전기회로를 살펴보겠습니다. 축전기와 코일로 이루어진 이상적인 회로에서는 전하와 전류가 주기적으로 변합니다. 전류가 흐르면서 전하의 양이 바뀌고, 전하의 양은 다시 전류가 변화하는 방식을 결정합니다. 이 두 변수의 관계를 수식으로 나타내면, 앞에서 보았던 용수철과 같은 형태가 나타납니다.

화면: 공통 청록 원·주황 상태점, 위치/전하 파랑, 속도/전류 보라. 자막은 하단 전용 영역. scene.py의 draw_circuit 참조.

조건: 등속 회전, 무마찰 선형 용수철, 무저항 이상적 LC. 상태축은 (x, −v/ω), (q, −I/ω); I=dq/dt를 기준으로 정의. 비교 시 진폭·시간을 정규화.

시작·종료: 해당 주장의 물리 시스템과 상태 궤도. 다음 씬과 같은 색/도형으로 연결. 독립 렌더 클래스 CircleCircuit.

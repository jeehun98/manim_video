# 서로의 변화를 결정하는 두 좌표

확정 구간: 28–50초 (22초). 사용자 제공 문장 종료 시각 준수.

주장: 서로의 변화를 결정하는 두 좌표.

대본: 그렇다면 이 점이 일정한 속도로 원을 회전할 때, 두 좌표는 어떤 규칙으로 변화할까요? 가로 좌표의 변화율은 세로 좌표에 비례하고, 세로 좌표의 변화율은 가로 좌표에 비례합니다. 다만 두 변화의 방향에는 반대 부호가 붙습니다. 이렇게 두 변수가 서로의 변화를 결정하면, 점은 중심에서 멀어지거나 가까워지지 않고 계속 방향을 바꾸며 회전합니다.

화면: 공통 청록 원·주황 상태점, 위치/전하 파랑, 속도/전류 보라. 자막은 하단 전용 영역. scene.py의 draw_rule 참조.

조건: 등속 회전, 무마찰 선형 용수철, 무저항 이상적 LC. 상태축은 (x, −v/ω), (q, −I/ω); I=dq/dt를 기준으로 정의. 비교 시 진폭·시간을 정규화.

시작·종료: 해당 주장의 물리 시스템과 상태 궤도. 다음 씬과 같은 색/도형으로 연결. 독립 렌더 클래스 CircleRule.

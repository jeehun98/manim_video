# 서로 다른 현상, 같은 변화 규칙

확정 구간: 115–126초 (11초). 사용자 제공 문장 종료 시각 준수.

주장: 서로 다른 현상, 같은 변화 규칙.

대본: 그 이유는 두 현상이 동일한 형태의 변화 규칙을 가지고 있기 때문입니다. 한 변수의 변화율이 다른 변수에 비례하고, 다른 변수의 변화율은 반대 부호로 첫 번째 변수에 비례합니다.

화면: 공통 청록 원·주황 상태점, 위치/전하 파랑, 속도/전류 보라. 자막은 하단 전용 영역. scene.py의 draw_merge 참조.

조건: 등속 회전, 무마찰 선형 용수철, 무저항 이상적 LC. 상태축은 (x, −v/ω), (q, −I/ω); I=dq/dt를 기준으로 정의. 비교 시 진폭·시간을 정규화.

시작·종료: 해당 주장의 물리 시스템과 상태 궤도. 다음 씬과 같은 색/도형으로 연결. 독립 렌더 클래스 CircleMerge.

# 직선으로 움직이는 용수철

확정 구간: 50–70초 (20초). 사용자 제공 문장 종료 시각 준수.

주장: 직선으로 움직이는 용수철.

대본: 그런데 이 규칙은 실제 원운동에서만 나타나는 것이 아닙니다. 용수철에 매달린 물체를 생각해 보겠습니다. 물체를 한쪽으로 당겼다가 놓으면, 중심을 지나 반대쪽으로 움직였다가 다시 돌아옵니다. 이때 물체의 위치는 속도에 의해 변하고, 속도는 위치에 비례하는 복원력에 의해 변합니다. 두 변수는 서로의 변화를 결정하고 있습니다.

화면: 공통 청록 원·주황 상태점, 위치/전하 파랑, 속도/전류 보라. 자막은 하단 전용 영역. scene.py의 draw_spring 참조.

조건: 등속 회전, 무마찰 선형 용수철, 무저항 이상적 LC. 상태축은 (x, −v/ω), (q, −I/ω); I=dq/dt를 기준으로 정의. 비교 시 진폭·시간을 정규화.

시작·종료: 해당 주장의 물리 시스템과 상태 궤도. 다음 씬과 같은 색/도형으로 연결. 독립 렌더 클래스 CircleSpring.

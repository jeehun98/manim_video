# 위치와 속도의 공간에서 발견한 원

확정 구간: 70–84초 (14초). 사용자 제공 문장 종료 시각 준수.

주장: 위치와 속도의 공간에서 발견한 원.

대본: 여기서 물체의 위치를 가로축에, 속도를 적절히 조정해 세로축에 놓아 보겠습니다. 그러면 놀랍게도 원이 나타납니다. 실제로는 좌우로만 움직이던 물체가, 위치와 속도의 공간에서는 원을 그리며 회전하고 있었던 것입니다.

화면: 공통 청록 원·주황 상태점, 위치/전하 파랑, 속도/전류 보라. 자막은 하단 전용 영역. scene.py의 draw_phase 참조.

조건: 등속 회전, 무마찰 선형 용수철, 무저항 이상적 LC. 상태축은 (x, −v/ω), (q, −I/ω); I=dq/dt를 기준으로 정의. 비교 시 진폭·시간을 정규화.

시작·종료: 해당 주장의 물리 시스템과 상태 궤도. 다음 씬과 같은 색/도형으로 연결. 독립 렌더 클래스 CirclePhase.

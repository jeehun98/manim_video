# 분포의 수학 11 제작 기준

- 학습 목표: 다변량 Gaussian의 **확률밀도**가 평균에서의 Mahalanobis 거리 제곱에 의해 정해짐을 보고, 같은 거리의 점을 연결한 타원이 곧 등밀도선임을 이해한다. 밀도와 한 점의 확률을 혼동하지 않는다.
- 앞 편의 양의 정부호 공분산 `Σ=[[4,1],[1,1]]`, 평균 `μ=0`을 이어 쓴다. 같은 가중치의 48개 점은 정확히 이 공분산을 가진다.
- 2차원 Gaussian 식은 `p(x)=(2π√|Σ|)⁻¹ exp[-(x−μ)ᵀΣ⁻¹(x−μ)/2]`이고 `d_M²=(x−μ)ᵀΣ⁻¹(x−μ)`다. 고정된 `Σ`에서 밀도는 `d_M`에 따라 엄격히 감소하므로 `p(x)=c`와 `d_M=r`은 같은 등고선을 가리킨다. 상대 밀도 `p(x)/p(μ)`는 거리 `0,1,2,3`에서 각각 `1,.6065,.1353,.0111`이다.
- 밀도 단면은 옆에서 본 Gaussian 곡선과 위에서 본 타원을 짝지은 개념 그림이다. 정확한 3D 표면 렌더라고 주장하지 않는다.
- 공분산 변화 장면은 단위원형, 가로 타원, 세로 타원, 기울어진 타원의 등고선을 비교한다. 밀도의 높이 자체는 행렬식에 따라 바뀌므로 형태 연결에 초점을 둔다.
- 마지막에는 `W=Σ⁻¹/²`를 점구름에 적용해 공분산이 `I`가 되는 실제 변환을 보여준다. 타원이 원으로 되는 장면은 Whitening의 질문을 여는 역할이다.
- 화면 순서: 10편 타원 → Gaussian 옆/위 보기 → 같은 높이 절단 → 지수의 이차형식 → `d_M²` 인식 → 밀도 감소 → 같은 거리·같은 밀도 → 여러 등고선 → 공분산별 형태 → `Σ→d_M→p` → 타원과 원 → Whitening 예고.
- 실제 TTS 길이는 아직 없어 50초 목표의 간결한 대본으로 제작한다. 구간 경계는 4,8,12,16,20,24,28,32,37,41,45,50초. 1080×1920, 30fps, 무음.

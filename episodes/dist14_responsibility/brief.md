# 분포의 수학 14 제작 기준

- 4부 **하나의 분포를 넘어**. 제목에 핵심 용어 `Responsibility`를 포함한다. 수식 설명보다 먼저 **아주 가까운 두 점의 최근접 중심 소속이 갑자기 1↔2로 바뀌는 장면**을 보여준다.
- 2차원 Gaussian의 중심은 `μ₁=(-0.5,0)`, `μ₂=(0.5,0)`, 공통 공분산은 `diag(0.4²,σ_y²)`, 가중치는 `π=(0.4,0.6)`이다. 점을 `x=-0.070693…`에서 `x=+0.070693…`로 옮기면 최근접 중심은 1에서 2로 바뀐다. 영상 좌표에서는 두 중심이 2.5 단위 떨어져 있고 점은 약 0.35 단위 움직인다.
- `σ_y≈0.479315`는 두 번째 위치 `(x,0)`에서 `π₁p(x|1)=0.12`, `π₂p(x|2)=0.28`이 되도록 정했다. 이에 따라 `p(x|1)=0.30`, `p(x|2)=0.46666…`, 합은 `0.40`, 정규화된 책임도는 정확히 `0.30`, `0.70`이다. 화면의 `≈0.47`만 반올림 표기다.
- 수식 `γₖ(x)=πₖp(x|k)/Σⱼπⱼp(x|j)=P(z=k|x)`는 혼합 모수와 성분 해석이 주어졌을 때의 사후 확률이다. 밀도 `p(x|k)`는 확률 자체가 아니며, 가중 밀도를 정규화한 뒤에 소속 확률이 된다. 가까운 중심 기준은 처음의 **하드 배정 예시**일 뿐 GMM의 일반적인 최적 배정 규칙이라고 주장하지 않는다.
- 점을 움직일 때 책임도는 연속적으로 변한다. 영상의 색 막대는 그 연속 변화를 도식화하며 양 끝 `γ₁≈1`과 `γ₁≈0`은 충분히 떨어진 위치를 뜻한다. 마지막의 `z`는 성분 출처를 가리키는 짧은 예고이며 잠재변수의 정의와 생성 과정은 15화로 넘긴다.
- 흐름: 겹친 두 Gaussian → 가까운 중심의 하드 배정 → 작은 이동에 라벨 역전 → 경계 의문 → 두 밀도 → 가중치 → 정규화 → 30/70 → Responsibility → 연속 변화 → Hard/Soft → 숨겨진 선택 질문.
- 실제 TTS 길이 미제공으로 압축 대본 45초 목표다. 구간 경계는 `3,6,9,12,15,18,21.5,25,28,31.5,35,38,41,45`초. 실제 음성 길이가 나오면 구간별 전환 시간을 조정한다. 1080×1920, 30fps, 무음.

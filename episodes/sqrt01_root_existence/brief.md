# √2는 답일까, 다른 표현일까?

- 확정 대본과 문장 종료 시각을 기준으로 160초, 9:16, 1080×1920, 30fps를 제작한다.
- 장면 순서는 narration.md와 timing.json을 따른다. MP4는 무음이며 하단에 내레이션 자막을 넣고 SRT도 별도로 제공한다.
- x² = 2와 x = ±√2를 실수에서 같은 해집합을 가리키는 두 표현으로 연결한다. 두 해는 ±로 구분하고 초반에는 수직선의 좌표로 표시하지 않는다.
- 유리수 수직선의 점들은 표본이다. 유리수 근이 없다는 사실은 별도의 알려진 결과로 표시한다.
- f(x) = x² − 2의 두 끝점과 부호를 곡선보다 먼저 표시한다. 연속성에 이어 실제 포물선을 그리며 교점을 c, f(c) = 0으로 표시한다. 소수 근삿값은 노출하지 않는다.
- 중간값 정리는 양의 해의 존재에 사용한다. 양수 범위의 증가성과 제곱의 대칭성으로 양·음의 두 해를 표시한다.
- 마지막에는 완비성, 중간값 정리, 해의 존재가 어떻게 연결되는지 짚은 뒤 도입의 수식으로 돌아온다.
- 화면 상단에는 처음부터 끝까지 두 식의 동치를 표시하고, 하단 자막은 확정 문장 종료 시각을 따른다.

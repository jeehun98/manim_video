# 신경망의 역설 07 — 최악의 상황을 먼저 학습하는 신경망

## 제작 기준

- 사용자 확정 원고 25문단과 종료 시각 5·8·13·15·22·26·29·35·37·43·48·52·56·59·65·69·72·76·80·85·91·94·101·105·108초를 사용한다. 총 108초.
- 음원 미제공으로 무음 마스터. 최종 1080×1920, 30fps, 미리보기 360×640.
- 핵심은 평평한 지형의 결과보다, 손실 증가 방향을 임시 탐색한 뒤 그곳의 기울기로 원래 파라미터를 갱신하는 실제 절차이다. 이전 영상 복습·다음 영상 예고는 넣지 않는다.

## 장면과 타이밍

- 0–13초: 현재 θ에서 손실을 낮추는 방향과 임시로 높이는 방향을 대비. 파라미터 평면의 점과 등고선을 사용한다.
- 13–37초: 낮고 좁은 골짜기와 조금 높고 넓은 골짜기. 같은 좌표 눈금·같은 반경에서 현재 손실과 주변 최대 손실의 순위가 달라짐을 보여준다.
- 37–48초: 반경 ρ의 영역과 그 안의 가장 불리한 손실이라는 이상적인 목표를 정의한다. 이 단계는 실제 전방향 탐색 알고리즘이 아니라 목적의 개념도이다.
- 48–59초: 내부 max와 외부 min을 차례로 강조해 Min-Max 목적을 설명한다.
- 59–69초: 기울기 기반 1차 교란 ε̂, 임시 위치에서 두 번째 기울기 계산, 원래 θ에서 출발하는 최종 업데이트를 동작으로 구분한다.
- 69–80초: 두 골짜기의 동일 반경 주변 최대 손실 비교로 목적의 차이를 회수한다.
- 80–91초: 경험적 일반화 개선과 한계. 파라미터 좌표계·반경·측정 방식의 영향과 새 데이터 정확도 보장 부재를 명시한다.
- 91–108초: 현재 손실과 주변 최대 손실의 차이를 다시 보여주고, 임시 탐색과 실제 학습 업데이트를 구별하며 독립적으로 완결한다.

## 수학·구현 정확성

- 핵심 목적은 minθ max‖ε‖₂≤ρ L(θ+ε)이다. L은 고정된 동일한 학습 데이터의 손실이며, 교란하는 것은 입력 데이터가 아니라 파라미터이다. 원 논문의 별도 가중치 정규화 항은 설명에서 생략한다.
- 내부 최대화의 정의와 실제 근사를 구분한다. 표준 1차 SAM은 ε̂=ρg/‖g‖₂, g=∇L(θ)로 교란을 근사한다. 이 점은 일반적으로 실제 최대점과 다르며 전역 최악점을 찾는 절차가 아니다.
- 표준 1차 업데이트는 θnew=θ−η∇L(θ+ε̂)이다. 두 번째 기울기의 평가 위치는 교란점, 실제 업데이트의 출발점은 원래 θ이다. ε̂에 대한 역미분 항을 생략한 1차 방식을 설명한다.
- 임시 점은 주황색, 원래 θ는 파란색, 최종 θnew는 초록색으로 구분한다. 주황색 점에서 계속 내려간 위치를 θnew로 잘못 표시하지 않는다. 원래 위치의 표시를 남겨 출발점이 보이게 한다.
- 2차원 파라미터 평면의 두 축은 같은 단위 길이를 사용하므로 반경 ρ 원은 L2 공의 정확한 단면이다. 고차원 전체 공간을 그대로 보여준다는 주장은 하지 않는다.
- 국소 알고리즘 예시: L(v)=0.12+0.5 vᵀHv, H=[[1.5,0.25],[0.25,0.6]], θ=(0.25,0.35), ρ=0.65, η=0.38. 기울기·교란·업데이트·등고선은 모두 이 함수에서 계산한다. 이 예시는 절차 설명용이며, 일정한 곡률의 이 함수에서 더 평평한 해를 찾는다는 예시는 아니다.
- 이상적인 내부 최대점은 이 설명용 함수의 반경 경계에 대해 조밀한 각도 표본으로 시각화한다. 이는 영상 제작용 계산이며 SAM 구현이 이렇게 전수 탐색한다는 뜻이 아니다.
- g=0이면 정규화 식을 그대로 적용할 수 없다. 실제 구현은 0 또는 수치 안정화 처리가 필요하다. 알고리즘 시연은 g≠0인 점을 사용한다. 골짜기 바닥에서의 비교는 목적함수 해석이며, 그 정지점에서 1차 교란을 계산하는 그림과 혼동하지 않는다.
- 두 골짜기는 별도의 1차원 설명용 비교이다. 좁은 Ls(u)=0.08+3.8u², 넓은 Lw(u)=0.26+0.45u², 공통 반경 0.35. 현재 손실은 0.08<0.26, 주변 최대는 0.5455>0.315125로 역전된다. 양쪽의 x·y 눈금과 반경을 동일하게 유지한다.
- 1차원 두 골짜기 비교와 2차원 국소 갱신 그림은 별도 모형이다. 수치는 실제 신경망·논문 실측·권장 하이퍼파라미터가 아니다. 일반 SGD의 한 단계와 SAM의 한 단계로 성능 우열을 증명하지 않는다.
- 손실 증가 방향의 1차 근사는 국소적인 설명이다. 임의의 큰 반경에서도 정확히 최악을 찾아내거나 손실을 올린다고 일반화하지 않는다.
- SAM이 항상 좁은 골짜기를 피하거나 가장 넓은 골짜기에 수렴한다고 보장하지 않는다. 평탄성은 파라미터화와 노름·반경에 의존하며, 주변 안정성이 새 데이터의 정확도를 자동 보장하지 않는다.

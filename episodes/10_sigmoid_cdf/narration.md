# Sigmoid 05 — 누적확률이라는 새 좌표

137초 · 한국어 자막 · 무음

앞에서 어떤 입력 분포에서는 Sigmoid를 통과한 뒤의
분포를 정확하게 예측할 수 있다고 했습니다.

대표적인 경우가 위치 0, 척도 1인
표준 Logistic 분포입니다.

Sigmoid는 바로 이 분포의
누적분포함수, CDF와 같습니다.

CDF는 어떤 값보다 작거나 같은 값이
나올 확률을 나타냅니다.

CDF가 0.7이라면, 그 값 이하에
전체 확률의 70퍼센트가 누적되어 있다는 뜻입니다.

그렇다면 표준 Logistic 입력에
Sigmoid를 적용하면 어떻게 될까요?

각 입력값은 자신의 위치까지
누적된 확률로 바뀝니다.

데이터가 많이 모이는 중앙에서는
작은 입력 차이에도 누적확률이 빠르게 변합니다.

반대로 데이터가 드문 양끝에서는
같은 확률 차이를 만들기 위해
더 큰 입력 간격이 필요합니다.

그 결과 출력은
0과 1 사이의 균등분포를 따릅니다.

즉 출력에서 길이가 같은 구간마다
같은 확률이 배정됩니다.

물론 이것이 실제로 뽑힌 값들이
항상 정확히 같은 간격으로 놓인다는 뜻은 아닙니다.

많은 표본을 반복해서 관찰했을 때,
각 구간에서 값이 나타날 확률이 같다는 의미입니다.

그리고 이 성질은
Sigmoid만의 특별한 현상이 아닙니다.

연속인 누적분포함수를 가진 확률변수라면,

자신의 CDF를 적용한 결과는
0과 1 사이의 균등분포가 됩니다.

원래 입력값 자체를 보는 대신,
그 값이 전체 분포에서

어디쯤 위치하는지를 나타내는
누적확률로 다시 표현한 것입니다.

즉 입력 공간의 좌표를
누적확률이라는 새로운 좌표로 바꾼 셈입니다.

Sigmoid에서 시작한 비균일 압축은 이렇게
CDF와 확률분포의 변환으로 이어집니다.

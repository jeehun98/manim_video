# 선형대수학 03 — 경로를 잇고, 기여를 모은다

100초 · 1080×1920 · 30fps · 무음.2편과 같은 발화 중심의 짧은 전환을 유지한다.

## 핵심

하나의 경로에서는 연결의 가중치를 곱하고, 같은 출발점과 목적지를 잇는 경로들의 기여는 더한다. 직접 연결이 없어도 두 단계 간접 영향이 존재할 수 있다.

새 예시의 방향은 이전 편과 동일하게 A[i,j]가 j→i다. 먼저 1→2→3을 보여준 뒤 4번 대상을 추가하여 두 번째 경로를 만든다.

- 1→2: 0.5, 2→3: 0.8. 경로 영향 0.4.
- 1→4: 0.2, 4→3: 0.3. 경로 영향 0.06.
- A=[[0,0,0,0],[0.5,0,0,0],[0,0.8,0,0.3],[0.2,0,0,0]].
- A[3,1]=0 (수학의 1부터 시작하는 인덱스).
- (A²)[3,1]=0.8×0.5+0.3×0.2=0.46. 이 예제의 나머지 A² 원소는 0.
- (A²)[i,j]=Σ_k A[i,k]A[k,j]. 오른쪽 A[k,j]가 먼저 j→k, 왼쪽 A[i,k]가 다음 k→i를 나타낸다.
- A²는 원소별 제곱이 아니라 행렬곱 AA다. 정확히 두 번 연결을 통과하는 영향이며, 직접 연결을 포함한 두 단계 이하의 총합이 아니다.
- 일반적으로 여기서 경로는 길이 2인 walk를 뜻한다. 중복 방문을 금지하는 단순 경로만을 뜻하지 않는다. 이 예시는 순환이 없는 그래프다.
- 같은 A를 두 번 적용하면 A(Ax)=A²x. 다른 관계는 A 다음 B일 때 B(Ax)=(BA)x다.
- 이동하는 단위 입력은 가중 영향 계산을 설명하는 도식이다. 각 가지에 1이 적용되는 것은 값을 물리적으로 분배하거나 확률을 보존한다는 의미가 아니다.

## 구성

기여 합산 복습 → 두 단계 연결 → 1에서 0.5, 다시 0.4 → 네 번째 대상을 거치는 경로 → 두 경로의 합 0.46 → A² 정의 → A와 A²의 (3,1) 비교 → 중간 대상 k에 대한 합 → 오른쪽 인자의 적용 순서 → BA로 일반화 → 관계의 합성 정리.

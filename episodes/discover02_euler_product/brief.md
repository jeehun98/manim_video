# 수학적 발견 02 — 제작 기준

- 제목: 소수를 세는 문제에 왜 복소수가 등장할까?
- 목표: 자연수의 가중합과 소수별 인자의 곱이 유일한 소인수분해를 통해 같은 항을 생성한다는 발견.
- 구조: 정렬된 자연수와 소인수분해 → s=2 가중치 → 소수별 선택 레인 → 12/30 생성 → 일대일 대응 → 기하급수 접기 → 오일러 곱 → 복소평면 → 해석적 연속 → 영점.
- 형식: 9:16, 1080×1920, 30fps 무음. 시간초는 고정하지 않으며 장면 흐름에 따라 결정한다. 화면 설명 자막과 같은 captions.srt를 렌더 시 생성한다. 음성용 대본은 별도 파일이다.
- 1은 빈 곱으로 나타낸다. 모든 자연수는 양의 정수이며, 소수 레인의 선택 지수는 0 이상이다. 유일성은 곱의 순서를 제외한 소인수분해의 유일성이다.
- 2·3·5의 레인은 예시다. 12와 30을 만들 때 나머지 모든 소수의 지수는 0이다. 전체 자연수 생성에는 모든 소수가 필요하다.
- 자연수 자체를 합하는 1+2+3+…가 아니라 n^(-s)의 가중합이다. 화면과 대본에서 구분한다.
- 급수와 오일러 곱은 Re(s)>1에서만 표시한다. 이 영역에서 절대 수렴하므로 항의 재배열과 곱 전개를 정당화할 수 있다.
- 해석적 연속은 원래 급수의 수렴 영역 확대와 다르다. 제타 함수는 s=1에 단순극을 갖는 유리형 함수이며, 영상은 그 점을 제외하고 확장한다고 표현한다.
- 복소평면 축은 Re(s), Im(s)이며 서로 축척이 다르다. 영점 위치는 실수부 1/2와 실제 허수부 좌표를 사용한다. 궤적으로 연결하지 않는다.
- 임계선은 영점과 다른 점선으로 표시한다. 양의 허수부를 가진 첫 세 비자명 영점의 근삿값만 표시하며 모든 영점에 대한 일반화를 주장하지 않는다.

## 출처 (2026-10-13 확인)

- NIST DLMF §25.2 정의·해석적 연속·오일러 곱: https://dlmf.nist.gov/25.2
- NIST DLMF §25.10 영점: https://dlmf.nist.gov/25.10
- Andrew Odlyzko 공개 영점표: https://www-users.cse.umn.edu/~odlyzko/zeta_tables/zeros1
- 사용한 허수부: 14.134725142, 21.022039639, 25.010857580. 화면에는 소수 셋째 자리까지 표시한다.

## 설명 생략 피드백 반영

- 오일러 곱 이후 s=2의 수렴과 s=1의 발산을 비교한다. 무한급수를 아무 입력에나 사용할 수 없음을 먼저 설명한다.
- 기하급수와 1/(1-x)의 관계는 |x|<1에서만 등식으로 표시한다. x=2에서는 발산하는 급수와 계산 가능한 함수값을 별개로 배치한다.
- 해석적 연속은 원래 영역의 값과 해석적 성질을 보존하는 확장이다. 임의로 값을 붙이는 뜻이 아니다. 연결된 영역에서 원래 함수와 일치하는 해석적 연속의 유일성은 제작 기준으로 유지하되, 이 편에서 증명하지 않는다.
- 복소평면을 살피는 목적은 소수와 연결된 제타 함수의 구조를 더 넓게 분석하는 것이다. Re(s)>1에는 영점이 없음을 표시한다.
- 극점 용어의 학습 부담을 줄이기 위해 화면에서는 s=1을 예외/제외로 표시한다. 수학적으로는 단순극이라는 사실을 유지한다.
- 마지막은 영점과 소수 분포 오차의 관계를 다음 편의 질문으로 남긴다. 리만 가설, 자명한 영점의 분류, 명시적 공식의 도출은 이 편에서 다루지 않는다.
- 시간초 고정보다 설명의 연결을 우선하여 수렴 비교와 기하급수 예시의 관찰 시간을 확보한다. 내레이션·TTS는 화면 전환 사이에 빈 줄을 유지한다.

## TTS 실측 타이밍 적용

- 이후 사용자 제공 문단별 종료 시각을 우선한다. 전체 길이는 143초이며, 대본 25개 문단의 시작·종료 시각은 timing.json에 기록한다.
- 종료 시각: 3, 11, 16, 19, 25, 34, 37, 41, 50, 55, 59, 62, 67, 73, 77, 85, 94, 102, 107, 114, 118, 127, 131, 136, 143초.
- 각 시각에서 다음 문단의 시각 요소가 시작한다. 장면 전체 교체 시 페이드아웃은 경계 시각 전에 마친다. 애니메이션 속도 일괄 변경 대신 각 설명의 관찰 시간을 조정한다.
- Scene.time 체크포인트가 0.05초 이상 초과하면 렌더 오류로 처리한다. 마지막 체크포인트는 143초이다.
- captions.srt는 위 25개 문단의 내레이션 자막이다. 화면 요약 문구의 별도 타이밍은 screen_captions.srt로 저장한다.
- TTS 오디오 파일은 아직 제공되지 않아 음성 mux는 하지 않는다. 기존처럼 무음 마스터를 제공한다.

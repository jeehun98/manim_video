# EP.05 — 곱의 미분법

사용자 콘티·확정 대본28문장·145초. 1920×1080, 16:9, 30fps. TTS 미제공으로 무음·전체 자막. 2027학년도 6월 모의평가 수학 5번.

g(x)=3x−1, h(x)=x²−2x+2. g(2)=5, g′(2)=3, h(2)=2, h′(2)=2. f′(2)=3·2+5·2=16, 정답①. 전개식 3x³−7x²+8x−2와 도함수 9x²−14x+8을 비교한다.

g는 청록, h는 보라. 두 함수를 별도 객체로 관리하고 하나씩 미분한 두 항을 더한다. 네 값을 계산할 때 물음표 카드를 채우고 결과가 공식의 대응 위치로 복사되게 한다. 전개도 올바른 방법이며 곱의 미분법이 항상 더 빠르다고 단정하지 않는다. 잘못된 공식은 처음부터 취소 표시 및 ‘일반적으로 성립하지 않음’ 문구를 붙인다.

18개 독립 교체 씬. 기존 시리즈 폰트·팔레트·자막·타이밍·렌더 도구 재사용. 하단 자막 영역 분리. 확정 문장 종료 시각 준수. 이전 편 복습·다음 편 예고·별도 엔드카드 없음.

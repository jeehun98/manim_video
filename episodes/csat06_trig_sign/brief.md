# EP.06 — 삼각함수의 항등식과 부호

사용자 콘티·확정 대본29문장·142초. 1920×1080,16:9,30fps. 음원 미제공으로 무음·전체 자막. 2027학년도 6월 모의평가 수학 6번.

조건 3π/2<θ<2π, cos²θ=1/10. sin²+cos²=1을 이용해 tan²=1/cos²−1=9. 제곱근 후보 ±3은 미확정으로 표시한다. 제4사분면에서는 cos>0, sin<0이므로 tan=−3, 정답①.

단위원은 x·y 같은 스케일로 구현. 점 P=(1/√10,−3/√10) 사용, θ=2π−arctan(3). 경계는 엄격한 부등식으로 제외. 제곱값→크기와 각도조건→부호를 분리. 대체 풀이에서 사인의 크기는 3/√10, 음수 부호는 별도 단계에서 붙인다. 제곱값이 양수라도 원래 값이 양수라고 단정하지 않는다. cos²=1/10>0이므로 나눗셈 가능.

기존 시리즈 폰트·팔레트·자막·렌더 흐름 재사용. 17개 독립 교체 씬. 확정 문장 종료 시각 고정, 이전 편 요약·다음 편 예고·별도 엔드카드 없음.

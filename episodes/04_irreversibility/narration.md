# 04 — Beyond Information Loss

사용자 제공 한국어 대본. 100초 편집 타이밍이며 녹음이 없는 무음 마스터입니다. 화면은 영어와 수식만 사용합니다. 실제 음성 녹음 후 타이밍 조정이 필요할 수 있습니다.

| 시간(초) | 내레이션 |
| --- | --- |
| 0–8 | 활성화 함수에서 흔히 강조되는 성질은 비선형성입니다. 비선형성을 통해 모델은 더 복잡한 관계를 표현할 수 있습니다. |
| 8–17 | 하지만 우리가 사용하는 연산에는 또 하나 흥미로운 성질이 있습니다. 서로 다른 입력을 같은 출력으로 만들어, 일부 차이를 되돌릴 수 없게 만드는 것입니다. |
| 17–24 | ReLU를 생각해 봅시다. -1도, -10도, -100도 ReLU를 지나면 모두 0이 됩니다. |
| 24–30 | 출력이 0이라는 것만으로는 원래 값이 얼마나 음수였는지 알 수 없습니다. |
| 30–34 | 서로 다른 여러 입력이 하나의 출력으로 합쳐진 것입니다. |
| 34–41 | 이런 구조는 다른 연산에서도 나타납니다. 절댓값에서는 -3과 3이 모두 3이 되면서 부호 정보가 사라집니다. |
| 41–46 | 제곱에서도 -2와 2가 모두 4가 됩니다. |
| 46–54 | Max Pooling에서는 [1, 7, 3, 2]가 7 하나로 줄어들면서 선택되지 않은 값들의 정보가 사라집니다. |
| 54–61 | Quantization에서는 1.01, 1.02, 1.03처럼 조금씩 다른 값들이 같은 값으로 묶일 수 있습니다. |
| 61–66 | 이런 연산들은 서로 다른 방식으로 입력 상태의 차이를 줄입니다. |
| 66–74 | 그런데 이것은 단순한 손실만은 아닙니다. ReLU를 지난 값은 더 이상 음수가 될 수 없습니다. 출력은 항상 0 이상입니다. |
| 74–80 | Clamp를 사용하면 값을 원하는 구간 안으로 제한할 수도 있습니다. |
| 80–86 | Quantization은 출력이 가질 수 있는 값을 미리 정해진 단계들로 제한합니다. |
| 86–91 | 즉 어떤 차이를 버리는 대신, 이후 값이 어떤 형태를 가질 수 있는지는 더 명확해집니다. |
| 91–100 | 여러 상태를 하나로 합치고, 가능한 출력의 범위를 제한하는 것. 이것이 비가역적 연산을 단순한 ‘정보 손실’ 이상으로 볼 수 있는 이유입니다. |

## 연출 및 정확성

- 도입의 곡선은 x³/4입니다. 비선형이면서 일대일인 예이며, 다음 장면에 Nonlinear ≠ irreversible를 명시합니다.
- ReLU 출력 0은 음수뿐 아니라 입력 0도 포함합니다. 화면에 x ≤ 0을 표시합니다. 양수 ReLU 출력은 입력을 정확히 복원합니다.
- 절댓값과 제곱은 실수 전체에서 부호를 잃습니다. 제곱은 |x| = √y를 남깁니다.
- Max Pooling은 두 입력 창이 같은 최댓값으로 합쳐지는 예를 추가해 공통 구조를 보여줍니다.
- Quantization의 구체적 예시는 0.1 단위 최근접 반올림입니다. 수직선은 전체 격자 중 일부이며 가능한 출력 전체가 유한하다는 의미가 아닙니다.
- 출력 제약은 각 연산의 정의에서 나옵니다. 비가역성 자체가 언제나 범위 제약을 새로 만든다는 주장은 아닙니다.
- 대본의 ‘이후 값’은 해당 연산의 출력에 관한 표현입니다. 이후 임의 연산까지 같은 범위가 유지된다는 의미는 아닙니다.
- 입력 상태의 구별이 감소하는 것과 집합의 기수·벡터 차원·저장 용량이 감소하는 것은 다릅니다.

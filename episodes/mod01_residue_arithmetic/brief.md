# 모듈러 연산 — 제작 기준

- 확정 대본·문장 종료 시각 178초, 콘티의 60fps 적용. 9:16, 1080×1920. TTS 음원 미제공으로 무음.
- 모바일 자막은 PadicScene의 (-0.2,-5.95), 폭7.2, 높이1.9 배치 재사용. 본문 하한-4.65. 가장 긴 자막·본문 하단 함께 검수.
- 15개 독립 씬. 기존 공통 도형·자막·렌더 도구 재사용.
- mod는 0≤r<n을 주는 나머지, 합동은 a≡b(mod n) iff n|(a−b). n≥2. 정수 전체를 n개 동치류로 분류.
- mod5: [1]={...,−4,1,6,11,16,...}. 덧셈·뺄셈·곱셈은 대표값에 무관하게 정의됨.
- 17+28=45≡0, 2+3=5≡0. 17−28=−11≡4, 2−3=−1≡4. 17×28=476≡1, 2×3=6≡1.
- 8≡2(mod6), 정수 나눗셈 후 4≢1(mod6). 올바른 약분은 4≡1(mod3). 나눗셈 전부가 불가능하다는 뜻이 아님.
- 2×3≡1(mod5), 역원2^−1≡3. 역원 존재 iff gcd(a,n)=1. mod6에서 2의 곱은0,2,4뿐이며1에 도달 못함.
- 빠른 거듭제곱: 7^(1,2,4,8,16) mod10 =7,9,1,1,1. 중간마다 제곱 후 나머지 취함.
- RSA 그림은 c≡m^e(mod n) 핵심 연산의 개념도.
- x²+y²=2023. mod4의 제곱0,1 및 합0,1,2와2023≡3이 충돌. 격자 일부의 시각화가 증명인 것처럼 제시하지 않음.
- FLT는 n>2, x,y,z 양의 정수 조건 명시. 합동식이 도구 중 하나라는 설명이며 전체 증명에는 더 깊은 이론이 필요함을 화면에 명시.
- FLT 참고 자료는 기존 fermat01의 검토 결과와 https://annals.math.princeton.edu/1995/141-3/p01 재사용.

# 선형대수학 09 — 방향과 조합으로 나누어 기록하기

112초 · 1080×1920 · 30fps · 무음.

## 핵심

Rank 2인 행렬의 네 열을 독립적인 두 방향과 각 열의 조합 계수로 정확히 표현한다. B는 방향, C는 조합을 담는다.

## 사례

B = [[1,0],[0,1],[1,1]] (3×2)
C = [[1,0,2,1],[0,1,-1,3]] (2×4)
A = BC = [[1,0,2,1],[0,1,-1,3],[1,1,1,4]] (3×4)

a₃ = 2a₁ − a₂, a₄ = a₁ + 3a₂. B의 두 열은 독립이며 A, B, C의 Rank는 모두 2이다. 이 예제에서는 첫 두 열을 선택하지만 일반적으로 첫 r개 열이 반드시 독립인 것은 아니다. 독립인 r개 열을 골라야 한다. 기저 선택은 유일하지 않다.

## 크기와 정확성

Rank(A)=r인 m×n 행렬은 m×r 행렬 B와 r×n 행렬 C의 곱으로 정확히 분해할 수 있다. 원소 수는 mn 대 r(m+n)이며, r(m+n)<mn일 때 줄어든다.

- 이번 3×4 예제: 12개 → 6+8=14개. 항상 압축되는 것은 아니다.
- 1000×1000, Rank 10 예제: 1,000,000개 → 10,000+10,000=20,000개. 원소 수 98% 감소.
- 원소 개수 비교이며 파일 형식, 정밀도 등을 포함한 실제 파일 바이트 수 보장은 아니다.
- 실제 Rank에 맞춘 정확한 분해다. 더 작은 Rank로 근사하며 정보를 버리는 방식과 구별한다.

## 화면 구성

네 열 → 독립인 두 열 선택 → 두 나머지 열의 조합 → 계수표 → A와 B,C → 열별 재구성 강조 → 일반 차원 → 원소 수 비교 → 작은 예제 주의 → 큰 행렬 예제 → 원본과 복원본 비교 → 방향과 조합.

화면과 SRT는 숫자·영어·수식을 그대로 사용한다. 한글 발음은 tts_script.txt에만 기록한다. 실제 음성이 제공되지 않아 발화 길이를 예상해 타이밍을 구성했다.

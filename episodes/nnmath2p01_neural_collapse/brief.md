# 신경망의 수학 2부 01 제작 기준

## 제목과 역할

- 제목: **분류만 하면 되는데 왜 클래스는 정삼각형을 만들까? — Neural Collapse**
- 2부의 출발점은 학습된 신경망 내부에서 나타나는 수학적 구조다.
- 초반에는 `같은 클래스끼리 모인다`를 자연스럽게 받아들이게 하고, 이미 완벽히 분류 가능한데도 클래스 중심이 대칭 구조로 향한다는 지점에서 진짜 질문을 연다.
- 결론을 원인 설명으로 닫지 않고 `Why does learning create symmetry?`를 남긴다.

## 학습 목표

- 분류 가능성과 Neural Collapse의 규칙적인 기하학은 같은 말이 아님을 구분한다.
- 학습 후반에 나타날 수 있는 네 현상을 하나의 변화 과정으로 이해한다.
  1. 클래스 내부 representation의 변동 감소
  2. 중심화·정규화한 클래스 평균의 simplex ETF 구조
  3. classifier weight와 클래스 평균 방향의 정렬
  4. nearest-class-center 규칙과 classifier 결정의 일치
- 복잡한 파라미터 공간의 학습 결과가 representation space에서 단순한 기하학으로 나타날 수 있다는 1부와의 연결을 이해한다.

## 정확성 기준

- Neural Collapse는 모든 모델과 모든 훈련 단계에서 반드시 나타나는 법칙으로 표현하지 않는다. `특정 조건`, `학습 후반`, `나타날 수 있다`를 유지한다.
- 정삼각형은 원래 feature 좌표의 세 평균이 그대로 정삼각형이라는 뜻이 아니다. 전체 평균을 제거한 centered class mean을 적절히 정규화한 방향의 구조다.
- `⟨μ̃ᵢ, μ̃ⱼ⟩ = −1/(C−1)`은 서로 다른 클래스 `i≠j`와 단위 정규화된 centered mean에 대한 식이다. `C`개 클래스의 simplex는 일반적으로 `C−1`차원 부분공간에 놓인다.
- `w_c ∥ μ̃_c`와 nearest-class-center 일치는 Neural Collapse의 이상화된 limiting geometry로 소개한다. 유한 시간의 실제 모델에서 정확한 등식이라고 단정하지 않는다.
- `Training Accuracy ≈ 100%` 이후에도 cross-entropy loss와 representation이 계속 변할 수 있음을 암시하되, 정확도와 loss가 같은 양이라고 말하지 않는다.
- NC1–NC4 번호는 전면에 내세우지 않는다.

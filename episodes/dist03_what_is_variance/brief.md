# 분포의 수학 03 제작 기준

- 학습 목표: 평균은 확률질량의 균형점, 분산은 그 중심에서의 **제곱거리의 확률가중 평균**이라는 직관을 만든다. 공식 암기보다 `중심 → 편차 → 상쇄 → 제곱 → 확률가중` 순서를 우선한다.
- 2편 마지막 장면의 두 이산 분포를 그대로 사용한다. 좁은 A는 `P(-1,0,1)=(.15,.70,.15)`로 `μ=0`, `Var=.30`이다. 넓은 B는 `P(-3,-2,0,2,3)=(.25,.15,.20,.15,.25)`로 `μ=0`, `Var=5.70`이다.
- `x-μ`는 부호가 있는 편차다. `-2`와 `+2`를 그대로 더하면 0이고, `-10`과 `+10`도 0이다. 이는 퍼짐이 0이라는 뜻이 아니다. `(-2)²=(+2)²=4`로 상쇄되지 않는 양을 보여준다.
- 제곱은 이 편에서 상쇄를 피하며 멀리 있는 값의 기여가 커지는 선택으로 소개한다. 절댓값도 부호 상쇄를 막을 수 있으므로 “부호를 없애는 유일한 방법”이라고 주장하지 않는다. 절댓값과 제곱의 선택 비교는 다음 주제로 남긴다.
- 이산 분포에 대해 `Var(X)=ΣₓP(X=x)(x-μ)²=E[(X-μ)²]`를 표시한다. 각 값의 확률이 곱해져야 하며 단순히 제곱 편차를 더하지 않는다.
- B에서 ±3의 확률 `.25`씩을 ±4로 옮기는 장면은 전체 확률과 평균을 유지하면서 분산을 `5.70 → 9.20`으로 늘린다.
- 마지막에는 둘 다 `μ=0`, `Var=1`인 다른 모양의 분포를 사용한다. 단봉형 C는 `P(-2,0,2)=(1/8,3/4,1/8)`, 양봉형 D는 `P(-1,1)=(1/2,1/2)`다. 따라서 같은 평균·분산은 같은 분포를 보장하지 않는다.
- 실제 TTS 길이 49초에 맞춘 구간 경계는 5, 9, 14, 18, 23, 27, 34, 38, 43, 49초다. 대본 길이가 가장 긴 분산 정의 장면에 7초를 배분했다. 1080×1920, 30fps 무음. 숫자·영문은 화면·대본에 원문으로 쓰고 TTS 발음 표기만 별도 파일에 둔다.

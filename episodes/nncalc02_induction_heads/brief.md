# 신경망 내부의 계산 02 — AI는 반복 패턴을 찾는 회로를 스스로 만든다

## 확정 자료와 형식

사용자 첨부 콘티와 확정 낭독 33구간, 누적 종료 시각 1,3,5,11,17,22,27,33,37,42,46,51,54,61,64,71,74,78,83,92,95,100,108,114,123,131,139,142,149,154,156,158,165초를 기준으로 한다. 콘티의 3:00~3:30 대략 배분보다 이 시각을 우선한다. 일반용 1920×1080·16:9, 쇼츠용 1080×1920·9:16, 모두 30fps·165초(2:45). 새 문장이나 임의 엔딩 시간을 추가하지 않는다. 사용자 최종 질문은 그대로 유지하며 '다음 편' 예고 문구는 추가하지 않는다.

기본 무음. 음원 파일은 미제공으로 실제 파형 싱크를 검증했다고 주장하지 않는다. 두 영상이 같은 timing.json과 발화를 쓰며 세로 화면은 전용 배치와 줄바꿈을 사용한다. TTS 원고는 주요 화면별 19문단, 빈 줄 하나로 구분한다. 제목·번호·시각은 낭독하지 않는다.

## 수학·회로 조건

- 실제 입력은 A B C D A 다섯 토큰이다. 별도 예측 칸의 ? 또는 B는 6번째 입력 토큰이 아니며 Q/K/V를 계산하는 입력 위치로 사용하지 않는다. B는 패턴 완성에 따른 후보이며 유일하게 강제되는 정답이라고 말하지 않는다.
- 첫 층 Previous Token Head의 참조는 위치 i → i−1. 정보는 반대로 이전 위치 → 현재 위치의 표현으로 추가된다. 원래 토큰 정보가 지워지거나 토큰 자체가 이동하지 않는다. 위치 2는 현재 B 정보와 앞 A 정보를 함께 가진다. 첫 위치의 앞 정보는 '시작/—'이며 실제 시작 토큰·경계 처리는 생략한 개념도다.
- 두 번째 층의 Query는 현재 5번 A 정보에서, Key는 앞 토큰 정보가 반영된 과거 위치에서 형성될 수 있다. A에 대응하는 Key 정보는 **2번 B 위치**에 있다. 선택 경로는 5→2이며 5→1로 잘못 그리지 않는다. 첫 위치의 Key는 시작 경계로 구별한다.
- QK 선택은 노란 선, Induction Head 표시는 주황색. OV 정보 전달은 2→5의 보라색 흐름. 선택된 Value의 B 관련 특징이 Output Projection을 거쳐 현재 위치의 표현에 기여하고 이후 읽기/출력에서 B의 예측을 지지한다. 문자 B를 그대로 복사하는 것이 선형 변환의 완전한 설명이라는 주장을 피한다.
- Previous Token Head는 파란색, 현재 A 청록색, 가져올 B 보라색. 두 Head 전체는 Induction Circuit, 패턴 연결을 수행하는 후속 Head는 Induction Head로 구별한다. 단순화된 대표 회로이며 모든 실제 Transformer의 보편적 배선도는 아니다.
- 모든 점수·세기·학습 시점·제거 효과 그림은 개념도다. 실제 수치·데이터를 재현하지 않는다. 회로 형성 시기와 행동 개선의 동시 관찰은 모든 문맥 능력에 대한 보편적 인과 증명이 아니다. 작은 attention-only 모델의 인과 근거와 큰 모델에서의 더 제한적인 근거를 구별한다.
- Head 출력 경로 제거는 개념적 ablation이다. 한 Head 제거가 반드시 B 오답을 만든다고 표시하지 않는다. 다른 경로가 기여할 수 있다.
- 마지막 데이터 조절은 형성 시점·강도에 관한 질문이다. 이미 학습된 모델을 즉시 바꾸는 장면이나 이 영상에서 새로 입증한 실험 결과로 보여주지 않는다. 데이터 분포 → 새로 학습 → 형성 비교의 순서를 유지한다.

## 근거

2026-10-21 [Olsson et al., In-context Learning and Induction Heads, 2022](https://arxiv.org/abs/2209.11895) 공식 초록 및 [저자 공개 본문](https://transformer-circuits.pub/2022/in-context-learning-and-induction-heads/)의 검색 인덱스에 실린 회로·근거 구분을 확인했다. 공개 본문 전체는 도구의 페이지 크기 한도로 열리지 않아 이를 전부 정독했다고 주장하지 않는다. 초록은 작은 attention-only 모델의 강한 인과 근거와 큰 MLP 포함 모델의 상관 근거를 구분한다. 회로 도식의 배경은 [A Mathematical Framework for Transformer Circuits](https://transformer-circuits.pub/2021/framework/index.html)다. 첨부 콘티의 수학적 조건을 위처럼 명시해 구현한다.

# 신경망 내부의 계산 02 — Induction Heads 상세 영상화 콘티

영상 제목: AI는 반복 패턴을 찾는 회로를 스스로 만든다 — Induction Heads

이번 영상은 단순한 Attention 설명이 아니라, 서로 다른 두 Attention Head가 어떻게 협력해 하나의 알고리즘을 구현하는가를 시각적으로 보여주는 것이 핵심이야.

특히 기존 대본에서 가장 중요한 부분은 다음 세 가지야.

1. 과거의 `A`를 찾는 것만으로는 다음 토큰 `B`를 예측할 수 없다.
2. 첫 번째 Head가 이전 토큰 정보를 옮기고, 두 번째 Head가 그 정보를 이용해 필요한 위치를 찾는다.
3. 이렇게 연결된 회로가 사람이 직접 설계하지 않아도 학습 중에 형성될 수 있다.

### 색상 규칙

| 요소                  | 색상     | 의미              |
| ------------------- | ------ | --------------- |
| 현재 토큰 A             | 청록색    | 찾으려는 패턴         |
| 과거 토큰 B             | 보라색    | 가져와야 할 다음 토큰 정보 |
| Previous Token Head | 파란색    | 앞 토큰 정보를 옮기는 연산 |
| Induction Head      | 주황색    | 일치하는 과거 위치 검색   |
| QK Attention        | 노란 연결선 | 어느 위치를 읽을지 결정   |
| OV 경로               | 보라색 흐름 | 선택된 위치에서 정보 전달  |

가장 중요한 원칙은 \*\*어디를 참조할지 선택하는 연산(QK)\*\*과 \*\*선택한 위치에서 어떤 정보를 가져오는 연산(OV)\*\*을 시각적으로 구별하는 것이야.

### 장면 14. 회로에 이름을 붙인다

화면 중앙에 앞선 두 Head의 합성 그림을 고정한다.

학습 스텝이 증가하면서 모델의 가중치와 Attention 패턴이 점차 변화하는 연출을 시작한다.

핵심: 초기 신경망의 모든 Head가 무작위 Attention 패턴이라는 식으로 지나치게 단순화하지 말고, 초기에는 특정한 회로가 뚜렷하지 않다가 학습 중에 발견 가능한 구조가 형성되는 모습을 보여줘.

여기서는 훈련 단계가 진행될수록 Induction 패턴의 강도가 올라가는 작은 그래프와 문맥 내 반복 패턴 활용 능력의 변화 그래프를 나란히 놓아도 좋아.

다만 연구에서 관찰한 학습 중의 급격한 변화가 모든 모델에서 발생하는 보편적인 임계 현상인 것처럼 표현하지 않는 게 중요해.

내레이션: “그런데 실제 연구에서는 학습이 진행되는 동안 이런 회로가 형성되는 현상이 관찰되었습니다. 특히 일부 트랜스포머에서는 인덕션 헤드가 형성되는 시기와 문맥 안의 반복 패턴을 활용하는 능력이 빠르게 개선되는 시기가 맞물렸습니다.”

## 4. Manim 구현 설계

이번 영상에서 반복적으로 필요한 컴포넌트는 다음과 같아.

| 클래스                  | 핵심 기능                       |
| -------------------- | --------------------------- |
| `TokenSequence`      | 토큰 배치, 색상 강조, 문자열 변경        |
| `AttentionArc`       | Query 위치에서 참조 위치로 연결선 생성    |
| `ResidualStreamView` | 각 위치의 원래 정보와 추가된 정보 표시      |
| `PreviousTokenHead`  | 한 위치 앞의 Value 정보 전달         |
| `InductionHead`      | 앞 토큰 정보가 일치하는 위치 선택         |
| `QKOVVisualizer`     | Attention 점수 계산과 정보 전달 분리   |
| `CircuitComposition` | 여러 Head의 연산을 하나의 계산 그래프로 연결 |
| `TrainingEvolution`  | 학습 단계별 Attention 패턴 변화      |
| `HeadAblation`       | Head 제거 및 예측 기여 변화 시각화      |

애니메이션 전체를 별도 장면으로 구현하기보다는, `TokenSequence`와 `AttentionArc`를 공통 객체로 유지한 채 `Transform`이나 `ReplacementTransform`으로 변경하는 구조가 좋아.

특히 3막에서 B 위치에 추가한 A 정보를 4막에서도 같은 색상과 동일한 위치로 유지해야 해. 이것이 두 층이 연결되는 과정을 이해시키는 핵심이야.

## 5. 제작 시 주의할 기술적 사항

- Attention 방향: 현재 A가 과거 B 위치를 참조한다. B의 Key에는 앞 토큰 A의 정보가 반영되어 있다.
- QK와 OV: 어느 위치가 선택되는지와 그 위치에서 어떤 정보가 전달되는지를 분리한다.
- Residual Stream: 토큰 정보가 실제로 다른 위치로 옮겨가는 것보다는, 대상 위치의 표현에 관련 정보가 추가되는 과정으로 표현한다.
- 회로 형성: 학습 과정의 변화는 특정 연구 모델에서 관찰된 결과이며, 모든 Transformer에 보편적으로 나타나는 현상이라고 단정하지 않는다.
- 개념도와 실제 측정치: 학습 곡선, Head의 Attention 강도, 제거 실험 수치는 실제 논문 데이터가 아니라면 개념도로 표시한다.

참고 연구: [In-context Learning and Induction Heads](https://transformer-circuits.pub/2022/in-context-learning-and-induction-heads/?utm_source=chatgpt.com) — Olsson et al., 2022.

이번 영상의 핵심 장면은 3막에서 4막으로 넘어가는 순간이야. 첫 번째 층이 B 위치에 과거 A의 정보를 남겨두고, 두 번째 층이 바로 그 정보를 이용해 B 위치를 찾는 과정.

이 연결을 제대로 보여주면 시청자는 Attention Head의 작동 방식만 배우는 것이 아니라, 서로 다른 신경망 연산이 합성되면서 하나의 알고리즘이 만들어지는 과정을 이해하게 될 거야.

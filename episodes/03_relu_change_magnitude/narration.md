# ReLU — Beyond the count

40초 영상용 축약 대본. 화면은 영어, 내레이션 원고는 한국어입니다.
음성은 포함하지 않은 무음 마스터입니다.

## 바로 읽는 대본

이전에는 몇 개가 0이 됐는지 세었습니다.
둘 다 절반. 하지만 같은 변화일까요?

하나는 작은 값, 다른 하나는 큰 값들이 사라졌습니다.
입력에서 출력을 빼면 제거된 부분이 보입니다.
그 크기는 두 번째가 백 배 큽니다.

입력 전체의 크기와 비교하면 어떨까요?
변화의 크기를 입력의 크기로 나누면,
약 4.5퍼센트와 97.6퍼센트입니다.

개수보다 사라진 값의 크기와 전체 대비 비율이 더 중요할 수 있습니다.
측정 기준에 따라 해석도 달라집니다.
어떤 변화가 더 중요한지는 생각해볼 문제입니다.

## 수학·시각화 기준

- A = [-0.1, -0.2, 3, 4], B = [-10, -20, 3, 4]. 두 출력은 [0, 0, 3, 4].
- Zeroed Ratio = count(x < 0) / N. 이미 0인 입력은 새로 억제된 값으로 세지 않습니다.
- 제거된 벡터 Δx = x − ReLU(x)는 부호를 보존합니다.
- 길이는 모두 유클리드 노름입니다. ||ΔA|| = sqrt(0.05) ≈ 0.224, ||ΔB|| = sqrt(500) ≈ 22.361.
- ||A|| = sqrt(25.05) ≈ 5.005, ||B|| = sqrt(525) ≈ 22.913.
- Relative Change = ||Δx|| / ||x|| (x ≠ 0). 계산은 반올림 전 값으로 합니다.
- A ≈ 4.4677%, B ≈ 97.5900%. 화면은 4.5%, 97.6%로 표시합니다.
- 입력과 변화의 절대 길이는 같은 축척의 나란한 막대로 비교합니다.
- 정규화 막대의 전체 테두리는 각 입력 길이를 1로 둔 기준이며 색 막대는 길이의 비입니다.
  유클리드 길이를 제거 부분과 보존 부분으로 더해서 분해한다는 뜻이 아닙니다.
- 상대 변화량은 정보 손실의 보편적 정의가 아니며 개수 비율을 대체하지 않습니다.

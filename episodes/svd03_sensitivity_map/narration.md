# SVD 03 — 방향별 감도 지도

100초 · 1080×1920 · 30fps · 한국어 자막 · 무음 마스터

발화 예상 길이에 맞춘 편집이며 실제 음성은 포함하지 않습니다.

| 시간 | 내레이션 | 화면 |
|---|---|---|
| 00:00–00:08 | 같은 크기의 변화를 여러 방향으로 만들어보겠습니다.<br>입력에서는 모두 길이가 같습니다. | 크기는 같고, 방향만 다르게<br>‖Δx‖ = 1 |
| 00:08–00:17 | 하지만 같은 행렬을 통과하면,<br>어떤 방향의 변화는 크게 늘고,<br>어떤 방향의 변화는 작게 줄어듭니다. | 같은 크기가, 다른 결과로<br>같은 A, 같은 입력 길이, 서로 다른 출력 길이 |
| 00:17–00:26 | 즉 입력 변화의 크기가 같아도,<br>방향이 다르면 출력에서 보이는<br>변화의 크기는 달라집니다. | 방향이 다르면, 반응도 다릅니다<br>단위원 → A → 타원 |

| 00:35–00:44 | SVD는 이 민감도를 가장 명확하게 볼 수 있는<br>서로 직교하는 입력 방향들을 찾아줍니다. | SVD가 찾아주는 기준 방향<br>v₁ᵀv₂ = 0     ·     ‖v₁‖ = ‖v₂‖ = 1 |

| 00:53–01:02 | 첫 번째 방향의 변화가 세 배가 된다면,<br>이 행렬은 그 방향에 강하게 반응하는 것입니다. | 첫 방향은 3배 · 강한 반응<br>‖Av₁‖ = σ₁ = 3 |
| 01:02–01:11 | 두 번째 방향의 같은 크기 변화가 절반으로 줄어든다면,<br>첫 번째 방향보다 훨씬 덜 민감합니다. | 두 번째 방향은 0.5배 · 약한 반응<br>‖Av₂‖ = σ₂ = 0.5     ·     σ₁ / σ₂ = 6 |
| 01:11–01:21 | 다른 방향의 변화도 기준 방향들의 조합으로 나눠봅니다.<br>각 성분은 자기 특잇값만큼 반응한 뒤,<br>다시 하나의 출력 변화로 합쳐집니다. | 다른 방향도 기준 방향의 조합<br>Δx = c₁v₁ + c₂v₂ |
| 01:21–01:30 | 이렇게 특잇값을 비교하면,<br>행렬이 어떤 방향에 민감하고<br>어떤 방향에 둔감한지 알 수 있습니다. | 민감함을 수치로 읽습니다<br>‖AΔx‖² = σ₁²c₁² + σ₂²c₂² |
| 01:30–01:40 | SVD는 행렬이 방향마다 얼마나 민감하게<br>반응하는지 보여주는 감도 지도입니다. | SVD는 행렬의 감도 지도<br>방향 vᵢ  +  감도 σᵢ  +  출력 방향 uᵢ |

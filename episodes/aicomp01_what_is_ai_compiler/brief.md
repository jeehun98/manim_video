# AI 컴파일러 01 — AI 컴파일러란 무엇일까?

## 상태와 제작 범위

- 기존 aic01–08의 정규 언어·일반 컴파일러 기초 자료와 구분하는 새 시리즈다. ID는 aicomp01부터 시작한다.
- 이전 영상 복습과 이후 영상 예고 없이 질문과 결론으로 독립적으로 완결한다.

## 학습 목표와 중심 주장

일반 컴파일러와 원리를 공유하면서도 텐서 의미와 머신러닝 프로그램 구조를 분석·변환의 중심에 두는 전문화가 왜 유용한지 이해한다. 핵심은 연산 이름 인식 자체가 아니라, 구조와 제약을 유지할 때 고려할 수 있는 실행 방법이다.

## 수학·기술 조건

1. 예시는 X∈R^(M×K), W∈R^(K×N), b∈R^N, Y∈R^(M×N). MatMul의 K축 reduction, b의 M축 broadcasting을 표시한다. ReLU는 원소별 max(0,z)다. 화면·자막은 영문과 수식을 유지한다.
2. 저수준 명령 목록은 개념도다. 실제 ISA·어셈블리·특정 컴파일러 출력으로 제시하지 않는다. 실제 구현에는 벡터·행렬 명령, FMA 등도 쓰일 수 있다.
3. 뒤집기 장면은 동일 계산의 표현 수준을 비교한다. 실제 컴파일이 반드시 저수준 명령에서 MatMul을 복원한다는 뜻으로 그리지 않는다. 실제 개념 파이프라인은 고수준 구조를 활용하다 낮은 수준으로 내리는 방향이다.
4. 일반 컴파일러도 고수준 IR·라이브러리·루프 분석으로 텐서 계산을 최적화할 수 있다. 두 표현을 서로 배타적인 컴파일러 유형으로 표시하지 않는다.
5. 타일링·구현 선택·fusion은 후보이며 항상 적용되거나 빨라진다고 말하지 않는다. Shape·Dtype·의존성·aliasing·효과·타깃과 허용되는 수치 계약을 확인해야 한다. 실수 수식은 구조 설명이며 FP bitwise 동치 보장이 아니다.
6. 자동 미분·변하는 실행 조건 등의 관심사는 모든 제품이 직접 제공하는 필수 기능 목록이 아니다. 자동 미분·그래프 포착·코드 생성은 서로 다른 구성 요소가 담당할 수 있다. 모델 학습과 컴파일러 자체의 학습을 혼동하지 않는다. 후반부는 네 가지 기술 카드의 나열 대신 전체 프로그램의 변환 흐름 안에서 설명한다.
7. 하나의 그래프에서 여러 하드웨어로 분기하는 그림은 지원되는 대상별 컴파일을 뜻한다. 동일 실행 파일이 모든 장치에서 실행된다는 뜻이 아니다. 라이브러리 호출도 가능한 출력이며 모든 연산의 코드를 직접 생성한다고 일반화하지 않는다.
8. XLA·torch.compile은 사례다. 첫 편에서는 제품 구조 강의나 AOT·JIT·Dynamic Shape 세부 설명으로 확장하지 않는다.
9. ‘프레임워크에서 컴파일 시스템으로 전달’은 이 장면에서 설명하는 컴파일 경로다. 모든 신경망 실행이 반드시 그래프 컴파일을 거친다는 인상을 주지 않도록 화면에 ‘컴파일 경로 예시’를 표시한다. 일반 컴파일러와 AI 컴파일러의 분석 수준이 서로 배타적이라는 뜻도 아니다.

## 사용자 수정 대본 반영

- 저수준 표현은 개별 연산·데이터 이동을 드러내지만 원래 수학적 구조를 알아보기 어려워질 수 있다는 표현을 유지한다.
- 행렬곱 구조의 발견에서 여러 층의 텐서 연산 관계를 분석하는 역할로 확장한다.
- 후반부는 신경망 프로그램 → 컴파일 시스템 → 하드웨어 실행 코드의 흐름으로 정리한다.
- narration.md는 원래 영문 표기, tts_script.txt는 사용자 발음 표기를 사용한다. 도입 설명과 수정 의도에 관한 사용자 메모는 발화에 포함하지 않는다.
- 최종 23개 발화 문단의 표기 변환을 반영했다. 사용자 종료 시각은 6,13,19,26,32,38,45,52,60,68,74,79,86,94,98,101,106,113,120,131,143,151,161초다. 문장 종료 시각이나 영상 길이는 추정하지 않았다.

## 최종 제작 기준

- 1080×1920·30fps 최종본, 360×640·30fps 미리보기, 기본 무음. TTS 음원 합성·mux는 하지 않는다.
- 각 발화 시작은 직전 종료 시각이며 Scene.time 누적 gate로 다음 종료 시각까지 진행한다. 초과 시 오류를 발생시킨다.
- 영상 내 짧은 핵심 자막과 전체 발화 SRT를 구분한다. SRT는 긴 발화만 2줄 단위로 나눠 해당 발화 구간 안에 배분하며 사용자가 제공한 구간의 최종 종료 시각은 유지한다. 세부 자막 내부 경계는 실제 음원 정렬 결과가 아니다.
- 제목·도형·하단 핵심 자막을 별도 세로 영역에 둔다. 명령→MatMul 뒤집기는 표현 수준의 비교라는 화면 주석을 둔다.
- 블록 분할과 fusion은 후보, 여러 하드웨어 분기는 대상별 실행 프로그램, 후반 전체 흐름은 컴파일 경로 예시로 표시한다.

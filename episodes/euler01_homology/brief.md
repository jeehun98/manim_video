# 왜 꼭짓점에서 모서리를 빼고, 면을 더할까?

사용자 제공 39문장·문장 종료 시각 173초를 확정 대본으로 사용한다. 9:16 쇼츠, 1080×1920·30fps. 해당 대본의 TTS 음원이 없어 영상은 무음이며, 모든 문장은 화면 자막과 `captions.srt`에 담는다. 기존 `exports/euler_1.mp4`는 다른 영상이므로 재사용하지 않는다.

학습 목표는 점과 선과 면을 차례로 추가하며 `V−E+F`의 교대 부호를 연결 성분·독립적인 고리·닫힌 2차원 순환으로 해석하는 것이다. 정육면체와 정사면체의 **경계 표면**에서는 `V−E+F=2`이고, 세 점으로 만든 채운 삼각형의 지표는 1이다. 닫힌 연결 가능 2차원 표면에서 손잡이 수가 `g`일 때 `χ=2−2g`; 일반적인 2차원 셀 복합체에서는 `χ=β₀−β₁+β₂`이다. 도넛 표면에는 독립적인 1차원 고리가 두 개 있다.

시각 규칙: 남색 배경, 꼭짓점 주황, 모서리 청록, 면 파랑, 독립적인 고리 보라. 화면 상단은 주장과 수식, 중앙은 도형 변화, 하단은 문장별 자막이다. 점 → 선 → 닫힌 고리 → 채운 면의 순서를 유지하며, 구 표면의 연속 변형과 손잡이를 뚫는 위상 변화는 구분한다. 이전 편 요약·다음 편 예고·엔드카드는 넣지 않는다.

# 제작 기준
- 확정 대본 35문장, 사용자 제공 종료 시각 그대로 156초. 9:16, 1080×1920, 30fps, 음원 미제공으로 무음.
- f(x)=x³−x−1, x₀=1.5. 접선 이동과 곡선으로의 수직 복귀를 분리한다.
- 접점 중심 확대와 동일한 x/y 축척. 수식·수치·기하를 실제 계산값으로 연결한다.
- 이차 수렴은 충분히 매끄러운 함수의 단순근 근처에서만 설명한다.
- 실패 예: x³−2x+2, 0→1→0 순환.
- 다변수: 원과 직선의 영점 조건을 선형화한다. 원 밖의 현재점에서 얻은 직선은 원 자체의 접선이 아니다. 양의 해 (1,1)로 수렴하는 예시이며 유일해를 주장하지 않는다.
- 최적화: h=x⁴/4+x²/2. 양의 곡률을 갖는 이차 근사의 최소점을 이용한다. h=0이 아닌 h′=0을 푼다.
- 청록: 원래 함수, 주황: 국소 근사, 노랑: 새 추정값, 보라: 실제 해. 수식과 설명에도 같은 색 적용.
- 기존 L’Hopital 화면 UI와 독립 씬 빌드를 재사용. 이전 편 복습·다음 편 예고·엔드카드 없음.

- 배치 수정: 그래프는 상단, 수식과 보조 설명은 그래프와 하단 나레이션 사이에 배치한다. 오차 표가 있는 장면은 표 아래에 수식을 둔다.

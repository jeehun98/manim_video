# 선형대수학 08 — Rank: 실제로 남는 자유도

107초 · 1080×1920 · 30fps · 무음.

## 핵심

행렬의 행·열·원소 수와 출력 공간의 독립적인 자유도 수는 구별된다. Rank는 상(image)의 차원이며 행/열 중 선형독립인 것의 최대 개수와 같다.

## 사례

A=[[1,2],[2,4]]: 행 2=2×행 1, 열 2=2×열 1, Rank(A)=1.

- y₁=x₁+2x₂, y₂=2x₁+4x₂=2y₁.
- 가능한 모든 출력은 {(t,2t):t∈R}.
- 입력 (1,0),(0,1),(2,-1),(-1,0)은 각각 (1,2),(2,4),(0,0),(-1,-2)로 간다.
- 표본 몇 개만으로 일반성을 주장하지 않고 먼저 모든 입력에 대한 출력 관계를 유도한다.

B=[[1,1],[1,-1]]: 독립인 두 행/열, Rank(B)=2.

- y₁=x₁+x₂, y₂=x₁-x₂.
- 임의의 y에 대해 x₁=(y₁+y₂)/2, x₂=(y₁-y₂)/2이므로 출력은 R² 전체.
- B(1/2,1/2)=(1,0), B(1/2,-1/2)=(0,1).

큰 행렬 C=[[1,2,3],[2,4,6],[3,6,9]]도 Rank=1이다. 모든 행이 첫 행의 배수이며 0이 아닌 행이 있다.

## 정확성

‘보존하는 자유도’는 계량적인 길이나 각도의 보존을 뜻하지 않는다. 선형변환 뒤 출력에 남는 독립적인 방향 수, 즉 상의 차원이라는 의미다. 일반적인 정보량(비트 수)을 세는 설명은 아니다. 2차원 예제의 직선은 Rank 1, 평면은 Rank 2이다. 모든 출력을 원점 하나로 보내는 영행렬의 Rank는 0이며, 더 높은 차원에서는 더 큰 Rank도 가능하다.

출력 공간의 생성 벡터는 열들이며, 행들은 입력을 읽는 선형 관계다. 두 관점을 혼동하지 않도록 ‘독립인 행의 최대 개수 = 독립인 열의 최대 개수 = 출력 공간의 차원’을 연결한다. 행 Rank와 열 Rank의 일반적인 동일성 증명은 이번 범위 밖이다.

## 화면

2×2 크기 → 행의 배수 관계 → 출력 수식 → 여러 입력에서 생기는 출력 점 → 직선 전체 → Rank 1 → 합/차의 독립적인 행렬 → 평면 출력 → 두 사례 비교 → 행/열 관점 연결 → 평면 일부가 직선으로 붕괴 → 3×3 Rank 1 사례.

격자의 변환은 입력 평면 일부를 시각화한 것이다. 유한한 점 구름이나 패치가 가능한 출력의 전부라는 뜻은 아니다. 비교 카드의 직선·다이아몬드는 출력 공간 차원의 도식이다.

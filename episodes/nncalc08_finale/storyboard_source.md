영상 제목: 신경망의 알고리즘을 발견하는 것에서 형성을 유도하는 것까지 — Interpretability & Patterning

이번 마지막 편의 역할은 앞선 연구들을 순서대로 요약하는 데 있지 않아. 같은 정답을 만드는 모델이 서로 다른 계산을 학습할 수 있다는 문제에서 출발해, 내부 알고리즘을 발견·검증하고, 나아가 그 형성에 영향을 주려는 연구까지 연결하는 것이 목표야.

따라서 앞선 영상의 수식과 실험을 모두 다시 설명하기보다, 각 영상의 대표적인 시각화 하나씩을 재사용하고 이들을 연결하는 새로운 애니메이션을 만드는 방향으로 구성할게.

애니메이션

### 장면 04 · 알고리즘 B: 모든 접두 구간 검사

0:12–0:20

발화: “하지만 올바른 괄호 문자열을 판별하려면, 전체 개수가 같은 것뿐 아니라 모든 중간 구간에서 닫는 괄호가 더 많아지지 않아야 합니다.”

이번 장면에서는 1편의 접두 합 그래프를 재사용해.

Algorithm B — Prefix Balance

애니메이션

1. 괄호를 왼쪽에서 오른쪽으로 읽는다.
2. `(`를 만나면 누적 높이가 1 증가한다.
3. `)`를 만나면 누적 높이가 1 감소한다.
4. 누적 높이가 0 아래로 떨어지지 않아야 한다는 수평 기준선을 강조한다.
5. 마지막 높이가 0이어야 한다는 조건도 표시한다.

정확한 판정 조건은 두 가지야.

\\[ \sum\_{i=1}^{n}x_i=0,\qquad \min\_{1\le k\le n}\sum\_{i=1}^{k}x_i\ge0 \\]

영상에서는 이 식을 모두 길게 보여주기보다, 총합 0과 기준선 아래로 내려가지 않는 조건을 그림으로 설명하는 것이 좋아.

### 장면 15 · SAE로 특징 후보를 발견한다

1:10–1:18

발화: “여러 특징이 같은 표현 공간에 겹쳐 나타날 수 있었고, 희소 오토인코더는 그 활성화에서 해석 가능한 특징 후보들을 찾아내는 방법을 제공했습니다.”

5편의 SAE 구조를 재사용한다.

Sparse Autoencoder

\\(h\in\mathbb R^2\\)

혼합된 활성화

\\(z\in\mathbb R^5\\)

희소 특징

\\(\hat h\in\mathbb R^2\\)

복원

애니메이션

1. 2차원 혼합 활성화 벡터가 입력된다.
2. Encoder를 통과하면서 5개의 잠재 특징 노드가 등장한다.
3. 일부 노드만 활성화되고 나머지는 어두워진다.
4. Decoder가 활성화된 특징들을 조합해 원래 벡터를 근사한다.
5. 특징 노드에 `Candidate Features`라는 라벨을 붙인다.

중요: 이 장면에서는 다섯 특징을 완벽하게 복원했다고 표현하지 않는다. SAE가 찾아낸 것은 해석 가능한 특징의 후보야.

### 장면 16 · 특징들을 연결해 계산 경로를 추적한다

1:18–1:24

발화: “그렇게 발견한 특징들 사이의 기여 관계를 추적하면, 특정 출력에 이르는 계산 경로에 관한 가설을 만들 수 있습니다.”

6편의 Attribution Graph를 재사용한다.

- 앞 장면에서 등장한 F1\~F5 노드들을 유지한다.
- 각 노드를 서로 다른 Transformer 층에 배치한다.
- 노드 사이에 방향성 기여 화살표를 생성한다.
- 오른쪽에 목표 출력 노드를 표시한다.
- 일부 경로만 보라색으로 강조한다.

화면 문구: `Features → Attribution Graph → Output`

### 장면 18 · 개입으로 역할을 시험한다

## 5막 — 데이터 분포로 내부 구조의 형성에 영향을 준다

1:57–2:32 · 장면 24\~28

학습 데이터의 작은 변화와 내부 관측량의 변화 사이의 관계를 측정하고, 이를 역으로 이용해 원하는 변화가 일어나도록 유도한다는 Patterning의 핵심을 보여줘야 해.

### 장면 24 · 학습 데이터 변화와 내부 관측량

1:57–2:06

발화: “학습 데이터의 비중을 조금 바꿨을 때 내부 관측량이 어떻게 변하는지 측정하고, 원하는 변화를 유도하는 방향으로 데이터의 비중을 조절하는 겁니다.”

Patterning의 국소 반응 관계

\\[ \Delta\mu\approx\chi\\,\Delta h \\]

데이터 분포의 작은 변화와 내부 관측량의 국소적인 반응을 나타내는 개념식

애니메이션 순서

1. 왼쪽에 서로 다른 데이터 유형을 의미하는 막대들을 나타낸다.
2. 특정 데이터의 가중치를 조금 높이고 다른 가중치를 조정한다.
3. 모델 학습을 의미하는 중간 블록을 통과한다.
4. 오른쪽의 내부 관측량 \\(\mu\\)가 변화한다.
5. 데이터 가중치의 변화와 관측량의 변화를 연결하는 화살표를 보여준다.
6. \\(\Delta\mu\approx\chi\Delta h\\)를 표시한다.
7. 목표로 하는 \\(\Delta\mu\\)를 먼저 선택한 뒤 데이터 조정 방향을 찾아가는 역방향 애니메이션을 추가한다.

과학적 정확성: 이는 작은 변화에 대한 국소 근사야. 모든 크기의 데이터 변화에서 동일한 선형 관계가 정확히 성립하는 것으로 그리면 안 돼. 또한 실제 연구는 확률적 학습 설정의 사후 기대 관측량과 감수율을 사용하므로, 그림의 막대들은 개념적 단순화라는 점을 유지해야 해.&#x20;

## 5. 최종 제작에서 특별히 중요한 장면

장면 09 — `())(` 반례

처음에 등장한 괄호 알고리즘 두 개가 왜 서로 다른지 시각적으로 보여주는 장면이야. 총개수는 같지만 접두 합이 음수가 되는 순간을 명확하게 드러내야 해.

장면 13\~18 — 앞선 연구들의 연결

짧은 요약 구간이지만, 단순한 연구 목록으로 보이지 않아야 해. 회로의 발견 → 특징의 분해 → 기여 관계 추적 → 개입 검증으로 자연스럽게 발전하는 과정을 한 공간에서 표현하는 것이 좋아.

장면 21\~24 — Interpretability에서 Patterning으로

이번 편의 핵심이야. `데이터 → 학습된 내부 구조`를 관찰하는 문제에서 `목표 내부 구조 → 데이터 조절`을 탐구하는 문제로 관점이 바뀌어야 해.

장면 26\~28 — 결과와 한계의 구분

Patterning이 특정 조건에서 알고리즘 선택에 영향을 줄 수 있었다는 것과, 모든 신경망에서 임의의 알고리즘을 자유롭게 설계할 수 있다는 주장은 다르다는 점을 분명히 해야 해.

장면 33 — 전체 시리즈의 마지막 프레임

결론은 정답이 아니라 검증할 수 있는 내부 계산에 대한 설명에 있어야 해.

이렇게 구성하면 여덟 편의 영상을 별도 전환 없이 연결했을 때도, 첫 편의 “같은 정답을 만드는 모델은 같은 알고리즘을 학습했을까?”라는 질문이 마지막 편의 “학습한 알고리즘을 어떻게 발견하고, 설명하고, 검증할 수 있을까?”라는 결론으로 이어지게 돼.

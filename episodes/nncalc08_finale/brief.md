# 마지막 편 · Interpretability & Patterning

사용자 확정 33개 발화·176초(2:56)·30fps. 일반 1920×1080와 쇼츠 1080×1920를 별도 배치.
음원 미제공으로 자막 포함 무음. 사용자가 요청한 마지막 편의 복습과 종합 구성을 유지한다. 별도 예고는 추가하지 않는다.

## 여섯 제작 단위

0–29초: 같은 정답이 같은 알고리즘을 보장하지 않는 괄호 문제.
29–59초: 반례 ())(: 개수 2=2이지만 접두 깊이 0,1,0,−1,0. 시험 통과만으로 내부 계산을 특정하지 않는다.
59–97초: 두 헤드의 계산 → 중첩 표현 → SAE 후보 → 기여도 그래프 → 판독과 개입.
97–117초: 학습된 계산을 읽는 질문에서 목표 계산에 맞는 데이터를 찾는 질문으로 전환.
117–152초: 데이터 재가중·새 학습·관측량 변화와 작은 모델의 두 실험, 적용 한계.
152–176초: 관찰·설명·시험이라는 검증 가능한 내부 계산 이해로 마무리.

## 정확성과 재사용

- 1편 BracketSequence, 2편 두 헤드 도식, 3편 데이터 재가중·형성 곡선, 4편 FeaturePlane, 5편 SAE, 6편 AttributionGraphView, 7편 판독·개입을 재사용한다.
- A(주황)는 전체 개수만 비교한다. B(청록)는 최종 합 0과 모든 접두 합 ≥0을 모두 요구한다.
- 반례 하나에서 올바른 답을 냈다고 접두 합 알고리즘을 구현했다고 단정하지 않는다. 두 수학적 규칙은 설명용 모델이지 실제 추출한 회로가 아니다.
- SAE 특징 후보와 CLT 기반 기여도 그래프의 특징을 같은 학습 사전이라고 연결하지 않는다. 공통 분석 원리를 연결하는 별도 방법임을 표시한다.
- Superposition은 다섯 독립 연속값의 무손실 저장을 보장하지 않는다. SAE도 완전한 정답 특징 복원을 보장하지 않는다.
- 판독과 개입, 행동 변화와 완전한 인과적 설명을 구분한다. 그래프는 검증할 가설이다.
- Patterning은 Δμ≈χΔh라는 작은 변화의 국소 반응을 역으로 활용한다. μ는 사후 기대 관측량이며 그림의 변화는 정성적 단순화다. 보통의 역행렬이나 임의 목표 도달을 보장하지 않는다.
- 데이터 비중 변경 뒤에는 새 학습을 거친다. 기존 모델의 회로를 즉시 편집하는 장면을 만들지 않는다.
- 형성 곡선과 알고리즘 선택 도식은 실측 그래프·비율이 아니다. 작은 언어 모델의 회로 형성 시점 실험과 합성 괄호 문제의 알고리즘 선택 실험을 구분한다.
- 마지막 프레임에도 미확인 경로와 물음표를 남긴다. 모든 계산이 완전히 밝혀진 것으로 표현하지 않는다.

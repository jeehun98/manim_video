# 정보이론 03 — 제작 기준

- 콘티 17개 장면을 13개 발화 구간으로 압축. 제목은 “확률은 곱해지는데, 정보는 왜 더해질까?”. 핵심 관점은 “로그는 곱셈의 깊이를 세는 좌표계”이다.
- 핵심 6–7구간에서는 동일한 화면을 유지한다. 확률 막대를 정확히 절반씩 줄이는 동안 반감 횟수 0,1,2,3과 오른쪽 단위 블록이 한 칸씩 늘어난다. 로그 공식보다 이 변환의 동시성을 먼저 보여준다.
- 길이 59.47초. TTS 비공백 글자 / 초당 7자, 문장 휴지 0.18초, 마지막 0.5초. 30fps 프레임 단위 경계. 등장·장면 전환은 발화 구간 안에 포함. 실제 음성 없음: 추정 타이밍.
- 동전 1과 동전 2는 독립이며 공정. 특정 순서쌍 (H₁,T₂)의 확률은 1/4. 순서와 무관한 “앞면 하나·뒷면 하나” 사건(확률 1/2)과 구별한다.
- 독립일 때 p(x,y)=p(x)p(y), 따라서 자기정보량 I(x,y)=I(x)+I(y). 정보 덧셈은 자연 현상에 대한 무조건적 주장보다 측정량에 요구하는 가법성으로 제시한다. 종속 사건에서는 조건부 확률과 조건부 정보량이 필요하며 이 편에서 범위 확장하지 않는다.
- f(pq)=f(p)+f(q)와 연속성 또는 단조성 등의 정칙 조건 아래 로그 형태가 도출된다. 단조 감소와 비자명성을 요구하면 f(p)=−k log p, k>0. f(1/2)=1로 단위를 정하면 −log₂ p. 가법성만으로 유일성이 성립한다고 주장하지 않는다.
- 정의의 적용 범위 0<p≤1. p=1이면 0 bit, p→0⁺이면 발산. 확률 0인 사건을 유한 정보량으로 보여주지 않는다.
- “곱셈 깊이”는 고정된 반감 비율에 대한 좌표다. p=2^(−n)에서는 반감 n회와 일치한다. 임의의 p에서는 실수 좌표로 연장할 수 있지만 실제 사건 개수나 모든 곱셈 인수의 개수를 뜻하지 않는다.
- 0,1,2,3 양의 값은 반감 횟수 또는 −log₂ p다. log₂ p 자체는 0,−1,−2,−3임을 별도 장면에서 보이고 부호를 뒤집는다. unsigned log 번역기 출력은 정보량 대신 log₂p₁+log₂p₂를 표시한다.
- bit의 밑은 2임을 화면과 나레이션에 명시. 다음 편 예고는 관측 전 예상 정보량의 평균, 즉 엔트로피. 모든 분포가 항상 같은 정보량을 주는 것으로 설명하지 않는다.
- 1080×1920 30fps 무음. TTS 원고와 SRT 별도. 공통 Malgun Gothic, 중앙 시각화와 하단 문구 구분.

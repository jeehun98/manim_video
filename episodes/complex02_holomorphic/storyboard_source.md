### **세부 구현**

복소좌표가 만들어지는 과정을 벡터의 합으로 표현합니다.

\\[ \underbrace{2}\_{\text{실수부}} +\underbrace{i}\_{\text{허수부}} \\]

실수축 방향의 파란색 화살표가 먼저 생성되고, 그 끝점에서 위쪽으로 노란색 화살표를 생성합니다. 마지막에는 원점에서 \\(2+i\\)까지의 벡터를 연결합니다.

- 실수축: \\(x\in[-3,3]\\)
- 허수축: \\(y\in[-3,3]\\)
- 두 축의 단위 길이는 반드시 동일하게 설정
- `NumberLine`에서 `ComplexPlane`으로 전환하되 원점과 기존 실수축의 위치는 유지

**연출 핵심:** 새로운 좌표계로 화면을 전환하는 것이 아니라, 기존 실수축에 새로운 축이 추가되어 공간이 확장되는 느낌을 전달합니다.

### **63–69초: 켤레복소수 함수 등장**

앞서 사용했던 제곱함수를 켤레복소수 함수로 전환합니다.

\\[ f(z)=z^2 \quad\longrightarrow\quad f(z)=\overline z \\]

복소수의 실수부는 파란색, 허수부는 노란색으로 구분합니다.

\\[ z=x+iy \\]

\\[ \overline z=x-iy \\]

`TransformMatchingTex`를 활용하여 허수부 앞의 부호만 변화시키고, 동시에 좌표평면 위의 점이 실수축을 기준으로 반사되도록 합니다.

### **69–74초: 복소평면의 반전**

복소평면에 격자와 비대칭적인 도형을 배치합니다. 단순한 격자만 반전하면 시각적으로 변화가 잘 드러나지 않으므로, 색상이 지정된 점과 도형을 함께 반사시키는 것이 좋습니다.

기준점은 이전과 동일하게 설정합니다.

\\[ z_0=1+i,\qquad f(z_0)=1-i \\]

### **74–81초: 접근 방향별 차분비 계산**

실수 방향

\\[ h=t \\]

\\[ \Delta w=t \\]

# **+1**

허수 방향

\\[ h=it \\]

\\[ \Delta w=-it \\]

# **−1**

\\[ \lim\_{t\to0}\frac{t}{t}\neq\lim\_{t\to0}\frac{-it}{it} \\]

이 7초 동안 두 가지 접근을 병렬로 보여줍니다.

- 74–77.5초: 실수 방향에서 접근하며 입력 화살표와 출력 화살표의 방향이 유지됨. 차분비 \\(+1\\) 등장.
- 77.5–81초: 허수 방향에서 접근하며 출력 화살표만 반전됨. 차분비 \\(-1\\) 등장.

### **81–87초: 미분 불가능**

앞서 제곱함수에서는 모든 차분비가 한 점으로 모였습니다. 반면 켤레복소수 함수에서는 서로 다른 값이 유지됩니다.

\\[ \frac{\overline h}{h}=e^{-2i\theta} \\]

Not Complex Differentiable

여기서 추가적인 시각적 연출이 가능합니다.

입력 변화량을 다음과 같이 설정하면,

\\[ h=re^{i\theta} \\]

차분비는 다음과 같습니다.

\\[ \frac{\overline h}{h} =\frac{re^{-i\theta}}{re^{i\theta}} =e^{-2i\theta} \\]

입력 변화량의 크기 \\(r\\)을 아무리 줄여도 방향 \\(\theta\\)에 따른 차이는 사라지지 않습니다.

Manim에서 입력점들은 원점으로 모이지만, 차분비를 나타내는 출력점들은 단위원 위에 그대로 남아 있는 모습을 표현하면 복소미분이 불가능한 이유를 매우 직관적으로 보여줄 수 있습니다.

### **87–90초: 복소함수를 두 성분으로 분리**

화면 중앙에 있던 복소함수 \\(f(z)\\)를 두 개의 실수값 함수로 분리합니다.

\\[ f(x+iy) = \underbrace{u(x,y)}\_{\text{실수부}} +i\underbrace{v(x,y)}\_{\text{허수부}} \\]

하나의 복소함수를 구성하는 두 개의 실수값 함수. 성분별 변화 구조를 분리해 보여줍니다.

### **90–96초: 두 방향에서의 미분값 비교**

실수축 방향과 허수축 방향에서 계산하는 차분비를 나란히 배치합니다.

실수축 방향:

\\[ \lim\_{t\to0}\frac{f(z+t)-f(z)}t =u_x+iv_x \\]

허수축 방향:

\\[ \lim\_{t\to0}\frac{f(z+it)-f(z)}{it} =v_y-iu_y \\]

복소미분이 가능하려면 두 식은 동일해야 합니다.

\\[ \color{#60a5fa}{u_x} +i\color{#fbbf24}{v_x} = \color{#60a5fa}{v_y} -i\color{#fbbf24}{u_y} \\]

실수부와 허수부를 각각 같은 색으로 강조하면서 식을 분리합니다.

### **96–99초: 코시-리만 방정식**

## **Cauchy–Riemann Equations**

\\[ \color{#60a5fa}{\frac{\partial u}{\partial x}}=\color{#60a5fa}{\frac{\partial v}{\partial y}} \\]

\\[ \color{#fbbf24}{\frac{\partial u}{\partial y}}=-\color{#fbbf24}{\frac{\partial v}{\partial x}} \\]

코시-리만 방정식

`TransformMatchingTex`를 사용하여 이전 등식에서 실수부끼리, 허수부끼리 서로 이동하면서 두 개의 방정식이 만들어지도록 합니다.

수학적으로는 코시-리만 방정식을 만족하는 함수의 미분 행렬이 다음과 같은 형태를 갖기 때문입니다.

\\[ J_f= \begin{pmatrix} u_x&u_y\\\ v_x&v_y \end{pmatrix} = \begin{pmatrix} a&-b\\\ b&a \end{pmatrix} \\]

이는 복소수 \\(a+ib\\)를 곱하는 것과 동일한 선형변환입니다.

행렬 수식은 영상에 반드시 포함하지 않아도 됩니다. 이후 등각사상 영상에서 재활용할 수 있는 애니메이션 객체로 준비해 두면 좋겠습니다.

\\[ f(z)=\frac{1}{2\pi i}\oint_C\frac{f(\zeta)}{\color{#60a5fa}{(\zeta-z)}}\\,d\zeta \\]

Manim에서는 모든 수식을 새로 작성하기보다 하나의 수식에서 변화하는 부분만 애니메이션으로 수정합니다.

### **좌표계 구현 시 주의사항**

Manim에서는 복소평면 객체를 실제 수학적 좌표에 기반해 변환하는 것이 중요합니다.

```
plane = ComplexPlane(    x_range=[-3, 3, 1],    y_range=[-3, 3, 1],    x_length=6,    y_length=6,)
```

좌표계에 속하는 점의 이동은 화면상의 임의의 좌표가 아니라 다음과 같이 처리합니다.

```
z = 1 + 1jinput_point = input_plane.n2p(z)output_point = output_plane.n2p(z**2)
```

접근 방향과 거리도 각각 독립적인 변수로 관리합니다.

```
radius = ValueTracker(1.0)theta = ValueTracker(0.0)def get_h():    return radius.get_value() * np.exp(        1j * theta.get_value()    )def difference_quotient(f, z):    h = get_h()    return (f(z + h) - f(z)) / h
```

이 구조를 사용하면 입력의 변화량과 출력의 변화량, 복소 차분비를 각각 다른 좌표평면에서 동시에 추적할 수 있습니다. 실제 실행 시에는 \\(h=0\\)이 되는 순간의 0으로 나누는 연산을 방지해야 합니다.

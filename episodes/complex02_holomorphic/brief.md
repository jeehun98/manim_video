# 복소해석학 — 170초 쇼츠
- 사용자 제공 대본과 29개 문장 종료 시각을 그대로 사용. 15개 독립 교체 씬.
- 1080×1920, 30fps, 5100프레임. TTS 미제공: 무음. 자막 중심 y=-6.15, 본문 하단 -4.9 이상.
- 복소좌표 양 축 단위 동일. 켤레함수 차분비 exp(-2iθ)는 반지름과 무관.
- CR은 필요조건이며 실수 전미분가능 가정하에 충분. 미분값 0 허용.
- 코시 공식은 원과 내부를 포함한 열린 영역에서 정칙일 때 적용. f=1/(1-z), 경로 반지름 .7, 특이점 1은 외부.
- 테일러 비교는 실제 복소 출력과 부분합을 계산하며 |z|<1 내부에서만 표시.
- 수학 참조: https://www.math.uci.edu/~ndonalds/math147/notes.pdf

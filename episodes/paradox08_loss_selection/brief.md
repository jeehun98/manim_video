# 신경망의 역설 08 — 무엇을 배우지 않을지 고르는 신경망

## 제작 기준

사용자가 제공한 17개 발화 종료 시각을 유지하는 98초 세로 영상. 음원 미제공으로 무음 제작하며 SRT와 발음용 TTS 원고를 별도 제공한다. 복습·다음 편 예고는 넣지 않는다.

주장: 현재 모델의 손실을 기준으로 학습 신호를 선택하면, 학습 분포가 달라지고 제한된 모델 용량에서 사실 정확도를 개선할 수 있다. 데이터베이스는 조건에 따라 레코드를 필터링하는 과정의 비유로만 사용한다.

## 원문 확인과 수학적 조건

Ye, Feldman, Talwar (2026), Cram Less to Fit More: Training Data Pruning Improves Memorization of Facts.
https://arxiv.org/html/2604.08519

- Algorithm 1: 현재 배치의 사실별 토큰 교차엔트로피 **합**으로 손실을 계산한다. 임계값 τ는 선택 비율 α에 대응하는 온라인 백분위수다.
- LossH: ℓ≤τ이면 선택, 그 위는 제외. LossHF: ℓ≤τ에서 선택 확률 ℓ/τ, 그 위는 0. 낮은 손실 영역은 연속적인 확률로 선택하며 임계값에서 불연속이다. 고정된 3개 구간 분류로 묘사하지 않는다.
- 손실은 빈도와 정보 난도의 대리 지표다. 높은 손실=희귀 사실, 낮은 손실=빈번한 사실이라는 등식을 주장하지 않는다.
- 높은 손실 제외는 용량에 맞는 사실 범위를 제한한다. 낮은 손실 반복 축소는 빈도 편중을 완화하며 추가 효과는 분포와 용량 조건에 따라 다르다.
- 해당 선택은 학습 도중 현재 모델로 수행한다. 모델이 자율적으로 의미를 판단하거나 원본 데이터를 영구 삭제하는 것으로 묘사하지 않는다.

## 결과 화면의 필수 구분

사용자 내레이션의 약 1.3배 결과는 §4.2의 **LossH-Wiki** 결과다. LossHF의 성능 수치로 표시하지 않는다. 주석된 Wikipedia 약 3B 토큰, 110M 파라미터 GPT2-Small 변형을 처음부터 학습한 실험이며 전체 데이터 학습 대비 개체 사실 성능 개선이다. 테스트 문맥에서 정답 문자열 생성 확률로 평가한 사실 정확도/기대 정답 사실 수에 해당한다. 확정적인 정답 개수를 직접 세었다고 단정하지 않는다.

Algorithm 2는 사실 답변 토큰을 선택하고, 선택한 사실 토큰 비중을 재조정하며 비사실 토큰은 유지한다. 문서를 통째로 삭제하거나 모든 언어 학습을 중간 손실에만 제한하는 방식이 아니다. 영상 결과 화면에 LossH-Wiki와 평가 조건을 명시한다.

정규화 막대 1.0과 약 1.3은 논문 초록의 상대 결과를 시각화한 것이며 재현 실험이나 새 측정치가 아니다. 레코드 A–D와 손실 숫자는 설명용이다. 기억 용량 상자는 개념도이며 사실별 고정 저장 슬롯을 뜻하지 않는다.

## 장면 순서

0–11초: 데이터→현재 모델 손실→선택→갱신.
11–28초: 손실의 양쪽 극단, 가능한 해석과 대리 지표 조건.
28–41초: 정확한 LossHF 선택 확률 그래프, 제외와 반복 축소 역할 비교.
41–48초: 설명용 레코드 조건 필터.
48–62초: 유한한 용량과 손실 최소화/사실 정확도 지표 차이.
62–76초: 학습 대상 범위와 반복 비중이라는 두 조절 축.
76–83초: LossH-Wiki의 약 1.3배 결과와 조건.
83–98초: 손실→선택→학습 분포 변화라는 결말.

## 시각 콘티 수정 (2026-10-20)

대본과 17개 타이밍을 유지하고 FactCard(fact_id, loss, frequency, selection_probability)를 공통 시각 요소로 도입했다. A/B/C/D의 색과 ID는 장면마다 동일한 사실을 뜻한다. 낮은 손실 카드 일부와 임계값 이하 후보는 확률적 필터를 통과하며 높은 손실 카드는 제외된다. 반복 A 카드 10장이 하나의 A로 합쳐지는 장면으로 반복 횟수와 서로 다른 사실 수를 구분한다. 카드 개수와 체크 수는 설명용이며 논문 결과 수치가 아니다. 실제 결과 장면은 기존 LossH-Wiki 비교를 유지한다. 기존 텍스트 중심 구현은 scene_text_version.py에 보존했다.

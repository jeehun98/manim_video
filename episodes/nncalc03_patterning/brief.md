# 신경망 내부의 계산 03 — 학습 데이터로 신경망 내부 회로의 형성을 조절하는 방법

## 확정 자료와 제작 규격

사용자 첨부 콘티와 확정 낭독 29구간의 종료 시각을 사용한다. 마지막은 **171초(2:51)**이며 콘티의 약 3분 배분보다 발화 시각을 우선한다. 일반용 1920×1080·16:9, 쇼츠용 1080×1920·9:16, 모두 30fps. 같은 발화를 사용하고 레이아웃·자막 줄바꿈을 각각 구성한다. 음원 파일은 제공되지 않아 기본 무음이며 파형 동기화 검증을 주장하지 않는다.

사용자가 직접 확정한 첫 문장의 이전 편 언급은 그대로 유지한다. 임의 복습 문장이나 후속 편 예고는 추가하지 않는다. TTS는 주요 화면별 15문단이며 빈 줄 하나로 구분하고 시각·제목·번호를 넣지 않는다.

## 실제 장면 시각

01 0–10 회로와 형성 시점 → 02 10–21 같은 모델·다른 데이터 비중 → 03 21–29 억제·기본·강조 → 04 29–48 실제 연구 결과 → 05 48–57 데이터 가중치와 모델 가중치 구별 → 06 57–66 데이터 방향별 영향 → 07 66–76 같은 작은 변화·다른 반응 → 08 76–93 감수율·벡터·국소 선형 관계 → 09 93–106 정방향과 방향 반전 → 10 106–114 목표 관측량 변화 → 11 114–130 데이터 조합 추정과 한계 → 12 130–138 재학습 검증 → 13 138–146 별도의 괄호 실험 → 14 146–158 Interpretability와 Patterning → 15 158–171 제한된 조건의 가능성과 결론.

장면 08–11에서는 같은 벡터·행렬 객체를 유지하고, 순서대로 Δh·Δμ, 행렬 χ·관계식을 드러낸 후 방향을 반전한다. 목표는 노란색 점선 테두리로 표시해 실현된 상태와 구별한다. 후보 데이터 조합과 국소 근사의 한계를 본문에서 크게 표시한다.

## 과학·수학 조건

- 데이터 가중치는 토큰/샘플의 학습 손실 기여 비중이며 모델 파라미터 자체가 아니다. 데이터 개입 후 새로 학습하며 모델 파라미터는 그 과정에서 갱신된다. 이미 학습된 Head를 직접 편집하거나 구조를 즉시 바꾸는 장면으로 표현하지 않는다.
- μ는 내부 관측량의 사후기댓값을 나타내는 구조 좌표다. 단일 실행의 회로 세기와 정확히 같은 값으로 취급하지 않는다. 화면에서는 '구조 관측량 변화'로 줄여 쓰되 수학 장면의 주석에 사후기댓값을 명시한다.
- Δμ ≈ χ Δh는 작은 데이터 분포 변화에 대한 국소 선형 근사다. 정규화·양수성 등 유효한 데이터 가중치/분포 제약이 있으며, 모든 데이터 방향을 임의로 사용할 수 있다는 주장을 하지 않는다.
- χ는 구조 관측량(행) × 데이터 방향(열)의 행렬이다. 예시 행렬은 **2×3**, 항목은 χᵢⱼ 기호이며 실측 숫자를 만들지 않는다. 표준 가역행렬을 가정하거나 χ⁻¹을 표시하지 않는다.
- 역문제는 χ Δh ≈ Δμ_target을 만족시키는 가능한 데이터 변화의 근사 조합을 찾는 것으로 표현한다. 논문의 의사역행렬 해는 배경 근거이며 본편에서 계산 공식으로 확대하지 않는다. 치역 밖 목표의 도달 불가성, 약한 방향·추정 오차, 큰 변화에서의 근사 실패를 숨기지 않는다. 단순 부호 반전이 역행렬 계산인 것처럼 표현하지 않는다.
- 같은 +Δh에 작은 +Δμ와 큰 −Δμ를 보이는 그림은 부호와 크기가 다를 수 있음을 설명하는 가상 예시다. 데이터 비중 증가가 언제나 회로 강도 증가를 뜻하지 않는다.
- 모델·데이터·곡선·반응은 개념도다. Prefix Matching Score 곡선은 연구의 정성적 경향을 설명하며, 실제 학습 시점·점수나 표준오차를 재현하지 않는다. 축에 가상 실측 수치를 붙이지 않는다. 조건의 0×·1×·2×·4×는 논문에 나온 실제 재가중 배수이며 곡선의 도식 값과 구별한다.
- 억제·기본·강조는 비교 범주다. 같은 구조·목표로 새로 학습한 조건을 뜻하며, 모든 seed에서 동일한 결과가 보장된다고 말하지 않는다. 강조 조건에 2×·4×를 함께 대응시키되 본편에 3개 조건만 있었다고 단정하지 않는다.
- 괄호 분류는 Induction Circuit 실험과 **별개**다. Local Learning Coefficient(LLC)를 통한 알고리즘 선택 분석임을 표시한다. `())(`는 개수 2=2, 접두사 깊이 1,0,−1,0. 두 규칙의 수락/거부와 일반화 차이를 설명하지만 개별 모델 집단의 비율을 만들지 않는다.

## 연구 확인

2026-10-21 [공식 ICML/PMLR 발표 페이지](https://proceedings.mlr.press/v306/wang26fw.html)와 [저자 원고 v1 §2.2–3.2, §4.4–4.5](https://arxiv.org/html/2601.13548v1)를 확인했다. 3M attention-only Transformer의 손실 재가중·재학습, Prefix Matching 및 Previous Token Score를 통한 형성 비교, 국소 선형 근사의 한계가 근거다. 실제 분포 개입은 감수율의 PC2 방향을 이용하며 '반복 문자열이면 무조건 좋은 데이터'라는 법칙으로 확장하지 않는다. 괄호 실험의 일반화 변화는 별도 설정의 결과다.

## 소스와 검토

content.py가 사용자 낭독·종료 시각 원본이다. `python scripts/prepare_nncalc03.py`가 대본·TTS·timing.json·가로/세로 SRT를 생성한다. nncalc02의 두 Head 그래픽을 InductionCircuitView에서 재사용한다. DataReweightingView, TrainingPopulation, CircuitFormationPlot, SusceptibilityMatrixView, InverseDesignView, AlgorithmSelectionView는 이번 편의 구성 요소다.

렌더 `python scripts/render.py nncalc03 [--preview]`, `python scripts/render.py nncalc03_shorts [--preview]`. 검토 `python scripts/check_nncalc03.py [--shorts] [--preview]`. 29개 종료 시각·171초·해상도·fps·TTS 일치, 2×3 행렬과 역행렬 미사용, 자막 안전 영역, 연속된 방향 반전 장면을 확인한다. 제작 결과는 production_checks.json 및 production_checks_shorts.json에 기록한다.

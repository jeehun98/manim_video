# 신경망 내부의 계산 03 — Patterning 상세 영상화 콘티

영상 제목: 학습 데이터로 신경망 내부 회로의 형성을 조절하는 방법 — Patterning

예상 분량: 약 3분 · 16:9 · Manim 기반 수학 애니메이션

이번 3편은 이전 2편에서 구현한 Induction Circuit의 그래픽을 재사용하면서, 신경망 내부의 계산을 관찰하는 것에서 원하는 계산이 형성되도록 학습 데이터를 설계하는 것으로 관점을 전환하는 영상이야.

실제 Patterning: The Dual of Interpretability 연구에서는 데이터 재가중을 통해 작은 언어 모델의 Induction Circuit 형성을 촉진하거나 지연시키고, 별도의 괄호 분류 실험에서는 학습되는 알고리즘의 선택에도 영향을 주었어.&#x20;

### 장면 08. 감수율 행렬의 등장

1:23–1:37

앞서 보여준 데이터 카드와 회로 관측량을 각각 벡터 형태로 변환한다.

화면 왼쪽에 `Δh`, 오른쪽에 `Δμ`를 배치한다. 두 벡터 사이에 주황색 행렬이 등장한다.

감수율 — Susceptibility

\\[ \Delta\mu\approx\chi\\,\Delta h \\]

\\(\Delta\mu\\)

구조 관측량 변화

\\(\chi\\)

감수율 행렬

\\(\Delta h\\)

수식을 한 번에 나타내지 말고 다음 순서로 등장시킨다.

1. 데이터 변화 벡터 `Δh`가 만들어진다.
2. 데이터와 내부 구조를 연결하는 감수율 행렬 `χ`가 등장한다.
3. 두 요소가 결합되며 관측량의 변화 `Δμ`가 나타난다.
4. 각 행렬 항목에서 해당 데이터 방향과 구조 관측량 사이에 연결선이 그어진다.

내레이션: “이처럼 데이터 분포의 작은 변화에 내부 구조가 얼마나 반응하는지를 나타내는 것이 감수율, 서셉티빌리티입니다. 데이터 가중치의 변화를 델타 에이치, 관찰하려는 구조의 변화를 델타 뮤라고 하겠습니다. 작은 변화에 대해서는 구조의 변화를 감수율 행렬 카이와 데이터 변화의 곱으로 근사할 수 있습니다.”

수학적 주의: 여기서 `Δμ`는 원 논문의 관점에서는 내부 관측량의 사후기댓값 변화를 의미해. 영상에서는 이해를 위해 관측량 변화라고 줄여 표현하되, 단일 학습 실행의 회로 변화가 정확히 이 선형식에 의해 결정된다고 묘사해서는 안 돼.&#x20;

수학적 연출 주의: 감수율은 일반적으로 정사각형 가역행렬이 아닐 수 있어. 따라서 화면에 단순한 `χ⁻¹`을 표시하기보다는 `역문제`, `근사해`, `가능한 데이터 변화`라는 표현을 사용하는 것을 추천해.

### 가장 중요한 전환 애니메이션

장면 09 → 10 → 11은 컷을 바꾸지 않고 하나의 연속된 애니메이션으로 만드는 게 좋아.

처음에는 다음 구조가 화면 중앙에 있어.

\\[ \underbrace{\Delta h}\_{\text{데이터 변화}} \xrightarrow{\quad\chi\quad} \underbrace{\Delta\mu}\_{\text{구조 변화}} \\]

이후 오른쪽의 `Δμ`가 노란색 목표 테두리로 바뀌고, 화면의 시각적 흐름이 반전돼.

정방향 분석

\\(\Delta h\\)

\\(\Delta\mu\\)

역방향 설계

\\(\Delta\mu\_{\mathrm{target}}\\)

\\(\Delta h\_{\mathrm{candidate}}\\)

이 한 번의 방향 전환이 Patterning 연구의 철학을 전달해.

기술적으로는 `TransformMatchingTex`, `ReplacementTransform`, `LaggedStart`를 활용하고, 수식이 변할 때 기존 기호들을 유지하면 새로운 공식으로 바뀌었다는 인상보다 같은 관계를 반대 방향으로 해석한다는 느낌을 줄 수 있어.

## 5. 영상화에서 주의할 점

과학적 정확성과 시각적 이해를 위해 다음 기준을 유지하면 좋아.

- 학습 데이터 가중치와 모델 가중치를 혼동하지 않기. 데이터 가중치는 특정 학습 샘플이 학습 목적함수에 기여하는 비중이며, 모델의 파라미터를 직접 수정하는 것은 아니야.
- 감수율은 국소적 반응으로 표현하기. 큰 데이터 분포 변화를 항상 정확히 예측하는 식처럼 묘사하지 않는다.
- 실험 결과와 개념도 구분하기. 회로 강도 그래프, 개별 데이터의 반응 막대는 실제 수치를 사용하지 않으면 `개념도`를 표기한다.
- 알고리즘 선택 실험은 별개임을 표시하기. Induction Circuit 형성 실험과 괄호 알고리즘 선택 실험은 동일한 실험이 아니야.
- Patterning을 완전한 제어 기술처럼 표현하지 않기. 제한된 조건에서 학습되는 내부 구조의 경향을 유도한 연구라는 점을 유지한다.

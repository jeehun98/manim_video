# 제작 기준 — 우리에게 오는 빛이 왜 우리에게서 멀어질까?

## 상태와 목표

- 사용자 요청 범위: 2편 내용의 물리적 정확성 확인과 대본 작업. narration.md, tts_script.txt, brief.md만 생성한다. 화면 소스·추정 타이밍·SRT·렌더 ID는 생성하지 않는다.
- 15개 주요 화면 변화 구간. 3분 이내 세로형 교육 영상 목표이며 길이는 대본 확정 후 실제 TTS 음원 또는 사용자 제공 구간 종료 시각으로 정한다.
- 독립 질문: 우리를 향해 오는 빛이 왜 한동안 더 멀어질 수 있을까?
- 결론: 국소적인 진행 방향과 우주론적으로 정의한 거리의 증가·감소는 다른 양이다. 초광속 후퇴 영역에서 방출된 빛도 도착 가능한 경우가 있다.
- 이전 편 복습·이후 편 예고·신경망 연결을 넣지 않는다. 에스컬레이터 비유도 생략하고 한 광자의 경로를 끝까지 따라간다.

## 물리적 조건

- 기본 설정: 평탄한 FLRW 우주, 공변 관측자, 관측자를 향해 방사 방향으로 진행하는 진공 광자. 같은 우주 시간 단면의 proper distance D=aχ를 사용한다.
- 광자는 dχ/dt=−c/a를 따르므로 dD/dt=HD−c. 이 조건에서는 단순한 직관적 근사가 아니라 정확한 관계다. ‘원거리에서 측정한 광자의 국소 속도’라는 의미는 아니다.
- HD와 −c는 같은 거리 미분의 분해 항이다. 서로 다른 위치의 국소 상대속도를 뉴턴식으로 합하는 표현은 피한다. 공간이라는 물질이 광자를 물리적으로 밀거나 광자가 힘에 밀려 뒤로 미끄러진다고 그리지 않는다.
- H(t)도 D(t)도 변한다. 가속 팽창 ä>0은 H의 증가와 동의어가 아니다. 물질과 양의 우주상수로 이루어진 평탄한 ΛCDM은 가속기에도 H가 감소할 수 있는 구체적 예시다.
- R_H=c/H는 순간적인 Ḋ=0 경계이며 보편적인 관측 가능성의 경계가 아니다. 허블 반지름이 단지 증가한다는 사실만으로 모든 광자의 도착을 보장하지 않는다. 이 영상은 해당 광자가 바깥에서 안쪽으로 넘어와 관측자에게 도착하는 경우를 선택한다.
- 최대 거리 조건: D=R_H에서 Ḋ=0. 이 교차가 최대점인 것은 선택한 모형에서 Ḣ<0이기 때문이다. 이때 D̈=ḢD<0. 임의의 우주 모형에서 모든 Ḋ=0 지점이 최대점이라고 일반화하지 않는다.
- 광자 방향은 공변 위치 χ가 감소한다는 뜻으로 표시한다. 화면 가로 위치는 proper distance D로 두어 처음에 오른쪽으로 움직이더라도 왼쪽 국소 화살표와 모순되지 않게 두 기준을 명시한다.
- 빛의 국소 속도는 정점에서도 c다. 방향 화살표를 뒤집거나 광자가 멈추는 애니메이션은 사용하지 않는다.
- 주요 장면에서 ‘국소 진행 방향’인 왼쪽 화살표와 ‘우리와의 거리 D’ 그래프를 동시에 유지한다. D(t)는 상승 → 최대 → 하강하지만 국소 방향은 뒤집히지 않는다.
- 사건의 지평선이 존재하는 모형에서 D_eh(t)=a(t)∫_t^∞ c dt′/a(t′). 그 바깥의 해당 시각에서 방출된 신호는 관측자에게 도달하지 않는다. 천체의 과거 빛까지 관측할 수 없다는 뜻은 아니다.
- 허블 구면과 사건의 지평선은 일반적으로 다르다. de Sitter 같은 특수한 경우에는 일치하므로 ‘언제나 다르다’라고 강조하지 않는다.
- 자료의 ‘처음 HD>c → 나중 HD<c → 최대 거리’ 나열은 시간 순서를 바로잡아 ‘HD>c → HD=c에서 최대 → HD<c → 도착’으로 구성한다.

## 장면별 시각화 기준

| 구간 | 화면의 주장과 변화 |
| --- | --- |
| 01 | 왼쪽 관측자, 오른쪽 광자. 국소 진행 화살표는 왼쪽인데 거리선은 늘어남. 첫 화면에 ‘국소 진행 방향’과 ‘우리와의 거리’를 분리한다. |
| 02 | 먼 은하가 광자를 방출. 광자 옆 작은 관측 창에서 c를 측정하며 화살표가 관측자 방향임을 보여준다. |
| 03 | 같은 우주 시간 단면 위 관측자–광자 거리 D 표시. 과거 은하 모습까지 같은 시각에 실시간 관측한 것처럼 묘사하지 않는다. |
| 04 | 격자의 공변 눈금 간격 증가와 눈금에 대한 광자의 진행을 동시에 표시. 거리 변화는 하나의 결과선으로 읽힌다. |
| 05 | Ḋ=HD−c. HD와 c의 기여를 색으로 구분하고 최종 값은 거리 증가율이라고 표시한다. 수식은 화면 원형, TTS는 발음 표기. |
| 06 | HD>c, Ḋ>0. 광자가 화면 오른쪽으로 움직여도 국소 방향 화살표는 왼쪽 유지. 아래 D(t) 그래프가 상승한다. |
| 07 | 같은 광자와 그래프를 유지. H(t)와 D(t)가 모두 변함을 나타내고 새로운 광자로 바꾸지 않는다. |
| 08 | 필요하면 ä>0과 Ḣ<0가 함께 가능한 것을 짧게 표시. 지구에서 빛을 쏘는 방향이나 빛 자체 속도가 변하는 장면은 넣지 않는다. |
| 09 | R_H=c/H를 관측자로부터 떨어진 점선 위치로 표시. HD=c는 그 위치에서 팽창을 따라가는 지점의 거리 증가율임을 명시하고, 광자의 Ḋ=HD−c와 구별한다. 반사·충돌·불투명 벽을 그리지 않는다. |
| 10 | ‘우리 우주의 역사처럼 허블 반지름이 커지는 구간’이라는 조건을 붙임. 점선 R_H(t)가 광자의 D(t)를 따라잡는 도착 가능 사례를 선택한다. 항상 증가하거나 모든 광자를 따라잡는다는 주장은 하지 않는다. |
| 11 | ‘이 광자의 경우’라는 조건 아래 Ḋ=0을 거리 그래프의 정점에 붙임. 작은 국소 창 속 광자는 c로 계속 이동하여 ‘정지’ 오해를 막는다. |
| 12 | HD<c, Ḋ<0. proper-distance 위치가 관측자 방향으로 이동해 D=0에 도착. |
| 13 | 하나의 D(t) 궤적을 완성하고 상승·최대·감소·도착을 읽는다. 국소 화살표는 모든 구간에서 같은 방향. |
| 14 | 허블 반지름은 순간적인 HD=c 위치, 사건의 지평선은 미래 신호의 도달 가능성을 가르는 경계로 역할을 구분한다. ‘지금 출발한 빛’ 기준을 표시하며 과거 빛을 볼 수 없다는 인상을 피한다. 이후 편 예고는 넣지 않는다. |
| 15 | 국소 진행 방향과 Ḋ의 부호를 병렬 비교하며 첫 질문에 답한다. |

## 후속 화면 제작의 계산 기준

- 미리 정한 종 모양 베지어 곡선에 H를 따로 붙이지 않는다. 구체적인 팽창 모형에서 광자 경로와 허블 반지름을 함께 계산한다.
- 후보: H(a)=H₀√(Ω_m a⁻³+Ω_Λ), Ω_m=0.3, Ω_Λ=0.7인 평탄한 물질+우주상수 모형. 교육용 모형임을 표시하고 방출 시각은 radiation이 중요한 극초기 대신 적절한 물질 우세기에 둔다.
- 선택한 도착 시각 t₀에 대해 D_γ(t)=a(t)∫_t^t₀ c dt′/a(t′), R_H=c/H를 사용하면 도착점과 중간 경로를 일관되게 얻을 수 있다.
- 방출점에서 D_γ>R_H인지, 최대점에서 D_γ=R_H인지, 이후 D_γ<R_H인지, t₀에서 D_γ=0인지 확인한다. χ=D/a의 단조 감소도 확인한다.
- 실제 우주 시간의 장면 재생은 TTS 길이에 맞춰 압축할 수 있다. 도식의 재생 속도를 물리적 초·광속의 실제 배율로 오인시키는 속도계를 사용하지 않는다.

## 대본 파일 기준

- narration.md는 원래 수학·영문 표기를 유지한다. tts_script.txt는 제목·번호·시간 없이 화면 변화마다 빈 줄 하나로 구분한다.
- TTS 발음: D=디, H=에이치, c=씨, HD=에이치와 디의 곱. ‘허블 반지름’, ‘사건의 지평선’은 한국어 그대로 읽는다.
- 구간 길이·총길이는 아직 확정하지 않으며 추정 시각을 넣지 않는다.

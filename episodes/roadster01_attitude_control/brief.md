# 가스를 뿜지 않고도 공중에서 회전할 수 있을까? — 제작 기준

## 상태와 목표

- 시리즈 예고 없이 완결되는 단일 영상. 기존 폴더 경로는 유지한다.
- 질문: 외부로 가스를 분출하지 않고 자동차의 방향을 바꾸고 정지할 수 있는가?
- 결론: 내부 원판과 차체가 각운동량을 교환하면 전체 각운동량 0을 유지하며 새로운 방향에서 정지할 수 있다. 보존되는 것은 방향이 아니라 각운동량이다.
- 10개 화면 구간. narration.md·tts_script.txt·brief.md만 수정한다. 길이는 대본 확정 후 TTS로 정하며 scene.py·SRT·timing.json·렌더 ID는 아직 만들지 않는다.
- 고양이 질문은 후속편 예고가 되므로 이번 단일 영상에서 제외한다. 포화는 스러스터와 휠의 보완 관계를 설명하는 짧은 구간이다.

## 물리적 조건

- 실제 로드스터에 반작용 휠이 탑재됐다는 주장이 아닌 가상 실험임을 낭독과 화면에 명시한다.
- 차체와 중심에 장착된 축대칭 원판의 고정된 공통 축 회전. 관성모멘트 일정, 초기 전체 각운동량 0, 외부 토크 무시. 질량중심을 따라가는 관성 시점에서 보여준다.
- 모든 각속도와 각운동량은 동일한 관성 기준으로 비교한다. L_total=I_body·ω_body+I_wheel·ω_wheel=0. 모터의 원판 상대 각속도 Ω를 쓰면 ω_wheel=ω_body+Ω이며, (I_body+I_wheel)·ω_body+I_wheel·Ω=0이다.
- Ω를 0에서 가속하고 일정하게 유지한 뒤 0으로 감속하면 차체와 원판 모두 최종 정지하지만 차체 각도 변화는 남는다. 차체 각도 변화는 −I_wheel/(I_body+I_wheel)·∫Ωdt. 원판의 각도까지 초기값으로 되돌리는 동작과 혼동하지 않는다.
- 모터 OFF와 속도 유지 명령은 구분한다. 이상적 무마찰 구간에서는 가속 종료 후 두 물체가 일정 속도로 반대로 돈다. 감속 중 토크는 각각의 기존 회전과 반대이며 정지 시 종료한다.
- 동일 크기의 반대 각운동량이지 동일 각속도가 아니다. 외부에서 본 회전 방향과 크기를 표시한다.
- 내부 장치만으로 계 전체의 질량중심 궤적을 바꾸거나 호버링할 수 없다. 균일 중력 아래 낙하는 계속되며, 화면에서 차체 위치를 고정하는 것은 추적 시점이다.
- 이상적인 방향 전환마다 휠에 각운동량이 필연적으로 누적되지는 않는다. 외부 교란 토크를 장기간 상쇄하는 실제 상황을 별도로 제시한다.
- 포화는 휠의 허용 각운동량·속도 한계로 해당 방향의 추가 제어 여유가 제한되는 현상이다. 모든 방향의 토크가 완전히 사라진다고 표현하지 않는다.
- Webb은 스러스터로 모멘텀 언로딩한다. 자기 토커를 Webb의 장치로 묘사하지 않는다.
- 스러스터는 분출 가스와, 반작용 휠은 내부 차체와 각운동량을 교환한다. 분출 가스를 포함한 전체 계와 차체+휠 계의 경계를 구분한다.

## 화면 기준

- 01: 로드스터 시연과 압축가스 스러스터는 도입. 최종 편집 전에 실제 원본의 동작을 대조하며 노즐별 동작을 추정하지 않는다.
- 02~07: 같은 차체와 원판 유지. 원판의 회전을 읽을 수 있는 표식, 차체 방향 표식, 고정 기준 방향을 둔다.
- 03~04: 반대 회전 화살표와 부호가 반대인 각운동량 막대. 합은 항상 0. L_body+L_wheel=0만 짧게 표시하고 식은 읽지 않는다.
- 05~06: 원판 가속 → 일정 속도 → 감속 → 둘 다 정지. 차체 각도는 단조 변화 후 새 값에서 유지. 목표 방향 도달 이전 제동 시작.
- 07: 초기와 최종을 겹쳐 차체 방향 변화 확인. 전체 각운동량은 둘 다 0.
- 08: Webb 반작용 휠 6개는 실제 사례. 가상 차체 모델을 실제 장치 배치도로 오인시키지 않는다.
- 09: 태양빛의 외부 토크 → 휠 각운동량 축적 → 스러스터로 해소. 이상적 실험과 조건이 달라졌음을 표시한다.
- 10: 가상 실험의 초기·최종 방향과 각운동량을 다시 보여주며 독립 결론으로 종료한다.

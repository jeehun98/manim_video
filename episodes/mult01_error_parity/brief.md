# 인공지능의 곱셈 · 오답에 남은 홀짝

## 제작 기준

- 사용자 제공 대본과 21개 문장 종료 시각을 그대로 사용한다. 총 102초, 3060프레임, 9:16 세로, 1080×1920, 30fps. 미리보기 360×640.
- 이번 요청은 완성 대본 및 실제 발화시각과 함께 영상 생성을 요청했으므로 영상 단계로 진행한다. 문장을 수정하거나 글자 수로 시간을 추정하지 않는다.
- 음원 미제공: 무음 영상. 전체 문장 자막을 지정된 문장 구간 동안 유지한다. 개별 어절의 시작 시각은 알 수 없으므로 추정 분할하지 않는다.
- 이전 편 복습·다음 편 예고 없음. 도입 질문과 오답 분석의 결론으로 독립 완결.
- 원문에서 92.7%와 홀짝을 언급하는 22–32초는 화면의 **십의 자리 숫자**를 대상으로 해석한다. 통계 대상이 답 전체라고 보이지 않도록 제목·대상·주의 문구를 함께 노출한다. 원문 낭독문 자체는 수정하지 않았다. 음성만 독립해서 들으면 통계 범위가 모호할 수 있다는 한계가 남는다.

## 화면 설계

계산 입력과 신경망 → 16,991문제 → 오류에서 발견한 십의 자리 92.7% → 정답 1081 / 가상 오답 1061의 십의 자리 8·6 확대 → 세로 곱셈과 올림 → 덧셈 선행 연구의 푸리에 파동 → 느린 파동의 크기 / 빠른 파동의 홀짝 → 나선 표현의 개념도 → 곱셈으로의 가설 → 관찰과 해석의 구분 → 정답률을 넘어 오답의 구조를 묻는 결론.

파동·나선은 교육용 개념도이며 실제 활성화·회로 추출 결과를 재현하지 않는다. 가상 오답 1061은 논문의 모델 출력이라고 주장하지 않는다. 23×47의 정답은 1081, 부분곱은 161+920. 나선은 일반화된 고차원 표현을 설명하기 위한 2D 투영 개념도이며 정확한 전체 표현이 아니다.

통계 범위는 Qwen3.5-2B에서 틀린 십의 자리 숫자 3,542개 중 홀짝이 실제 숫자와 일치한 비율 92.7%. 모델 기반 기준선 44.4%. 모든 모델·모든 숫자에 대한 법칙으로 확대하지 않는다. 곱셈 내부 메커니즘은 직접 입증하지 않았다.

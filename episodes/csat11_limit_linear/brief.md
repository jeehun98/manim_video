# EP.11 제작 기준

사용자 확정 대본 및 44개 문장 종료 시각 준수. 200초, 1920×1080, 30fps, 16:9. 음원 미제공으로 무음·화면 자막.

R(x)=f(x+2)/[x(f(x)−3)], f는 일차함수. a=0에서 유한한 극한 존재, a=3에서 미존재. 목표 f(4). 첫 조건에서 f(2)=0, 둘째 조건에서 f(3)=3을 필요조건으로 도출한 뒤 f(x)=3x−6을 결정하고 원래 식으로 검증한다. R(x)=1/(x−3), x≠0,3. x=0에 빈 점 (0,−1/3), x=3에 수직점근선. 좌극한 −∞, 우극한 +∞. 정답 f(4)=6(①).

함수 결정 전 실제 직선 그래프를 공개하지 않음. f(x+2)는 입력 전체로 표시해 f(x)+2와 구분. 0/0은 값이 아닌 극한 형태로 표시. 필요조건과 충분한 검증 구별. 실제 좌표축으로 그래프·점·기울기 대응. 28개 독립 교체 가능 씬. 이전 편 복습·다음 편 예고 없음. 선택지 원문 미제공으로 임의 선택지 없음.

# 신경망의 역설 03 — 신경망은 키메라를 학습할 때 더 똑똑해진다?

## 제작 기준

- 사용자 확정 원고 23문단과 누적 종료 시각 2·5·11·16·18·22·28·34·40·43·49·53·56·60·67·73·78·84·93·96·100·104·109초를 사용한다.
- 총 109초. TTS 음원 미제공으로 무음 마스터. 최종 1080×1920, 30fps. 미리보기 360×640.
- 핵심은 ‘혼합 데이터의 실제 정답 발견’이 아니라 ‘입력 사이에서 따라야 할 예측 규칙을 인위적으로 부여하는 정규화’이다.
- 이전 편 복습과 다음 편 예고를 넣지 않는다.

## 장면 구성

1. 0–22초: 같은 크기로 정렬한 고양이·강아지 입력의 픽셀 선형 혼합, 50·50 목표를 제시한다. 실제 생물 형태로 합성한 키메라를 보여주지 않는다.
2. 22–40초: 양 끝의 분류는 맞아도 중간 행동은 결정되지 않음을 보인다. 같은 두 끝점에 여러 곡선이 가능하고, 예시 곡선이 중간에서 요동친다.
3. 40–53초: 불규칙한 예측 곡선 위에 선형 목표를 추가한다. 70·30, 50·50에서 입력과 목표 비율이 같음을 연결한다.
4. 53–67초: 고차원 입력 공간의 두 점과 선분을 1차원 단면으로 표현한다. λ는 고양이 A의 비율이며, 왼쪽 강아지 B가 λ=0, 오른쪽 고양이 A가 λ=1이다. 선분 위 이동과 목표 q고양이=λ의 이동을 동기화한다.
5. 67–78초: 관측한 실제 정답과 우리가 설정한 혼합 목표를 구별한다. 실제 세계의 잠재 정답 함수를 그리지 않는다.
6. 78–96초: 같은 좌표에서 예측 곡선이 선형 목표에 가까워지는 과정을 보여준다. 설명용 변화이며 실제 학습 궤적·실험 결과가 아님을 명시한다. ‘정확히 선형’으로 고정하지 않고 잔여 오차를 남긴다.
7. 96–109초: 혼합 이미지를 회수하고, 입력 선분 위에서 ‘기존 학습: 각 데이터의 정답을 알려준다’와 ‘Mixup: 데이터 사이의 예측 규칙까지 알려준다’를 순서대로 등장시킨다.

## 정확성 기준

- x̃=λxA+(1−λ)xB, q̃=λyA+(1−λ)yB에 같은 λ∈[0,1]을 사용한다. yA·yB는 One-Hot 목표이다.
- f는 로짓이 아니라 예측 확률 벡터를 뜻한다. f(x̃)≈q̃는 학습으로 유도하는 목표이지 모든 점에서 성립하는 보장이 아니다.
- 그래프는 입력 선분을 따라 본 고양이 확률 하나의 단면이다. 두 클래스 예시에서 강아지 확률은 1−고양이 확률이다. 실제 다중 클래스 데이터셋 전체를 두 클래스로 제한한다는 주장은 하지 않는다.
- 예측 곡선의 양 끝은 0.02와 0.98로 표시한다. 유한 Softmax에서 정확한 0·1에 도달했다고 표현하지 않는다. 분류 정답과 확률 일치는 구별한다.
- 혼합 입력의 목표는 사람이나 관측 장치로 얻은 실제 정답이 아니다. Mixup은 입력·라벨 사이의 선형 거동이 유용하다는 귀납적 가정을 부여한다.
- 곡선의 불규칙성, 학습에 따른 완화는 설명용으로 만든 함수이다. 성능 수치나 실측 손실·정확도를 꾸며내지 않는다. ‘가정이 유용할 때 도움이 됨’을 명시한다.
- 실제 Mixup은 샘플 쌍과 혼합 비율을 표본 추출한다. 모든 쌍의 모든 선분을 전수 학습하는 그림으로 표현하지 않는다. 원 연구의 Beta 분포는 이 영상의 설명 범위에서 생략한다.
- ‘데이터가 아니라 제약’이라는 결론은 혼합 데이터를 실제로 추가하지 않는다는 뜻으로 쓰지 않는다. 혼합 데이터를 통해 예측 함수에 제약을 추가한다는 뜻으로 명시한다.

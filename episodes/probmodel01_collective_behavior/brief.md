# 제작 기준

166초, 9:16, 1080×1920, 30fps. 음원 미제공: 무음. 확정 대본·발화 시각 유지.
입자 충돌은 개념도. 확산은 초기 집중된 입자들의 1차원 수평 위치로 표시. 표본 히스토그램과 이론 밀도를 구분.
12×12, 주기 경계, 외부장 0 이징 모형의 체커보드 Metropolis 상태를 사전 계산. 유한 격자의 순간 자화 m_N과 무한 정방격자의 자발 자화 곡선을 구분한다. 개별 스핀은 두 자기 상태의 변수.
임계점의 엄밀한 상전이는 열역학적 극한. 임계점 위에도 유한 표본 자화는 0 부근에서 요동. 자화 그래프는 연속적으로 0에 접근한다.
브라운 경로는 독립 정규 증가량의 누적. 고해상도 경로의 부분 구간을 재표본화해 확대하며 유한 선분 근사임을 명시. 확률 1의 어디서나 비미분 가능성은 이상적 과정의 성질이며 실제 미시 속도와 구별.
1차원 무표류 X₀=0, Var(X_t)=2Dt. 밀도는 정규화 유지. 시간4배→분산4배→표준편차2배.

# 분포의 수학 17 — GMM Singularity 제작 기준

- 제목: **학습 점수를 무한히 올릴 수 있다면 좋은 모델일까? | GMM Singularity**. 기존 ELBO·Local Optimum 편은 보존한다. 새 ID는 **dist17_singularity**, 출력 파일은 `dist17_singularity.mp4`다. 핵심은 분산을 줄여 한 점을 붙잡는 병적인 해가 학습 목적함수를 무한히 높일 수 있다는 반전이다.
- 화면은 1차원 Gaussian의 밀도를 사용한다. μ=xᵢ이면 지수항은 1이며 성분의 높이는 `1/(√(2π)σ)`다. σ는 표준편차, σ²는 분산이다. σ>0에서 0으로 접근하며 σ=0을 정상적인 Gaussian 밀도로 표시하지 않는다. 밀도는 1보다 클 수 있지만 전체 적분은 1이다.
- 실제 계산 예시: 관측점 12개, 선택점 xᵢ=0.4. `pσ(x)=(1/12)N(x|0.4,σ²)+(11/12)N(x|0,1.3²)`다. 붕괴 성분의 가중치는 양의 상수로 고정한다. 다른 모든 점은 고정된 배경 성분으로부터 양의 밀도를 계속 받으므로 로그 밀도가 −∞로 떨어지지 않는다. 선택점의 로그 밀도만으로도 전체 log likelihood가 +∞로 발산하는 수열을 만들 수 있다.
- 수치 점수 화면은 σ=0.03,0.01,0.0001,10⁻¹²의 **전체 혼합밀도**와 **전체 데이터 로그 가능도**를 실제 계산한다. 이 구간의 점수 상승을 검증했다. 1에서 0.1까지 폭을 줄이는 동안 전체 점수가 매 순간 오르는 것은 아니므로 초기 축소 장면은 성분의 높이만 보여준다. EM이 항상 이 경로를 따라가거나 모든 초기값에서 붕괴한다고 주장하지 않는다.
- Gaussian 그래프는 고정된 선형 밀도 축이다. 밀도 1의 눈금을 남긴다. 봉우리가 화면을 넘으면 곡선을 상단에서 잘라 두 조각으로 표시하고, 위쪽 화살표와 실제 높이 수치를 붙인다. 높은 봉우리를 납작하게 만들거나 몰래 세로축을 바꾸지 않는다. 면적 설명은 잘리지 않는 σ=0.3 곡선을 사용한다.
- 이 문제는 평균과 공분산에 제약이 없는 GMM의 가능도가 유계가 아닐 수 있다는 것이다. 보통의 과적합과 관련된 병적 사례이며 완전히 별개의 현상처럼 단정하지 않는다. “점수 최대화”만으로 유한한 정상 해가 보장되지 않음을 설명한다. 정상적인 점들에도 고정 배경 성분의 밀도가 유지되는 조건을 포함한다.
- 해결 화면: 1차원 분산 하한 `σ²≥ε>0`, 붕괴를 막는 regularization 또는 prior. 다차원에서는 모든 공분산 고유값의 하한이 필요하다. 임의의 prior나 임의의 regularizer가 항상 문제를 해결한다고 주장하지 않는다.
- **59.2초 추정**. 12개 구간의 발음용 TTS 비공백 글자 수를 초당 7.5자로 환산하고 문장 끝 짧은 휴지(0.18초), 마지막 여운 0.8초만 추가했다. 균일한 긴 구간을 쓰지 않는다. 경계 `6.2,9.6,13.5,17.3,22.2,27.8,33.3,37.7,41.9,48.8,53.2,59.2`. 실제 음성은 아직 제공되지 않았으며 이는 음성 동기화가 아닌 발화 길이 추정이다. `content.py`가 대본과 타이밍의 기준이다.

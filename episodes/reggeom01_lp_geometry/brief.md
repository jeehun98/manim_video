# 규제의 정의가 바꾸는 최적해

사용자 제공 39문장·문장 종료 시각 176초를 확정 대본으로 사용한다. 가로 16:9·1920×1080 및 세로 9:16·1080×1920, 30fps. 음원이 제공되지 않아 무음 영상과 전체 자막을 제작한다. 쇼츠용 세로판은 같은 장면 로직을 공유하고 화면비에 맞춰 제목·수식·도형·자막을 별도로 배치한다.

핵심 주장: 손실 최소점 `a=(2, 0.8, 0.35)`와 `Q=diag(1,1.2,1.6)`을 고정한다. 동일 반경 `||w||ₚ≤1`에서 p만 바꾸면 제약 영역과 실제 최적해가 바뀐다. L1의 해 `(1,0,0)`은 제약 최적화로 검증한다. L2·L4·L∞의 접촉점은 수치 최적화 결과를 사용한다. p<1에서는 영역의 비볼록성만 보여 주고 전역 최적해를 단정하지 않는다.

원점과 좌표계는 전 구간 동일하다. 손실 등면은 주황색, 제약 영역은 청록색, 최적해는 흰색, 0 좌표는 보라색이다. 수식과 전체 문장 자막은 카메라와 독립된 화면 평면에 둔다. 이전 편 복습·다음 편 예고·별도 엔드카드는 없다.

콘티의 `L2`는 `w₁²+w₂²+w₃²≤1`과 동치인 단위 L2 볼로 표현한다. 벌점형 목적함수와 제약형은 적절한 대응 파라미터가 있을 때 비교하며, 둘의 λ와 제약 반경을 임의로 동일시하지 않는다.

설명 동작 보강: 0–31초에는 경사 감소 경로와 `w(λ)=QA/(Q+λ)`의 실제 L2 벌점 해를 움직인다. 31–47초에는 세 좌표 성분을 선으로 합치고 등손실면을 차례로 만든다. 61–85초에는 반지름이 같은 점을 회전시키고 실제 접촉 수준까지 타원체를 확장한다. 85–127초에는 양의 영역의 평면에서 합이 1인 점을 이동시킨 뒤 여덟 면을 조립하고, 모서리→꼭짓점 이동에서 0인 좌표를 수치로 유지한다. 133–150초에는 Lp 경계를 매 프레임 다시 계산하여 변형한다. 볼록 문제의 해는 KKT 방정식의 근으로 계산한 65개 표본 사이를 보간하고 해당 Lp 경계로 재투영한다. 각 표본과 구간 끝의 해는 실제 제약 최적화 결과다. 150–156초의 비볼록성은 축의 두 단위 꼭짓점을 잇는 선분의 중점이 `0.5^0.7+0.5^0.7>1`로 영역 밖에 있음을 보여 준다. 156–176초에는 같은 손실함수의 L2와 L1 해를 다시 변화시켜 도입의 질문에 답한다.

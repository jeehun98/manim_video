# 과학의 한 장면 03 — Bullet Cluster 제작 기준

- 질문: 가스와 중력렌즈 질량 지도의 중심은 왜 서로 다른 곳에 있는가?
- 목표: 충돌 때 가스와 은하의 운동이 달라져, 대부분의 보통 물질인 가스와 총질량 피크가 분리됨을 이해한다.
- 형식: 76초, 1080×1920, 30fps 무음. 대사 글자 수/초는 01편과 같으며 화면 길이는 각 대사의 글자 수 비율로 배분한다.
- 순서: 질문과 접근 → 충돌과 통과 → X선 가스 → 렌즈 질량 복원 → 지도 겹침 → 충돌 재생 → 암흑물질 → 위치 차이로 마무리.
- 은하=금색 점, 뜨거운 가스=분홍색 구름, 질량 지도=보라색 영역. 앞선 편의 보라색 질량, 청록색 렌즈 패턴을 이어간다.
- 은하도 보통 물질이다. 보통 물질 전체가 질량과 분리됐다고 말하지 않는다. 대부분의 보통 물질인 가스의 피크와 총질량 피크의 어긋남을 강조한다.
- X선 가스는 가시광선으로 보이는 구름이 아니다. 색은 파장별 관측과 렌즈 추론 결과를 구분하는 시각화다.
- 실제 가스는 두 성분과 충격파 구조를 보이며 한 점에 완전히 멈추지 않는다. 단순화된 두 가스 구름이 은하보다 뒤처지는 모습으로 표현한다.
- 초기 보라색 영역은 설명용 질량 모형. 뒤에 렌즈로 복원한 지도가 나타난다. 입자를 직접 관측하는 것이 아니다.
- 충돌 전후 같은 은하단의 은하와 질량 영역이 함께 통과하며, 가스는 이동이 늦어진다. 질량 분포도 중력적 영향을 받으므로 절대 아무 상호작용도 없다고 말하지 않는다.
- 관측된 결과에서 충돌 과정을 추론한 모형이다. 실제 실시간 충돌 영상이나 역산 알고리즘, 특정 축척 또는 위치 수치가 아니다.
- 지도는 하늘에 투영된 총질량이고, 가스와 별 질량도 포함한다. 가스 영역에서 질량이 완전히 0이라고 말하지 않는다.
- 표준 우주론에서 지배적인 비발광 질량 성분을 암흑물질로 설명한다. 입자 정체의 직접 검출로 표현하지 않는다.
- 핵심 화면: 가스 중심의 분홍 십자와 질량 중심의 보라 십자를 점선으로 연결해 위치 차이를 보여준다.

## 사전 설명 보강

- 충돌 전에 보통 물질 안에서 뜨거운 가스의 질량이 별보다 크다는 비교 막대 장면을 추가한다. 암흑물질을 포함한 전체 질량 비교로 오해하지 않도록 명시한다.
- X선 가스 장면에서 보통 물질만 있다면 질량도 가스 쪽에 많이 있어야 한다는 예상을 설명한다.
- 암흑물질 도입 전에 은하 쪽 별 질량과 그곳의 렌즈 질량을 비교한다. 위치가 별 쪽인 이유가 별 질량 자체 때문이라는 오해를 막는다.
- 9개 대사의 글자 수 비율로 시간을 다시 배분한다. 비교 막대는 설명용이며 실제 비율이 아니다.
- 마지막 대사에 빛으로 직접 보이지 않아도 중력렌즈로 질량 분포를 추론할 수 있음을 명시한다.

# 씬별 제작 기준

총 167초, 사용자 확정 대본·종료 시각을 준수한다. 세로 프레임 9×16, 본문 y≥−4.9, 하단 자막 중심 −6.15. 각 씬 독립 교체 가능.

| 씬 | 초 | 주장·화면 |
| --- | --- | --- |
| 01 | 0–18 | 수의 덧셈·곱셈 교환에서 행동 순서에 대한 질문으로 |
| 02 | 18–44 | 3D 책의 X→Y, 초기화 후 Y→X. 앞표지 −Y와 +X 직접 비교 |
| 03 | 44–61 | 원점 중심의 90° 회전으로 (1,0)→(0,1), (0,1)→(−1,0) |
| 04 | 61–79 | (2,1)의 성분을 회전시킨 뒤 재합성해 (−1,2) |
| 05 | 79–94 | 기저벡터의 상을 열로 모아 행렬 조립, 좌표에 적용 |
| 06 | 94–104 | A 적용 후 B는 B(Av)=(BA)v |
| 07 | 104–126 | 같은 3D 책·축·회전 상태로 BA와 AB의 결과 차이를 재현 |
| 08 | 126–134 | 비가환성 명명 |
| 09 | 134–148 | 로봇·우주선·그래픽에서 자세 합성의 중요성 |
| 10 | 148–160 | 교환법칙의 성립 여부는 연산에 따라 다름 |
| 11 | 160–167 | 계산 결과뿐 아니라 연산 규칙을 연구하는 관점으로 완결 |

우선 저해상도 검수: 02의 표지·책등·고정축과 순차 회전, 05의 행렬 열 조립, 07의 동일한 회전 결과. 자동 검사: 회전 행렬 직교성/행렬식, 실제 재생된 회전의 왼쪽 합성과 법선, 2D 기저의 상·성분 재합성, 문장/SRT 일치·연속성, 자막 시각/범위, 프레임 수·해상도·전체 디코딩.

## 전체 내레이션

지금까지 지수함수와 로그를 EML의 연결 구조로 표현했습니다.

이번에는 가장 익숙한 이항 연산인 덧셈을 없애보겠습니다.

보통 덧셈 노드 하나면 충분하지만, 이번에는 같은 EML 노드만 반복해 연결합니다.

입력 x는 다섯 개의 EML 노드를 지나며 다음 계산에 필요한 형태로 바뀝니다.

입력 y는 한 개의 EML을 지나 e의 y승이 되고, 두 경로는 다음 EML에서 만납니다.

안쪽부터 계산하면 지수와 로그가 생겼다가 마지막 두 노드에서 다시 정리됩니다.

복잡한 EML tree의 최종 결과는 처음 덧셈과 같은 x+y입니다.

왼쪽은 덧셈 노드 하나, 오른쪽은 EML-only tree입니다. 두 graph의 입력과 출력 관계는 같습니다.

연산자의 종류는 하나로 줄었지만 node 수와 depth는 늘었습니다. 어떤 graph가 잘 실행되는지는 별도의 문제입니다.

그렇다면 곱셈은 같은 EML만으로 어떤 연결 구조를 만들게 될까요?

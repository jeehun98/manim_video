# SVD 05 — 타원을 훑어 찾는 두 값

85초 · 1080×1920 · 30fps · 한국어 자막 · 무음 마스터

발화 예상 길이에 맞춘 편집이며 실제 음성은 포함하지 않습니다.

| 시간 | 내레이션 | 화면 |
|---|---|---|
| 00:00–00:05 | 길이가 1인 입력 하나를 잡고,<br>방향만 천천히 돌려보겠습니다. | 단위 입력을 하나만 잡습니다<br>x(θ) = cos θ v₁ + sin θ v₂ |
| 00:05–00:12 | 입력 방향이 돌 때마다<br>같은 행렬의 반응을 하나씩 확인합니다. | 입력 방향을 스캔합니다<br>θ : 0 → 2π |
| 00:12–00:19 | 회전하는 입력에 대응하는 출력점은<br>타원 궤적을 한 바퀴 훑습니다. | 출력점은 타원을 훑습니다<br>y(θ) = Ax(θ) |
| 00:19–00:26 | 여기서 볼 값은 타원 위의 위치가 아니라,<br>원점에서 출력점까지의 길이입니다. | 매 순간 길이를 잽니다<br>L(θ) = ‖Ax(θ)‖ |
| 00:26–00:33 | 입력 각도마다 측정한 출력 길이를<br>아래 그래프에 계속 기록해보겠습니다. | 길이를 아래에 기록합니다<br>L(θ) = √(9 cos²θ + 0.25 sin²θ) |
| 00:33–00:37 | 스캐너가 장축 방향을 지날 때<br>출력 길이는 가장 커집니다. | 가장 높은 곳에 닿는 순간<br>max L(θ) = 3 |
| 00:37–00:42 | 모든 방향별 반응이 닿을 수 있는 위쪽 경계,<br>그 값이 가장 큰 특잇값입니다. | 이 위쪽 경계가 σ₁<br>σ₁ = 3 |
| 00:42–00:46 | 단축 방향을 지날 때는<br>출력 길이가 가장 작아집니다. | 가장 낮은 곳에 닿는 순간<br>min L(θ) = 0.5 |
| 00:46–00:51 | 모든 방향별 반응이 내려갈 수 있는 아래쪽 경계,<br>그 값이 가장 작은 특잇값입니다. | 이 아래쪽 경계가 σ₂<br>σ₂ = 0.5 |
| 00:51–00:57 | 그 사이 높이들도 실제 출력 길이이지만,<br>각각을 특잇값이라고 부르지는 않습니다. | 중간 높이는 일반적인 반응<br>σ₂ < L(θ) < σ₁ |
| 00:57–01:04 | 곡선 전체는 방향마다 달라지는 반응이고,<br>특잇값은 그 곡선을 가두는 위아래 두 경계입니다. | 곡선 전체와 두 경계는 다릅니다<br>방향별 반응 전체 ≠ 특잇값 |
| 01:04–01:11 | 입력 방향을 한 바퀴 모두 훑어도<br>출력 길이는 두 경계 밖으로 나가지 않습니다. | 한 바퀴를 훑어도 넘지 않습니다<br>0.5 ≤ ‖Ax‖ ≤ 3 |
| 01:11–01:17 | 타원은 모든 방향의 반응을 남기고,<br>특잇값은 그 스캔에서 발견한<br>최대와 최소를 남깁니다. | 타원에서 찾은 최대와 최소<br>σ₁ = max ‖Ax‖     ·     σ₂ = min ‖Ax‖ |
| 01:17–01:25 | 특잇값은 타원 위의 모든 값이 아니라,<br>행렬이 만들 수 있는 변화의 범위를<br>위와 아래에서 정하는 값입니다. | 변화의 범위를 정하는 두 값<br>σ₂ ≤ ‖Ax‖ ≤ σ₁ |

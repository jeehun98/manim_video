# 신경망 내부의 계산 07 — Probing & Intervention 상세 영상화 콘티

총 175초 (2분 55초) · 16:9 · Manim 기반 · 제공한 발화 타임스탬프 32개 구간에 대응

영상 제목: 신경망이 알고 있는 정보와 실제 계산에 사용하는 정보를 구별하는 방법 — Probing & Intervention

이번 7편은 6편의 Circuit Tracing과 연결되지만, 이전 편의 내용을 직접 복습하지 않아도 이해할 수 있도록 구성하는 게 좋아.

영상 전체에서 하나의 Transformer와 내부 활성화 벡터 \\(h\\)를 유지하고, 이 벡터에 대해 두 가지 서로 다른 실험을 진행해.

- Probing: 모델을 고정한 상태에서 활성화에 어떤 정보가 들어 있는지 읽어본다.
- Intervention: 활성화의 일부 정보를 제거하고 모델의 나머지 계산과 출력을 비교한다.

마지막에는 정보의 판독 가능성 → 개입의 효과 → 계산 메커니즘의 검증이라는 세 단계로 정리해 8편의 학습 유도 검증 문제로 연결할 거야.

## 1. 전체 영상의 시각적 설계

이번 편에서 끝까지 재사용할 분석 구조

상단은 별도의 Probe가 활성화에서 정보를 읽는 과정, 하단은 변환된 활성화를 원 모델의 뒷부분에 전달하는 개입 실험을 의미한다.

### 그래픽 규칙

| 요소               | 색상  | 역할             |
| ---------------- | --- | -------------- |
| 원래 Transformer   | 회색  | 분석 대상, 파라미터 고정 |
| 원래 활성화 \\(h\\)   | 보라색 | 두 실험의 공통 출발점   |
| Linear Probe     | 청록색 | 정보 판독          |
| 품사·수 정보의 제거 방향   | 주황색 | 개입 대상          |
| 변환된 활성화 \\(h'\\) | 노란색 | 개입 이후의 표현      |
| 모델 출력·예측 변화      | 파란색 | 행동 비교          |
| 손상된 다른 정보        | 붉은색 | 개입의 교란 가능성     |

가장 중요한 화면 규칙: Probe의 예측 결과와 원래 Transformer의 예측 결과를 절대 같은 출력창에 표시하지 않는 것이 좋아. 두 결과는 답하는 질문부터 다르기 때문이야.

### 장면 05. 복수형 정보가 내부에 표현되어 있을까?

0:15–0:21

발화: “그렇다면 신경망의 내부 활성화에도 단수형과 복수형을 구별할 수 있는 정보가 들어 있을까요?”

문장이 Transformer에 들어간다.

특정 층의 특정 위치에 대응하는 활성화 벡터를 꺼내 확대한다.

여기서 처음부터 `h₂ = plural`처럼 한 뉴런에 의미를 지정하지 않는 게 중요해. 앞선 4편에서 배운 Superposition과 모순되기 때문이야.

### 장면 07. Transformer 고정, 활성화 수집

0:24–0:30

발화: “먼저 기존 신경망의 특정 층에서 활성화 벡터를 수집하고, 원래 모델의 가중치는 고정합니다.”

Frozen Transformer

\\(h^{(1)},h^{(2)},\ldots\\)

활성화 샘플

- `The cat is sleeping`, `The cats are sleeping` 등 여러 입력 문장을 보여준다.
- 각 문장에서 대상 단어 위치의 활성화를 수집한다.
- 수집된 활성화에 단수 또는 복수 라벨을 붙인다.
- Transformer에는 자물쇠 아이콘을 유지한다.

연출 주의: Probe 학습용 샘플을 수집한다는 뜻이지, 원래 언어 모델을 새로 학습한다는 뜻은 아니야.

### 장면 08. 별도의 작은 분류기 학습

0:30–0:37

발화: “그다음 이 벡터를 입력받아 단수형과 복수형을 구분하는 작은 선형 분류기를 따로 학습시킵니다.”

Linear Probe 학습 구조

\\(h\\)

\\(w^\top h+b\\)

Singular

Plural

\\[ p(\mathrm{plural}\mid h)=\sigma(w^\top h+b) \\]

애니메이션 순서

1. 활성화 벡터가 선형 분류기에 들어간다.
2. 가중치 \\(w\\)와 편향 \\(b\\)가 나타난다.
3. 예측이 단수형 또는 복수형으로 분류된다.
4. 분류 오류를 기준으로 Probe의 \\(w,b\\)만 업데이트한다.
5. Transformer 쪽 가중치는 끝까지 고정된 상태를 유지한다.

### 장면 16. 제거 전후의 계산을 비교한다

1:07–1:14

발화: “정보가 존재하는지를 확인하는 대신, 그 정보를 제거했을 때 모델의 계산이 어떻게 달라지는지 살펴보는 겁니다.”

Transformer를 앞부분과 뒷부분으로 분리한다.

앞부분의 출력에서 활성화 \\(h\\)가 생성된다.

두 경로에서 동일한 Transformer 뒷부분의 파라미터를 사용한다는 것을 나타내기 위해 색상과 모양을 동일하게 유지한다.

### 장면 18. 품사 정보를 읽어내는 방향 찾기

1:18–1:23

발화: “예를 들어 신경망의 활성화에서 품사 정보를 읽어낼 수 있는 방향들을 찾습니다.”

여기서 예제는 앞서 사용한 단수·복수 구분에서 품사(POS) 정보로 전환돼.

혼동을 피하려면 화면에서 `Number (Singular / Plural)` 분석 라벨을 지우고 `POS (Noun / Verb / Adjective …)`로 바꿔줘.

품사 정보와 관련된 선형 방향 찾기

고차원 활성화를 2차원에 단순화한 가상 분포. 품사가 실제로 이렇게 군집된다는 뜻은 아니다.

서로 다른 품사의 샘플들이 모여 있고, Probe가 이들을 구별하는 방향을 찾는 모습을 보여준다.

### 장면 19. 품사 정보를 선형적으로 읽기 어렵게 만든다

1:23–1:28

발화: “그다음 활성화 벡터를 변환해, 해당 품사 정보를 선형적으로 읽어내기 어렵게 만듭니다.”

방금 찾은 품사 구분 방향을 주황색으로 강조한다.

모든 활성화 점을 그 방향에 수직인 부분공간으로 투영한다.

\\[ h'=Ph \\]

P: 선택한 선형 판독 방향을 제거하도록 구성한 투영 연산자

애니메이션에서는 다음 흐름을 사용한다.

1. 품사 구분 방향 \\(w\\)가 등장한다.
2. 활성화 벡터를 \\(w\\)와 수직인 방향에 투영한다.
3. 투영 이후 기존 선형 Probe의 구분 능력이 약해진다.
4. 새로운 Probe를 다시 학습해도 선형적으로 해당 속성을 예측하기 어려운지 확인하는 모습을 짧게 보여준다.

실제 Amnesic Probing은 Iterative Null-space Projection(INLP)을 이용해 여러 판독 방향을 반복해서 중화하는 접근이야. 단 한 번의 투영으로 모든 품사 정보가 완벽히 삭제된다고 표현하지 않는 것이 중요해.&#x20;

### 영상 생성 시 가장 중요한 네 장면

장면 08 — Linear Probe 학습: 별도 분류기만 학습한다는 점을 명확히 보여줘야 해. 원 모델은 고정되어 있고, 높은 정확도는 판독 가능성에 대한 증거라는 사실이 핵심이야.

장면 19 — 정보 제거 투영: 특정 정보를 없애기 위해 뉴런을 삭제하는 것이 아니라 활성화 공간을 변환한다는 점을 보여줘. `h' = Ph`가 이번 영상의 핵심 수학적 시각화야.

장면 25\~27 — 개입의 한계: 하나의 방향에 다른 정보도 함께 들어 있을 수 있다는 점을 보여줘야, 개입으로 인한 행동 변화와 완전한 인과적 설명의 차이가 전달돼.

장면 35\~37 — 학습 유도로 돌아가기: 3편의 Patterning 그림을 재사용해, 원하는 회로를 형성했다는 주장에 어떤 검증이 필요한지라는 8편의 질문을 남겨줘.

이렇게 제작하면 7편은 별개의 프로빙 기법 소개가 아니라, 신경망 내부에서 정보를 관찰하는 것과 실제 계산의 원인을 설명하는 것 사이의 차이를 정리하는 편으로 기능해.

그리고 쇼츠들을 그대로 합쳤을 때도 6편의 계산 경로 추적 → 7편의 인과적 근거 구분 → 8편의 계산 형성 검증으로 자연스럽게 이어질 수 있어.

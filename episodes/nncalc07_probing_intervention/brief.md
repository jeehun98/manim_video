# Probing & Intervention · 제작 기준

사용자 확정 37개 발화·175초(2:55)·30fps. 콘티 첫머리의 32개 표기보다 실제 원고와 말미의 37개 구간을 따른다.
일반 1920×1080, 쇼츠 1080×1920를 각각 배치한다. 음원 미제공으로 자막 포함 무음. 발음 원고에는 시각·장면 제목을 넣지 않는다.

## 여섯 주장

0–21초: 단수·복수 정보를 판독할 수 있는지 질문한다.
21–61초: 고정된 모델의 활성화에서 별도 선형 Probe를 학습한다. 새로운 자료의 높은 정확도는 선형 판독 가능성의 근거다.
61–94초: 읽기에서 제거 개입으로 질문을 바꾼다. 여기서 실험 속성을 Number에서 POS로 명시적으로 전환한다.
94–129초: 가상 개입 결과 A/B와 다른 정보의 동반 손상 가능성.
129–155초: 판독·행동 영향·계산 경로라는 세 질문을 구분한다.
155–175초: 데이터로 학습을 유도한 뒤 내부 형성과 역할까지 검증한다.

## 수학과 정확성

- 원래 모델의 가중치는 고정한다. 학습되는 것은 별도의 Probe w,b다. p(plural|h)=σ(wᵀh+b) 예시를 쓴다.
- Probe의 단수/복수 판독창과 원래 모델의 토큰 예측창을 분리한다. Probe 결과가 원 모델 출력에 전달되는 화살표를 만들지 않는다.
- The/cats/are/sleeping은 문장 구성 요소를 나눈 예시다. 실제 tokenizer의 네 토큰이라는 주장은 하지 않는다. h의 특정 좌표를 복수형 뉴런으로 단정하지 않는다.
- 판독 정확도는 조건문으로 표현하며 실측 비율·수치를 만들지 않는다. 학습에 쓰지 않은 문장·자료에서의 평가를 표시한다.
- POS 투영 그림은 고차원 공간을 설명하는 2D 가상 예시다. w=(1,1)/√2, P=I−wwᵀ, h′=Ph. P²=P, Pᵀ=P, Pw=0, wᵀh′=0을 확인한다.
- 투영 한 번이 모든 POS 정보를 없앤다는 뜻이 아니다. INLP의 Probe 재학습·투영 반복과 새 Probe 평가를 명시한다. 남은 비선형 정보나 다른 표현의 보완 가능성도 유지한다.
- 같은 입력과 같은 뒷부분 모델 가중치로 h/h′를 비교한다. 표현을 바꾸는 것이며 뉴런을 삭제하거나 원 모델을 재학습하는 것이 아니다.
- 출력 분포 A/B는 가상 예시다. 변화가 크면 제거한 표현의 영향에 관한 근거이지만, POS만의 효과라고 단정하지 않는다. 변화가 작아도 정보 미사용을 증명하지 않는다.
- u=(1.3,.1)은 제거 방향 성분을 갖는 다른 정보 방향의 설명 예시다. Pu≠u라는 점으로 동반 손상을 보여준다.
- 프로빙과 개입을 우열 관계로 나열하지 않는다. 서로 다른 질문과 증거를 제공하며 경로 가설 및 대조 실험과 결합한다.
- 데이터 비중 조절 뒤에는 새로 학습하는 단계를 둔다. 이미 학습한 회로가 슬라이더로 즉시 변하는 것처럼 표현하지 않는다.
- 마지막 제공 발화는 유지하며 별도의 이전 편 복습·다음 편 예고는 추가하지 않는다.

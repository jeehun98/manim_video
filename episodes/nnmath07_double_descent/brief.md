# 신경망의 수학 07 제작 기준

## 제목과 핵심

- 제목: **모델은 클수록 과적합된다? 실제로는 다시 좋아질 수 있습니다 — Double Descent**
- 익숙한 U자형 과적합 그림의 오른쪽 끝에서 관찰을 멈췄다는 점을 시각적 반전으로 쓴다. 크기를 더 늘렸을 때 일부 설정에서 Test Error가 다시 감소할 수 있다는 결과를 **Double Descent**로 명명한다.
- 화면의 중심 대립은 `잡음까지 맞출 능력 ↑`와 `훈련 데이터를 만족하는 해의 선택 폭 ↑`다. 어느 하나만으로 test 성능을 결정한다고 말하지 않는다.
- 마지막에는 큰 모델로 학습한 뒤 파라미터를 줄일 수 있는 경우를 다음 화 질문으로 연결한다.

## 정확성 기준

- Double Descent는 모델 크기 증가에 따른 Test Error의 가능한 형태다. 모든 데이터셋·모델·학습 설정에서 나타나는 법칙이 아니다.
- 훈련 데이터를 거의 완벽히 맞출 수 있는 부근은 **interpolation threshold**에 해당하는 직관이다. 정확한 위치는 유효 용량, 데이터 수, 노이즈, 최적화 등에 따라 달라진다. 영상에는 용어를 크게 도입하지 않는다.
- 장면 7의 진동하는 곡선은 높은 Test Error를 낳을 수 있는 개념적 예시다. 보간 경계의 모든 모델이 이런 모양인 것은 아니다.
- 모델이 커지면 훈련 데이터의 잡음까지 표현할 능력이 늘 수 있고, 같은 훈련 제약을 만족하는 파라미터 해도 더 다양해질 수 있다. 후자가 일반화 개선을 자동으로 보장하지 않는다. 최적화와 암묵적 편향 등이 어떤 해를 선택하는지도 중요하다.
- 이전 U자 곡선은 일부 크기 범위에서 유효한 관찰이다. 오른쪽으로 확장했을 때 제2하강이 나타나는 경우를 보여준다.
- 마지막 100M→50M→10M 압축 장면은 **가능한 사례를 묘사하는 개념적 연출**이다. 모든 모델이 90%의 파라미터를 제거하고 성능을 유지한다는 실험 결과로 제시하지 않는다.

## 제작 형식

- 기존 nnmath 시리즈 색·폰트·9×16 프레임·상하단 레이아웃을 따른다.
- 14장면, 106초, 전환 포함 장면당 약 6–9초. 6화 대본 길이와 실제 TTS 93초를 기준으로 7화 발화 약 99초를 추정하고 7초의 화면 여유를 둔다. 7화 TTS 실측 오디오는 아직 없어 구간 경계는 초안이다.
- 360×640 미리보기, 1080×1920 30fps 무음 최종본. 대본·SRT·TTS 원고는 별도다.

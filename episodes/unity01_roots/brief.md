# 단위근 쇼츠 제작 기준

173초, 9:16, 1080×1920, 60fps. 제공된 문장 종료 초를 자막과 렌더에 적용한다. 내레이션 음원은 제공되지 않았다.

| 구간 | 화면 |
| --- | --- |
| 0–13 | 방정식과 정오각형의 대비 |
| 13–36 | 세제곱 방정식 인수분해, 판별식, 포물선과 복소근 |
| 36–50 | 복소평면에 세 해를 배치하고 거리와 120° 간격 측정 |
| 50–71 | 한 점에서 직교좌표, 극형식, 지수형식 연결 |
| 71–81 | 곱셈의 확대와 회전, 같은 복소수의 거듭제곱 |
| 81–108 | 크기·각도 조건, 입력과 출력의 1:3 회전, 근의 일치 |
| 108–133 | 양의 정수 n에 대한 일반식과 정다각형 비교 |
| 133–151 | 비에타 관계와 벡터의 평행이동으로 다섯 근의 합 확인 |
| 151–163 | 72° 회전의 순열과 곱셈에 대한 닫힘 |
| 163–173 | 방정식, 정다각형, 회전 대칭의 연결 |

단위원 위의 위치는 정확한 각도로 계산한다. 차수가 바뀔 때 새 차수의 근을 별도로 표시한다. 다섯 벡터의 합은 방향과 길이를 보존한 평행이동으로 보여준다.

# 씬별 제작 기준

확정 입력: 사용자 제공 35문장과 종료 시각. 총 162초. 세로 프레임 9×16, 본문 y ≥ −4.9, 자막 중심 y = −6.15. 원 대본과 타이밍 변경 없음. 모든 씬 독립 렌더·교체 가능.

| 씬 | 초 | 주장과 화면 |
| --- | --- | --- |
| 01 | 0–15 | 2·3·4차의 근호 공식에서 5차의 질문으로 전환하고 해의 대칭을 제시 |
| 02 | 15–32 | 2·3의 순서가 달라도 합과 곱은 동일. 유리수 두 근의 교환을 갈루아 대칭으로 오인하지 않도록 표시 |
| 03 | 32–50 | 3개 해의 6배열, 4!·5!, 순열 합성의 닫힘 |
| 04 | 50–61 | 모든 순열 중 기준체의 대수적 관계를 보존하는 변환이 갈루아 군 |
| 05 | 61–80 | ±√2의 교환은 유리수 계수 관계를 보존 |
| 06 | 80–94 | √2를 기준으로 고정하면 교환이 금지되고 id만 남음 |
| 07 | 94–107 | 근호 풀이의 조건을 정규부분군 열·가환 몫군과 연결 |
| 08 | 107–121 | 일반 5차의 S₅와 그 안의 짝순열 정규부분군 A₅ |
| 09 | 121–127 | A=(123), B=(345)의 비가환 합성. 몫군의 가환성이 필요함을 명시 |
| 10 | 127–138 | S₄의 가환 몫군 열과 S₅의 비가환 A₅ 몫을 비교 |
| 11 | 138–154 | 일반 근호 공식의 부재와 특정 5차·수치 근사의 가능성을 구별 |
| 12 | 154–162 | 해의 대칭 구조로 풀이 가능성을 밝히는 갈루아 이론. 마지막 1초 정지 |

우선 검수: 06의 고정 표시·교환 차단, 09의 합성 결과, 10의 몫군 표기. 자동 검사: 35문장 연속성·SRT 일치·자막 표시 시각·프레임 수·해상도·전체 디코딩. 후반 시각 검수에서 결론·예외의 문구도 확인한다.

# 씬별 제작 기준

대본과 종료 시각은 사용자 제공값. 총 165초. 세로 9×16, 본문 y≥−4.9, 하단 자막 중심 y=−6.15. 각 씬은 독립 렌더·교체 가능.

| 씬 | 초 | 주장·화면 |
| --- | --- | --- |
| 01 | 0–24 | 추상 상태 그래프에서 도달 가능성과 변하지 않는 규칙의 필요성 제시 |
| 02 | 24–45 | 합법적 슬라이드 시연 후 외부에서 14·15를 교환한 목표 설정 |
| 03 | 45–69 | ABC 교환 및 같은 BAC를 만드는 1회·3회 경로 비교 |
| 04 | 69–84 | ABC→BAC는 홀순열, ABC→BAC→BCA는 짝순열 |
| 05 | 84–102 | 1회 슬라이드는 빈칸과 숫자의 교환. 고정 칸의 체스판 색 도입 |
| 06 | 102–117 | 빈칸 색과 전체 순열이 함께 반전. 빈칸 원위치는 짝수 이동 필요 |
| 07 | 117–137 | 목표의 홀순열과 빈칸 원위치의 짝순열 조건 충돌 |
| 08 | 137–151 | 실제 이동에 따라 p·c 동시 반전과 I=p⊕c=0 유지 시연. 불변량 명명 |
| 09 | 151–157 | 실제 두 종류 상태에서 계산한 I=0·I=1 분류 개념도 |
| 10 | 157–165 | 변하지 않는 성질을 찾는 사고방식으로 완결. 마지막 1초 정지 |

대표 저해상도 검수: 02의 외부 교환 구분, 06의 이동·카운터 동기화, 08의 두 값과 불변량. 자동 검수: 모든 이동의 인접성·p/c 반전·I 보존, 대본/SRT 일치와 시간 연속성, 자막 시각/범위, 각 씬·최종 영상의 프레임 수/길이/해상도 및 전체 디코딩.

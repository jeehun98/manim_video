# 신경망의 수학 04 제작 기준

## 제목과 역할

- 제목: **서로 다른 두 신경망 사이에도 정답이 있을까? — Mode Connectivity**
- 목표: 서로 다른 초기값에서 얻은 좋은 해 두 점을 직선으로 보간해 보고, 직선의 Loss 장벽과 우회하는 저손실 경로를 순서대로 발견하는 실험처럼 보여준다.
- 핵심 식은 `θ(t)=(1−t)θA+tθB` 하나다. 이것은 두 점 사이의 **직선 보간**을 정의하며 Mode Connectivity 자체를 보장하는 공식은 아니다.
- 2화의 해 집합과 연결하고, 다음 편의 방향별 민감도 질문으로 끝낸다.

## 정확성 기준

- 같은 구조·데이터·목표로 학습해도 초기값이 다르면 서로 다른 파라미터에 도달할 수 있다. 두 결과가 모두 좋은 해라는 것은 이 영상의 실험 설정이다.
- 두 끝점의 Loss가 낮아도 직선 보간의 중간 Loss가 낮다는 보장은 없다. 화면의 봉우리는 **가능한 예시**다.
- 직선에 장벽이 보인다는 사실만으로 전체 고차원 공간에서 해가 분리됐다고 결론낼 수 없다.
- 곡선 경로에서 낮은 Loss를 유지하는 연결은 특정 모델·학습 설정에서 발견되는 현상이다. 모든 두 해를 연결할 수 있다고 주장하지 않는다.
- `θA`, `θB`는 3화처럼 반드시 같은 함수를 뜻하지 않는다. 이번 편은 둘 다 좋은 성능을 내는 해 사이의 Loss 경로를 다룬다.
- 마지막의 가파른/평평한 방향은 국소적인 Loss 민감도를 예고한다. Hessian 용어는 이 편에서 설명하지 않는다.

## 연출·형식

- 기존 nnmath의 세로 프레임, 상단 시리즈 표시, 하단 자막, 색상을 따른다.
- 장면 전환 0.1–0.4초를 각 구간에 포함한다. 사용자가 확인한 TTS 길이 111초에 맞춰, 공백 제외 대본 글자 수 비율로 각 장면을 7–12초로 배분했다. 총 114초로 3초의 여유를 둔다. 개별 TTS 타임코드가 없어 구간 경계는 추정치다.
- 360×640 미리보기, 1080×1920 30fps 무음 최종본. TTS와 SRT는 별도다.

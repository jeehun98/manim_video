| 00:00–00:08 | 서로 거의 같은 두 입력을 놓아보겠습니다.<br>하나는 x, 다른 하나는 x에 작은 변화를 더한 값입니다. | 거의 같은 두 입력<br>x   /   x + εvᵢ |

| 00:35–00:43 | 따라서 출력의 차이는<br>εσᵢuᵢ입니다. | 작은 차이도 같은 배율로<br>Δy = εσᵢuᵢ |

| 00:52–01:01 | 특잇값이 0.2이면 차이는 5분의 1로 줄어듭니다.<br>출력에서 두 입력의 차이가 훨씬 작아집니다. | 특잇값이 0.2이면<br>‖Δy‖ / ‖Δx‖ = 0.2 |

| 01:20–01:29 | 아주 작은 특잇값은 차이를 약하게 만들지만,<br>정확히 0일 때만 그 방향의 차이가 완전히 사라집니다. | 작아도 0은 아닙니다<br>작은 값: 구분이 어려움     /     0: 구분 불가능 |

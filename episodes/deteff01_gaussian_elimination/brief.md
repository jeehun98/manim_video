# 제작 기준

162초 · 9:16 · 1080×1920 · 30fps. 제공 대본과 발화 종료 시각을 유지한다. 무음 영상, 발음 원고와 기호 자막 별도. 확정 대본의 이전 내용 언급은 유지하고 추가 예고는 넣지 않는다.

핵심: 행 덧셈 불변성 → 소거 → 상삼각행렬 → 항등순열만 남음 → 대각선 곱. 계산 대상 행렬은 소거·순열·LU 장면에서 동일한 A=[[2,1,1],[4,3,3],[2,2,3]], U=[[2,1,1],[0,1,1],[0,0,1]]를 사용한다. L=[[1,0,0],[2,1,0],[1,1,1]]이며 A=LU이다.

두 행은 서로 다르다(i≠j). 행 배수 k≠0은 되돌릴 수 있는 기본 행 연산이며 행렬식은 k배. 교환마다 −1. 피벗 교환이 필요 없는 현재 사례에만 A=LU를 쓰며 일반적으로 PA=LU가 필요할 수 있음을 작게 표기한다.

전단 그림은 별도의 E(k)=[[1,k],[0,1]], det E=1의 단위 정사각형이다. 원래 A의 실제 이미지로 오해하지 않도록 별도 예시라고 표시한다. 실제 소거와의 연결은 왼쪽 기본행렬 곱 det(EA)=det E det A로 설명한다.

상삼각행렬의 항등순열 이외 선택에는 반드시 대각선 아래 원소가 포함된다. 위쪽 원소는 지우지 않는다. 일반 대각선에 0이 있을 수도 있으므로 비영 항이 반드시 존재한다고 주장하지 않는다. 0을 피할 수 있는 유일한 후보가 대각선이다.

10!=3,628,800. 직접 순열 전개의 항 개수 n!와 소거의 통상적인 산술 연산량 O(n³)을 구분한다. 비트 복잡도·실행시간을 수치 비교하지 않는다. 부동소수점 피벗·오차 설명은 본 영상 범위 밖이다.

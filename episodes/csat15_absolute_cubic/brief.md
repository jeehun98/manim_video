# EP.15 제작 기준

사용자 제공 75개 문장 종료 시각 준수. 339초, 1920×1080, 30fps, 16:9. 음원 미제공으로 무음·화면 자막.

연속함수에서 A,B를 양·음 영역의 양의 넓이로 두면 ∫|f|=A+B, |∫f|=|A−B|. 두 값이 다름⇔양·음값 모두 존재. 조건(가)의 p집합=(0,3). 각 부호변화근 r가 만드는 (r−3,r)의 합집합이 (0,3)이므로 모든 부호변화근 r=3. f(0)=0이고 0은 부호변화근일 수 없어 중근. 삼차식 f=kx²(x−3), k≠0. 조건(나)의 q집합=(0,1) → k>0, min_[0,3]f=−1. f′=3kx(x−2), min=f(2)=−4k → k=1/4 → f(6)=27(④).

전 실수에서 삼차함수의 최솟값으로 표시하지 않으며 반드시 [0,3]을 명시한다. k부호 확정 전 그래프는 방향 예시라 표시. 수직이동 개념도에 k=1/4 형태를 내부 계산에 사용하지만 계수·최저점 좌표는 해당 유도 전 공개하지 않음. 음수영역 소멸은 실제 근과 적분영역으로 구현. p=0,3과 q=0,1 경계에서 양·음 동시존재가 아님을 표시.

40개 독립 교체 가능 씬. 보조 이동구간 장면은 91–99초 씬에 통합, 전체 길이 유지. 이전 편 복습·다음 예고 없음.

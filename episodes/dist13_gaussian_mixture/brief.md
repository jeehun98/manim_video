# 분포의 수학 13 제작 기준

- 4부 **하나의 분포를 넘어** 첫 편. 제목에 핵심 용어 `Gaussian Mixture Model`을 포함한다.
- 학습 목표: 서로 떨어진 두 데이터 군집을 하나의 Gaussian으로 모델링하면 가운데 빈 곳에도 밀도가 생긴다는 문제에서 출발한다. 두 단순 성분을 가중치를 두고 섞으면 하나의 복잡한 분포가 된다는 관점이 주인공이다.
- 화면 예시는 성분 평균 `μ₁=(-2,1)`, `μ₂=(2,-1)`, 같은 성분 공분산 `Σ=[[0.36,-0.11],[-0.11,0.22]]`, 혼합 가중치 `π₁=0.4`, `π₂=0.6`이다. 점은 고정 난수로 24개와 36개를 생성한다. 점의 개수 비율은 모델 가중치와 일치한다.
- 단일 Gaussian의 표시용 평균과 공분산은 이 혼합분포의 정확한 1·2차 모멘트 `μ=π₁μ₁+π₂μ₂`, `Σ_single=Σ+π₁π₂(μ₁−μ₂)(μ₁−μ₂)ᵀ`를 사용한다. 두 군집 사이에서는 단일 Gaussian이 밀도 최고점을 갖지만 각 성분 밀도는 낮다. 단일 Gaussian을 실제 최적 적합으로 주장하지 않는다.
- 두 정규화된 밀도 `p₁,p₂`는 적분이 각각 1이므로 무가중 합의 적분은 2다. `πₖ≥0`, `Σₖπₖ=1`이면 `p(x)=Σₖπₖ N(x|μₖ,Σₖ)`는 정규화된 혼합밀도다. 여기서 `+`는 밀도의 가중합이지 각 관측값을 합산한다는 뜻이 아니다.
- 1차원 프로필은 두 성분과 가중합의 두 봉우리 구조를 설명하는 개념도다. 2차원 점구름의 정확한 밀도 단면 그래프는 아니다.
- 마지막 점 `x`는 성분을 확정 배정하지 않는다. `P(z=k|x)`라는 사후 성분 확률의 질문만 제시한다. 혼합비 `πₖ`와 개별 점의 책임도는 다른 값이며, 수치 계산은 14화로 넘긴다.
- 흐름: 두 군집 → 단일 Gaussian의 빈 공간 문제 → 성분 두 개 → 합의 정규화 문제 → 가중치 → 혼합밀도 → GMM 이름 → 단순한 성분들의 복잡한 설명 → 점의 잠재 출처 질문 → soft assignment/Responsibility.
- 실제 TTS 길이 41초에 맞춰 영상은 43초다. 구간 경계는 `2.7,6.1,8.9,12.1,16.1,19.8,23.0,25.8,29.0,32.1,35.9,38.1,43.0`초다. 문장 길이에 맞춰 설명 장면을 압축하고 마지막 질문 뒤 약 2초를 남긴다. 1080×1920, 30fps, 무음.

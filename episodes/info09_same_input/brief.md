# 정보이론 09 — 같은 입력은, 가공해도 같은 출발점이다

- 목표: 가공의 실제 동작을 따라가며 합쳐진 구분이 뒤의 계산만으로 돌아오지 않는 이유를 보여준다. 정보 감소라는 문장이나 공식을 도입으로 쓰지 않는다. 네 원본 상태를 두 그룹으로 합친 뒤, 두 개의0을 같은 연산기에 통과시킨다.
- 원본은 A/B/C/D 각1/4. f(A)=f(B)=0,f(C)=f(D)=1. Y=0만 받은 관측자는 A/B 중 무엇인지 알 수 없다. 예측·추측을 출력할 수 있지만 이 균등 예시에서 Y만으로 A/B를 정확하게 식별하는 것은 불가능하다.
- 후속 가공 g(y)=(5y+3)²+8. 화면 연산 단계는 ×5,+3,제곱,+8. 실제0 경로0→0→3→9→17,1 경로1→5→8→64→72. 내레이션은 값이 변하는0→3→9→17을 읽되 ×5의0유지도 화면에 표시한다. A/B 유래0은 같은 모양·같은 색으로 처리하고 원본 표시는 가공기의 입력과 분리한다. 색·분기별 연산·숨겨진 원본 태그로 정보가 우회하지 않는다.
- 17이라는 더 큰 숫자를 얻는 것은 상태를 더 구별하게 되는 것과 다르다. g는 Y={0,1}에서 단사이므로 후속 결과{17,72}는 정확히 같은 두 그룹을 구별한다. I(X;Y)=I(X;g(Y))=1bit. 원본 그대로면 I(X;X)=H(X)=2bits.
- 대조 가공은 두 Y값을 모두17로 만드는 상수함수다. 결과만 보면 원본 네 후보가 모두 남고 I(X;Z)=0. 이는 g와 별도 비교 경로다. 0→17,1→72인 같은 함수가 갑자기 모두17을 출력한다고 혼용하지 않는다.
- 일반 DPI 조건은 X→Y→Z Markov chain, 즉 Z는Y와 X에 독립인 추가 난수만 이용하거나 Y의 결정적 함수일 수 있다. 본 영상은 결정적 유한 이산 예시다. 새로운 관측·X로부터의 우회 입력·원본별 다른 연산은 없다. 독립 난수로 Z의 엔트로피를 키워도 X에 대한 상호정보량이 늘지는 않는다. 영상에서 감소를 비교하는 양은 I(X;·)이며 결과의 숫자 크기·문자열 길이·변수 자체의 모든 엔트로피가 아니다.
- 일반적으로 서로 다른Y들을 합쳐도 X와 무관한 차이만 버리면 I(X;Y)는 유지될 수 있다. 이 예시에서는 Y의 두 값이 서로 다른 원본 그룹을 완전히 구별하므로 이를 합치면 정보가 엄격히 감소한다. 원안의 모든 합치기가 항상 엄격한 감소를 유발한다는 표현은 사용하지 않는다.
- 신경망 연결은 고정된 입력만 처리하는 고정 가중치의 표현 변환으로 한정한다. 구체 그림은 A(0,0),B(1,1),C(0,1),D(1,0)에서 h=(x₁−x₂)²를 계산해 A/B는0,C/D는1로 정리하는 XOR 특징이다. 선형으로 읽기 쉬운 표현은 될 수 있으나 네 원본 좌표는 복원되지 않는다. 원본에 대한 정보2→1bit, 그룹 라벨에 대한 정보1→1bit. 예시는 실제 학습 실험이나 모든 신경망의 개선 보장이 아니다. 외부 학습 자료가 지식을 제공하는 상황과 새 관측 없이 가공하는 DPI 설정을 혼동하지 않는다.

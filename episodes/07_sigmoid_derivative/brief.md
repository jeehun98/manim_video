# Sigmoid 02 — 검토 및 제작 메모

- 100초, 1080×1920, 30fps. 첫 편과 같은 색상·글꼴, 한국어 자막, 무음 마스터.
- 대본의 변화율을 `출력 변화량 / 입력 변화량`으로 명시했다. 유한 구간의 평균 변화율과 입력 변화량이 0으로 접근할 때의 미분계수를 구분했다.
- 국소 근사 `Δy ≈ σ′(x) Δx`에만 압축률 해석을 적용한다. 작은 미분계수일수록 작은 입력 차이가 출력에 덜 남는다. 정확한 실수 연산에서 유한 입력의 미분계수는 0이 아니다.
- 확대 그래프는 x=0 주변의 변위 좌표 `(x, σ(x)−0.5)`를 사용한다. 눈금은 가로 ±0.2, 세로 ±0.05이며 화면상의 각도 자체를 기울기 수치로 해석하지 않는다.
- `s(1−s)=0.25−(s−0.5)²`로 최댓값 0.25를 뒷받침한다.
- 수치 검토: x=0에서 Δx=0.01의 실제 출력 변화는 약 0.002499979. x=±5의 미분계수는 약 0.006648057이며 같은 작은 입력 변화의 1차 근사는 0.0000664806.
- 다음 편의 현상을 이번 편에서 단정적으로 설명하지 않고 “기울기가 거의 0이라면?”으로 마무리한다.

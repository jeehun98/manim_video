# 정답을 찾는 것과 이해하는 것 01 — 제작 기준

- 목표: 개별 소수 위치의 불규칙성과 전체 개수의 점근적 규칙성의 대비.
- 구성: 1~100 숫자 → 소수 점 → 정확한 계단 → 주황색 근사 → 100/1만/100만 축 재조정 → 비율 → 결론.
- 9:16, 1080×1920, 30fps. 무음 마스터. 사용자 요청에 따라 콘티 시간초는 고정하지 않는다.
- 체로 100만 이하 소수와 누적 개수를 계산한다. 계단은 실제 소수 위치에서만 상승한다.
- x/ln x는 x≥2에서 그린다. 실제 개수와 같은 데이터 축을 사용한다.
- 비율 화면의 가로축은 로그 눈금, 세로축은 1~1.2 고정. 연결선은 다섯 표본을 잇는 안내선이다.
- 100→1000에서 비율이 증가하는 모습을 유지한다. 상대 오차의 단조 감소와 절대 오차 감소를 주장하지 않는다.
- 상대 오차의 정의는 |π(x)−x/ln x|/π(x). 화면에서는 비율을 사용한다.

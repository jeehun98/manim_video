# Sigmoid 04 — 값에서 분포로

100초, 1080×1920, 30fps, 한국어 자막, 무음 마스터.

## 대본 검토

중앙에서 차이가 더 많이 남는다는 표현은 양끝과의 상대적 비교다. 모든 위치에서 Sigmoid 미분계수는 0.25 이하이며, 입력 차이를 확대한다는 의미가 아니다.

입력 범위를 넓히면 언제나 같은 모양의 출력이 된다는 일반화는 피한다. 영상에서는 구체적으로 평균이 0인 정규분포의 표준편차를 바꾸며, 평균을 옮긴 세 번째 사례도 보여준다.

마지막은 입력 분포가 주어졌을 때 출력 분포를 계산할 수 있다는 설명으로 수정했다. 다음 편에서는 표준 로지스틱 분포의 누적분포함수가 Sigmoid라는 점을 이용해 균등분포로 이어갈 수 있다. 이번 영상에서는 그 결론을 공개하지 않는다.

## 데이터와 표시

- 정규분포의 `(i+0.5)/240` 분위수 240개를 고정해 사용한다. 무작위 추출 표본이 아니라 분포를 안정적으로 보여주는 대표 표본이다.
- A: 평균 0, 표준편차 0.5. B: 평균 0, 표준편차 2.5. C: 평균 2, 표준편차 0.5.
- 입력 히스토그램은 [-8,8], 구간 폭 0.5. 출력은 [0,1], 구간 폭 0.05. 모든 사례에서 축과 구간 폭은 고정된다.
- 세로축은 구간별 표본 개수이며 확률밀도가 아니다. 입력과 출력은 서로 다른 구간 폭을 사용하므로 막대 높이 자체를 압축률로 해석하지 않는다.
- 각 입력값에 Sigmoid를 적용해 출력을 직접 계산한다. 총 240개가 모두 유지되며 표시 범위 밖 표본은 없다.
- 점의 가로 위치는 실제 값, 세로 위치는 같은 구간 안에서의 누적 순서다. 파랑과 분홍으로 음수·양수의 대응을 보여준 뒤 히스토그램으로 정리한다.

# 신경망의 역설 05 — 좋은 해는 점이 아니라 영역이다?

## 제작 기준

- 사용자 확정 대본 25문단과 누적 종료 시각 5·11·15·20·24·29·37·39·43·47·53·58·61·67·71·76·80·83·89·95·101·104·108·112·118초를 사용한다. 총 118초.
- TTS 음원 미제공으로 무음 마스터. 최종 1080×1920, 30fps. 미리보기 360×640.
- 핵심은 같은 사전학습 모델에서 파인튜닝한 호환 모델 사이에서 직선 보간과 평균이 좋은 해가 될 수 있는 기하학이다. 이전 영상 복습·다음 영상 예고를 넣지 않는다.

## 장면 구성

- 0–15초: 실제 3D 설명용 손실 표면과 이동하는 파라미터 점. 화면의 2축은 고차원 파라미터 공간의 2차원 단면이다.
- 15–24초: 공통 사전학습 θ₀에서 서로 다른 설정으로 θA·θB를 얻는 분기. 구조·파라미터 대응은 유지한다.
- 24–43초: 대응 가중치의 평균으로 단일 모델을 만들며 추가 경사하강법 없이 실행하는 모습을 표시한다.
- 43–61초: 파라미터 직선 위의 λ와 그 지점의 손실을 동기화한다. 중간 손실 장벽의 예시를 제시한다.
- 61–83초: 같은 조건을 비교하는 별도의 낮은 손실 경로 예시로 전환한다. θA와 θB의 중간점 λ=0.5를 강조한다. 3D 표면으로 돌아와 넓은 국소 골짜기라는 해석을 보여준다.
- 83–95초: 예측 평균 앙상블은 두 모델 실행, 가중치 평균은 단일 모델 실행임을 대비한다.
- 95–104초: 공통 출발점·대응 파라미터·낮은 보간 손실 조건과 검증 필요성을 명시한다.
- 104–118초: 좋은 두 점에서 주변의 국소 저손실 영역으로 강조를 넓힌다. 전체 좋은 해 집합이 볼록하다고 주장하지 않는다.

## 수학·연출 정확성 기준

- θ(λ)=(1−λ)θA+λθB, λ=0은 A, 1은 B, 0.5는 동일 가중 평균이다. 모델 구조·텐서 대응·클래스 의미가 호환된다는 조건이 필요하다. 독립적인 무작위 초기화 모델을 무조건 평균내지 않는다.
- 직선은 파라미터 공간의 직선이다. 표면에 올린 손실 곡선의 높이는 L(θ(λ))이므로 일반적으로 3차원에서 직선이 아니다. 손실 높이까지 평균해서 실제 중간 모델의 손실이라고 표시하지 않는다.
- 모든 지형·곡선·벡터 수치는 설명용 모형이다. 실제 학습 결과나 논문의 실측 데이터로 제시하지 않는다. 논문의 정량 성능 수치는 영상에 사용하지 않는다.
- 실제 표면은 매끄러운 골짜기 함수의 낮은 해상도 메시이다. 표면의 2차원 단면과 국소 영역은 전체 고차원 손실 지형을 충실하게 재구성한 것이 아니다.
- 마지막 강조는 새 면을 겹치지 않고 원래 메시의 국소 면을 색칠한다. 카메라를 위쪽으로 이동해 저손실 영역을 드러낸다. 표시된 6개 예시 파인튜닝 좌표의 평균은 A·B 중간점과 일치하도록 구성했다. 평균 좌표를 지형 함수에 대입하며 손실 높이 자체를 평균하지 않는다.
- A·B를 서로 다른 엄밀한 국소 최솟값이라고 증명하지 않는다. 사용자 대본의 ‘최솟값처럼 보임’은 낮은 손실의 학습 해라는 기하학적 직관으로 표현한다.
- 서로 다른 두 낮은 해 사이의 임의 곡선이 아니라 직선 보간과 중간점을 강조한다. 비선형 mode connectivity의 존재만으로 가중치 평균이 좋다고 결론내리지 않는다.
- 한 직선의 낮은 손실은 전체 좋은 해 집합의 볼록성이나 주변의 넓은 저손실 영역을 증명하지 않는다. 넓은 골짜기는 조건부 기하학적 해석이다. 마지막 화면에도 전체 볼록성 보장 없음 표시를 남긴다.
- 낮은 손실이 정확도 향상을 자동 보장하지 않는다. 일반화 성능의 개선은 연구에서 관찰된 조건부 결과이며 별도 검증이 필요하다.
- f평균가중치(x)와 평균예측은 일반적으로 같지 않다. 앙상블과 동일한 예측을 보장하지 않는다. ‘추론 비용 추가 없음’은 같은 구조의 단일 모델과 비교하는 것이며, 여러 후보 모델을 학습·저장·선택하는 제작 비용이 없다는 뜻이 아니다.
- 두 모델의 균등 평균을 주 예시로 사용하지만 Model Soups는 여러 모델도 평균할 수 있다. 실제 연구의 모든 후보를 무조건 평균하는 방식과 검증 기반 후보 선택을 구별한다. 화면에서는 ‘검증으로 호환성·성능 확인’을 표시한다.
- ‘추가 학습 없음’은 평균 모델을 만드는 데 추가 경사하강법이 필수적이지 않다는 뜻이다. 모델 종류에 따른 정규화 통계 등의 처리가 전혀 필요 없다는 보장으로 확대하지 않는다.

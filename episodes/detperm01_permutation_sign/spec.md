# 장면 설계

상단: 현재 주장과 고정 규칙. 중앙: 카드/행렬/순서 있는 벡터. 하단: 별도 발화 자막. 짝순열 초록, 홀순열 주황, 방향 보라, 붕괴 빨강.

- 0–15초: 계산 규칙에 담긴 기하학 (Shot01)
- 15–35초: 순서를 나열하는 여섯 가지 방법 (Shot02)
- 35–66초: 교환과 순열의 홀짝성 (Shot03)
- 66–100초: 열 선택이 만드는 두 항 (Shot04)
- 100–116초: 3×3 행렬과 여섯 순열 (Shot05)
- 116–131초: 열 교환과 방향의 반전 (Shot06)
- 131–152초: 같은 열이면 행렬식은 0 (Shot07)
- 152–163초: 순열로 계산하는 공간의 방향 (Shot08)

대표 검수: Shot03 교환 경로, Shot04 선택과 부호, Shot05 여섯 항, Shot06 방향, Shot07 동일 열. 모든 최종 씬의 경계·자막·프레임 수를 자동 검사한다.

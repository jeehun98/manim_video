# **행렬식의 계산에는 왜 순열이 등장할까? — Manim 영상화 콘티**

총 163초 (2분 43초) · 9:16 세로 영상 · 1080×1920 · 수학 애니메이션 중심

이번 영상의 핵심은 **숫자를 재배열하는 단순한 순열이 어떻게 행렬식의 복잡한 계산 규칙으로 연결되는지** 보여주는 것이다.

앞선 영상이 행렬식의 기하학적 의미를 설명했다면, 이번 영상에서는 그 기하학적 성질이 실제 계산 공식에 어떻게 반영되는지를 보여준다.

특히 세 가지 장면이 중요하다.

1. **순열의 발견:** 세 숫자의 순서를 바꾸면 여섯 가지 배열이 등장한다.
2. **순열과 행렬식의 연결:** 각 행에서 선택한 열의 순서가 하나의 순열을 이룬다.
3. **부호의 기하학적 의미:** 두 열을 교환하면 행렬식의 부호가 바뀌고, 같은 열이 존재하면 행렬식이 0이 된다.

## **1. 전체 시각적 구성**

① 순열

숫자의 순서를 바꾸기

② 원소 선택

각 행과 열에서 하나씩

③ 홀짝성과 부호

짝순열 (+), 홀순열 (−)

④ 차원 붕괴

같은 열이면 행렬식 0

## **2. 화면 레이아웃**

화면을 크게 세 영역으로 구성한다.

| 영역 | 화면 비율 | 역할              |
| -- | ----- | --------------- |
| 상단 | 약 18% | 현재 개념과 핵심 수식    |
| 중앙 | 약 62% | 순열·행렬·격자 애니메이션  |
| 하단 | 약 20% | 한국어 설명과 나레이션 자막 |

색상은 전체 영상에서 고정한다.

- 파란색: 선택된 원소 및 기본 순서
- 초록색: 짝순열, 양수 항
- 주황색: 홀순열, 음수 항
- 보라색: 공간의 방향 및 반전
- 빨간색: 서로 같은 열, 차원 붕괴

순열 단계에서 사용한 색을 행렬 단계에서도 그대로 유지하면, 시청자가 **숫자 배열 → 행렬의 열 선택 → 계산 항**의 관계를 자연스럽게 따라갈 수 있다.

# **3. 구간별 상세 콘티**

## **장면 1. 왜 행렬식은 곱하고 뺄까? (0\~15초)**

대본: 행렬식은 왜 서로 다른 원소들을 곱하고… 이 기하학적 성질은 행렬식의 계산 규칙과도 연결되어 있습니다.

**0\~5초 — 계산 공식에서 시작**

화면 중앙에 2×2 행렬이 등장한다.

\\[ A=\begin{pmatrix}a&b\\\c&d\end{pmatrix} \\]

각 원소를 순서대로 강조하고, 곧바로 아래 수식을 나타낸다.

\\[ \det(A)=ad-bc \\]

`a`와 `d`를 연결하는 파란색 선, `b`와 `c`를 연결하는 주황색 선이 등장한다.

두 곱셈 항 `ad`, `bc`를 각각 강조한다.

`+`와 `−` 부호 중 특히 마이너스 부호를 확대하며 다음 장면으로 이어진다.

**5\~11초 — 이전 영상과 연결**

수식이 축소되고, 배경에 단위 정사각형과 좌표 격자가 등장한다.

정사각형을 평행사변형으로 변형한 다음, 좌우로 뒤집는다.

- 넓이 확대: `|det(A)| = 2`
- 방향 반전: `det(A) = -1`

두 장면을 빠르게 보여주며 지난 영상의 내용을 시각적으로 상기시킨다.

**11\~15초 — 계산 규칙으로 돌아오기**

격자가 사라지고 수식만 남는다.

`ad - bc`의 두 항을 강조한다.

그 아래에 질문을 나타낸다.

**왜 이 두 가지 조합일까?**

## **장면 2. 순열의 등장 — 숫자 세 개를 나열하는 방법 (15\~35초)**

대본: 먼저 세 개의 숫자, 일, 이, 삼을… 이처럼 원소들의 순서를 바꾸어 나열하는 것을 순열이라고 합니다.

**15\~19초 — 세 숫자 등장**

중앙에 세 개의 숫자 카드가 차례대로 등장한다.

# **1**

# **2**

# **3**

세 개의 숫자 카드 — 서로 다른 색을 끝까지 유지

각 카드는 등장한 이후에도 번호에 따라 동일한 색을 유지한다.

**19\~22초 — 순서를 바꿔보기**

숫자 카드 2와 3이 서로 위치를 바꾼다.

`1 2 3 → 1 3 2`

이어서 첫 번째 카드와 두 번째 카드가 위치를 바꾼다.

`1 2 3 → 2 1 3`

숫자들이 서로 자리를 바꾸는 과정에서 곡선 이동 경로를 잠깐 표시한다.

**22\~30초 — 여섯 가지 순열 나열**

실제 영상에서는 숫자 배열을 한꺼번에 등장시키지 않는다.

나레이션과 동기화하여 1초\~1.3초 간격으로 순차적으로 배열한다.

**30\~35초 — 순열이라는 이름 부여**

여섯 배열이 하나의 그룹으로 축소되고 위에 제목이 등장한다.

`순열 (Permutation)`

아래에는

`같은 원소, 다른 순서`

를 표시한다.

이후 여섯 배열을 흐리게 만들고 `1 2 3`만 화면 중앙으로 확대한다.

## **장면 3. 교환 횟수로 순열을 구분하다 (35\~66초)**

이 장면은 뒤에서 행렬식의 부호를 이해하기 위한 핵심이다.

**35\~41초 — 교환 연산 정의**

`1 2 3` 숫자 카드 세 개를 다시 크게 나타낸다.

2와 3의 숫자 위에 곡선 화살표를 그린다.

`교환 (Swap)`

카드가 서로 반대 방향의 곡선을 따라 이동한다.

**41\~47초 — 한 번 교환**

1

2

3

1

3

2

교환 1회 · 홀수

교환 직후 아래에 `Swap Count = 1`이라는 카운터를 나타낸다.

카운터 옆에 주황색 마이너스 기호가 등장한다.

**47\~52초 — 두 번 교환**

이번에는 `1 2 3`에서 시작한다.

\\[ (1,2,3)\rightarrow(2,1,3)\rightarrow(2,3,1) \\]

첫 번째 교환에서 1과 2를 바꾼다.

두 번째 교환에서 1과 3을 바꾼다.

화면 아래 카운터가 `0 → 1 → 2`로 증가한다.

마지막에 초록색 플러스 기호를 나타낸다.

**52\~61초 — 짝순열과 홀순열**

여섯 순열을 다시 등장시키고 두 그룹으로 분류한다.

짝순열 (+)

### **1  2  3**

### **2  3  1**

### **3  1  2**

홀순열 (−)

### **1  3  2**

### **2  1  3**

### **3  2  1**

두 그룹 위에 각각 `Even permutation`, `Odd permutation`을 작게 표시한다.

**61\~66초 — 홀짝성이 유지된다**

하나의 순열을 여러 경로로 만드는 예시를 보여준다.

예를 들어 `1 3 2`는 한 번의 교환으로도, 세 번의 교환으로도 만들 수 있다.

화면에서

`1회 → 홀수`

`3회 → 홀수`

를 동시에 보여준다.

그 아래에

**교환 횟수는 달라도 홀짝성은 같다.**

라는 문구를 나타낸다.

이 장면에서는 실제 교환 경로를 정확히 구현해야 한다. 불필요하게 복잡한 경로 전체를 길게 보여주기보다는 첫 번째 경로와 두 번째 경로를 비교하는 방식이 적절하다.

## **장면 4. 순열을 행렬의 계산에 적용하다 (66\~100초)**

대본: 그렇다면 이 순열이 행렬식과는 어떤 관계가 있을까요? … 그 결과가 바로 에이 디 마이너스 비 씨입니다.

이 장면은 영상 전체에서 가장 중요한 연결 구간이다. **숫자의 순서를 나열하던 화면이 행렬에서 원소를 선택하는 화면으로 변하는 것**이 핵심이다.

**66\~73초 — 순열에서 행렬로 전환**

화면에 `1 2`라는 두 숫자 카드를 나타낸다.

이 두 숫자는 이제 순열의 원소가 아니라 행렬에서 선택할 **열 번호**가 된다.

숫자 카드 아래에 2×2 행렬을 등장시킨다.

\\[ A=\begin{pmatrix} a&b\\\ c&d \end{pmatrix} \\]

행렬 위쪽에는 `1열`, `2열`, 왼쪽에는 `1행`, `2행`이라는 작은 라벨을 배치한다.

**73\~82초 — 가능한 선택 두 가지**

순열 (1, 2)

## **+ ad**

순열 (2, 1)

## **− bc**

왼쪽부터 순차적으로 애니메이션을 재생한다.

- 첫 번째 경우: 1행에서 1열의 `a`, 2행에서 2열의 `d`를 선택한다.
- 두 번째 경우: 1행에서 2열의 `b`, 2행에서 1열의 `c`를 선택한다.

선택한 원소가 행렬 밖으로 복제되어 각각 `ad`, `bc`라는 곱셈 항을 만든다.

**82\~91초 — 선택 순서와 부호**

화면 상단에 두 개의 숫자 카드가 등장한다.

`1 2 → 2 1`

숫자 카드의 위치가 한 번 교환되면 아래의 `+ ad`가 `− bc`로 바뀌는 모습을 보여준다.

이때 **원소를 선택하는 순서의 홀짝성이 부호를 결정한다**는 사실을 강조한다.

**91\~100초 — 행렬식 완성**

두 항을 화면 중앙으로 모은다.

\\[ \boxed{\det(A)=ad-bc} \\]

화면 아래에는 다음 대응관계를 표시한다.

`짝순열 → +`

`홀순열 → −`

이 장면에서는 공식을 다시 계산하는 대신, **공식이 순열의 두 가지 경우로부터 만들어졌다는 사실**을 보여주는 것이 중요하다.

## **장면 5. 3×3 행렬식에는 여섯 가지 순열이 등장한다 (100\~116초)**

대본: 삼 행 삼 열에서도 같은 원리가 적용됩니다. … 홀순열이면 빼는 것입니다.

**100\~108초 — 3×3 행렬 등장**

2×2 행렬을 축소하고 3×3 행렬로 확장한다.

\\[ A=\begin{pmatrix} a&b&c\\\ d&e&f\\\ g&h&i \end{pmatrix} \\]

이제 1, 2, 3이라는 열 번호를 선택할 수 있다.

앞서 순열을 설명했던 여섯 배열을 다시 등장시킨다.

열 선택 순서 → 행렬식의 항

| 순열  | 선택한 원소    | 계산 항 |
| --- | --------- | ---- |
| 123 | a · e · i | +aei |
| 132 | a · f · h | −afh |
| 213 | b · d · i | −bdi |
| 231 | b · f · g | +bfg |
| 312 | c · d · h | +cdh |
| 321 | c · e · g | −ceg |

실제 영상에서는 이 표를 그대로 사용하기보다는 행렬 원소를 선택하는 애니메이션을 빠르게 여섯 번 재생한다.

**108\~116초 — 여섯 항을 결합**

선택 결과를 두 그룹으로 분리한다.

\\[ \underbrace{aei+bfg+cdh}\_{\text{짝순열}} \\]

\\[ \underbrace{-afh-bdi-ceg}\_{\text{홀순열}} \\]

각 그룹을 초록색과 주황색으로 구분하고, 최종적으로 하나의 행렬식으로 결합한다.

\\[ \det(A)=aei+bfg+cdh-afh-bdi-ceg \\]

복잡한 일반화 공식까지 소개할 필요는 없다. 핵심은 **3×3에서도 같은 선택 규칙이 반복된다는 것**이다.

## **장면 6. 왜 순열의 홀짝성이 행렬식의 부호를 결정할까? (116\~131초)**

대본: 그런데 왜 굳이 부호를 구분해야 할까요? … 방향의 반전을 계산에 반영하는 역할을 합니다.

여기서는 앞선 영상의 공간 변형을 다시 가져온다.

**116\~119초 — 질문**

화면 중앙에 두 개의 부호를 크게 나타낸다.

`+` 와 `−`

그 아래에 `왜 부호가 필요할까?`라는 문구를 표시한다.

**119\~126초 — 두 열을 교환하면 방향이 뒤집힌다**

원점에서 시작하는 두 기저벡터를 가진 평행사변형을 등장시킨다.

\\[ A=\begin{pmatrix} 2&1\\\ 0&1 \end{pmatrix} \\]

두 열을 교환한다.

\\[ B=\begin{pmatrix} 1&2\\\ 1&0 \end{pmatrix} \\]

각 열에 대응하는 벡터의 위치를 교환하며 평행사변형의 방향이 바뀌는 모습을 보여준다.

애니메이션에서는 두 벡터의 길이와 색을 유지한 채 서로 역할을 교환시킨다.

중요한 것은 넓이는 그대로지만 **벡터가 이루는 순서가 반대로 바뀐다는 것**이다.

**126\~131초 — 순열의 홀짝성과 연결**

평행사변형을 축소하고, 위쪽에는 `1 2 → 2 1`을 나타낸다.

아래쪽에는 `+ → −`를 나타낸다.

그 사이에 `교환 1회`라는 문구를 배치한다.

이 장면은 순열에서 설명했던 교환 연산과 완전히 동일한 시각적 동작을 사용한다.

## **장면 7. 두 열이 같으면 행렬식이 0이 되는 이유 (131\~152초)**

대본: 예를 들어 두 열이 완전히 같다면 어떻게 될까요? … 공간의 차원이 붕괴한다는 기하학적 의미와도 일치합니다.

세 번째 하이라이트다. 앞선 영상에서 다룬 차원 붕괴가 이번에는 **행렬식의 계산 성질로부터 다시 도출되는 장면**이다.

**131\~137초 — 두 열이 같은 행렬**

다음 행렬을 등장시킨다.

\\[ A=\begin{pmatrix}1&1\\\2&2\end{pmatrix} \\]

두 열을 각각 파란색과 주황색 테두리로 둘러싼다.

두 열을 서로 교환하지만 원소의 값은 그대로 유지된다.

화면 하단에는 다음 문구를 나타낸다.

`열을 교환해도 A는 그대로`

**137\~146초 — 부호 반전의 모순**

화면을 위아래로 나눈다.

위쪽에는 `열 교환 → 부호 반전`이라는 규칙을 표시한다.

아래쪽에는 다음 수식을 단계적으로 나타낸다.

\\[ \det(A)=-\det(A) \\]

\\[ 2\det(A)=0 \\]

\\[ \boxed{\det(A)=0} \\]

마지막 식을 빨간색으로 강조한다.

**146\~152초 — 기하학적으로 확인**

화면 오른쪽에 두 열벡터가 동일한 방향으로 겹쳐진 모습을 보여준다.

원래 단위 정사각형이 하나의 선분으로 압축된다.

`Area = 0`을 강조한다.

이후 수식과 그림을 동시에 보여준다.

`계산 결과 = 기하학적 결과`

이렇게 마무리하면 행렬식의 계산 공식과 공간 변화가 하나의 원리로 연결된다는 인상을 줄 수 있다.

## **장면 8. 마무리 — 순열이 공간의 방향을 계산한다 (152\~163초)**

대본: 결국 행렬식의 계산은 단순히 원소들을 임의로 곱하고 더하는 과정이 아닙니다. 가능한 순열을 모두 고려하고, 그 순열의 홀짝성으로 공간의 방향까지 반영하는 계산인 것입니다.

**152\~157초 — 계산 규칙의 재구성**

3×3 행렬을 다시 등장시킨다.

행렬에서 서로 다른 행과 열의 원소를 선택하는 여섯 가지 경우가 순차적으로 강조된다.

각 선택이 하나의 곱셈 항으로 변환된다.

**157\~163초 — 최종 메시지**

여섯 항을 초록색과 주황색으로 분리한 뒤 하나의 행렬식으로 합친다.

화면 중앙에 다음 문구를 나타낸다.

DETERMINANT × PERMUTATION

\\[ \det(A)=\sum\_{\sigma\in S_n}\mathrm{sgn}(\sigma)\prod\_{i=1}^{n}a\_{i,\sigma(i)} \\]

일반식은 마지막 1\~2초에만 짧게 보여주거나 생략해도 된다. 이번 영상에서는 공식을 외우게 하는 것보다 **순열이 행렬식의 각 항과 부호를 결정한다는 직관**을 남기는 것이 우선이다.

## **5. 제작상 중요한 검증 사항**

- **순열의 홀짝성:** `123`, `231`, `312`는 짝순열이고, `132`, `213`, `321`은 홀순열이다.
- **3×3 행렬식의 항:** 각 항은 행마다 하나, 열마다 하나의 원소를 반드시 선택해야 한다.
- **열 교환:** 원래 행렬의 두 열을 교환하면 행렬식의 부호가 바뀐다.
- **같은 열:** 두 열이 같으면 행렬식이 0이다.
- **시각적 일관성:** 순열에서 한 번 교환할 때마다 부호가 반전된다는 규칙을 행렬식 장면에서도 동일하게 유지한다.

마지막으로, 이번 영상에서는 **수학적으로 새로운 두 개념을 소개하는 것이 아니라 하나의 원리가 서로 다른 표현으로 등장한다는 사실**을 강조하는 것이 좋겠다.

초반에는 숫자의 순서를 바꾸는 단순한 조작으로 보였던 것이, 마지막에는 공간의 방향을 측정하는 행렬식의 부호를 결정하는 역할로 다시 등장한다.

바로 이 연결이 영상의 핵심이다.

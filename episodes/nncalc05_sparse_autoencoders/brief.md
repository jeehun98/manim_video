# Sparse Autoencoders · 제작 기준

확정 대본 33문장과 사용자 누적 종료 시각을 사용한다. 총 171초(2:51), 30fps.
일반 1920×1080, 쇼츠 1080×1920. 같은 발화와 별도 네이티브 배치. 음원 미제공으로 무음.
원본 콘티는 storyboard_source.md, 확정 시각은 timing.json에 둔다.

## 여섯 제작 단위

0–26초: 2차원 활성화에서 숨은 특징 조합을 찾는 문제.
26–56초: 고정된 원래 모델에서 활성화 수집 → 별도 SAE의 2→5→2 구조.
56–91초: 복원의 비유일성 → 희소 제약 → 다양한 입력이 공통 사전을 사용.
91–111초: 복원 오차와 희소성 페널티의 절충.
111–131초: 2023년 실제 연구와 활성화 개입 사례.
131–171초: 의미 해석·분할·병합의 한계와 검증할 후보 계산 경로.

여섯 단위는 각각 독립 Scene 클래스로 렌더할 수 있으며, 전체 클래스는 같은 단위들을 순서대로 실행한다.
각 단위의 spec은 scene_specs.md, 원고는 narration.md 및 화면 변화별 TTS에 기록한다.

## 시각 및 수학

- 4편의 다섯 색상을 재사용한다. 가상의 생성 특징과 학습된 후보 사전은 동일한 정답으로 단정하지 않는다.
- 원래 모델 가중치는 고정. 활성화 자료를 복사하며, SAE Encoder/Decoder만 학습한다.
- z = ReLU(W_enc(h−b_dec)+b_enc), ĥ = Dz+b_dec. D의 열이 디코더 사전 방향이다.
- 설명 예시 D는 열 노름 1, 각도 20°,100°,170°,280°,330°. 설명 계산에는 b_dec=0을 사용한다.
- 잠재값 A=(.85,0,0,.62,0), B=(0,.7,0,0,.65), C=(.9,0,.4,0,0). 수치·활성화는 실제 실험 측정값이 아니다.
- 학습 중 D가 달라질 수 있다는 점과, 학습 후 입력 A/B/C에서 동일 D를 재사용한다는 점을 구별한다.
- L=||h−ĥ||²+λ||z||₁는 대표 L1 예시다. L1은 활성화 크기의 합으로, 활성화 개수를 직접 세지 않는다. 디코더 열 노름 제약으로 단순 스케일 변환 회피를 막는 조건도 표시한다.
- 복원 비유일성은 같은 h를 서로 다른 좌표 사전 및 계수로 정확히 나타내는 개념 예시로 보여준다.
- 특징 분할·병합은 다른 사전 크기/학습 조건의 분해를 비교하며, 하나의 SAE 안에서 노드가 물리적으로 분열하는 것으로 표현하지 않는다.
- 개입은 SAE가 텍스트를 생성하는 과정이 아니다. 학습된 방향으로 원래 Transformer의 활성화를 바꾸고 원래 모델의 나머지 계산을 실행한다.
- 마지막 그래프는 추적 대상 후보 연결이다. 실제 인과 경로를 확인한 결과로 표시하지 않는다.
- 마지막 질문과 경로 추적 발화는 사용자 제공 원고를 유지하며 별도 편명 예고는 추가하지 않는다.

## 연구 근거

Bricken et al. (2023), [Towards Monosemanticity: Decomposing Language Models With Dictionary Learning](https://transformer-circuits.pub/2023/monosemantic-features/index.html).
연구의 512뉴런 MLP 활성화·4,096 잠재 특징 사전 사례와 아랍 문자/Base64 후보 및 개입 결과를 연결한다.
예시 문자열·막대 높이는 실측 재현이 아니다. 잠재 특징 수는 확정된 독립 의미의 개수가 아니다.

# EP.01 지수법칙 — 82초 개정본

사용자 제공 18문장·종료 시각과 82초 콘티 기준. 1920×1080, 16:9, 30fps. TTS 미제공으로 무음.

실제 문제와 선택지 제시 → 밑 확인 → 근호 변환 → 지수 덧셈 → 역수와 정답 → 밑·음수 지수의 오개념 방지 → 전체 풀이.

밑 청록, 지수 노랑, 주의 주황, 정답 초록. 잘못된 식에는 처음 등장할 때부터 취소표를 함께 표시한다. 문제의 작은 참조식을 유지하고 중앙에서는 현재 계산 항을 확대한다. 9개 독립 교체 씬, 하단 자막 영역 분리.

기존 143초 대본·소스·타이밍·보고서는 revisions/v1_143s에 보존. 기존 영상은 exports/csat01_v1_143s.mp4. 현재 파일과 혼용하지 않는다.

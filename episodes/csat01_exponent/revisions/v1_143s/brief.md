# 수능 수학 EP.01 — 지수법칙

- 출처：사용자 제공 콘티 기준 2027학년도 6월 모의평가 공통 1번 + 자체 응용문제. 수능 본시험으로 표기하지 않는다.
- 확정 입력: 사용자 대본 30문장과 문장 종료 시각. 총 143초, 1920×1080, 30fps, 16:9. 음원 미제공으로 무음.
- 핵심: 같은 밑으로 통일 → 반복 곱셈과 지수 덧셈 → 치환으로 합과 곱 추출.
- 색상: 밑 청록 #38BDF8, 지수 노랑 #FACC15, 관계 보라 #C084FC, 결과 초록 #4ADE80.
- 수학 조건: 분수·음수 지수 확장은 양의 밑 기준. 반복 곱셈 설명을 분수 지수의 증명으로 오인하지 않게 구분한다.
- 응용: a=3^x, b=3^(-x), a+b=4, ab=1, a^3+b^3=4^3-3·1·4=52.
- 씬은 11개 독립 렌더·교체. timing.json에 확정 구간과 문장 시각 보존. 자막은 하단 전용 영역.
- 마지막 질문은 본문 위에서 유지하며 별도 엔드카드, 다음 편 예고를 넣지 않는다.

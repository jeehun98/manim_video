# 신경망의 수학 02 제작 기준

## 제목과 역할

- 제목: **왜 더 큰 공간에서 답을 찾는 것이 쉬울까?**
- 1화의 `d_intrinsic ≪ D`에서 출발해, 여분의 파라미터가 낭비만이 아니라 해 집합의 자유도와 최적화의 도달 가능성을 늘릴 수 있다는 기하학적 직관을 만든다.
- 마지막에는 해 집합의 크기만으로 최적화 난이도를 설명할 수 없음을 분명히 하고 3화의 curvature/Hessian 질문으로 연결한다.

## 핵심 흐름

1. 큰 공간이 단순한 낭비인지 질문한다.
2. 해가 고립된 점 하나라면 차원을 키운다고 찾기 쉬워지지 않음을 먼저 인정한다.
3. `w₁w₂ = 1`을 이용해 같은 결과를 만드는 파라미터가 연속적인 곡선을 이룰 수 있음을 보여준다.
4. 변수는 늘지만 독립 제약 수가 유지되는 이상적 상황에서 해 집합의 차원이 커질 수 있음을 선→면으로 시각화한다.
5. 여러 초기점이 서로 다른 위치에서 해 집합에 도달하는 모습으로 overparameterization의 기하학적 역할을 제시한다.
6. loss landscape의 경사·평탄 방향·saddle을 꺼내며 이 설명만으로는 부족하다고 반전한다.

## 정확성 기준

- `w₁w₂ = 1`의 해는 선형 부분공간이 아니라 곡선이다. 화면에는 `solution set / manifold-like structure`라고 표기한다.
- `dim(S) ≈ D − r`는 전역 공식이나 모든 신경망에 대한 정리가 아니다. 독립 제약의 국소 Jacobian rank가 `r`이고 해가 regular한 이상적 상황에서 쓰는 차원 계수 직관이다.
- 파라미터 차원이 커지면 항상 학습이 쉬워진다고 말하지 않는다. 같은 기능의 중복 표현이나 여분의 해 방향이 생길 **수 있다**고 표현한다.
- solution set이 넓다는 사실만으로 gradient-based optimization의 성공을 보장하지 않는다. 초기화, 경로의 곡률, saddle, conditioning 등 loss geometry가 별도로 중요하다.
- flatness를 일반화 성능과 직접 동일시하지 않는다. 이번 편에서는 좋은 해 근처의 서로 다른 방향 민감도만 예고한다.

## 연출 기준

- 1화의 마지막 장면과 동일한 색·레이아웃으로 시작한다.
- 고립점은 확대될수록 더 작은 표적으로 보이게 한다.
- `w₁w₂ = 1`은 좌표축과 양의 두 갈래 hyperbola 중 제1사분면 곡선, 예시 해 `(1,1)`, `(2,1/2)`, `(4,1/4)`로 보여준다.
- `ℝ² → ℝ³ → ℝᴰ`는 곡선이 원근감 있는 면과 추상적인 고차원 리본으로 확장되는 morph로 표현한다. 실제 해 집합이 평면이라는 뜻은 아니다.
- 중심 문장 `SEARCH SPACE ↑, TARGET SET ↑`와 한국어 `찾을 공간은 커졌지만, 표적도 함께 커질 수 있다`를 충분히 오래 보여준다.
- 마지막은 `λ₁ ≫ λ₂ ≈ 0`을 보여주되 Hessian이라는 이름은 아직 말하지 않는다.

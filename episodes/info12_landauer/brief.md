# 정보이론 12 — Landauer’s Principle

학습 목표: 출력 하나로 합쳐진 입력의 구분이 물리적 메모리에서 사라질 때, 메모리 엔트로피 감소를 환경이 보상해야 함을 이해한다. 핵심은 열 발생 일반론보다 정보 삭제의 평균 열 하한이다.

## 제작 기준

- 제목: 정보 1비트를 지우는 데 필요한 최소 비용 — Landauer’s Principle | 정보이론 12.
- 세로 1080×1920, 30fps. 기존 시리즈 색상과 Malgun Gothic 유지.
- 13구간, 약 79.5초. 구간은 발화 길이 기반 누적 시각에 맞춘다. 실제 TTS 음원은 포함하지 않는다.
- 물리적 장면부터 시작: 두 칸 상자 → 공 위치 불명 → 왼쪽으로 초기화 → 두 경로가 같은 상태 → 가능한 위치 두 개에서 하나 → 환경으로 열 방출.
- 공은 하나. 가능한 두 시작 상태와 두 경로는 별개의 대안이며 두 공을 하나로 합치는 그림이 아니다.
- 수식은 9번째 구간에서 딱 한 번 평균 열의 하한을 이름 붙이는 데 사용한다. 앞 구간에는 엔트로피 수식, NOT 기호, 추상 게이트가 없다.
- 장벽 개방, 피스톤 압축, 칸막이 복원, 피스톤 복귀를 보여준다. 시작 위치를 읽어서 분기하는 제어가 아니라 동일한 외부 제어의 개념도다. 초기와 최종 장치 형상은 같다.
- 열 파동과 환경 입자 움직임은 개념도다. 열 수치의 시뮬레이션이나 엔트로피라는 물질이 이동하는 그림으로 해석하지 않는다.
- 등확률 미지 비트 및 평균 하한 조건을 남기며, 전체 컴퓨터 소비와 구분한다.

## 과학적 조건과 표현

표준 대칭 메모리의 처음에 독립적이고 등확률인 미지 비트, 정확한 고정 상태 초기화, 온도 T의 열환경, 초기와 최종의 장치 조건 복원을 전제로 한다. 정보 엔트로피는 1 bit에서 0 bit로, 논리적 자유도의 물리적 엔트로피는 kB ln 2만큼 감소한다. 환경 엔트로피 증가 Q/T와 제2법칙에서 환경으로 방출되는 **평균** 열이 kB T ln 2 이상임을 표현한다. 개별 시행마다 동일한 열이 나온다는 뜻이 아니다.

처음부터 알려진 비트와 편향된 비트에는 같은 1 bit 조건을 그대로 적용하지 않는다. N배 예시는 등확률인 독립 비트 N개다. 입자나 모든 미시적 상태가 소멸한다는 주장을 하지 않는다. 논리적 가역성은 실제 장치의 열역학적 가역성을 자동으로 보장하지 않는다. 이상적인 느린 제어에서 하한에 접근하며 실제 소비 전력 전체를 이 식으로 계산하지 않는다. 열과 일의 무조건적 동일시를 피하고 식은 평균 환경 열로 표기한다.

상수: kB=1.380649×10⁻²³ J/K, T=300 K, kB T ln 2=2.870978885×10⁻²¹ J. 화면과 발화는 약 3×10⁻²¹ J.

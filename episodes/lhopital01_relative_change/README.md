# 로피탈의 정리 — 왜 따로 미분해도 될까?

사용자 제공 34문장·179초, 쇼츠용 9:16·1080×1920·30fps·무음·전체 자막. 12개 독립 씬을 조립한다.

- 미리보기: `python scripts/render.py lhopital01 --preview`
- 최종본: `python scripts/render.py lhopital01`
- 대표 씬 검수: `python episodes/lhopital01_relative_change/build.py --preview --only 05,07,09,10`
- 출력: `exports/lhopital01_short.mp4`

국소 확대, 같은 c를 쓰는 코시의 평균값 정리, x³/x²의 접근 속도, 테일러 선도항을 실제 좌표와 기울기에 맞춰 애니메이션으로 표현한다. 음원이 제공되지 않아 무음이며 `captions.srt`와 `tts_script.txt`를 별도로 제공한다.

# 로피탈의 정리 — 왜 따로 미분해도 될까?

사용자가 제공한 34문장·179초를 확정 대본으로 사용한다. 첨부의 16:9 배치 권장보다 쇼츠 요청을 우선해 9:16·1080×1920·30fps로 제작한다. 음원이 제공되지 않아 무음·전체 문장 자막이며 별도 SRT를 제공한다. 이전 편 복습·다음 편 예고·엔드카드는 없다.

핵심은 계산법 자체보다 상대적 접근 속도, 국소 일차 근사, 코시의 평균값 정리, 고차 항의 차이를 움직이는 그래프로 관찰하는 것이다. 청록색 f는 분자, 파란색 g는 분모, 주황색은 할선, 보라색은 접선, 노란색은 비율·결론이다. 수식의 함수색과 그래프색을 맞춘다. 세로 화면에서 비교 패널은 위아래로 배치하며 잘라내기로 화면비를 바꾸지 않는다.

적용 조건: 근방에서 미분 가능, g′≠0, 0/0 또는 ∞/∞ 형태, 도함수 비율의 극한 존재 등 정리의 가정을 명시한다. 접선 근사 장면만 f(0)=g(0)=0 및 g′(0)≠0인 sin(x), x 예시를 사용한다. 이 직관을 일반 정리의 증명으로 대신하지 않는다. 그래프 확대는 x와 y를 같은 배율로 재좌표화하며 눈금의 실제 값을 함께 바꾼다.

코시 장면은 0/0·x→0+의 예시 f(x)=x², g(x)=x를 매개변수 곡선 P(u)=(g(u),f(u))로 그린다. 할선 기울기는 t, 접선 기울기는 2c이므로 c=t/2를 실제 계산한다. 일반 평균값 정리를 두 함수에 따로 적용해 서로 다른 c를 동일시하지 않는다. 고차 장면은 f(x)=x³, g(x)=x²를 명시하여 f/g=x→0을 유지한다.

테일러는 sin(x)의 실제 전개와 다항 근사를 사용한다. 일반적인 매끄러운 함수가 자신의 무한 테일러 급수와 항상 일치한다는 표현은 쓰지 않는다. 유한 차수의 선도항 해석과 로피탈의 적용 조건을 구별한다.

script.json의 12씬은 각각 독립 렌더·교체 가능하다. 씬별 시작·끝은 사용자 종료 시각에 고정한다. 대표 검수는 05(국소 확대), 07(코시), 09(고차), 10(테일러)부터 수행하고 최종본에서 중요한 전환과 화면 범위를 확인한다.

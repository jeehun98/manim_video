# 분포의 수학 06 제작 기준

- 학습 목표: 공분산을 두 편차의 곱을 평균낸 값으로 이해하고, 그 **부호가 평균점을 기준으로 함께 움직이는 선형 방향**을 나타냄을 본다.
- 기준점은 `(μ_X, μ_Y)`다. 오른쪽 위 `(+,+)`와 왼쪽 아래 `(−,−)`는 `(x−μ_X)(y−μ_Y)>0`, 왼쪽 위 `(−,+)`와 오른쪽 아래 `(+,−)`는 곱이 음수다. 축 위에서는 곱이 0이다.
- 이산 분포의 정의는 `Cov(X,Y)=E[(X−μ_X)(Y−μ_Y)]`다. 점 그림에서는 각 점을 동일 가중 관측으로 표현하며 평균 기여의 직관을 설명한다.
- `Cov≈0`은 양·음의 선형 기여가 상쇄됨을 뜻한다. 독립성 또는 모든 관계의 부재를 주장하지 않는다. 가로로 긴 타원도 공분산 0일 수 있다.
- 마지막 회전에는 같은 타원형 점 집합을 사용한다. 점은 장축 2.3, 단축 0.6인 타원 위에 균등한 각도로 놓고, 타원만 `+35° → 0° → −35°`로 회전한다. 형태와 축 길이는 유지되고 공분산 부호는 `+ → 0 → −`로 바뀐다.
- 순서: 우상향 점구름 → 평균점과 사분면 → `(+,+)` → `(−,−)` → 편차의 곱 → 반대 부호 → 사분면 부호 지도 → 전체 평균 → 양수 → 음수 → 0 근처 → 세 부호 비교 → 같은 분포 회전과 다음 질문.

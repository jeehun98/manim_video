# Sigmoid 06 — 한계와 선택의 이유

150초, 1080×1920, 30fps, 한국어 자막, 무음.

## 대본 검토

- 0.2의 반복 곱셈은 각 단계의 전체 미분값을 0.2로 가정한 스칼라 예시다. 실제 신경망 역전파는 가중치 행렬과 활성화 함수의 미분, 경로의 합 등을 포함한다.
- `σ′(x)≤0.25`와 `0.25⁵≈0.00098`은 Sigmoid 미분계수들의 곱에 관한 설명이다. 전체 네트워크 기울기의 상한이나 모든 층에서 기울기가 반드시 감소한다는 주장으로 사용하지 않는다. 화면과 대본 모두 범위를 명시한다.
- 이진 분류 확률은 학습된 모델의 Bernoulli 확률 모수로 해석한다. 단순히 범위가 (0,1)이라는 이유만으로 임의의 값이 잘 보정된 확률이 되는 것은 아니다.
- 게이트는 `출력=g×입력`의 스칼라 예시로 설명하며, LSTM에서는 요소별 곱으로 작동한다. 입력·망각·출력 게이트가 Sigmoid를 사용한다. 셀 후보값까지 Sigmoid를 쓴다고 설명하지 않는다.
- 사용자 결론을 유지하되, 깊은 은닉층의 한계와 출력·게이트의 역할을 분리해 비교한다.

## 수치 확인

0.2, 0.2²=0.04, 0.2³=0.008. 0.25⁵=0.0009765625.

σ(log(4))=0.8. 통과 비율 0.2와 0.8에 입력 8을 곱하면 각각 1.6과 6.4.

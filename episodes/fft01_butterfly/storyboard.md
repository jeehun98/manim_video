# **Manim 상세 영상화 콘티**

## **고속 푸리에 변환은 무엇이 다를까? — 버터플라이 연산**

총 177초(2분 57초) · 9:16 쇼츠 · 확정 나레이션 기준

이번 영상에서 가장 중요한 것은 **푸리에 변환의 수학적 성질이 어떻게 실제 계산 구조의 변화로 이어지는지** 보여주는 것입니다.

처음에는 모든 입력과 출력이 연결된 밀집된 계산 구조를 보여주고, 복소평면에서 회전 인자의 대칭성을 발견한 뒤, 이를 이용해 계산 구조를 버터플라이 형태로 재구성합니다.

마지막에는 처음과 동일한 입력과 출력 사이에서 필요한 계산만 줄어들었다는 사실을 강조합니다.

# **1. 영상 전체의 시각적 방향**

DFT

## **O(N²)**

모든 성분을 직접 계산

FFT

## **O(N log N)**

분할과 중간 결과의 재사용

같은 입력 · 같은 출력 · 다른 계산 구조

위의 두 계산 구조가 영상의 시작과 끝을 연결하는 대표 이미지가 됩니다.

FFT 그림은 비트 반전 순서로 입력을 재배치한 Radix-2 FFT 계산 그래프를 나타냅니다. 연결선 자체의 개수를 연산 횟수와 동일하게 해석하지 않도록 주의합니다.

화면 문구:

`Same Mathematical Result`

### **7–12초 — 달라지는 것은 계산 과정**

DFT와 FFT의 내부를 각각 열어 보여주는 느낌으로 계산 그래프가 등장합니다.

DFT에는 모든 입력이 모든 출력으로 연결된 구조를, FFT에는 단계별로 중간 결과가 전달되는 구조를 보여줍니다.

아직 버터플라이 연산이라는 명칭은 소개하지 않습니다.

시청자가 두 구조의 차이를 궁금해하도록 만드는 장면입니다.

## **Scene 02. 직접 계산은 왜 N²이 필요할까?**

00:12–00:36 · DFT의 계산 구조

### **12–16초 — 연속 신호에서 8개의 데이터 추출**

화면에 사인파들이 합성된 연속 신호를 나타냅니다.

그 위에 일정한 간격으로 8개의 샘플을 찍습니다.

\\[ x_0,x_1,x_2,\ldots,x_7 \\]

연속적인 곡선은 점점 투명해지고, 8개의 샘플 데이터만 남습니다.

### **16–23초 — 주파수 성분을 하나씩 계산**

화면 하단에 복소 지수함수들을 순차적으로 등장시킵니다.

각 주파수에 대응하는 회전 속도가 서로 다르다는 것을 표현합니다.

\\[ X_k=\sum\_{n=0}^{N-1}x_n e^{-2\pi i kn/N} \\]

수식에서 세 부분을 색상으로 구분합니다.

- \\(x_n\\): 입력 데이터
- \\(e^{-2\pi i kn/N}\\): 주파수에 대응하는 회전 인자
- \\(\sum\\): 모든 곱셈 결과의 합

처음부터 식 전체를 유도하지 않고, **각 입력값에 회전 인자를 곱하고 합산하는 과정**만 보여줍니다.

### **23–30초 — 모든 입력이 하나의 출력에 사용된다**

먼저 \\(X_0\\)에 연결되는 8개 간선을 활성화합니다.

이후 \\(X_1\\), \\(X_2\\), \\(X_3\\)으로 활성화 영역을 빠르게 이동시킵니다.

마지막에는 모든 연결선을 표시합니다.

### **30–36초 — N² 복잡도**

계산 구조를 8행 8열의 행렬로 변환합니다.

\\[ 8\times8=64 \\]

\\[ N\times N\quad\Rightarrow\quad O(N^2) \\]

여기서 64는 DFT의 각 항을 구성하는 곱셈의 개수이며, 전체 산술 연산 횟수는 아닙니다.

행렬의 크기를 확대하면서 \\(N^2\\)라는 계산 구조를 강조합니다.

## **Scene 03. 계산에 숨어 있는 회전의 대칭성**

00:36–01:04 · 수학적 구조의 발견

이번 영상에서 가장 중요한 수학적 기반이 되는 장면입니다.

### **36–40초 — 행렬 내부를 확대한다**

앞서 보여준 DFT 행렬을 확대합니다.

각 칸에 있던 복소 지수함수를 다음과 같이 간결하게 표현합니다.

\\[ W_N=e^{-2\pi i/N} \\]

\\[ X_k=\sum\_{n=0}^{N-1}x_nW_N^{kn} \\]

행렬에 등장하는 회전 인자들이 서로 완전히 다른 값이 아니라, 같은 복소수의 거듭제곱이라는 사실을 시각적으로 보여줍니다.

### **40–45초 — 복소 지수함수에서 회전으로**

복소평면을 등장시킵니다.

\\[ e^{-i\theta}=\cos\theta-i\sin\theta \\]

원점에서 실수축의 1을 향하는 벡터를 그린 후, 시계 방향으로 회전시킵니다.

표준 DFT에서는 지수에 음의 부호가 있으므로 시계 방향으로 표현합니다.

### **45–49초 — 8개의 회전 인자 배치**

\\[ W_8=e^{-2\pi i/8} \\]

원을 45도씩 나누면서 여덟 개의 점을 차례대로 생성합니다.

Manim에서는 `ValueTracker`와 `always_redraw`를 사용하여 하나의 회전 벡터가 이동할 때마다 점을 남기도록 구현할 수 있습니다.

### **49–55초 — 큰 구조 안에 작은 구조가 존재한다**

홀수 지수에 해당하는 회전 인자들을 흐리게 처리합니다.

짝수 지수의 네 점만 파란색으로 강조합니다.

\\[ W_8^{2k}=W_4^k \\]

8점 복소평면에서 선택한 네 점을 복제하여 오른쪽의 4점 복소평면으로 이동시킵니다.

점의 위치가 변하지 않고, 수식의 아래첨자와 지수만 바뀌도록 연출합니다.

일반적인 관계도 표시합니다.

\\[ W_N^{2k}=W\_{N/2}^k \\]

**큰 변환 속에 작은 변환의 구조가 그대로 포함되어 있습니다.**

### **55–60초 — 반대편 회전 인자의 관계**

이번에는 단위원에서 한 점과 정반대에 있는 점을 선택합니다.

\\[ W_8^{k+4}=-W_8^k \\]

45도 위치에 있던 벡터를 반 바퀴 회전시켜 반대편의 벡터와 겹치게 합니다.

두 복소수의 절댓값은 동일하고, 부호만 반대라는 사실을 나타냅니다.

### **60–64초 — 두 가지 성질을 정리한다**

화면 중앙에 다음 두 식을 남깁니다.

\\[ \color{#42B8E8}{W_N^{2k}=W\_{N/2}^{k}} \\]

\\[ \color{#A18CF3}{W_N^{k+N/2}=-W_N^k} \\]

첫 번째 식에는 `분할`, 두 번째 식에는 `재사용`이라는 작은 라벨을 붙입니다.

이 두 성질을 다음 장면의 계산 구조 변화와 직접 연결합니다.

## **Scene 04. 하나의 변환을 두 개로 나눈다**

01:04–01:20 · 짝수·홀수 분할

### **64–69초 — 입력을 재배치한다**

처음 등장했던 8개의 샘플 카드가 다시 나타납니다.

중요한 것은 8개의 데이터를 앞의 4개와 뒤의 4개로 나누는 것이 아니라는 점입니다.

짝수 인덱스와 홀수 인덱스에 해당하는 카드가 서로 다른 방향으로 이동하도록 명확하게 표현합니다.

### **69–76초 — 수식에서도 동일하게 분리된다**

화면에 8점 DFT를 전개한 수식을 배치합니다.

\\[ \begin{aligned} X_k={}&x_0+x_1W_8^k+x_2W_8^{2k}\\\ &+x_3W_8^{3k}+x_4W_8^{4k}\\\ &+x_5W_8^{5k}+x_6W_8^{6k}\\\ &+x_7W_8^{7k} \end{aligned} \\]

짝수 항은 파란색으로, 홀수 항은 노란색으로 변경합니다.

그 후 같은 색상의 항들끼리 이동해 두 그룹으로 모이게 합니다.

\\[ \begin{aligned} E_k={}&x_0+x_2W_4^k\\\ &+x_4W_4^{2k}+x_6W_4^{3k} \end{aligned} \\]

\\[ \begin{aligned} O_k={}&x_1+x_3W_4^k\\\ &+x_5W_4^{2k}+x_7W_4^{3k} \end{aligned} \\]

홀수 항에서 공통 회전 인자 \\(W_8^k\\)가 바깥쪽으로 빠져나오는 과정을 애니메이션으로 보여줍니다.

최종적으로:

\\[ \boxed{X_k=E_k+W_8^kO_k} \\]

여기서 \\(E_k\\)와 \\(O_k\\)는 각각 4점 DFT의 결과입니다.

4-point DFT

다음 장면에서 동일한 중간 결과로 서로 다른 주파수 성분을 얻을 수 있다는 것을 보여줍니다.

## **Scene 05. 왜 더하고 빼는 것만으로 두 결과를 얻을까?**

01:20–01:57 · 영상의 핵심 설명 구간

### **80–86초 — 두 중간값을 준비한다**

화면 왼쪽에 짝수 항의 변환 결과 \\(E_k\\)를 배치합니다.

오른쪽에는 홀수 항의 변환 결과 \\(O_k\\)를 배치합니다.

홀수 항에는 보라색의 회전 인자 \\(W_N^k\\)를 곱합니다.

\\[ \color{#42B8E8}{E_k} \qquad \color{#A18CF3}{W_N^k}\color{#E8B45D}{O_k} \\]

곱셈이 끝나면 \\(W_N^kO_k\\) 전체를 하나의 계산 결과 카드로 묶습니다.

이 카드는 이후 덧셈과 뺄셈에서 재사용합니다.

### **86–90초 — 덧셈**

두 중간값 카드가 덧셈 연산자로 이동합니다.

\\[ X_k=E_k+W_N^kO_k \\]

8점 DFT의 예시에서는 \\(k=1\\)을 선택합니다.

\\[ X_1=E_1+W_8O_1 \\]

첫 번째 결과가 초록색으로 나타납니다.

### **90–95초 — 뺄셈**

새로운 입력을 생성하지 않습니다.

앞서 사용했던 두 중간값 카드를 그대로 복제하여 뺄셈 연산자로 이동시킵니다.

\\[ X_5=E_1-W_8O_1 \\]

동일한 중간값 → 서로 다른 두 주파수 성분

\\(X_1\\)과 \\(X_5\\)가 서로 다른 주파수 성분이라는 점을 표시합니다.

### **95–106초 — 짝수 항은 유지되고 홀수 항은 반전된다**

이 구간에서는 반드시 **주파수 인덱스 하나를 구체적으로 선택**하는 것이 좋습니다.

8점 DFT에서

\\[ k=1\longrightarrow k=5 \\]

로 이동하는 모습을 보여줍니다.

각 입력 항에 적용되는 회전 인자의 지수를 비교합니다.

8점 DFT · 주파수 인덱스 이동

| 입력 | \\(k=1\\)     | \\(k=5\\)     | 변화    |
| -- | ------------- | ------------- | ----- |
| x0 | \\(W_8^{0}\\) | \\(W_8^{0}\\) | 유지    |
| x1 | \\(W_8^{1}\\) | \\(W_8^{5}\\) | 부호 반전 |
| x2 | \\(W_8^{2}\\) | \\(W_8^{2}\\) | 유지    |
| x3 | \\(W_8^{3}\\) | \\(W_8^{7}\\) | 부호 반전 |
| x4 | \\(W_8^{4}\\) | \\(W_8^{4}\\) | 유지    |
| x5 | \\(W_8^{5}\\) | \\(W_8^{1}\\) | 부호 반전 |
| x6 | \\(W_8^{6}\\) | \\(W_8^{6}\\) | 유지    |
| x7 | \\(W_8^{7}\\) | \\(W_8^{3}\\) | 부호 반전 |

회전 인자의 지수는 8을 주기로 반복됩니다.

이 표 전체를 한 번에 보여주기보다는 짝수 행과 홀수 행을 각각 순차적으로 활성화합니다.

복소평면에서의 대응도 함께 표현합니다.

주파수 인덱스에 따른 회전 인자

k = 1k = 5

짝수 항 n = 2

\\(W_8^{2}\\)

초기 위치

홀수 항 n = 1

\\(W_8^{1}\\)

초기 위치

\\[ W_N^{(k+N/2)n}=W_N^{kn}(-1)^n \\]

이 관계가 이번 장면의 결정적인 수학적 근거입니다.

\\[ (-1)^n= \begin{cases} +1 & n\text{이 짝수}\\\ -1 & n\text{이 홀수} \end{cases} \\]

따라서 주파수 인덱스를 \\(N/2\\)만큼 이동하면 짝수 입력의 기여는 유지되고, 홀수 입력의 기여만 반전됩니다.

### **106–112초 — 두 수식의 공통 구조 발견**

두 출력을 나란히 배치합니다.

\\[ X_1= \color{#42B8E8}{E_1}+ \color{#E8B45D}{W_8O_1} \\]

\\[ X_5= \color{#42B8E8}{E_1}- \color{#E8B45D}{W_8O_1} \\]

두 식을 반투명하게 겹치면 덧셈과 뺄셈 기호를 제외한 모든 요소가 일치합니다.

이때 \\(E_1\\)과 \\(W_8O_1\\)을 각각 박스로 묶습니다.

**달라지는 것은 결합 연산뿐입니다.**

Radix-2 FFT에서는 단계별로 결합되는 인덱스 사이의 간격이 두 배씩 증가합니다.

```
def butterfly_pairs(n, stage):    half = 1 << stage    block = half * 2    pairs = []    for start in range(0, n, block):        for j in range(half):            pairs.append({                "upper": start + j,                "lower": start + j + half,                "twiddle": np.exp(                    -2j * np.pi * j / block                )            })    return pairsfor stage in range(3):    print(        stage + 1,        butterfly_pairs(8, stage)    )
```

# **5. 영상화할 때 주의할 부분**

**회전 인자의 방향:** DFT의 음의 지수를 기준으로 복소수는 시계 방향으로 회전해야 합니다.

**짝수·홀수 분할:** 입력값 자체가 짝수인지 홀수인지가 아니라, 입력의 인덱스가 짝수인지 홀수인지에 따라 분할합니다.

**버터플라이 결과의 재사용:** 유도 과정에서 \\(E_k\\)와 \\(O_k\\)는 작은 DFT의 결과이고, 홀수 쪽에 회전 인자를 곱한 중간값을 한 번 계산하여 두 출력에서 공유합니다.

**계산 복잡도:** \\(N^2\\)과 \\(N\log N\\)은 계산량의 증가율이며, 실제 연산 횟수나 실행 시간과 정확히 일치하는 수치는 아닙니다.

**알고리즘의 범위:** 영상은 \\(N\\)이 2의 거듭제곱인 경우의 Radix-2 Cooley–Tukey FFT를 기준으로 설계했습니다.

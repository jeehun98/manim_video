# 장면 설계

파랑 짝수 입력/E, 노랑 홀수 입력/O, 보라 회전 인자, 초록 출력. 입력은 0부터 인덱싱한다. 상단 현재 주장, 중앙 도형과 식, 하단 독립 발화 자막.

- 0–12초: 같은 변환, 다른 계산 구조 (Shot01)
- 12–36초: 직접 계산은 왜 N²일까? (Shot02)
- 36–64초: 회전 인자의 주기성과 대칭성 (Shot03)
- 64–80초: 짝수·홀수 인덱스로 분할 (Shot04)
- 80–117초: 같은 중간값으로 두 출력 (Shot05)
- 117–125초: 버터플라이 연산 (Shot06)
- 125–139초: 작게 나누고 단계별로 결합 (Shot07)
- 139–157초: 계산 구조에서 N log N으로 (Shot08)
- 157–177초: 대칭성으로 줄이는 계산 (Shot09)

대표 검수: Shot03 시계방향·네 점 대응, Shot05 주파수 이동·중간값 공유, Shot06 버터플라이, Shot07 입력 순서와 세 단계. 마지막 출력은 실제 직접 DFT 및 FFT 수치 검산과 연결한다.

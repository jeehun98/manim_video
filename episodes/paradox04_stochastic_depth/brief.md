# 신경망의 역설 04 — 신경망은 얕게 학습해야 더 깊어진다?

## 제작 상태

- 최신 사용자 확정 대본 26문단과 누적 종료 시각을 반영해 133초 영상으로 제작한다. TTS 음원은 미제공으로 무음 마스터이다.
- narration.md·tts_script.txt를 최신 원고로 갱신하고, timing.json·SRT·scene.py를 제작한다. 렌더 ID는 paradox04이다. 최종 1080×1920, 30fps, 미리보기 360×640.
- 이전 영상 복습·다음 영상 예고 없이 해당 질문과 결론으로 독립적으로 완결한다.

## 중심 주장

전체 구조는 깊게 유지하되, 학습에서는 기존 잔차 연결을 이용해 일부 변환을 건너뛴다. 공유된 가중치를 가진 부분 신경망들의 깊이와 구성이 달라지며, 잔차 변환을 거치는 계산·역전파 단계가 줄어든다. 이 방법은 깊은 신경망의 학습과 일반화에 도움이 될 수 있다.

## 주요 화면 변화

1. 깊은 전체 네트워크와 짧아진 학습 경로를 대비한다.
2. 단순 직렬 신경망을 임의로 끊는 것과 달리, 잔차 블록에는 기존의 두 경로가 있음을 설명한다.
3. 입력 x와 변환 F(x)를 더하는 동일 차원 identity 블록을 확대한다.
4. 화면에 x다음=x+bF(x)를 표시하고 b=1과 b=0을 전환한다. 추가되는 것은 잔차 분기의 0/1 게이트이며, 새로운 학습 가능한 연결이 아니다.
5. 8개 대상 잔차 블록 중 5개와 4개가 살아남는 예시를 교대한다. 전체 골격과 각 블록의 가중치 표시는 유지한다.
6. 같은 회로에서 역방향 화살표를 표시한다. 꺼진 잔차 분기의 미분을 생략하고 항등 경로로 기울기가 흐르는 모습을 보여준다.
7. 8개의 이진 선택에서 2⁸=256가지 조합을 나타낸다. 깊이만 달라지는 것이 아니라 같은 깊이에서도 구성 블록이 다를 수 있음을 보여준다.
8. 여러 부분 신경망에서 같은 블록 Fₗ과 가중치를 공유한다는 점을 강조한다.
9. 추론에서는 전체 블록으로 돌아오고, 원래 방법의 생존 확률 보정을 잔차 출력에 표시한다.
10. 깊은 전체 구조와 짧은 학습 경로를 다시 대비하며 완결한다.

## 수학적 정확성 기준

- 핵심 식은 같은 차원의 identity shortcut 블록 xₗ₊₁=xₗ+bₗFₗ(xₗ)이다. 블록의 합산 뒤 비선형성을 생략한 설명 모형임을 명시한다.
- 원 논문에는 합산 후 ReLU가 있으며, 저자들이 사용하는 비음수 입력에서는 생략 블록이 identity로 환원된다. 차원 변경 구간의 projection shortcut까지 항상 입력을 그대로 보존한다고 일반화하지 않는다. 화면의 8개 게이트 예시는 동일 차원 구간으로 한정한다.
- bₗ=0이면 변환 분기를 생략해도 identity 경로가 남는다. bₗ=1이면 두 경로를 합산한다. ‘새 경로가 만들어진다’는 표현은 기존 경로의 활성 패턴 변화라는 뜻이며 동적으로 새 연결 가중치를 생성한다는 뜻이 아니다.
- 원래 방식은 미니배치마다 블록 게이트를 표본 추출한다. 대본의 ‘이번 학습’은 해당 학습 단계의 미니배치를 뜻한다. 현대적인 샘플별 DropPath 구현과 섞지 않는다.
- 단순화한 모형의 국소 야코비안은 I+bₗJ_Fₗ이다. bₗ=0이면 I이다. 꺼진 구간의 변환 미분을 생략한다는 사실과 전체 기울기의 소실·폭주가 보편적으로 해결된다는 주장은 구별한다.
- 지름길과 항등 경로 자체는 ResNet의 성질이다. Stochastic Depth가 추가하는 것은 잔차 변환의 무작위 생략과 유효 깊이 변화이다.
- 8개 블록의 독립적인 이진 선택이 모두 가능하면 조합은 256개이다. 8개 깊이가 아니라 256개 구성이다. 같은 수의 블록이 켜져도 블록 조합은 다를 수 있다. 게이트 확률이 0 또는 1로 고정된 블록이 있다면 가능한 구성 수는 줄어든다.
- 5개·4개는 가능한 표본 예시이다. 정확히 그 수만 선택하도록 강제하거나, 각 단계마다 반드시 다른 깊이가 나온다고 주장하지 않는다. 문장의 ‘매번 달라짐’은 깊이가 무작위로 변할 수 있다는 뜻이다.
- 서로 다른 부분 신경망은 가중치를 공유하며, 별도 모델 256개를 독립적으로 학습하는 것이 아니다.
- 원래 방법은 학습 중 bₗFₗ을 사용하고, 추론 시 pₗFₗ로 조정한다. pₗ은 생존 확률이다. 학습 중 bₗFₗ/pₗ을 사용하고 추론에서 Fₗ을 쓰는 inverted 방식과 혼용하지 않는다.
- 전체 블록을 사용하는 추론은 비선형 네트워크 모든 마스크 출력의 정확한 평균이라는 보장은 없다.
- 블록을 실제 조건부로 생략해야 그 분기의 연산 비용을 줄일 수 있다. F를 모두 계산한 뒤 출력만 0으로 만드는 구현의 속도 향상을 보장하지 않는다. 실측 속도·정확도 수치는 넣지 않는다.
- 더 높은 정확도나 더 깊은 구조의 학습 성공을 모든 데이터·모델·확률 설정에서 보장하지 않는다.
- 특정 앞단 표현에 대한 의존 완화는 정규화 효과를 설명하는 직관이다. 일반화 개선의 유일한 원인이나 보편적으로 증명된 인과 관계로 제시하지 않는다.
- 학습 목적은 마스크 분포에 대한 기대 손실 minθ Eᵦ[L(fθ,ᵦ(x),y)]이다. 화면의 여러 행은 별도 가중치가 아니라 같은 θ의 서로 다른 활성 패턴이다. 256개를 한 단계에 전수 계산하는 것이 아니라 표본 추출한 구성으로 갱신한다.
- 같은 전체 추론 구조의 표현력과 무작위 부분 경로의 학습 목적을 구별한다. 부분 신경망의 수가 많다는 사실을 독립적인 학습 파라미터 수나 전체 함수 클래스의 증가로 해석하지 않는다.

## 최신 장면 타이밍

문단 종료: 6 / 8 / 17 / 21 / 27 / 31 / 38 / 44 / 48 / 51 / 57 / 60 / 67 / 71 / 75 / 79 / 85 / 91 / 96 / 100 / 105 / 113 / 119 / 125 / 130 / 133초.

- 0–21초: 깊은 전체 구조와 짧은 학습 경로의 질문.
- 21–44초: 잔차 분기와 항등 분기, 게이트 OFF와 순·역방향 전달.
- 44–60초: 8개 블록, 256개 구성, 5개·4개 활성 예시.
- 60–75초: 앞단 변환이 빠진 경우에도 후단 블록이 작동하도록 학습.
- 75–85초: 표현력과 학습이 선택하는 함수를 구별.
- 85–105초: 여러 경로의 평균 손실, 가중치 공유, 정규화.
- 105–113초: 원래 방법의 추론 시 생존 확률 보정.
- 113–133초: 더 작은 모델의 표현력이 아니라 여러 경로에서 작동하는 해를 찾는 학습으로 완결.

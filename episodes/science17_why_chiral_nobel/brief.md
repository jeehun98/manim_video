# 제작 기준 — 왜 분자의 비대칭이 노벨 화학상을 받았을까?

- 목표: 1편의 자기촉매 메커니즘을 반복하지 않고, 이 연구가 바꾼 질문과 노벨상의 의미를 설명한다.
- 핵심 흐름: 생명의 homochirality → 대칭적인 법칙 → 기존 비대칭 합성의 질문 후퇴 → Kagan의 증폭 → Soai의 피드백 → 자발적 대칭 깨짐이라는 문제 설정 → 생명의 기원과 합성화학.
- `0.00005% ee → 99.5% ee` 수치와 세부 반응 과정은 1편과의 중복을 피하기 위해 사용하지 않는다.
- 기존 비대칭 합성은 키랄 촉매만을 뜻하지 않으므로 화면과 내레이션에 `촉매나 다른 키랄한 원천`이라고 표현한다.
- Soai 반응은 생명의 손성에 대한 가능한 증폭 경로를 제공하지만 실제 역사와 최초 편향의 기원을 확정하지 않는다.
- 16장면, 실제 TTS 누적 시각 기준 146초, 세로 1080×1920 / 30fps / 무음.

## 근거

- Soai et al., Nature 1995, DOI 10.1038/378767a0

- 촉매에서 생성물로 이어지는 질문 사슬의 레이블과 피드백 비교 패널의 점 위치를 수정해 겹침과 경계 이탈을 제거했다.

# Dynamic Inference 01 제작 기준

- 한 편에서 남길 발견은 `모델의 최대 깊이가 고정되어 있어도 실제 실행 깊이는 입력마다 달라질 수 있다`이다.
- Early Exit은 중간 classifier의 confidence가 기준 이상일 때 뒤쪽 레이어 전체를 생략하는 동적 추론으로 표현한다.
- confidence는 정답 보장이 아니므로 threshold를 낮출 때의 조기 오판 위험과 높일 때의 작은 계산 절감을 함께 보여준다.
- 학습법, calibration, 다중 exit loss는 이 편에서 다루지 않는다.
- 입력 사진 세 장은 내장 생성형 이미지 도구로 제작한 PNG이며 Manim은 해당 이미지를 배치하고 애니메이션만 담당한다.
- 초반 세 입력의 전체 경로에서 쉬운 입력 하나의 L4 예측으로 카메라의 논리가 자연스럽게 좁혀지도록 구성한다.
- 마지막 Token 장면은 다음 편 `Token Pruning`의 질문만 남긴다.
- 영상은 82초, 1080×1920, 30fps 무음 마스터다.

## 생성 이미지 프롬프트 요약

- `easy_cat.png`: 선명하고 식별하기 쉬운 줄무늬 고양이, 정사각형 사진, 중립 실내 배경, 텍스트 없음.
- `ambiguous_animal.png`: 털과 자세 때문에 고양이와 작은 개 사이가 다소 모호한 장모 동물, 정사각형 사진, 텍스트 없음.
- `blurry_animal.png`: 움직임 블러와 약한 저조도 노이즈가 있는 고양잇과 동물, 정사각형 사진, 텍스트 없음.

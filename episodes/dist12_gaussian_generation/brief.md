# 분포의 수학 12 제작 기준

- 학습 목표: 표준 2차원 Gaussian `Z~N(0,I)`에 선형변환과 이동을 적용해 다양한 Gaussian을 **생성**한다. Whitening을 별도 주제로 반복하지 않고 마지막 역방향 장면에서 짧게 회수한다.
- 화면의 표본은 고정 난수 72개를 중심화·표준화해 표본 평균 0, 공분산 `I`가 정확하도록 만든다. 같은 점들을 매 장면 `Z → SZ → RSZ → RSZ+μ`로 변환한다.
- 사용 행렬은 `S=diag(2,1)`, `R`은 `45°` 회전, `A=RS`, 화면 예시 평균은 `μ=(1,−0.6)`이다. `Cov(SZ)=diag(4,1)`, `Cov(AZ)=AAᵀ=[[2.5,1.5],[1.5,2.5]]`이다. 점군과 타원은 같은 행렬로 변환한다.
- 일반적으로 공분산 `Σ`가 대칭 양의 준정부호이면 `AAᵀ=Σ`인 행렬 `A`를 택할 수 있어 평균 `μ`인 Gaussian `AZ+μ`를 만들 수 있다. 이 편의 그림과 역변환은 양의 정부호·가역 행렬 예시를 사용한다. 특이 공분산의 Gaussian은 낮은 차원에 놓이는 퇴화 분포이며 일반적인 2차원 밀도와 구별한다.
- `Z~N(0,I)`는 모든 방향의 단위벡터 `v`에 대해 `Var(vᵀZ)=1`이다. 가로 좌표를 2배 늘리면 분산은 4배가 된다. 공분산 공식은 `Cov(AZ)=A Cov(Z) Aᵀ=AAᵀ`다. 이동은 평균만 바꾸고 공분산을 바꾸지 않는다.
- 마지막 역방향 `A⁻¹(X−μ)` 장면은 이 예시를 표준 공간으로 되돌리는 Whitening 직관이다. 임의의 복잡한 분포 생성은 다음 질문으로만 남기며, 이 편에서 비선형 변환의 수학은 전개하지 않는다.
- 흐름: 표준 원형 → 방향 동등 → 가로 늘리기 → 분산 변화 → 회전 → 행렬 A → `AAᵀ` → 목표 공분산 → 평균 이동 → 생성식 → 여러 Gaussian → 역방향/Whitening → 더 복잡한 분포 질문.
- 실제 TTS 길이는 아직 없어 50초 목표의 압축 대본이다. 구간 경계는 4,8,12,16,20,24,28,32,36,40,44,47,50초. 1080×1920, 30fps, 무음.

# EP.20 제작 기준

- 확정 길이 345초, 1920×1080, 16:9, 30fps, 무음.
- 43개 독립 씬, 사용자 문장 종료 시각 82개를 준수한다.
- 교점 → 로그 변환 → β=3α → m=3 → β⁴=3 → g(m) → (pqr)²=48.
- 실제 조건을 만족하는 b와 교점으로 그래프를 그린다. 수치 b는 화면에 공개하지 않는다.
- 색: 지수함수 청록, 로그함수 보라, 교점 노랑, 직선 초록.
- 세 빈칸 상태를 상단에 유지하며 관련 로그 관계를 계산 중 표시한다.
- 186–191초 원문의 밑변환 설명은 분자·분모가 반대다. 화면·자막만 교정하고 발음 원문 보존.
- 대표 그래프, 로그 대입, 밑변환, 최종 계산을 미리 확인한 뒤 최종 렌더한다.


## 고정 문제 정보 카드 (2026-11-16)

최종본에는 원래 조건과 구하는 값을 상단 1920×180 영역에 고정 표시한다. 기존 본문과 자막은 화면비를 유지해 1600×900으로 축소하고 (160,180)에 배치한다. 길이·발화·프레임 수는 유지한다. 공통 카드 정의와 합성 도구: `episodes/csat_series/problem_cards/`. 원본 보관: `exports/problem_card_originals/`.

# EML 02 제작 기준

- 항등식: `ln x = EML(1, EML(EML(1,x),1))`, 실수 범위에서는 `x>0`.
- 계산 순서: `A=EML(1,x)=e−ln x`, `B=EML(A,1)=eᵉ/x`, `EML(1,B)=e−ln(eᵉ/x)=ln x`.
- tree의 내부 노드는 모두 동일한 `EMLNode`이며 post-order로 아래에서 위로 활성화한다.
- 핵심 메시지는 복잡한 식 자체가 아니라 `같은 primitive + 다른 연결 구조 → 다른 연산`이다.
- 새 log 하드웨어가 생긴다고 해석하지 않는다. 여기서 graph는 표현 graph이며 실제 실행 비용과는 별도다.
- 3편은 상수 1에서 `e`, `0`, `−1` 등을 생성하는 방향으로 이어간다.

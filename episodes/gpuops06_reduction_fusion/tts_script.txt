앞에서는 현재 가지고 있는 값 하나를 바이어스와 렐루에 계속 넘겼습니다. 원소 하나의 경로를 이어 붙인 퓨전이었습니다.

이번에는 상황을 바꿔보겠습니다. 각 원소에 렐루를 적용한 뒤 모든 결과를 더합니다.

렐루까지는 원소 하나만 있으면 됩니다. 하지만 최종 합은 엑스 이 하나만 가지고 결정할 수 없습니다. 여러 결과가 만나야 합니다.

두 커널을 따로 실행하면 모든 렐루 결과를 텐서로 만들어 글로벌 메모리에 저장하고, 리덕션 커널이 다시 읽어 합을 계산합니다.

그런데 최종 출력에 이 배열 자체가 필요한 것은 아닙니다. 필요한 것은 배열 안 값들의 합입니다.

그렇다면 렐루 결과가 만들어지는 순간 그 값을 현재까지의 파셜 섬에 반영할 수 있습니다. 중간값 대신 필요한 상태를 갱신합니다.

지피유에서는 여러 쓰레드가 동시에 값을 처리합니다. 하나의 합을 순서대로 만들기보다, 각 실행 그룹이 자신의 파셜 섬을 만들 수 있습니다.

합은 부분적으로 계산한 결과를 다시 합칠 수 있습니다. 여러 파셜 섬을 트리처럼 머지하면 전체 리덕션 결과가 됩니다.

이제 모든 렐루 결과를 하나의 중간 텐서로 완성해 놓을 필요가 없습니다. 값은 생성되면서 파셜 스테이트로 축약됩니다.

에필로그 퓨전은 현재 값 하나를 다음 연산에 넘겼습니다. 리덕션 퓨전은 여러 값을 작은 부분 상태로 축약하면서 넘깁니다.

이 구조는 섬뿐 아니라 맥스나 민에도 나타납니다. 여러 값을 어떤 작은 상태로 모아 다시 합칠 수 있는가, 다음에는 소프트맥스를 생각해볼 수 있습니다.

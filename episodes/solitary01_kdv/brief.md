# 제작 기준

9:16, 1080×1920, 60fps, 174초. 제공된 문장 종료 시각을 사용한다. 음원은 제공되지 않았다.

| 구간 | 화면 |
| --- | --- |
| 0–17 | 창작 캐릭터의 장풍에서 이동하는 봉우리로 전환 |
| 17–34 | 돌의 입수, 동심원, 절단선을 통한 단면 추출 |
| 34–47 | 파장별 상대 이동과 실시간 합성 |
| 47–62 | 높이에 따른 특성 속도와 분산 비교 |
| 62–91 | 배의 정지, 물결의 분리, 높이와 반치폭, 고립파 정의 |
| 91–110 | 동일 속도의 성분에서 단일 봉우리의 평행이동으로 전환 |
| 110–122 | 선형 분산과 비대칭 진동 꼬리 |
| 122–137 | 특성선을 따른 앞쪽 경사의 압축 |
| 137–152 | 동일 초기 조건에서 비선형, 분산, KdV를 공통 시계로 비교 |
| 152–168 | KdV의 세 항과 파형 변화 대응 |
| 168–174 | 고립파 해와 높이·폭을 유지하는 진행파 |

후반의 네 모델은 모두 초기 파형 u₀(x)=½ sech²(x/2)를 사용한다. 선형 이류 속도는 1이며, 분산은 넓은 주기 영역에서 FFT 위상 진화로 근사한다. 비선형 특성선은 최초 교차 시간 √3/2 이전까지만 진행한다. KdV에서는 c=1인 정확한 진행파를 사용한다. 각 파장의 속도 차이를 설명하는 초반 세 성분은 개념도다. 장풍과 수로는 설명용 도식이다.

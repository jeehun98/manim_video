# 씬별 제작 기준

확정 입력은 사용자 대본과 종료 시각. 총 174초. 세로 프레임 9×16, 본문 y≥−4.9, 자막 중심 y=−6.15. 씬별 독립 렌더·교체 가능.

| 씬 | 초 | 주장·화면 |
| --- | --- | --- |
| 01 | 0–11 | 다른 숫자들을 묶어도 연산을 유지할 수 있는가? |
| 02 | 11–25 | 나머지를 기준으로 무한한 정수를 짝수·홀수 두 집단으로 |
| 03 | 25–42 | 구체적인 합이 달라도 결과 집단은 동일 |
| 04 | 42–62 | 짝수의 닫힘·항등원·역원. 부분군 2ℤ≤ℤ |
| 05 | 62–91 | 대표 선택 무관성, gNg⁻¹=N의 집합 보존, 가환인 정수 덧셈 |
| 06 | 91–107 | 두 잉여류가 [0]·[1]이라는 몫군의 원소가 됨 |
| 07 | 107–122 | 큰 홀수 합의 정확한 값 없이 결과 집단 결정 |
| 08 | 122–136 | 정사각형의 네 회전·네 반사, 회전부분군의 정규성 |
| 09 | 136–148 | 회전·반사의 합성표가 홀짝 덧셈표와 같음 |
| 10 | 148–157 | 부분군→정규부분군 조건→몫군의 역할 연결 |
| 11 | 157–167 | 개별 값은 흐려지고 두 원소의 덧셈 구조가 남음 |
| 12 | 167–174 | 무엇을 같은 것으로 볼 수 있는가로 완결 |

대표 저해상도 검수: 03의 숫자→집단 연산, 05의 집합 보존, 06의 잉여류→몫군 원소, 08의 꼭짓점 이동. 자동 검사: D₄의 64개 합성·C₄ 정규성·두 잉여류 합성 규칙, 정수 대표 변경의 일관성, 실제 렌더 변환 기록, 문장/SRT 일치·연속성, 자막 시각/범위, 각 씬/최종 영상의 길이·해상도·프레임 수·전체 디코딩.

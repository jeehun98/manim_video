# 제작 기준 — 모든 방향을 담는 집합의 차원

- 23장면 / 175초 사용자 제공 TTS 구간 종료 시각 반영 / 1080×1920 / 30fps / 무음. 3분 이내 쇼츠.
- 반전: 측도(면적·부피) 0과 작은 차원은 동의어가 아니다.
- 1–2: 연속적인 바늘 회전 문제. 3에서 각 방향의 단위 선분 포함이라는 집합 문제로 전환한다.
- 직관형 개정: 선과 Kakeya의 ‘같은 면적 0, 다른 방향 구조’를 먼저 대비한 후 해상도별 칸 수의 성장률로 차원을 소개한다. 4→8→16과 4→16→64를 실제 격자 변화로 보여준다.
- 특정 점을 확대할 때 반드시 새로운 방향이 등장한다고 주장하지 않는다. 집합 전체를 덮는 칸의 성장률에 관한 설명이다.
- 튜브는 유한 해상도의 분석 도구임을 독립 장면으로 설명한다. sticky/plank/slab 전문용어는 내레이션에서 제거하고, 확대 수준과 뭉침/퍼짐으로 말한다.
- 삼각형 겹침은 방향 보존의 개념도이며 실제 Besicovitch/Perron-tree 구성 또는 회전 경로의 증명이 아니다.
- 화면의 유한 선분·두꺼운 튜브는 방향과 근사의 개념도다. 화면에 그린 유한 다발 자체의 차원이 3이라는 뜻이 아니다.
- 상자 개수 N(r)의 성장률은 Minkowski/box 차원의 직관. 측도 0인 집합에서 정확한 N(r)~r^-3 상수 비교나 정확한 8배를 주장하지 않는다. 하위 차수 요인은 있을 수 있다.
- 논문 결론은 모든 R³ Kakeya 집합의 Hausdorff 및 Minkowski 차원 3. Kakeya maximal function 추측 등 모든 관련 추측이 해결됐다고 말하지 않는다.
- sticky, tube/plank/slab는 다중 규모 분석의 개념도. 단순한 두 갈래 그림을 완전한 증명으로 제시하지 않는다.
- 공동 증명자 Joshua Zahl 명시. 필즈상은 Hong Wang의 더 넓은 업적에 수여.

## 검증

- 360×640 / 30fps 미리보기 성공: 5,250프레임, 175초 목표.
- 23개 구간의 85% 지점 프레임을 모아 제목·본문·자막 영역을 시각 검토. 겹침 및 프레임 이탈 없음.
- 직관형 개정 미리보기 재검토: 해상도별 칸 수, 분리된 면적/차원 카드, 튜브 두께 설명, 두 갈래 증명 개념도, 실제 파형 화면 확인. 부피 문구와 입체 도형 간 간격 확보.
- 구간 경계 연속성 및 Python 구문 검사 통과.
- 직관형 개정 대본의 사용자 측정 TTS 총길이: 186초(3:06).
- TTS 축약: 발화 기준 문자 1,212→1,135개, 약 6.4% 감소. 같은 발화 속도에서 약 174초 예상(문자 비례 추정이며 재합성 실측 아님).
- 축약 후 사용자 제공 실측 종료 시각: 5,11,18,25,34,42,49,56,64,70,79,85,92,101,110,117,125,132,141,149,156,165,175초.

- 측정 타이밍으로 미리보기 및 최종본 재렌더. 실제 음성 파일은 전달되지 않아 mux하지 않음.

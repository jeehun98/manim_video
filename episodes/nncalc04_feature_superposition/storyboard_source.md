# 신경망 내부의 계산 04 — Feature Superposition 상세 영상화 콘티

총 159초 (2분 39초) · 16:9 · Manim 기반 · 발화 타임스탬프 기준

이번 영상은 뉴런 2개가 만드는 2차원 표현 공간을 영상 처음부터 끝까지 유지하면서, 그 안에 특징 5개를 배치하고, 겹침으로 인한 간섭과 희소성의 역할을 설명하는 구성이 가장 좋아.

특히 60초에 Superposition이라는 이름이 등장하기 전까지는 개념을 먼저 보여주고, 63\~99초에서는 실제 연구의 기하학적 발견으로 연결해. 103초부터는 벡터 방향과 뉴런 좌표축이 서로 다르다는 사실을 시각적으로 보여주면서 Polysemanticity를 설명하는 거야.

## 1. 영상 전체의 시각 설계

반복해서 사용할 핵심 공간

2개 뉴런의 좌표축과 5개 특징 방향을 표시한 개념도. 각도의 선택은 설명용이다.

### 색상과 레이아웃

| 시각 요소               | 색상        | 역할                  |
| ------------------- | --------- | ------------------- |
| Neuron 1 / Neuron 2 | 옅은 회색     | 고정된 좌표축             |
| 특징 F1\~F5           | 서로 다른 5색  | 특징의 구분              |
| 간섭 및 복원 오차          | 붉은색       | 특징 간 구분의 어려움        |
| 희소한 활성화             | 청록색       | 드물게 나타나는 특징         |
| 학습된 기하학적 배열         | 보라색 중심    | 실제 Toy Model의 표현 구조 |
| 뉴런의 다의성             | 여러 특징색 혼합 | 하나의 좌표에 다양한 특징 기여   |

화면 구성: 수학적 시각화가 중심일 때는 공간을 화면 왼쪽 약 65%에 크게 배치하고, 오른쪽 35%에 입력 특징과 활성화 상태를 보여줘. 103초 이후에는 좌측의 평면 그래프를 줄이고, 뉴런별 반응을 비교하는 화면으로 전환하면 돼.

### 중요한 과학적 구분

다섯 벡터가 서로 다른 방향을 가진다고 해서 2차원에 다섯 개의 독립적인 연속값을 손실 없이 저장할 수 있다는 뜻은 아니야.

시각화에서도 처음에는 간섭을 보여주고, 희소성이 그 간섭 비용을 낮출 수 있다는 순서를 유지하는 것이 중요해.

또한 특징은 벡터 방향, 뉴런은 표현 공간의 좌표축이라는 구분을 끝까지 유지해야 해.

# 2. 초 단위 상세 콘티

## 1막 — 뉴런 두 개로 몇 개의 특징을 표현할 수 있을까?

0:00–0:25 · 6개 발화 구간

장면 01 · 두 뉴런의 등장

0:00–0:04

발화: “신경망에 뉴런이 두 개뿐이라면, 서로 다른 특징을 몇 개까지 표현할 수 있을까요?”

화면 중앙에 뉴런 두 개를 배치한다. 처음에는 두 원이 각각 밝아지는 신경망 형태로 보여준다.

곧 뉴런 그림을 `Neuron 1`, `Neuron 2`라는 두 개의 숫자 출력으로 변형한다.

화면 오른쪽에는 `Feature 1`, `Feature 2`, `Feature 3`, `Feature 4`, `Feature 5` 다섯 카드를 차례로 나타내고, 물음표를 표시한다.

애니메이션: `FadeIn → Indicate → Transform`

장면 02 · 2차원 좌표계 생성

0:04–0:09

발화: “두 개의 뉴런이 만드는 표현 공간은 2차원입니다. 서로 수직인 방향도 두 개뿐이죠.”

각 뉴런의 출력값을 X축과 Y축으로 대응시킨다.

두 뉴런 그림이 좌표축으로 이동하고, 공간의 중앙에 90도 직각 표시가 등장한다.

\\[ h=(h_1,h_2)\in\mathbb{R}^2 \\]

뉴런 1의 활성화 = 가로좌표 · 뉴런 2의 활성화 = 세로좌표

애니메이션: `ReplacementTransform(NeuronOutputs, Axes)`

여기서 두 좌표축이 고정되며 이후 120초까지 계속 재사용된다.

장면 03 · 세 번째 특징의 문제

0:09–0:12

발화: “그렇다면 세 번째 특징부터는 포기해야 할까요?”

X축에는 F1, Y축에는 F2 화살표가 등장한다.

세 번째 특징 F3 카드가 공간 바깥에서 들어오지만, 새로운 수직축을 찾지 못하는 연출을 한다.

잠깐 공간을 어둡게 하고 `F3 = ?`를 띄운다.

의도: 두 개의 직교 방향만 존재한다는 사실을, 특징 두 개밖에 표현하지 못한다는 결론으로 단정하지 않고 질문으로 남긴다.

장면 04 · 특징을 방향으로 생각하기

0:12–0:17

발화: “특징을 하나의 뉴런에 대응시키는 대신, 벡터의 방향으로 표현한다고 생각해 봅시다.”

기존 F1과 F2가 뉴런 축에 붙어 있는 상태에서, F3를 대각선 방향으로 생성한다.

좌표축은 움직이지 않고 특징 벡터만 자유롭게 회전한다.

애니메이션: `GrowArrow → Rotate → Indicate`

화면에 `뉴런 = 좌표축`, `특징 = 방향`을 짧게 표시한다.

장면 05 · 여러 방향의 존재

0:17–0:21

발화: “2차원 평면에는 서로 다른 방향을 얼마든지 만들 수 있습니다.”

원점에서 12\~16개의 얇은 화살표를 방사형으로 생성한다. 이 화살표들은 밝기가 약하고, 벡터 방향의 다양성만 보여준다.

이후 대부분을 지워 다섯 방향만 남길 준비를 한다.

주의: 방향이 무한히 많다는 것은 실제 저장 가능한 독립 특징의 수가 무한하다는 의미가 아니야.

장면 06 · 특징 다섯 개 배치

0:21–0:25

발화: “예를 들어 다섯 개의 특징을 다섯 방향에 배치할 수 있죠.”

다섯 특징 F1\~F5를 다섯 색상의 벡터로 배치한다.

처음에는 서로 다른 임의의 방향으로 표시한다. 나중에 연구 결과에서 오각형 배열로 재정렬할 것이므로 이 단계부터 정오각형으로 놓지 않는 편이 좋아.

화면 하단에 `2 dimensions · 5 feature directions`를 표시한다.

## 2막 — 여러 특징을 겹치면 어떤 문제가 생길까?

0:25–0:39 · 3개 발화 구간

장면 07 · 선형독립성의 한계

0:25–0:30

발화: “하지만 여기에는 문제가 있습니다. 두 차원에 놓인 다섯 벡터는 서로 모두 독립적일 수 없습니다.”

다섯 특징 화살표를 그대로 유지한다.

이 중 F1과 F2 두 벡터를 강조하고, F3가 두 벡터의 선형결합으로 나타날 수 있다는 것을 보여준다.

\\[ v_3=a v_1+b v_2 \\]

두 벡터의 합성 애니메이션을 통해 F3와 같은 방향의 화살표를 만든다.

중요: 방향이 다르다는 것과 선형독립이라는 것은 다르다는 사실을 보여주는 장면이야.

장면 08 · 여러 특징이 동시에 활성화된다

0:30–0:35

발화: “여러 특징이 동시에 활성화되면 벡터들이 더해지고, 서로 간섭합니다.”

F1과 F3를 활성화한다.

원점에서 F1 벡터를 먼저 그린 뒤, 그 끝에서 F3 벡터를 평행이동하고 최종 합성 벡터를 표시한다.

\\[ h=x_1v_1+x_3v_3 \\]

나머지 세 특징은 회색으로 낮춘다.

F1과 F3 각각의 방향을 알아야 하는데 실제 출력은 하나의 합성 벡터라는 점을 강조한다.

장면 09 · 복원의 모호함

0:35–0:39

발화: “어떤 특징이 나타났는지 정확하게 구분하기 어려워질 수 있는 겁니다.”

합성 벡터의 끝점에 붉은색 테두리를 표시한다.

다른 특징들의 조합으로도 같은 위치 또는 비슷한 위치를 만들 수 있다는 것을 두 번째 합성 경로로 보여준다.

서로 다른 두 조합이 동일한 출력점으로 연결되는 개념적 그림이다.

연출 포인트: 이 장면에서는 표현의 모호함을 보여주되, 학습된 모델에서 모든 조합이 반드시 혼동된다는 식으로 묘사하지 않는다.

## 3막 — 특징이 드물게 나타나면 무엇이 달라질까?

0:39–1:03 · 5개 발화 구간

이 구간이 Superposition의 핵심 원리를 설명하는 부분이야. 앞선 장면에서 간섭이라는 문제를 만들었으므로, 이제 특징들의 동시 활성화 빈도가 줄어들면 간섭 비용도 달라진다는 것을 보여줘야 해.

### 장면 10 · 특징의 활성화 빈도를 바꾸는 실험

0:39–0:42

발화: “그런데 특징들이 아주 드물게 나타난다면 어떨까요?”

- 기존 2차원 공간과 다섯 특징 벡터를 유지한다.
- 우측 상단에 `Feature Activity`라는 제목의 패널을 만든다.
- 다섯 특징의 활성화 막대가 모두 높은 상태에서 하나씩 짧아진다.
- 동시에 활성화된 두 특징 벡터가 합쳐져 나타났던 붉은색 간섭 효과가 사라진다.

전환: 간섭 장면의 붉은색을 제거하고, 청록색 활성화 표시만 남긴다.

### 장면 11 · Dense와 Sparse의 차이

0:42–0:49

발화: “대부분의 입력에서는 다섯 특징 중 하나만 활성화되고, 여러 특징이 동시에 나타나는 경우는 드물다고 해봅시다.”

화면을 좌우로 분할한다.

입력마다 나타나는 특징의 차이

Dense

여러 특징이 자주 활성화

Sparse

소수의 특징만 활성화

설명용 활성화 패턴. 각 열은 특징, 각 행은 하나의 입력을 나타낸다.

애니메이션 순서

1. Dense 행렬의 각 행에서 여러 칸이 동시에 켜진다.
2. Sparse 행렬에서는 각 행에서 한두 칸만 켜지는 모습을 보여준다.
3. 두 행렬 아래에 각각 합성 벡터를 나타낸다.
4. Dense 쪽에서는 겹치는 화살표가 많고, Sparse 쪽에서는 대부분 하나의 특징 방향만 나타난다.

단, Sparse를 반드시 특징 하나만 활성화되는 상태로 정의하면 안 돼. 영상 속 입력은 이해를 위한 극단적인 예시야.

### 장면 12 · 간섭할 기회가 줄어든다

0:49–0:54

발화: “이 경우 특징들이 같은 차원을 공유하더라도 실제로 서로 간섭하는 상황은 줄어듭니다.”

화면을 다시 2차원 벡터 공간으로 복귀시킨다.

처음에는 F1과 F3가 동시에 켜져 하나의 합성 벡터를 만든다. 다음에는 F1만 활성화된 입력과 F3만 활성화된 입력을 순서대로 보여준다.

- 동시 활성화: 두 벡터의 합성
- 개별 활성화: 각 특징 방향의 신호가 나타남

핵심 자막: `동시 활성화 감소 → 간섭 비용 감소 가능`

여기서는 주의해야 할 부분이 있어. 특징을 하나씩 활성화하더라도 다른 특징 방향으로 투영하면 교차 반응이 생길 수 있어. 따라서 간섭이 완전히 사라진다고 표현하는 대신, 여러 특징이 함께 활성화되어 발생하는 간섭이 줄어드는 모습을 보여줘.

### 장면 13 · 완전한 분리 대신 공간 공유를 선택한다

0:54–1:00

발화: “신경망은 일부 간섭을 감수하는 대신, 제한된 공간에 더 많은 특징을 표현하는 선택을 할 수 있습니다.”

한 화면에 두 가지 선택을 비교한다.

일부 특징만 표현

적은 간섭, 일부 특징 포기

더 많은 특징 공유

공간 공유, 일부 간섭 허용

연출 포인트: 오른쪽의 공간 공유 방식이 언제나 더 뛰어나다는 식으로 보여주지 않는다. 희소성·특징 중요도·복원 오차에 따라 선택의 유불리가 달라진다는 메시지야.

1:00–1:03

화면의 모든 보조 패널을 제거한다.

## Feature Superposition

### 장면 15 · 다섯 특징을 두 차원에 압축하는 실험

1:03–1:12

발화: “2022년 발표된 토이 모델스 오브 슈퍼포지션 연구에서는, 다섯 개의 입력 특징을 단 두 차원의 내부 공간에 표현하도록 작은 신경망을 학습시켰습니다.”

Toy Model의 핵심 구조

입력

## 5D

5 Features

Bottleneck

## 2D

2 Neurons

재구성

## 5D

Reconstruction

애니메이션 순서

1. 서로 다른 다섯 입력 특징이 각각의 축으로 등장한다.
2. 다섯 입력이 두 개의 중간 활성화 값으로 압축된다.
3. 두 값에서 다시 다섯 개의 출력이 생성된다.
4. 원래 입력과 재구성 출력의 차이가 손실로 표시된다.

원 논문의 단순화된 모델에서는 비선형 출력, 묶인 가중치 등의 조건을 이용하므로 일반적인 임의의 5→2→5 오토인코더와 동일하게 단정하지 않는 것이 좋아.

### 장면 16 · 자주 활성화되는 특징

### 장면 17 · 희소성이 증가하면서 나타나는 변화

중요한 해석: 이 구조는 주어진 손실함수와 특징 분포하에서 학습된 결과야. 단순히 벡터 사이의 각도를 최대화하기만 하면 모든 조건에서 최적이라는 의미는 아니야.

- `FeatureVector`: 색상, 방향, 길이, 활성화 수준을 가진 벡터
- `ActivationPattern`: 특징별 활성화 여부를 표시하는 매트릭스
- `VectorComposition`: 복수 특징의 벡터 합성과 투영 표현
- `ToyModel`: 입력 특징, 2차원 병목, 재구성 출력을 연결하는 도식
- `NeuronResponse`: 입력에 따른 뉴런 활성화 막대
- `SparseFeatureView`: 다음 편 SAE와 연결할 특징 분해 도식

`ValueTracker`로 특징 벡터의 방향과 크기를 제어하고, `always_redraw`로 활성화 막대와 투영선이 연동되도록 구현하면 장면 사이의 시각적 연결을 자연스럽게 유지할 수 있어.

## 5. 최종 제작 우선순위

이번 영상에서 특히 시간을 투자해야 할 부분은 장면 08, 11\~13, 19, 24\~26이야.

- 08: 여러 특징 벡터가 더해지는 순간, 간섭이 생기는 이유를 명확히 전달한다.
- 11\~13: 희소성이 공간 공유를 유리하게 만들 수 있는 이유를 실제 활성화 패턴으로 보여준다.
- 19: 규칙적인 다섯 특징 방향이 등장하며 연구의 기하학적 발견을 전달한다.
- 24\~26: 특징 방향을 뉴런 좌표축에 투영하면서 하나의 뉴런이 여러 특징에 반응할 수 있는 이유를 설명한다.

특히 24\~26번은 이 영상의 결론을 이해시키는 데 가장 중요한 장면이야. 앞부분에서는 왜 많은 특징을 겹쳐 표현하는지가 설명되고, 여기서는 그 결과 신경망을 뉴런 단위로 해석하기 어려워지는 이유가 드러나거든.

이 구조라면 159초의 발화 시간을 그대로 유지하면서도 2차원 공간 → 특징 간섭 → 희소성 → 학습된 기하학 → 다의성 → 특징 분해라는 하나의 연속된 시각적 이야기로 완성할 수 있어.

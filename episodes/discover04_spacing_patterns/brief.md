# 수학적 발견 04 제작 기준

- 목표: 개별 값과 위치가 달라도, 정규화한 최근접 간격에는 비슷한 통계적 구조가 나타날 수 있다는 발견.
- 99초, 9:16, 1080×1920, 30fps, 무음. 콘티의 시간초보다 발견의 흐름을 우선한다. TTS 길이는 아직 실측하지 않았다.
- 구성: 독립 무작위 점 → 이름을 숨긴 실제 영점 배열 → 작은 간격의 차이 관찰 → 영점 정체 공개 → 간격 분포와 GUE 비교 → 레벨 반발 → 통계적 유사성과 이해의 구분.
- GUE 고유값은 무작위 행렬 모형의 자료이며 실제 양자계의 실험·시뮬레이션 자료로 표시하지 않는다. 초반 두 배열은 같은 개수의 점을 공통 평균 간격으로 환산한 뒤 같은 축척으로 표시한다.

## 실제 영점 자료

- Odlyzko zeros3.txt 원문을 저장한다. 영점 번호 10^12+1부터 10^12+10^4까지 10,000개, 최근접 간격은 9,999개이다.
- 원자료는 γ−267653395647의 오프셋이다. 보증 정확도는 10^−8. 전체 높이를 만든 뒤 차분하지 않고 오프셋끼리 차분해 유효 숫자를 보존한다.
- 각 간격의 중간 높이 t에서 log(t/(2π))/(2π)를 곱해 국소 평균 간격으로 환산한다. 마지막으로 유한 표본 평균을 정확히 1로 맞추는 작은 전역 보정을 적용한다. 보정 전 평균은 spacing_data.json에 기록한다.
- 낮은 위치의 첫 영점 몇 개를 전체 통계의 근거로 쓰지 않는다. 도입·간격 예시도 같은 높은 위치의 실제 자료를 사용한다.

## GUE 표본 및 이론

- 복소 가우스 A로 H=(A+A†)/√(2N)을 생성한다. N=160, 행렬 100개, seed=20261013. 각 행렬에서 정렬된 고유값의 중앙 60%(인덱스 32:128)를 사용한다.
- 반원 분포 CDF로 unfolding한 뒤 차분한다. 총 9,500개 간격이며, 표본 평균을 1로 맞춘다. 가장자리 고유값을 섞지 않는다.
- 흰 점선은 2×2 Wigner surmise가 아니다. bulk 사인 커널 K(x,y)=sin(π(x−y))/(π(x−y))의 Fredholm determinant E(s)=det(I−K_(0,s))를 Gauss–Legendre Nyström 48점으로 계산하고, cubic spline의 두 번째 미분으로 최근접 간격 밀도 p(s)=E''(s)를 얻는다.
- 계산 범위 s=0~4, 간격 0.01. 64점 적분과 비교하고 질량·1차 모멘트를 확인한다. 화면에는 0~3을 표시한다.
- 히스토그램은 0~3, bin 폭 0.15. 구간 밖 꼬리를 버리고 다시 정규화하지 않는다. 전체 표본 수와 bin 폭으로 확률 밀도를 계산한다.
- 재생성: `.venv\Scripts\python.exe episodes/discover04_spacing_patterns/prepare.py`. 영점 원문은 이미 저장되어 있어 재계산에 네트워크가 필요하지 않다.

## 구분해야 할 주장

- 비교하는 통계는 최근접 간격 분포이다. 몽고메리의 쌍상관 함수와 혼용하지 않는다. 제한된 쌍상관 결과를 전체 최근접 간격 분포의 증명이라고 말하지 않는다.
- 레벨 반발은 작은 정규화 간격의 억제이며 물리적인 반발력이 아니다. 독립 Poisson 점 과정의 최근접 간격 이론 exp(−s)와 비교한다.
- ‘간격<0.3’ 비율은 실제 영점 자료 약 2.6%, GUE 표본 약 2.8%, 독립 Poisson 이론 약 25.9%이다. 자료·모형·이론을 구분한다.
- GUE는 특정 대칭성의 일부 양자 혼돈계를 설명하는 모형이다. 모든 양자계에 적용하지 않는다. 예를 들어 시간반전 대칭 유무에 따라 다른 앙상블이 필요할 수 있다.
- 영점 통계의 GUE 대응 전체는 아직 미해결이다. 통계적 유사성이 동일한 시스템·공통 원인의 확정·리만 가설의 증명을 뜻하지 않는다.
- 힐베르트–푈리야 접근의 구체적 소개는 이 편에 넣지 않고 공통 구조에 대한 질문으로 마무리한다.
- captions.srt는 화면 요약 문구의 자막이다. 내레이션·TTS 대본은 전환 단위로 빈 줄을 둔다.

## 발견 중심 피드백 반영

- 초반 제목과 자막에서 영점·제타 함수의 이름을 숨긴다. 25초에 실제 영점의 정체를 공개하고, GUE는 분포를 겹치는 40초에 소개한다.
- 독립 배열은 seed=20261014의 균일 독립 표본 24개다. 정렬 후 표본 평균 간격을 1로 환산한다. 점들을 배치한 뒤 움직이거나 밀어내지 않는다.
- 다른 배열은 zeros3 원문의 인덱스 100:124, 즉 10^12+101부터 10^12+124까지의 실제 영점 24개다. 국소 평균 간격으로 환산하고 이 표시 창의 평균을 1로 맞춘다. 특정 패턴을 만들려고 점을 수정하지 않는다.
- 두 표시 창에 같은 축척을 적용한다. 개별 짧은 창은 관찰의 도입이며, 통계 판단은 전체 9,999개 간격의 히스토그램에 근거한다.
- 정규화 과정의 숫자·나눗셈 애니메이션은 빼고 ‘평균 간격 = 1’ 표기만 남긴다. 실제 자료·GUE 표본·이론의 표기는 유지한다.
- 2.6%와 25.9%는 검증된 화면 보조 정보로 유지하고 내레이션에서는 읽지 않는다.
- 마지막은 미해결 상태를 밝힌 뒤 ‘관계를 보기 시작하면 서로 다른 문제를 같은 관점에서 볼 수 있다’는 독립적인 학습 목표로 끝낸다.

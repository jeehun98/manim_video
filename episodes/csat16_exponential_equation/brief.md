# EP.16 제작 기준

사용자 제공 39개 문장 종료 시각 준수. 160초, 1920×1080, 30fps, 16:9. 음원 미제공으로 무음·화면 자막.

3^(x−6)=(1/9)^x. 1/9=3^−2, (3^−2)^x=3^−2x. 지수함수3^t의 일대일성으로 x−6=−2x → x=2. 검산 양변1/81. 주관식이므로 선택지 번호를 붙이지 않음. 음수지수 결과는 음수가 아님. a^−1=1/a는 a≠0, 실수지수 거듭제곱 법칙은 a>0을 표시. 지수비교 조건 a>0,a≠1. 밑1에서는 1²=1⁵임을 반례로 표시하고, 0<a<1은 감소하지만 일대일임을 설명.

23개 독립 교체 가능 씬. 수식 변환과 두 지수의 대응을 강조. 실제 함수좌표의 y=3ᵗ 그래프와 수평선의 유일한 교점으로 일대일성 설명. 이전 편 요약·다음 예고 없음.

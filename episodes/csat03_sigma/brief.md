# EP.03 시그마와 수열의 합

사용자 제공 확정 대본 21문장·109초, 1920×1080、16:9、30fps. 음원 미제공으로 무음·전체 자막.

출처: 제공 콘티 기준 2027학년도 6월 모의평가 수학 3번. 정답은 ④. 제공되지 않은 다른 선택지의 값은 만들어 표시하지 않는다.

핵심: 같은 합산 범위와 bₖ의 계수 확인 → 두 식 뺄셈 → bₖ 소거 → 합=9. 연립방정식 치환은 같은 원리를 설명하는 다른 풀이. A=9, B=1.

aₖ와 A는 청록, bₖ와 B는 보라. 범위와 내부 항은 별도 객체. 괄호 앞 마이너스를 두 항 모두에 적용하고, 보라색 두 항이 합쳐져 소거되게 한다. 범위가 다르면 공통항과 남는 항을 분리한다.

13개 독립 교체 씬, 제공 문장 종료 시각 고정. 1·2편의 폰트·팔레트·자막·렌더 도구 재사용. 이전 편 복습·다음 편 예고·별도 엔드카드 없음.

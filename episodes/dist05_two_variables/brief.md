# 분포의 수학 05 제작 기준

- 학습 목표: 두 변수를 함께 관측하면 각 변수의 1차원 분포(주변분포) 외에 **어떤 x와 어떤 y가 한 쌍인지**가 새 정보로 생김을 이해한다.
- 앞부분의 한 사람 예시는 `(키, 몸무게)=(172,68)`이며 단위는 화면에 `cm`, `kg`로 적는다. 다른 관측값은 `(165,55)`, `(170,63)`, `(175,70)`, `(180,78)` 등을 포함한다.
- 비교용 13명 데이터의 키 목록은 `[155,158,160,163,165,168,170,172,175,178,180,183,185]`이고 몸무게 목록은 `[50,52,53,56,55,60,63,68,70,69,78,76,81]`이다. A는 같은 인덱스끼리 짝지어 대체로 우상향한다. B는 키 순서를 유지하고 몸무게 목록을 뒤집어 짝지어 대체로 우하향한다. 두 점구름은 키 값들의 다중집합과 몸무게 값들의 다중집합이 각각 정확히 같으므로 두 주변분포가 같다. 쌍의 구성만 다르다.
- 키와 몸무게는 설명을 위한 관측 예시이며, 함께 움직인다는 관찰을 인과관계로 해석하지 않는다.
- 점구름의 등고선은 방향을 돕는 개념적 스케치다. 실제 확률밀도 추정 결과라고 주장하지 않는다.
- 순서: 1차원 요약 → 두 값의 관측 → 평면의 한 점 → 점구름 → 축별 투영 → 같은 주변분포와 다른 짝짓기 → 반대 방향 → 함께 움직임 → 새 정보의 필요 → 관계와 방향 → 공분산 질문.
- 실제 TTS 음성이 아직 없으므로 짧은 대본에 맞춘 목표 길이 46초, 구간 경계 4, 8, 12, 16, 20, 25, 29, 33, 37, 41, 46초다. 1080×1920, 30fps 무음. 숫자·영문은 원문 표기하고 발음 표기만 TTS 파일에 둔다.

# 분포의 수학 01 제작 기준

- 학습 목표: 분포를 가능한 값의 공간에 확률이 놓인 구조로 이해한다.
- 예시 데이터는 `[1, 1, 2, 2, 2, 4]`이며 빈도는 1에 2개, 2에 3개, 3에 0개, 4에 1개다. 순서를 섞어도 빈도 모양은 같다.
- 이 여섯 관측값에서 얻는 것은 **경험적 분포**다. `P̂(X=1)=2/6`, `P̂(X=2)=3/6`, `P̂(X=3)=0`, `P̂(X=4)=1/6`이고 합은 1이다. `0.33, 0.50, 0.17`은 반올림 표시다.
- 데이터가 어떤 생성 분포에서 나왔다는 그림은 가능한 생성 관점이다. 여섯 값만으로 실제 생성 분포를 확정하지 않는다.
- 순서: 숫자 나열 → 값 공간의 점 → 순서 섞기 → 개수와 확률 → 총 확률 1 → 다양한 분포 모양 → 데이터 표본 → 중심 질문.
- 72초, 1080×1920, 30fps 무음 영상. 구간 경계는 6, 14, 22, 34, 44, 53, 62, 72초다. 화면과 대본은 숫자·영문 원문을 쓰고 발음 표기는 TTS 파일에 둔다.
- 화면 하단 자막 영역을 확보한다. 점과 막대는 네 값 위치에 정렬하며 3의 빈 칸을 유지한다. 마지막의 세 모양은 개념 그림이며 앞선 여섯 값의 분포로 오해되지 않게 장면을 전환한다.

# 분포의 수학 04 제작 기준

- 학습 목표: 평균과 분산은 분포를 두 숫자로 압축한 요약이며, 이 두 숫자만으로 원래 분포를 복원할 수 없음을 이해한다.
- 3편 마지막의 이산 분포를 그대로 잇는다. 단봉형 A는 `P(-2)=1/8`, `P(0)=3/4`, `P(2)=1/8`이고 양봉형 B는 `P(-1)=P(1)=1/2`이다. 둘 다 `μ=0`, `σ²=1`이다. A는 중앙 질량이 크고, B는 중앙 질량이 없다.
- B의 퍼짐 조절 장면은 질량 `1/2`씩을 `±1.5`에 둔 임시 상태(`σ²=2.25`)에서 `±1`로 이동해 `σ²=1`이 되는 과정을 보여준다. 각 상태의 총확률은 1이고 평균은 0이다.
- 동일한 `(μ,σ²)`로 압축되는 두 입력을 화면 중앙의 한 요약 카드로 모은다. `P_A≠P_B`를 표시하고, 평균·분산이 분포 자체가 아님을 강조한다.
- 봉우리 개수, 꼬리, 비대칭성은 일반적인 분포 모양 정보의 예다. A와 B 사이에 없는 차이까지 이 예시의 사실로 주장하지 않는다.
- 마지막의 `(x,y)`는 다음 편에서 다룰 두 변수 관측값이다. 이 편에서 **압축된 두 숫자**는 `μ`와 `σ²`임을 분명히 구별한다.
- 순서: A와 두 수치 → 분포 가리기 → B 등장 → 평균 확인 → 분산 맞추기 → 동일 요약·다른 분포 → 두 숫자로 압축 → 잃는 모양 정보 → 통계량과 분포 구별 → 2차원 예고.
- 실제 음성 길이 43초에 맞춰 대본 분량별 구간을 재배분했다. 구간 경계는 4, 8.5, 12.5, 16.5, 20.5, 25, 28.5, 33, 37, 43초다. 1080×1920, 30fps 무음. 숫자·영문은 화면·대본에 원문으로 쓰고 발음 표기만 TTS 파일에 둔다.

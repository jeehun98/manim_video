# 선형대수학 05 — 같은 입력, 다른 패턴별 배율

99초 · 1080×1920 · 30fps · 무음.

## 중심 메시지

한 입력에 섞인 패턴들을 행렬이 서로 다른 배율로 강조하거나 억제할 수 있다. 개별 좌표의 숫자 변화만 보여주지 않고, 입력의 패턴 분해 → 각 패턴의 배율 변화 → 결과 재합성을 시각화한다.

## 수학

4편과 같은 A=[[1,0.5,0],[0.5,1.5,0.5],[0,0.5,1]].

- v₁=(1,2,1), Av₁=2v₁.
- v₂=(1,-1,1), Av₂=0.5v₂.
- 입력 x=v₁+v₂=(2,1,2).
- 결과 Ax=2v₁+0.5v₂=(2.5,3.5,2.5).
- 선형성 A(v₁+v₂)=Av₁+Av₂와 두 고유벡터의 배율 변화를 함께 이용한다.
- 일반식 A(c₁v₁+c₂v₂)=c₁λ₁v₁+c₂λ₂v₂에서 v₁,v₂는 A의 고유벡터다. 임의의 모양이 언제나 상수배로만 변한다는 주장이 아니다.
- 이 A는 대칭이고 고유벡터 기저를 갖지만, 모든 행렬이 실수 고유벡터들의 완전한 기저를 갖는 것은 아니다. 이번 입력은 지정된 두 고유벡터가 만드는 부분공간 안에 있다.
- 강조/억제는 이 예에서 고유성분의 계수에 대한 말이다. 양의 고유값 2와 0.5를 사용한다. 음의 배율에 따른 부호 반전, 비대각화 가능 행렬은 이번 범위 밖이다.
- 행렬을 원소별 연산으로 계산할 수 없다는 주장이 아니다. 모든 행렬이 좌표를 반드시 혼합한다는 주장도 하지 않는다. 동일한 작용을 패턴 성분 관점으로도 이해할 수 있다는 뜻이다.

## 화면

성분의 위치 1,2,3을 가로축, 실제 값을 세로축으로 한 꺾은선/막대 혼합 도식을 사용한다. 모든 비교 패널은 동일한 값 눈금이다. 패턴별로 정규화하지 않으며 음수 성분을 0 아래에 표시한다. 금색은 v₁, 분홍은 v₂, 청록은 혼합 입력과 결과다.

입력 (2,1,2)은 가운데가 낮고, 출력 (2.5,3.5,2.5)은 가운데가 높다. 이 변화를 두 성분의 서로 다른 배율과 연결하는 장면이 핵심이다.

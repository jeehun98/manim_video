# 활성화 함수의 기하학 01 — ReLU는 좌표를 어떻게 압축할까?

## 학습 목표

- 처음부터 끝까지 고정된 `x₁,x₂` 좌표계 위에서 한 뉴런의 기하학을 추적한다.
- `w`를 뉴런이 바라보는 방향, `u=wᵀx+b`를 그 방향의 부호 있는 좌표로 읽는다.
- `u=0` 경계에 평행한 좌표 `v`를 함께 두고 `(u,v)→(max(0,u),v)`를 격자로 보여준다.
- 여러 뉴런의 부호 좌표가 영역별 activation pattern과 piecewise affine 규칙을 만든다는 흐름으로 연결한다.

## 중심 흐름

`방향 w → 좌표 u → 부호 → u=0 경계 → 음수 u의 붕괴 → 여러 uᵢ → 부호 영역 → affine rule`

## 정확성 기준

- ReLU를 ‘접는다’고 부르지 않는다. `u<0`을 양수 쪽으로 반사하는 `|u|`와 달리, ReLU는 모든 음수 `u`를 `0`으로 보내 경계에 붕괴시키거나 눌러 붙인다.
- 화면의 `(u,v)→(max(0,u),v)`는 한 좌표에 ReLU를 적용하고 나머지 좌표를 참조용으로 유지한 좌표 변환이다. 단일 뉴런 자체의 출력은 스칼라 `max(0,u)`이며 `v`까지 출력한다는 뜻이 아니다.
- `wᵀx+b`는 `w`가 단위벡터일 때 유클리드 부호 거리와 일치한다. 화면에서는 정규화된 `w` 방향을 사용하며, 일반적인 경우에는 scale이 포함된 affine coordinate로 설명한다.
- 같은 activation pattern 영역에서 ReLU network는 일반적으로 linear가 아니라 affine이다.
- 여러 경계 장면은 일반 위치의 예시이며 최대 영역 수 정리를 주장하지 않는다.

## 연출 기준

- 고정된 `x₁,x₂` 격자는 모든 장면에 낮은 opacity로 남는다. 장면의 주인공이 바뀌어도 좌표 기준은 사라지지 않는다.
- 움직이는 점과 투영선, `u` 수치는 하나의 tracker에 연결해 점의 이동과 동시에 갱신한다.
- `u,v`축은 별개의 완성 화면으로 교체하지 않는다. 기존 `w` 화살표가 `u`축으로, 기존 경계가 `v`축으로 변형되고, 같은 전경 격자가 그 좌표계에 맞춰 회전한다.
- ReLU 장면에서도 새 격자로 갈아 끼우지 않고, 회전한 전경 격자 자체에 `(u,v)→(max(0,u),v)` 변형을 적용한다.
- 대표 장면은 35–47초: 음수 `u` 격자와 점들이 `u=0` 경계로 이동해 겹치고, 양수 쪽 격자는 그대로 남는다.
- 뉴런 추가는 직선만 추가하지 않고 `wᵢ 화살표 → uᵢ 라벨 → uᵢ=0 경계`를 한 묶음으로 순차 등장시킨다.
- TTS 실측 문단 종료 시점 `9·18·29·35·47·56·63·71·78·84·94초`에 화면 전환을 맞춘다.
- 94초, 1080×1920, 30fps, 무음 마스터. 미리보기는 360×640이다.

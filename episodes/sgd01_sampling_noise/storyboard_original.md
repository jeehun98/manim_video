### Scene 01 — 왜 전체 데이터를 사용하지 않을까?

00:00–00:14

문제 제시

도입 화면: 전체 데이터가 하나의 거대한 연산에 들어간다.

대응 나레이션

“인공지능을 학습시킬 때, 왜 전체 데이터가 아닌 일부 데이터만 사용하는 걸까요?”

“가장 일반적인 이유는 계산 효율입니다.”

“신경망은 손실함수의 기울기를 계산하고, 그 반대 방향으로 가중치를 수정합니다.”

“하지만 데이터가 수백만 개라면, 매번 모든 데이터를 계산하는 데 막대한 시간이 필요합니다.”

영상 연출

- 00:00 — 화면 중앙에 작은 데이터 블록 하나가 나타납니다.
- 00:02 — 데이터 블록이 빠르게 복제되며 10개, 100개, 수천 개로 늘어나는 느낌을 만듭니다.
- 00:04 — 카메라가 축소되며 거대한 데이터 행렬을 보여줍니다.
- 00:06 — 모든 데이터가 아래쪽의 신경망 연산 블록으로 들어갑니다.
- 00:09 — 연산 블록 내부에 행렬곱 기호와 기울기 계산 기호가 나타납니다.
- 00:11 — 화면에 `FULL DATASET / EVERY UPDATE` 표시.
- 00:13 — 데이터가 너무 많아 연산 과정이 반복되는 것을 짧게 보여줍니다.

Manim 구현

`VGroup`으로 데이터 타일을 묶고, `LaggedStart`를 사용해 블록을 순차적으로 등장시킵니다.

많은 데이터가 있다는 인상을 주되 수백만 개의 실제 `Mobject`를 생성할 필요는 없습니다. 수십 개의 타일을 반복 패턴으로 사용합니다.

### Scene 02 — 미니배치가 만들어지는 과정

00:14–00:31

Sampling → Gradient → Average

대응 나레이션

“그래서 일부 데이터를 무작위로 선택하고, 그 데이터들의 기울기를 평균해 가중치를 수정합니다.”

“이것이 미니배치를 사용하는 확률적 경사하강법, SGD의 기본 아이디어입니다.”

세부 애니메이션

- 전체 데이터 행렬을 유지합니다.
- 임의의 8개 타일만 초록색으로 강조합니다.
- 선택되지 않은 데이터는 투명도를 낮춥니다.
- 선택된 타일들이 화면 아래로 이동해 미니배치를 구성합니다.
- 각 타일에서 작은 기울기 화살표가 생성됩니다.
- 화살표들을 벡터 합으로 결합합니다.
- 합성 벡터를 배치 크기로 나누어 평균 기울기를 표시합니다.
- 최종적으로 하나의 업데이트 화살표가 생성됩니다.

화면 하단에 잠깐 다음 관계식을 표시합니다.

\\[ g_B=\frac{1}{B}\sum\_{i\in\mathcal B}g_i \\]

시각화 포인트: 미니배치는 데이터를 하나만 선택하는 방식이 아니라, 선택된 여러 데이터의 기울기를 평균하는 방식임을 분명히 보여줍니다. 배치 크기 1은 이후 핵심 예시에서 별도로 사용합니다.

### Scene 03 — 같은 가중치, 다른 기울기

00:31–00:43

핵심 의문 제기

대응 나레이션

“그런데 이 방식은 계산량을 줄이는 데서 끝나지 않습니다.”

“같은 가중치에서도 어떤 데이터를 선택했느냐에 따라, 계산되는 기울기가 달라지기 때문입니다.”

화면 구성

중앙에 2차원 파라미터 공간을 배치합니다.

- 가로축: \\(\theta_1\\)
- 세로축: \\(\theta_2\\)
- 중앙점: 현재 가중치 \\(\theta\\)

이 점에서 서로 다른 방향으로 뻗는 세 개의 기울기 화살표를 보여줍니다.

애니메이션

- 같은 원점에서 기울기 A가 생성됩니다.
- A가 사라지고 B가 생성됩니다.
- 다시 C로 변합니다.
- 이후 세 화살표가 동시에 나타납니다.
- 원점은 움직이지 않은 채 `SAME θ`가 강조됩니다.
- `DIFFERENT SAMPLES`라는 문구를 표시합니다.

이 장면에서는 실제 SGD 업데이트를 수행하지 않습니다. 동일한 위치에서 샘플만 변경해 기울기가 어떻게 달라지는지를 보여주는 단계입니다.

### Scene 04 — 두 기울기가 정확히 상쇄된다

00:43–01:04

핵심 반전 ①

이번 영상에서 가장 신경 써서 제작할 장면입니다.

대응 나레이션

“예를 들어 지금 위치에서 두 데이터의 기울기가 크기는 같고, 방향은 정반대라고 생각해 보겠습니다.”

“전체 데이터를 평균하면 두 기울기가 상쇄되어 0이 됩니다.”

“이 위치에서 전체 기울기만 사용하는 경사하강법은 가중치를 바꾸지 않습니다.”

00:43–00:49 — 반대 방향의 두 기울기

- 두 데이터 블록 A, B가 화면 상단에 나타납니다.
- A에서 주황색 기울기 \\(g_1=+5\\)가 생성됩니다.
- B에서 파란색 기울기 \\(g_2=-5\\)가 생성됩니다.
- 두 기울기를 같은 기준점에 배치합니다.
- 방향은 반대, 길이는 동일하게 그립니다.

00:49–00:57 — 평균과 상쇄

- 두 화살표를 원점에서 머리와 꼬리를 연결한 벡터합 형태로 이동합니다.
- 양쪽 화살표가 정확히 상쇄됩니다.
- 최종 합벡터 길이가 0이 됩니다.
- 수식 `(5 + (−5)) / 2 = 0`을 표시합니다.
- 화면 중앙에는 점 하나만 남습니다.

00:57–01:04 — 전체 경사하강법은 멈춘다

- 파라미터 위치에 작은 점을 배치합니다.
- 업데이트 화살표가 길이 0으로 축소됩니다.
- 파라미터 점은 움직이지 않습니다.
- `FULL-BATCH GD`와 `NO UPDATE` 표시.
- 오른쪽으로 전환하기 직전까지 정지 상태를 유지합니다.

이 예시는 정확하게 두 데이터만 존재하는 손실함수 또는 다른 데이터들의 기울기까지 상쇄되는 상황으로 정의해야 합니다.

또한 전체 기울기가 0인 점은 최소점뿐 아니라 안장점이나 최대점일 수도 있습니다. 다음 장면에서 이를 짧게 보완합니다.

### Scene 05 — 같은 위치에서 SGD는 움직인다

01:04–01:23

핵심 반전 ②

대응 나레이션

“하지만 둘 중 하나만 선택하면 기울기는 0이 아닙니다.”

“전체 기울기가 0인 위치에서도, SGD의 개별 업데이트는 가중치를 움직일 수 있는 것입니다.”

“물론 전체 기울기가 0이라는 사실만으로 좋은 최소점이라고 판단할 수는 없습니다.”

세부 애니메이션

- 직전 장면의 정지한 점을 화면 왼쪽으로 옮깁니다.
- 화면을 `Full-batch`와 `SGD` 두 영역으로 나눕니다.
- 두 영역에 동일한 가중치 위치를 표시합니다.
- 왼쪽은 전체 기울기가 0이므로 움직이지 않습니다.
- 오른쪽은 미니배치 크기 1로 데이터 A를 선택합니다.
- 기울기 \\(+5\\)가 나타납니다.
- 실제 가중치 업데이트 방향은 기울기의 반대인 왼쪽으로 표시합니다.
- 다음 스텝에서는 데이터 B를 선택할 수 있음을 보여주고, 새 위치에서 기울기를 다시 계산합니다.

중요한 점은 그림에서 기울기 화살표와 업데이트 화살표의 방향을 구분하는 것입니다.

\\[ \Delta\theta=-\eta g_B \\]

기울기가 오른쪽을 가리키면 가중치 업데이트는 왼쪽으로 향해야 합니다.

또한 매번 기울기가 재계산되므로 이후 스텝에서 반드시 원래 위치로 돌아오는 것처럼 표현하지 않습니다.

이 장면을 마무리하면서 작은 자막으로 `Stationary point ≠ necessarily minimum`을 표시할 수 있습니다.

### Scene 06 — 이것이 샘플링 잡음이다

01:23–01:39

Sampling Noise 정의

대응 나레이션

“이처럼 미니배치 기울기와 전체 기울기 사이에 생기는 차이를, 기울기 추정의 잡음이라고 부릅니다.”

“여기서 잡음은 계산이 잘못되었다는 뜻이 아닙니다.”

“어떤 데이터를 뽑았느냐에 따라 생기는 변동입니다.”

장면 구성

직전 장면의 2차원 좌표계를 재사용합니다.

중앙에서 세 가지 벡터를 차례로 표시합니다.

- 파란색: 전체 기울기 \\(g\\)
- 초록색: 미니배치 기울기 \\(g_B\\)
- 보라색: 두 벡터의 차이 \\(\xi_B\\)

세부 연출

- 01:23 — 파란색 전체 기울기 \\(g\\)가 나타납니다.
- 01:26 — 다른 방향으로 초록색 미니배치 기울기 \\(g_B\\)가 나타납니다.
- 01:29 — 두 벡터의 끝점을 연결하는 보라색 화살표가 생성됩니다.
- 01:31 — `Sampling Noise`라는 글자가 보라색 벡터 옆에 나타납니다.
- 01:34 — 미니배치 선택이 바뀌며 초록색 벡터가 다른 방향으로 회전합니다.
- 01:36 — 동시에 보라색 벡터도 변하지만 전체 기울기 \\(g\\)는 그대로 유지됩니다.

Manim 구현

`Arrow`, `ValueTracker`, `always_redraw`를 사용하면 두 벡터의 차이를 실시간으로 갱신할 수 있습니다.

\\[ \xi_B=g_B-g \\]

이 장면에서 실제 잡음의 정의를 보여주고, 다음 장면에서는 잡음이 아무 방향으로나 발생하지 않는다는 사실을 설명합니다.

01:46–01:56 — 미니배치를 바꿔도 결과가 비슷하다

- 다른 미니배치를 선택합니다.
- 평균 화살표가 조금 움직이지만 방향과 길이가 크게 달라지지 않습니다.
- 세 번째 미니배치도 선택합니다.
- 평균 벡터들이 좁은 영역에 모이는 모습을 보여줍니다.

화면 하단에 `LOW VARIANCE`를 표시합니다.

### Scene 08 — 서로 다른 방향을 요구하는 데이터

핵심 반전 ③

“반대로 특정 방향에서 차이가 크다면, 그 방향으로 기울기가 더 크게 흔들릴 수 있습니다.”

01:56–02:02 — 기울기 분포가 넓어진다

## 3. 영상 전체에서 중요한 연출상의 연결

이번 콘텐츠는 총 12개 장면이지만, 장면마다 새로운 도형을 만들 필요는 없습니다.

가능하면 하나의 좌표계가 지속적으로 변화하는 방식을 사용하겠습니다.

데이터 공간

전체 데이터에서 미니배치 선택

기울기 공간

개별 기울기 → 평균 → 잡음

파라미터 공간

기울기에 따른 가중치 업데이트

학습 동역학

확률적 궤적과 최종 도달 영역

여기서 기울기 공간과 파라미터 공간은 같은 차원을 가질 수 있지만 의미가 다릅니다. 기울기는 업데이트 방향을 계산하는 벡터이고, 파라미터는 실제로 변화하는 상태입니다.

시각적으로는 공통 좌표계를 사용해도 되지만, 화면에 `Gradient Vector`와 `Parameter Update`라는 표기를 다르게 유지하면 혼동을 막을 수 있습니다.

다음과 같은 방식으로 수학적 계산과 애니메이션을 분리하는 것을 권장합니다.

```
import numpy as npdef full_gradient(grads):    return np.mean(grads, axis=0)def minibatch_gradient(grads, batch_size, rng):    indices = rng.integers(        0, len(grads), size=batch_size    )    return np.mean(grads[indices], axis=0)def sgd_update(theta, grad, learning_rate):    return theta - learning_rate * grad
```

여기서 `grads`는 같은 파라미터 위치에서 계산한 개별 데이터의 기울기 배열입니다.

이 방식으로 미니배치 크기별 기울기 분포를 먼저 계산하고, 실제 결과를 Manim의 화살표와 점으로 표시하면 됩니다.

## 5. 제작 우선순위

영상 전체에서 시각적 완성도에 가장 많이 투자할 장면은 세 개입니다.

첫째, Scene 04–05의 기울기 상쇄와 SGD 업데이트입니다. 전체 기울기가 0인데도 SGD는 움직일 수 있다는 역설을 보여주는 가장 중요한 장면입니다.

둘째, Scene 07–08의 방향성 있는 잡음입니다. 무작위로 샘플링한다고 해서 아무 방향으로나 흔들리는 것은 아니라는 사실을 전달합니다. 이번 영상의 과학적 깊이가 여기에서 드러납니다.

셋째, Scene 09의 배치 크기 비교입니다. 잡음을 추상적 개념에서 실제로 조절 가능한 학습 변수로 연결합니다. 가능하면 시뮬레이션 결과를 그대로 애니메이션에 사용하면 좋습니다.

마지막에는 SGD가 더 좋은 학습을 보장한다거나 잡음이 항상 유익하다는 결론을 내리지 않습니다.

대신 \*\*“일부 데이터를 선택한다는 계산상의 선택이, 학습의 확률적 동역학 자체를 바꾼다”\*\*는 메시지를 남기는 것이 이번 영상에 가장 적합합니다.

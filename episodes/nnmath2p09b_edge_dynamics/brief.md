# 신경망의 수학 2부 09B 제작 기준

## 목표

Learning Rate를 키우지 않아도 모델이 더 높은 curvature 영역으로 이동하면서 안정성 경계에 접근할 수 있음을 설명하는 122초 세로형 영상이다.

## 핵심 흐름

`0<ηλ<2 복습 → parameter 이동 → η=0.01 숫자 예시 → λ_max 상승 → 경계 부근의 지속 학습 → Edge of Stability`

## 정확성

- 고정 quadratic의 조건을 실제 비선형 신경망 전체에 대한 보편 법칙처럼 표현하지 않는다.
- Edge of Stability는 모든 optimizer와 설정에서 나타나는 현상으로 단정하지 않는다.
- 경계 부근의 진동과 실제 divergence를 구분한다.

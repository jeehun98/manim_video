렐루는 음수를 영으로 만들고 양수는 그대로 통과시킵니다. 예를 들어 마이너스 이, 일, 마이너스 오, 삼은 영, 일, 영, 삼이 됩니다.

각 출력은 자기 입력 하나만 보면 됩니다. 첫 번째 원소를 계산할 때 다른 원소의 값은 필요하지 않습니다.

그래서 지피유에서는 여러 쓰레드가 서로 다른 원소를 맡아 같은 연산을 수행할 수 있습니다. 한 쓰레드가 하나 이상의 원소를 처리할 수도 있습니다.

그런데 쓰레드 하나의 렐루 계산 자체는 아주 작습니다. 값을 보고 영과 비교해 선택하면 끝입니다.

하지만 계산 전에 입력을 글로벌 메모리에서 읽고, 결과를 다시 저장해야 합니다. 별도 렐루 커널의 흐름은 리드, 렐루, 라이트입니다.

큰 텐서에서는 이처럼 값을 읽고 쓰는 일이 렐루 계산보다 더 큰 부담이 될 수 있습니다. 이런 경우를 메모리 바운드라고 부릅니다.

이제 렐루 앞에 매트멀을 놓아봅시다. 매트멀 결과 와이를 메모리에 쓰고, 별도 렐루 커널이 와이를 다시 읽으면 중간 결과가 한 번 나갔다가 돌아옵니다.

그런데 매트멀이 만든 출력 일부가 아직 실행 중인 타일에 남아 있다면, 그 값에 바로 렐루를 적용하고 최종 결과만 저장할 수 있습니다.

두 연산을 같은 실행 흐름에 넣는 퓨전입니다. 분리 실행의 중간 와이 라이트와 리드를 피할 수 있지만, 최종 결과의 라이트는 남습니다.

렐루 수식은 그대로입니다. 지피유에서 실행 비용을 가르는 것은 계산뿐 아니라, 값을 어디서 읽고 어디에 저장하느냐일 수 있습니다.

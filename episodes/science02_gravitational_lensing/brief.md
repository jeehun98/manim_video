# 과학의 한 장면 02 제작 기준

- 질문 하나: 보이지 않는 질량은 어떻게 찾을까?
- 목표: 배경 은하의 빛 왜곡을 통해 앞쪽의 총질량 분포를 추론하고, 보통 물질과 비교해 추가 질량을 이해한다.
- 형식: 61초, 1080×1920, 30fps, 무음. 01편의 대사 글자 수/초 기준을 적용해 전체 길이를 정하고, 화면별 글자 수 비율로 배분한다.
- 소스: scene.py, narration.md, tts_script.txt, captions.srt, timing.json.
- 흐름: 질문과 직진 빛 → 질량 주변의 부드러운 경로 → 관측자 시점의 호와 다중상 → 별+가스 예상과 관측 비교 → 여러 은하의 왜곡 패턴에서 질량 지도 → 총질량과 보통 물질 비교 → 첫 편과 연결 → 마지막 빛의 호.
- 처음에는 총질량 헤일로를 보여주지 않는다. 추론이 끝난 뒤 질량 지도가 나타난다.
- 기하, 광선, 호, 지도와 막대는 모두 개념도다. 특정 은하단의 관측 자료, 실제 렌즈 해 또는 수치를 재현하지 않는다. 빛의 경로는 부드러운 곡선으로 그리며 충돌·굴절처럼 급히 꺾지 않는다.
- 옆에서 보는 광선과 관측자 시점의 왜곡상은 별개 장면으로 명시한다.
- 강한 렌즈의 호/다중상에서 약한 렌즈의 여러 은하 평균 왜곡으로 넘어간다. 개별 은하의 원래 모양을 안다고 가정하지 않는다. 실제 복원에는 배경 은하들의 형태 통계, 거리와 렌즈 모형이 필요하다.
- 복원 장면은 통계적 역추론을 설명하는 시각화이며 실제 역산 알고리즘이 아니다. 선분들은 관측된 접선 방향 왜곡을 강조한 개념도다.
- 질량 지도는 시선 방향으로 투영된 총질량이다. 암흑물질만을 직접 촬영한 지도가 아니다.
- 은하단의 보통 물질에는 별 외에 뜨거운 가스도 중요하므로 예상 및 대본에 가스를 반드시 포함한다. 가스는 가시광선에서 그대로 보이지 않으며 다른 파장 관측을 함께 활용한다.
- 더 넓게 그린 지도만으로 질량이 더 많다고 증명하지 않는다. 총질량과 별+가스 추정량을 함께 비교한다. 막대에는 실제 수치를 부여하지 않는다.
- 표준 중력 이론에서 보통 물질을 넘어선 추가 질량을 암흑물질로 설명한다. 입자 정체의 직접 검출로 표현하지 않는다.
- Bullet Cluster와 질량-가스 위치 어긋남은 후속 편으로 남긴다.

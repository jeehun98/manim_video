## 핵심 주장

구문 트리의 각 부분을 시작점·끝점을 가진 작은 ε-NFA 조각으로 변환하고, 부모 연산의 조립 규칙을 적용하면 전체 기계를 얻는다. 연산을 다시 소개하는 것보다 **하위 표현식의 변환 결과가 상위 변환의 입력이 되는 과정**을 중심에 둔다.

## 정확성 조건

1. 알파벳 {A,B}, 고전적 정규식 `(A|B)*ABB`. 콘티의 `*(A|B)ABB`는 오타이며 본문·화면에서 사용하지 않는다. 해당 언어는 {wABB | w∈{A,B}*}. 부분 검색이 아니라 입력 전체 판정이다.
2. AST는 각 문자 발생 위치를 별도 잎으로 둔다. 예: Concat(Star(Union(A,B)),Concat(A,Concat(B,B))). 연결의 괄호 결합 방식은 고정해 화면과 구현을 일치시킨다. ABB를 미분해 리터럴 하나처럼 처리하지 않는다.
3. 교육용 구성은 각 조각이 입구와 출구 하나를 갖는 표준 ε-NFA 방식이다. 문자 조각은 두 상태와 문자 전이 하나. 선택은 새 입구·출구와 ε-전이 네 개. 별표는 새 입구·출구와 내부 진입·반복·탈출·0회 우회의 ε-전이 네 개. 연결은 앞 출구→뒤 입구의 ε-전이 하나이며 이 방식에서는 새 상태를 추가하지 않는다.
4. 이 구성에서 리터럴 발생 5개→상태 10개, 선택 2개·별표 2개를 더해 전체 상태 14개. 문자 전이 5개, ε-전이 11개이다. 상태를 합치거나 dangling edge를 patch하는 구현은 다른 수를 가질 수 있으므로 보편적인 최소 상태 수라고 말하지 않는다.
5. 조각의 출구는 최종 완성 기계의 수용 상태와 구분한다. 중간 조각의 출구에 도착했다고 전체 입력을 수용하지 않는다. 전역 수용 상태는 식 전체를 완성한 뒤 지정한다.
6. ε는 입력을 소비하지 않는다. ε-NFA의 언어는 NFA/DFA로도 인식 가능하므로 표현력을 추가하지 않는다. ε-전이가 구현에 반드시 필요한 유일한 방법이라는 주장도 하지 않는다.
7. 완성된 ε-NFA는 자동으로 CPU 기계어가 된 것이 아니다. 상태·전이 자료와 이를 처리하는 시뮬레이터를 구분한다. ε-closure를 포함한 도달 가능 상태 집합으로 전체 입력을 처리하고 마지막에 전역 수용 상태 포함 여부로 판정한다. 실제 하드웨어가 여러 경로를 동시에 실행한다는 뜻은 아니다.
8. AABB는 앞 반복 부분에서 A 한 개, 마지막 연결 부분에서 ABB를 읽는 수용 경로가 있다. ABB는 반복 0회로 수용한다. ABBA는 전체 입력 종료 시 수용하지 못한다. 처음부터 경로를 하나만 탐욕적으로 고르는 방식으로 설명하지 않는다.
9. 전체 정의에는 ε·∅ 같은 기초 조각도 포함할 수 있다. 이 영상 예시는 리터럴·선택·연결·반복만 사용한다. 모든 문자열 언어를 정규식으로 표현할 수 있다는 주장은 하지 않는다.
10. AI lowering은 IR의 연산·타입·layout·효과·타깃 조건 등을 고려한다. IR은 공유·의존성·제어 흐름·영역을 포함할 수 있으므로 항상 단순 AST postorder 치환이라고 일반화하지 않는다. 실제 컴파일러가 언제나 MatMul→Add→ReLU를 하나의 커널로 바꾸는 것도 아니다.
11. 앞 영상 복습·정리나 다음 편 예고는 넣지 않는다. 이 영상은 동등성 재증명이나 실행 속도 비교보다 구조를 따르는 구체적인 구성 과정에 집중한다.

## 대본 v2 피드백 반영

- 연산의 정의보다 자식 조각→부모 조각→다음 부모의 입력이라는 재귀적 조립을 중심에 둔다. 동일한 입구·출구 인터페이스를 모든 수준에서 유지한다.
- 반복되는 설명을 합치고, 같은 규칙을 재사용한다는 문장은 유지했다.
- 실행 설명은 초기 ε-closure, 문자 이동, 다시 ε-closure, 입력 종료 후 최종 수용 상태 포함 여부 순서로 명시했다. 이 설명은 상태 하나만 추적하는 DFA 실행과 구별한다.
- 무한히 다양한 식은 각 식의 길이는 유한하지만 가능한 식 전체가 무한하다는 뜻이다. ε-NFA의 상태 수는 해당 유한 식에 대해 유한하다.
- AI lowering이 Thompson 구성과 동일한 알고리즘이거나 항상 단순 트리 순서의 변환이라는 주장은 하지 않는다.
- v2 검토 당시에는 화면·TTS 음원·타임코드·렌더를 생성하지 않았다. 현재 상태는 아래 제작 기록을 따른다.

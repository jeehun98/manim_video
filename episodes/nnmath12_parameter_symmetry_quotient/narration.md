# 신경망의 수학 12 — 서로 다른 파라미터가 어떻게 같은 신경망이 될까?

## 00:00–00:10

입력 공간에서 신경망을 보았다면, 이번에는 파라미터 공간을 보겠습니다. 이 공간에서는 서로 다른 좌표가 같은 신경망을 나타내는 이상한 일이 생깁니다.

## 00:10–00:22

은닉 뉴런이 두 개인 작은 신경망을 생각해봅시다. 출력은 `y=v₁h₁+v₂h₂`입니다. 각 뉴런은 자신에게 들어오고 나가는 가중치와 bias를 가지고 있습니다.

## 00:22–00:36

이제 `h₁`과 `h₂`를 교환합니다. 위치만 바꾸는 것이 아니라 각 뉴런의 모든 입력 연결, 출력 연결, bias를 한 묶음으로 함께 옮깁니다. 파라미터 배열은 달라지지만 오른쪽 함수 그래프는 움직이지 않습니다.

## 00:36–00:48

같은 입력들을 두 네트워크에 넣어도 출력은 전부 같습니다. 전체 연결을 함께 순열했기 때문에 계산에서는 `v₁h₁+v₂h₂`의 두 항 순서만 바뀝니다. `θ_A≠θ_B`이지만 두 함수는 같습니다.

## 00:48–01:02

Parameter Space에서 두 모델은 멀리 떨어진 `θ_A`와 `θ_B`입니다. 하지만 Function Space로 내려보내면 두 점은 정확히 같은 함수 `f` 위에 겹칩니다. 파라미터가 다르다고 반드시 다른 함수는 아닙니다.

## 01:02–01:12

같은 함수는 같은 입력에 같은 출력을 만듭니다. 같은 데이터와 같은 예측 기반 loss를 사용한다면 loss도 같습니다. 따라서 `f_A=f_B`이면 `L(θ_A)=L(θ_B)`입니다.

## 01:12–01:22

그래서 Loss Landscape의 서로 먼 minimum 중 일부는 다른 함수를 학습한 해가 아니라, 같은 함수가 파라미터 공간에 대칭적으로 복제된 것일 수 있습니다.

## 01:22–01:35

서로 구별되는 은닉 뉴런이 두 개면 같은 함수의 순열 표현은 최대 `2!=2`개입니다. 세 개면 `3!=6`, 네 개면 `4!=24`개입니다. 같은 함수의 parameter point가 공간 곳곳에 빠르게 늘어납니다.

## 01:35–01:48

이제 permutation만 다른 점들을 하나의 묶음으로 둘러쌉시다. 어떤 기준에서 같은 것으로 취급하기로 한 점들의 집합을 equivalence class, 동치류라고 합니다.

## 01:48–02:02

각 동치류 전체를 하나의 새로운 점으로 압축하면 quotient space가 됩니다. `Parameter Space / Permutation Symmetry`의 슬래시는 숫자 나눗셈이 아니라, 순열 대칭으로 같은 점들을 하나로 식별한다는 뜻입니다. 서로 다른 파라미터에서 같은 함수로, 동치 관계와 동치류를 거쳐 quotient space가 자연스럽게 등장합니다.

# Quantization 시리즈 3편 제작 기준

- 이 편의 유일한 학습 목표는 `Scale = 정수 격자 한 칸이 의미하는 실제 값의 크기`다.
- 위쪽 실수 축과 아래쪽 정수 축을 대응시키는 시각 문법을 사용하며, 같은 `MappedAxes` 컴포넌트를 Zero Point 편에서도 재사용한다.
- `0~1 ↔ 0~255`에서는 양 끝을 포함한 256개 위치 사이에 255개 간격이 있으므로 `s=1/255≈0.0039216`이다.
- 입력 `x=0.43`은 `q=round(0.43×255)=110`, 복원값은 `110/255≈0.43137`이다.
- `0~100 ↔ 0~255`의 scale은 `100/255≈0.39216`이다.
- `x≈s·q`는 실수 0과 정수 0이 일치하는 이번 예시에 한정한다. 일반식의 offset은 다음 Zero Point 편에서 도입한다.
- Zero Point, symmetric/asymmetric, clipping, calibration, signed INT8, per-channel scale, 오차 분석은 설명하지 않는다.
- 영상은 60초, 1080×1920, 30fps, 무음 마스터다.

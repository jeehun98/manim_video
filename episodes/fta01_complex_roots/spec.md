# 독립 교체 씬

- 01: 0–23초 / 계산하지 않아도 알 수 있다
- 02: 23–48초 / 수가 확장되어 온 이유
- 03: 48–73초 / 대수학의 기본정리
- 04: 73–92초 / 숫자에서 평면 위의 점으로
- 05: 92–104초 / 최고차항과 다섯 번의 회전
- 06: 104–115초 / 입력 원을 줄이면
- 07: 115–132초 / 반드시 원점을 지난다
- 08: 132–152초 / 계산과 존재는 다른 문제
- 09: 152–177초 / 그 근들은 복소수 안에 있다

상단 제목, 중앙 시각화, 하단 -4.9 이하 자막 전용. 입력 파랑·출력 금색·근 분홍·결론 초록.

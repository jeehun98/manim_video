# **대수학의 기본정리 — Manim 상세 영상화 콘티**

총 177초 · 2분 57초 · 9:16 쇼츠 · 수학적 직관 중심

이번 영상의 핵심은 **다항방정식의 근을 직접 계산하지 않아도, 복소평면에서 곡선이 움직이는 모습을 통해 근의 존재를 이해할 수 있다는 것**입니다.

영상 전반부는 수 체계가 확장되는 과정을 짧고 직관적으로 보여주고, 후반부는 복소평면 두 개를 이용해 입력과 출력의 관계를 시각화합니다.

특히 97\~129초는 이번 영상의 핵심 구간입니다. 여기에서는 단순히 곡선이 움직이는 것보다 **원점을 감는 횟수가 달라지려면 반드시 원점을 통과해야 한다**는 사실을 시청자가 직접 발견하도록 구성합니다.

### **Scene 01 — 모든 다항방정식에는 해가 존재한다**

00:00–00:23 · 도입 및 문제 제시

0–3초

검은 배경 중앙에 `모든 다항방정식에는 해가 존재한다`를 등장시킵니다. 먼저 `모든`을 크게 강조하고, 나머지 문장을 순차적으로 나타냅니다.

단, 화면 작은 글씨로 `복소수 범위 · 1차 이상`을 함께 표시해 수학적 조건을 명확히 합니다.

**5차 방정식 등장**

\\[ x^5-3x^4+7x^3-2x^2+5x+11=0 \\]

긴 수식을 중앙에 크게 배치합니다. 나레이션에 맞춰 각 항이 왼쪽부터 순차적으로 나타납니다.

최고차항 \\(x^5\\)만 파란색으로 강조하고, 화면 상단에 `5차 방정식`이라는 작은 라벨을 표시합니다.

13–23초

**계산하지 않아도 알 수 있는 사실**

수식 아래에 물음표 다섯 개를 배치합니다.

`?  ?  ?  ?  ?`

이어서 다섯 개의 근을 나타내는 기호 \\(r_1,\ldots,r_5\\)로 전환합니다. 실제 근의 값은 공개하지 않습니다.

마지막에 `5개의 근 · 중복도 포함`이라는 설명을 강조합니다.

이 장면에서는 근의 좌표를 미리 배치하지 않는 편이 좋습니다. 후반부의 메시지가 **값을 모르더라도 존재를 알 수 있다**는 것이기 때문입니다.

그 직후 허수축이 세로 방향으로 자라나면서 \\(\pm i\\)가 등장합니다.

### **Scene 03 — 복소수는 다항식에 대해 닫혀 있다**

00:48–01:13 · 대수학의 기본정리 소개

**48–59초**

중앙의 복소평면을 확대하고, 화면 위쪽에 차수가 다른 다항식 세 개를 순서대로 표시합니다.

\\[ \begin{aligned} P_2(z)&=z^2+1\\\ P_3(z)&=z^3-1\\\ P_5(z)&=z^5+\cdots \end{aligned} \\]

각 다항식 옆에 `복소수 근 존재`라는 체크 표시를 넣습니다. 차수가 올라가도 새로운 수 축을 추가하지 않고 동일한 복소평면을 유지합니다.

**59–70초**

화면을 정리하고 다음 두 수식을 순차적으로 보여줍니다.

\\[ P(z)=0 \\]

\\[ P(z)=a_n(z-r_1)(z-r_2)\cdots(z-r_n) \\]

두 번째 수식에서 \\(r_1,r_2,\ldots,r_n\\)을 차례로 밝히며, `n차 → n개의 근 (중복도 포함)`으로 연결합니다.

**70–73초**

수식 전체를 작게 축소하고 중앙에 정리 이름을 등장시킵니다.

Fundamental Theorem of Algebra

\\(\deg P=n\quad\Longrightarrow\quad n\text{ roots in }\mathbb C\\)

**Manim 구현**

여기서는 `TransformMatchingTex`가 중요합니다. 다항식에 포함된 차수 \\(n\\)을 추출하듯 이동시켜 근의 개수 \\(n\\)에 대응시키면, 숫자 두 개가 우연히 같은 것이 아니라 정리가 그 관계를 보장한다는 느낌을 줄 수 있습니다.

### **Scene 04 — 복소평면에서 다항식은 어떻게 움직일까?**

01:13–01:32 · 기하학적 증명으로 전환

이 장면부터는 영상의 시각적 언어가 바뀝니다.

앞에서는 하나의 복소평면만 사용했지만, 이제 **왼쪽은 입력 복소평면, 오른쪽은 출력 복소평면**으로 구분합니다.

입력 원 위의 점을 다항식에 넣으면 출력 복소평면에 대응하는 점이 생깁니다.

**73–78초**

기존의 대수학의 기본정리 텍스트를 위로 이동시키고 다음 질문을 띄웁니다.

`왜 반드시 근이 존재할까?`

질문이 사라지면서 두 개의 복소평면이 나타납니다.

**78–82초**

복소수 \\(z=a+bi\\)를 입력 평면의 점 하나로 표시합니다.

오른쪽에는 함수 변환을 나타내는 화살표를 그립니다.

\\[ z\longmapsto P(z) \\]

입력 점이 움직일 때마다 출력 점이 함께 움직이게 연결합니다.

**82–87초**

왼쪽 평면에 반지름 \\(R\\)인 원을 그립니다.

\\[ z(t)=Re^{it},\quad 0\le t\le2\pi \\]

위 식은 화면에 작게 배치하고, 실제 이해는 애니메이션에 맡깁니다.

원의 오른쪽 끝에서 파란 점이 반시계 방향으로 움직이기 시작합니다.

**87–92초**

오른쪽 평면에서는 노란 점이 입력의 움직임에 대응해 이동합니다. 노란 점의 궤적을 `TracedPath`처럼 남겨 닫힌 곡선이 생성되는 과정을 보여줍니다.

여기서는 출력 곡선이 반드시 원 형태일 필요가 없습니다. 일반 다항식에서는 복잡하게 변형된 닫힌 곡선이 나타납니다.

시청자가 이해해야 하는 것은 다음 관계입니다.

**입력에서 한 바퀴 이동하면, 출력에서도 하나의 닫힌 경로가 만들어진다.**

### **Scene 05 — 최고차항이 회전수를 결정한다**

01:32–01:44 · 5차항의 의미를 회전으로 해석

이 장면은 가능한 한 명확하게 표현하는 것이 중요합니다.

일반적인 5차 다항식의 최고차항은 \\(a_5z^5\\)입니다. 복소평면에서 \\(z\\)를 한 바퀴 회전시키면 \\(z^5\\)는 다섯 바퀴 회전합니다.

같은 원을 다섯 번 도는 출력은 궤적 자체만으로는 구분되지 않으므로, 점의 회전과 회전 카운터를 함께 보여줍니다.

**92–97초**

화면을 잠시 두 단계로 나눕니다.

첫 번째는 입력 \\(z=Re^{it}\\).

두 번째는 최고차항 \\(a_5z^5=a_5R^5e^{5it}\\).

지수의 \\(t\\)와 \\(5t\\)를 각각 파란색과 노란색으로 강조합니다.

**97–104초**

입력의 파란 점을 한 바퀴 회전시킵니다. 오른쪽 출력 점은 다섯 바퀴 회전합니다.

출력 평면 아래쪽에 다음 숫자를 증가시키는 카운터를 표시합니다.

`감김수 0 → 1 → 2 → 3 → 4 → 5`

화면의 핵심 설명은 다음 한 문장으로 충분합니다.

`입력 1회전 → 출력 5회전`

여기서 화면 하단에 `충분히 큰 원에서는 최고차항이 지배적`이라는 작은 설명을 유지합니다.

주의할 점은 **경로를 다섯 번 겹쳐 그려 선을 굵게 만드는 것으로 회전수를 표현하지 않는 것**입니다. 회전하는 점과 카운터를 함께 사용해야 감김수의 의미가 전달됩니다.

### **Scene 06 — 원의 크기를 줄이면 어떤 일이 생길까?**

01:44–01:55 · 감김수 변화의 조건을 준비

이 장면은 수학적 정확성과 시각적 명료성을 위해 **단순한 5차 다항식을 예시로 사용**하는 것을 추천합니다.

\\[ P(z)=z^5+1 \\]

원래 도입부의 5차 방정식과 다른 예시이므로, 화면 상단에 `회전 원리를 살펴보기 위한 간단한 예시`라는 라벨을 표시합니다.

이 다항식을 선택하는 이유는 입력 원의 크기를 줄였을 때 출력 곡선이 어떻게 변하는지 정확하게 보여줄 수 있기 때문입니다.

입력이 \\(z=Re^{it}\\)라면

\\[ P(z)=1+R^5e^{5it} \\]

즉, 출력은 **중심이 1이고 반지름이&#x20;**\\(R^5\\)**인 원을 다섯 번 도는 움직임**입니다.

R ＞ 1

R = 1

R ＜ 1

개념도. 원점(분홍 점)을 통과하는 순간 전후로 감김수가 달라집니다. 정확한 원의 크기는 각 패널에서 다르게 표시했습니다.

**104–110초**

왼쪽 입력 평면에서 파란 원이 서서히 작아집니다.

오른쪽 출력 평면에는 그에 대응하는 원이 나타납니다. 출력 원의 중심은 \\(1\\)에 고정되고 반지름만 감소합니다.

입력 원 위에 있는 점은 이때 잠깐 멈추게 하고, 원의 크기 변화에만 집중시킵니다.

**110–115초**

입력 원이 원점으로 수축할수록 출력 원은 \\(P(0)=1\\)을 향해 줄어듭니다.

여기서 오른쪽 출력 평면의 원점 \\(0\\)과 최종 점 \\(1\\)을 반드시 구분해 표시합니다.

- 분홍 점: 원점 \\(0\\), 방정식의 해를 판정하는 기준
- 초록 점: \\(P(0)=1\\), 최종적으로 출력 곡선이 수축하는 위치

출력은 원점이 아닌 \\(1\\)로 수축하므로, 마지막 상태에서는 원점을 감지 않습니다.

### **Scene 07 — 감김수가 바뀌려면 반드시 원점을 지나야 한다**

01:55–02:12 · 영상의 핵심 발견 장면

여기에서는 일반적인 다항식으로 돌아가기보다는, 직전의 \\(P(z)=z^5+1\\) 예시를 유지하는 것이 좋습니다. 하나의 사례에서 감김수가 실제로 변화하는 모습을 끝까지 보여주는 편이 직관적입니다.

**115–121초**

화면을 오른쪽 출력 복소평면 중심으로 확대합니다.

큰 노란 원이 원점을 감싸고 있습니다.

반지름이 줄어들면서 노란 원의 왼쪽 경계가 분홍색 원점에 가까워집니다.

여기서 질문을 상단에 표시합니다.

`원점을 감던 곡선이 원점을 감지 않게 되려면?`

원의 왼쪽 경계가 원점과 정확히 만나는 순간, 잠시 화면을 정지합니다.

**121–123초**

원점에서 분홍색 파동 효과가 발생하고, 아래 수식을 표시합니다.

\\[ \boxed{P(z)=0} \\]

**123–129초**

잠시 왼쪽 입력 평면을 다시 보여줍니다.

출력값이 원점에 도달한 순간의 입력값 \\(z\\)를 분홍색으로 표시하고, 두 점을 연결하는 대응 관계를 강조합니다.

\\[ z=r\quad\Longrightarrow\quad P(r)=0 \\]

시청자가 이해해야 하는 것은 **출력 곡선이 원점을 지난다는 사실과 방정식에 해가 존재한다는 사실이 동일한 사건**이라는 점입니다.

**129–132초**

두 평면을 다시 나란히 배치하고, 아래쪽에 결론을 표시합니다.

`원점을 지나는 출력 → P(z)=0 → 근의 존재`

해당 문장은 세 부분으로 나누어 순차적으로 밝힙니다.

### **Scene 08 — 해를 계산하지 않고 존재를 증명한다**

## **3. 핵심 Manim 구현 설계**

특히 중요한 것은 **104\~129초의 복소평면 애니메이션이 실제 수학적 관계를 보존해야 한다**는 점입니다. 단순히 임의의 곡선을 축소하는 방식은 권장하지 않습니다.

### **입력과 출력의 대응 관계**

입력 원 위의 점을 다음과 같이 정의합니다.

\\[ z(t)=Re^{it} \\]

다항식은

\\[ P(z)=z^5+1 \\]

따라서 출력값은

\\[ P(z(t))=1+R^5e^{5it} \\]

입니다.

이 식을 그대로 사용하면 다음 세 상황을 정확하게 구현할 수 있습니다.

| 입력 반지름         | 출력 곡선          | 감김수              |
| -------------- | -------------- | ---------------- |
| \\(R>1\\)      | 원점을 내부에 포함하는 원 | 5                |
| \\(R=1\\)      | 원점을 통과하는 원     | 원점을 지나므로 정의되지 않음 |
| \\(0\le R<1\\) | 원점을 포함하지 않는 원  | 0                |

참고로 \\(R=1\\)에서는 서로 다른 다섯 입력값이 모두 근이 됩니다. \\(z^5+1\\)의 다섯 근이 모두 단위원 위에 있기 때문입니다.

### **Manim 코드 구조 예시**

아래는 핵심 애니메이션에 사용할 수 있는 구현 골격입니다. 좌우 복소평면을 고정하고, `ValueTracker`로 원의 반지름과 점의 회전각을 제어합니다.

```
        self.add(            input_plane,            output_plane,            input_circle,            output_curve,            input_dot,            output_dot,            output_origin,        )        # 입력 1회전, 출력 5회전        self.play(            theta.animate.set_value(TAU),            run_time=5,            rate_func=linear,        )        # 입력 원 축소        self.play(            radius.animate.set_value(1),            run_time=2,            rate_func=smooth,        )        # 원점 통과 상태를 강조        self.wait(1)        # 원점을 감지 않는 출력 곡선으로 이동        self.play(            radius.animate.set_value(0.5),            run_time=2,            rate_func=smooth,        )        # 최종적으로 P(0)=1        self.play(            radius.animate.set_value(0),            run_time=2,            rate_func=smooth,        )        self.wait(1)
```

이 코드는 장면의 핵심 수학적 대응을 구현하기 위한 예시입니다. 최종 제작에서는 텍스트, 라벨, 세로 화면에서의 배치, 발화 타이밍을 별도로 구성해야 합니다. 또한 원점 통과 장면에서는 `theta`를 적절히 조절해 실제로 \\(P(z)=0\\)이 되는 출력 점을 강조하면 좋습니다.

## **4. 영상에서 반드시 지켜야 할 수학적 표현**

| 내용                  | 정확한 표현 및 주의점                             |
| ------------------- | ---------------------------------------- |
| 모든 다항방정식에 해가 있다     | 복소수 계수의 1차 이상 다항방정식에 한정                  |
| 5차 방정식에는 근이 다섯 개 있다 | 중복도를 포함해 정확히 다섯 개                        |
| 큰 원에서 출력이 다섯 번 돈다   | 충분히 큰 반지름의 원에서는 출력 곡선이 원점을 다섯 번 감음       |
| 원을 줄이면 근을 만난다       | 원점을 통과하는 출력이 발생하는 순간 해당 입력이 근            |
| 감김수가 5에서 0으로 변한다    | 출력 곡선이 원점을 지나지 않는 동안 감김수는 변하지 않음         |
| 5차 방정식의 해를 모른다      | 근의 존재를 보장하는 것과 근의 구체적인 값을 계산하는 것은 별개의 문제 |

특히 대본 115\~123초의 \*\*“중간에 반드시 원점을 지나야 합니다”\*\*라는 설명은 감김수의 불변성을 전제로 합니다. 따라서 이 구간에서 출력 곡선이 원점에 접하거나 통과하는 순간을 정확하게 표시하는 것이 중요합니다.

## **5. 최종 제작 시 가장 중요한 세 가지**

**첫째, 5차 방정식의 근을 실제로 계산해서 보여주지 않는 것.** 영상의 도입과 결말은 근의 값을 모르더라도 근의 존재가 보장된다는 메시지를 유지해야 합니다.

**둘째, 입력 원과 출력 곡선을 반드시 동시에 움직이는 것.** 입력이 원을 한 바퀴 도는 동안 출력이 다섯 바퀴 돌고, 입력 반지름이 감소하면 출력 곡선의 형태도 바뀐다는 인과관계가 선명해야 합니다.

**셋째, 115\~129초에 충분한 시각적 집중도를 주는 것.** 나레이션은 이 구간에서 길게 설명하지 않습니다. 따라서 원점 통과 직전 곡선을 잠깐 멈추고, 통과하는 순간 색상과 확대 효과를 사용한 다음 \\(P(z)=0\\)을 표시하는 편이 좋습니다.

이번 영상의 가장 중요한 장면은 대수학의 기본정리라는 이름이 등장하는 70초가 아니라, **원점을 감던 곡선이 수축하면서 반드시 원점을 통과해야 하는 121초**입니다.

시청자가 그 장면을 이해했다면, 단순히 정리를 암기하는 것이 아니라 **수학적 구조의 불변성을 이용해 존재를 증명할 수 있다는 사실**까지 이해하게 됩니다.

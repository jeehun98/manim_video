# EP.17 제작 기준

사용자 제공 47개 문장 종료 시각 준수. 187초, 1920×1080, 30fps, 16:9. 음원 미제공으로 무음·화면 자막.

f′(x)=6x²+5,f(0)=3,목표f(1). 적분해 f=2x³+5x+C. C=3, f(1)=10. 다른 풀이 ∫₀¹f′dx=7=f(1)−f(0),3+7=10. 모든 부정적분에는 +C 표시. 항별 적분은 C 포함 또는 명시적으로 원시함수의 항임을 표시. 이전 단계에서 함수식을 먼저 공개하지 않음. 그래프는 실제 좌표계·정확한 접선 기울기 사용. f_C 수직 이동에도 f′는 같으며 접선들은 평행. 정적분 그래프의 넓이7을 원함수 높이차7로 연결. 주관식이므로 선택지 번호 없음.

26개 독립 교체 가능 씬. 이전 편 복습·다음 예고 없음. 기존 공통 타이밍·자막·렌더 도구 재사용.

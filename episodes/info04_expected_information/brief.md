# 정보이론 04 — 평균 구분 깊이 개정판

- 제목: 현실 하나를 특정하려면 몇 번을 나눠야 할까? 원안 19개 장면을 12개 발화 구간으로 압축. “평균 정보량” 대신 질문 트리의 설계와 구분 깊이를 먼저 체감한다.
- 이전 4편 소스·대본은 archive/info04_expected_information_v1/, 기존 MP4는 exports/info04_before_revision.mp4로 보존한다. ID info04와 Scene 클래스는 유지한다.
- 8개 균등 후보는 최적 균형 이진 트리에서 모두 깊이 3. 정보 손실 없는 정확한 예/아니오 질문, 비용은 질문당 1, 후보에 대한 임의 부분집합 질문을 허용한다. 실제 센서 비용이나 공간 탐색 제약을 도입하지 않는다.
- 비균등 p=(0.5,0.25,0.125,0.125), 균형 트리 평균 L=2. 재설계된 A/B/C/D 깊이는 1/2/3/3, L=H=1.75. 단순 후보 개수와 확률 질량을 반으로 가르는 것의 차이를 보여준다.
- 질문은 A인가 → (아니오) B인가 → (아니오) C인가. 예에 0, 아니오에 1을 붙여 A:0, B:10, C:110, D:111. Prefix-free이며 코드 길이와 질문 깊이가 일치한다.
- dyadic 확률 p=2^(−d)인 이 예시는 d=−log₂p가 정수라 엔트로피와 최적 평균 질문 수가 정확히 일치한다. 일반 분포에서는 서로 같지 않다. H≤L최적<H+1 (양의 확률이 있는 적어도 두 결과, 제약 없는 최적 이진 prefix 트리). 한 결과만 확실하면 질문 0개로 처리할 수 있다.
- 여러 독립 결과를 묶는 block coding에서 H≤L_n/n<H+1/n으로 결과당 평균 깊이가 H에 접근한다. 9구간은 이를 짧게 표시한다. 일반 엔트로피를 언제나 실제 1회 평균 질문 수로 설명하지 않는다.
- 원안 0.97/0.01/0.01/0.01은 H≈0.242이나 이진 1회 질문의 최적 평균 깊이는 1.05이므로, 초단편의 주된 비교는 정확히 일치하는 dyadic 분포로 한정하고 일반 관계를 따로 설명한다.
- “자주 나오는 결과는 얕게”는 최소 평균 깊이를 위한 설계 관점. 균등이어도 비대칭 트리를 만들 수 있으나 효율적이지 않다. 최적 트리를 기준으로 설명한다.
- 길이 58.50초. TTS 비공백 글자 / 초당 7자, 문장 휴지 0.18초, 마지막 0.5초. 등장·전환은 발화 구간 안에 포함. 실제 음성 미제공으로 추정 타이밍.

# 분포의 수학 15 제작 기준

- 4부 **하나의 분포를 넘어**. 제목은 **「관측된 데이터 뒤에는 무엇이 숨어 있을까? | Latent Variable」**. 첨부 콘티에 따라 잠재변수 정의로 곧장 가지 않고, 14화의 `30%/70%` 관측점에서 시간을 되감아 GMM이 점 하나를 실제로 만드는 순서를 먼저 보여준다.
- 14화와 같은 2성분 예시를 사용한다. 평균은 `μ₁=(-0.5,0)`, `μ₂=(0.5,0)`, 가중치는 `π=(0.4,0.6)`, 공통 공분산은 `diag(0.4²,0.479315…²)`이다. 강조점 `x=(0.070693…,0)`에서 `π₁p(x|1)=0.12`, `π₂p(x|2)=0.28`이므로 `P(z=1|x)=0.3`, `P(z=2|x)=0.7`이다.
- 생성 과정은 `z~Categorical(π)`를 먼저 뽑고 `x|z=k~N(μₖ,Σₖ)`에서 점을 뽑는다. 시각화에서는 이번 한 번의 선택을 `z=2`로 정해 14화의 강조점 위치에 점을 만든다. 그 점을 포함해 성분 1의 점 24개와 성분 2의 점 36개를 쌓는다. 이 숫자는 화면 예시의 고정 표본 수이며 모든 표본에서 정확히 그 비율이 나온다는 주장은 아니다.
- 생성 장면에서 색과 작은 숫자는 제작자가 알고 있는 성분 출처 `zᵢ`를 뜻한다. 관측 장면에서는 이 표식을 제거하고 같은 좌표의 `xᵢ`만 남긴다. `z`는 이 **생성 모델 안에서** 정의되는 미관측 선택 변수다. 실제 데이터가 반드시 동일한 물리적 선택 과정으로 생성됐다는 주장은 하지 않는다.
- `P(z=k|x)`는 주어진 GMM 모수와 관측값에 대한 **사후확률**이다. 영상이 예시로 보여준 단일 생성의 실제 선택은 `z=2`지만, 관측자에게 출처를 가린 뒤 추론한 결과는 `0.3/0.7`이다. `70%`를 개별 점의 일부나 선택 비율 `π₂`와 혼동하지 않도록 한다.
- 중반의 핵심 대비는 생성 방향 `z→x`와 추론 방향 `x→P(z|x)`다. Responsibility를 이 역추론의 확률로 회수한 다음에야 GMM의 이산 선택값을 넘어 연속형 잠재변수와 다차원 요인 예시로 넓힌다. `z∈R² → x∈R¹⁰⁰`은 가능한 모델의 개념도이며 모든 복잡한 데이터에 2차원 원인이 있다는 뜻이 아니다.
- 끝에서는 GMM의 모수와 성분 소속이 모두 미지인 상황을 제시한다. “분포를 알아야 소속을 추정하고, 소속을 알아야 분포를 추정한다”는 순환 질문에서 끝내며 Expectation–Maximization의 작동 방식은 설명하지 않는다.
- 흐름: 14화의 `30/70` → 그 확률의 의미 질문 → 생성 전으로 되감기 → 가중치만 존재 → `z=2` 선택 → `z`의 의미 → `x` 생성 → 두 단계 모형 → 반복 표본 → 출처 표시와 제거 → 잠재변수 이름 → 관측점에서 사후확률 회수 → 생성/추론 방향 대비 → Responsibility → 이산에서 연속 잠재변수로 → 작은 잠재공간과 큰 관측공간 → 관측 복잡성과 원인 구조 → 두 미지수의 순환 문제.
- 실제 TTS는 **95초**다. 영상은 **100초**이며 구간 경계는 `4,7.5,11,15.5,20,24,28,31.5,36,40,44,48,53,58,62,66.5,71,75.5,80,84.5,89,100`초다. 마지막 질문 화면을 음성 종료 뒤에도 약 5초 유지한다. 1080×1920, 30fps, 무음.

# 신경망의 수학 03 제작 기준

## 제목과 역할

- 제목: **백만 개의 파라미터가 정말 백만 개의 역할을 할까? — Parameter Symmetry**
- 핵심 명제: `θ ≠ θ′`이면서 `fθ = fθ′`일 수 있다. 서로 다른 파라미터 좌표가 같은 함수를 표현할 수 있다.
- 1화의 작은 학습 부분공간, 2화의 큰 해 집합을 다시 보고, 파라미터 수와 실질적 기능 자유도를 구별한다.
- 마지막에는 파라미터 거리와 함수 거리의 차이를 질문한다.

## 수학적 정확성

- 장면 2–5의 모델은 활성화 함수와 편향이 없는 두 스칼라 곱셈 `f(x)=w₂w₁x`이다. `w₁w₂=6`이면 모든 실수 입력 `x`에 대해 같은 함수가 된다.
- 영상의 곡선은 이해를 위해 양수인 제1사분면 가지를 보여준다. 음수 두 값의 가지도 같은 곱을 만들지만 예시 화면에서는 생략한다.
- `θ ∈ ℝ¹,⁰⁰⁰,⁰⁰⁰`은 백만 개의 실수 파라미터를 가진 모델의 파라미터 공간을 뜻한다. 각 좌표가 독립적인 *기능*을 갖는다는 결론은 아니다.
- 두 곱셈 인자의 재척도화는 이 예시의 연속 대칭이다. 실제 신경망의 대칭은 구조와 활성화 함수에 따라 달라지므로 모든 파라미터 방향이 중복이라고 단정하지 않는다.
- 1화의 intrinsic dimension과 이번 편의 함수 중복은 관련된 관점이지만 동일한 양이라고 주장하지 않는다.

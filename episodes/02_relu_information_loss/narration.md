# ReLU — Information Loss #1

42초 무음 마스터용 선택 내레이션. 화면은 전편처럼 영어입니다.

| 시간 | 내레이션 |
| --- | --- |
| 0–7초 | ReLU의 규칙은 같습니다. 하지만 입력에 따라 그 효과는 달라집니다. |
| 7–14초 | 음수에서 0이 된 값은 각각 0, 50, 75퍼센트입니다. 이것을 Zeroed Ratio라고 해 봅시다. |
| 14–21초 | 분포도 같습니다. 양수가 많으면 적게, 음수가 많으면 많이 0으로 모입니다. |
| 21–28초 | 입력 분포를 알면 억제될 비율을 예상할 수 있습니다. 이 대칭 예시는 절반. 분포가 이동하면 비율도 변합니다. |
| 28–36초 | 이 두 입력은 모두 절반이 0이 됩니다. 사라진 값의 크기는 크게 다르죠. |
| 36–42초 | 같은 개수가 사라졌다면 정보 손실도 같을까요? 다음에는 얼마나 제거됐는지 살펴봅니다. |

Zeroed Ratio는 count(x < 0) / N으로 정의합니다. 이미 0이었던 입력은
새로 억제된 값에 포함하지 않습니다. 일반적으로 출력이 0일 확률 P(X ≤ 0)과
음수가 억제될 확률 P(X < 0)은 다를 수 있습니다.

그림은 실제 신경망 측정치가 아닌 표준편차 0.9인 연속 정규분포의 예시입니다.
확률 표시는 정규분포 CDF로 계산하며, 그림은 유한 구간의 밀도 막대입니다.
0으로 모이는 분홍 막대는 확률 질량의 개념적 표현이고 출력 밀도 높이가 아닙니다.
Zeroed Ratio나 제거된 크기를 정보이론적 정보 손실과 동일시하지 않습니다.

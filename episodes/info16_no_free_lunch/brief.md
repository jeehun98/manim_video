# 정보이론 16 — 학습이 가능하려면 세상이 특별해야 합니다 — No Free Lunch

학습 목표: 본 데이터에 맞는 여러 정답 함수 중 새 점의 답을 선택하려면 귀납 편향이 필요하며, 실제 일반화는 그 편향과 문제 분포의 구조가 맞는 데서 나온다는 점을 이해한다. 기존 15편 Szilard Engine을 유지하고 16편으로 추가한다.

## 제작 기준

- 세로 1080×1920, 30fps. 무음 영상 / 별도 발화용 대본과 SRT. 발화 길이 추정에 맞춰 구간 누적 시각을 고정한다.
- 중심 장면: 관측한 정답 0,1,1은 같지만 x4에서 갈리는 두 세계. 미관측 네 정답의 16개 조합을 모두 보여주고, x4=0/1 세계가 각각 8개임을 직접 센다.
- 전개: 새 점 → 두 세계 → 16개 완성 → 8/16 비교 → 균등 평균의 NFL 조건 → 가까운 답의 유사성 가정 → 가정과 세계의 일치/실패 → 귀납 편향 → CNN → 압축 비유 → 암기와 일반화 → 핵심 결론.
- 마지막 두 구간은 분리해 충분히 유지한다. 모든 알고리즘이 현실에서도 같다는 해석을 배제하고, 현실의 구조와 모델의 가정이 만나는 장면으로 끝낸다.
- 제목에 No Free Lunch를 상시 표시한다. 중간에서 균등 평균 조건과 정리 이름을 직접 연결하고, 마지막에 정리 이름을 다시 언급해 좋은 알고리즘의 부재가 아니라 만능 학습법의 부재라는 의미를 회수한다.
- 수식 도입보다 카드의 답이 갈리는 장면을 앞세운다. 무작위 장식 대신 동일 증거와 서로 다른 미관측 정답을 나란히 표시한다.

## 수학적 조건과 표현의 범위

유한 입력 공간 {x1,...,x7}, 이진 정답, 관측 위치 x1,x2,x3의 정답 0,1,1을 고정한다. 모든 2^7개의 정답 함수를 사전에 균등하게 취급하면 관측 후에도 미관측 네 답은 16개 완성에 균등하게 분포한다. x4를 포함하는 특정 미관측 점에서 조건부 정답 확률은 1/2다. 예측이 0,1 또는 무작위여도 정답 함수와 별도 상관관계가 없다면 기대 0-1 오류는 1/2이며, 동일한 관측 집합을 이용하는 학습법 간 평균 우위는 없다. 이는 감독학습의 off-training-set 비교이며, 최적화 NFL과 혼합하지 않는다.

관측 점을 포함하는 훈련 정확도 비교가 아니다. 실제 문제 분포에 균등 함수 사전분포를 가정하는 것도 아니다. 현실의 데이터가 어느 함수나 구조를 더 자주 생성하는지에 따라 알고리즘의 성능 차이가 생긴다. 개별 문제에서 잘하는 이유가 오직 단일 사전 가정 때문이라고 단정하지 않는다. 데이터 양, 잡음, 최적화, 계산 자원도 성능에 영향을 준다.

가까운 입력의 유사성은 하나의 예시이며 구조가 반드시 부드럽거나 사람 눈에 단순해야 하는 것은 아니다. 두 비교 세계의 앞 세 답은 동일하고 x4만 달라 예측 성공/실패를 보여준다. 마지막 밝게 남기는 세계 두 개는 유사성 선호의 개념 예시이며 정확한 모델 클래스 정의나 NFL의 증명 대신 사용하지 않는다.

CNN의 지역적 수용 영역과 공유 필터는 지역 패턴·이동에 대한 등변성의 예시다. CNN 전체가 임의의 이동에 완전히 불변이라는 주장이나 모든 이미지 문제에 우월하다는 주장을 하지 않는다.

무구조 예제는 미관측 정답이 관측 데이터와 독립이고 등확률인 경우로 한정한다. 무작위 정답이어도 불균형 등 다른 통계적 구조가 있으면 절반 이상 정확도가 가능하다. 압축 장면은 반복 구조가 짧은 설명과 예측을 돕는다는 비유다. 압축 가능성이 일반화를 항상 보장하거나 모든 구조가 문자 반복이라는 명제가 아니다.

## 근거

## 검증

16개 완성과 8/8 분할, 두 학습법의 조건부 평균 정확도를 계산한다. 360×640 미리보기 전체 구간과 카드 강조·CNN 필터 이동을 확인하고, 1080×1920 최종본 전체를 디코딩해 프레임 수와 종료 시각을 확인한다.

# AI 컴파일러 01 — 유한한 뉴런으로 무한히 많은 패턴을 인식할 수 있을까?

부제: 신경망에서 정규 표현식까지.

## 학습 목표

유한한 상태가 무한히 많은 유한 길이 문자열을 처리할 수 있음을 이해한다. 상태는 기억의 한 형태이며 과거 전체 대신 앞으로의 판정에 필요한 정보만 유지한다. 같은 정규 언어를 정규식과 오토마타로 표현할 수 있다는 직관을 형식적 신경망의 역사와 연결한다.

## 제작 기준

- 6장면 종료: 20, 49, 72, 97, 124, 149초. 사용자 제공 31개 문장 종료 시각을 적용한다. 실제 음원 파일 대조는 미실시다.
- 세로 1080×1920, 30fps, 무음. 미리보기 360×640. timing.json이 대본·SRT의 단일 타이밍 원본이다.
- 복습·시리즈 요약·후속 예고 없이 이 영상의 질문으로 완결한다.
- 뉴런 발화 → 시간 지연 → 상태 전이 → 문자열 집합 → 정규식. 03–05를 중심으로 제작한다.

## 수학적·역사적 조건

1. 알파벳 {A,B}, 언어 {AⁿB | n≥0}. 무한 길이 문자열이 아니라 무한히 많은 유한 문자열이다. 실제 장치의 시간·물리 자원이 무한하다는 주장이 아니다.
2. DFA 전이: q0에서 A→q0, B→q1; q1에서 A/B→qx; qx에서 A/B→qx. 초기 q0, 수용 q1. 입력 종료 시에만 수용 판정. 공문자열·BA·ABA·ABB는 거부한다.
3. 세 뉴런 그림은 개념도이며 이 DFA를 세 뉴런으로 구현했다는 주장이 아니다. 일반적으로 유한 개 이진 뉴런과 유한 지연 기억은 유한 상태를 갖는다. 현대 연속값 신경망 전체에 이를 일반화하지 않는다.
4. AND 예시는 단위 시간 지연을 명시해 C(t+1)=A(t)∧B(t)로 표시한다. 회귀 연결은 시간 반응의 개념도이다.
5. Kleene의 1951 보고서 및 1956 출판을 구분한다. 정규 사건 연구의 역사적 형식 신경망과 현대 딥러닝을 구분한다.
6. 이론적 정규 표현식과 유한 오토마타의 동등성: 모든 정규식에 같은 언어를 인식하는 오토마타가 있고 역방향도 성립한다. 임의의 두 식·기계가 같다는 뜻이 아니다. 예시 비교는 증명 전체를 대신하지 않는다.
7. 검색창은 줄 전체 판정으로 ^A*B$를 표시한다. 예시 입력은 개행 없는 각 단일 문자열이며 부분 검색과 전체 판정을 혼동하지 않는다.

## 검증

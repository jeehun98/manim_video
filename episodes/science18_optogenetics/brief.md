# 제작 기준 — 빛으로 뉴런을 켤 수 있을까?

- 목표: 전구·리모컨·빛의 문이라는 비유로 관찰에서 개입, 상관관계에서 인과적 역할 검증으로 넘어간 광유전학의 의미를 설명한다.
- 17장면 / 사용자 제공 TTS 누적 시각 기준 141초 / 세로 1080×1920, 30fps, 무음.
- 피드백 반영 순서: 뇌의 전구 → 직접 누를 스위치 → 선택의 어려움 → 녹조류 → 빛으로 여는 문 → 전기적 변화 → 채널로돕신 이름 → 유전자 발현 → 뉴런의 리모컨 → WHEN × WHO → 행동 실험 → 인과적 역할 → 회로 시험 → 별도 억제 단백질 → 노벨상.
- 전압 그래프와 임계점·활동전위 전문 용어의 연속 설명을 제거하고 신호가 축삭을 따라 퍼지는 그림으로 대체한다.
- 뉴런을 전구로 표현하는 것은 시각적 비유다. 행동 예시는 개념 실험이며 결과가 회로마다 다르고 각 집단이 하나의 기능을 전담한다는 뜻은 아니다.
- OFF는 광자극 없음이며 자발적 뉴런 활동이 없어짐을 뜻하지 않는다. 억제에는 다른 옵신이 필요하다.
- 빛 조사 영역과 유전적 발현 대상의 교집합이 표적이다. 모든 선택 세포가 뇌 전체에서 동시에 반응하는 것으로 표현하지 않는다.
- 개입 결과는 적절한 대조 실험과 함께 해석하며 충분성·필요성이나 유일한 원인을 자동으로 확정하지 않는다.
- 모든 전압과 발화 파형, 행동 결과는 개념도다.

## 검증

- 수정본 360×640 미리보기와 접촉 시트에서 비유의 순서 및 세로 안전영역을 확인했다.
- 빛의 문과 마지막 전구/문구 배치를 개별 프레임으로 확인했다. 마무리 전구판을 위로 옮겨 문구와 분리하고 행동 실험의 빛 화살표를 레이블 바깥으로 이동했다.
- 대본·TTS·자막·타이밍에 사용자 제공 종료 시각 `4,13,19,26,33,41,48,57,65,74,82,90,100,109,118,128,141초`를 적용했다.
- 음성 파일이 첨부되지 않아 음소·문장 내부 시각은 직접 측정하지 않았다. 장면 경계는 제공된 실측값이며 문장별 SRT는 해당 구간 안에서 문자 비중으로 배분했다.
- 미리보기 및 최종 렌더 완료. 17개 종료 시각과 연속된 구간 경계를 검사했고 시간 초과 없이 통과했다.
- 최종본: 1080×1920, 30fps, 4,230프레임, 140.999초, 영상 스트림만 포함. SRT 마지막 시각 141초.

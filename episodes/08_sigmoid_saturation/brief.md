# Sigmoid 03 — 대본 검토

100초, 1080×1920, 30fps, 한국어 자막, 무음 마스터.

## 수정 의도

- 역전파는 출력값의 변화 자체를 전달하는 것이 아니라 손실의 기울기를 연쇄법칙으로 계산한다. `y=σ(x)`에서 `∂L/∂x=(∂L/∂y)σ′(x)`로 명시했다.
- “거슬러 올라갈수록 작아진다”는 단정을 제거했다. 한 Sigmoid의 국소 미분계수가 기울기에 미치는 효과를 보여주고, 여러 층의 반복은 다음 편의 질문으로 남겼다. 전체 네트워크에서는 가중치와 다른 미분값, 경로 및 손실 구성도 영향을 준다.
- 포화는 입력 변화에 둔감한 상태로 설명한다. 유한 실수 입력에서 출력이나 미분계수가 정확히 0 또는 1이 된다고 설명하지 않는다.
- 수치 예시는 x=5에서 σ′(5)≈0.006648, 출력 쪽 기울기 1을 가정한다. 움직이는 점의 크기는 개념적인 강조이며 기울기의 정량 척도가 아니다.
- 양수 예시: σ(5)≈0.993307 → σ(6)≈0.997527. 음수 예시: σ(−5)≈0.006693 → σ(−6)≈0.002473.

## 장면

0–42초: 전편 복습, 포화의 정의, 양끝의 실제 출력 변화.

42–74초: 순전파와 역전파 방향, 연쇄법칙, 입력 쪽 기울기의 수치 예시.

74–100초: 두 방향의 공통 미분계수, 기울기 소실과의 연결, 다음 편 질문.

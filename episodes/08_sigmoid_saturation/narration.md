# Sigmoid 03 — 포화와 작아지는 학습 신호

100초 · 한국어 자막 · 음성 및 음악 없음

앞에서 Sigmoid의 기울기는
작은 입력 차이를 얼마나 남기는지 보여주는
국소적인 압축률이라고 했습니다.

그런데 양끝으로 갈수록
이 기울기는 점점 0에 가까워집니다.

이 영역에서는 입력이 조금 변해도
출력은 거의 변하지 않습니다.

이처럼 출력이 양끝의 값에 가까워져
입력 변화에 둔감해진 상태를 포화라고 합니다.

예를 들어 입력이 이미 큰 양수라면,
값이 조금 더 커져도 출력은 거의 1에 머뭅니다.

큰 음수에서도 마찬가지입니다.
출력은 거의 0에 머물고,
입력 변화는 잘 드러나지 않습니다.

문제는 이 기울기가
순전파에서만 중요한 것이 아니라는 점입니다.

학습할 때는 손실을 줄이기 위해,
각 값이 손실에 미치는 영향을 역방향으로 계산합니다.

역전파에서는 출력 쪽 손실 기울기에
Sigmoid의 기울기를 곱해
입력 쪽 손실 기울기를 구합니다.

포화 영역에서는 곱해지는 값이 거의 0이므로,
이 함수를 통과하는 학습 신호가 크게 줄어듭니다.

즉 Sigmoid의 양끝에서는
출력에 드러나는 작은 입력 차이뿐 아니라,

입력 쪽으로 전달되는
손실의 기울기까지 작아질 수 있습니다.

이것이 Sigmoid의 포화가
기울기 소실, Vanishing Gradient와 연결되는 이유입니다.

그렇다면 이런 작은 값의 곱셈이
여러 층에서 반복되면 어떻게 될까요?

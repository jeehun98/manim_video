# FlashAttention 시리즈 3편 제작 기준

- 핵심은 score 전체를 저장하지 않고도 안정적인 Softmax의 요약 상태 `m`, `ℓ`을 block-wise로 갱신할 수 있다는 점이다.
- 예시는 `[1,3,2]`, `[2,5,4]`, `[0,4,1]` 세 블록을 사용한다.
- 첫 블록: `m₁=3`, `ℓ₁=e⁻²+e⁰+e⁻¹≈1.503`.
- 두 번째 블록: `m₂=5`, 이전 기여는 `ℓ₁e^(3−5)≈0.203`, 새 블록 기여는 `e⁻³+e⁰+e⁻¹≈1.418`, 따라서 `ℓ₂≈1.621`.
- 세 번째 블록은 최댓값을 바꾸지 않고 약 `0.393`을 더해 최종 `m=5`, `ℓ≈2.014`를 만든다.
- Full scan에서도 `max=5`, `Σexp(x−5)≈2.014`이므로 block-wise 결과와 같다.
- running max는 수치 안정성의 기준이며, 기준이 바뀔 때 이전 합을 `exp(m_old−m_new)`로 재조정해야 한다.
- 3편은 output accumulator를 설명하지 않는다. `O`는 마지막 질문에만 등장하며 4편에서 `m,ℓ,O` 공동 갱신으로 확장한다.
- `ℓ`은 숫자 1이나 알파벳 l과 구분하기 위해 화면과 문서에서 script ell 기호를 사용한다.

# 분포의 수학 08 제작 기준

- 학습 목표: 방향을 골라 투영한 분산을 비교하면서 공분산 행렬의 최대 고유벡터를 발견한다. 다른 고유벡터도 퍼짐의 주축이며, **최대 분산 방향은 가장 큰 고유값에 대응하는 고유벡터**임을 구별한다.
- 사용 행렬은 `Σ=[[2,1],[1,2]]`다. 같은 가중치를 가진 48개 점의 표본을 평균 0, 분산 `2,2`, 공분산 `1`이 정확하도록 구성한다. 이산 점구름의 확률가중 공분산으로 해석한다.
- 단위방향 `v=(cosθ,sinθ)`에 투영한 값 `vᵀX`의 분산은 `vᵀΣv=2+sin(2θ)`다. `θ=45°`에서 최대 `3`, `θ=135°`에서 최소 `1`, 축 방향 `0°/90°`에서는 `2`다.
- `v₁=(1,1)/√2`, `Σv₁=3v₁`; `v₂=(−1,1)/√2`, `Σv₂=v₂`. 공분산 행렬이 실수 대칭 양의 준정부호이므로 직교하는 고유벡터를 주축으로 선택할 수 있다. 고유값은 각 단위 주축의 **투영 분산**이며 타원의 길이 자체와는 구별한다.
- 화면 순서: 점구름과 숫자 → **점구름과 좌표축을 유지한 채 투영 화면으로 이동** → 방향 회전과 분산 측정 → 최대 방향 → `vᵀΣv` → 각도별 최댓값 → `Σv₁=3v₁` → 고유벡터·고유값 → 수직 방향 → 두 주축 요약 → 새 축과 대각 행렬.
- 제공된 실제 TTS 길이 42초에 맞춘 구간 경계: 3.5, 7, 10.5, 14.5, 18, 22.5, 26.5, 30, 33.5, 37.5, 42초. 이전 49초 판본에서 초반 좌표가 잠깐 나타났다 사라지는 전환을 제거했다. 1080×1920, 30fps 무음.

# 정보이론 05 — 압축과 비트의 지출

- 제목: 압축은 예상 가능한 것을 짧게 쓰는 것이다. 원안 17개 화면을 12개 발화 구간으로 정리. 정의나 알고리즘보다 “같은 원문, 다른 비트 비용”을 먼저 확인한다.
- 학습 목표: 무손실 압축은 원문을 정확히 복원하면서 확률에 맞춰 표현 비용을 재배분할 수 있다. 모든 압축 알고리즘이 1기호 가변길이 코드를 쓰거나 모든 파일이 짧아진다고 주장하지 않는다.
- 원문 AAABAAACAAADAAABACAD, 총 20기호. A14, B2, C2, D2로 경험 비율 0.7/0.1/0.1/0.1과 정확히 일치한다. 인위적으로 구성한 예시이며 랜덤 표본의 수렴 증거가 아니다.
- 고정 코드 A00 B01 C10 D11: 본문 40 bits. 가변 코드 A0 B10 C110 D111: 본문 30 bits. 절약 10 bits=25%. A14→14bits(14bit 절약), B4→4(변화 없음), C4→6, D4→6(각 2bit 증가). 압축은 자주 쓰는 곳에서의 절약이 드문 곳의 증가를 상쇄하는 것으로 보여준다.
- 고정/가변 코드표를 송수신자가 공유한다는 가정. 길이/파일 헤더/모형/코드표 전달 오버헤드는 제외하는 본문 비교이며 화면에 표시한다. 짧은 파일에서 총 파일 길이까지 25% 절약한다고 단정하지 않는다.
- Prefix-free 코드이므로 공백 없는 연속 비트열에서도 복원 가능. decode 함수로 두 본문 모두 동일한 20기호를 복원함을 확인한다. 화면의 색과 시각적 간격은 설명용이며 전송 구분자로 계산하지 않는다.
- 정보량 −log₂p와 실제 코드 길이를 동일시하지 않는다. p(A)=0.7의 정보량≈0.515, 실제 길이1. p(B)=p(C)=p(D)=0.1은 각각≈3.322이지만 B의 실제 길이는2, C/D는3. 단일 결과마다 L≥I인 것은 아니다.
- 평균 L=1.5 bits/기호, 엔트로피 H=1.356780 bits/기호. 최적 무손실 이진 prefix 코드의 평균 길이에 H≤L최적<H+1. 알려진 IID 분포의 여러 기호를 묶으면 기호당 평균이 H에 접근할 수 있다. 실제 부호의 평균과 이상적 한계를 구별한다.
- 원안 ABACADAEAFAGAHAI는 규칙을 알면 예측 가능한 문자열이다. “반복보다 규칙과 모형이 중요함”으로 장면을 수정: 홀수 위치 A, 짝수 위치 다음 알파벳, 다음은 A G A H. 규칙의 기술 비용과 공유 조건은 모형에 따라 필요하며 이를 무시한 보편적 압축률을 제시하지 않는다.
- 마지막 실제 p=(.7,.1,.1,.1), 예상 q=(.1,.7,.1,.1)을 비교하고 잘못 배분한 비트 비용을 다음 질문으로 남긴다. Cross Entropy를 이번 편의 실제 1기호 코드 길이와 정확히 동일하다고 미리 정의하지 않는다. 다음 편에서는 이상적 log loss/부호 길이와 실제 정수 코드 길이를 구별할 것.
- 길이 57.03초. TTS 비공백 글자 / 초당7자, 문장 휴지0.18초, 마지막0.5초. 30fps 프레임 경계. 전환/등장 시간은 구간 안에 포함. 실제 음성 없이 발화 추정.
- 1080×1920 30fps 무음. TTS/SRT 별도. 공통 Malgun Gothic과 시리즈 색상. 중앙 시각화·하단 자막 안전 영역 구분.

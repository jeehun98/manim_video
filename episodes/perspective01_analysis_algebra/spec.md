# 씬별 주장과 확정 길이

- 01: 0–23초 / 같은 수학, 다른 관점
- 02: 23–33초 / 모든 실수에서 양수일까?
- 03: 33–55초 / 첫 번째 접근 · 구간별 비교
- 04: 55–86초 / 다섯 구간, 하나의 결론
- 05: 86–102초 / 두 번째 접근 · 숨겨진 구조
- 06: 102–132초 / 짧은 증명이 더 좋은 증명일까?
- 07: 132–151초 / 각 관점이 던지는 질문
- 08: 151–164초 / 같은 대상, 다른 성질
- 09: 164–173초 / 어떤 관점으로 바라볼 것인가?

상단 제목, 중앙 본문, y<-4.9 자막 전용. 구간별 검증은 하나의 고정 수직 배치 수직선 사용. 실제 좌표 간 거리 보존.

33–86초: 원래 다항식과 양수 증명 목표를 고정 표시. 앞 두 항은 파랑, 나머지 항은 노랑으로 풀이와 대응. 구간 조건 → 항별 비교 → 하한 결론을 순차 공개. 대본·타이밍 유지.

# 신경망 내부의 계산 01 — 정답만 가르쳤는데, AI는 어떻게 풀이를 배울까?

시리즈: 신경망 내부의 계산 — 표현에서 알고리즘까지

## 확정 기준

- 사용자 제공 최종 대본과 32개 누적 문장 종료 시각으로 제작한다. 마지막 종료 시각 **164초(2:44)**가 기준이다. 목표 범위 2:20~2:40 및 상세 콘티의 약 2:52보다 실제 발화 시각을 우선한다. 추가 엔딩 시간을 붙이지 않는다.
- 사용자가 이번 편에 지정한 **16:9 수학 애니메이션**. 1920×1080, 30fps. 미리보기 640×360. 기존 시리즈의 세로형 기본값을 이 편에 적용하지 않는다.
- 대본은 사용자가 확정했고 발화 시각도 제공했다. 음원 파일은 제공되지 않았으므로 기본 영상은 무음이며, 실제 음원 파형·발화 시작점과의 동기화 검증을 주장하지 않는다. 문장 종료 시각을 글자 수 추정으로 바꾸지 않는다.
- narration.md에는 원 표기, tts_script.txt에는 사용자가 제공한 실제 낭독 문장을 그대로 사용한다. TTS는 주요 화면별 14문단, 빈 줄 하나로 구분하며 시각·제목·장면 번호를 넣지 않는다.
- content.py → scripts/prepare_nncalc01.py → narration.md·tts_script.txt·timing.json·captions.srt. 영상과 자막은 같은 32개 시각을 사용한다.

## 연출과 재사용 컴포넌트

어두운 남색 배경, 개수 비교 청록색, 중첩 확인 보라색, 성공 초록색, 위반 붉은색, 훈련 카드 흰색, 새 입력 노란색. BracketSequence는 토큰 강조, CountingAlgorithm은 두 카운터, DepthTracker는 부호 있는 누적 깊이와 위반 이력, ModelPopulation은 개념적 모델 집단, DistributionWeighting은 예제 유형별 비중을 표현한다.

핵심은 훈련 입력에서는 두 경로가 같은 정답에 도달하고 새 입력에서는 갈라진다는 것이다. 중첩 깊이가 −1이 되는 단계에서 0.5초 멈춘다. 이후 최종 깊이가 0으로 돌아와도 위반 이력은 사라지지 않는다.

데이터 비중 변경은 이미 학습된 단일 모델의 알고리즘을 즉시 바꾸는 슬라이더로 보여주지 않는다. **분포 변경 → 다시 학습 → 새 모델 집단**을 각각 표시한다. 샘플 막대 길이·모델 수·색상 비율은 정량값이 아닌 개념도임을 표시한다. 실제 관찰 연구를 소개하되 이 프로젝트에서 신경망 실험을 수행한 것처럼 표현하지 않는다.

## 수학적·서사적 조건

- 실제 정답은 올바른 단일 괄호 중첩이다. 개수 규칙은 불완전한 후보 규칙이며 `올바름`은 그 규칙의 출력이라는 점을 색상·패널로 구별한다.
- 훈련 예시는 `()()`, `(())`, `(()`, `())`. 교육용 구성으로 논문 전체 데이터셋의 재현이 아니다. 도입에서도 `())(`를 정답과 함께 학습시키지 않는다. 이 입력은 두 규칙을 구별하는 새 입력이기 때문이다.
- 깊이는 여는 괄호 +1, 닫는 괄호 −1의 접두사 합. `(())`는 0,1,2,1,0; `())(`는 0,1,0,−1,0이다. 중첩은 모든 깊이 ≥0, 최종 깊이 0을 요구한다.
- 네트워크 노드·연결선·학습 펄스는 개념도다. 실제 카운터 회로나 스택을 추출했다거나 상징적 코드가 생겼다고 단정하지 않는다. 오차 감소의 정량 실험 곡선을 만들지 않는다.
- 같은 훈련 **분포**를 사용한다는 말과 매 실행의 초기값·데이터 셔플까지 모두 같다는 말을 구별한다. 일반화 행동과 특정 내부 알고리즘 전체의 입증도 구별한다.
- 특정 예제를 강조하면 모든 모델이 반드시 특정 알고리즘으로 수렴한다는 법칙으로 확장하지 않는다. 사용자 대본의 '유도'는 경향의 변화다.
- Linear Probe·Intervention 설명, 이전 편 복습, 후속 편 예고는 넣지 않는다. Patterning은 이번 편의 발견을 설명하는 연구 이름으로만 등장한다.

## 연구 근거

- George Wang & Daniel Murfet, [Patterning: The Dual of Interpretability](https://proceedings.mlr.press/v306/wang26fw.html), ICML 2026. 공식 페이지는 괄호 문제에서 훈련 정확도가 같은 여러 알고리즘과 데이터 개입을 통한 알고리즘 선택 유도를 보고한다.
- [저자 원고 v1 §4 및 §4.5](https://arxiv.org/html/2601.13548v1#S4)는 두 규칙이 일치하는 분포의 훈련, 제외했던 입력에서의 차이, 데이터 구성 변경 후 재학습한 모델 집단의 일반화 분포 변화를 설명한다. 수치와 세부 수학은 본편에서 재현하지 않는다.
- 최종판 공식 페이지와 저자 원고를 2026-10-21 확인했다. 이 영상의 토큰·샘플 막대·집단 아이콘은 교육용 개념도다.

### 쇼츠 세로 버전

사용자의 추가 요청에 따라 같은 확정 대본과 32개 종료 시각, 총 164초로 9:16 버전을 별도로 제작한다. 대본을 축약하거나 발화 속도를 임의로 바꾸지 않는다. scene_shorts.py가 가로 버전의 수학 컴포넌트를 사용하되 장면은 세로로 새로 배치한다. 두 알고리즘은 위아래 비교, 재가중→재학습→새 모델 집단은 아래 방향 흐름이다. 1080×1920·30fps, 미리보기 360×640. 본문은 x±4, y−5.1~4.85, 자막은 별도 하단 패널 안에서 배치한다. 자막은 같은 문장을 세로 폭에 맞게 줄바꿈한다. 무음이며 가로 출력 파일은 덮어쓰지 않는다. `python scripts/render.py nncalc01_shorts`, 검토는 `python scripts/check_nncalc01.py --shorts`. 결과는 production_checks_shorts.json에 기록한다.

`python scripts/render.py nncalc01 --preview` 후 장면별 화면 검토, 이어 `python scripts/render.py nncalc01`. `python scripts/check_nncalc01.py --preview` 또는 `python scripts/check_nncalc01.py`로 길이·해상도·fps·32개 종료 시각·TTS 원고 일치를 확인하고 장면별 검토 이미지를 생성한다. 결과는 production_checks.json에 기록한다.

# 신경망 내부의 계산 01 — 정답만 가르쳤는데, AI는 어떻게 문제 푸는 방법을 배울까?

## 이번 영상의 주장

정답 라벨은 훈련 예제에서 맞혀야 할 출력을 지정한다. 그 출력을 구현하는 계산은 유일하게 정해지지 않으며, 데이터 구성과 학습 조건에 따라 서로 다른 규칙에 대응하는 모델이 형성될 수 있다.

처음의 질문에 마지막이 답해야 한다. '오차를 줄이는 가중치 학습으로 계산이 형성되지만, 정답만으로 계산 규칙이 하나로 정해지지는 않는다'로 끝낸다. 내부 연구 도구의 소개로 주제를 바꾸지 않는다.

## 제작 상태와 순서

- 2026-10-21 사용자 피드백을 반영한 v2 대본. 현재는 대본 검토 단계이며 영상은 새로 생성하지 않는다.
- `narration.md`·`tts_script.txt` 사용자 검토와 확정 → 확정된 버전의 실제 TTS 음원 또는 사용자 발화시간·문장 종료 시각 → 그 시간 안에서 화면·자막·타이밍 설계 → 미리보기 → 최종 렌더.
- 이전 대본의 실측 1:19와 이전 제작물의 2:52는 이 버전의 길이가 아니다. 글자 수 비례로 타이밍을 배정하지 않는다. 이전의 3분 상한은 길이 제약으로만 참고한다.
- `content.py`가 12문단의 원본이다. `python scripts/prepare_nncalc01.py`는 대본·발음 원고·검토 상태만 생성한다. timing.json·SRT·영상은 만들지 않는다.
- 기존 scene.py·timing.json·captions.srt·production_checks.json 및 exports의 MP4는 이전 대본 결과물이다. 기존 제작 소스는 revisions/v1_probe_intervention/에 보존했다. 현재 scene.py에는 대본 확정·실제 발화시간 전 실행을 막는 상태 확인을 두었다. 새 화면은 별도로 다시 설계해야 한다.

## 서사와 화면 구상

1. 괄호 문자열과 정답 라벨만 제공한다. 사람이 알고리즘을 입력하는 화살표는 없다.
2. 예측 → 정답과 비교 → 오차 → 가중치 갱신을 보여준다. 깊이·괄호 수를 중간 정답으로 제공하지 않는다.
3. 같은 훈련 데이터를 설명하는 두 계산 규칙을 나란히 제시한다.
4. 개수 규칙은 최종 합, 중첩 규칙은 전체 경로의 조건을 본다.
5. 제한된 훈련 집합에서는 두 규칙이 모두 정답이다.
6. `())(`에서 규칙이 갈린다. 단순 사고실험이라는 표시를 유지한다.
7. 연구 결과로 전환한다. 같은 훈련 분포에서 서로 다른 일반화 행동을 보인 실제 학습 모델 집단을 소개한다.
8. 학습된 알고리즘은 가중치들이 구현하는 계산 규칙이라는 의미를 설명한다. 사람의 프로그램 코드가 저절로 작성된다고 표현하지 않는다.
9. 데이터 구성·모델 구조·초기화·최적화는 규칙 형성에 영향을 주는 조건이다.
10. 연구에서 데이터 구성 변경 후 모델 집단의 일반화 분포가 달라졌다는 결과를 제시한다. 상세한 Patterning 수학은 다루지 않는다.
11. 서로 다른 일반화는 새로운 입력에서의 신뢰성 차이와 연결된다.
12. 정답을 가르치는 것과 풀이까지 지정하는 것의 차이로 완결한다.

영상 내 이전 편 복습·후속 편 예고 없음. 내부 기획 순서는 01 학습 목표와 학습된 규칙 → 02 Induction Heads → 03 Patterning → 04 Probing·Intervention이며, 이 목록을 영상에서 예고하지 않는다.

## 예시의 정확성

- 실제 정답 기준은 올바른 단일 괄호 중첩이다. A는 개수만 비교하는 불완전한 후보, B는 모든 접두사 깊이 ≥0 및 최종 깊이 0을 확인하는 후보다.
- 화면용 훈련 예시: `()()`, `(())`는 올바름, `((()`, `()))`는 올바르지 않음. 모든 입력이 짝수 길이이며 두 규칙 모두 같은 정답을 낸다. 이 네 문자열은 설명용으로 선정했으며 논문 전체 훈련 집합의 재현이 아니다.
- 새 입력 `())(`의 깊이는 0,1,0,−1,0. A 수락, B 거부. 올바른 `(())`의 깊이는 0,1,2,1,0이다.
- 중간 계산이 형성된다는 말은 상징적 카운터나 특정 뉴런의 깊이 저장이 반드시 나타난다는 주장이 아니다. 이번 편에서는 중간 벡터의 깊이 측정 결과를 제시하지 않는다.
- 두 규칙에 대응하는 행동이 관찰됐다는 주장과 내부 메커니즘을 완전히 증명했다는 주장을 구별한다. 출력 차이만으로 회로 전체를 복원했다고 말하지 않는다.
- 정답만으로 규칙이 유일하지 않다는 말은 데이터가 아무 제약도 주지 않는다는 뜻이 아니다. 규칙을 구별하는 예제를 추가하면 후보를 제약할 수 있다. 무한한 데이터에 대한 보편적 불가능성도 주장하지 않는다.
- 학습은 알고리즘 후보 목록 중 이름을 고르는 절차가 아니다. 서로 다른 파라미터 해가 다른 일반화 규칙에 대응한다는 설명이다. 간단한 규칙이 항상 선택된다는 법칙이나 모든 조건에서 규칙을 원하는 대로 결정할 수 있다는 주장은 하지 않는다.

## 연구 확인과 적용 범위

2026-10-21 [Patterning: The Dual of Interpretability의 공식 발표 페이지](https://proceedings.mlr.press/v306/wang26fw.html)와 [저자 원고 v1 본문 §4, §4.5](https://arxiv.org/html/2601.13548v1#S4)를 확인했다. 최종판 PDF는 웹 도구가 형식을 지원하지 않아 본문 세부 사항은 버전을 명시한 저자 원고로 확인했다.

- §4는 두 규칙이 일치하는 입력으로 훈련 분포를 구성하고, 제외했던 입력에서 일반화가 갈리는 설정을 설명한다.
- §4.5는 같은 기준 분포로 재학습한 모델 집단이 두 규칙에 대응하는 분포를 보이고, 데이터 구성 변경으로 그 비율이 달라지는 결과를 보고한다. 대본은 이 정성적 결과만 소개한다.
- '같은 훈련 분포'를 '모든 실행에서 동일한 개별 데이터·초기값·순서'로 바꾸어 말하지 않는다. 연구에서는 seed와 데이터 셔플을 달리한다.
- 모델 구조·정규화·초기화에 관한 선행 결과는 본문 §4에서 Li et al. (2025)을 인용해 소개한다. 본편은 개별 요인의 효과 크기나 특정 방향을 주장하지 않는다. 최적화 과정의 영향은 가중치 학습 과정에 대한 일반 설명이며 이 실험이 모든 요인을 분리 검증했다는 뜻이 아니다.
- 논문에 수록된 재학습은 데이터 유형의 구성을 바꾼 실험이다. 개별 모델마다 원하는 알고리즘을 확실하게 지정했다는 뜻이 아니다. 이번 영상은 연구를 소개하며 실제 신경망 실험을 새로 수행하지 않는다.

## 발음 원고

화면·대본의 숫자는 원 표기를 유지하고, TTS에는 `1 → 일`, `0 → 영`, `-1 → 마이너스 일`, `2개 → 두 개`, `Patterning → 패터닝`으로 읽을 말을 둔다. 12개 주요 화면 단위에 대응하는 12문단을 빈 줄 하나로 나누며 제목·장면 번호·시각을 넣지 않는다.

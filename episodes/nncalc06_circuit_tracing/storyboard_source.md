영상 제목: 신경망이 답을 만드는 계산 경로를 추적하는 방법 — Circuit Tracing

이번 편의 중심은 특징을 발견하는 것과, 그 특징들이 실제로 어떤 계산을 수행하는지 알아내는 것은 다르다는 사실이야.

5편의 마지막 장면에서 특징 노드들이 남아 있었다면, 6편에서는 그 노드 사이에 어떤 연결을 그릴 수 있는지 살펴보는 방식으로 자연스럽게 이어갈 수 있어. 별도의 전환 영상이나 이전 편 요약은 필요하지 않아.

실제 논문에서 사용한 Dallas → Texas → Austin 사례를 중심으로 시각화하고, CLT와 Attribution Graph를 단순한 네트워크 그림이 아니라 계산을 추적하기 위한 분석 도구로 표현하겠어. 연구진은 그래프로 세운 가설을 별도 개입 실험으로 검증했으며, 그래프 자체가 원 모델의 완전한 작동 원리를 의미하지는 않는다고 설명해.&#x20;

## 1. 영상 전체의 시각적 구조

영상 전반에 사용할 핵심 시각화

그래프는 영상 이해를 위한 단순화 도식이며, 원 논문의 실제 노드·연결·기여도를 그대로 재현한 것은 아니다.

색상 규칙은 영상 끝까지 유지하는 게 좋아.

| 요소                | 색상  | 의미                 |
| ----------------- | --- | ------------------ |
| 원래 Transformer    | 회색  | 실제로 분석하려는 모델       |
| CLT 희소 특징         | 청록색 | 해석 가능한 특징 후보       |
| Attribution Graph | 보라색 | 출력에 대한 기여 관계       |
| 검증할 계산 경로         | 노란색 | 아직 검증 중인 가설        |
| 개입                | 주황색 | 원 모델의 활성화를 변경하는 실험 |
| 근사 오차·불확실성        | 붉은색 | 원본과 대체 모델의 차이      |

전체 영상에서 세 공간을 시각적으로 구별해야 해.

Original Model → Replacement Model → Attribution Graph

그리고 마지막에는 Attribution Graph → Original Model의 개입 검증으로 되돌아오는 구성이야.

### 장면 12 · SAE와 Transcoder의 차이

0:53–1:02

발화: “희소 오토인코더가 내부 활성화를 복원하도록 학습했다면, 트랜스코더는 특정 연산의 입력을 받아 그 연산의 출력을 근사하도록 학습합니다.”

SAE와 Transcoder의 학습 목표

Sparse Autoencoder

\\(h\rightarrow z\rightarrow\hat h\\)

활성화 자체를 복원

Transcoder

\\(x\rightarrow z\rightarrow\widehat{f(x)}\\)

특정 연산의 출력을 근사

애니메이션

1. SAE 화면에서 `h`가 입력되고 다시 `h`로 복원된다.
2. Transcoder 화면으로 변하면서 입력은 `x`, 원래 MLP의 목표 출력은 `f(x)`가 된다.
3. Transcoder가 `f(x)`에 가까운 출력을 생성한다.
4. 원래 MLP와 Transcoder의 출력값을 나란히 비교한다.

중요: 이 장면에서 SAE와 Transcoder를 서로 완전히 다른 종류의 모델로 묘사하지 않는 편이 좋아. 둘 다 희소 특징을 활용할 수 있지만, 학습 목표와 계산 분석에서의 역할이 다르다는 것을 보여주는 거야.

Attribution Graph의 구성

실제 Attribution Graph는 특징뿐 아니라 입력 임베딩, 복원 오차, 출력 노드 등도 포함할 수 있다.

4. 노드 사이의 기여 연결을 그린다.
5. 출력 노드까지 화살표가 이어진다.

### 장면 19 · 특징 간 기여의 크기

1:28–1:33

발화: “분석용 모델에서 한 특징의 활성화가 다른 특징의 계산에 얼마나 기여하는지를 나타냅니다.”

- F1에서 F2로 향하는 화살표를 확대한다.

# 수학적 발견 03 제작 기준

- 목표: 제타 함수의 비자명 영점쌍이 실제 진동항에 대응하고, 이 항들이 소수 거듭제곱 가중 계단의 오차를 설명한다는 발견.
- 95초, 9:16, 1080×1920, 30fps, 무음 마스터. 대본의 TTS 실측 길이는 아직 없으며 추후 사용자 타이밍에 맞출 수 있다.
- 구성: π(x) 회수 → 간단한 가중 계단 소개 → 같은 축에서 추세 제거 → 실제 오차 → 진동 1/5/30개 합성 → 영점의 정체 공개 → 점 선택과 진동 대응 → 명시적 공식의 구조 → 리만 가설.
- 그림은 임의의 사인파가 아니다. data.py에 기록한 Odlyzko의 첫 30개 양의 허수부와 각각의 켤레 영점을 사용한다. 이 알려진 영점들의 실수부는 1/2이다. 전체 영점에리만 가설을 가정한 그림이 아니다.
- ψ(x)는 소수 거듭제곱에서만 ln p만큼 점프한다. p가 아니라 p^k의 로그를 더하지 않으며, 6처럼 서로 다른 소수의 곱에서는 점프하지 않는다.
- 정확한 공식: ψ₀(x)=x−Σρ x^ρ/ρ−ln(2π)−½ln(1−x⁻²), x>1. 영점 합은 허수부 높이에 대해 대칭으로 절단한 극한이며, 임의 순서의 절대 수렴 합으로 설명하지 않는다.
- 정확한 명시적 공식의 대상 ψ₀는 점프의 중간값을 사용한다. 화면의 실제 데이터는 일반적인 우연속 계단 ψ이다. 중간값 규칙은 구현·해석의 기준으로 유지하고 화면 설명은 생략한다.
- 쌍 진동: −2Re(x^ρ/ρ)=−2x^β/|ρ| cos(γln x−arg ρ). 허수부는 로그 좌표의 각주파수이며, 진폭에는 분모 |ρ|도 들어간다.
- 합성 화면에서는 선형 x축 2~100과 고정된 오차 축을 사용한다. 단일 진동 설명 화면의 가로축만 ln x이며 이를 화면에 표시한다.
- 1/5/30쌍 근사에는 상수와 자명한 영점에 해당하는 보정항을 모두 포함한다. 유한 절단은 불연속 계단을 완전히 복원하지 못한다. 항 추가가 모든 점의 오차를 단조 감소시킨다고 주장하지 않는다.
- 리만 가설은 미해결 명제로 소개한다. 조건부 오차 상한 O(√x ln²x)는 점별 실제 오차 그래프나 고정된 수치 상한선이 아니라 점근적 성장 제약이다.
- 정확한 영점 계산법, 명시적 공식의 복소적분 증명, 오차 상한 증명은 이 편에서 다루지 않는다. 로그 미분식과 복소수 거듭제곱 전개는 화면과 내레이션에서 제외한다.
- 내레이션은 화면 전환마다 빈 줄로 나눈다. captions.srt는 사용자 제공 TTS 종료 시각에 따른 내레이션 자막이며, screen_captions.srt는 화면 요약 문구의 자막이다.

## 출처 (2026-10-13 확인)

- NIST DLMF §25.16, ψ의 정의·소수정리와의 관계·리만 가설의 오차 제약: https://dlmf.nist.gov/25.16
- Wolfram MathWorld, 완전한 ψ₀ 명시적 공식: https://mathworld.wolfram.com/ExplicitFormula.html
- Odlyzko, 첫 30개 양의 영점 허수부: https://www-users.cse.umn.edu/~odlyzko/zeta_tables/zeros1

## 발견 중심 재구성

- 제목은 「소수의 불규칙성을 설명하는 보이지 않는 파동」으로 변경한다.
- 시청자가 기억할 주장은 하나: 불규칙해 보이는 소수 분포의 흔들림이 복소평면에 놓인 제타 영점의 위치와 연결된다.
- 파동을 먼저 합성한 뒤 출처를 공개한다. 전체 수식, 로그 가중치의 유도, 켤레쌍 유도, 중간값 규칙은 설명하지 않는다. 해당 계산 규칙은 data.py에 유지한다.
- 장면 A: ψ(x)−αx, 0≤α≤1을 각 계단 꼭짓점에서 계산한다. 차이를 꺼내는 동안 좌표 축척을 유지한다. 이후 세로축을 확대할 때는 화면에 표시한다.
- 장면 B: 알려진 영점 하나를 선택하면 그 영점과 켤레에서 계산한 진동을 오른쪽에 표시한다. 두 번째 점을 선택하면 오른쪽 성분을 교체하고 아래의 부분합에는 두 번째 성분을 더한다. 이후 아래를 30쌍 근사로 갱신한다.
- 파동 공개 이전의 ‘진동 1/5/30개’는 실수 진동항 Wρ의 개수다. 각각은 켤레 영점 한 쌍에 해당한다. 진동의 합에는 고정 보정항이 포함됨을 화면에 표시한다.
- 영점 데이터와 그래프 축은 기존 수치 구현을 유지한다. 실제 ψ 오차에만 진동을 겹치며 π 오차에 직접 적용하지 않는다.
- 마지막에는 수치적 big-O 수식 대신 영점의 위치가 오차의 성장 범위를 제약한다는 의미를 전달한다.

## 사용자 제공 TTS 종료 시각 적용

- 19개 문단의 종료 시각: 8, 16, 19, 21, 26, 31, 33, 37, 44, 47, 49, 52, 56, 62, 70, 75, 82, 89, 95초.
- timing.json에 내레이션 원문과 시작·종료를 기록한다. 전체 길이는 95초. 19~21초에 직선 제거, 33~37초에 진동 추가, 47초에 영점 공개, 75초에 리만 가설 장면으로 전환한다.
- captions.srt는 위 내레이션 19개 문단의 타이밍, screen_captions.srt는 화면 요약 문구의 타이밍이다.
- 문장 ‘분포5에서’는 ‘분포에서’로 정리한다. 오디오 파일은 제공되지 않았으므로 무음 마스터로 렌더한다.

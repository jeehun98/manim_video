# 신경망의 수학 09 제작 기준

## 제목과 역할

- 제목: **Loss가 같다면 어떤 해가 더 좋을까? — Beyond the Loss Value**
- 8화의 여러 zero-training-loss 해에서 출발한다. 같은 점수라면 주변을 보자는 자연스러운 해결책을 실험하고, 6화의 좌표 의존성 때문에 단순한 flatness 비교가 충분하지 않음을 발견한다.
- 판단 질문을 `현재 Loss` → `지정한 파라미터 변화에 대한 Loss` → `같은 변화가 실제 함수에 미치는 영향` → `입력 변화에 대한 동작`으로 확장한다.
- 결론: **어떤 해에 도달할 수 있는가**와 **그중 어떤 해를 좋다고 평가할 것인가**는 별개의 문제다.

## 정확성 기준

- 화면의 동률은 **Training Loss**에 한정한다. Test 성능, 분포 밖 입력에 대한 동작, 명시적 regularization을 포함한 다른 목적함수까지 같다고 뜻하지 않는다.
- 파라미터 perturbation의 크기와 분포를 고정할 때만 국소 안정성 비교가 의미 있다. 유클리드 flatness는 재파라미터화에 따라 바뀔 수 있다.
- `fθ=fθ′`를 보여주는 재척도화 예시는 6화의 두 스칼라 곱셈 모델 `f(x)=w₁w₂x`다. `(w₁,w₂)→(cw₁,w₂/c)`는 `c≠0`에서 동일 함수를 유지한다. 일반 신경망 전체에 적용되는 보편 대칭으로 주장하지 않는다.
- 같은 크기의 `δθ`가 다른 크기의 함수 변화를 만들 수 있다. 구체적인 비교에는 어떤 입력 `x` 또는 입력 분포에서 출력 차이를 측정하는지 정의해야 한다.
- 입력 변화 `x→x+ε`에 대한 안정성은 파라미터 변화에 대한 안정성과 별도다. 어떤 입력 변화가 의미 있는지도 문제에 따라 정해야 한다.
- 주변 안정성, 함수 변화, 미지 데이터 성능은 서로 관련될 수 있지만 하나가 다른 하나를 자동으로 보장하지 않는다. 실제 해 평가에는 검증 데이터 등 목적에 맞는 근거가 필요하다.
- 마지막 100M→20M 압축은 조건부 개념 예시다. 모든 큰 모델이 그렇게 줄고 정확히 동일한 함수를 유지한다고 말하지 않는다.

## 제작 형식

- 기존 nnmath 색·한글 폰트·9×16 화면·상단 시리즈 표시·하단 자막을 따른다.
- 16장면 93초, 구간당 5–7초. 8화의 실제 TTS 94초와 대본 분량을 기준으로 이번 발화를 약 87초로 추정해 6초 여유를 둔다. 이번 편 TTS 실측은 아직 없어 구간 경계는 추정치다.
- 360×640 미리보기, 1080×1920 30fps 무음 최종본. TTS와 SRT는 별도 자료다.

# 정보이론 06 — 틀린 확률과 현실의 청구서

- 제목: 틀린 확률을 믿으면 왜 더 많은 비트를 쓰게 될까? 원안18장면을 12발화 구간으로 압축. 새로운 관점: 현실 p는 지출 빈도, 모형 q는 가격표. 동일 현실의 평균 청구서가 틀린 가격표 때문에 비싸진다.
- p=(.7,.1,.1,.1), q=(.1,.3,.3,.3), A/B/C/D 순. p는 실제 데이터 생성 분포, q는 예측 확률 모형. q를 개인의 감정/확신 정도와 동일시하지 않는다.
- 5편의 실제 정수 prefix code 비용에서 이번 편은 이상적 log-cost −log₂q(x)로 옮긴다. 구분을 화면과 나레이션에 명시. q에서 A의 가격≈3.322, 다른 각 기호≈1.737 bits. A의 p 기준 가격≈0.515. 모두 실수 비용이며 A의 실제 1기호 코드가 3.322개 물리적 비트라고 표현하지 않는다.
- 이 원안 q에서 최적 1기호 Huffman 코드가 모두 2비트일 수 있다. 따라서 q를 따른 최적 실제 코드에서 A만 더 길어진다고 꾸미지 않는다. 블록 부호화 등의 이상적 부호 비용 해석으로 설명한다. 정수 길이·헤더·모형 비용이 있는 유한 실제 파일 길이를 CE와 정확히 동일시하지 않는다.
- 데이터는 5편과 같은 20기호 AAABAAACAAADAAABACAD. A14, B/C/D 각2회로 실제 p와 정확히 일치하도록 구성한 예시. 무작위 표본 수렴 실험이 아니다. q가격으로 A비용≈46.506993, 총≈56.928787 bits, 기호당≈2.846439. 영수증 숫자는 반올림해 표시.
- Cross Entropy H(p,q)=−Σp log₂q=Eₚ[−log₂q(X)]. p는 평균 가중치, q는 log 내부의 비용. H(p)=1.356780, H(p,q)=2.846439, 추가=1.489660 bits/기호.
- q=p이면 H(p,q)=H(p). 실제 p를 고정할 때 H(p,q)≥H(p); CE 자체가 추가분만을 뜻하지 않는다. 서로 다른 p의 CE 높낮이만으로 모델 일치도를 단정하지 않는다.
- 비용 변화는 q_t=(1−t)p+tq의 특정 혼합 경로만 사용. t=0,.3,.65,1에서 실제 계산해 단조 증가를 확인. 임의의 거리에서 “멀수록 CE가 커짐”이 성립한다고 주장하지 않는다. 영상은 반대로 q에서 p로 돌아가며 비용 감소를 보여준다.
- 분류 연결은 단일 관측의 정답 one-hot pᵧ=(1,0,0)이다. 전체 실제 데이터 생성 분포가 항상 one-hot이라고 설명하지 않는다. q=(.7,.2,.1)이면 비용−log₂q(cat). q(cat)=.99와 .01의 비용은 각각 약0.0145와6.6439 bits. 한 번의 관측에서 비용이 큰 것이 심리적 믿음 수정량이나 실제 추가 코드 길이와 같은 뜻은 아니다.
- 이 편은 base2라 bits. 일반 ML 라이브러리의 자연로그 CE는 nats이며 상수 배율 차이. 다음 편 KL은 총비용에서 본래 엔트로피를 뺀 추가분으로 연결한다. 이번 편에서 그 이름은 미리 공개하지 않는다.
- p(x)>0인데 q(x)=0이면 무한비용. p(x)=0인 항은0으로 제외한다. 이번 화면 예시는 모두 적절히 정규화된 양의 q와 분류 one-hot을 사용한다.
- 분포 막대는 실제비율, 비용 막대는 동일척도 1bit당1.8프레임단위. 분류 비교는 두 행 모두 1bit당0.95단위. 작은 비용에 임의 최소폭을 주지 않는다.
- 길이 58.63초. 비공백 TTS 글자/초당7자, 문장 휴지0.18초, 마지막0.5초. 30fps 프레임 경계. 전환/등장은 구간 안에 포함. 실제 음성 없는 추정 타이밍.
- 1080×1920 30fps 무음. TTS/SRT 별도. 공통 Malgun Gothic과 색상. 하단 문구·외부 SRT 안전영역 확보.
- 참고: https://www.deeplearningbook.org/contents/prob.html §3.13 (H(p,q)=H(p)+KL, −Eₚlogq, 고정p에서 최소화 의미).

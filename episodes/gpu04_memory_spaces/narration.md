## 00:00:00.000–00:00:07.000 / 7초 / recap

## 00:00:14.000–00:00:20.000 / 6초 / global_intro

## 00:00:20.000–00:00:25.000 / 5초 / global_users

하지만 계산할 때마다 값을 다시 가져오면,

## 00:00:31.000–00:00:37.000 / 6초 / register_intro

그중 하나가 Register입니다.

## 00:00:37.000–00:00:43.000 / 6초 / register_private

## 00:00:43.000–00:00:49.000 / 6초 / load_register

값 3을 읽어 Register에 가져왔다고 해보겠습니다.

## 00:00:49.000–00:00:55.000 / 6초 / compute_one

읽어온 값에 1을 더하면 4가 됩니다.
계산 중인 값은 Register에 있습니다.

## 00:00:55.000–00:01:01.000 / 6초 / compute_two

처음 값을 다시 읽지 않고, 계산을 이어갑니다.

## 00:01:01.000–00:01:07.000 / 6초 / private_scope

Register는 기본적으로 그 Thread 자신의 공간입니다.
다른 Thread와 데이터를 공유하기 위한 공간은 아닙니다.

## 00:01:07.000–00:01:13.000 / 6초 / shared_question

그렇다면 같은 Block 안의 여러 Thread가
같은 데이터를 반복해서 사용한다면 어떨까요?

## 00:01:13.000–00:01:19.000 / 6초 / shared_intro

같은 Block 안의 Thread들이 함께 쓰는 공간입니다.

## 00:01:19.000–00:01:25.000 / 6초 / shared_repeat

여기서는 여러 Thread가 같은 값을 재사용합니다.
매번 Global Memory에서 읽을 수도 있지만,

## 00:01:25.000–00:01:31.000 / 6초 / stage_shared

## 00:01:31.000–00:01:37.000 / 6초 / ready

함께 쓰기 전에 데이터 준비가 끝났는지 맞춥니다.

## 00:01:37.000–00:01:43.000 / 6초 / reuse_one

## 00:01:43.000–00:01:49.000 / 6초 / reuse_again

같은 데이터를 다시 사용할 때도,

## 00:01:49.000–00:01:55.000 / 6초 / reuse_message

## 00:01:55.000–00:02:01.000 / 6초 / shared_limit

## 00:02:13.000–00:02:18.000 / 5초 / tradeoff

## 00:02:24.000–00:02:30.000 / 6초 / summary_global

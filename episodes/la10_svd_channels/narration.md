|---|---|

| 00:05–00:11 | 이번에는 행렬 안의 관계를<br>여러 개의 단순한 채널로 나누어 보겠습니다. |
| 00:11–00:17 | 복잡하게 겹쳐 있던 관계를<br>하나씩 분리해서 보는 겁니다. |

| 00:56–01:03 | 이런 채널들을 모두 더하면,<br>원래 행렬이 정확히 만들어집니다. |
| 01:03–01:09 | 하나의 복잡한 관계는, 여러 단순한 관계가<br>겹쳐 작용한 결과로 볼 수 있습니다. |
| 01:09–01:15 | 이 분해를 SVD,<br>특잇값 분해라고 합니다. |
| 01:15–01:22 | σᵢ는 특잇값입니다. 큰 값부터 정리하면,<br>강한 채널과 약한 채널이 드러납니다. |
| 01:22–01:30 | 다만 실제 기여는, 그 입력에<br>해당 패턴이 얼마나 들어 있는지에도 달려 있습니다. |
| 01:30–01:37 | 약한 채널을 빼면 더 단순해지지만,<br>그때부터는 원래 행렬의 근사가 됩니다. |
| 01:37–01:49 | SVD는 행렬 속 관계를,<br>입력 패턴과 전달 강도, 출력 패턴으로 나누어 보여줍니다. |

# 선형대수학 10 — SVD 채널

109초 · 세로 1080p · 30fps · 무음.

## 핵심

실수 행렬의 SVD를 A = Σᵢ σᵢuᵢvᵢᵀ인 Rank 1 채널들의 합으로 소개한다. 각 채널은 입력 x의 성분 vᵢᵀx를 읽고 σᵢ배 하여 uᵢ 방향으로 내보낸다. 단순히 vᵢ를 uᵢ로 치환하는 연산이 아니다.

입력 패턴끼리와 출력 패턴끼리는 각각 정규직교한다. σᵢ는 음수가 아니며 내림차순 정렬한다. 같은 크기의 입력 패턴에 대한 증폭률을 비교할 수 있지만 실제 기여 크기는 σᵢ|vᵢᵀx|다. 입력의 해당 성분이 0이면 출력 기여도 0이다.

## 수치 사례

s=1/√2
U=[[s,-s,0],[s,s,0],[0,0,1]]
V=[[1,0,0],[0,s,-s],[0,s,s]]
σ=(3,1.5,0.4)
A=U diag(σ) Vᵀ.

카드의 작은 막대는 실제 vᵢ와 uᵢ의 성분을 같은 척도로 나타낸다. 기준선 위/아래가 양수/음수다. 행렬 히트맵은 파랑 양수, 분홍 음수이며 밝기는 절댓값에 대응한다. 연결망은 이 A의 0이 아닌 성분을 그린 것이다.

## 시각적 구성

행렬과 연결망 → 겹친 반투명 채널을 세 레이어로 펼침 → 단일 채널 → 성분 읽기, 배율, 출력 → Rank 1 수식 → 정규직교 조건 → 강도 비교 → 전체 채널 합 → 다시 겹침 → SVD 표기 → 특잇값 → 실제 입력 의존성 → 약한 채널 제거 → 마무리.

겹침은 합을 설명하는 도식이다. 반투명 색의 광학적 합성이 행렬 원소의 정확한 수치 합을 뜻하지 않는다. σᵢ>0인 각 채널의 Rank는 1이며 0이 아닌 채널 수는 Rank(A)다. 모든 채널의 합은 정확한 행렬이고, 0이 아닌 채널을 버리면 근사가 된다. 이번 예제의 마지막 채널 제거 오차의 Frobenius norm과 spectral norm은 모두 0.4다.

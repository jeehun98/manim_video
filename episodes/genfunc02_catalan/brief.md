# 카탈란 수와 생성함수 — 제작 기준

- 확정 대본과 문장 종료 시각: 171초. 9:16, 1080×1920, 30fps, TTS 미제공으로 무음.
- 순서 있는 이진 트리: 왼쪽과 오른쪽 구분, 자식은 0–2개. 빈 트리는 1가지. 모든 노드 수 n 기준.
- C_n=1/(n+1) binom(2n,n). n=0..6: 1,1,2,5,14,42,132.
- 노란 루트는 x, 청록 왼쪽은 C(x), 빨강 오른쪽은 C(x), 초록 계수는 구조의 개수.
- 실제 트리 분해 → 추상화 → 1+xC(x)² → C에 대한 이차방정식 → 상수항으로 해 선택 → 계수 추출.
- C_-(x)는 x=0에서 원래 분수에 직접 대입하지 않고 유리화한 2/(1+sqrt(1-4x))의 연속 확장으로 값 1 확인.
- 실수 그래프는 0<x≤1/4. C_+(x)는 x→0+에서 발산. 형식적 멱급수의 상수항 조건과 구분.
- 이항전개에서 k−1=n → k=n+1을 보이고 일반항으로 정리. C10=16,796, C20=6,564,120,420.
- 8개 씬 독립 렌더. 기존 자막·타이밍·렌더 구성과 색상 재사용. 본문과 하단 자막 분리.
- 내레이션 문장과 종료 시각은 수정하지 않음. 자막에 한글 발음 대신 수식 기호 사용.

# 정보이론 07 — 같은 데이터, 187비트 차이

- 수정 목적: 추상적인 청구서 설명 대신 동일한 원본을 두 확률표로 실제 인코딩·복원한 장면에서 시작한다. 총 길이 59.30초, 11구간. 단어 가격/비용의 반복을 줄이고 데이터열과 비트열을 중심으로 설명한다.
- 실제 생성 분포 P=(0.75,0.25), 모델의 가정 Q=(0.5,0.5). 믿음은 심리적 개념이고 Q는 이 가정을 수치화한 확률모델이다. P는 예시의 데이터 생성 확률이며 관측 표본의 빈도와 구별한다.
- 시연 표본은 앞 8기호 AABAAABA에 Random(7)로 섞은 A744/B248을 붙여 A750/B250, 총 1000개로 구성한다. 빈도가 P와 정확히 맞도록 만든 예시이며 임의의 1000개 표본이 언제나 이 빈도라는 뜻은 아니다. 양쪽은 같은 원본이며 순서까지 완전히 동일하다.
- 두 기호의 개별 이진 prefix code는 모두 길이1이므로 A의 개별 코드가 0.415비트라고 주장하지 않는다. 데이터열 전체에 정확한 정수 구간 기반 산술 부호화를 적용한다. P는 가중치(3,1), Q는(1,1). 최종 구간 안에 완전히 포함된 가장 짧은 dyadic cell을 찾고, 그 중점으로 정확 유리수 복호화한다.
- 실제 유효 본문 길이 P813/Q1000비트, 차이187비트. 모형과 기호 수는 송수신자가 공유하고 헤더/패딩은 제외한다. ASCII .bits.txt 파일은 비트열의 기록이지 디스크 파일 크기가 아니다. 전체 문자열 roundtrip 검증 결과는 encoding_report.json에 보관한다. 특정 인코더·표본의 결과이며 모든 압축기의 최적 길이라고 일반화하지 않는다.
- 이상적 길이는 -log₂ P(message)=811.278124459비트, -log₂ Q(message)=1000비트. 이상적 차이188.721875541비트. P의 유한 코드 종료 오버헤드1.721875541비트 때문에 실제 차이187과 다르다. 화면에서 실제 본문 길이와 이상적 길이를 분리한다.
- H(P)=0.811278124459, H(P,Q)=1, KL(P‖Q)=0.188721875541 bits/기호. 1000개에 대한 기대 이상적 추가 길이 약188.7비트. 내레이션에서는 약189비트로 반올림한다. 사건별 이상적 차이 A=+0.584962501, B=-1. 실제 빈도 가중합750×log₂(1.5)−250=188.721875541.
- KL은 정규화된 분포에서 항상0 이상. 개별 사건의 부호화 surprisal 차이는 음수 가능. 유한 임의 표본의 실제 코드 길이 차이가 항상 양수라는 주장은 하지 않는다. P>0,Q=0이면 KL 무한대, P=0의 항은0으로 취급한다. 이 영상의 양쪽 확률은 모두 양수이다.
- 역방향 KL(Q‖P)=0.207518749639. 데이터를 만드는 쪽이 Q가 되므로 평균 가중치도50:50으로 달라진다. 비대칭 부등호는 이 예시의 값이며 모든 서로 다른 쌍이 반드시 비대칭인 것은 아니다.
- Q=P이면 KL0이지만 H(P)는 남는다. 추가 맥락 없이 해당 분포를 표현하는 설정의 정보량이며 모든 가능한 압축/맥락 아래 불변이라는 뜻은 아니다. 고정P에서 Cross Entropy를 줄이는 것은 KL을 줄이는 것과 동치다.
- 구간 타이밍: 발음 대본 비공백 글자당1/7초, 문장휴지0.18초, 마지막0.5초. 30fps에 맞춰 반올림. 각 구간의 전환과 비트열 등장도 이 시간 안에 포함한다. 실제 TTS 오디오는 아직 없으므로 발화 시간은 추정이다.

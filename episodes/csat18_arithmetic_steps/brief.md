# EP.18 제작 기준

사용자 제공 43개 문장 종료 시각 준수. 191초, 1920×1080, 30fps, 16:9. 음원 미제공으로 무음·화면 자막.

조건 a₆=5,a₅=a₂−6. a₅−a₂=(5−2)d=3d=−6→d=−2. a₆=a₁+5d=a₁−10=5→a₁=15. 실제항15,13,11,9,7,5. 일반항aₙ=a₁+(n−1)d=17−2n. 좌표(n,aₙ)는 자연수 n에서 이산점, 직선은 규칙을 보여주는 보조선. 가로1,세로−2 또는 가로3,세로−6의 기울기와 공차 연결. 일반적으로 d=0도 가능하므로 일차식 설명에서 d≠0을 보조 표시.

89–94초 원문 발음의 십이 작습니다를 12로 오인하지 않게 자막은 10만큼 작습니다로 표시. 역방향은 +2, 정방향은 −2. 항6개 사이의 간격5개, 항2..5는4항 사이3간격을 시각적으로 구별. 주관식 정답15. 29개 독립 교체 가능 씬. 이전 편 복습·다음 예고 없음.

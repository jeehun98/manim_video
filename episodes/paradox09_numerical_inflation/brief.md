# 신경망의 역설 09 — 신경망을 무너뜨린 것은 단 하나의 반올림이었다?

## 제작 기준

사용자 대본 34구간, 종료 시각 5–173초를 그대로 사용한다. 첨부 시각 콘티를 기준으로 9개 시각 모티프를 반복한다. 1080×1920, 30fps, 무음; 음성 원고와 SRT 별도. 이전 편 복습과 다음 편 예고 없음.

학습 목표: Softmax의 공통 이동 대칭성 → 기울기 합 0 → 유한 정밀도의 상쇄 실패 → 분류기/특징 평균의 피드백 → 특정 조건의 Slingshot 손실 급등.

## 원문과 조건

Liu Hanqing, Jianjun Cao, Yuanze Li, Zijian Zhou (2026), Grokking or Glitching? How Low-Precision Drives Slingshot Loss Spikes, arXiv:2605.06152v4 (2026-10-07).
https://arxiv.org/html/2605.06152

- 정확한 실수 연산에서 p=softmax(z), one-hot y, g=p−y이면 Σg=0. z+c·1은 같은 확률을 나타낸다. 이 순수 데이터 손실의 로짓 기울기 성질과 정규화·옵티마이저까지 포함한 실제 파라미터 갱신을 구분한다. 모든 옵티마이저가 정확 연산에서 분류기 평균을 보존한다고 일반화하지 않는다.
- 실제 CE 구현에서는 log-sum-exp 등의 흡수 오차가 정답 기울기를 0으로 만들면서 오답 성분을 남길 수 있다. 화면의 float32 예시 z=(20,0,0)는 NumPy의 안정화 softmax 경로로 직접 계산하며 모든 프레임워크의 동일 결과를 주장하지 않는다. 1 근처의 반올림과 작은 양수의 표현 가능성은 서로 다르다. 표시된 g의 합은 반올림된 출력의 합이 아니라 계산된 성분의 잔여를 뜻한다.
- 공통 로짓 이동의 3차원 방향 u=(1,1,1)/√3와 직교한 분류 방향 v=(-2,1,1)/√6를 2차원 정사영하여 표현한다. g_parallel=(Σg)/√3. 빨간 화살표는 기울기 성분이며 경사하강 갱신은 반대 방향임을 명시한다. 그림의 작은 잔여는 가시성을 위해 확대한다.
- 마지막 분류층 z=Wh에서 W의 클래스 행 평균과 h의 데이터 평균은 특징 공간에 속한다. 로짓 공간의 (1,1,1)이 그대로 특징 공간의 평균 벡터가 되는 식으로 연결하지 않는다.
- 원논문 §3의 피드백 유도는 CE, SC, 근사 Neural Collapse, 균형 배치와 기하학적 조건을 사용한다. ReLU 네트워크에서 잔여 질량 ε 변화가 느린 등의 조건 아래 반평행 정렬과 지수 성장을 분석한다. 영상의 두 평균 벡터와 성장 곡선은 이러한 동역학의 설명용 개념도이며 실험 측정값이 아니다.
- NFI 자체가 손실 급등과 동의어가 아니다. 일부 표본의 margin이 흡수 조건을 벗어남 → 정답 기울기 재등장 → Adam의 모멘트가 즉시 대응하지 못하는 큰 갱신 → 손실 급등을 분리한다. 모든 급등이나 모든 아키텍처에 적용되는 보편 원인으로 제시하지 않는다.
- 제목과 마지막 문장의 ‘단 하나’는 비유적 질문이다. 문자 그대로 한 번의 반올림 사건만으로 붕괴가 보장된다는 주장이 아니다. 반복되는 수치적 잔여와 학습 피드백이 핵심이다.

## 화면 구성과 시간

0–16: 설명용 손실 곡선과 급등, 반올림 원인의 질문.
16–43: 고정 기준선의 로짓 막대 높이를 같은 양만큼 증가시켜도 확률 막대는 고정. 세 확률의 합 1과 같은 손실.
43–56: 정답 음수/오답 양수의 정확한 상쇄.
56–83: 고확신 확률의 float32 반올림, 정답 음수 화살표 소실, 양수 잔여.
83–100: 로짓 공간 정사영, 공통 방향 기울기 성분 0과 비영 값의 대비.
100–117: h→W→z 순전파와 역전파, 평균 벡터를 별도 특징 공간에 제시.
117–134: 두 평균이 번갈아 서로의 다음 변화를 키우는 루프, 단순 누적과 피드백 비교.
134–144: NFI 성장과 뒤늦은 손실 급등을 분리, 기울기 재등장과 큰 업데이트 사이 단계 표시.
144–173: 적용 범위와 대칭성/수치 동역학의 차이, 작은 오차를 증폭하는 학습 과정으로 결말.

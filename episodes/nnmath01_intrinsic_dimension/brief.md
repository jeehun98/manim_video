# 신경망의 수학 01 제작 기준

## 제목과 역할

- 제목: **왜 모델은 필요 이상으로 큰 학습 공간에서 움직일까?**
- 이 영상은 parameter space 입문이 아니라, parameter space를 이미 안다는 전제에서 이상한 실험을 바로 던지는 시리즈 오프닝이다.
- 논문 *Measuring the Intrinsic Dimension of Objective Landscapes*의 무작위 부분공간 학습 실험을 이용해 `모델의 크기란 무엇인가?`라는 질문을 연다.

## 학습 목표

- 파라미터 수 `D`와 학습 중 실제로 허용한 자유도 `d`를 구분한다.
- `θ = θ₀ + Pφ`에서 `P`와 `θ₀`는 고정하고 `φ`만 학습한다는 점을 보여준다.
- 작은 무작위 부분공간에서도 기준 성능에 가까워질 수 있다는 실험적 현상을 이해한다.
- 성능 기준에 도달하는 최소 부분공간 차원으로 intrinsic dimension을 측정한다는 아이디어를 소개한다.
- 이 결과가 좋은 해의 기하학, overparameterization, Hessian, mode connectivity, optimization geometry로 이어지는 질문임을 남긴다.

## 정확성 기준

- 모델의 전체 파라미터 수를 줄이거나 weight를 제거하는 pruning으로 묘사하지 않는다. 모델은 계속 `D`개의 파라미터로 표현되며, 학습 가능한 좌표만 `d`개다.
- `P`는 학습하지 않는 무작위 사영으로 표현한다. 학습 변수는 `φ ∈ ℝᵈ`다.
- intrinsic dimension은 절대적인 하나의 속성처럼 단정하지 않는다. 모델, 데이터, 최적화 방법, 기준 성능과 부분공간 구성에 의존하는 실험적 측정값이다.
- 작은 부분공간 학습이 좋은 해가 단순한 평면이나 넓은 고체 영역임을 증명한다고 말하지 않는다. 좋은 해가 고립된 한 점이라는 그림을 의심하게 하는 단서로만 사용한다.
- 화면의 성능 곡선과 `d = 10, 50, 100, 500, 1000`은 개념 설명용 도식이며 특정 실험 결과값으로 제시하지 않는다.

## 연출 기준

- 첫 16초 안에 `백만 개의 방향이 정말 모두 필요한가?`를 던진다.
- 거대한 공간은 다수의 희미한 축과 점 구름, 작은 부분공간은 기울어진 반투명 평면으로 추상화한다.
- `1,000,000 parameters → 1,000,000 parameters`와 `degrees of freedom: 1,000,000 → 500`을 같은 화면에 대비한다.
- 성능 곡선은 `d`가 증가할 때 기준선에 접근하는 형태만 보여주며 실제 논문 수치를 흉내 내지 않는다.
- 좋은 해는 점에서 곡선·리본·분산된 영역으로 변형하되 `possible geometry`라는 표기로 가설임을 유지한다.
- 마지막은 `Large Parameter Space ≠ Equally Large Intrinsic Dimension`과 다음 질문으로 닫는다.
- 112초, 1080×1920, 30fps, 무음 마스터. 미리보기는 360×640이다.

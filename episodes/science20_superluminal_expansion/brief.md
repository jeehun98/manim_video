# 제작 기준 — 빛보다 빠른 게 존재한다?

## 상태와 목표

- 대본·타이밍 확정 후 영상 제작 단계. 사용자 제공 15구간 종료 시각을 반영하여 scene.py, timing.json, captions.srt를 작성하고 science20을 렌더 ID로 등록한다.
- 사용자 요청: 첨부 1편 콘티를 바탕으로 영상 제작. 서두는 ‘빛보다 빠른 게 존재한다?’라는 호기심을 유발하는 질문으로 강화한다.
- 132초(2분 12초), 세로형 Manim 영상. 최종 목표 1080×1920 / 30fps / 3960프레임 / 무음. 음성 파일 자체는 전달되지 않았으며 종료 시각을 사용한다.
- 핵심 주장: FLRW 우주에서 팽창을 따라가는 두 지점의 같은 우주 시간에서 정의한 proper distance 증가율은 c를 넘을 수 있지만, 국소 관성계에서 물질·정보의 운동 속도 제한을 위반하지 않는다.
- 다른 편 복습·이후 편 예고 없이 첫 질문에 답하며 독립적으로 완결한다.

## 장면 구성

| 구간 | 화면의 주장과 변화 |
| --- | --- |
| 01 | ‘빛보다 빠른 게 존재한다?’ 질문 → 빛 c → 먼 은하 사이의 거리선 증가. 즉시 ‘거리 증가율’ 표기. |
| 02 | 고정 격자와 가까운 관측자 옆을 지나가는 은하. v_local < c. 물체가 정확히 c에 도달하는 속도계는 사용하지 않는다. |
| 03 | 격자에 고정된 A/B가 눈금을 가로지르지 않은 채 간격 증가. |
| 04 | ‘가상의 눈금’ 표시. 각 동일 길이 구간의 같은 시간, 같은 비율 팽창. 실제 고체 자는 그리지 않는다. |
| 05 | 한 칸 거리선과 작은 증가량 Δℓ 강조. |
| 06 | 열 칸을 동시에 늘리고 증가량만 옮겨 하나의 막대로 합친다. ΔD = ΣΔℓ. 속도 벡터 합성으로 표현하지 않는다. |
| 07 | 거리 1:2:5와 거리 증가율 1:2:5 비교. 동일한 시간 구간과 H를 유지한다. |
| 08 | 표준적인 팽창 우주에서 우주 팽창을 따라가는 두 지점임을 명시. D=aχ → Ḋ=H(t)D. χ가 일정한 공변 지점이라는 조건, H=ȧ/a. |
| 09 | 가로 D, 세로 Ḋ 그래프에서 HD 직선이 c 수평선을 통과. 교차점 D=c/H 표시. ‘가시성의 경계’나 ‘우주의 끝’으로 해석하지 않는다. |
| 10 | 각 은하 근처의 작은 관측 영역 세 개에서 진공 광자가 동일한 c로 진행. ‘국소적으로 직접 측정’을 강조하고, 원거리 동시 관측을 실제 통신으로 오인시키지 않는다. |
| 11 | 가까운 곳을 지나가는 물체 / 먼 두 지점의 거리 변화 카드를 병렬 비교. |
| 12 | 짧은 띠와 긴 띠가 모두 1% 증가. 전체도 1%이며 20구간의 1%를 20%로 합하지 않는다. 비율은 같고 절대 길이 증가량이 다름을 보여준다. |
| 13 | 동일 길이 선분의 방향이 조금씩 바뀌며 큰 원호 형성. 경로의 방향 변화 비유이며 공간의 내재 곡률 증명으로 제시하지 않는다. |
| 14 | 국소 v_light=c / 원거리 Ḋ>c를 함께 표시. ‘같은 측정이 아니다’. |
| 15 | 확장 격자에서 질문 회수. ‘빛보다 빠른 물체를 발견한 것은 아니다 / 빛보다 빠른 거리 증가율은 가능’. 같은 단위라도 다른 측정임을 강조한다. |

## 정확성·연출 조건

- ‘공간이 물질처럼 c보다 빠르게 날아간다’라는 표현을 피한다. 비교하는 양은 명시된 우주 시간 단면에서 정의한 거리의 시간 변화율이다.
- 팽창률 H는 속도 자체가 아니라 시간의 역수 차원을 가진다. 시간에 따라 달라질 수 있으며 비교 장면은 동일 순간 또는 짧은 시간 구간이다.
- 길이 증가량의 합산과 특수상대론적 속도 합성을 구별한다. 멀리 떨어진 물체의 상대속도는 비교 방식에 따라 정의가 달라진다.
- 진공에서 국소적으로 측정한 빛의 속도 c를 다룬다. 매질 속 빛, 좌표 속도와 혼합하지 않는다.
- 격자는 공변 좌표 표지이며 실재하는 지지대가 아니다. 실제 은하의 고유 운동은 이 도식에서 생략한다. 중력적으로 결합된 모든 물체가 허블 팽창을 그대로 따르는 것으로 그리지 않는다.
- 피드백을 반영하여 신경망 비유를 제거하고 15장면으로 구성한다. 곡선의 방향 변화 비유는 짧게 유지하고 곧바로 우주 팽창의 결론으로 돌아온다. 비유가 같은 물리 또는 동일한 정리라는 주장은 하지 않는다.
- 화면·내레이션 문서는 c, H, D, 1% 등 원래 표기를 유지한다. 발음 원고에서는 씨, 에이치, 디, 일 퍼센트로 풀어 쓴다.
- TTS 원고는 주요 화면 변화마다 빈 줄 하나로 나누고 제목·번호·시간을 제외한다.

# SVD: 네 가지 관점

기존 선형대수 10편의 SVD 소개에서 이어지는 독립적인 다섯 편입니다. 세로 1080×1920, 30fps, 한국어 화면 자막과 별도 SRT를 제공하며 음성·음악은 없습니다. 각 편은 단독으로도 이해하도록 시작합니다.

| ID | 관점 | 핵심 시각화 |
|---|---|---|
| svd01 | 최적의 망각 | 실제 행렬과 절단 SVD의 히트맵, 남기는 채널에 따른 오차 |
| svd02 | 차이의 생존율 | 기준 입력과 기준 출력에 대한 두 점의 상대 거리 |
| svd03 | 방향별 감도 지도 | 같은 척도의 단위원과 타원, 특이벡터 방향의 화살표 |
| svd04 | 독립적인 질문 | 부호 있는 입력 좌표, 배율, 출력 벡터의 합 |
| svd05 | 타원을 훑어 찾는 두 값 | 회전 입력 스캐너, 출력 길이 곡선, 최대·최소 경계 |
| svd06 | Condition Number | 납작해지는 타원, 방향별 오차, 서로 가까워지는 출력점 |
| svd07 | 역행렬과 오차 증폭 | 납작한 타원에서 복원, 출력의 0.01 오차가 입력에서 0.10으로 확대 |

## 수학·제작 기준

실수 행렬을 다루며 특이벡터의 길이는 1, 입력끼리와 출력끼리는 각각 직교합니다. 특잇값은 음수가 아니며 내림차순입니다. 각 예제는 해당 편의 설명을 위한 별도의 행렬입니다.

1편: 정규화된 4×4 Hadamard 행렬 H와 σ=(4,2,1,0.3)를 사용해 A=H diag(σ) Hᵀ를 구성합니다. 모든 히트맵은 같은 부호·밝기 척도입니다. 파랑은 양수, 분홍은 음수이며 밝기는 절댓값입니다. 표의 오차는 Frobenius norm의 제곱입니다. Rank k 이하 근사 전체에 대한 최적성은 Eckart–Young–Mirsky 정리입니다. spectral norm에서도 최적이지만 본 영상은 제곱합 오차에 집중합니다. 최적해의 유일성을 주장하지 않습니다. 작은 특잇값이 의미적으로 무가치하다는 뜻은 아닙니다.

2편: 각 σ 장면은 해당 특잇값을 갖는 상황을 비교합니다. σ가 달라지는 동안 동일한 고정 행렬이라고 주장하지 않습니다. 입력 패널은 x, 출력 패널은 Ax를 기준점으로 합니다. ε의 화면 길이는 0.65이고 출력 거리는 정확히 σ배입니다. σ=0.2와 σ=0을 구별합니다. 생존율은 확률이 아니며 1을 넘을 수 있습니다. 작은 특잇값이 양수이면 정확한 계산에서는 차이가 남습니다.

3편: A=R(0.45) diag(3,0.5) R(0.6)ᵀ. 두 패널에 같은 길이 척도를 씁니다. σ₁/σ₂=6. 원과 타원은 방향별 단위 변화의 끝점 자취입니다. 모든 입력 방향이 특이벡터인 것은 아니며 일반 방향은 그 조합으로 설명합니다.

4편: 직교 좌표계에서 x의 좌표 (2,−1,0.5), σ=(3,1.5,0.4). 출력의 u 좌표는 (6,−1.5,0.2)입니다. x에 v₁을 더하면 첫 좌표만 3으로 바뀝니다. 각 채널 도식은 벡터 합의 계산을 나타내며 막대의 물리적 이동을 뜻하지 않습니다. 독립적인 질문은 직교 방향을 의미하고 통계적 독립을 뜻하지 않습니다. 실제 기여 크기는 σᵢ|vᵢᵀx|입니다.

5편: A=R(0.28) diag(3,0.5). 단위 입력 방향 θ를 한 바퀴 스캔하며 타원 위 출력점과 길이 L(θ)=‖Ax(θ)‖를 동시에 추적합니다. 아래 곡선은 모든 방향별 반응이고, σ₁=3과 σ₂=0.5는 곡선이 닿는 위·아래 경계입니다. 중간 높이는 실제 반응이지만 각각을 특잇값이라고 부르지 않습니다.

6편: A(s)=diag(3,s), s:1→0.1. 같은 크기의 회전 입력 오차가 방향에 따라 서로 다른 출력 길이를 만드는 모습을 먼저 보여줍니다. 이후 σmin을 줄이면 타원, κ=3/s, 두 출력점 Ax₁=(3,sε), Ax₂=(3,−sε)의 간격이 함께 변합니다. condition number는 최대 절대 증폭이 아니라 방향별 보존 정도의 격차로 설명합니다.

7편: A=diag(3,0.1), y=(3,0), ỹ=(3,0.01). A⁻¹y=(1,0), A⁻¹ỹ=(1,0.1). Condition number 30과 이 방향의 역변환 오차 증폭 10배를 구별합니다. 점 주변 확대 창에서는 출력과 복원된 입력의 변위를 같은 척도로 보여줍니다.

## 재생성

각 에피소드의 `tts_script.txt`는 최신 자막의 내레이션을 한국어 발음으로 변환한 순수 낭독용 텍스트입니다. SVD는 “에스 브이 디”, vᵢ는 “브이 아이”, σᵢ는 “시그마 아이”, uᵢ는 “유 아이”로 읽고 숫자도 한글로 풀어 씁니다. 문단은 자막 구간에 대응하며 타임코드나 화면 전용 수식은 읽기용 파일에 넣지 않습니다. 같은 파일을 `exports/svd01_tts_script.txt` 등의 이름으로도 제공합니다. 음성 파일은 생성하지 않습니다.

3편 수정본은 100초입니다. “거의 변하지 않음” 대신 “변화가 작게 줄어듦”으로 설명하고, 입력 방향 vᵢ를 따라 길이 1만큼 변화시킬 때 출력 변화의 크기가 σᵢ임을 명시합니다. 3배와 0.5배 장면에서는 해당 입력·출력 화살표를 함께 강조합니다. 마지막은 “행렬이 방향마다 얼마나 민감하게 반응하는지 보여주는 감도 지도”로 마무리합니다.

2편 수정본은 기존 00:00–01:39 타임라인을 유지합니다. 설명의 중심은 “그 방향의 입력 차이가 출력까지 얼마나 살아남는가”입니다. 00:25–00:35에는 단위 변화 1이 특잇값 크기의 출력 변화로 바뀌는 별도 도식을 쓰고, 이후 작은 차이 ε의 전달로 돌아옵니다. 0.2에서는 출력의 차이가 작아짐을, 정확히 0에서는 그 방향의 차이가 사라짐을 구별합니다.

1편 수정본은 115초입니다. 기본 패턴 uᵢvᵢᵀ와 그 세기를 조절하는 σᵢ를 구분합니다. 4를 남길 때의 제곱 오차 2²+1²+0.3²=5.09와 2를 남길 때의 4²+1²+0.3²=17.09를 두 패널로 비교합니다. 기본 rank-1 패턴들이 Frobenius 내적에서 정규직교하므로 버린 특잇값의 제곱을 더할 수 있습니다. 마지막은 “무엇부터 잊을지를 정해줍니다”로 마무리합니다.

`python scripts/prepare_svd.py`로 대본, SRT, 에피소드 진입점을 재생성합니다. `python scripts/render.py svd01 --preview`로 360×640 미리보기, `python scripts/render.py svd01`로 최종 영상을 만듭니다. svd02부터 svd05까지도 동일합니다.

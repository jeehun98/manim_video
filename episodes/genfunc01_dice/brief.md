# 생성함수 쇼츠 제작 기준

- 사용자 제공 대본·종료 시각 확정본: 176초, 9:16, 1080×1920, 30fps.
- 청록 첫 주사위, 빨강 두 번째 주사위, 노랑 지수·결과, 초록 계수·경우의 수.
- 순서가 구별되는 두 주사위의 36가지 결과. 합 7은 6가지.
- 지수법칙 → 동류항 수집 → 전체 분포 → 일반 수열 → 10개 주사위 → 형식적 멱급수.
- a_n은 크기 n인 구조의 개수이며, 예시 상자는 구조의 크기만 표시한다.
- G=1/(1-x)는 형식적 멱급수의 항등식. 실수 급수 해석 시 |x|<1을 화면에 병기.
- 6^10=60,466,176. 압축된 표현이 계수 추출의 계산까지 없애지는 않음을 화면에 명시.
- 하단 고정 자막, 본문 하한 -4.9. 예고·복습·구독 유도 없음.
- 8개 씬 독립 렌더, 소스 해시로 캐시. TTS 미제공으로 무음.

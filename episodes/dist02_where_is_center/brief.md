# 분포의 수학 02 제작 기준

- 학습 목표: 최빈값(가장 큰 확률), 중앙값(누적 확률이 1/2을 지나는 위치), 평균(확률질량의 균형점)을 구별한다.
- 첫 대칭 이산 분포는 `x=-4,…,4`, 확률 `[.04,.07,.11,.18,.20,.18,.11,.07,.04]`다. 최빈값, 중앙값, 평균 모두 0이다. `P(X<0)=.40`, `P(X≤0)=.60`이므로 이산 중앙값의 중심 질량을 고려한다.
- 오른쪽 `x=8`에 확률 `.08`을 추가할 때 기존 확률은 모두 `.92`배로 정규화한다. 이 분포의 최빈값과 중앙값은 0, 평균은 `.64`다. 먼 값 하나만으로 세 중심이 모두 달라진다고 그리지 않는다.
- 세 중심이 갈라지는 별도 비대칭 분포는 `x=-4,…,4,8`, 확률 `[.02,.03,.05,.08,.20,.18,.15,.10,.07,.12]`다. 합은 1, 최빈값 0, 중앙값 1, 평균 1.67이다. 화면에서 “분포 모양을 더 바꾸면”이라고 전환을 명시한다.
- 마지막 두 분포의 평균은 모두 0이다. 좁은 A는 `P(-1,0,1)=(.15,.70,.15)`, 넓은 B는 `P(-3,-2,0,2,3)=(.25,.15,.20,.15,.25)`다.
- 순서: 중심 질문 → Mode → Median → Mean → 대칭일 때 겹침 → 먼 값 추가 → 평균 이동 → 별도 비대칭 예시에서 세 중심 분리 → 평균의 의미 → 같은 평균·다른 퍼짐.
- 목표 길이 70초, 구간 경계 7, 13, 20, 28, 33, 39, 46, 54, 61, 70초. 1080×1920, 30fps 무음. 화면·자막·대본은 숫자·영문 원문 표기, 발음 표기는 TTS 파일에 둔다.

# 제작 기준 — Softmax의 치명적인 결함

- 납품: 106초, 9:16 세로 쇼츠 하나, 1080×1920, 30fps. 기본 무음, 별도 TTS 원고와 SRT.
- 사용자 제공 문장과 종료 시각을 확정 기준으로 사용. 24개 발화 구간, 27개 시각 컷.
- 어두운 남색 바탕, 정상 계산 청록, 소실 빨강, 해결 연두. 복습과 다음 편 예고 없음.
- 학습 목표: 실수에서 동치인 식도 유한 정밀도 계산에서는 결과가 달라질 수 있다.
- 조건: one-hot 정답, 유한한 로짓, 정답 로짓의 기울기. 모든 파라미터의 학습이 멈춘다는 뜻이 아님.
- FP32 예시는 이진 표현 가능한 눈금으로 설명. 0.99999999의 FP32 반올림은 1.0.
- 개선식은 작은 지수항을 로짓 차이에서 직접 계산. 반올림된 정답 확률에서 복원하는 방식이 아님. 지수 언더플로 한계는 남음.
- 86–93초 Slingshot 비교는 개념도로 명시, 실제 연구 데이터 수치로 사용하지 않음.
- 연구 카드: 공식 논문 제목, 저자, 소속, arXiv 식별자 재조판. 웹 캡처가 아님.

# Quantization 시리즈 4편 제작 기준

- 이 편의 유일한 핵심은 `Zero Point = 실수 0을 표현하는 정수 값`이다.
- Scale은 축의 한 칸 크기, Zero Point는 축의 위치라는 대비를 유지한다.
- `−1~3 ↔ 0~255`에서는 이상적인 zero point가 `63.75`이며 정수로 반올림해 약 `64`로 표현한다. 정확히 64라고 단정하지 않고 화면과 내레이션에서 `≈64`를 사용한다.
- `−3~1 ↔ 0~255`에서는 zero point가 약 `191`로 이동한다. 정수 격자는 고정하고 실수 자의 숫자와 0 마커를 이동시킨다.
- 복원식은 `x≈s(q−z)`만 소개하며 zero point 계산식의 상세 유도는 하지 않는다.
- 대칭 예시는 `−1~1 ↔ −127~127`, `z=0`으로 제한한다. 하드웨어상 이점은 다루지 않는다.
- clipping, rounding error의 상세 분석, calibration, per-channel zero point는 제외한다.
- 마지막 `0.43→0.44` 장면은 다음 Quantization Error 편의 질문만 제시한다.
- 영상은 60초, 1080×1920, 30fps, 무음 마스터다.

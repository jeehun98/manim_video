# AI 컴파일러 02 — 유한한 기억으로 모든 규칙을 인식할 수 있을까?

부제: 유한 오토마타와 학습되는 기억.

## 현재 제작 기준

- 6장면, 사용자 문장 종료 시각 기준 140초. 종료 21/34/47/75/91/140초. 실제 음원 파일 대조는 미실시다.
- 세로 1080×1920·30fps, 미리보기 360×640, 무음. 31개 화면 변화 구간을 timing.json·SRT·내레이션에 정렬한다.
- TTS 원고는 화면 변화마다 빈 줄 하나로 분리하고 타임코드·제목을 제외한다. 발음 표기는 TTS에만 적용한다.
- 복습·시리즈 요약·후속 예고 없이 이 영상 자체의 질문과 결론으로 완결한다.

## 주장과 구성

| 시간 | 내용 |
|---|---|
| 0–21 | A*B: 입력 전체 대신 현재 상태로 판정 |
| 21–34 | AⁿBⁿ: 과거의 개수가 미래의 판정에 필요 |
| 34–47 | 유한 상태의 수보다 많은 과거 중 충돌이 존재 |
| 47–75 | AA와 AAAAA가 하나의 q로 합쳐지는 설명용 예시, 공통 BB 이후 판정 모순 |
| 75–91 | 별도 스택에 미대응 A의 개수를 보존 |
| 91–140 | RNN의 학습된 상태 갱신과 미래를 위해 남겨야 할 정보, 구별 가능한 과거라는 결론 |

## 정확성 조건

1. 알파벳 {A,B}, 입력 종료 시 전체 문자열을 판정한다. A*B는 부분 검색이 아니며, 비교 언어는 {AⁿBⁿ | n≥1}이다. 공문자열은 후자에서 제외된다.
2. 상태가 k개인 DFA에서 A¹부터 Aᵏ⁺¹까지의 k+1개 접두사는 적어도 두 상태가 같아진다. 어떤 1≤i<j에 대해 q_i=q_j이다. 동일한 Bⁱ를 읽으면 최종 상태도 같지만 AⁱBⁱ는 수용, AʲBⁱ는 거부해야 하므로 모순이다. NFA도 대응하는 유한 DFA가 있으므로 인식 불가능하다.
3. AA와 AAAAA는 일반적인 모든 기계가 충돌하는 고정 입력 쌍이 아니다. 일반적인 충돌 존재를 먼저 표시하고 2회·5회가 설명용 예시임을 계속 표시한다. 두 경로가 하나의 q로 합쳐진 뒤 공통 BB를 처리한다. k/i/j는 내레이션으로 읽지 않는다.
4. n의 상한이 정해지면 유한 상태로 인식 가능하다. 모든 유한 상태 기계가 개수 정보를 전혀 보존하지 못하는 것은 아니다.
5. 스택은 이론적으로 크기 제한이 없는 외부 기억이다. 유한 제어로 A 구간/B 구간을 구별한다. B 뒤의 A, 빈 스택에서 B, 입력 종료 시 남은 표식, 공문자열을 거부한다. AABB는 수용한다.
6. RNN과 DFA는 입력을 순차 처리하며 현재 상태를 갱신한다는 구조로 연결한다. h_t=f_theta(h_(t-1),x_t). 은닉 상태의 차원만으로 유한 오토마타와 동일한 인식 한계를 주장하지 않는다. RNN이 스택 인식기의 능력을 자동으로 얻거나 정확한 개수 알고리즘을 학습했다고 주장하지 않는다.
7. 명시적 전이와 학습된 갱신의 대비는 이 영상의 설계 예시이다. 모든 오토마타를 사람이 수작업으로 설계한다는 일반 명제가 아니다. 정규식에서 생성하거나 학습된 모델에서 추출하는 경우도 있다.
8. 같은 상태로 합쳐진 두 과거는 같은 후속 입력을 받으면 구별되지 않는다. 이미 버린 정보가 다른 후속 입력의 중복 단서로도 절대 추론될 수 없다는 포괄적 주장이 아니다. 영상은 같은 상태·같은 후속 입력 조건을 명시한다.
9. 정규 언어의 두 과거를 같은 상태로 묶으려면 가능한 모든 후속 입력에 대해 수용 여부가 같아야 한다. 어떤 접미사에서라도 판정이 다르면 구별해야 한다. RNN에서도 미래 과제에 필요한 정보를 보존하는지를 묻되, 근사 예측을 형식언어의 정확한 인식 정리와 동일시하지 않는다.
10. 이전 판의 하드웨어 정밀도 설명과 길이 일반화·짧은 학습 성공/긴 입력 비교·패턴 대 규칙 질문은 현행 영상과 대본에서 삭제했다. 현재 결론은 무엇을 구별할 수 있도록 기억하는가이다.

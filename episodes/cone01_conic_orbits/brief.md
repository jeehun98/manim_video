# 가장 완벽한 도형, 원뿔 — 우주의 궤도를 설명하는 기하학

사용자 제공 40문장·종료 시각 기준 177초. 9:16 쇼츠, 1080×1920·30fps. TTS 음원 미제공으로 무음이며 모든 문장을 화면 자막에 넣는다. 대본·문장 종료 시각은 변경하지 않는다.

핵심: 이중 원뿔 `x²+y²=z²`와 평면 `z=ax+b`의 교점을 화면의 등각 투영으로 보여준다. 수평 절단은 원, 기울어진 절단은 타원, 모선과 평행한 경계는 포물선, 두 원뿔을 가로지르는 절단은 쌍곡선이다. 원뿔은 실제 궤도를 만드는 원인이 아니다.

물리 모델: 하나의 이상적인 점질량 중력 중심에서 `μ=r₀=1`, 출발 위치는 일정하고 접선 속도만 바꾼다. `e=v₀²−1`로 원 `e=0`, 타원 `e=.47`, 포물선 `e=1`, 쌍곡선 `e=1.5`를 만든다. 화면의 궤적은 `r=p/(1+e cosθ)`에서 계산하고 `p=r₀(1+e)`를 사용한다. 역제곱 중력의 운동방정식과 각운동량 보존을 거친 결과라는 중간 표시를 둔다. 유한한 화면 때문에 열린 궤도는 적당한 반지름에서 잘라 그린다.

타원의 첫 초점은 태양이며, 다른 초점은 `a`, `b`로부터 `c=√(a²−b²)`로 정해지는 기하학적 위치다. 초점 설명에는 형태가 분명한 `e=.65` 타원을 사용한다. 두 번째 초점에서 행성으로 향하는 힘 화살표는 표시하지 않는다. 행성이 받는 중력 벡터는 행성에서 태양 방향으로만 그린다.

시각 규칙: 남색 배경, 청록 원, 푸른 타원, 노란 포물선, 보라 쌍곡선, 주황 태양·중력, 투명한 푸른 절단 평면. 서사는 `원뿔 절단 → 같은 네 궤도 → 하나의 중력 중심 → 두 번째 초점의 의미 → 역제곱 법칙 → 공통 원뿔곡선`으로 독립적으로 완결한다.
